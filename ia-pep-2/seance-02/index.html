🧰 Séance 02 — Panorama des outils d'IA pour l'enseignantSession 02 — Overview of AI tools for the teacherالحصة 02 — نظرة عامة على أدوات الذكاء الاصطناعي للمعلّم

Découvrir les principales familles d'outils d'IA (texte, images, quiz, voix) et apprendre à choisir l'outil adapté à une tâche de classe. Discover the main families of AI tools (text, images, quizzes, voice) and learn to choose the right tool for a classroom task. اكتشاف أهمّ عائلات أدوات الذكاء الاصطناعي (نصوص، صور، اختبارات، صوت) والتعلّم كيفية اختيار الأداة المناسبة لمهمّة صفّية.

Durée : 1 h 30 · Module « Intelligence Artificielle » · 2ème année PEP — ENS Duration: 1 h 30 · Module "Artificial Intelligence" · 2nd year PEP — ENS المدّة: 1 h 30 · وحدة « الذكاء الاصطناعي » · السنة الثانية PEP — المدرسة العليا للأساتذة

🎯 Objectifs pédagogiques 🎯 Learning objectives 🎯 الأهداف البيداغوجية
  • Citer et décrire 5 familles d'outils d'IA utiles à l'enseignant.
  • Pour une tâche donnée (préparer une leçon, illustrer, évaluer), choisir la famille et l'outil adapté.
  • Construire un tableau comparatif de 3 outils sur des critères précis (coût, facilité, RGPD, langue).
  • Identifier les précautions de base avant d'utiliser un outil avec des élèves (âge, données personnelles).
  • Name and describe 5 families of AI tools useful to the teacher.
  • For a given task (preparing a lesson, illustrating, assessing), choose the right family and tool.
  • Build a comparison table of 3 tools using precise criteria (cost, ease, GDPR, language).
  • Identify basic precautions before using a tool with pupils (age, personal data).
  • أن يذكر ويصف خمس عائلات من أدوات الذكاء الاصطناعي المفيدة للمعلّم.
  • أن يختار العائلة والأداة المناسبة لمهمّة معيّنة (تحضير درس، توضيح، تقييم).
  • أن يبني جدولاً مقارناً لثلاث أدوات وفق معايير دقيقة (التكلفة، السهولة، حماية البيانات، اللغة).
  • أن يحدّد الاحتياطات الأساسية قبل استعمال أداة مع التلاميذ (السنّ، البيانات الشخصية).

Les 6 familles d'outils d'IAThe 6 families of AI toolsالعائلات الست لأدوات الذكاء الاصطناعي

Pour se repérer, on classe les outils d'IA en six grandes familles selon ce qu'ils produisent. Un même site peut cumuler plusieurs familles.

Zoom sur les assistants de texteFocus on text assistantsتوقّف عند المساعدات النصّية

Ce sont les outils les plus utilisés : ils peuvent rédiger, résumer, reformuler, traduire, proposer des exercices. Pour un enseignant, ils font gagner beaucoup de temps sur la préparation.

  • Usages concrets : rédiger la consigne d'un exercice, adapter un texte à un niveau de lecture, créer une dictée, reformuler une explication simple.
  • Point de vigilance : toujours relire et vérifier le contenu (niveau de langue, exactitude des faits, vocabulaire adapté à l'âge).
  • Exemples : ChatGPT, Gemini, Claude, Le Chat (Mistral), Copilot.

These are the most used tools: they can write, summarise, rephrase, translate, propose exercises. For a teacher, they save a lot of preparation time.

  • Concrete uses: write exercise instructions, adapt a text to a reading level, create a dictation, rephrase a simple explanation.
  • Watch out: always proofread and check the content (language level, factual accuracy, age-appropriate vocabulary).
  • Examples: ChatGPT, Gemini, Claude, Le Chat (Mistral), Copilot.

وهي الأدوات الأكثر استعمالاً: يمكنها الكتابة والتلخيص وإعادة الصياغة والترجمة واقتراح التمارين. وهي توفّر للمعلّم وقتاً كبيراً في التحضير.

  • استعمالات ملموسة: كتابة تعليمة تمرين، تكييف نص مع مستوى قراءة، إعداد إملاء، إعادة صياغة شرح مبسّط.
  • نقطة يقظة: المراجعة والتحقق دائماً من المحتوى (مستوى اللغة، دقة الحقائق، مفردات مناسبة للسنّ).
  • أمثلة: ChatGPT, Gemini, Claude, Le Chat (Mistral), Copilot.

Zoom sur les générateurs d'imagesFocus on image generatorsتوقّف عند مولّدات الصور

Un générateur d'images transforme une description en texte en une illustration. Utile pour illustrer une leçon, créer un poster, un coloriage ou un personnage de classe.

  • Consigne de description : sujet, style (aquarelle, bande dessinée, photo), ambiance (lumineux), et ce qu'il ne faut PAS représenter.
  • Exemples : DALL·E (dans ChatGPT/Bing), Midjourney, Leonardo, Ideogram, et l'outil « Magic Media » de Canva.
  • Précautions : vérifier le réalisme (déformations), respecter les droits d'auteur, ne pas figurer de vrai enfant identifiable.
Règle RGPD de base : ne jamais importuner d'image ou de nom d'élève réel dans un générateur d'images. Les images produites doivent rester génériques et anonymes.

An image generator turns a text description into an illustration. Useful to illustrate a lesson, create a poster, a colouring sheet or a class mascot.

  • Description prompt: subject, style (watercolour, comic, photo), mood (bright), and what should NOT be depicted.
  • Examples: DALL·E (in ChatGPT/Bing), Midjourney, Leonardo, Ideogram, and Canva's "Magic Media" tool.
  • Precautions: check realism (deformations), respect copyright, never depict an identifiable real child.
Basic GDPR rule: never feed a real pupil's image or name into an image generator. Generated images must remain generic and anonymous.

يحوّل مولّد الصور وصفاً نصّياً إلى رسم توضيحي. وهو مفيد لتوضيح درس، أو صنع ملصق، أو صفحة تلوين، أو شخصية القسم.

  • تعليمة الوصف: الموضوع، الأسلوب (ألوان مائية، قصص مصوّرة، صورة فوتوغرافية)، الجوّ (مضيء)، وما يجب ألّا يُصوَّر.
  • أمثلة: DALL·E (داخل ChatGPT/Bing)، Midjourney، Leonardo، Ideogram، وأداة « Magic Media » في Canva.
  • احتياطات: التحقق من الواقعية (تشوّهات)، احترام حقوق المؤلف، وعدم إظهار طفل حقيقي يمكن التعرّف عليه.
قاعدة أساسية لحماية البيانات: لا تُدخل أبداً صورة أو اسم تلميذ حقيقي في مولّد صور. يجب أن تبقى الصور المولّدة عامة ومجهولة الهوية.

Zoom sur les outils de quiz, de voix et de présentationFocus on quiz, voice and presentation toolsتوقّف عند أدوات الاختبارات والصوت والعروض

Ces outils se concentrent sur des tâches très précises, souvent avec des versions gratuites suffisantes pour une classe.

  • Quiz / évaluation : Quizizz AI, Kahoot, LearningApps, Socrative — générer un QCM à partir d'une consigne, avec correction automatique.
  • Voix / audio : synthèse vocale pour lire un texte à voix haute (aide à la lecture), génération de dictées audio.
  • Présentation : Gamma, Canva, PowerPoint — créer des diapositives structurées à partir d'un plan.
Conseil pratique : testez toujours l'outil sur un appareil d'élève avant la séance. Un outil « gratuit » peut afficher de la publicité inadaptée à des enfants.

These tools focus on very specific tasks, often with free versions that are enough for a classroom.

  • Quiz / assessment: Quizizz AI, Kahoot, LearningApps, Socrative — generate a quiz from a prompt, with automatic marking.
  • Voice / audio: speech synthesis to read a text aloud (reading support), generate audio dictations.
  • Presentation: Gamma, Canva, PowerPoint — build structured slides from an outline.
Practical tip: always test the tool on a pupil's device before the session. A "free" tool may show advertising unsuitable for children.

تتركّز هذه الأدوات على مهام دقيقة جداً، وغالباً ما تكون نسخها المجانية كافية لقسمٍ دراسي.

  • الاختبارات والتقييم: Quizizz AI, Kahoot, LearningApps, Socrative — توليد أسئلة من تعليمة، مع تصحيح آلي.
  • الصوت: تركيب كلامي لقراءة نصّ جهراً (دعم للقراءة)، وتوليد إملاءات صوتية.
  • العروض: Gamma, Canva, PowerPoint — إنشاء شرائح منمّقة انطلاقاً من خطة.
نصيحة عملية: جرّبوا الأداة دائماً على جهاز تلميذ قبل الحصة. قد تعرض أداة « مجانية » إعلانات غير مناسبة للأطفال.

Choisir le bon outil pour la bonne tâcheChoose the right tool for the right taskاختيار الأداة المناسبة للمهمّة المناسبة

Voici une grille de décision en 5 questions à poser avant tout choix d'outil :

  1. Quelle tâche ? Rédiger → texte. Illustrer → image. Évaluer → quiz. Présenter → diaporama.
  2. Pour qui ? Un élève de CP n'a pas le même outil qu'un collègue qui prépare un cours.
  3. Combien ça coûte ? Y a-t-il une version gratuite suffisante ? Puis-je l'utiliser hors connexion ?
  4. Où vont les données ? L'outil respecte-t-il le RGPD ? Peut-on l'utiliser avec les élèves (âge minimum) ?
  5. Qui vérifie ? Le contenu généré est-il fiable ? Qui relit avant de l'utiliser en classe ?

Here is a 5-question decision grid to ask before choosing any tool:

  1. What task? Writing → text. Illustrating → image. Assessing → quiz. Presenting → slides.
  2. For whom? A Year-1 pupil does not get the same tool as a colleague preparing a lesson.
  3. How much? Is there a good enough free version? Can I use it offline?
  4. Where do the data go? Does the tool respect the GDPR? Can it be used with pupils (minimum age)?
  5. Who checks? Is the generated content reliable? Who reviews it before class?

إليكم شبكة قرار من خمسة أسئلة تطرحونها قبل اختيار أي أداة:

  1. ما المهمّة؟ الكتابة → نصّ. التوضيح → صورة. التقييم → اختبار. العرض → شرائح.
  2. لمن؟ تلميذ التحضيري لا يملك نفس أداة الزميل الذي يحضّر درساً.
  3. كم التكلفة؟ هل توجد نسخة مجانية كافية؟ هل يمكن الاستعمال دون اتصال؟
  4. إلى أين تذهب البيانات؟ هل تحترم الأداة قواعد حماية البيانات؟ هل تصلح للتلاميذ (سنّ أدنى)؟
  5. من يتأكّد؟ هل المحتوى المولّد موثوق؟ ومن يراجعه قبل استعماله في القسم؟

Un scénario complet : la leçon de sciences de la semaineA complete scenario: the week's science lessonسيناريو كامل: درس العلوم لهذا الأسبوع

Prenons un exemple : préparer une leçon de découverte du monde sur « le cycle de l'eau » pour des CP.

  1. Avec un assistant de texte : rédiger le déroulé de la séance et 3 phrases simples de synthèse.
  2. Avec un générateur d'images : créer 2 illustrations schématiques (nuage, rivière, soleil).
  3. Avec un générateur de quiz : produire 4 questions vrai/faux à projeter en fin de séance.
  4. Avec la synthèse vocale : enregistrer la lecture des 3 phrases pour la mise en autonomie.
À faire noter aux étudiants : un même objectif de cours peut mobiliser 4 outils différents. Le rôle de l'enseignant reste de coordonner et de vérifier.

Let's take an example: preparing a "discovering the world" lesson on the water cycle for Year-1 pupils.

  1. With a text assistant: write the session plan and 3 simple summary sentences.
  2. With an image generator: create 2 schematic illustrations (cloud, river, sun).
  3. With a quiz generator: produce 4 true/false questions to project at the end.
  4. With speech synthesis: record the reading of the 3 sentences for independent work.
Point to note: one lesson objective can involve 4 different tools. The teacher's role remains to coordinate and to check.

لنأخذ مثالاً: تحضير درس اكتشاف العالم حول « دورة الماء » لأقسام التحضيري الابتدائي.

  1. بمساعدة المساعد النصّي: كتابة خطّ الحصة وثلاث جمل بسيطة للتلخيص.
  2. بمولّد الصور: إنشاء رسمين توضيحيين مخططين (سحابة، نهر، شمس).
  3. بمولّد الاختبارات: إنتاج أربعة أسئلة صح/خطأ لعرضها في نهاية الحصة.
  4. بالتركيب الصوتي: تسجيل قراءة الجمل الثلاث للعمل المستقل.
ما ينبغي تذكيره للطلبة: هدف درس واحد يمكن أن يحرّك أربع أدوات مختلفة. ويبقى دور المعلّم هو التنسيق والتحقق.

✏️ Activités et exercices✏️ Activities and exercises✏️ الأنشطة والتمارين

  • Démo collective : montrer un exemple de production de 3 outils (texte, image, quiz) sur le même sujet de leçon.
  • Tableau comparatif (binômes) : 3 outils × 5 critères (coût, facilité, qualité, RGPD, langue). Remplir une case avec un « + », un « = » ou un « − ».
  • Défi « trouver la bonne famille » : pour 4 situations (dictée, coloriage, affiche, auto-correction), choisir la famille d'outil adaptée et justifier.
  • Collective demo: show one output of 3 tools (text, image, quiz) on the same lesson topic.
  • Comparison table (in pairs): 3 tools × 5 criteria (cost, ease, quality, GDPR, language). Fill in each cell with a "+", "=" or "−".
  • "Find the right family" challenge: for 4 situations (dictation, colouring, poster, self-check), choose the right tool family and justify.
  • عرض جماعي: إظهار مثال من إنتاج ثلاث أدوات (نصّ، صورة، اختبار) حول نفس موضوع الدرس.
  • جدول مقارنة (مجموعات ثنائية): 3 أدوات × 5 معايير (التكلفة، السهولة، الجودة، حماية البيانات، اللغة). ملء كل خانة بـ « + » أو « = » أو « − ».
  • تحدّي « ابحث عن العائلة المناسبة »: لأربع حالات (إملاء، تلوين، ملصق، تصحيح ذاتي)، اختيار عائلة الأداة المناسبة وتبرير ذلك.

🧠 À retenir🧠 Key takeaways🧠 ما يجب تذكّره

  • Six familles d'outils : texte, images, voix, quiz, présentation, vidéo.
  • On choisit un outil selon la tâche, le public, le coût, la protection des données et la vérification.
  • Pas d'outil sans vérification : l'enseignant garde le dernier mot.
  • La version gratuite suffit souvent pour une classe ; toujours tester sur un appareil d'élève.
  • Six tool families: text, images, voice, quizzes, presentation, video.
  • Choose a tool according to the task, the audience, cost, data protection and verification.
  • No tool without checking: the teacher has the final word.
  • The free version is often enough for a class; always test on a pupil's device.
  • ستّ عائلات أدوات: النصوص، الصور، الصوت، الاختبارات، العروض، الفيديو.
  • نختار الأداة حسب المهمّة والجمهور والتكلفة وحماية البيانات والتحقق.
  • لا أداة بلا تحقق: كلمة الفصل للمعلّم.
  • غالباً ما تكفي النسخة المجانية لقسم؛ ونختبر دائماً على جهاز تلميذ.

Assistant conversationnel — Chatbot / conversational assistant

Outil d'IA qui répond en textes à des questions (ChatGPT, Gemini…).

An AI tool that answers questions in text (ChatGPT, Gemini…).

أداة ذكاء اصطناعي تجيب نصوصاً عن الأسئلة (ChatGPT, Gemini…).

Générateur d'images — Image generator

Outil qui crée une image à partir d'une description en texte.

A tool that creates an image from a text description.

أداة تنشئ صورة انطلاقاً من وصف نصّي.

Synthèse vocale (TTS) — Text-to-Speech (TTS)

Transformation d'un texte écrit en audio parlé par une voix artificielle.

Conversion of written text into spoken audio using an artificial voice.

تحويل نصّ مكتوب إلى صوت منطوق بصوت اصطناعي.

Freemium — Freemium

Modèle où une version de base est gratuite et les fonctions avancées payantes.

A model where a basic version is free and advanced features are paid.

نموذج تكون فيه النسخة الأساسية مجانية والوظائف المتقدّمة مدفوعة.

Famille d'outils — Tool family

Catégorie d'outils produisant le même type de résultat (textes, images…).

A category of tools producing the same type of output (texts, images…).

فئة من الأدوات تنتج نفس النوع من النتائج (نصوص، صور…).

RGPD — GDPR

Règlement européen protégeant les données personnelles ; impose des précautions pour les données d'élèves.

European regulation protecting personal data; it requires precautions for pupil data.

اللائحة الأوروبية لحماية المعطيات الشخصية؛ تفرض احتياطات بشأن بيانات التلاميذ.
