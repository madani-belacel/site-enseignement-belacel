# Séance 02 — Overview of AI tools for the teacher

**Module : Intelligence Artificielle — 2ème année PEP (ENS)**  
**Auteur : Dr. Madani BELACEL — Université de Mostaganem**  
**Durée : 1 h 30**  

Discover the main families of AI tools (text, images, quizzes, voice) and learn to choose the right tool for a classroom task.

## Objectifs pédagogiques
- Name and describe 5 families of AI tools useful to the teacher.
- For a given task (preparing a lesson, illustrating, assessing), choose the right family and tool.
- Build a comparison table of 3 tools using precise criteria (cost, ease, GDPR, language).
- Identify basic precautions before using a tool with pupils (age, personal data).

## Déroulé de la séance (1 h 30)
- **00–10 — Welcome, recap and survey** : Recap of session 1. Survey: "Which AI tools have you already used?".
- **10–30 — The 6 tool families** : Text, images, voice/audio, quizzes/assessment, presentation, video. Examples for each family.
- **30–55 — Guided demo of 3 tools** : A text assistant, an image generator, a quiz generator. Live, if connected.
- **55–70 — Choosing criteria for a tool** : Cost, ease, quality, data protection (GDPR), pupil age, language, reliability.
- **70–80 — Activity: comparison table** : In pairs: compare the 3 tools seen in the demo on a shared board.
- **80–90 — Wrap-up and preview of session 3** : Collective takeaways. Preview: large language models (LLMs).

## Contenu détaillé
### The 6 families of AI tools
To get oriented, we classify AI tools into six main families according to what they produce. One site can combine several families.

| Family | What it produces | Common examples |
|---|---|---|
| 📝 Text | Texts, summaries, translations, lesson plans | ChatGPT, Gemini, Claude, Copilot, Le Chat (Mistral) |
| 🖼️ Images | Illustrations, posters, colouring sheets, characters | DALL·E (in Bing/GPT), Midjourney, Leonardo, Ideogram, Canva Magic |
| 🎤 Voice / audio | Audio from text (synthetic voices), subtitles | Text-to-Speech tools, ElevenLabs |
| 📊 Quiz / assessment | Quizzes, exercises, marking grids | Quizizz AI, LearningApps, Moodle (auto questions) |
| 📽️ Presentation | Slides, visual support | Gamma, Canva, PowerPoint Copilot |
| 🎬 Video | Short educational videos, talking avatars | Synthesia, HeyGen (avatars), AI editing tools |
> 💡 **<strong>Mindset:</strong> "An AI tool is like a versatile colleague: you must know their specialities and call the right specialist for the right task."**

### Focus on text assistants
These are the most used tools: they can write, summarise, rephrase, translate, propose exercises. For a teacher, they save a lot of preparation time.

- <strong>Concrete uses:</strong> write exercise instructions, adapt a text to a reading level, create a dictation, rephrase a simple explanation.
- <strong>Watch out:</strong> always proofread and check the content (language level, factual accuracy, age-appropriate vocabulary).
- <strong>Examples:</strong> ChatGPT, Gemini, Claude, Le Chat (Mistral), Copilot.

### Focus on image generators
An image generator turns a text description into an illustration. Useful to illustrate a lesson, create a poster, a colouring sheet or a class mascot.

- <strong>Description prompt:</strong> subject, style (watercolour, comic, photo), mood (bright), and what should NOT be depicted.
- <strong>Examples:</strong> DALL·E (in ChatGPT/Bing), Midjourney, Leonardo, Ideogram, and Canva's "Magic Media" tool.
- <strong>Precautions:</strong> check realism (deformations), respect copyright, never depict an identifiable real child.
> 💡 **<strong>Basic GDPR rule:</strong> never feed a real pupil's image or name into an image generator. Generated images must remain generic and anonymous.**

### Focus on quiz, voice and presentation tools
These tools focus on very specific tasks, often with free versions that are enough for a classroom.

- <strong>Quiz / assessment:</strong> Quizizz AI, Kahoot, LearningApps, Socrative — generate a quiz from a prompt, with automatic marking.
- <strong>Voice / audio:</strong> speech synthesis to read a text aloud (reading support), generate audio dictations.
- <strong>Presentation:</strong> Gamma, Canva, PowerPoint — build structured slides from an outline.
> 💡 **<strong>Practical tip:</strong> always test the tool on a pupil's device before the session. A "free" tool may show advertising unsuitable for children.**

### Choose the right tool for the right task
Here is a 5-question decision grid to ask before choosing any tool:

- <strong>What task?</strong> Writing → text. Illustrating → image. Assessing → quiz. Presenting → slides.
- <strong>For whom?</strong> A Year-1 pupil does not get the same tool as a colleague preparing a lesson.
- <strong>How much?</strong> Is there a good enough free version? Can I use it offline?
- <strong>Where do the data go?</strong> Does the tool respect the GDPR? Can it be used with pupils (minimum age)?
- <strong>Who checks?</strong> Is the generated content reliable? Who reviews it before class?

### A complete scenario: the week's science lesson
Let's take an example: preparing a "discovering the world" lesson on the water cycle for Year-1 pupils.

- With a text assistant: write the session plan and 3 simple summary sentences.
- With an image generator: create 2 schematic illustrations (cloud, river, sun).
- With a quiz generator: produce 4 true/false questions to project at the end.
- With speech synthesis: record the reading of the 3 sentences for independent work.
> 💡 **<strong>Point to note:</strong> one lesson objective can involve 4 different tools. The teacher's role remains to coordinate and to check.**

## Activités et exercices
- Collective demo: show one output of 3 tools (text, image, quiz) on the same lesson topic.
- Comparison table (in pairs): 3 tools × 5 criteria (cost, ease, quality, GDPR, language). Fill in each cell with a "+", "=" or "−".
- "Find the right family" challenge: for 4 situations (dictation, colouring, poster, self-check), choose the right tool family and justify.

## À retenir
- Six tool families: text, images, voice, quizzes, presentation, video.
- Choose a tool according to the task, the audience, cost, data protection and verification.
- No tool without checking: the teacher has the final word.
- The free version is often enough for a class; always test on a pupil's device.

## Glossaire
- **Assistant conversationnel** : An AI tool that answers questions in text (ChatGPT, Gemini…).
- **Générateur d'images** : A tool that creates an image from a text description.
- **Synthèse vocale (TTS)** : Conversion of written text into spoken audio using an artificial voice.
- **Freemium** : A model where a basic version is free and advanced features are paid.
- **Famille d'outils** : A category of tools producing the same type of output (texts, images…).
- **RGPD** : European regulation protecting personal data; it requires precautions for pupil data.
