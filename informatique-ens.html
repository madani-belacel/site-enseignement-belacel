📚 Module Informatique ENS

Informatique fondamentale pour l'École Normale Supérieure

  1. Accueil
  2. Enseignement
  3. Informatique ENS

Description : Module d'informatique destiné aux étudiants de l'École Normale Supérieure. Contenu CS réel : algorithmique, Python, POO, bases de données, développement Web, Git, Scratch, projet tuteuré. 9 cours + 9 TD par année.

ENS 1ère année

Algorithmique et programmation (Python), Scratch, HTML/CSS, Git

🇫🇷 Version Française9 Cours + 9 TD 🇬🇧 Version Anglaise9 Courses + 9 Tutorials

ENS 2ème année

POO (Python), Bases de données (SQL), Développement Web, Projet

🇫🇷 Version Française9 Cours + 9 TD 🇬🇧 Version Anglaise9 Courses + 9 Tutorials

📋 Programme

ENS 1ère année

  • Cours 01 : Introduction à l'algorithmique
  • Cours 02 : Variables, types, opérateurs
  • Cours 03 : Structures de contrôle
  • Cours 04 : Fonctions et modularité
  • Cours 05 : Listes et chaînes
  • Cours 06 : Algorithmes fondamentaux
  • Cours 07 : Scratch par blocs
  • Cours 08 : Introduction au Web (HTML/CSS)
  • Cours 09 : Git et collaboration

ENS 2ème année

  • Cours 01 : Programmation Orientée Objet
  • Cours 02 : Classes et héritage
  • Cours 03 : Bases de données (SQL)
  • Cours 04 : Développement Web avancé
  • Cours 05 : Frameworks Web
  • Cours 06 : API REST et données
  • Cours 07 : Didactique de l'informatique
  • Cours 08 : Projet tuteuré
  • Cours 09 : Révision et synthèse
