ICT Tutorial 04 — Microsoft Word: Office Automation for Teaching

Instructor: BELACEL Madani Module: ICT Level: ENS Year 1 — English Department Duration: 1h30 Academic year: 2025-2026

(Email and detailed progress of the session: see PDF cover page.)

Exercise 1 — Lesson plan formatting (15 min)

Statement: Create a lesson preparation sheet with: header (level, subject, duration), objectives, procedure, assessment. Apply academic standards.

Corrected: Times New Roman 12, spacing 1.5. Header: 2-column table (information/value). Objectives written in infinitive form. Procedure: 4-column table (Phase/Duration/Activity/Mode).

Exercise 2 — Custom styles for teaching documents (15 min)

Statement: Create and customize 3 Word styles: Exercise-title (bold, blue, 14pt), Instruction (italic, 11pt), Answer (green, 11pt). Apply to an exercise document.

Corrected: Home → Styles → Create a Style. Customize font, size, color. Apply by selecting text. Save to Normal.dotm template for reuse.

Exercise 3 — Correcting and annotating student work (18 min)

Statement: Type a student text containing 5 intentional errors. Use track changes and comments to correct it as a teacher would.

Corrected: Review → Track Changes. Each correction appears in color. Comments: select text → New Comment. Write a constructive final feedback.

Exercise 4 — Mail merge for report cards (15 min)

Statement: Create a report card template and merge with an Excel list of 5 students (name, surname, subject, grade, comment).

Corrected: Mailings → Select Recipients → Use an existing list. Insert merge fields. Preview results. Finish & Merge → Edit individual documents.

Exercise 5 — Gap-fill exercise with table (14 min)

Statement: Design a gap-fill exercise on irregular verbs using Word tables (3 columns: infinitive, past, past participle) with blank cells to fill.

Corrected: Insert → Table → 4 rows × 3 columns. Header in bold. Leave cells blank. Protect answer cells if distributing via Moodle.

Exercise 6 — Annual teaching progression table (13 min)

Statement: Design an annual progression table for 30 weeks with: week, theme, objectives, assessment. Use tabs and indents for professional layout.

Corrected: Table: 4 columns × 32 rows (1 header + 30 weeks + 1 total). Landscape orientation. Title: "Annual Progression — English — Year 1 Secondary 2025-2026". Print on one page.
