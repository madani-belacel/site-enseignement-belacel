Course Overview — E-learning Platform (Moodle)

Learning Objectives

Knowledge: - Define ICT and its evolution - Distinguish technical, information, and communication dimensions - Understand pedagogical ICT integration in language didactics

Skills: - Use ICT tools to design teaching sequences - Evaluate and select digital resources for the classroom - Create interactive teaching materials

Attitudes: - Adopt a digital mediator posture in the classroom - Develop critical thinking about tools and resources

1. Definition and Evolution (10 min)

ICT covers digital tools and systems for creating, processing, storing, transmitting, and sharing information.

Evolution: NTIC (1990-2005) → ICT (2005-present) → AI and EdTech (2020+).

For the future teacher: ICT are not just personal tools but pedagogical instruments to integrate into teaching practice.

2. Three Dimensions (10 min)

Dimension Definition Pedagogical application
Technical Hardware + software IWB, tablet, Moodle, VLE
Information Content manipulated PDF, video, podcast resources
Communication Exchange between people Forum, videoconference, virtual classroom

3. ICT and Pedagogy (20 min)

Why integrate ICT in language teaching? - Learner motivation and engagement - Access to authentic resources (videos, articles, podcasts) - Individualized learning paths - Autonomy development

Application areas: - Listening: podcasts, audio recording - Writing: blogs, wikis, collaborative editing - Interaction: videoconferencing with partner classes - Grammar/vocabulary: interactive exercises, quizzes

4. The SAMR Model (15 min)

Level Meaning Example
Substitution Tech replaces without change Paper → PDF
Augmentation Tech improves the task PDF with hyperlinks
Modification Tech transforms the task Collaborative document (Google Docs)
Redefinition Tech creates new possibilities Project with partner class via video

Goal: aim for Modification and Redefinition levels.

Tool Use Type

6. Teacher Digital Competencies (15 min)

  1. Design sequences integrating digital tools
  2. Implement collaborative online activities
  3. Assess with digital tools
  4. Ensure security and ethics
  5. Develop professional monitoring

7. Ethics and Security (10 min)

  • GDPR compliance: protect student data
  • Copyright: use open-licensed resources (Creative Commons)
  • Cyberbullying: prevention in class
  • Digital identity: the teacher as a role model

8. Conclusion (5 min)

  • ICT are a pedagogical lever for language teachers
  • Integration must be thoughtful (SAMR model)
  • Future teachers must develop digital competencies
