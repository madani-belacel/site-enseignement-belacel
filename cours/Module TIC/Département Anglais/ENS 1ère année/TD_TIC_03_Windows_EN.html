(Email and detailed progress of the session: see PDF cover page.)

Exercise 1 — Interface identification (15 min)

Statement: In a screenshot, identify 8 elements of the Windows Desktop.

Fixed: Desktop, icons, taskbar, start menu, notification area, active window, trash, search bar.

Exercise 2 — Creating a tree (18 min)

Statement: Create the L1 Languages ​​tree in Documents (Courses, Tutorials, Exams, Projects, Saves).

Corrected: Structure conforms to the course convention with dated subfolders.

Exercise 3 — Professional naming (15 min)

Statement: Rename 5 files according to YYYY-MM-DD_Module_Type_Name_vX.ext.

Corrected: Ex. 2026-06-04_TIC_TD3_BELACEL_v1.docx — no prohibited characters.

Exercise 4 — Keyboard shortcuts (15 min)

Statement: Copy, cut, paste, cancel and lock session by keyboard only.

Fixed: Ctrl+C, Ctrl+X, Ctrl+V, Ctrl+Z, Windows+L.

Exercise 5 — Safety (17 min)

Statement: List 6 important safety rules for a student.

Fixed: Session lock, 3-2-1 backups, updates, antivirus, USB caution, strong passwords.

Exercise 6 — Windows et gestion de classe (10 min)

Statement: En tant qu'enseignant, comment organiser l'arborescence des fichiers d'une classe de 30 élèves sur un réseau Windows ? Proposez une structure de dossiers et des règles de nommage.

Detailed correction: Structure : D:\Année2025-2026[Matière][Élève_Nom]\Devoirs. Règles : nommer les fichiers avec la norme Nom_Prénom_Date_Type (ex. DUPONT_Marie_2026-01-15_Redaction.docx). Droits d'accès : enseignant en modification, élèves en lecture seule dans les dossiers des autres.
