Exercise 1 — Parsing a URL

Statement: Break down the URL https://www.univ-example.dz/cours/tic/chap2.html (protocol, domain, path).

Detailed correction: - https:// — secure HTTP protocol. - www.univ-example.dz — domain name (server). - /cours/tic/chap2.html — path to the resource (HTML page).

Exercise 2 — Browsers

Statement: Comparing two browsers (Chrome and Firefox): an advantage and an educational use for each.

Detailed correction: - Chrome: numerous extensions; synchronization Google account. - Firefox: enhanced privacy; open source development. - Use: documentary research, Moodle access, online PDF reading.

Exercise 3 — HTTP vs HTTPS

Statement: Why choose HTTPS to connect to the university platform?

Detailed correction: - Encryption of exchanged data (identifiers, notes). - Server authentication (SSL/TLS certificate). - Protection against eavesdropping on public network (Wi-Fi).

Exercise 4 — Academic research

Statement: Formulate an advanced query to find articles on “ICT and language teaching” (quotes, operators).

Detailed correction: - "ICT" AND "language teaching" (Google academic or institutional engine). - Filter by date (last 5 years). - Favor .edu domains, university bibliographic bases. - Note author, title, URL, date of consultation for citation.

Exercise 5 — Web source evaluation

Statement: Evaluate the reliability of an anonymous blog vs. a .edu page: 4 criteria.

Detailed correction: 1. Author identified and qualified? 2. Date of recent publication? 3. Objectivity and bibliographic references? 4. Institutional or commercial domain? → The anonymous blog should be discarded for a university assignment without overlap.

Exercise 6 — Web et publication scientifique (10 min)

Statement: Comparez le référencement (SEO) d'une page académique vs d'une page commerciale. Quelles balises HTML (meta description, title, heading) optimiser pour un profil Google Scholar ?

Detailed correction: SEO académique : title = nom + affiliation + mots-clés ; meta description = résumé de recherche ; heading = structure claire (H1 nom, H2 publications, H3 projets). Google Scholar indexe automatiquement les profils .edu, les PDF, les articles avec DOI.
