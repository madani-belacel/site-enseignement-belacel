📖 ICT Tutorial 04 — Microsoft Word: Academic Publishing and Research

Dr. BELACEL Madani Maître de Conférences B (MCB)

Université de Mostaganem — Faculté des langues étrangères · Département d'anglais
madani.belacel [at] univ-mosta.dz

Exercise 1 — Thesis formatting standards (15 min)

Statement: Apply master's thesis formatting standards (font, spacing, margins, recto-verso, pagination).

Corrected: Times New Roman 12, line spacing 1.5, margins 2.5 cm (3 cm binding), bottom center pagination. Front matter in Roman numerals, body in Arabic numerals.

Exercise 2 — Styles and document hierarchy (15 min)

Statement: Structure a research document (introduction, literature review, methodology, results, discussion) with Heading 1, Heading 2, Heading 3 styles. Generate an automatic 3-level table of contents.

Corrected: Heading 1 = main parts, Heading 2 = sub-parts, Heading 3 = sub-sections. Table of contents: References → Table of Contents → Automatic. Check hierarchy before generation.

Exercise 3 — Citations and bibliography (18 min)

Statement: Enter 5 references (book, article, chapter, thesis, website) in Word's source manager, insert 3 in-text citations, and generate a bibliography in APA 7 style.

Corrected: References → Manage Sources → New. Select source type. Insert citation. Bibliography: References → Bibliography. Check APA 7 compliance (author, date, title, source, DOI).

Exercise 4 — Tables, figures and cross-references (15 min)

Statement: Create a comparative table and a figure with automatically numbered captions. Insert cross-references (see Table 1, see Figure 2).

Corrected: Insert caption: References → Insert Caption. Cross-reference: Insert → Link → Cross-reference. Numbers update automatically.

Exercise 5 — Section breaks and front matter (14 min)

Statement: Create a document with: cover page (no number), abstract (Roman), body (Arabic). Use section breaks.

Corrected: Layout → Breaks → Section Break → Next Page. Disconnect headers/footers. Different numbering per section.

Exercise 6 — Data collection form (13 min)

Statement: Create a Word form with fillable fields, dropdown lists, and checkboxes for a research questionnaire. Protect the document for filling only.

Corrected: Developer → Design Mode → Content Controls. Insert rich text, dropdown list, checkbox. Protect: Restrict Editing → Filling in forms.
