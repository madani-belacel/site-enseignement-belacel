📖 ICT Tutorial 10 — Internet Services for Research

Dr. BELACEL Madani Maître de Conférences B (MCB)

Université de Mostaganem — Faculté des langues étrangères · Département d'anglais
madani.belacel [at] univ-mosta.dz

Exercise 1 — Literature search strategy (15 min)

Statement: Develop a search equation on "the impact of ICT on EFL motivation" with: keywords, Boolean operators, filters (date, language, document type). Test on Google Scholar and your university portal.

Detailed correction: ("ICT" OR "digital") AND ("motivation" OR "engagement") AND ("EFL" OR "English as a foreign language"). Filters: 2020-2026, English, peer-reviewed articles. Compare results across databases.

Exercise 2 — Research alerts and RSS (18 min)

Statement: Set up a Google Scholar alert on your research topic. Configure an RSS reader (Feedly/Inoreader) with 3 academic sources. Explain the benefit for a researcher.

Detailed correction: Google Scholar → Alerts → enter search equation + email. RSS: add feeds from journals (ALSIC, ReCALL, CALL). Benefit: passive reception of new publications, time-saving.

Exercise 3 — Source evaluation (15 min)

Statement: Analyze 3 sources on the same topic using the CRAAP test (Currency, Reliability, Authority, Accuracy, Purpose). Rank by reliability.

Detailed correction: Source 1 (peer-reviewed journal article) → reliable; Source 2 (personal blog) → verify; Source 3 (government .gov site) → reliable. Criteria: date, author affiliation, peer review, citations received.

Exercise 4 — Academic archiving and visibility (18 min)

Statement: Simulate depositing an article on an open archive (HAL, ResearchGate, Academia). Compare advantages/limitations of each platform for an Algerian researcher's visibility.

Detailed correction: HAL: academic legitimacy, no direct evaluation. ResearchGate: social network, metrics, fast deposit, but commercial model. Academia: similar to RG. Recommendation: prioritize HAL + complement with ResearchGate for networking.

Exercise 5 — Collaborative writing and proofreading (14 min)

Statement: Compare Word Online, Google Docs, Overleaf for collaborative article writing. List 3 advantages and 3 disadvantages of each tool.

Detailed correction: Word Online: familiar interface, track changes, but limited formatting. Google Docs: real-time comments, version history, but sometimes faulty export. Overleaf: ideal LaTeX, versioning, but learning curve.

Exercise 6 — APIs and data extraction (10 min)

Statement: Explain what a REST API is. Give an example of a pedagogical or scientific use of an API (OpenAI, Google Translate, Wikipedia).

Detailed correction: API = interface that allows two applications to communicate. Example: use the Google Translate API to automatically analyze student translations; or the Wikipedia API to extract linguistic data for corpus analysis.
