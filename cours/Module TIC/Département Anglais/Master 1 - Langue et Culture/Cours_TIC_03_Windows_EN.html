Course Plan

  1. Introduction to Windows in the academic context
  2. The complete Windows Desktop GUI
  3. Advanced file and folder management
  4. File Extensions and Naming Conventions
  5. Essential Keyboard Shortcuts
  6. Personalization and organization of the workspace
  7. Basic security and best practices
  8. Conclusion and transition to Word

1. Introduction to Windows (10 min)

Windows is the most widely used operating system in academia. Mastering Windows allows you to save time, avoid losing documents and produce quality work.

2. Graphical Interface (15 min)

  • Desktop: main workspace
  • Icons: shortcuts to applications and folders
  • Taskbar: open applications
  • Start Menu: programs, settings, search
  • Notification area: network, volume, updates

Organize the office by thematic folders (Courses, Tutorials, Exams, Administrative).

3. Files and Folders (15 min)

A file = name + extension. A folder = container.

Recommended tree structure: Documents/L1_Langues_2026-2027/Cours | TD | Exams | Projects | Backups

Convention: YYYY-MM-DD_Module_Type_Name_vX.ext

4. Common Extensions (10 min)

Extension Kind Application
.docx Document Word
.pdf Finalized document PDF reader
.pptx Presentation Power point
.xlsx Spreadsheet Excel

5. Keyboard Shortcuts (10 min)

Ctrl+C/V/X, Ctrl+Z, Ctrl+A, Windows+L (lock), Windows+S (search).

6. Personalization (10 min)

Simple wallpaper, pin Word/Chrome/Explorer, light/dark mode, optimized taskbar.

7. Safety (10 min)

Lock session, 3-2-1 backup rule, Windows updates, antivirus, caution with unknown USB drives.

8. Conclusion (10 min)

A good command of Windows is the foundation of all your digital skills.
