Course Sheet — E-learning Platform (Moodle)

Reference: titles aligned with USTO Canvas (elearning.univ-usto.dz); best practices from 10 Algerian university Moodle platforms.

Target audience: L1 Language students / ENS Year 1

Prerequisites: see FR fiche session 05

Learning outcomes: knowledge, skills and attitudes aligned with Biskra/USTO model (savoir / savoir-faire / savoir-être).

Assessment: coursework 40% + Moodle quiz 20–30% + final exam 30%

Learning activities: Moodle forum, assignment upload, guided TD exercises

Assessment activities: chapter quizzes (USTO/M'sila model)

Bibliography: institutional Moodle guides (Boumerdès, Béjaïa); course-specific references in FR version

Instructor: BELACEL Madani — madani.belacel@univ-mosta.dz

Course Plan

  1. Introduction: Why use Excel at university?
  2. Interface and basic concepts
  3. Data entry, formatting and organization
  4. Essential formulas and functions
  5. Relative and absolute references
  6. Creating and Customizing Charts
  7. Good practices and export for academic use
  8. Conclusion and transition to PowerPoint

1. Introduction (10 min)

Excel allows you to organize notes, bibliographies, survey data, automatic calculations and graphs for reports.

2. Interface (15 min)

Workbook (.xlsx), sheet, cell (B5), range (A1:D10), formula bar.

3. Input and Formatting (15 min)

Inline 1 headers, borders, alignment, conditional formatting.

4. Formulas (20 min)

=SUM(), =AVERAGE(), =MIN()/=MAX(), =COUNT(), =IF().

5. References (15 min)

Relative (B2) vs absolute ($B$2) — F4 key.

6. Graphics (10 min)

Histogram, curve, sectors — title, legends, sober style.

7. Good Practices (5 min)

Naming, Ctrl+S, PDF export, check formulas.

8. Conclusion (10 min)

Next class: Microsoft PowerPoint — Academic Presentations.
