Exercise 1 — Personal definition (15 min)

Statement: Give your own definition of ICT in 2-3 lines, then compare it to the ITU definition.

Detailed correction: ICT brings together digital tools for processing, transmission and access to information. The ITU emphasizes digital form and the convergence of technologies.

Exercise 2 — The three dimensions (15 min)

Statement: Explain with personal examples the three dimensions: Techniques, Information, Communication.

Detailed correction: Technical = PC + Moodle; Information = PDF handout; Communication = email to teacher or TD forum.

Exercise 3 — ICT functions (18 min)

Statement: For each action, identify the function: processing / transmission / backup. Word writing, email sending, USB copying, Teams videoconferencing, PDF printing.

Detailed correction: Word → processing; email and Teams → transmission; USB → backup; printing → processing/output.

Exercise 4 — Language applications (18 min)

Statement: Name 5 concrete uses of ICT for a foreign language student.

Detailed correction: Online multilingual corpora, video with native speakers, Moodle for homework, digital library, PowerPoint for presentations.

Exercise 5 — Critical thinking (14 min)

Statement: Write a paragraph (10-12 lines) on the opportunities and risks of ICT for language students.

Detailed correction: Opportunities: global resources, MOOCs, collaboration. Risks: plagiarism, misinformation, addiction, privacy. Posture: critical thinking and academic ethics.

Exercise 1 — Basic vocabulary (15 min)

Statement: Define: computing, hardware, software, CPU, RAM, SSD.

Corrected: Computer science = automatic processing of information; hardware = hardware; software = software; CPU = processor; RAM = volatile random access memory; SSD = fast non-volatile storage.

Exercise 2 — Input / Processing / Output (15 min)

Statement: Classify: keyboard, screen, processor, printer, microphone, hard drive.

Fixed: Input: keyboard, microphone; Processing: processor; Output: screen, printer; Storage: hard drive.

Exercise 3 — RAM vs storage (18 min)

Statement: Why does an unsaved document disappear after a power outage?

Fixed: The data being edited is in RAM (volatile). Without saving to disk/SSD/cloud, they are lost when shut down.

Exercise 4 — Choice of support (18 min)

Statement: For daily work, long-term archive, file transport — recommend media and justify.

Fixed: SSD for everyday use; HDD or cloud for archives; USB key for occasional transport.

Exercise 5 — Good practices (14 min)

Statement: List 6 important best practices for a student.

Fixed: Regular backups, updates, antivirus, folder organization, 3-2-1 rule, RAM/storage distinction.

Exercice 1 — Définition et acronymes

Énoncé : Définir Internet en une phrase et expliquer la signification de TCP/IP.

Corrigé détaillé : - Internet = réseau mondial interconnectant des réseaux locaux/régionaux/internationaux. - TCP = Transmission Control Protocol (fiabilité de transmission). - IP = Internet Protocol (adressage et routage des paquets).

Exercice 2 — Internet vs Web

Énoncé : Pour chaque élément, indiquer s'il relève d'Internet, du Web, ou des deux : navigateur Chrome, câble fibre, page HTML, protocole HTTP, routeur.

Corrigé détaillé : - Chrome : Web (client) + Internet (infrastructure). - Fibre : Internet. - Page HTML : Web. - HTTP : Web (service sur Internet). - Routeur : Internet.

Exercice 3 — Connexion à Internet

Énoncé : Décrire les étapes pour connecter un portable au Wi-Fi du campus.

Corrigé détaillé : 1. Activer le Wi-Fi (icône barre des tâches). 2. Sélectionner le réseau institutionnel. 3. S'authentifier (identifiants universitaires). 4. Vérifier l'accès (ouvrir un site ou Moodle). 5. Verrouiller la session en quittant la salle (Windows+L).

Exercice 4 — Adresse IP

Énoncé : Quelle est la différence entre IPv4 et le rôle du DHCP ? Donner un exemple d'adresse IP.

Corrigé détaillé : - IPv4 : format 4 octets décimaux (ex. 192.168.1.10), identifiant unique sur le réseau. - DHCP : attribue automatiquement IP, masque et passerelle au poste client. - Sans DHCP, configuration manuelle nécessaire.

Exercice 5 — Usages et sécurité

Énoncé : Citer trois usages académiques d'Internet et deux précautions de sécurité sur réseau public.

Corrigé détaillé : - Usages : Moodle, bibliothèque numérique, visioconférence, dépôt de devoirs. - Sécurité : éviter transactions sensibles ; utiliser HTTPS ; ne pas partager mots de passe ; VPN si disponible.

Detailed correction: - https:// — secure HTTP protocol. - www.univ-example.dz — domain name (server). - /cours/tic/chap2.html — path to the resource (HTML page).

Exercise 2 — Browsers

Statement: Comparing two browsers (Chrome and Firefox): an advantage and an educational use for each.

Detailed correction: - Chrome: numerous extensions; synchronization Google account. - Firefox: enhanced privacy; open source development. - Use: documentary research, Moodle access, online PDF reading.

Exercise 3 — HTTP vs HTTPS

Statement: Why choose HTTPS to connect to the university platform?

Detailed correction: - Encryption of exchanged data (identifiers, notes). - Server authentication (SSL/TLS certificate). - Protection against eavesdropping on public network (Wi-Fi).

Detailed correction: 1. Author identified and qualified? 2. Date of recent publication? 3. Objectivity and bibliographic references? 4. Institutional or commercial domain? → The anonymous blog should be discarded for a university assignment without overlap.

Exercise 1 — Types of networks

Statement: Associate LAN, MAN, WAN with: computer room, city network, global Internet.

Detailed correction: - Computer room → LAN (Local Area Network). - City network → MAN (Metropolitan Area Network). - Worldwide Internet → WAN (Wide Area Network).

Exercise 2 — Topologies

Statement: Draw a star topology with 4 stations and a central switch. Name a benefit.

Detailed correction: - 4 PCs individually connected to the switch (central hub). - Advantage: failure of a cable only affects one station; easy troubleshooting. - Very common in Wi-Fi (access point = center).

Exercise 3 — Network components

Statement: Connect component and role: switch, router, network card, Ethernet cable.

Detailed correction: - Switch: interconnects machines via LAN. - Router: connects LAN to the Internet (IP routing). - Network card (NIC): machine/network interface. - Ethernet cable: wired transmission medium.

Exercise 4 — Addressing and DHCP

Statement: A station displays 169.254.x.x. What likely problem? Which protocol resolves IP assignment?

Detailed correction: - APIPA address: no DHCP server reachable (Wi-Fi not connected or box turned off). - DHCP must assign IP, mask, gateway, DNS. - Solution: check Wi-Fi/Ethernet connection, restart box, contact IT support.

Exercise 5 — Campus case

Statement: Propose 3 rules for good use of the university network.

Detailed correction: 1. Educational and research use (no illegal downloads). 2. Do not share institutional Wi-Fi credentials. 3. Respect the IT charter (security, bandwidth, shared printers).

Exercise 3 — Email protocols

Statement: Associate SMTP, POP, IMAP with: send, receive locally, multi-device sync.

Detailed correction: - SMTP → sending. - POP → reception (often local download). - IMAP → reception with box sync on multiple devices (mobile + PC recommended).

Exercise 4 — File transfer

Detailed correction: - USB key: fast in person, risk of loss/virus. - Drive: sharing link, traceability, institutional quota limit. - Email: attachment limit (~25 MB depending on server), practical for small files. → For 15 MB: Drive or Moodle platform preferred.
