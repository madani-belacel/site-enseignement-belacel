ICT Course 01 — Introduction to ICT (ENS)

Lecturer: BELACEL Madani
Module: ICT
Level: ENS 1st and 2nd Year — English Department
Duration: 1h30
Academic Year: 2025-2026

Course Overview — E-learning Platform (Moodle)

Target audience: ENS students — future language teachers

Prerequisites: Basic computer skills (Licence level)

Learning Objectives

Knowledge: - Define ICT and its evolution - Distinguish technical, information, and communication dimensions - Understand pedagogical ICT integration in language didactics

Skills: - Use ICT tools to design teaching sequences - Evaluate and select digital resources for the classroom - Create interactive teaching materials

Attitudes: - Adopt a digital mediator posture in the classroom - Develop critical thinking about tools and resources

Assessment: Tutorial 40% + ICT Teaching Project 30% + Exam 30%

1. Definition and Evolution (10 min)

ICT covers digital tools and systems for creating, processing, storing, transmitting, and sharing information.

Evolution: NTIC (1990-2005) → ICT (2005-present) → AI and EdTech (2020+).

For the future teacher: ICT are not just personal tools but pedagogical instruments to integrate into teaching practice.

2. Three Dimensions (10 min)

Dimension Definition Pedagogical application
Technical Hardware + software IWB, tablet, Moodle, VLE
Information Content manipulated PDF, video, podcast resources
Communication Exchange between people Forum, videoconference, virtual classroom

3. ICT and Pedagogy (20 min)

Why integrate ICT in language teaching? - Learner motivation and engagement - Access to authentic resources (videos, articles, podcasts) - Individualized learning paths - Autonomy development

Application areas: - Listening: podcasts, audio recording - Writing: blogs, wikis, collaborative editing - Interaction: videoconferencing with partner classes - Grammar/vocabulary: interactive exercises, quizzes

4. The SAMR Model (15 min)

Level Meaning Example
Substitution Tech replaces without change Paper → PDF
Augmentation Tech improves the task PDF with hyperlinks
Modification Tech transforms the task Collaborative document (Google Docs)
Redefinition Tech creates new possibilities Project with partner class via video

Goal: aim for Modification and Redefinition levels.

5. ICT Tools for Language Teachers (20 min)

Tool Use Type
Moodle Learning platform LMS
Quizlet / Kahoot Gamified exercises Quiz
Padlet Collaborative wall Brainstorming
Audacity Audio recording Oral production
LearningApps Interactive exercises Creation
Google Classroom Classroom management LMS

6. Teacher Digital Competencies (15 min)

  1. Design sequences integrating digital tools
  2. Implement collaborative online activities
  3. Assess with digital tools
  4. Ensure security and ethics
  5. Develop professional monitoring

7. Ethics and Security (10 min)

  • GDPR compliance: protect student data
  • Copyright: use open-licensed resources (Creative Commons)
  • Cyberbullying: prevention in class
  • Digital identity: the teacher as a role model

8. Conclusion (5 min)

  • ICT are a pedagogical lever for language teachers
  • Integration must be thoughtful (SAMR model)
  • Future teachers must develop digital competencies

TD 01 (1h30) — analyzing ICT tools for the classroom.

Course Plan

  1. Introduction: Why understand computers?

  3. The computer: concept and model of von Neumann
  4. Hardware components (Hardware)
  5. Software and operating systems (Software)
  6. Interaction between Hardware and Software
  7. Best practices for university students
  8. Conclusion and transition to Windows

1. Introduction (10 min)

Understanding how the computer works is essential for any student, even in the Languages ​​sector. This allows you to better use your tools (Word, browser, Moodle), avoid data loss, diagnose simple problems and effectively organize your digital workspace.

The computer has become the main university working instrument.

2. What is IT? (10 mins)

Computer science is the science of automatic information processing using algorithms executed by machines. It includes theory, hardware, software and networks.

User approach: understand enough to use the computer well in your studies.

3. von Neumann model (15 min)

A computer is a programmable machine capable of: receiving data (Input), processing it (CPU), temporarily storing it (RAM), returning it (Output) and retaining it (Secondary storage).

This operation follows the von Neumann model (1945), still used today.

4. Hardware Components (15 min)

  • Processor (CPU): the brain of the computer
  • Motherboard: interconnection of components
  • RAM: volatile RAM, very fast
  • Storage: HDD or SSD (faster)
  • Peripherals: input (keyboard, mouse), output (screen, printer), external storage (USB key)

Important point: RAM loses unsaved data when turned off.

5. Software (15 min)

  • Operating system: Windows, Linux, macOS
  • Application software: Word, PowerPoint, browsers, Moodle
  • Utility software: antivirus, compressors

The hardware is tangible; the software is intangible but essential.

6. Hardware / Software Interaction (10 min)

Example: keyboard keystroke → OS translated → processor processes → screen displays.

Without software, hardware is useless. Without hardware, the software cannot run.

7. Good Practices (10 min)

  1. Backup regularly (Ctrl + S + Cloud)
  2. Organize your files from the start of the semester
  3. Update Windows and software
  4. Use an antivirus
  5. Distinguish between RAM and permanent storage

8. Conclusion (5 min)

Understanding computer architecture allows you to be more independent and efficient.

1. Introduction to Windows (10 min)

Windows is the most widely used operating system in academia. Mastering Windows allows you to save time, avoid losing documents and produce quality work.

2. Graphical Interface (15 min)

  • Desktop: main workspace
  • Icons: shortcuts to applications and folders
  • Taskbar: open applications
  • Start Menu: programs, settings, search
  • Notification area: network, volume, updates

Organize the office by thematic folders (Courses, Tutorials, Exams, Administrative).

3. Files and Folders (15 min)

A file = name + extension. A folder = container.

Recommended tree structure: Documents/L1_Langues_2025-2026/Cours | TD | Exams | Projects | Backups

Convention: YYYY-MM-DD_Module_Type_Name_vX.ext

4. Common Extensions (10 min)

Extension Kind Application
.docx Document Word
.pdf Finalized document PDF reader
.pptx Presentation Power point
.xlsx Spreadsheet Excel

5. Keyboard Shortcuts (10 min)

Ctrl+C/V/X, Ctrl+Z, Ctrl+A, Windows+L (lock), Windows+S (search).

6. Personalization (10 min)

Simple wallpaper, pin Word/Chrome/Explorer, light/dark mode, optimized taskbar.

7. Safety (10 min)

Lock session, 3-2-1 backup rule, Windows updates, antivirus, caution with unknown USB drives.

8. Conclusion (10 min)

A good command of Windows is the foundation of all your digital skills.
