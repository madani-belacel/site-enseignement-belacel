Course Overview — E-learning Platform (Moodle)

Learning Objectives

Knowledge: - Define ICT and distinguish NTIC/TIC/ICT - Identify the three dimensions: technical, information, communication - List main functions: processing, transmission, storage

Skills: - Use Moodle and institutional email - Name and classify digital tools by function - Evaluate online source reliability (CRAP introduction)

Attitudes: - Adopt a critical approach to digital tools - Respect academic ethics (plagiarism, privacy)

1. Introduction and Importance (10 min)

Information and Communication Technologies (ICT) are digital tools that allow us to create, process, store, transmit, and share information.

Why this course in Licence 1? - Access resources: Moodle, digital library, PDF materials - Communicate: institutional email, forums - Research: documentary databases, linguistic corpora - Produce: Word assignments, PowerPoint slides

2. Detailed Definition (15 min)

Convergence of three domains: 1. Computing — automatic information processing 2. Telecommunications — remote transmission (Internet, Wi-Fi) 3. Audiovisual and multimedia — text, image, sound, video

3. Historical Evolution (10 min)

Period Term Meaning
1990–2005 NTIC Emphasis on newness: Internet, email, GSM
Since ~2005 ICT Technologies integrated into daily life

4. Three Fundamental Dimensions (15 min)

Dimension Description Example
Technical Hardware + software PC, smartphone, browser
Information Content manipulated Text, image, sound, video
Communication Exchange between people Email, forum, videoconference

5. ICT Functions (15 min)

Function Description Examples
Processing Input, formatting, calculation Word, Excel
Transmission Sending or sharing remotely Email, Teams, Drive
Storage Lasting preservation USB key, cloud, server

6. Main ICT Services (10 min)

  • Email (@univ-mosta.dz)
  • Web browsing and search
  • Videoconferencing (Teams, Zoom)
  • Learning platforms (Moodle, Google Classroom)
  • Cloud storage (Drive, OneDrive)

7. Applications in Education (10 min)

  • E-learning and hybrid teaching
  • Digital libraries
  • Collaborative work
  • Online assessment
  • Multilingual documentary research

8. Expected Digital Skills (10 min)

  1. Academic office software (Word, PowerPoint)
  2. Documentary research (keywords, credibility)
  3. File management (naming, formats)
  4. Professional email communication
  5. Security and ethics (passwords, plagiarism)

9. Conclusion (5 min)

  • ICT = convergence of computing, telecom, and multimedia
  • Three dimensions: technical, information, communication
  • Three functions: processing, transmission, storage
