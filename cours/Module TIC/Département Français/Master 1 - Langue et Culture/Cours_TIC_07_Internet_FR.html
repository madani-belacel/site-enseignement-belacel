Introduction — Internet comme infrastructure de recherche (10 min)

Internet n'est pas une simple technologie : c'est l'infrastructure mondiale qui permet la communication scientifique, l'accès aux ressources documentaires, et la diffusion des résultats de recherche.

En Master Langue et Culture, Internet est : - Un objet d'étude (la communication en ligne, les communautés virtuelles) - Un outil de recherche (corpus numériques, bibliothèques en ligne) - Un vecteur de diffusion (publication en accès ouvert, réseaux académiques)

Spécificité algérienne : Le réseau académique (via ANPT et CERIST) relie les universités algériennes entre elles et au réseau mondial (Internet2 / GÉANT). L'accès aux ressources payantes (Cairn, OpenEdition, Taylor & Francis) se fait via le proxy institutionnel.

Définition et histoire d'Internet (15 min)

Définition : réseau de réseaux interconnectés utilisant le protocole TCP/IP pour acheminer des paquets de données.

Date Événement Portée scientifique
1969 ARPANET — 4 nœuds (UCLA, Stanford, UCSB, Utah) Prémices de la collaboration à distance
1972 Premier courriel (Ray Tomlinson) Naissance de la communication académique asynchrone
1983 Adoption obligatoire de TCP/IP Standardisation = interopérabilité mondiale
1989 Proposition du Web (Tim Berners-Lee, CERN) Partager des documents de recherche
1991 Premier site Web Accès public à l'information scientifique
1998 Google Révolution de la recherche d'information
2000s ADSL, Wi-Fi, 3G/4G Démocratisation de l'accès
2010s Open Access, Science ouverte Mouvement pour la libre circulation des savoirs
2020s Fibre optique, 5G, IA générative Nouveaux paradigmes de recherche

En Algérie : Introduction d'Internet au milieu des années 1990 (CERIST). Généralisation dans les universités à partir de 2005. Aujourd'hui : fibre optique dans les campus, connexion via le réseau RENATER-like algérien.

Réseau mondial et protocole TCP/IP (10 min)

Modèle TCP/IP en 4 couches :

Couche Protocoles Rôle
Application HTTP, SMTP, DNS, FTP, SSH Services accessibles au chercheur
Transport TCP (fiable), UDP (rapide) Contrôle de flux, segmentation
Internet IP, ICMP Routage, adressage logique
Accès réseau Ethernet, Wi-Fi, fibre Transmission physique

Paquet : unité de données routée indépendamment (commutation de paquets). Chaque paquet emprunte un chemin potentiellement différent.

Pour la recherche : comprendre TCP/IP permet de comprendre comment circulent les données de corpus (Big Data linguistique), pourquoi certaines ressources sont lentes selon la localisation, et comment le chiffrement (TLS) protège les échanges académiques.

Connexion à Internet — spécificité universitaire algérienne (10 min)

Connexion universitaire : - Réseau filaire (fibre / Ethernet) dans les salles informatiques - Wi-Fi (eduroam ou SSID institutionnel WPA2/WPA3) - Proxy : configurer le navigateur pour accéder aux ressources payantes (Cairn, OpenEdition, Cambridge UP) - VPN : accès aux ressources depuis le domicile

Contexte Technologie Authentification
Campus Fibre + Wi-Fi Login institutionnel
Domicile ADSL / Fibre / 4G FAI privé + VPN
Bibliothèque Wi-Fi Proxy ou accès libre
Mobilité 4G/5G Forfait mobile + data

Problématique algérienne : débit variable selon les régions, coupures électriques ponctuelles, coût de la data mobile. Le formateur doit prévoir des alternatives hors ligne.

Internet ≠ Web : clarification conceptuelle (5 min)

Internet Web (WWW)
Infrastructure physique et protocolaire Service applicatif (pages HTTP)
Date de naissance : 1969 (ARPANET) Date de naissance : 1991
TCP/IP HTTP/HTTPS sur TCP
Services : courriel, FTP, VoIP, Web Contenu : pages, médias, applications
Analogie : réseau routier Analogie : les commerces et services

Implication Master : ne pas confondre les couches dans un travail de recherche. Quand on parle de « données Web », on parle d'un service sur Internet.

Adressage IP et DNS (10 min)

IPv4 : 32 bits (ex. 193.194.87.10 — adresse CERIST). IPv6 : 128 bits (déploiement progressif).

Notion Définition Exemple
IP privée Adresse LAN non routée sur Internet 192.168.1.x, 10.x.x.x
IP publique Adresse unique sur Internet 193.194.87.10
Masque Délimite réseau / hôte 255.255.255.0 (/24)
Passerelle Routeur sortant du LAN 192.168.1.1
DNS Résolution nom → IP hal.univ-mosta.dz → IP

DNS académique : le DNS universitaire peut bloquer certains sites (conformément à la charte algérienne). Les chercheurs peuvent utiliser un DNS alternatif (Cloudflare 1.1.1.1, Google 8.8.8.8) en dernier recours.

Application recherche : comprendre l'adressage permet de localiser des corpus hébergés, configurer un serveur pour l'analyse de données, et comprendre les restrictions géographiques d'accès aux ressources.

Internet Linguistics (15 min)

David Crystal (2011) — Internet Linguistics propose d'étudier le langage sur Internet comme un objet linguistique à part entière.

Domaines d'étude

1. Communication synchrone / asynchrone - Chat, messagerie instantanée (synchrone) - Forums, courriels, réseaux sociaux (asynchrone)

2. Nouvelles variétés linguistiques - Netspeak : abréviations, acronymes, émoticônes - Alternance codique (code-switching) dans les communications multilingues - Création lexicale : « troller », « liker », « googler »

3. Communautés virtuelles et langues - Français algérien en ligne (Darija sur Facebook/YouTube) - Communautés berbérophones : revitalisation via Internet (IRC, réseaux sociaux) - Arabe algérien dans les commentaires en ligne

4. Méthodologie de recherche en Internet Linguistics - Constitution de corpus Web (web scraping, API Twitter) - Analyse des conversations en ligne (analyse du discours numérique) - Éthique de la recherche sur les données publiques en ligne

Identité numérique du chercheur (5 min)

En Master, il est temps de construire une identité numérique académique :

  • ORCID (orcid.org) : identifiant chercheur unique, obligatoire pour toute publication
  • Google Scholar : profil avec vos publications et citations
  • ResearchGate / Academia.edu : réseaux sociaux académiques (attention : conditions d'utilisation)
  • HAL : dépôt systématique de vos productions

Stratégie : choisir un même nom d'affichage sur toutes les plateformes pour la cohérence.

Sécurité académique et éthique (5 min)

Risques : phishing (courriels usurpant l'identité du professeur), malware (téléchargement non sécurisé), vol d'identité académique.

Bonnes pratiques : - Vérifier l'URL des sites de dépôt avant de saisir ses identifiants - Utiliser HTTPS systématiquement (extension HTTPS Everywhere) - Charte universitaire : droit d'auteur, citation des sources - Licences Creative Commons : comprendre CC-BY, CC-BY-SA, CC-BY-NC

Spécificité Algérie : la loi 08-15 (2008) régit le droit d'auteur. Les ressources numériques sont soumises à cette législation. La contrefaçon numérique est passible de poursuites.

Conclusion (5 min)

  • Internet = infrastructure TCP/IP ; ressource essentielle pour la recherche
  • Bibliothèques numériques, archives ouvertes, Internet Linguistics

QCM d'auto-évaluation (5 questions)

1. Quelle est la principale différence entre Internet et le Web ? - a) Internet est plus rapide que le Web - b) Internet est l'infrastructure ; le Web est un service applicatif (HTTP) ✓ - c) Le Web a été inventé avant Internet - d) Internet ne permet que le courriel

2. Quel protocole est responsable de la résolution nom de domaine → adresse IP ? - a) HTTP - b) SMTP - c) DNS ✓ - d) TCP

3. Que signifie ORCID pour un chercheur ? - a) Un réseau social - b) Un identifiant unique et pérenne de chercheur ✓ - c) Un moteur de recherche - d) Un logiciel de gestion bibliographique

4. D'après Crystal (2011), que désigne le terme « Netspeak » ? - a) Le langage parlé au téléphone - b) Les variétés linguistiques spécifiques à la communication en ligne ✓ - c) Un logiciel de traduction automatique - d) La vitesse de connexion Internet

5. Quelle archive ouverte est libre d'accès et pluridisciplinaire, née en France ? - a) Cairn - b) HAL ✓ - c) Google Scholar - d) ResearchGate

Note pédagogique Master

Transposition didactique : Ce cours ne se limite pas à une description technique d'Internet. Il aborde Internet comme infrastructure de recherche, objet d'étude linguistique, et espace de publication académique. La distinction Internet/Web est cruciale pour les futurs cours (TIC 08, 09, 10).

Conseil pour le formateur : Privilégier les démonstrations en direct (configuration proxy, recherche dans HAL, analyse d'un commentaire YouTube). Insister sur les ressources numériques réellement accessibles depuis l'Algérie. Le cours Internet Linguistics suscite généralement l'intérêt des étudiants : prévoir des exemples concrets (Darija sur Facebook, tamazight sur YouTube).

Prolongement recherche : Les étudiants peuvent approfondir la Computer-Mediated Communication (CMC) et ses implications pour l'analyse du discours (Herring 2007, Thurlow & Mroczek 2011). Un mémoire sur l'évolution du français algérien dans les commentaires Facebook est envisageable.
