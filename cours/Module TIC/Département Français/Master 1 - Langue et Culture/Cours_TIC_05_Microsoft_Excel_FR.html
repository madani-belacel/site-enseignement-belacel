Objectifs de l'enseignement

En termes de savoir : - Comprendre le rôle du tableur dans la recherche quantitative en sciences du langage - Distinguer les types de données (nominal, ordinal, intervalle, ratio) et leur traitement dans Excel - Maîtriser les fonctions statistiques de base pour l'analyse de corpus et d'enquêtes - Connaître les principes de nettoyage et de préparation des données pour l'analyse

En termes de savoir-faire : - Créer et gérer une base de données de recherche (corpus, enquête, lexique) dans Excel - Utiliser les fonctions avancées : RECHERCHEV, SI, SOMME.SI, NB.SI, fonctions de texte - Réaliser des graphiques scientifiques (histogrammes, courbes, nuages de points, boîtes à moustaches) - Nettoyer et structurer des données textuelles pour l'analyse quantitative - Exporter des données vers d'autres outils (SPSS, R, Python)

En termes de savoir-être : - Adopter une démarche rigoureuse de gestion des données de recherche - Vérifier la cohérence et la fiabilité des données saisies - Documenter ses traitements pour assurer la reproductibilité

1. Introduction : Excel dans la Recherche en Langues (10 min)

1.1 Pourquoi Excel en Master Langue et Culture ?

Excel n'est pas un outil « réservé aux comptables ». En sciences du langage, il permet de :

  • Analyser des enquêtes sociolinguistiques : dépouiller des questionnaires, croiser des variables (âge × usage du dialecte, niveau d'études × compétence en français)
  • Gérer des corpus textuels : compiler des métadonnées (auteur, date, genre, nombre de mots), calculer des fréquences lexicales
  • Analyser des données lexicales : créer des lexiques de fréquence, étudier la richesse lexicale (type/token ratio), la densité lexicale
  • Visualiser des données : produire des graphiques pour illustrer ses résultats dans le mémoire
  • Préparer des données pour des outils avancés : structurer des données pour les importer dans R, SPSS, AntConc, Python

1.2 Cas concrets de recherche avec Excel

Projet de recherche Données dans Excel Analyse
Enquête sur les pratiques linguistiques à Oran 150 répondants × 25 variables Tris à plat, tris croisés, graphiques
Analyse stylométrique de 10 romans algériens 10 fichiers × métadonnées + fréquences Type/token ratio, mots-clés, dispersion
Lexique de spécialité du français juridique 500 termes × 8 variables Fréquences, domaines, catégories grammaticales
Corpus de discours politiques 50 discours × 15 variables linguistiques Évolution temporelle, comparaison locuteurs

2. Types de Données et Structuration (15 min)

2.1 Rappel : interface et concepts

  • Classeur (.xlsx) : fichier contenant plusieurs feuilles
  • Feuille (Sheet) : grille de cellules
  • Cellule : intersection ligne/colonne (ex: B5)
  • Plage : ensemble de cellules (ex: A1:D10)
  • Tableau structuré : Insertion → Tableau (ou Ctrl+T) → plage nommée avec filtres automatiques

2.2 Types de données en recherche linguistique

Type Exemple Traitement Excel
Nominal (catégoriel) Dialecte (oranais, algérois, constantinois) Texte ; graphique en secteurs
Ordinal Niveau de français (A1, A2, B1, B2) Texte ordonné ; graphique en barres
Intervalle Âge (25-34, 35-44) Nombre ; histogramme
Ratio Nombre de mots, fréquence lexicale Nombre décimal ; histogramme, nuage
Texte libre Transcription d'entretien Texte long ; non quantifiable directement

2.3 Structurer une base de données de recherche

Règle d'or : une ligne = une observation ; une colonne = une variable.

Exemple : base d'enquête sociolinguistique

ID Age Sexe Ville Dialecte_usage Niveau_fr Profession Heures_tv_fr Mots_par_jour_fr
001 22 F Oran Oranais B2 Étudiante 3 1500
002 35 H Alger Algérois C1 Enseignant 1 800
003 28 F Constantine Constantinois B1 Journaliste 2 2000

2.4 Mise en forme des données

  • En-têtes en ligne 1 : court, sans espaces, sans accents (ex: Dialecte_usage plutôt que « Dialecte d'usage »)
  • Format des colonnes : sélectionner la colonne → Accueil → Format → Texte / Nombre / Date
  • Validation des données : Données → Validation des données → créer des listes déroulantes (ex: Homme/Femme) pour éviter les erreurs de saisie
  • Tableau structuré : Ctrl+T → les formules deviennent lisibles : =SOMME(Tableau1[Colonne1])
  • Gel des volets : Affichage → Figer les volets → figer la ligne d'en-tête

3. Nettoyage et Préparation des Données (15 min)

3.1 Pourquoi nettoyer ses données ?

Les données brutes contiennent presque toujours des erreurs : espaces invisibles, doublons, valeurs manquantes, formats inconsistants. Un nettoyage rigoureux est indispensable avant toute analyse.

3.2 Techniques de nettoyage dans Excel

Problème Solution Excel
Espaces avant/après =SUPPRESPACE(A2)
Doublons Données → Supprimer les doublons
Valeurs manquantes =NB.VIDE(plage) pour les repérer
Casse incohérente =MAJUSCULE(A2), =MINUSCULE(A2), =NOMPROPRE(A2)
Caractères non imprimables =EPURAGE(A2)
Format nombre stocké en texte Sélectionner la colonne → Données → Convertir
Fusions de cellules Éviter absolument ! Remplir plutôt vers le bas (Ctrl+D)

3.3 Nettoyer un corpus textuel

Supprimer lignes vides, uniformiser la casse, supprimer la ponctuation (=SUBSTITUE(A2;".";"")), compter les mots par cellule (=NBCAR(A2)-NBCAR(SUBSTITUE(A2;" ";""))+1), filtrer les anomalies.

3.4 Structurer des métadonnées de corpus

Fichier Auteur Titre_oeuvre Annee Genre Nb_mots Nb_types TTR
roman01.txt Dib, Mohammed La Grande Maison 1952 Roman 45230 5230 0.116
roman02.txt Mammeri, Mouloud La Colline oubliée 1952 Roman 38900 4890 0.126
roman03.txt Kateb, Yacine Nedjma 1956 Roman 62400 7120 0.114

4. Fonctions Essentielles pour l'Analyse Linguistique (15 min)

4.1 Fonctions statistiques de base

Fonction Syntaxe Usage en recherche
SOMME =SOMME(D2:D100) Total de mots d'un corpus
MOYENNE =MOYENNE(E2:E100) Longueur moyenne des textes
MEDIANE =MEDIANE(E2:E100) Valeur centrale (robuste aux extrêmes)
ECARTYPE =ECARTYPE.STANDARD(E2:E100) Dispersion des longueurs
MIN / MAX =MIN(E2:E100) Texte le plus court / le plus long
NB =NB(E2:E100) Nombre de textes (valeurs numériques)
NBVAL =NBVAL(A2:A100) Nombre de textes (tout type)

4.2 Fonctions conditionnelles

Fonction Syntaxe Exemple
NB.SI =NB.SI(B2:B100;"F") Compter le nombre de femmes dans l'enquête
NB.SI.ENS =NB.SI.ENS(B2:B100;"F";C2:C100;">30") Femmes de plus de 30 ans
SOMME.SI =SOMME.SI(D2:D100;"Oranais";E2:E100) Total mots des textes oranais
SOMME.SI.ENS =SOMME.SI.ENS(E2:E100;D2:D100;"Oranais";B2:B100;"F") Total mots des textes oranais d'autrices
MOYENNE.SI =MOYENNE.SI(B2:B100;"H";C2:C100) Âge moyen des hommes

4.3 RECHERCHEV (VLOOKUP)

Permet de fusionner deux tables à partir d'une clé commune. Essentiel pour croiser des données de corpus avec des métadonnées.

=RECHERCHEV(A2;'Meta corpus'!A:B;2;FAUX)

Exemple : dans une table « Fréquences lexicales », ajouter la catégorie grammaticale de chaque mot à partir d'une table « Lexique de référence ».

4.4 Tableaux croisés dynamiques (TCD)

Les TCD sont l'outil le plus puissant d'Excel pour explorer des données multidimensionnelles.

  1. Sélectionner votre tableau → Insertion → Tableau croisé dynamique
  2. Glisser les variables dans les zones :
  3. Lignes : la variable à explorer (ex: Dialecte)
  4. Colonnes : la variable de croisement (ex: Sexe)
  5. Valeurs : la mesure (ex: Nb de répondants)
  6. Le TCD calcule automatiquement les effectifs et pourcentages

5. Fonctions de Texte pour le Traitement de Corpus (10 min)

5.1 Manipulation de chaînes

Fonction Syntaxe Utilité
NBCAR =NBCAR(A2) Compter les caractères d'un texte
GAUCHE =GAUCHE(A2;10) Extraire les 10 premiers caractères
DROITE =DROITE(A2;4) Extraire l'extension ou l'année
STXT =STXT(A2;5;3) Extraire 3 caractères à partir du 5e
CHERCHE =CHERCHE("mot";A2) Position d'un mot dans la chaîne
SUBSTITUE =SUBSTITUE(A2;"ancien";"nouveau") Remplacer un mot par un autre
SUPPRESPACE =SUPPRESPACE(A2) Supprimer les espaces inutiles
CONCAT =CONCAT(A2;" ";B2) Assembler des valeurs textuelles

5.2 Analyse de fréquence lexicale

Segmenter le corpus en mots (outil externe : Python, AntConc) → TXT mot par ligne → Importer dans Excel → Insertion → Tableau croisé dynamique (mot en ligne, comptage en valeur) → Trier par fréquence. Alternative : =NB.SI(plage;mot) pour un mot spécifique.

5.3 Exemple : Type/Token Ratio (TTR)

Le Type/Token Ratio mesure la richesse lexicale d'un texte : - Tokens (occurrences) : nombre total de mots - Types (formes distinctes) : nombre de mots différents - TTR = Types / Tokens (plus le ratio est élevé, plus le vocabulaire est riche)

Dans Excel : TTR = B2 / A2 où B2 = nombre de types et A2 = nombre de tokens.

Texte Tokens Types TTR
Roman A 45000 5200 0.116
Roman B 38000 6100 0.161
Roman C 62000 7100 0.115

6. Statistiques Descriptives pour les Données Langagières (10 min)

6.1 Tendances centrales et dispersion

Moyenne (longueur moyenne des mots), Médiane (robuste aux valeurs extrêmes), Mode (catégorie dominante). Écart-type (dispersion), Variance, Quartiles (=QUARTILE(plage;1)), Boîte à moustaches.

6.2 Analyse des fréquences

Pour un tableau de fréquences lexicales : 1. Calculer la fréquence relative : fréquence_relative = occurrence_mot / total_tokens * 100 2. Calculer le rang de fréquence (loi de Zipf) : =RANG(fréquence; plage_fréquences; 0) 3. Visualiser la distribution : histogramme avec courbe de tendance

Loi de Zipf : dans tout corpus, la fréquence d'un mot est inversement proportionnelle à son rang. Quelques mots très fréquents (le, de, un) représentent une grande partie du corpus — des milliers de mots rares complètent la distribution.

7. Graphiques Scientifiques pour la Recherche en Langues (10 min)

7.1 Types de graphiques et usages

Type de graphique Usage en recherche Données
Histogramme Distribution d'âge, fréquences lexicales Variable quantitative
Barres groupées Comparaison de moyennes par groupe Variable catégorielle × quantitative
Secteurs (camembert) Répartition par dialecte, par sexe Variable catégorielle (peu de modalités)
Courbe Évolution temporelle (fréquence d'un mot dans le temps) Variable quantitative continue
Nuage de points Corrélation entre deux variables (âge × score) Deux variables quantitatives
Boîte à moustaches Comparaison de distributions (longueur des textes par auteur) Quantitative × catégorielle

7.2 Créer un graphique scientifique

  1. Sélectionner les données (en-têtes inclus)
  2. Insertion → Graphique → choisir le type
  3. Personnaliser :
  4. Titre : explicite (ex: « Distribution des fréquences lexicales dans le corpus »)
  5. Axes : nommer l'axe X et Y (avec unités si nécessaire)
  6. Légende : claire, concise
  7. Couleurs : sobres (éviter les couleurs vives)
  8. Style : + → cocher « Courbe de tendance » si pertinent (R² à afficher)
  9. Copier-coller dans Word : Ctrl+C dans Excel → Ctrl+V dans Word → Conserver le formatage source et lier les données

Note pédagogique Master

Transposition didactique pour le Master

Ce cours introduit l'étudiant en Langue et Culture à une démarche quantitative qui peut sembler éloignée de sa formation littéraire. La transposition didactique est essentielle :

  1. Du qualitatif au quantitatif : l'étudiant en lettres est formé à l'analyse qualitative (interprétation de textes, analyse du discours). Excel lui montre comment les méthodes quantitatives peuvent enrichir et objectiver ses analyses.
  2. De la théorie à la pratique : la loi de Zipf, le TTR, les fréquences lexicales sont des concepts abstraits — Excel permet de les manipuler concrètement sur des données réelles.
  3. De l'outil à la méthode : Excel n'est pas présenté comme un logiciel bureautique mais comme un environnement d'analyse — les fonctions sont enseignées dans leur contexte d'application (recherche).
  4. De la donnée à l'interprétation : le cours insiste sur le fait qu'un résultat quantitatif n'a de sens que dans un cadre théorique — Excel produit des chiffres, le chercheur produit du sens.
  5. De l'autonomie à la collaboration : les fichiers Excel bien structurés peuvent être partagés, réutilisés, combinés — c'est une initiation aux principes de la science ouverte.

Conseil pour le formateur

  • Avant la séance : préparer un fichier Excel « brut » contenant des données d'enquête fictives mais réalistes (20 répondants, 10 variables). Distribuer ce fichier comme base de travail.
  • Pédagogie : le cours mêle exposés (concepts) et TP (manipulations). Chaque nouvelle fonction doit être immédiatement testée par les étudiants sur leur fichier.
  • Difficulté anticipée : les étudiants en Langue et Culture peuvent être angoissés par les chiffres. Insistez sur le fait qu'il n'y a que des additions, des divisions et des comptages — pas de mathématiques avancées.
  • Évaluation : le projet noté consiste à analyser un petit corpus (20 textes courts) ou une enquête (30 répondants) avec Excel : fichier structuré, nettoyage, statistiques descriptives, 2 graphiques, interprétation d'une demi-page.

Prolongement recherche

Ce cours constitue la première étape d'un parcours d'analyse quantitative : - Analyse statistique avancée : initiation à R / RStudio au Semestre 2 (package stylo pour la stylométrie) - Traitement Automatique des Langues : Python avec NLTK pour l'analyse automatisée de corpus — les données préparées dans Excel alimenteront les scripts Python - Enquête de terrain : conception de questionnaires et traitement des données avec Excel puis SPSS - Atelier visualisation de données : création de visualisations avancées avec R (ggplot2), Tableau, ou DataWrapper - Mémoire : le fichier Excel d'analyse peut être annexé au mémoire comme preuve du travail méthodologique
