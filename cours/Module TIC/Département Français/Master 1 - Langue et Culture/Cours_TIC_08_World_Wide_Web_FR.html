Introduction — Le Web comme objet de recherche (10 min)

Le World Wide Web (WWW) a été inventé en 1989 par Tim Berners-Lee au CERN pour faciliter le partage de documents entre chercheurs. Aujourd'hui, le Web est à la fois :

  • Une infrastructure documentaire (pages, médias, applications)
  • Un objet d'étude pour les sciences du langage et de la culture
  • Un terrain de collecte (corpus, enquêtes, observations)

En Master Langue et Culture : le Web permet d'étudier les discours en ligne, les communautés virtuelles, l'évolution des langues, et la circulation des contenus culturels. L'analyse du Web s'inscrit dans le courant des Digital Humanities (Humanités Numériques).

Architecture du Web : client-serveur (10 min)

Modèle client-serveur : - Client : navigateur (Chrome, Firefox, Edge) envoie une requête HTTP - Serveur : hébergeur (Apache, Nginx) renvoie la ressource (HTML, CSS, JS, média) - Protocole : HTTP/HTTPS (couche application de TCP/IP)

Cycle requête-réponse :

Client (navigateur) --[GET /page.html]--> Serveur
Serveur --[200 OK + contenu HTML]--> Client

Middleware dans le contexte académique : - Proxy universitaire : intercepte les requêtes pour l'authentification aux ressources payantes - CDN (Content Delivery Network) : accélère la livraison des contenus - Cache : stockage local (navigateur) et intermédiaire (proxy)

URL : structure et syntaxe avancée (10 min)

Décomposition d'une URL académique :

https://hal.science/hal-01234567v1/document
Composant Rôle Exemple
Schéma Protocole https://
Sous-domaine Service spécifique hal
Domaine principal Institution science
TLD Extension .fr, .dz, .org
Chemin Ressource /hal-01234567v1/document
Paramètres Requête ?q=linguistique+algérie
Fragment Ancre #bibliographie

Exercice Master : analyser l'URL d'un article dans Cairn, d'un cours Moodle, d'une page HAL. Identifier les paramètres de session et les éventuels identifiants.

Internationalized Domain Names (IDN) : domaines en caractères non latins (arabe, cyrillique, chinois). Exemple : .dz (Algérie) avec caractères arabes possibles à l'avenir.

HTTP/HTTPS : protocoles et sécurité (10 min)

Méthodes HTTP : | Méthode | Usage | Exemple académique | |---------|-------|-------------------| | GET | Récupérer une ressource | Afficher article HAL | | POST | Envoyer des données | Soumettre formulaire Moodle | | PUT | Mettre à jour | Modifier profil ORCID | | DELETE | Supprimer | Retirer un fichier |

Codes de statut : - 2xx : succès (200 OK) - 3xx : redirection (301, 302) - 4xx : erreur client (404 Not Found, 403 Forbidden) - 5xx : erreur serveur (500 Internal Server Error)

HTTPS : HTTP sur TLS (chiffrement). Vérifier le cadenas dans la barre d'adresse avant de saisir des identifiants universitaires.

HTTP/2 et HTTP/3 : versions plus rapides (multiplexage, QUIC). Impact sur la consultation de corpus volumineux.

HTML : structure sémantique des pages (10 min)

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Mon mémoire - HAL</title>
  <meta name="description" content="Résumé de recherche en linguistique">
</head>
<body>
  <header>
    <h1>Titre du mémoire</h1>
    <p class="author">Par Étudiant X</p>
  </header>
  <main>
    <article>
      <section id="introduction">
        <h2>Introduction</h2>
        <p>Contenu de l'introduction...</p>
      </section>
    </article>
  </main>
  <footer>
    <p>© 2025 - Licence CC-BY</p>
  </footer>
</body>
</html>

Balises sémantiques HTML5 : header, nav, main, article, section, aside, footer — améliorent l'accessibilité et le référencement.

HTML pour le chercheur : inspecter une page (F12) permet de comprendre la structure d'un site, d'extraire des données, d'analyser les microdonnées (schema.org) pour le Web sémantique.

Web scraping : constitution de corpus (15 min)

Méthodes de collecte de données Web

Méthode Outil Volume Compétence
Copier-coller manuel — Faible Aucune
Extension navigateur Data Miner, Web Scraper Moyen Basique
Script Python BeautifulSoup, Scrapy Élevé Programmation
API officielle Twitter API, YouTube Data API Très élevé Développement
Outil no-code Octoparse, ParseHub Moyen Configuration

Bonnes pratiques pour la recherche en langue

  1. Respecter le robots.txt du site (indique les pages interdites au scraping)
  2. Limiter le taux de requêtes (ne pas surcharger le serveur)
  3. Citer la source : date de collecte, URL, méthode
  4. Consentement : pour les données personnelles ou les forums privés
  5. Anonymisation : supprimer les identifiants des participants

Exemple de corpus Web pour Master Langue et Culture

  • Commentaires YouTube sur une chaîne algérienne (français/darija)
  • Articles de presse en ligne algérienne (El Watan, Liberté)
  • Forums de discussion en tamazight
  • Pages Facebook d'artistes ou d'écrivains algériens

Web 2.0 et contenu généré par les utilisateurs (10 min)

Web 2.0 (O'Reilly 2005) : passage du Web statique (lecture) au Web participatif (écriture). Caractéristiques : - Contenu généré par les utilisateurs (UGC) - Plateformes collaboratives (Wikipédia, YouTube, Facebook, Instagram) - Architecture de la participation

Intérêt pour la recherche en langue et culture :

Plateforme Données exploitables Question de recherche
YouTube Commentaires, transcriptions Variations linguistiques en Algérie
Facebook Posts, réactions, commentaires Code-switching français/darija
Twitter/X Tweets, hashtags, retweets Discours politique en ligne
Wikipedia Historique de révision Construction collaborative du savoir
Blogs Articles, commentaires Écriture numérique et standards

Analyse du discours numérique : prendre en compte le contexte technique (limite de caractères, affordances de la plateforme), le multilinguisme, et les normes communicatives spécifiques à chaque site.

Web sémantique et données liées (10 min)

Web sémantique (Berners-Lee et al. 2001) : extension du Web où l'information est structurée pour être interprétable par les machines.

Technologies clés : - RDF (Resource Description Framework) : graphe de triplets (sujet-prédicat-objet) - SPARQL : langage de requête pour les données RDF - OWL : langage d'ontologies - SKOS : systèmes d'organisation des connaissances - schema.org : vocabulaire structuré pour les moteurs de recherche

Application en SHS : - Wikidata : base de connaissances collaborative liée - BNF Data : données bibliographiques liées - Pleiades : ressources en géographie ancienne liée - DBpedia : version structurée de Wikipédia

Exercice : interroger Wikidata avec SPARQL pour extraire les écrivains algériens francophones.

Archivage du Web pour la mémoire culturelle (5 min)

Problème : le Web est éphémère — les pages disparaissent, les contenus changent (lien brisé = référence perdue).

Projets d'archivage : - Internet Archive / Wayback Machine (archive.org) : 866 milliards de pages archivées - Archives du Web français (BnF) : dépôt légal du Web depuis 2006 - Archive.today : capture instantanée

Pour le chercheur : - Archiver systématiquement les pages citées dans votre mémoire - Utiliser le DOI (Digital Object Identifier) pour les ressources pérennes - Préférer les ressources avec une politique d'archivage (HAL, OpenEdition)

Évaluation des sources Web (5 min)

Grille CRAP adaptée au contexte algérien :

Critère Questions à se poser
Currency (Actualité) Date de publication ? Mise à jour récente ?
Reliability (Fiabilité) Sources citées ? Auteur identifiable ? Références ?
Authority (Autorité) Affiliation institutionnelle ? Titres académiques ?
Purpose (Finalité) Site institutionnel (.dz, .gov) ? Commercial ? Militant ?

Pièges spécifiques : - Sites « académiques » auto-publiés sans comité de lecture - Mélange information/opinion sur les blogs - Deepfakes et désinformation en ligne

QCM d'auto-évaluation (5 questions)

1. Quelle méthode HTTP est utilisée pour soumettre un formulaire sur Moodle ? - a) GET - b) POST ✓ - c) PUT - d) DELETE

2. Que signifie le code HTTP 404 ? - a) Succès de la requête - b) Redirection permanente - c) Ressource non trouvée ✓ - d) Erreur serveur interne

3. Dans le contexte du Web sémantique, que signifie RDF ? - a) Rapid Data Format - b) Resource Description Framework ✓ - c) Réseau de Diffusion Français - d) Random Data File

4. Quel outil est recommandé pour archiver une page Web citée dans un mémoire ? - a) Google Drive - b) Wayback Machine (Internet Archive) ✓ - c) Dropbox - d) Microsoft Word

5. Lequel de ces éléments n'est PAS une caractéristique du Web 2.0 ? - a) Pages statiques uniquement en lecture ✓ - b) Contenu généré par les utilisateurs - c) Plateformes collaboratives - d) Réseaux sociaux

Note pédagogique Master

Transposition didactique : Ce cours transforme la simple « navigation Web » (niveau licence) en une méthodologie de recherche numérique. L'étudiant apprend à considérer le Web comme un terrain d'enquête et une source de données. L'accent est mis sur les compétences techniques minimales (inspecter, scraper) et les compétences réflexives (éthique, évaluation).

Conseil pour le formateur : Prévoir une connexion Internet stable pour les démonstrations de scraping et de SPARQL. Avoir un plan B (captures d'écran, exemples hors ligne) en cas de coupure. Montrer des exemples algériens concrets (presse en ligne, pages Facebook). Attention à l'aspect juridique : ne pas encourager le scraping illégal.

Prolongement recherche : Les étudiants peuvent explorer les Digital Methods (Rogers 2013) pour une analyse approfondie des controverses en ligne, ou constituer un corpus longitudinal de presse algérienne en ligne pour une analyse diachronique du discours.
