Référentiel : titres et structure alignés sur Canvas Univ-Mosta (elearning.univ-usto.dz) ; bonnes pratiques benchmark 10 universités algériennes (voir BENCHMARK_10_UNIVERSITES_ELEARNING.md).

Objectifs de l'enseignement

En termes de savoir : - Maîtriser l'organisation du système de fichiers Windows pour la recherche académique - Comprendre les principes d'arborescence pour les données de recherche - Distinguer les formats de fichiers pour les données scientifiques (TXT, CSV, XML, JSON, TSV) - Connaître les outils Windows pour la recherche : Explorateur avancé, PowerShell, sous-système Linux (WSL)

En termes de savoir-faire : - Structurer un espace de travail pour un projet de recherche / mémoire - Utiliser les outils de gestion bibliographique (Zotero) sous Windows - Automatiser des tâches simples de gestion de fichiers (renommage, tri) - Maîtriser la recherche avancée de fichiers par métadonnées et contenu - Utiliser les outils d'accessibilité et de productivité pour la rédaction scientifique

En termes de savoir-être : - Adopter une organisation méthodique et reproductible de ses données de recherche - Respecter les principes FAIR (Findable, Accessible, Interoperable, Reusable) dans la gestion de ses fichiers - Développer une culture de la sauvegarde et de l'archivage

Mode d'évaluation : TD 30 % + Projet « Organisation d'un espace de recherche numérique » 30 % + QCM 20 % + Examen pratique 20 %

1. Introduction : Windows comme Environnement de Recherche (10 min)

1.1 Pourquoi Windows est crucial en Master

Au niveau Licence, Windows était un outil pour accéder à Moodle, écrire des devoirs et naviguer. En Master, Windows devient l'environnement de travail du chercheur :

  • Gestion de données : organiser, nommer, trouver et archiver des centaines de fichiers (corpus, articles, notes, données brutes)
  • Écosystème logiciel : faire cohabiter Zotero, Word, AntConc, Python, TXM, navigateurs, lecteurs PDF
  • Interopérabilité : Windows doit dialoguer avec des serveurs Linux, des clouds, des bases de données
  • Automatisation : des tâches répétitives (renommage, conversion, tri) peuvent et doivent être automatisées

1.2 Windows 11 pour la recherche

Windows 11 offre des fonctionnalités particulièrement utiles pour le chercheur en langues : - Snap Layouts : organiser ses fenêtres (Word, Zotero, navigateur, Explorateur) sur un grand écran - Virtual Desktops : séparer ses espaces (recherche / rédaction / administratif) - Windows Terminal : terminal moderne intégré (PowerShell, CMD, WSL) - WSL 2 (Windows Subsystem for Linux) : exécuter des outils Linux natifs (Python, R, TXM) sans dual-boot - PowerToys : outils avancés (PowerRename, PowerToys Run, FancyZones)

2. Arborescence de Recherche : Principes et Conventions (15 min)

2.1 Pourquoi une arborescence rigoureuse ?

Une arborescence bien conçue est le fondement d'une recherche reproductible. Elle permet de : - Retrouver instantanément n'importe quel fichier - Distinguer les données brutes des données traitées - Séparer les versions de travail des versions finales - Faciliter le partage et l'archivage

2.3 Conventions de nommage

Règle Exemple Pourquoi
Date ISO (AAAA-MM-JJ) en premier 2025-10-15_Compte_rendu_TD.docx Tri chronologique automatique
Noms sans espaces ni accents corpus_presse_2025 Compatibilité scripts et outils Linux
Version explicite Memoire_Ch1_v2.docx Évite les confusions
Suffixe de statut _BRUT, _PROPRE, _FINAL Distingue les états des données

2.4 Métadonnées et recherche avancée

Windows indexe automatiquement les fichiers pour permettre une recherche par : - Nom et extension - Contenu textuel (Word, PDF, TXT) : taper un mot présent dans le document - Métadonnées : auteur, date de création, mots-clés (onglet Détails dans Propriétés) - Tags Windows : ajouter des tags aux fichiers de recherche (ex: #corpus, #litterature_algerienne)

Astuce Master : utilisez ext:.pdf auteur:belacel dans la barre de recherche de l'Explorateur pour filtrer par extension ET auteur simultanément.

3. Formats de Fichiers pour la Recherche en Langues (15 min)

3.1 Formats textuels

Format Usage Avantage Inconvénient
.txt (UTF-8) Corpus bruts, scripts, notes Universel, lisible par tout outil Pas de mise en forme
.csv Données tabulaires (métadonnées de corpus) Structuré, importable dans Excel/R/Python Encodage UTF-8 à vérifier
.xml Corpus annotés (TEI, XML) Standard pour humanités numériques Verbosité, taille
.json Données structurées pour API, web Léger, natif en Python/JS Moins standard en SHS
.md (Markdown) Notes de recherche, documentation Léger, versionnable (Git), convertible (Pandoc) Pas de mise en page riche
.pdf/.pdfa Diffusion, archivage, dépôt légal Universel, non modifiable Difficile à traiter automatiquement

3.2 Le format TEI (Text Encoding Initiative)

Le TEI XML est le format standard international pour l'encodage de textes en sciences humaines. Il permet de : - Baliser des structures textuelles (chapitres, paragraphes, vers) - Annoter des entités nommées (personnes, lieux, dates) - Coder des phénomènes linguistiques (variantes, corrections, gloses) - Assurer l'interopérabilité entre projets et institutions

Exemple minimal :

<TEI>
  <teiHeader>
    <fileDesc>
      <titleStmt><title>Corpus de romans algériens</title></titleStmt>
    </fileDesc>
  </teiHeader>
  <text>
    <body>
      <p>Ceci est un <rs type="person">personnage</rs> dans le texte.</p>
    </body>
  </text>
</TEI>

3.3 Conversion entre formats

Un chercheur en langues doit savoir convertir ses fichiers entre formats selon les besoins : - Pandoc : .md ↔ .docx ↔ .pdf ↔ .tex (outil en ligne de commande) - Calibre : conversion de formats de livres numériques (ePub, Mobi) - Python (pandas) : .csv ↔ .json ↔ .xml pour données tabulaires - PowerShell : manipulation de fichiers texte (encodage, remplacement)

4. Outils Avancés de Gestion de Fichiers (15 min)

4.1 Explorateur de fichiers avancé

Windows 11 propose des fonctionnalités avancées souvent méconnues :

  • Volet de navigation structuré (Accès rapide, OneDrive, Ce PC)
  • Volet d'aperçu (Alt+P) : visualiser un fichier sans l'ouvrir (PDF, image, texte)
  • Regrouper par : par type, date, auteur, tags
  • Filtrer : par taille, type, date de modification
  • Bibliothèques : regrouper virtuellement des dossiers dispersés
  • Compresser / Extraire : gestion native des ZIP

4.2 Recherche avancée avec l'Explorateur

Syntaxe de recherche dans la barre de l'Explorateur :

Commande Effet
corpus Fichiers contenant "corpus" dans le nom ou le contenu
type:.pdf Uniquement les PDF
datemodif:>01/09/2025 Modifiés après septembre 2025
auteur:belacel Fichiers dont l'auteur est Belacel
taille:>10Mo Fichiers de plus de 10 Mo
tags:corpus Fichiers taggés "corpus"

Combinaison : type:.pdf datemodif:>01/09/2025 corpus algérien

4.3 Windows Terminal et PowerShell

PowerShell permet d'automatiser des tâches : renommer en masse (Get-ChildItem *.txt | Rename-Item -NewName { $_.Name -replace 'X', 'Y' }), compter les mots, convertir l'encodage en UTF-8.

4.4 WSL (Windows Subsystem for Linux)

WSL 2 exécute un noyau Linux sous Windows — utile pour les outils TAL natifs (TreeTagger, Stanza), Python/R en environnement Unix, et Git en ligne de commande.

5. Gestion Bibliographique avec Zotero (15 min)

5.1 Pourquoi un gestionnaire bibliographique en Master ?

Un mémoire de Master cite 30 à 80 sources. Zotero automatise la gestion des références et la génération des bibliographies.

5.2 Installation et configuration

  1. Télécharger Zotero depuis zotero.org (version standalone)
  2. Installer le connecteur pour navigateur (Chrome/Firefox/Edge)
  3. Installer le plugin Word (inclus dans l'installateur Zotero)
  4. Configurer :
  5. Préférences → Citer → Style : APA 7 (ou autre selon consigne)
  6. Préférences → Sync : créer un compte Zotero.org pour synchronisation cloud
  7. Préférences → Avancé : dossier de stockage des PDFs

5.3 Ajouter des références

Méthode Description
Connecteur navigateur Depuis une page web (Cairn, Google Scholar, Persée, OpenEdition), cliquez sur l'icône Zotero
Import PDF Glissez-déposez un PDF dans Zotero — il extrait automatiquement les métadonnées
Identifiant Saisissez un DOI, ISBN, PMID — Zotero télécharge la notice
Saisie manuelle Ajoutez une référence si aucune méthode automatique ne fonctionne

5.4 Organiser sa bibliothèque

  • Collections : dossiers thématiques (Linguistique, Littérature, Méthodologie)
  • Tags : mots-clés transversaux (#corpus, #analyse_discours, #sociolinguistique)
  • Notes : associer des notes de lecture à chaque référence
  • Recherche avancée : sauvegarder des recherches réutilisables

5.5 Citer avec Zotero dans Word

Dans Word : onglet Zotero → Add/Edit Citation → chercher la référence → insérer. En fin de document : Add/Edit Bibliography génère la bibliographie. Avantage clé : changer de style (MLA → APA) met à jour toutes les citations d'un clic. (Voir Cours 04 pour le détail complet.)

6. Automatisation et Productivité (10 min)

6.1 Raccourcis clavier essentiels

Win+E (Explorateur) — Win+D (Bureau) — Win+Tab (Bureaux virtuels) — Win+L (Verrouiller) — Win+S (Recherche) — F2 (Renommer) — Ctrl+Shift+N (Nouveau dossier) — Ctrl+Maj+Échap (Gestionnaire tâches)

6.2 PowerToys (Microsoft Power Utilities)

  • PowerRename : renommage avancé avec regex (utile pour normaliser des noms de fichiers de corpus)
  • FancyZones : disposition avancée des fenêtres (Word à gauche, Zotero à droite, navigateur en haut)
  • PowerToys Run : lanceur d'applications et recherche rapide (Alt + Espace)
  • Text Extractor : OCR sur n'importe quelle zone de l'écran (Win + Shift + T)
  • Color Picker : sélecteur de couleurs (Win + Shift + C)

7. Sauvegarde, Archivage et Principes FAIR (10 min)

7.1 Stratégie de sauvegarde 3-2-1

Niveau Description Exemple
3 copies Toujours 3 copies de vos données Original + sauvegarde1 + sauvegarde2
2 supports Sur au moins 2 supports différents SSD interne + disque externe
1 hors site 1 copie hors de votre domicile Cloud (OneDrive, Google Drive) + clé chez un proche

7.2 Windows et l'archivage long terme

  • Historique des fichiers : activer dans Paramètres → Sauvegarde → Historique des fichiers
  • OneDrive : synchronisation cloud automatique (Univ-Mosta offre un compte via Office 365)
  • Point de restauration : avant installation de nouveaux logiciels de recherche
  • PDF/A : format d'archivage validé par le Dépôt Légal Numérique algérien (Décision n°75)

7.3 Les principes FAIR appliqués à l'organisation Windows

Findable (nommage + tags) — Accessible (chemins logiques + OneDrive) — Interoperable (formats ouverts TXT/CSV/XML) — Reusable (README.txt dans chaque dossier décrivant contenu, source, conventions).

8. Conclusion (10 min)

Windows n'est pas qu'un système d'exploitation : c'est l'infrastructure numérique de votre recherche en Master. Une organisation rigoureuse de vos fichiers, une gestion professionnelle de votre bibliographie et une stratégie de sauvegarde solide sont des compétences aussi importantes que la rédaction elle-même.

Note pédagogique Master

Transposition didactique pour le Master

Ce cours marque une rupture qualitative avec l'approche Licence : il ne s'agit plus d'« apprendre à utiliser Windows » mais de concevoir Windows comme un environnement de recherche professionnel. La transposition s'articule autour de cinq compétences-clés :

  1. Architecture de l'information : l'étudiant apprend à organiser ses données selon une logique de recherche (données brutes → nettoyées → analysées → publiées) plutôt qu'une logique « dossier personnel ».
  2. Interopérabilité : Windows doit cohabiter avec Zotero, WSL, des clouds, des formats multiples — l'étudiant comprend l'écosystème logiciel dans son ensemble.
  3. Automatisation : les tâches répétitives (renommage, conversion, tri) sont confiées à des scripts — premier pas vers la pensée computationnelle.
  4. Gestion bibliographique : Zotero n'est pas un outil facultatif mais un prérequis méthodologique pour le mémoire.
  5. Reproductibilité : l'organisation des fichiers et la documentation associée (README.txt) anticipent les exigences de la recherche scientifique.

Conseil pour le formateur

  • Avant la séance : demander aux étudiants de créer un compte Zotero.org et d'installer Zotero. Vérifier que Windows est à jour.
  • Matériel nécessaire : un vidéoprojecteur pour montrer l'explorateur, Zotero, et les manipulations. Préparer un dossier ZIP avec des fichiers à renommer pour l'atelier PowerShell.
  • Points d'attention : la partie Zotero est longue — prévoir 20 min dédiées. Certains étudiants auront des difficultés avec PowerShell ; rassurez-les en montrant que quelques commandes suffisent pour gagner un temps considérable.
  • Évaluation : le projet noté consiste à rendre un plan de gestion des données pour le mémoire — structuré, avec arborescence, conventions de nommage, et description de la stratégie de sauvegarde.

Prolongement recherche

Ce cours prépare directement : - L'atelier Zotero avancé (Semestre 2) : styles personnalisés, groupes collaboratifs, API Zotero - L'enquête de terrain (S2) : organisation des données d'enquête (entretiens, questionnaires) - Le dépôt du mémoire : respect des normes du Dépôt Légal Numérique algérien - Twitter / Academia.edu / ResearchGate : gestion des identifiants numériques du chercheur (ORCID)

Pour les étudiants souhaitant approfondir : suivre le MOOC « Gestion des données de la recherche » sur FUN-MOOC ou la formation « Data Management » proposée par le CRAIM (Alger).
