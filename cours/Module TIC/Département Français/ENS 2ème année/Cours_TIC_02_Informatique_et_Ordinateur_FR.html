1. Introduction : Pourquoi Comprendre l'Ordinateur ? (10 min)

Comprendre le fonctionnement de l'ordinateur est essentiel pour tout étudiant, même en filière Langues. Cela permet de :

  • Mieux utiliser ses outils (Word, navigateur, Moodle, ENT)
  • Éviter les pertes de données par une gestion éclairée du stockage
  • Diagnostiquer les problèmes simples (câble débranché, batterie, redémarrage)
  • Organiser efficacement son espace de travail numérique
  • Acquérir un vocabulaire technique de base pour communiquer avec les services informatiques

L'ordinateur est devenu le principal instrument de travail universitaire et sa maîtrise est une compétence transversale indispensable pour le futur enseignant de langues.

2. Qu'est-ce que l'Informatique ? (10 min)

graph LR
    A[Données] --> B[Traitement<br/>par l'ordinateur]
    B --> C[Résultats]
    D[Algorithme] --> B
    E[Utilisateur] --> B

L'informatique est la science du traitement automatique de l'information à l'aide d'algorithmes exécutés par des machines. Elle inclut quatre domaines principaux :

  1. La théorie — fondements mathématiques et algorithmiques
  2. Le matériel (Hardware) — composants physiques de l'ordinateur
  3. Les logiciels (Software) — programmes qui pilotent le matériel
  4. Les réseaux — communication entre machines

Pour l'étudiant en langues, l'approche est utilisateur : comprendre suffisamment pour bien utiliser l'ordinateur dans ses études et, plus tard, dans sa pratique professionnelle d'enseignant.

3. Modèle de von Neumann (15 min)

        S[Sortie]
        ST[Stockage permanent<br/>HDD / SSD]

    UC <--> MU
    UC --> S

Un ordinateur est une machine programmable capable de quatre opérations fondamentales :

  1. Entrée (Input) — recevoir des données (clavier, souris, microphone)
  2. Traitement (Processing) — exécuter des instructions par le CPU
  3. Stockage temporaire (Memory) — conserver les données en cours de travail (RAM)
  4. Sortie (Output) — restituer les résultats (écran, imprimante, haut-parleurs)

Le modèle de von Neumann (John von Neumann, 1945) est le fondement architectural de la quasi-totalité des ordinateurs modernes. Il repose sur le concept de programme enregistré : les instructions et les données sont stockées dans la même mémoire.

4. Composants Matériels (Hardware) (15 min)

Composant Rôle Caractéristique importante
Processeur (CPU) Exécute les instructions Fréquence en GHz, nombre de cœurs
Carte mère Interconnecte tous les composants Format, chipset, sockets
RAM (Mémoire vive) Stockage temporaire des données actives Capacité en Go, vitesse en MHz
Stockage (HDD/SSD) Conservation permanente des données Capacité en Go/To, vitesse de lecture
Carte graphique Génère l'affichage à l'écran Mémoire dédiée, résolution supportée
Périphériques d'entrée Souris, clavier, webcam, microphone Interface USB, Bluetooth
Périphériques de sortie Écran, imprimante, enceintes Résolution, connectique
Alimentation Fournit l'énergie électrique Puissance en Watts, rendement

Point clé : La RAM est volatile — elle perd toutes les données non sauvegardées lorsque l'ordinateur s'éteint. Le stockage permanent (HDD/SSD) conserve les données même hors tension. Cette distinction est fondamentale pour éviter les pertes de travail.

Catégories de logiciels :

Catégorie Rôle Exemples
Système d'exploitation Interface entre matériel et utilisateur Windows 11, Ubuntu, macOS
Logiciels applicatifs Réalisent des tâches spécifiques Microsoft Office, navigateur web
Logiciels utilitaires Maintenance et optimisation Antivirus, compresseur, nettoyage

Différence fondamentale : Le hardware est tangible (on peut le toucher), le software est intangible (ensemble d'instructions). Mais l'un ne fonctionne pas sans l'autre.

6. Interaction Hardware / Software (10 min)

Exemple concret : Lorsque vous tapez une lettre au clavier :

  1. Hardware : la touche est pressée, un signal électrique est envoyé
  2. Système d'exploitation : intercepte le signal et détermine le caractère
  3. Application (Word, navigateur) : reçoit le caractère et l'affiche
  4. Hardware : l'écran affiche le caractère à l'écran

Ce cycle entrée → traitement → sortie se produit des milliers de fois par seconde, chaque jour, sans que l'utilisateur en ait conscience.

7. Bonnes Pratiques pour Étudiants Universitaires (10 min)

  1. Sauvegarder régulièrement — utiliser Ctrl + S systématiquement + sauvegarde cloud (OneDrive, Google Drive)
  2. Organiser ses dossiers — créer une arborescence claire dès le début du semestre (par matière, par semaine)
  3. Mettre à jour — Windows et les logiciels doivent être à jour pour des raisons de sécurité
  4. Utiliser un antivirus — Windows Defender est suffisant s'il est activé et à jour
  5. Distinguer RAM et stockage — ne pas confondre les deux : un manque de RAM ralentit l'ordinateur, un disque plein empêche de sauvegarder
  6. Éteindre correctement — toujours utiliser l'arrêt du système, ne pas débrancher brutalement

8. Conclusion (10 min)

Comprendre l'architecture de l'ordinateur permet d'être plus autonome et efficace dans son travail universitaire et professionnel.

Points essentiels à retenir : - L'informatique = traitement automatique de l'information - Le modèle de von Neumann : entrée → traitement → sortie - La RAM est volatile, le stockage permanent ne l'est pas - Le hardware et le software sont indissociables - Les bonnes pratiques évitent les pertes de données

Note pédagogique ENS

Transposition didactique : Ce cours sur l'architecture de l'ordinateur peut être adapté pour une séquence en classe de langues au collège ou au lycée. L'enseignant stagiaire peut proposer à ses élèves une activité de découverte et d'identification des composants d'un ordinateur (observation, schéma, légende) en lien avec le vocabulaire technique en langue cible.

Conseil pour l'enseignant formateur : Proposer aux étudiants ENS de démonter (virtuellement ou physiquement) un vieil ordinateur pour identifier les composants étudiés en cours. Cette activité concrète favorise la mémorisation et donne du sens aux concepts théoriques.

Prolongement : Demander aux étudiants de créer un schéma annoté de l'architecture de von Neumann à l'aide d'un outil numérique (Lucidchart, Draw.io, PowerPoint) et de le partager sur un forum Moodle. Cette activité développe à la fois les compétences TIC et la compréhension de l'architecture.
