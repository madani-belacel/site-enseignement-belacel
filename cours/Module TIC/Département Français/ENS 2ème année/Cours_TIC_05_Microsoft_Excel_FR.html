1. Introduction (10 min)

Excel est le tableur de la suite Microsoft Office, standard dans l'administration universitaire algérienne (notes, PV de délibérations, statistiques).

Usages académiques concrets pour un étudiant en français : - Relevé de vocabulaire et fréquence lexicale (petits corpus) - Tableau de notes de classe (moyenne, écart-type, rang) - Planification de projet (mémoire, stage) - Données d'enquête sociolinguistique (questionnaire)

Alternatives libres : Google Sheets (collaboratif), LibreOffice Calc (gratuit, utilisable sur postes ENS).

3. Saisie, Mise en Forme et Organisation (15 min)

Bonnes pratiques de saisie

  • Ligne 1 : en-têtes en gras (Nom, Prénom, Note1, Note2, Moyenne)
  • Pas de lignes vides à l'intérieur du tableau
  • Un seul tableau par feuille
  • Format cohérent : même décimales pour les notes (ex. 14,50)

Mise en forme utile

Outil Emplacement Usage
Bordures Accueil > Police Cadrer le tableau
Format nombre Accueil > Nombre Décimales, pourcentage
Mise en forme conditionnelle Accueil > Styles Couleur si note < 10
Ajuster texte Accueil > Alignement En-têtes longs
Figer les volets Affichage > Figer Ligne 1 toujours visible

4. Formules et Fonctions Essentielles (20 min)

Syntaxe d'une formule

Toute formule commence par =.

=SOMME(A1:A10)   → somme des valeurs
=MOYENNE(B2:B20) → moyenne arithmétique
=MIN(C3:C15)     → valeur minimale
=MAX(C3:C15)     → valeur maximale
=NB(D1:D30)      → nombre de cellules numériques
=SI(E2>=10;"Admis";"Ajourné") → condition

Exemple détaillé : calcul de mention

Colonne Formule Résultat
Moyenne =MOYENNE(C2:D2) 15,0
Mention =SI(E2>=16;"TB";SI(E2>=14;"B";SI(E2>=12;"AB";SI(E2>=10;"P";"A")))) B

Tableau des fonctions courantes

Fonction Syntaxe Description
SOMME =SOMME(plage) Additionne
MOYENNE =MOYENNE(plage) Moyenne
MIN =MIN(plage) Minimum
MAX =MAX(plage) Maximum
NB =NB(plage) Compte nombres
NB.SI =NB.SI(plage;"critère") Compte selon critère
SI =SI(test;vrai;faux) Conditionnelle
RECHERCHEV =RECHERCHEV(valeur;table;col;0) Recherche verticale
STXT =STXT(texte;début;nbr) Extrait chaîne

Impact pédagogique (ENS)

En département de français, NB.SI et RECHERCHEV sont utiles pour l'analyse de corpus textuels et la gestion des relevés de notes par lot.

5. Références Relatives et Absolues (15 min)

Référence relative

B2 → en recopiant vers le bas → B3, B4, B5...

La référence s'ajuste automatiquement.

Référence absolue

$B$2 → en recopiant → reste $B$2

Ne change jamais. Utile pour un seuil (ex. 10/20).

Référence mixte

$B2 → colonne fixe, ligne variable
B$2 → ligne fixe, colonne variable
Formule Copiée en C3 Utilité
=B2 =C3 Relative
=$B$2 =$B$2 Absolue (seuil)
=$B2 =$B3 Mixte colonne fixe
=B$2 =C$2 Mixte ligne fixe

Raccourci F4 : basculer entre les modes (relatif → absolu → mixte → relatif).

6. Création et Personnalisation de Graphiques (10 min)

Types de graphiques

Type Usage Exemple académique
Histogramme Comparer des valeurs Notes par étudiant
Courbe Évolution dans le temps Progression semestrielle
Secteurs Répartition % mentions obtenues
Barres Comparaison horizontale Classement

Étapes (Excel)

  1. Sélectionner les données (en-têtes inclus)
  2. Insérer > Graphique > choisir type
  3. Ajouter titre, légendes, étiquettes
  4. Mise en forme sobre (couleurs sobres, pas d'effet 3D inutile)

Conseils ENS

  • Titre explicite : Moyennes du TD Groupe A — Semestre 1
  • Légende si plusieurs séries
  • Police lisible (≥ 10 pt)
  • Exporter en image pour rapport Word

7. Tri, Filtres et Bonnes Pratiques (10 min)

Tri

  • Sélectionner le tableau > Données > Trier
  • Trier par une ou plusieurs colonnes (ex. moyenne décroissante)

Filtre automatique

  • Sélectionner > Données > Filtrer
  • Filtrer par valeur, couleur, condition

Bonnes pratiques

Pratique Pourquoi
Nommer les onglets (Notes, Graphique) Clarté
Ctrl+S toutes les 5 min Éviter perte de données
Vérifier formules avec Ctrl+~ Débogage
Ne pas fusionner les cellules inutilement Problèmes de tri
Exporter en PDF pour Moodle Compatibilité
Sauvegarder version .xlsx + .pdf Archivage

Raccourcis essentiels

Action Raccourci
Nouveau classeur Ctrl+N
Enregistrer Ctrl+S
Afficher formules Ctrl+ù (ou `)
Sélectionner ligne Shift+Espace
Sélectionner colonne Ctrl+Espace
Graphique rapide Alt+F1

Note pédagogique ENS — Transposition didactique

Transposition didactique

  • Du savoir savant au savoir enseigné : Le tableur est un outil issu de l'informatique de gestion. Pour des étudiants de français, on le transpose en outil de gestion de données académiques (notes, bibliographies, enquêtes).
  • Réduction de la complexité : on limite le champ aux 6 fonctions de base + RECHERCHEV (utile en master). On évite les macros, TCD et formules matricielles.
  • Médiation sémiotique : usage de la métaphore du « cahier de notes papier » pour introduire le classeur / feuille / cellule.

Conseil pour le formateur

  • Prérequis vérifiés : s'assurer que les étudiants maîtrisent la souris, le clavier alpha-numérique, la sauvegarde de fichier (vu en TIC 04).
  • Rythme : alterner 10 min de démonstration → 10 min d'exercice guidé → 5 min de vérification.
  • Erreurs fréquentes :
  • oublier le = devant une formule
  • confusion entre la référence relative et absolue
  • cellules fusionnées qui bloquent le tri
  • Remédiation : prévoir une fiche « 5 erreurs Excel et comment les corriger » distribuée en séance.

Prolongements

  • TIC 06 (PowerPoint) : copier-coller le graphique Excel dans le diaporama.
  • TIC 07 (Internet) : chercher des données ouvertes (ONS, World Bank) et les importer dans Excel.
  • Projet interdisciplinaire : avec le module de Linguistique, analyser la fréquence des mots dans un corpus texte avec NB.SI et STXT.
  • Mémoire de Master : utiliser Excel pour les tableaux de dépouillement de questionnaires d'enquête sociolinguistique.
