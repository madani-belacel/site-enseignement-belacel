Introduction au Web (10 min)

Le World Wide Web (WWW) permet d'accéder à des ressources via des URL et un navigateur. Standard ouvert : HTML, HTTP, URLs.

Contexte Moodle : la plateforme e-learning est une application Web (PHP) accessible par navigateur.

Web 1.0, 2.0, 3.0 — évolution

Génération Période Caractéristique Exemple
Web 1.0 (statique) 1991–2004 Pages HTML lues passivement Sites vitrines
Web 2.0 (social) 2004–2015 Contenu généré par l'utilisateur Forums, Moodle, YouTube
Web 3.0 (sémantique) 2015–présent Données liées, IA, personnalisation Recommandations intelligentes
Web 3 (décentralisé) Émergent Blockchain, dApps Identité numérique

Navigateurs Web (15 min)

Navigateurs courants : Chrome, Firefox, Edge, Safari.

Composant Rôle
Moteur de rendu (Blink, Gecko, WebKit) Affiche HTML/CSS
Moteur JS (V8, SpiderMonkey, JavaScriptCore) Exécute scripts JavaScript
Stockage local Cookies, cache, localStorage

Mettre à jour le navigateur pour la sécurité (correctifs).

URL et structure d'une adresse Web (15 min)

Exemple : https://elearning.univ-usto.dz/course/view.php?id=2094

Partie Signification Exemple concret
https:// Protocole sécurisé (TLS) Chiffrement des données
elearning.univ-usto.dz Nom de domaine (DNS) Sous-domaine + domaine + .dz
/course/view.php Chemin ressource Script PHP sur serveur
?id=2094 Paramètre (query string) Identifiant unique du cours

HTTP (non chiffré, port 80) vs HTTPS (TLS, port 443, cadenas vert).

HTML — structure d'une page (10 min)

<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Mon cours de Littérature</title>
</head>
<body>
    <header>
        <h1>Cours de Littérature française</h1>
    </header>
    <main>
        <article>
            <h2>Chapitre 1 : Le classicisme</h2>
            <p>Le <strong>classicisme</strong> est un courant littéraire du XVII<sup>e</sup> siècle.</p>
            <ul>
                <li>Molière</li>
                <li>Racine</li>
                <li>La Fontaine</li>
            </ul>
        </article>
    </main>
    <footer>
        <p>&copy; 2025 — Département Français</p>
    </footer>
</body>
</html>

Balises essentielles : h1–h6, p, a href, img, ul/li, table. Inspecter (F12) pour comprendre une page Moodle.

Balises HTML — glossaire pour étudiants de lettres

Balise Rôle Usage en lettres
<h1> à <h6> Titres hiérarchiques Structure de dissertation
<p> Paragraphe Corps de texte
<strong> Mise en valeur Termes importants
<em> Italique Titres d'œuvres
<a href=""> Lien hypertexte Références bibliographiques
<blockquote> Citation longue Extraits d'œuvres
<ul> / <ol> Listes Plan, bibliographie
<table> Tableau Données comparatives

Moteurs de recherche (10 min)

  • Google, Bing, DuckDuckGo : indexation + algorithme de pertinence
  • Requête booléenne : "TIC enseignement" AND Algérie
  • Critères CRAP : Currency, Reliability, Authority, Purpose (recherche documentaire)

Privilégier sources .edu, .gov, bases Cairn, HAL, Erudit pour travaux universitaires.

Critères CRAP — grille d'évaluation d'une page Web

Critère Questions à se poser Indicateur
Currency (Actualité) Date de publication ? Mise à jour récente ? Pied de page, date article
Reliability (Fiabilité) Sources citées ? Références bibliographiques ? Notes, bibliographie
Authority (Autorité) Qui est l'auteur ? Institution ? Domaine .edu / .gov ? À propos, page contact
Purpose (Objectif) Informer, vendre, convaincre ? Objectivité ? Ton, publicité, parti pris

Opérateurs booléens pour la recherche académique

Opérateur Rôle Exemple en lettres
AND Les deux termes "littérature maghrébine" AND "oralité"
OR Au moins un terme "francophonie" OR "postcolonial"
NOT (ou -) Exclure un terme "cours littérature" -"vente"
" " Expression exacte "théorie de la réception"
site: Limiter à un site "oralité" site:cairn.info
filetype: Type de fichier "didactique français" filetype:pdf

Navigation sécurisée (10 min)

  • Vérifier HTTPS et certificat (cadenas vert dans la barre d'adresse)
  • Ne pas saisir identifiants sur sites suspects (phishing)
  • Cookies : session Moodle ; ne pas les partager
  • Vie privée : navigation privée ≠ anonymat total

Indicateurs de confiance d'une page Web

Indicateur Ce que ça garantit Comment vérifier
Cadenas vert 🔒 Connexion chiffrée (HTTPS) Barre d'adresse
Certificat valide Identité du site vérifiée Cliquer sur le cadenas
Domaine officiel Pas de typosquatting Vérifier l'orthographe
Contact visible Transparence de l'éditeur Page « Contact » / « À propos »

Accessibilité et multilingue (10 min)

Note pédagogique ENS

Transposition didactique

Le cours sur le Web est conçu selon une approche de transposition progressive adaptée aux étudiants de lettres :

  1. Du concret à l'abstrait : le cours part d'URLs réelles (Moodle USTO, Mostaganem) que les étudiants manipulent quotidiennement, puis remonte vers les concepts (protocole, DNS, HTML).
  2. Analogies littéraires : la structure HTML est comparée à la structure d'une dissertation (titre = h1, paragraphe = p, citation = blockquote). Cette analogie facilite l'appropriation par des étudiants familiers de l'analyse textuelle.
  3. Esprit critique : les critères CRAP sont présentés comme une grille d'analyse documentaire — transfert direct des compétences d'analyse littéraire vers l'évaluation des sources numériques.
  4. Contextualisation linguistique : les exemples HTML utilisent des contenus littéraires français (Molière, Racine, La Fontaine) pour maintenir la cohérence disciplinaire.

Conseil pour le formateur

  • Démonstration essentielle : l'inspecteur F12 est l'outil le plus puissant de cette séance. Prévoir une démonstration en direct sur la page d'accueil Moodle de l'université.
  • Éviter l'excès technique : ne pas détailler le fonctionnement complet de HTTP (en-têtes, codes status). Se limiter à HTTP vs HTTPS.
  • Requêtes booléennes : préparer un exemple avec le groupe sur un thème littéraire (ex: « littérature algérienne d'expression française » AND « oralité » AND algérie). Montrer le résultat sur Google Scholar et Cairn.
  • Accessibilité : sensibiliser les futurs enseignants à l'importance de produire des contenus accessibles (textes alternatifs, contrastes).
  • Gestion du temps : le HTML peut être survolé si le groupe est en retard ; l'essentiel est la compréhension des URL et des critères d'évaluation.
