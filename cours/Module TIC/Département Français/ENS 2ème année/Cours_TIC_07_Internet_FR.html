Différences Internet et Web (10 min)

Internet Web (WWW)
Infrastructure globale de réseaux Service applicatif (pages HTTP/HTTPS)
Courriel (SMTP), FTP, VoIP aussi Navigateur + URL + HTML requis
Protocole TCP/IP HTTP sur TCP
Existe depuis 1969 (ARPANET) Existe depuis 1991 (CERN)
Transporte tous types de données Transporte uniquement du contenu Web

Moodle = service Web ; courriel = SMTP — tous deux sur Internet.

Adressage IP (notions) (10 min)

  • IPv4 : 4 octets (ex. 192.168.1.10) — 32 bits, ~4,3 milliards d'adresses
  • IPv6 : 128 bits (déploiement croissant) — adresses hexadécimales
  • IP privée : 192.168.x.x, 10.x.x.x, 172.16.x.x (LAN — non routées sur Internet)
  • IP publique : visible sur Internet, attribuée par le FAI
  • DNS : résolution nom → adresse (ex. google.com → 142.250.x.x)

DHCP : attribution automatique IP/masque/passerelle sur le LAN.

Classes d'adresses IPv4

Classe Plage Masque par défaut Usage
A 1.0.0.0 – 126.255.255.255 255.0.0.0 Grands réseaux
B 128.0.0.0 – 191.255.255.255 255.255.0.0 Réseaux moyens (universités)
C 192.0.0.0 – 223.255.255.255 255.255.255.0 Petits réseaux (LAN)
D 224.0.0.0 – 239.255.255.255 N/A Multicast
E 240.0.0.0 – 255.255.255.255 N/A Recherche

Usages académiques et sécurité (10 min)

  • Usages : Moodle, bibliothèque en ligne, visioconférence (BBB — Béjaïa)
  • Risques : phishing, malware, Wi-Fi public non sécurisé, vol d'identifiants
  • Bonnes pratiques : HTTPS, VPN institutionnel si disponible, MFA courriel

Charte universitaire : usage responsable, pas de partage illégal de contenus.

Note pédagogique ENS

Transposition didactique

Le concept d'Internet est abordé selon une démarche de transposition progressive :

  1. Représentations initiales : les étudiants utilisent Internet quotidiennement (Moodle, WhatsApp, YouTube) sans connaître son fonctionnement. Le cours part de ces usages pour remonter vers l'infrastructure.
  2. Modélisation simplifiée : le modèle TCP/IP est présenté en 4 couches seulement (vs 7 couches OSI) pour éviter la surcharge cognitive.
  3. Ancrage analogique : l'analogie postale (paquet = lettre, IP = adresse, routeur = centre de tri) facilite la compréhension des concepts abstraits.
  4. Contextualisation algérienne : les exemples (ANPT, Mobilis, Ooredoo, Moodle Univ-Mosta) ancrent les concepts dans le vécu des étudiants.

Conseil pour le formateur

  • Anticiper la confusion Internet/Web : insister sur la distinction dès l'introduction. Proposer l'image du réseau routier (Internet) vs les magasins (sites Web).
  • Utiliser des vidéos courtes : la simulation ARPANET (2 min) capte l'attention et rend l'histoire concrète.
  • Prévoir un exercice IP : demander aux étudiants de trouver leur adresse IP (ipconfig / ifconfig) sur leur poste — transposition immédiate.
  • Éviter la technique pure : adapter le niveau aux étudiants de lettres. Privilégier l'intuition et la visualisation aux formules binaires.
  • Gestion du temps : la partie historique peut être raccourcie si le groupe maîtrise déjà les notions de base.
