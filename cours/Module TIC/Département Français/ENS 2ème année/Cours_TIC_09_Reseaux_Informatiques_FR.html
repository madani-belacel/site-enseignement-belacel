Introduction aux réseaux (10 min)

Un réseau informatique relie des équipements pour échanger des données. Alignement USTO ISIL-S4 UEF422 — chapitre 01 « Introduction et topologies ».

Définition : ensemble de nœuds (hôtes) + liens + protocoles (TCP/IP, Ethernet).

Pourquoi ce cours pour un futur enseignant de français ?

Contexte Application

Moodle Savoir pourquoi le réseau peut ralentir (bande passante partagée)
Wi-Fi campus Sécuriser sa connexion et ses identifiants
Visioconférence Comprendre les contraintes réseau (latence, débit)

Topologies : bus, anneau, étoile (15 min)

  • Bus : câble partagé (obsolète,ThickNet années 80)
  • Anneau : Token Ring (IBM, historique)
  • Étoile : nœuds vers switch central — standard LAN actuel

Comparaison des topologies

Critère Bus Anneau Étoile
Câblage Économique Moyen Plus long (au switch)
Panne Tout le réseau tombe Boucle cassée Un seul nœud affecté
Ajout d'un nœud Difficile Interruption Simple (prise libre sur switch)
Débit Partagé (collisions) Partagé Dédié (full duplex)
Usage aujourd'hui Historique Historique Standard université

Topologies : maillée et arborescente (10 min)

  • Maillée : plusieurs chemins — Internet, routage dynamique (USTO ch. 6)
  • Arborescente : hiérarchie switch → switch (déploiement campus)

Spanning Tree Protocol (STP) : évite les boucles en topologie redondante.

Comparaison topologies étendues

Topologie Redondance Coût Exemple
Maillée complète Maximale Très élevé Cœur Internet (routeurs)
Maillée partielle Bonne Élevé Réseau inter-campus
Arborescente Faible Modéré Salle informatique
Hybride (étoile + maillée) Bonne Moyen Campus universitaire typique

Composants d'un réseau (10 min)

Équipement Couche OSI Rôle Exemple
Carte réseau (NIC) 1–2 Interface hôte avec le réseau Intel Ethernet, Wi-Fi
Switch 2 (Liaison) Commutation LAN, VLAN Cisco Catalyst, HP ProCurve
Routeur 3 (Réseau) Routage inter-réseaux Cisco ISR, MikroTik
Point d'accès (AP) 2 Extension Wi-Fi Ubiquiti UniFi, TP-Link
Modem 1 Modulation/démodulation signal Box ADSL/fibre
Firewall 3–4 Filtrage sécurité PfSense, FortiGate

Serveur : héberge Moodle, DNS, DHCP, messagerie.

Rôle des équipements — analogie simple

Équipement réseau Analogie
Switch Standardiste qui connecte les appels dans un bâtiment
Routeur Facteur qui achemine le courrier entre villes
Point d'accès Wi-Fi Antenne relais téléphonique (sans fil)
Firewall Agent de sécurité à l'entrée du bâtiment

Adressage IP et DHCP (10 min)

  • IP + masque + passerelle + DNS
  • DHCP : serveur attribue automatiquement (campus, box)
  • NAT : routeur traduit IP privées → IP publique

Exemple de configuration IP

Adresse IP      : 192.168.1.50
Masque          : 255.255.255.0 (/24)
Passerelle      : 192.168.1.1
DNS principal   : 8.8.8.8
DNS secondaire  : 8.8.4.4

Interprétation

Champ Valeur Signification
192.168.1.50 IP privée Attribuée par DHCP dans le LAN
255.255.255.0 Masque /24 254 adresses disponibles sur ce réseau
192.168.1.1 Passerelle Adresse du routeur/box
8.8.8.8 DNS Serveur DNS Google (résolution noms)

Conseils pour la connexion Wi-Fi campus

  1. SSID officiel : se connecter uniquement au réseau de l'université (ex: UNIV-MOSTA-WIFI)
  2. Mot de passe : utiliser le mot de passe institutionnel, ne pas le partager
  3. VPN : si disponible, utiliser le VPN pour les connexions sensibles (notes, examens)
  4. Antivirus : garder l'antivirus à jour sur son poste personnel
  5. Déconnexion : se déconnecter après chaque session sur les postes partagés

Note pédagogique ENS

Transposition didactique

Les concepts de réseaux sont transposés pour des étudiants de lettres selon plusieurs axes :

  1. Du connu vers l'inconnu : les étudiants utilisent le Wi-Fi campus quotidiennement mais n'en connaissent pas l'infrastructure. Le cours part de l'expérience utilisateur (connexion Moodle) vers la modélisation technique (topologie, équipements).
  2. Analogies spatiales : la topologie est expliquée par analogie avec l'organisation spatiale d'un campus — le switch = le bâtiment central, les câbles = les couloirs, le routeur = la porte d'entrée vers l'extérieur.
  3. Éviter la complexité inutile : le modèle OSI n'est pas détaillé (7 couches) — on se limite aux équipements et à leur rôle perçu. Les adresses IP sont présentées sans sous-réseau ni CIDR pour ce niveau.
  4. Contextualisation professionnelle : le futur enseignant doit comprendre le réseau de son établissement pour mieux utiliser les ressources numériques pédagogiques.

Conseil pour le formateur

  • Schémas : privilégier les schémas dessinés en direct (ou animés) pour montrer la différence entre topologies. Un volontaire peut venir dessiner au tableau.
  • Exercice salle info : si possible, faire le cours ou une partie en salle informatique pour montrer les équipements réels (switch, câbles RJ45, baie de brassage).
  • Configuration IP : demander aux étudiants de lancer ipconfig (Windows) ou ifconfig (Mac/Linux) sur leur poste. C'est concret et immédiat.
  • Éviter les détails de routage : ne pas aborder les protocoles de routage (OSPF, BGP). Se limiter à l'idée que le routeur trouve le chemin.
  • Vidéo démo : une animation de 2 min sur le fonctionnement d'un switch est plus efficace qu'un long exposé.
