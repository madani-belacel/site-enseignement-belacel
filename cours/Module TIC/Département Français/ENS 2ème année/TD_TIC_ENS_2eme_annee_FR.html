Exercice 1 — Définition personnelle (15 min)

Énoncé : Donnez votre propre définition des TIC en 2-3 lignes, puis comparez-la à la définition UIT.

Corrigé détaillé : Les TIC regroupent outils numériques de traitement, transmission et accès à l'information. L'UIT insiste sur la forme numérique et la convergence des technologies.

Exercice 2 — Les trois dimensions (15 min)

Énoncé : Expliquez avec des exemples personnels les trois dimensions : Techniques, Information, Communication.

Corrigé détaillé : Technique = PC + Moodle ; Information = polycopié PDF ; Communication = email au professeur ou forum TD.

Exercice 3 — Fonctions des TIC (18 min)

Énoncé : Pour chaque action, identifiez la fonction : traitement / transmission / sauvegarde. Rédaction Word, envoi email, copie USB, visioconférence Teams, impression PDF.

Corrigé détaillé : Word → traitement ; email et Teams → transmission ; USB → sauvegarde ; impression → traitement/sortie.

Exercice 4 — Applications en langues (18 min)

Énoncé : Citez 5 usages concrets des TIC pour un étudiant en langues étrangères.

Corrigé détaillé : Corpus multilingues en ligne, visio avec locuteurs natifs, Moodle pour devoirs, bibliothèque numérique, PowerPoint pour exposés.

Exercice 5 — Réflexion critique (14 min)

Énoncé : Rédigez un paragraphe (10-12 lignes) sur opportunités et risques des TIC pour les étudiants en langues.

Corrigé détaillé : Opportunités : ressources mondiales, MOOC, collaboration. Risques : plagiat, désinformation, addiction, vie privée. Posture : esprit critique et éthique académique.

Énoncé : Pourquoi un document non sauvegardé disparaît-il après une coupure de courant ?

Corrigé : Les données en cours d'édition sont en RAM (volatile). Sans enregistrement sur disque/SSD/cloud, elles sont perdues à l'arrêt.

Corrigé : SSD pour usage quotidien ; HDD ou cloud pour archives ; clé USB pour transport ponctuel.

Exercice 1 — Définition et acronymes

Énoncé : Définir Internet en une phrase et expliquer la signification de TCP/IP.

Corrigé détaillé : - Internet = réseau mondial interconnectant des réseaux locaux/régionaux/internationaux. - TCP = Transmission Control Protocol (fiabilité de transmission). - IP = Internet Protocol (adressage et routage des paquets).

Exercice 2 — Internet vs Web

Énoncé : Pour chaque élément, indiquer s'il relève d'Internet, du Web, ou des deux : navigateur Chrome, câble fibre, page HTML, protocole HTTP, routeur.

Corrigé détaillé : - Chrome : Web (client) + Internet (infrastructure). - Fibre : Internet. - Page HTML : Web. - HTTP : Web (service sur Internet). - Routeur : Internet.

Exercice 3 — Connexion à Internet

Énoncé : Décrire les étapes pour connecter un portable au Wi-Fi du campus.

Corrigé détaillé : 1. Activer le Wi-Fi (icône barre des tâches). 2. Sélectionner le réseau institutionnel. 3. S'authentifier (identifiants universitaires). 4. Vérifier l'accès (ouvrir un site ou Moodle). 5. Verrouiller la session en quittant la salle (Windows+L).

Exercice 4 — Adresse IP

Énoncé : Quelle est la différence entre IPv4 et le rôle du DHCP ? Donner un exemple d'adresse IP.

Corrigé détaillé : - IPv4 : format 4 octets décimaux (ex. 192.168.1.10), identifiant unique sur le réseau. - DHCP : attribue automatiquement IP, masque et passerelle au poste client. - Sans DHCP, configuration manuelle nécessaire.

Exercice 5 — Usages et sécurité

Énoncé : Citer trois usages académiques d'Internet et deux précautions de sécurité sur réseau public.

Corrigé détaillé : - Usages : Moodle, bibliothèque numérique, visioconférence, dépôt de devoirs. - Sécurité : éviter transactions sensibles ; utiliser HTTPS ; ne pas partager mots de passe ; VPN si disponible.

Exercice 1 — Types de réseaux

Énoncé : Associer LAN, MAN, WAN à : salle informatique, réseau ville, Internet mondial.

Corrigé détaillé : - Salle informatique → LAN (Local Area Network). - Réseau ville → MAN (Metropolitan Area Network). - Internet mondial → WAN (Wide Area Network).

Exercice 2 — Topologies

Énoncé : Dessiner une topologie en étoile avec 4 postes et un switch central. Citer un avantage.

Corrigé détaillé : - 4 PC reliés individuellement au switch (hub central). - Avantage : panne d'un câble n'affecte qu'un poste ; dépannage facilité. - Très courante en Wi-Fi (point d'accès = centre).

Exercice 3 — Composants réseau

Énoncé : Relier composant et rôle : switch, routeur, carte réseau, câble Ethernet.

Corrigé détaillé : - Switch : interconnecte machines en LAN. - Routeur : relie LAN à Internet (routage IP). - Carte réseau (NIC) : interface machine/réseau. - Câble Ethernet : support de transmission filaire.

Exercice 4 — Adressage et DHCP

Énoncé : Un poste affiche 169.254.x.x. Quel problème probable ? Quel protocole résout l'attribution d'IP ?

Corrigé détaillé : - Adresse APIPA : pas de serveur DHCP joignable (Wi-Fi non connecté ou box éteinte). - DHCP doit attribuer IP, masque, passerelle, DNS. - Solution : vérifier connexion Wi-Fi/Ethernet, redémarrer box, contacter support IT.

Exercice 5 — Cas campus

Énoncé : Proposer 3 règles de bon usage du réseau universitaire.

Corrigé détaillé : 1. Usage pédagogique et recherche (pas de téléchargements illégaux). 2. Ne pas partager identifiants Wi-Fi institutionnels. 3. Respecter charte informatique (sécurité, bande passante, imprimantes partagées).

Exercice 1 — Moteur de recherche

Énoncé : Expliquer le rôle des crawlers et l'intérêt d'un métamoteur.

Corrigé détaillé : - Crawlers : robots qui explorent le Web et indexent les pages. - Métamoteur : interroge plusieurs moteurs, fusionne et déduplique les résultats (ex. Qwant, Dogpile).

Exercice 2 — Courriel professionnel

Énoncé : Rédiger un email à un enseignant pour demander un report de TD (objet, formule, structure).

Corrigé détaillé : - Objet : [L1 Langues] Demande report TD TIC — Nom Prénom - Formule : « Madame, Monsieur, » - Corps : motif bref, date souhaitée, politesse. - Signature : nom, groupe, email institutionnel. - Pièce jointe seulement si justificatif demandé.

Exercice 3 — Protocoles email

Énoncé : Associer SMTP, POP, IMAP à : envoi, réception locale, synchronisation multi-appareils.

Corrigé détaillé : - SMTP → envoi. - POP → réception (souvent téléchargement local). - IMAP → réception avec sync boîte sur plusieurs appareils (recommandé mobile + PC).

Exercice 4 — Transfert de fichiers

Énoncé : Comparer clé USB, Google Drive et email pour remettre un devoir de 15 Mo.

Corrigé détaillé : - Clé USB : rapide en présentiel, risque perte/virus. - Drive : lien de partage, traçabilité, limite quota institutionnel. - Email : limite pièce jointe (~25 Mo selon serveur), pratique pour petits fichiers. → Pour 15 Mo : Drive ou plateforme Moodle préférable.

Exercice 5 — Synthèse module TIC

Énoncé : Résumer en un tableau 3 colonnes (Séances 01-04, 05-06, 07-10) les compétences acquises.

Corrigé détaillé : | Bloc | Compétences | |------|-------------| | 01-04 | Culture TIC, PC, Windows, Word | | 05-06 | Excel (calcul), PowerPoint (oral) | | 07-10 | Internet, Web, réseaux, services numériques | → Culture numérique complète pour la Licence Langues.
