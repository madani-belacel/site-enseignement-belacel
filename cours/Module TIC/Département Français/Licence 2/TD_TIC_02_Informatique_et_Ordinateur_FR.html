TD TIC 02 — Informatique et Architecture de l'Ordinateur

Enseignant : BELACEL Madani
Module : TIC
Niveau : Licence 2 — Département Français
Durée : 1h30
Année universitaire : 2025-2026

(Email et déroulement détaillé de la séance : voir page de garde du PDF.)

Exercice 1 — Vocabulaire de base (15 min)

Énoncé : Définissez : informatique, hardware, software, CPU, RAM, SSD.

Corrigé : Informatique = traitement automatique de l'information ; hardware = matériel ; software = logiciels ; CPU = processeur ; RAM = mémoire vive volatile ; SSD = stockage rapide non volatile.

Exercice 2 — Entrée / Traitement / Sortie (15 min)

Énoncé : Classez : clavier, écran, processeur, imprimante, micro, disque dur.

Corrigé : Entrée : clavier, micro ; Traitement : processeur ; Sortie : écran, imprimante ; Stockage : disque dur.

Exercice 3 — RAM vs stockage (18 min)

Énoncé : Pourquoi un document non sauvegardé disparaît-il après une coupure de courant ?

Corrigé : Les données en cours d'édition sont en RAM (volatile). Sans enregistrement sur disque/SSD/cloud, elles sont perdues à l'arrêt.

Exercice 4 — Choix de support (18 min)

Énoncé : Pour travail quotidien, archive longue durée, transport de fichiers — recommandez un support et justifiez.

Corrigé : SSD pour usage quotidien ; HDD ou cloud pour archives ; clé USB pour transport ponctuel.

Exercice 5 — Bonnes pratiques (14 min)

Énoncé : Listez 6 bonnes pratiques importantes pour un étudiant.

Corrigé : Sauvegardes régulières, mises à jour, antivirus, organisation des dossiers, règle 3-2-1, distinction RAM/stockage.
