1. Introduction : Excel pour l'Analyse en Didactique (10 min)

En Master 2 DLE, Excel sert à analyser les données issues de questionnaires d'enquête, tests de niveau, entretiens structurés et observations de classe. Il permet :

  • La saisie et le codage systématique des réponses
  • Le calcul de statistiques descriptives (moyenne, écart-type, fréquences)
  • La construction de tableaux croisés pour explorer les relations entre variables
  • La production de graphiques prêts pour publication

Exemple type : Analyse d'un questionnaire sur l'impact des TICE en classe de FLE (20 questions, 30 répondants, échelle Likert).

2. Structure des Données (10 min)

Règle d'or : Une ligne = un sujet ; une colonne = une variable.

ID Sexe Age Niveau_Fr Heures_TICE Motivation Score
01 F 22 B2 3 4 15
02 M 24 C1 5 5 18

Types de variables : - Nominales : Sexe, Université, Filière - Ordinales : Niveau (A1-C2), Satisfaction (1-5) - Continues : Âge, Score, Heures de travail

3. Codage des Réponses et Nettoyage (15 min)

Codage : transformer les réponses textuelles en valeurs numériques : - Homme = 1, Femme = 2 - Toujours = 5, Souvent = 4, Parfois = 3, Rarement = 2, Jamais = 1

Nettoyage : - Supprimer les lignes vides - Vérifier les valeurs aberrantes (âge = 150) - Remplacer les valeurs manquantes par N/A ou -99 - Uniformiser les formats (dates, séparateur décimal)

4. Statistiques Descriptives (20 min)

Fonction Utilité Syntaxe
=MOYENNE() Moyenne d'une série =MOYENNE(B2:B31)
=ECARTYPE.STANDARD() Dispersion =ECARTYPE.STANDARD(B2:B31)
=NB.SI() Fréquence d'une valeur =NB.SI(C2:C31;"F")
=MAX() / =MIN() Étendue =MAX(D2:D31)
=QUARTILE() Distribution =QUARTILE(D2:D31;1)

Interprétation : une moyenne de 4,2 sur une échelle de satisfaction (1-5) indique un fort taux de satisfaction ; un écart-type faible (< 0,8) montre un consensus.

5. Tableaux Croisés Dynamiques (15 min)

TCD = l'outil le plus puissant d'Excel pour l'analyse d'enquête.

  1. Sélectionner les données → Insertion → Tableau croisé dynamique
  2. Lignes : variable indépendante (Sexe, Niveau)
  3. Colonnes : variable dépendante (Satisfaction, Score)
  4. Valeurs : moyenne, somme, effectif

Exemple : Satisfaction × Sexe → permet de voir si les femmes sont plus satisfaites des TICE que les hommes.

Segment : ajouter des filtres visuels (par Niveau, par Université) pour explorer les sous-groupes.

6. Graphiques pour Publication (15 min)

Type de graphique Usage en didactique
Histogramme Fréquences des réponses
Barres groupées Comparaison (pré-test / post-test)
Boîte à moustaches Distribution des scores
Nuage de points Corrélation (heures TICE × progression)
Radar Profil de compétences

Recommandations pour publication : - Polices de caractères sobres (Arial, 10-12 pt) - Titre clair, légendes, source - Palette de couleurs accessible (ColorBrewer) - Résolution ≥ 300 dpi pour l'export

7. Export et Documentation (10 min)

Formats : - .xlsx — données brutes + analyses - .csv — données interopérables (DSpace) - .pdf — graphiques pour le mémoire

Documentation du protocole : chaque fichier Excel doit contenir une feuille "Readme" décrivant : - Source des données - Date de collecte - Variables et codage - Traitements effectués

8. Conclusion (10 min)

L'analyse de données avec Excel est une compétence clé pour le Master 2 DLE, permettant de passer des données brutes aux résultats interprétés. Elle prépare aux analyses plus avancées sous SPSS, R ou JASP pour le doctorat.

Note pédagogique Master 2

Transposition recherche : Ce cours transpose les méthodes d'analyse quantitative issues de la psychométrie et de la sociolinguistique. Le questionnaire Likert, l'analyse de fiabilité (alpha de Cronbach) et le TCD préparent les étudiants aux analyses avancées sous SPSS (module "Analyse de données" au S2). La documentation du protocole répond aux exigences FAIR de reproductibilité.

Conseil au formateur : Commencer par un jeu de données réel (ex. enquête TICE déjà collectée par un collègue) plutôt qu'un tableau fictif. Les étudiants en didactique sont souvent réticents aux chiffres : une approche par problème concret (ex. "Votre mémoire montre-t-il que les TICE améliorent l'oral ?") facilite l'engagement. Prévoir un temps de manipulation libre après le TP cadré.

Prolongement : Ce cours prépare les étudiants à l'analyse quantitative en doctorat (SPSS, JASP, R). Les étudiants peuvent être invités à suivre le cours "Statistical Methods for Language Research" sur Coursera (University of Toronto) ou le MOOC "Statistique pour la recherche en éducation" (FUN-MOOC).

Annexe — Pièges à éviter

Piège Solution
Saisir des textes libres dans une colonne quantitative Utiliser des listes déroulantes (Validation des données)
Calculer une moyenne sur des données ordinales Vérifier la nature de l'échelle
Fusionner des cellules dans un tableau de données Ne jamais fusionner dans la feuille de données brutes
Interpréter une corrélation comme une causalité Toujours mentionner "association" et non "cause"
Oublier les étiquettes des axes Légende + titre + unité obligatoires
