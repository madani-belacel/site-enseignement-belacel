1. Introduction à Windows (10 min)

Windows reste le système d'exploitation dominant dans le paysage universitaire algérien (≈ 95 % des postes). En Master 2 DLE, sa maîtrise va bien au-delà de l'usage bureautique : elle conditionne la qualité de la gestion des données de recherche, la fluidité du travail de rédaction et la pérennité des fichiers.

Pour un étudiant-chercheur, Windows est l'interface entre la pensée scientifique et sa matérialisation numérique. Savoir organiser ses fichiers, maîtriser les formats, sécuriser ses données et automatiser les tâches répétitives sont des compétences fondamentales — souvent implicites mais décisives dans le parcours de master.

2. Interface Graphique pour le Chercheur (15 min)

  • Explorateur de fichiers : panneau de navigation rapide, dossiers épinglés, bibliothèque Documents
  • Recherche Windows : syntaxe kind:docx author:belacel pour retrouver un fichier par métadonnée
  • OneDrive / iCloud / Google Drive : synchronisation entre postes de travail
  • Outils intégrés : Capture (Shift+S), Sticky Notes, Quick Assist

Organiser le bureau par dossiers thématiques : [Recherche], [M2-Memoire], [Donnees], [Biblio], [Admin].

3. Gestion Systématique des Données de Recherche (15 min)

Les principes FAIR (Findable, Accessible, Interoperable, Reusable) s'appliquent dès le Master :

Principe Application M2
Findable Nommage systématique AAAA-MM-JJ_Type_Sujet_vX.ext
Accessible Dossiers structurés + README.md dans chaque niveau
Interoperable Formats ouverts (.csv, .txt, .md, .pdf)
Reusable Documentation des protocoles et métadonnées

Convention recommandée pour le mémoire : 2025-10-01_Article_RevueDidactique_v1.docx

5. Zotero et Gestion Bibliographique (10 min)

Zotero est l'outil de référence pour le Master 2 :

  • Installation et extension navigateur (Chrome/Firefox)
  • Création de collections : par chapitre, par thématique (Didactique, TIC, Learning Analytics, Corpus)
  • Export BibTeX : intégration avec Word et Overleaf
  • Groupes Zotero : travail collaboratif entre masterants sous la direction du promoteur
  • Styles : adapter APA 7, MLA, Normes Univ-Mosta

6. Git pour Chercheurs (10 min)

Git n'est pas réservé aux informaticiens. En Master 2 DLE, il permet de :

  • Versionner le mémoire (v1, v2, ..., v_finale_soutenance)
  • Travailler à plusieurs sur un chapitre (GitHub / GitLab)
  • Revenir à une version antérieure en cas d'erreur
  • Préparer le terrain pour des publications ultérieures (articles, chapitres)

Workflow :

git init m2_memoire
git add chapitre1.docx
git commit -m "Premiere version Chapitre 1"
git push origin main

7. Stratégies de Sauvegarde (10 min)

Règle 3-2-1 : - 3 copies du fichier - 2 supports différents (HDD local + cloud) - 1 copie hors site (NAS, Cloud, clé chiffrée)

Pour le Master 2 : - Sauvegarde quotidienne automatique (OneDrive ou Google Drive) - Sauvegarde hebdomadaire sur HDD externe - Archive mensuelle sur NAS universitaire - Chiffrement : BitLocker (Windows Pro) ou VeraCrypt

8. Dual Boot et Machines Virtuelles pour la Recherche (10 min)

En didactique des langues, certains outils sont plus performants sous Linux (Python NLP, LanceBox, TXM). Configurations possibles :

  • Dual Boot : Windows + Ubuntu pour Linux natif
  • Machine Virtuelle : VirtualBox + Ubuntu (sans modifier le système hôte)
  • WSL2 : Windows Subsystem for Linux → terminal Linux dans Windows

Utile pour : traitement de corpus (Python + NLTK/spaCy), analyses statistiques (R Studio), transcription audio (Praat).

9. Conclusion (10 min)

La maîtrise de Windows en Master 2 DLE dépasse la bureautique : c'est un levier pour l'organisation de la recherche, l'intégrité des données et la production scientifique. Un chercheur bien outillé est un chercheur plus efficace.

Prochain cours : Microsoft Word — Mise en page du mémoire et normes institutionnelles.

Note pédagogique Master 2

Transposition recherche : Ce cours s'appuie sur les principes FAIR (Wilkinson et al., 2016) et les recommandations du RDA (Research Data Alliance). L'organisation FAIR des données est aujourd'hui exigée par les revues scientifiques et les financeurs (ANR, H2020). En Algérie, le déploiement de DSpace-CRIS dans les universités (CERIST, 2024) rend cette compétence indispensable.

Conseil au formateur : Privilégier l'atelier pratique à la démonstration magistrale. Les étudiants de M2 DLE ont des profils variés (linguistique, didactique) : adapter le rythme et prévoir une fiche d'aide pas-à-pas. Insister sur les conséquences d'une perte de données à ce stade du parcours.

Prolongement : Ce cours prépare le terrain pour l'UE "Méthodologie de la recherche" et le séminaire "Learning Analytics et TICE". Les étudiants peuvent être invités à suivre le MOOC "Gestion des données de la recherche" (Fun-MOOC, Inria).
