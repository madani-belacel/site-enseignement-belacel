Introduction : le Web comme terrain de recherche (10 min)

Le World Wide Web n'est pas seulement un réservoir d'informations : il constitue un terrain de recherche à part entière pour le didacticien des langues. On y trouve :

  • Des interactions langagières authentiques (forums, commentaires, chats pédagogiques)
  • Des dispositifs d'apprentissage (plateformes Moodle, MOOCs, sites de télécollaboration)
  • Des données d'enquête potentielles (questionnaires, entretiens synchrones)
  • Des ressources pédagogiques à évaluer et intégrer dans un scénario didactique

Ce cours outille le chercheur M2-DLE pour faire du Web un objet et un instrument de recherche.

HTTP (non chiffré) vs HTTPS (TLS — cadenas). Pour la recherche : privilégier les sites HTTPS pour la collecte éthique de données.

HTML et extraction de contenu (10 min)

Comprendre le HTML permet d'extraire du contenu pour l'analyse :

<!DOCTYPE html>
<html>
<head><title>Forum FLE</title></head>
<body>
  <div class="message">
    <p class="auteur">Étudiant 1</p>
    <p class="contenu">Je pense que l'activité était...</p>
    <span class="date">2025-10-15</span>
  </div>
</body>
</html>

Outils d'extraction : - Sans code : Web Scraper (extension Chrome), ParseHub, Octoparse - Avec code : Python + BeautifulSoup / Scrapy

Évaluation des ressources pédagogiques en ligne (10 min)

Grille CRAP : Currency, Reliability, Authority, Purpose

Grille MERLOT (adaptée) :

Critère Questions
Qualité du contenu Le contenu est-il exact et pertinent pour l'objectif d'apprentissage ?
Potentiel pédagogique La ressource favorise-t-elle l'interaction et l'autonomie ?
Facilité d'utilisation L'interface est-elle intuitive pour l'apprenant FLE ?
Interactivité Y a-t-il des exercices, des quiz, des feedbacks ?
Accessibilité La ressource respecte-t-elle les normes WCAG ?

Enquêtes en ligne et questionnaires (10 min)

Étapes de conception : 1. Définir la question de recherche (ex. « Quelles sont les stratégies d'apprentissage lexical des étudiants algériens en FLE ? ») 2. Choisir l'outil : LimeSurvey (recommandé, RGPD-compatible, hébergement institutionnel) ou Google Forms (simple mais limites RGPD) 3. Structure du questionnaire : consentement éclairé → données démographiques → échelle de Likert → questions ouvertes 4. Test pilote (n = 3-5) avant diffusion 5. Diffusion : lien Moodle, courriel, réseaux sociaux académiques

Web scraping pour la constitution de corpus (10 min)

Applications en didactique des langues : - Constitution d'un corpus d'interactions pédagogiques depuis des forums Moodle - Extraction de commentaires d'apprenants sur des sites d'évaluation de cours - Collecte de pages Web pour analyse de contenu (manuels numériques, ressources FLE)

Méthode simplifiée (sans code) : 1. Identifier l'URL cible (forum, site de ressources) 2. Utiliser Web Scraper Chrome → sélectionner les éléments par CSS selectors 3. Exporter en CSV/JSON 4. Nettoyage des données (OpenRefine / Excel)

Éthique : toujours vérifier les conditions d'utilisation du site (robots.txt) ; ne pas collecter de données personnelles sans consentement.

Digital ethnography / Virtual ethnography (10 min)

Hine (2000) — Virtual Ethnography : observer et analyser les pratiques sociales en ligne comme on le ferait sur un terrain physique.

Kozinets (2010) — Netnography : adaptation de l'ethnographie aux communautés en ligne (forums, réseaux sociaux, mondes virtuels).

Application M2-DLE : - Observation participante d'une communauté d'apprentissage de langues en ligne (ex. groupe Facebook « Apprendre le français ») - Analyse des interactions dans un tandem linguistique via Skype/Zoom - Étude des échanges sur un forum dédié à la formation des enseignants de FLE

Méthode : immersion → collecte de traces → entretiens avec les participants → analyse thématique.

Contexte réglementaire algérien (5 min)

  • Décret exécutif 18-179 relatif à l'ANPT et à l'aménagement des parcs technologiques — socle du développement numérique universitaire
  • Instruction n° 329 du 14 juillet 2021 : généralisation des ENT (Environnements Numériques de Travail) et des plateformes pédagogiques (Moodle) dans toutes les universités
  • Guide des bonnes pratiques du numérique éducatif (Ministère de l'Enseignement Supérieur, 2022) : critères de qualité pour les ressources pédagogiques numériques

Note pédagogique Master 2

Transposition recherche : Ce cours transpose les travaux fondateurs de Hine (2000) sur l'ethnographie virtuelle et de Kozinets (2010) sur la netnographie. Il s'appuie également sur les apports de Hubbard & Levy (2006) pour l'évaluation des ressources en CALL (Computer-Assisted Language Learning). Les étudiants sont invités à confronter ces cadres avec les spécificités du terrain algérien dans leur mémoire.

Conseil au formateur : Organiser une séance en salle informatique avec connexion Internet. Préparer un corpus test de 3-4 sites FLE aux qualités contrastées pour l'exercice d'évaluation. Pour le web scraping, utiliser Web Scraper Chrome (extension) qui ne nécessite pas de compétences en programmation. Prévoir un temps pour la discussion éthique : qu'est-ce qu'une collecte de données acceptable en ligne ?

Prolongement : Ce cours prépare directement au TIC 09 (Réseaux) pour l'analyse des réseaux sociaux d'apprentissage, et au TIC 10 (Services Internet) pour les outils bibliographiques et la publication. Les étudiants peuvent dès cette séance prototyper leur questionnaire et commencer une observation ethnographique exploratoire.

QCM d'auto-évaluation

1. Que signifie le « S » de HTTPS ? A) Secure (sécurisé par TLS/SSL) ✓ B) Simple C) Standard D) Social

2. Quel outil permet d'extraire des données d'une page Web sans code ? A) Python + BeautifulSoup B) Web Scraper (extension Chrome) ✓ C) Microsoft Word D) Adobe Acrobat

3. Le CRAP test évalue : A) La vitesse de chargement d'une page B) La qualité du code HTML C) La fiabilité d'une ressource Web (Currency, Reliability, Authority, Purpose) ✓ D) Le nombre de visiteurs d'un site

4. Quelle est la première étape d'une enquête par questionnaire en ligne ? A) Diffuser le lien sur Facebook B) Définir la question de recherche ✓ C) Analyser les résultats D) Supprimer les données incomplètes

5. Selon Hine (2000), l'ethnographie virtuelle consiste à : A) Étudier les virus informatiques B) Observer et analyser les pratiques sociales en ligne comme sur un terrain physique ✓ C) Programmer des sites Web D) Traduire des textes ethnographiques en ligne

Conclusion (5 min)

Le Web est un terrain de recherche fécond pour le didacticien des langues : il permet la collecte de données authentiques, l'observation de communautés d'apprentissage et l'évaluation de ressources pédagogiques. Le chercheur M2-DLE doit maîtriser les outils techniques et éthiques pour y mener des investigations rigoureuses.

TD 08 : choisir un site FLE, l'évaluer selon la grille CRAP/MERLOT (1 page) et proposer un scénario d'intégration pédagogique.
