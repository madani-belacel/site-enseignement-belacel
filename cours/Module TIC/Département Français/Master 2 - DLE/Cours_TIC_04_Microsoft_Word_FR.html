Objectifs de l'enseignement

En termes de savoir : - Maîtriser les styles Word pour un document long (mémoire 60-80 pages) - Comprendre la structuration section par section (pages liminaires, corps, annexes) - Identifier les normes typographiques institutionnelles (Univ-Mosta, ENS)

En termes de savoir-faire : - Paramétrer une page de garde conforme au template PG-fr - Créer une table des matières, une liste des figures et des tableaux automatiques - Intégrer Zotero pour les citations et la bibliographie - Générer un PDF/A pour le dépôt sur DSpace-CRIS - Utiliser les champs croisés (renvois) pour la numérotation des parties

En termes de savoir-être : - Adopter une rigueur typographique et bibliographique

Mode d'évaluation : Devoir Word 50 % + QCM 20 % + Projet mise en page 30 %

1. Introduction : Word pour la Recherche (10 min)

En Master 2 DLE, Microsoft Word est l'outil principal de rédaction du mémoire. Un document bien structuré : - Facilite la relecture par le promoteur - Réduit le temps de mise en forme final - Garantit la conformité aux normes de dépôt - Permet une génération fiable de PDF/A

Objectif final : produire un document de 60-80 pages avec page de garde, TDM automatique, bibliographie Zotero et export PDF/A.

2. Page de Garde et Sections (15 min)

La page de garde suit le template institutionnel PG-fr.docx :

  • Bloc 1 : Ministère, université, faculté, département
  • Bloc 2 : Intitulé du mémoire, spécialité
  • Bloc 3 : Présenté par / Sous la direction de
  • Bloc 4 : Année universitaire, jury

Sections Word : Chaque bloc est un saut de section (page suivante) pour gérer indépendamment en-têtes, pieds de page et numérotation.

3. Styles Avancés pour Document Long (20 min)

Style Usage Police Taille
Titre 1 Chapitres Times New Roman 16 pt gras
Titre 2 Sections Times New Roman 14 pt gras
Titre 3 Sous-sections Times New Roman 12 pt gras italique
Normal Corps Times New Roman 12 pt
Citation Citations longues Times New Roman 11 pt italique

Astuce M2 : personnaliser les styles dans le volet "Styles" → "Modifier" → enregistrer dans le template PG-fr pour réutilisation.

4. Table des Matières, Listes des Figures et Tableaux (15 min)

Table des matières automatique : - Appliquer les styles Titre 1-3 - Références → Table des matières → choisir un format - Mettre à jour : clic droit → Mettre à jour les champs

Liste des figures : - Insérer des légendes sous chaque figure (Références → Insérer une légende) - Insertion → Table des matières → Insérer une table des figures

Liste des tableaux : même procédé avec le type "Tableau".

5. Renvois, Notes de Bas de Page et Champs Croisés (10 min)

Renvoi croisé : nécessaire pour les mentions "(cf. Chapitre 3, section 2.1)" qui se mettent à jour automatiquement.

  • Insertion → Renvoi → Type : Titre → "Voir page xxx"
  • Note de bas de page : Références → Insérer une note de bas de page
  • Champs : { TOC \o "1-3" } pour TDM avancée

6. Zotero et Bibliographie (15 min)

Workflow Zotero + Word :

  1. Installer Zotero + plug-in Word (Zotero Connector)
  2. Créer une collection "M2_Memoire" dans Zotero
  3. Ajouter les références via le connecteur navigateur
  4. Dans Word : positionner le curseur → Zotero → Add/Edit Citation
  5. Choisir le style APA 7 (ou norme Univ-Mosta personnalisée)
  6. En fin de document : Zotero → Add/Edit Bibliography
  7. Générer la bibliographie automatique

Alternatives : Mendeley (Elsevier), EndNote (payant), BibTeX (overleaf)

7. Export PDF/A pour DSpace (10 min)

Le PDF/A (ISO 19005) est le format d'archivage longue durée. Il intègre toutes les polices et interdit les éléments dynamiques.

Pour générer un PDF/A dans Word : 1. Fichier → Enregistrer sous → PDF 2. Cliquer sur "Options..." → cocher "PDF/A conforme" 3. Vérifier avec Adobe Acrobat ou VeraPDF

Dépôt sur DSpace-CRIS : le fichier PDF/A est obligatoire avec le formulaire de métadonnées (titre, résumé, mots-clés, promoteur, jury).

8. Accessibilité et Normes Typographiques (10 min)

Accessibilité : - Styles hiérarchiques (lecteur d'écran) - Texte alternatif sur les images - Contraste suffisant (ratio > 4.5:1) - Polices sérif pour l'impression, sans sérif pour le numérique

Normes typographiques Univ-Mosta : - Marges : 2,5 cm (haut/bas), 3 cm (gauche), 2 cm (droite) - Interligne : 1,5 - Police : Times New Roman 12 - Alignement : justifié - Pagination : chiffres romains (pages liminaires) — arabes (corps)

9. Conclusion (10 min)

La maîtrise avancée de Word est un marqueur de professionnalisation pour le masterant. Savoir structurer, référencer et exporter son mémoire dans les formats institutionnels est une compétence transversale valorisable en doctorat, dans l'enseignement et en recherche.

Note pédagogique Master 2

Transposition recherche : La structuration du mémoire en Word s'appuie sur les normes internationales de rédaction académique (ISO 2145, APA 7). Le PDF/A est la norme d'archivage ISO 19005, adoptée par les bibliothèques numériques (DSpace-CRIS, HAL, OpenTheses). Ces compétences sont transférables à la rédaction d'articles scientifiques et de rapports de recherche.

Conseil au formateur : Ne pas sous-estimer les difficultés techniques des étudiants avec Zotero et les sections. Prévoir un tutoriel vidéo pas-à-pas et une séance de rattrapage en petit groupe. Montrer un exemple de mémoire mal formaté vs bien formaté pour motiver l'apprentissage.

Prolongement : Ce cours prépare les étudiants à l'UE "Méthodologie de la recherche" et à la rédaction du pro et de l'article scientifique. Les étudiants intéressés peuvent explorer Overleaf/LaTeX pour une alternative professionnelle à Word.
