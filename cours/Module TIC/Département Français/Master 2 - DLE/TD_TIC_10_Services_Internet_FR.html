Exercice 1 — Stratégie de recherche documentaire (15 min)

Énoncé : Élaborer une équation de recherche sur « l'impact des TIC sur la motivation en FLE » avec : mots-clés, opérateurs booléens, filtres (date, langue, type de document). Tester sur Google Scholar et le portail SNDL.

Corrigé détaillé : ("TIC" OR "numérique") AND ("motivation" OR "engagement") AND ("FLE" OR "français langue étrangère"). Filtres : 2020-2026, français/anglais, articles/revues. Comparer les résultats SNDL vs Google Scholar.

Exercice 2 — Veille informationnelle et alertes (18 min)

Énoncé : Configurer une alerte Google Scholar sur le thème de recherche. paramétrer un lecteur RSS (Feedly/Inoreader) avec 3 sources académiques. Expliquer l'intérêt pour un chercheur.

Corrigé détaillé : Google Scholar → Alertes → entrer l'équation de recherche + email. RSS : ajouter les flux des revues (ALSIC, Revue TIC et Société, ASP). Avantage : réception passive des nouvelles publications, gain de temps.

Exercice 3 — Évaluation des sources (15 min)

Énoncé : Analyser 3 sources sur un même sujet selon la grille CRAP (Currency, Reliability, Authority, Purpose) ou la méthode RADAR. Classer par fiabilité.

Corrigé détaillé : Source 1 (article revue ACL) → fiable ; Source 2 (blog personnel) → à vérifier ; Source 3 (site gouvernemental .gov.dz) → fiable. Critères : date des références, affiliation de l'auteur, revue avec comité de lecture, citations reçues.

Exercice 4 — Dépôt et diffusion académique (18 min)

Énoncé : Simuler le dépôt d'un article sur une archive ouverte (HAL, ResearchGate, Academia). Comparer les avantages/limites de chaque plateforme pour la visibilité d'un chercheur algérien.

Corrigé détaillé : HAL : légitimité académique, pas d'évaluation directe. ResearchGate : réseau social, métriques, dépôt rapide, mais modèle commercial. Academia : similarité avec RG. Recommandation : priorité à HAL + complément ResearchGate pour le réseau.

Exercice 5 — Rédaction collaborative et relecture (14 min)

Énoncé : Comparer Word Online, Google Docs, Overleaf pour la rédaction collaborative d'un article. Lister 3 avantages et 3 inconvénients de chaque outil.

Corrigé détaillé : Word Online : interface familière, suivi modif, mais formatage limité. Google Docs : commentaires temps réel, historique, mais export parfois défectueux. Overleaf : idéal LaTeX, versionnement, mais courbe d'apprentissage.

Exercice 6 — API et extraction de données (10 min)

Énoncé : Expliquer ce qu'est une API REST. Donner un exemple d'utilisation pédagogique ou scientifique d'une API (OpenAI, Google Translate, Wikipedia).

Corrigé détaillé : API = interface de programmation qui permet à deux applications de communiquer. Exemple : utiliser l'API Google Translate pour analyser automatiquement des traductions d'étudiants ; ou l'API Wikipedia pour extraire des données linguistiques.
