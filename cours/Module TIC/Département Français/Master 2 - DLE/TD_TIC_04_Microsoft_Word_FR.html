Exercice 1 — Mise en page normes de thèse (15 min)

Énoncé : Appliquer les normes de mise en page pour un mémoire de master (police, interligne, marges, recto-verso, foliotage).

Corrigé : Times New Roman 12, interligne 1,5, marges 2,5 cm (3 cm reliure), numérotation bas centre. Pages liminaires en chiffres romains, corps en chiffres arabes.

Exercice 2 — Styles et hiérarchie documentaire (15 min)

Énoncé : Structurer un document de recherche (introduction, état de l'art, méthodologie, résultats, discussion) avec styles Titre 1, Titre 2, Titre 3. Générer une table des matières automatique à 3 niveaux.

Corrigé : Titre 1 = parties principales, Titre 2 = sous-parties, Titre 3 = sous-sections. Table des matières : Références → Table des matières → automatique. Vérifier la hiérarchie avant génération.

Exercice 3 — Citations et bibliographie (18 min)

Énoncé : Saisir 5 références (livre, article, chapitre, thèse, site web) dans le gestionnaire de sources Word, insérer 3 citations dans le texte et générer la bibliographie en style APA 7.

Corrigé : Références → Gérer les sources → Nouveau. Type de source selon le document. Citation : insérer une citation. Bibliographie : Références → Bibliographie. Vérifier la conformité APA 7 (auteur, date, titre, source, DOI).

Exercice 4 — Tableaux, figures et références croisées (15 min)

Énoncé : Créer un tableau comparatif et une figure avec légendes numérotées automatiquement. Insérer des références croisées (voir Tableau 1, voir Figure 2).

Corrigé : Insérer une légende : Références → Insérer une légende. Référence croisée : Insérer → Lien → Référence croisée. Les numéros se mettent à jour automatiquement.

Exercice 5 — Sectionnement et pages liminaires (14 min)

Énoncé : Créer un document avec : page de garde sans numéro, résumé en romains, corps en arabes. Utiliser les sauts de section.

Corrigé : Mise en page → Sauts de section → Page suivante. Dissocier les en-têtes/pieds de page. Numérotation différente par section.

Exercice 6 — Formulaire de collecte de données (13 min)

Énoncé : Créer un formulaire Word avec champs à remplir, zones de texte déroulantes et cases à cocher pour un questionnaire de recherche. Protéger le document en remplissage.

Corrigé : Développeur → Mode création → Contrôle de contenu. Insérer zone de texte enrichi, liste déroulante, case à cocher. Protéger : Restreindre édition → Remplissage de formulaires.
