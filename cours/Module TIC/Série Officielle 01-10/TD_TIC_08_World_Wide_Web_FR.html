Exercice 1 — Analyse d'une URL

Énoncé : Décomposer l'URL https://www.univ-exemple.dz/cours/tic/chap2.html (protocole, domaine, chemin).

Corrigé détaillé : - https:// — protocole sécurisé HTTP. - www.univ-exemple.dz — nom de domaine (serveur). - /cours/tic/chap2.html — chemin vers la ressource (page HTML).

Exercice 2 — Navigateurs

Énoncé : Comparer deux navigateurs (Chrome et Firefox) : un avantage et un usage pédagogique pour chacun.

Corrigé détaillé : - Chrome : extensions nombreuses ; synchronisation compte Google. - Firefox : vie privée renforcée ; développement open source. - Usage : recherche documentaire, accès Moodle, lecture PDF en ligne.

Exercice 3 — HTTP vs HTTPS

Énoncé : Pourquoi privilégier HTTPS pour se connecter à la plateforme universitaire ?

Corrigé détaillé : - Chiffrement des données échangées (identifiants, notes). - Authentification du serveur (certificat SSL/TLS). - Protection contre l'écoute sur réseau public (Wi-Fi).

Exercice 4 — Recherche académique

Énoncé : Formuler une requête avancée pour trouver des articles sur « TIC et enseignement des langues » (guillemets, opérateurs).

Corrigé détaillé : - "TIC" AND "enseignement des langues" (Google académique ou moteur institutionnel). - Filtrer par date (5 dernières années). - Privilégier domaines .edu, bases bibliographiques universitaires. - Noter auteur, titre, URL, date de consultation pour citation.

Exercice 5 — Évaluation de source Web

Énoncé : Évaluer la fiabilité d'un blog anonyme vs une page .edu : 4 critères.

Corrigé détaillé : 1. Auteur identifié et qualifié ? 2. Date de publication récente ? 3. Objectivité et références bibliographiques ? 4. Domaine institutionnel ou commercial ? → Le blog anonyme est à écarter pour un devoir universitaire sans recoupement.
