TD Recherche Documentaire — M2 DLE — Séance 07 (FR)

Enseignant : BELACEL Madani
Module : Recherche Documentaire
Niveau : Master 2 — DLE — Département Français
Durée : 1h30

Objectif du TD

Configurer Zotero pour le mémoire.

Exercice 1 — Installation (12 min)

Énoncé : Installer Zotero + connecteur ; créer compte sync.

Corrigé détaillé :

Extension Chrome/Firefox active ; dossier racine Memoire_M2_DLE.

Exercice 2 — Import 5 refs (20 min)

Énoncé : Importer 5 références (DOI ou magic wand Scholar).

Corrigé détaillé :

Vérifier auteur, titre, revue, pages, DOI ; corriger champs manquants.

Exercice 3 — Dossiers (15 min)

Énoncé : Organiser refs en 3 dossiers (théorie, méthode, terrain).

Corrigé détaillé :

Structure alignée plan revue de littérature.

Exercice 4 — Note de lecture (18 min)

Énoncé : 1 note structurée : idée, méthode, limites, lien problématique.

Corrigé détaillé :

Modèle fiche : citation clé + commentaire critique.

Exercice 5 — Export APA (20 min)

Énoncé : Bibliographie APA 7 + export .bib.

Corrigé détaillé :

Ordre alphabétique ; hanging indent ; fichier .bib testé.

Déroulement séance — 1h30 (90 min)

Phase Durée Total cumulé
Accueil 5 min 5 min
Ex.1 Install 12 min 17 min
Ex.2 Import 20 min 37 min
Ex.3 Dossiers 15 min 52 min
Ex.4 Note 18 min 70 min
Ex.5 Export 20 min 90 min
Total 90 min
## Conclusion du TD

Consolidez votre protocole documentaire : requêtes rigoureuses, sources évaluées, bibliographie structurée.
