TD Recherche Documentaire — M2 DLE — Séance 08 (FR)

Enseignant : BELACEL Madani
Module : Recherche Documentaire
Niveau : Master 2 — DLE — Département Français
Durée : 1h30

Objectif du TD

Maîtriser APA 7 in-text et bibliographie.

Exercice 1 — Citation directe (18 min)

Énoncé : Citation directe 2 lignes + référence APA 7 complète.

Corrigé détaillé :

Guillemets ; (Auteur, année, p. X) ; entrée bibliographie conforme.

Exercice 2 — Paraphrase (18 min)

Énoncé : Paraphraser un passage de 4 lignes avec citation.

Corrigé détaillé :

Reformulation originale ; pas de copier-coller partiel.

Exercice 3 — ISO 690 (15 min)

Énoncé : Convertir 2 références APA en ISO 690.

Corrigé détaillé :

Format notice ; ponctuation ISO ; URL DOI.

Exercice 4 — Primaire/secondaire (18 min)

Énoncé : Cas : vous citez A qui cite B — comment faire ?

Corrigé détaillé :

Citer B (original) si accessible ; sinon « B cité in A » avec prudence.

Exercice 5 — Corriger erreurs (16 min)

Énoncé : Corriger 5 erreurs dans bibliographie fournie.

Corrigé détaillé :

Majuscules titre ; DOI ; pages ; cohérence in-text/biblio.

Déroulement séance — 1h30 (90 min)

## Conclusion du TD

Consolidez votre protocole documentaire : requêtes rigoureuses, sources évaluées, bibliographie structurée.
