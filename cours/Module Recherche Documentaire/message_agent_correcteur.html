Pipeline de génération

Sources LaTeX (Cours_Latex/*.tex)
    → python build_official.py --course all --lang both
    → .md / .pdf / .pptx générés dans Département Français/ et Département Anglais/

Les fichiers .md sont AUTO-GÉNÉRÉS. Ne jamais les modifier directement.
Toujours modifier les sources LaTeX (.tex) puis regénérer.

P1 — C1 : Pages PDF insuffisantes (TD)

Constat :

Dossier Cours TD
FR ✅ 6 pages chacun ❌ 3 pages chacun (81 lignes MD)
EN ✅ 6 pages chacun ❌ 3-4 pages chacun (124 lignes MD)

Objectif : Chaque TD doit faire 5+ pages avec contenu plein, aéré et lisible.

Actions : 1. Enrichir les sources LaTeX des TD (fichiers dans Cours_Latex/) — ajouter : - Protocole documentaire détaillé (pas à pas pour chaque exercice) - Journal de requêtes exemplifié (plusieurs exemples avec base, syntaxe, hits, décision) - Études de cas concrètes liées au mémoire M2 DLE - Grilles d'auto-évaluation - Schémas / captures d'écran supplémentaires 2. Cibler un volume suffisant pour produire 5+ pages PDF par TD 3. Regénérer avec python build_official.py --course all --lang both

Remarque : Les TD EN sont déjà plus complets que les TD FR (appendice journal de requêtes). Enrichir les sources LaTeX FR d'abord, puis les deux langues seront régénérées.

Actions : 1. Ajouter dans Programme.md les références aux textes officiels algériens 2. Ajouter dans au moins 2-3 Cours (sources LaTeX) les citations des arrêtés ministériels 3. Les références européennes (CECRL, Conseil de l'Europe) sont pertinentes et doivent être conservées — ne pas les supprimer, ajouter le cadre algérien en complément

P3 — C3 : Dépendance template externe

Constat : Les templates sont référencés depuis latex/official_paths.py vers /home/madani/Bureau/Habilitation_Universitaire/Templatte/, pas dans le module.

Actions : - Soit copier les templates dans un dossier local (Module Recherche Documentaire/Templatte/) - Soit modifier official_paths.py pour utiliser des chemins absolus documentés

Ce que tu NE dois PAS faire

  • ❌ Ne pas modifier les fichiers .md directement (ils sont générés)
  • ❌ Ne pas supprimer les références européennes (CECRL, etc.) — ajouter le cadre algérien en complément
  • ❌ Ne pas modifier les fichiers suivi/ (ce sont les rapports d'audit)
  • ❌ Ne pas modifier les archives ZIP (vérification externe)

Ordre recommandé

  1. Comprendre la pipeline : lire latex/README.md, latex/build_official.py
  2. Localiser les sources des TD : vérifier si elles sont dans les scripts Python ou les fichiers LaTeX
  3. Enrichir les sources LaTeX des TD (FR et EN) — cible 5+ pages par TD
  4. Ajouter les références algériennes dans Programme.md et les Cours (sources LaTeX)
  5. Copier les templates localement (C3)
  6. Regénérer tout : python build_official.py --course all --lang both depuis latex/
  7. Corriger les permissions
