Sommaire rapide

1. There is + singular2. There are + plural3. Negative: There isn't / There aren't4. Questions: Is there...? Are there...?5. Short answers: Yes, there is / No, there isn't6. There is vs It is7. There are + some8. There is + some + uncountable9. Describing rooms and places10. Practice: your town and home
Objectif du niveau : maîtriser les bases de ce thème pour les utiliser naturellement dans des phrases simples, claires et correctes.

1There is + singular — There is + مفرد

📘 نستعمل There is (يوجد/هناك) مع الاسم المفرد: There is a book on the table (يوجد كتاب على الطاولة).
الاختصار: There's.
📗 Explication claire : Use 'There is' with a singular noun: There is a book on the table. Short form: There's.
There is + a/an + singular noun + place
Englishالعربيةالنُّطق «...»
There is a cat in the garden.يوجد قطة في الحديقة.«ذير إيز آ كات إين ذا غاردن»
There's a phone in my bag.يوجد هاتف في حقيبتي.«ذيرز آ فون إين ماي باغ»
Is there a bank near here?هل يوجد بنك قريب من هنا؟«إيز ذير آ بانك نير هير»

2There are + plural — There are + جمع

📘 نستعمل There are مع الاسم الجمع: There are two windows in the room (يوجد نافذتان في الغرفة).
لا نقول There is مع الجمع.
📗 Explication claire : Use 'There are' with plural nouns: There are two windows.
There are + plural noun + place
Englishالعربيةالنُّطق «...»
There are four chairs here.توجد أربعة كراسي هنا.«ذير آر فور تشيرز هير»
There are many students.يوجد طلاب كثيرون.«ذير آر ماني ستيودنتس»
There are apples in the basket.يوجد تفاح في السلة.«ذير آر أبلز إين ذا باسكيت»

3Negative: There isn't / There aren't — النفي: ليس هناك

📘 النفي: There isn't (مع مفرد) و There aren't (مع جمع): There isn't any sugar (لا يوجد سكر),
There aren't any pencils (لا توجد أقلام).
📗 Explication claire : Negatives: There isn't (singular), There aren't (plural).
There isn't + a/an/any + singular | There aren't + any + plural
Englishالعربيةالنُّطق «...»
There isn't a TV in my room.لا يوجد تلفاز في غرفتي.«ذير إيزنت آ تي في إين ماي روم»
There aren't any chairs.لا توجد كراسي.«ذير آرنت إني تشيرز»
There's no milk in the fridge.لا يوجد حليب في الثلاجة.«ذيرز نو ميلك إين ذا فريدج»

4Questions: Is there...? Are there...? — السؤال: هل يوجد...؟

📘 نقلب الفعل للسؤال: Is there a bank?
(هل يوجد بنك؟),
Are there any shops?
(هل توجد محلات؟).
نستعمل any في السؤال مع الجمع و بعض المفرادات.
📗 Explication claire : Questions: Is there...? (singular), Are there...? (plural). Use 'any' in questions.
Is there + a/an + noun? | Are there + any + plural noun?
Englishالعربيةالنُّطق «...»
Is there a mosque near here?هل يوجد مسجد قريب؟«إيز ذير آ موسك نير هير»
Are there any parks in town?هل توجد حدائق في المدينة؟«آر ذير إني باركس إين تاون»
Is there a problem?هل توجد مشكلة؟«إيز ذير آ بروبلم»

5Short answers: Yes, there is / No, there isn't — الأجوبة القصيرة

📘 نجيب باختصار: Yes,
there is.
أو No,
there isn't.
للجمع: Yes,
there are.
أو No,
there aren't.
لا نكرر الاسم في الجواب المختصر.
📗 Explication claire : Short answers: Yes, there is. No, there isn't. (plural: there are / there aren't).
Yes, there is/are. | No, there isn't/aren't.
Englishالعربيةالنُّطق «...»
Is there a library? Yes, there is.هل توجد مكتبة؟ نعم.«إيز ذير آ لايبراري ييس ذير إيز»
Are there any buses? No, there aren't.هل توجد حافلات؟ لا.«آر ذير إني باسز نو ذير آرنت»
Is there any water? Yes, there is.هل يوجد ماء؟ نعم.«إيز ذير إني ووتر ييس ذير إيز»

6There is vs It is — الفرق بين There is و It is

📘 There is يُقدم شيئاً جديداً لأول مرة (يوجد...),
أما It is فيحدد شيئاً معروفاً (إنه...).
مثال: There is a dog in the street.
It is brown.
📗 Explication claire : 'There is' introduces something new. 'It is' describes known things.
There is + new noun → then → It is + description
Englishالعربيةالنُّطق «...»
There is a bird on the tree. It is singing.يوجد طائر على الشجرة. إنه يغرد.«ذير إيز آ بيرد أون ذا تري إت إيز سينغينغ»
There is a school near here. It is new.يوجد مركز قريب. إنه جديد.«ذير إيز آ سكول نير هير إت إيز نيو»
Is there a doctor? It is Dr. Madani.هل يوجد طبيب؟ إنه الدكتور مداني.«إيز ذير آ داكتور إت إيز در مداني»

7There are + some — There are + some (بعض)

📘 مع الجمع نستعمل some في الجملة المثبتة: There are some books (يوجد بعض الكتب).
أما في النفي والسؤال فنستعمل any.
📗 Explication claire : Use 'some' in positive plurals: There are some books. Use 'any' in negatives and questions.
positive: There are some + plural | question/negative: any
Englishالعربيةالنُّطق «...»
There are some chairs.توجد بعض الكراسي.«ذير آر سام تشيرز»
Are there any problems?هل توجد مشاكل؟«آر ذير إني بروبلمز»
There aren't any eggs.لا توجد بيضات.«ذير آرنت إني إغز»

8There is + some + uncountable — There is + some + غير معدود

📘 مع الأسماء غير المعدودة (ماء, حليب, سكر, خبز) نستعمل There is وليس There are: There is some water (يوجد بعض الماء).
📗 Explication claire : With uncountable nouns (water, milk) use 'There is': There is some water.
There is + some + uncountable noun
Englishالعربيةالنُّطق «...»
There is some bread.يوجد بعض الخبز.«ذير إيز سام بريد»
There is some juice in the fridge.يوجد بعض العصير في الثلاجة.«ذير إيز سام جوس إين ذا فريدج»
Is there any rice? Yes, there is.هل يوجد أرز؟ نعم.«إيز ذير إني رايس ييس ذير إيز»

9Describing rooms and places — وصف الغرف والأماكن

📘 لوصف مكان نستعمل There is/are مع حروف الجر المكانية: in,
on,
under,
next to,
between.
مثال: There is a bed next to the window (توجد سرير بجانب النافذة).
📗 Explication claire : Describe places with There is/are + place prepositions (in, on, under, next to).
There is/are + noun + preposition + place
Englishالعربيةالنُّطق «...»
There is a lamp on the desk.يوجد مصباح على المكتب.«ذير إيز آ لامب أون ذا ديسك»
There is a table in the kitchen.توجد طاولة في المطبخ.«ذير إيز آ تيبل إين ذا كيتشين»
There are pictures on the wall.توجد صور على الجدار.«ذير آر بيكتشيرز أون ذا وول»
