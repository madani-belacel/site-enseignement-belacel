1. Présentation du module

Le module Réseaux Informatiques couvre l'ensemble des concepts fondamentaux et avancés des réseaux : des topologies de base (ISIL-S4) jusqu'aux architectures Cloud et SDN (Master RSID). Il est structuré par niveau de Licence, Ingénieur et Master.

2. Niveaux couverts

Code Filière Semestres Contenu
ISIL-S4 Licence ISIL S4 Fondamentaux : OSI, TCP/IP, Ethernet, IP, Transport
SI-S5 Licence SI S5 Réseaux avancés : subnetting, VLAN, IPv6
ING-S5→S9 Ingénieur Réseaux S5→S9 Routage dynamique, BGP, MPLS, QoS, virtualisation, IoT
RSID-M1 Master RSID S1→S2 Cloud, SD-WAN, Kubernetes, Zero Trust, SDN, automatisation

3. Programme détaillé

ISIL-S4 (8 chapitres)

Chap. Titre Thèmes
1 Introduction et topologies Topologies bus, étoile, anneau, maillage ; normes et organismes

4 Couche Liaison Ethernet Trames, MAC, commutateur, LLC

6 Couche Transport TCP/UDP Segments, ports, contrôle de flux, fiabilité
7 Couche Application DNS, HTTP, FTP, SMTP, DHCP
8 Équipements réseaux Hub, switch, routeur, pare-feu, CSU/DSU

SI-S5 (9 chapitres)

Chap. Titre Thèmes

5. Pipeline de génération

Ce module utilise un pipeline LaTeX → Python : - Sources : Cours_Latex/ (fichiers .tex structurés par niveau) - Script de build : latex/build_official_reseaux.py - Génération complémentaire : Réseaux-Univ-Mosta-MathInfo/ (scripts Python + sources Markdown) - Sortie : Série_Officielle/ (PDF + PPTX) - Pipeline global : python build_official_reseaux.py --niveau all --type all

Contexte réglementaire algérien

Ce module Réseaux s'inscrit dans le cadre réglementaire algérien de la formation en Mathématiques et Informatique :

  • Arrêté ministériel fixant les programmes du cycle Licence (ISIL, SI) — Filière Mathématiques et Informatique — définit les objectifs, contenus et volumes horaires des enseignements.
  • Arrêté ministériel fixant les programmes du cycle Ingénieur (Réseaux et Systèmes) — cadre institutionnel des formations d'ingénieur.
  • Arrêté ministériel fixant les programmes du cycle Master (RSID — Réseaux et Systèmes d'Information Distribués) — cadre institutionnel de la formation Master.
  • Programme national de la filière Mathématiques et Informatique (Univ-Mosta-MB / Université de Mostaganem) — référentiel officiel pour les enseignements de réseaux.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement des réseaux informatiques.
  • Références pédagogiques : Pujolle (Réseaux), Goupille (Routage IP), Servin (Réseaux et télécoms) — ouvrages de référence utilisés dans le cadre national.

Note sur les dépendances externes
