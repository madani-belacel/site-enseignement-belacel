Chapitre 03 — SDN — Software Defined Networking

Attribut Valeur
Niveau Ingénieur RI
Semestre S7
Durée estimée 3 h CM
Chapitre 03

Objectifs pédagogiques

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Séparer data, control, application planes.
  2. Expliquer OpenFlow tables (match/action).
  3. Présenter contrôleurs (ONOS, ODL, Ryu) et API northbound.
  4. Analyser bénéfices : centralisation, programmabilité.
  5. Discuter limites : scalabilité, migration brownfield.

Plan du chapitre

  1. Planes SDN
  2. OpenFlow
  3. Contrôleurs
  4. API
  5. Limites

1. Planes SDN

Plane Fonction Exemple

2. OpenFlow

action: output port, mod_dl_dst, drop

3. Southbound

OpenFlow, NETCONF, gRPC — southbound APIs vers devices.
