Partie 2 — Étapes pratiques

Étape 1 — Adressage (30 min)

Câbler, IP, connectivité locale.

Étape 2 — ACL serveur (60 min)

Permettre admin HTTPS vers serveur ; deny étudiants ; logique documentée.

Étape 3 — PAT (45 min)

NAT overload VLAN étudiants vers Gi0/3.

Étape 4 — Tests (45 min)

Ping/traceroute ; telnet 443 depuis PC-A OK, PC-B bloqué.

Partie 3 — Vérifications

Test Commande Résultat attendu

Étudiant bloqué idem PC-B timeout

Route show ip route connected + static default

Partie 4 — Questions de bilan

  1. Où placer ACL inbound vs outbound ?
  2. Ordre règles si permit any any avant deny ?
  3. Différence NAT inside/outside ?
  4. Impact deny implicite ?
