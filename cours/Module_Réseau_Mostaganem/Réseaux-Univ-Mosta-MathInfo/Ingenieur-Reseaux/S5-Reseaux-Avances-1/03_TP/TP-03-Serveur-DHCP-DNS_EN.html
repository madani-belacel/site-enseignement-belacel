TP 03 — Serveur DHCP/DNS

Attribute Value
Level Engineer RI
Semester S5
Estimated duration 3 h
Outil GNS3
Chapters associés Ch. 05

Objectives

  • Configurer DHCP pools IOS ou Linux
  • Déployer relais sur router distant
  • Valider résolution DNS interne

Matériel et logiciels

Élément Version / Remarque
GNS3 Dernière version stable
PC étudiant Windows 10+ / Linux
Documentation Chapters associés + RFC pertinentes

Partie 1 — Context et topologie

Context

Département Mathématiques et Informatique, University of Mostaganem — cas pratique aligné sur le programme officiel.

Topology cible

R1 (relay) VLAN10 — R2 (DHCP+DNS Linux ou IOS) ; PC client VLAN10 ; serveur statique .5

Équipement Interface Adresse IP Masque / Remarque
R1 Vlan10 10.10.10.1 /24
R2 eth0 10.20.1.1 /24 serveur
PC DHCP VLAN10
SRV statique 10.10.10.5 réservé

Partie 2 — Étapes pratiques

Étape 1 — Exclusions et pool (45 min)

Pool 10.10.10.100–200, GW/DNS via options.

Étape 2 — Relay (30 min)

ip helper-address 10.20.1.1 sur R1.

Étape 3 — DNS (60 min)

Zone interne, enregistrement A pour serveur lab.

Étape 4 — Capture (45 min)

Wireshark : voir DORA sur interface relay.

Partie 3 — Vérifications

Test Commande Résultat attendu
DHCP ipconfig /all sur PC IP dans pool
Ping GW ping 10.10.10.1 OK
DNS nslookup lab.local réponse 10.10.10.5
Exclusion .5 statique pas dans bail client

Annexe — Corrigé / Configurations de référence

Pool + excluded-address 10.10.10.5 ; BIND ou dnsmasq zone lab.local.
