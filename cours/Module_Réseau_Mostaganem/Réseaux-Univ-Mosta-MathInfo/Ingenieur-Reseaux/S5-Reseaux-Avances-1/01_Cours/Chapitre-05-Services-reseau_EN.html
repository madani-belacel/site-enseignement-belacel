Learning Objectives

After completing this chapter, the student will be able to:

  1. Expliquer le cycle DORA du DHCP et les options courantes (3, 6, 51, 66).
  2. Configurer serveur DHCP Cisco IOS et relais DHCP (ip helper-address).
  3. Décrire résolution DNS récursive vs itérative, enregistrements A/AAAA/CNAME/MX.
  4. Déployer DNS interne split-horizon pour intranet University of Mostaganem.
  5. Superviser NTP/SNMP pour synchronisation et inventaire (aperçu).

1. DHCP

DORA : Discover → Offer → Request → Acknowledge.

Option Nom Example
1 Subnet mask 255.255.255.0
3 Default router 10.10.10.1
6 DNS servers 10.20.1.53, 10.20.1.54
51 Lease time 86400 s
66 TFTP server VoIP (aperçu) 
R-DHCP(config)# ip dhcp pool VLAN10
R-DHCP(dhcp-config)# network 10.10.10.0 255.255.255.0
R-DHCP(dhcp-config)# default-router 10.10.10.1
R-DHCP(dhcp-config)# dns-server 10.20.1.53
R-DHCP(dhcp-config)# lease 0 12 0

2. Relais DHCP

Sans serveur sur chaque subnet, le DHCP relay forward les broadcasts :

interface Vlan20
 ip address 10.10.20.1 255.255.255.255.0
 ip helper-address 10.20.1.100
Problème Solution
Single point of failure 2 serveurs, scopes split 80/20
Exhaustion pool réduire lease, monitoring
Rogue DHCP DHCP snooping (switch)

3. DNS

Hiérarchie : root → TLD → domaine autoritaire.

Type Role
A / AAAA Nom → IPv4 / IPv6
CNAME Alias
MX Messagerie
PTR Reverse (in-addr.arpa)

Résolution récursive (client → résolveur) vs itérative (résolveur → root chain).

$ dig @10.20.1.53 portail.fac-mi.univ-mosta.dz A +short
$ nslookup -type=mx univ-mosta.dz

4. NTP et SNMP (aperçu)
