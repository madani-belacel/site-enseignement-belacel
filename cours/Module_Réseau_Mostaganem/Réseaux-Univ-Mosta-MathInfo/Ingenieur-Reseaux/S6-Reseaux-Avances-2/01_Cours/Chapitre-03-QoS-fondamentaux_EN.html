Attribute Value

Chapter 03

Learning Objectives

After completing this chapter, the student will be able to:

  1. Comparer IntServ (RSVP) et DiffServ (PHB, DSCP).
  2. Classifier et marquer trafic VoIP, vidéo, best-effort.
  3. Configurer queuing (FIFO, WFQ, CBWFQ, LLQ) sur router.
  4. Dimensionner bandes garanties vs peak.
  5. Mesurer latence, jitter, perte pour SLA multimédia.

2. DiffServ

Edge : classify + mark (DSCP). Core : PHB (Per-Hop Behavior).

class-map match-any VOICE
 match dscp ef
policy-map WAN-OUT
 class VOICE
  priority percent 30
 class class-default
  fair-queue

4. Cas VoIP campus

Département University of Mostaganem : 200 postes VoIP, lien WAN 50 Mbps.

  1. Réserver 15 % LLQ EF.
  2. Marquer à l'IP Phone ou switch (mls qos trust dscp).
  3. Mesurer MOS via jitter < 30 ms objectif.
