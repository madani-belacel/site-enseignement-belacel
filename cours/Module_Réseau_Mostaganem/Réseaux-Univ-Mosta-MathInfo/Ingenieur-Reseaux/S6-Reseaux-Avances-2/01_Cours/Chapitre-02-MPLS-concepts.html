1. Motivation

MPLS (Multiprotocol Label Switching) : forwarding rapide par label (20 bits) au lieu lookup IP longest-prefix complet à chaque hop.

Couche Nom Fonction
Control LDP/RSVP-TE Distribution labels
Data LFIB Commutation label

Utilisations : VPN opérateur, Traffic Engineering, backbone ISP.

2. Label Switch Path

Push (ingress PE) → Swap (P routers) → Pop (egress PE).

[CE]--[PE1]===MPLS cloud===[PE2]--[CE distant]
      push L=100      swap      pop
Équipement Rôle MPLS
CE Client edge — routes IP classiques
PE Provider edge — VRF, labels
P Provider core — swap only

3. VPN MPLS L3 (aperçu)

Séparation clients via VRF + route-target import/export.

Concept Description
VRF Table routage virtuelle par client
RD Route Distinguisher — unicite BGP
RT Import/export entre VRF

Le CE voit un lien IP simple ; le cœur MPLS transporte labels.

4. MPLS et SD-WAN

Offres entreprise : liaisons MPLS garanties QoS vs Internet + overlay SD-WAN.

Critère MPLS SD-WAN
QoS Contractuelle Policy-based multi-lien
Coût Élevé Variable
