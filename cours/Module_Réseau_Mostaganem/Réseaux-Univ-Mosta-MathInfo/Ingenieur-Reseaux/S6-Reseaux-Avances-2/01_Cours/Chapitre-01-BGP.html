1. BGP — protocole inter-AS

BGP-4 (Border Gateway Protocol) échange de préfixes entre systèmes autonomes (AS). Path-vector : évite boucles via AS-PATH.

Caractéristique BGP OSPF
Portée Inter-domaine Intra-domaine
Transport TCP 179 IP proto 89
Métrique Politique + attributs Coût lien
Table Internet ~900k+ préfixes N/A campus

eBGP : voisins AS différents (souvent directement connectés ou multihop). iBGP : même AS — nécessite full-mesh ou route reflectors.

2. Attributs de décision

Ordre simplifié Cisco best-path :

Priorité Attribut Sens
1 Weight (local Cisco) Plus haut gagne
2 LOCAL_PREF Plus haut (iBGP in)
3 AS-PATH Plus court souvent préféré
4 MED Plus bas (influence entrée)
5 eBGP > iBGP — 
R1# show ip bgp
*> 203.0.113.0/24  10.0.0.2   65002 65003 i

3. Politiques et sécurité

Filtrer annonces entrantes/sortantes — route-map :

route-map FILTER-IN permit 10
 match ip address prefix-list ALLOW-ONLY
route-map FILTER-IN deny 100
!
neighbor 10.0.0.2 route-map FILTER-IN in

Bonnes pratiques : prefix-lists strictes, max-prefix, TTL security, MD5 TCP, RPKI (aperçu).

Cas Université de Mostaganem : peering MAN avec opérateur local — n'annoncer que agrégats publics autorisés.

4. Configuration eBGP minimale

R-AS65001(config)# router bgp 65001
R-AS65001(config-router)# neighbor 10.0.0.2 remote-as 65002
R-AS65001(config-router)# network 198.51.100.0 mask 255.255.255.0
Commande Rôle
show ip bgp summary État sessions
clear ip bgp * soft Renégociation policies
debug ip bgp updates Analyse annonces

Convergence : plus lente qu'IGP — acceptable à l'échelle Internet.
