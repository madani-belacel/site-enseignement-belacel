Chapter 04

Learning Objectives

After completing this chapter, the student will be able to:

  1. Analyser STP/RSTP/MST — root bridge, ports bloqués.
  2. Configurer EtherChannel L2/L3 (PAgP/LACP).
  3. Implémenter redondance L3 : HSRP, VRRP, GLBP.
  4. Concevoir topologie sans SPOF au cœur campus.
  5. Tester basculement et temps de convergence.

1. STP/RSTP

802.1D STP : un chemin actif, autres bloqués — évite boucles L2.

État port Signification
Blocking Pas de transit user
Forwarding Trafic autorisé
Listening/Learning Transition

RSTP 802.1w : convergence ~ secondes. MST : instances multiples par VLAN.

2. EtherChannel

Agrégation 2–8 liens = 1 logique :

interface Port-channel 1
 switchport mode trunk
 channel-group 1 mode active
Protocol Standard
LACP 802.3ad (inter-vendor)
PAgP Cisco proprietary

3. HSRP/VRRP

First Hop Redundancy : IP virtuelle partagée.

interface Vlan10
 ip address 10.10.10.2 255.255.255.0
 standby 10 ip 10.10.10.1
 standby 10 priority 110
 standby 10 preempt
Protocol Standard
HSRP Cisco
VRRP RFC 5798
GLBP Load balance actif

4. Design sans SPOF

Dual core + dual distribution + uplinks redondants + STP root primaire/secondaire.

Tests : coupure lien uplink, vérifier ping continu vers GW virtuel (< 3 s perte typique HSRP).
