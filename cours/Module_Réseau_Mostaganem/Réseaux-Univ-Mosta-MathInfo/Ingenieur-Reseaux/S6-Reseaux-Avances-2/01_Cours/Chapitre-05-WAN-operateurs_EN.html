Chapter 05

Learning Objectives

After completing this chapter, the student will be able to:

  1. Comparer technologies WAN : PPP, Metro Ethernet, MPLS, LTE backup.
  2. Décrire architecture ISP hiérarchique (Tier, IXP).
  3. Concevoir VPN site-à-site IPsec vs MPLS.
  4. Négocier SLA opérateur (disponibilité, RTT, support).
  5. Planifier continuité : lien secours, SD-WAN (aperçu).
