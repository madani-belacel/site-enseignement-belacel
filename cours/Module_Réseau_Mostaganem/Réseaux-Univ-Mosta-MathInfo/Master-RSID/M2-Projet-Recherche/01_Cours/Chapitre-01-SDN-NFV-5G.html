Chapitre 01 — SDN/NFV pour la 5G

Attribut Valeur
Niveau Master RSID
Semestre M2
Durée estimée 6 h CM
Chapitre 01

Objectifs pédagogiques

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Décrire l'architecture 5G (NR, 5GC, network slicing).
  2. Expliquer le rôle du SDN/NFV dans le cœur 5G.
  3. Configurer un slice réseau avec isolation garantie.
  4. Analyser les défis de déploiement (latence, orchestration).
  5. Comparer 4G vs 5G du point de vue réseau.

Plan du chapitre

  1. Fondements 5G
  2. SDN dans le cœur 5G
  3. NFV et Virtualisation
  4. Network Slicing
  5. Travaux dirigés

1. Architecture 5G

5G Core (5GC) : AMF, SMF, UPF, NRF — séparation plan contrôle/données renforcée.

NR (New Radio) : bandes mmWave et sub-6 GHz — Massive MIMO.

2. SDN pour 5G

UPF programmable via P4 — flexibilité du forwarding selon service.

3. NFV

VNF : 5GC fonctions logicielles sur COTS — MANO orchestration (ETSI NFV).

4. Network Slicing

Slice : eMBB (vidéo), URLLC (IoT critique), mMTC (massif).

5. Défis

Latence < 1 ms, orchestration multi-domaine, sécurité inter-slice.
