Chapters associés Ch. 04

Objectives

  • Formuler une question de recherche (RQ) structurée
  • Réaliser une requête bibliographique systématique sur IEEE Xplore / ACM DL
  • Appliquer les critères PRISMA pour la sélection d'articles

Consignes générales

  • Justifier toutes les réponses (calculs, schémas, tableaux).
  • Les schémas doivent être lisibles et légendés.
  • Durée indicative : 2 h en autonomie encadrée.

Exercice 1 — Question de recherche PICO (6 pts)

En vous basant sur la thématique "Security IoT industrielle dans un contexte 5G", formuler une question de recherche selon le modèle PICO adapté aux sciences du numérique :

  • P (Population) : domaine / système étudié
  • I (Intervention) : méthode ou solution proposée
  • C (Comparison) : alternative de référence
  • O (Outcome) : résultat mesurable attendu

Example : "Dans les networks IoT industriels (P), l'utilisation d'un IDS basé apprentissage profond (I) comparé à une approche par règles (C) améliore-t-elle le taux de détection d'intrusions (O) ?"

Exercice 2 — Chaîne de requête bibliographique (6 pts)

Construire une chaîne de requête booléenne pour IEEE Xplore sur la thématique choisie. Utiliser les opérateurs AND, OR, NOT, les guillemets pour les expressions exactes et la troncature *.

Example : ("industrial IoT" OR "IIoT") AND ("intrusion detection" OR "anomaly detection") AND ("deep learning" OR "neural network") NOT ("smart home")

  1. Proposer une requête avec au moins 3 concepts.
  2. Justifier le choix des mots-clés et l'exclusion.

Exercice 3 — Diagramme PRISMA (4 pts)

À partir des résultats suivants, construire le diagramme de flux PRISMA (4 étapes : identification, screening, eligibility, inclusion) :

Annexe — Corrigé TD 04

  1. P : Networks IoT industriels ; I : IDS basé deep learning (LSTM, CNN) ; C : IDS basé règles (Snort, Suricata) ; O : Taux de détection (DR), faux positifs (FPR)

  2. Requête : ("industrial IoT" OR "IIoT" OR "Industry 4.0") AND ("intrusion detection" OR "anomaly detection") AND ("deep learning" OR "LSTM" OR "CNN") NOT ("smart home" OR "wearable")

  3. Diagramme PRISMA : 340 identifiés → -45 doublons → 295 screening → -200 exclus → 95 éligibles → -60 exclus → 35 inclus

  4. Grille de lecture : Problème → méthode → métriques (accuracy, precision, rappel, F1) → résultats → limites (dataset déséquilibré, overfitting, passage à l'échelle)
