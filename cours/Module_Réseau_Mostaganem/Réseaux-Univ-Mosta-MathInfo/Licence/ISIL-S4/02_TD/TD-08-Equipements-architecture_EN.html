Exercice 3 — Dépannage (5 pts)

Un utilisateur signale « pas d'Internet ». Voici les résultats :

ping 127.0.0.1     → OK
ping 192.168.1.1   → OK (passerelle)
ping 8.8.8.8       → Échec (Request timed out)
ping google.com    → Échec (Could not find host)
ipconfig           → IP: 192.168.1.50, Masque: 255.255.255.0, GW: 192.168.1.1, DNS: 192.168.1.1

a) Le problème est-il local (L1-L3 LAN) ou au-delà ? Justifier.

b) Proposer 3 causes possibles.

c) Proposer 3 actions de diagnostic supplémentaires.

Annexe — Corrigé TD 08

Corrigé Exercice 1

Équipement Couche Fonction
Hub L1 Répète signal sur tous ports
Switch L2 Commute trames par MAC
Routeur L3 Route paquets IP
Pare-feu L3-L4 Filtre trafic
NIC L1-L2 Interface hôte/réseau
AP Wi-Fi L1-L2 Accès sans fil au LAN

a) Switch 16+ ports, routeur/pare-feu, câbles Cat 6, serveur, imprimante réseau

b)

Équipement IP

Imprimante 192.168.100.10
PC 1-11 192.168.100.11–21
DHCP pool 192.168.100.100–200

c) Topologie étoile : tous les PC → Switch → Routeur → Internet

d) Entre le switch LAN et Internet — filtre trafic entrant/sortant

Corrigé Exercice 3

a) Au-delà du LAN — ping passerelle OK mais pas Internet

b) 1. Routeur WAN down 2. Pare-feu bloque sortie 3. Problème NAT 4. FAI en panne 5. DNS down (mais ping 8.8.8.8 échoue aussi → plutôt routage)

c) tracert 8.8.8.8, vérifier config routeur, tester depuis un autre PC, contacter admin réseau
