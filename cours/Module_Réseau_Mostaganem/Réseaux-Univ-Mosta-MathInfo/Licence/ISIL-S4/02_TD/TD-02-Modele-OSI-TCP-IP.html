Annexe — Corrigé TD 02

Corrigé Exercice 1

Élément Couche
HTTP 7 — Application
Switch 2 — Liaison
IP 3 — Réseau
Câble RJ-45 1 — Physique
TCP 4 — Transport
Routeur 3 — Réseau
Adresse MAC 2 — Liaison
DNS 7 — Application

Corrigé Exercice 2

a) Data → Segment → Paquet → Trame → Bits

b) - Transport : src port 49152, dest port 80 - Réseau : src IP 192.168.1.10, dest IP 10.0.0.5 - Liaison : MAC src (PC), MAC dest (passerelle ou serveur si même LAN)

c) Bits → Trame → Paquet → Segment → Data (L1 → L7)

Corrigé Exercice 3

Critère OSI TCP/IP
Couches 7 4
Transport 4 Transport
Couche 3 IP (dans modèle) Internet (IP)
Nature Théorique Implémenté
Usage Pédagogique, diagnostic Production Internet

Corrigé Exercice 4

Symptôme Couche Justification
a) LED éteinte L1 Physique Pas de signal sur le média
b) ping GW échoue L2/L3 Problème local MAC/IP/masque
c) ping Internet échoue L3 Routage, NAT, pare-feu
d) DNS échoue L7 Service DNS inaccessible
e) Erreur 404 L7 Serveur répond mais ressource absente
