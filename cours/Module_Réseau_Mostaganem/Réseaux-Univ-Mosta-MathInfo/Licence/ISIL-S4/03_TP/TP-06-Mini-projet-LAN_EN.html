TP 06 — Mini-projet réseau local

Attribute Value
Level Bachelor ISIL — S4
Estimated duration 3 h
Outil Cisco Packet Tracer
Prérequis Tous les chapitres, TP 01–03

Objectifs

  • Concevoir et déployer un réseau LAN complet
  • Intégrer switch, routeur, serveur, DHCP, DNS simulé
  • Produire un document de conception professionnel

Partie 1 — Cahier des charges

Contexte : Le département ISIL de l'Université de Mostaganem ouvre un nouveau laboratoire de 12 postes étudiants, 1 poste enseignant, 1 serveur de fichiers, 1 imprimante réseau, avec accès Internet.

Exigences

Exigence Détail
Topologie Étoile, 1 switch principal
Réseau étudiants 192.168.50.0/26 (62 hôtes max)
Réseau serveurs 192.168.51.0/28 (14 hôtes max)
Internet Via routeur avec NAT
Services DHCP sur le routeur, serveur fichier statique
Sécurité Imprimante accessible depuis les deux réseaux

Partie 2 — Consignes

Étape 1 — Document de conception (45 min)

Rédiger (dans le compte-rendu) :

  1. Schéma de topologie (draw.io, Packet Tracer ou à la main scanné)
  2. Tableau d'adressage IP complet
  3. Liste des équipements (modèle, quantité)
  4. Justification des choix (masques, segmentation)

Étape 2 — Construction Packet Tracer (60 min)

Équipements minimum : - 1 Routeur 4321 (2 interfaces LAN + 1 WAN simulée) - 1 Switch 2960-24TT - 12 PC « Étudiant » (regrouper 2-3 suffisent pour le test) - 1 PC Enseignant - 1 Server-PT (serveur fichiers) - 1 Imprimante (optionnel)

Adressage proposé :

Équipement IP Masque GW
R1 G0/0 (LAN étudiants) 192.168.50.1 255.255.255.192 —
R1 G0/1 (LAN serveurs) 192.168.51.1 255.255.255.240 —
PC Enseignant 192.168.50.10 255.255.255.192 192.168.50.1
PC Étudiant-1 192.168.50.20 255.255.255.192 192.168.50.1
Serveur fichiers 192.168.51.5 255.255.255.240 192.168.51.1
R1 G0/2 (WAN) 203.0.113.1 255.255.255.252 —

Étape 3 — Configuration routeur (45 min)

! Interfaces
interface GigabitEthernet0/0
 ip address 192.168.50.1 255.255.255.192
 no shutdown
interface GigabitEthernet0/1
 ip address 192.168.51.1 255.255.255.240
 no shutdown

! Routes inter-réseaux (si nécessaire — directement connectées)
! NAT pour Internet (optionnel)
ip route 0.0.0.0 0.0.0.0 [interface_WAN]

! DHCP pool étudiants (optionnel)
ip dhcp pool ETUDIANTS
 network 192.168.50.0 255.255.255.192
 default-router 192.168.50.1
 dns-server 8.8.8.8

Étape 4 — Tests de validation (30 min)

Test Commande Attendu
Ping intra-réseau PC-Etu → PC-Ens OK
Ping inter-réseau PC-Etu → Serveur OK
Ping passerelle PC → 192.168.50.1 OK
Accès serveur ping 192.168.51.5 OK
Simulation trafic Mode Simulation ping Traversée routeur visible

Partie 3 — Livrables obligatoires

Livrable Format Poids
Document de conception PDF (3-5 pages) 40 %
Fichier Packet Tracer .pkt 30 %
Tests et captures PDF (captures ping, show ip route) 20 %
Présentation orale (2 min) Oral 10 %

Structure du document de conception

  1. Introduction et contexte
  2. Schéma de topologie
  3. Plan d'adressage IP
  4. Liste des équipements
  5. Configuration clé (extraits CLI)
  6. Résultats des tests
  7. Conclusion et améliorations possibles

Partie 4 — Questions de bilan

  1. Pourquoi séparer le réseau serveurs (192.168.51.0/28) du réseau étudiants ?
  2. Quel masque choisi pour le réseau étudiants (/26) et combien d'hôtes reste-t-il ?
  3. Quel équipement relierait-on en DMZ si le serveur web devait être public ?
  4. Comment ajouteriez-vous un point d'accès Wi-Fi ?
  5. Quelles failles de sécurité ce réseau présente-t-il (niveau ISIL-S4) ?

Annexe — Corrigé (éléments clés)

  1. Sécurité — isoler les serveurs des postes étudiants.
  2. /26 = 62 hôtes ; 12+1+1 = 14 utilisés → marge suffisante.
  3. Serveur web en DMZ derrière pare-feu, pas avec les fichiers internes.
  4. AP connecté au switch, même VLAN ou VLAN dédié invités.
  5. Pas de pare-feu L7, pas de segmentation avancée, mots de passe par défaut, pas de chiffrement interne.
