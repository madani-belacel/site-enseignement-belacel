TP 05 — DNS et HTTP : capture et analyse

Attribute Value
Level Bachelor ISIL — S4
Estimated duration 3 h
Outil Wireshark
Prérequis Ch. 06–07, TP 04

Objectifs

  • Capturer et analyser des requêtes DNS
  • Observer le three-way handshake TCP
  • Analyser une requête/réponse HTTP ou HTTPS (en-têtes)

Partie 2 — Consignes

Étape 1 — Capture DNS (45 min)

  1. Vider le cache DNS :
ipconfig /flushdns        # Windows
  1. Démarrer capture Wireshark.
  2. Exécuter :
nslookup www.univ-mosta.dz
nslookup www.google.com
  1. Filtrer : dns

Étape 3 — Capture TCP Handshake (30 min)

  1. Filtrer : tcp.flags.syn == 1
  2. Identifier une connexion complète : SYN → SYN-ACK → ACK
  3. Noter les numéros de port source/dest et les flags

1 SYN ? —

Étape 4 — HTTPS (30 min)

  1. Visiter https://www.univ-mosta.dz ou https://www.google.com
  2. Filtrer : tls ou ssl
  3. Observer que le contenu HTTP est chiffré (Application Data)
  4. Expliquer pourquoi on ne voit pas le GET en clair

Étape 5 — Chronologie complète (30 min)

Reconstituer l'ordre pour un accès web :

1. DNS Query → 2. DNS Response → 3. TCP SYN → 4. SYN-ACK → 5. ACK
→ 6. TLS Client Hello → 7. TLS Server Hello → 8. HTTP (chiffré)

Partie 3 — Vérifications

Test Critère
DNS capturé Query + Response visibles
HTTP en clair GET et code 200 visibles
TCP handshake 3 segments identifiés
HTTPS Contenu chiffré confirmé

Partie 4 — Questions de bilan

  1. DNS utilise-t-il TCP ou UDP ? Dans quels cas TCP est-il utilisé ?
  2. Quel port utilise le client pour une connexion HTTPS ?
  3. Pourquoi le three-way handshake est-il nécessaire avant HTTP ?
  4. Que signifie le code HTTP 301 ?
  5. Comment différencier une trame DNS d'une trame HTTP dans Wireshark ?

Annexe — Corrigé

  1. UDP principalement ; TCP pour transferts de zone (zone transfer) ou messages > 512 octets.
  2. Port éphémère (ex: 52341) vers port 443.
  3. TCP établit une connexion fiable avant d'échanger des données applicatives.
  4. 301 = redirection permanente vers une autre URL.
  5. Filtre dns vs http ; port 53 vs port 80/443 ; protocole visible dans la colonne Protocol.
