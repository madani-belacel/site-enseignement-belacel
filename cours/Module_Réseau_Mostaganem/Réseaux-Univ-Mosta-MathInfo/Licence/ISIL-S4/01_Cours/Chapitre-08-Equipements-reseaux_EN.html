Chapitre 08 — Équipements réseaux et architecture LAN/WAN

Attribute Value
Level Bachelor ISIL — S4
Module UEF422 — Networks
Estimated duration 3 h CM (+ 2 h TD associé)
Chapter 08 / 08
Références [KR] Ch. 4.3 ; [CI] CCNA Module 1–3 ; [FO] Ch. 6

Chapter Objectives

After completing this chapter, the student will be able to:

  1. Identifier et décrire les équipements réseau (NIC, hub, switch, routeur, pare-feu).
  2. Associer chaque équipement à sa couche OSI.
  3. Concevoir une architecture LAN simple pour un petit bureau ou campus.
  4. Comprendre l'interconnexion LAN/WAN et le rôle du FAI.
  5. Appliquer une méthodologie de dépannage réseau de base.

1. Carte réseau (NIC)

La NIC (Network Interface Card) est l'interface entre l'hôte et le réseau.

Caractéristique Détail
Couche OSI 1 (Physique) + 2 (Liaison)
Adresse MAC Unique, gravée ou configurable
Connecteur RJ-45 (Ethernet), antenne (Wi-Fi)
Débit 100 Mbps, 1 Gbps, 10 Gbps
Fonction Conversion données ↔ signaux, adressage MAC 
┌──────────────────────────────────┐
│           PC / Serveur           │
│  ┌──────────┐   ┌─────────────┐  │
│  │    OS    │──→│    NIC      │──┼──→ Câble / Wi-Fi
│  │ (Driver) │   │ MAC: xx:xx  │  │
│  └──────────┘   └─────────────┘  │
└──────────────────────────────────┘

2. Équipements de couche 1 et 2

2.1 Tableau comparatif

Équipement Couche Fonction Domaine collision Domaine broadcast Statut
Répéteur 1 Régénère le signal Partagé Partagé Rare
Hub 1 Répète sur tous les ports Unique Unique ❌ Obsolète
Switch (L2) 2 Commute les trames par MAC Par port Unique ✅ Standard LAN
Pont (Bridge) 2 Relie deux segments LAN Séparé Unique Rare (remplacé par switch)

2.2 Switch — approfondissement

Caractéristique Détail
Ports 8, 16, 24, 48 (modèles courants)
Vitesse 100 Mbps, 1 Gbps, 10 Gbps (uplink)
Table MAC Apprend automatiquement (CAM table)
Full-duplex Émission et réception simultanées
VLAN Segmentation logique (802.1Q)
PoE Alimentation des AP/switch via câble Ethernet

Switch manageable vs non-manageable :

Type Configuration Usage
Non-manageable Plug-and-play, aucune config Petit bureau, maison
Manageable CLI, Web, SNMP, VLAN, QoS Entreprise, campus

2.3 Point d'accès Wi-Fi (Access Point)

Caractéristique Détail
Couche 1 + 2 (802.11)
Fonction Connecte les clients sans fil au LAN filaire
Connexion Relié à un switch par câble Ethernet

3. Équipements de couche 3

3.1 Routeur

Caractéristique Détail
Couche OSI 3 (Réseau)
Fonction Routage de paquets IP entre réseaux
Interfaces Ethernet, fibre, serial (WAN)
Table de routage Statique ou dynamique (OSPF, BGP)
Services intégrés NAT, DHCP, ACL, pare-feu basique 
Réseau A (192.168.1.0/24) ──→ [Routeur] ──→ Réseau B (192.168.2.0/24)
                                    │
                                    └──→ Internet (WAN)

3.2 Routeur vs Switch — règle fondamentale

Question Équipement
Connecter des PC dans le même réseau ? Switch
Connecter deux réseaux différents ? Routeur
Accéder à Internet ? Routeur (passerelle par défaut)
Segmenter le broadcast (VLAN) ? Switch (L2) ou Routeur (L3)

3.3 Switch multicouche (Layer 3 Switch) — aperçu

  • Switch avec capacité de routage intégrée.
  • Route entre VLANs sans routeur externe.
  • → Approfondi en Ingénieur.

4. Pare-feu et sécurité périmétrique

4.1 Pare-feu (Firewall)

Caractéristique Détail
Couche 3–4 (IP, port) voire 7 (NGFW)
Fonction Filtrer le trafic selon des règles de sécurité
Types Stateful (avec état), Stateless (ACL simples)
Emplacement Périmètre (entre LAN et Internet), DMZ

Exemple de règles :

Règle Source Destination Port Action
1 LAN Internet 80, 443 Autoriser
2 Internet LAN Any Bloquer
3 LAN LAN Any Autoriser
4 Any Any Any Bloquer (deny all)

4.2 DMZ (Demilitarized Zone)

                    Internet
                       │
                  ┌────┴────┐
                  │ Pare-feu │
                  └────┬────┘
              ┌────────┼────────┐
              │                 │
         ┌────┴────┐      ┌────┴────┐
         │   DMZ   │      │   LAN   │
         │ (Web,   │      │ (PC,    │
         │  Mail)  │      │  BDD)   │
         └─────────┘      └─────────┘
  • DMZ : Zone exposée contenant les serveurs publics (web, mail).
  • LAN : Zone interne protégée.
  • Un attaquant compromettant la DMZ n'accède pas directement au LAN.

6. Interconnexion LAN/WAN

6.1 Du LAN à Internet

[PC] → [Switch LAN] → [Routeur/Pare-feu] → [Modem/Box FAI] → [Réseau FAI] → Internet
        192.168.x.x      NAT + routage         IP publique       MPLS/Fibre
        (privé)                               (publique)
Étape Action
1 Le PC envoie un paquet vers 8.8.8.8 (Google DNS)
2 Paquet arrive au routeur LAN (passerelle par défaut)
3 Routeur applique NAT : IP source 192.168.x.x → IP publique FAI
4 Paquet transite via le réseau de l'opérateur (Algérie Télécom, etc.)
5 Routage Internet jusqu'à la destination
6 Réponse revient via NAT inverse

6.2 Équipements côté opérateur (aperçu)

Équipement Rôle
DSLAM / OLT Concentrateur accès (ADSL/Fibre)
Routeur de bord (PE) Routage, BGP
Commutateur backbone Cœur du réseau opérateur

7. Méthodologie de dépannage réseau

7.1 Modèle OSI bottom-up (couche basse → haute)

Étape Couche Vérification Commande
1 Physique (L1) Câble branché ? Link/LED actif ? Inspection visuelle
2 Liaison (L2) Adresse MAC, ARP, switch arp -a, ipconfig /all
3 Réseau (L3) Adresse IP, masque, passerelle ipconfig, ip addr
4 Transport (L4) Connectivité TCP/UDP ping, telnet, Test-NetConnection
5 Application (L7) DNS, HTTP, services nslookup, curl, navigateur

7.2 Commandes de diagnostic essentielles

# Windows
ipconfig /all              # Configuration IP complète
ping 192.168.1.1           # Test connectivité L3
ping 8.8.8.8              # Test connectivité Internet
tracert www.univ-mosta.dz        # Chemin vers destination
arp -a                     # Table ARP (L2)
nslookup www.univ-mosta.dz       # Résolution DNS (L7)
netstat -an                # Connexions actives (L4)

# Linux
ip addr show               # Configuration IP
ip route show              # Table de routage
ping -c 4 8.8.8.8         # Test connectivité
traceroute 8.8.8.8        # Chemin
ss -tulnp                  # Ports en écoute

7.3 Arbre de décision simplifié

Pas de connectivité ?
├── ping 127.0.0.1 OK ?
│   ├── NON → Problème stack TCP/IP local (driver NIC)
│   └── OUI → ping passerelle OK ?
│       ├── NON → Problème L2/L3 local (câble, IP, masque, switch)
│       └── OUI → ping 8.8.8.8 OK ?
│           ├── NON → Problème routage/NAT/pare-feu
│           └── OUI → ping nom de domaine OK ?
│               ├── NON → Problème DNS
│               └── OUI → Problème application (navigateur, proxy)

9. QCM

N° Question a b c d Réponse
1 Un switch opère en couche… 1 2 3 7 b
2 Un routeur connecte… Deux PC du même réseau Deux réseaux différents Un PC à une imprimante USB Un câble à un autre câble b
3 Un hub est aujourd'hui… Standard Obsolète Utilisé en WAN Un pare-feu b
4 La DMZ contient… Les PC des employés Les serveurs publics exposés Le switch cœur Le FAI b
5 NAT est implémenté sur… Switch Routeur Hub Câble b
6 La passerelle par défaut est… Un serveur DNS Le routeur sortie du LAN Un switch Un hub b
7 PoE permet de… Router des paquets Alimenter un AP via Ethernet Chiffrer le trafic Résoudre les noms DNS b
8 En dépannage, on teste d'abord… HTTP DNS ping localhost puis passerelle FTP c
9 Un pare-feu filtre selon… Uniquement les adresses MAC IP, ports, protocoles Uniquement la couche 1 Le débit b
10 Le modèle hiérarchique a… 2 couches 3 couches (accès, distribution, cœur) 7 couches 1 couche b
