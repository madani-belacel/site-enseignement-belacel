Chapter Objectives

After completing this chapter, the student will be able to:

  1. Décrire la trame Ethernet (IEEE 802.3) et ses champs.
  2. Expliquer le fonctionnement de l'adressage MAC.
  3. Différencier hub, switch et carte réseau (NIC).
  4. Comprendre la commutation et la table MAC d'un switch.
  5. Expliquer le protocole CSMA/CD (historique) et le full-duplex.
  6. Donner un aperçu des VLAN (802.1Q).

1. Rôle de la couche Liaison

La couche Liaison de données (Layer 2) assure :

Fonction Description
Encapsulation Organiser les bits en trames
Adressage physique Adresse MAC (Media Access Control)
Contrôle d'accès au média Qui peut transmettre et quand (MAC sublayer)
Détection d'erreurs CRC/FCS — détecter les trames corrompues
Commutation locale Transfert de trames dans un LAN (switch)

La couche Liaison opère dans un même domaine de diffusion (broadcast domain) au sein d'un LAN.

2. Sous-couches LLC et MAC

La couche Liaison se subdivise en deux sous-couches :

Sous-couche Sigle Rôle
Logical Link Control LLC (802.2) Interface avec la couche 3, multiplexage des protocoles
Media Access Control MAC (802.3) Adressage, contrôle d'accès, trames

3. Adressage MAC

3.1 Format

  • Adresse MAC : 48 bits (6 octets), généralement notée en hexadécimal.
  • Exemple : 4C:EB:42:A1:B2:C3 ou 4C-EB-42-A1-B2-C3
  • OUI (Organizationally Unique Identifier) : 3 premiers octets → identifient le fabricant.
  • 3 derniers octets : numéro de série attribué par le fabricant.

3.2 Types d'adresses MAC

Type Bit de poids faible du 1er octet Comportement
Unicast 0 (pair) Destinée à une seule NIC
Multicast 1 (impair, bit I/G) Destinée à un groupe de NICs
Broadcast Tous bits à 1 : FF:FF:FF:FF:FF:FF Destinée à tous les hôtes du LAN

3.3 MAC vs IP

Critère Adresse MAC Adresse IP
Couche 2 (Liaison) 3 (Réseau)
Taille 48 bits 32 bits (IPv4)
Attribution Fixe (usine) ou configurable Logique (DHCP, manuelle)
Portée Locale (LAN) Globale (routée)
Changement à chaque saut Oui (réécrite par routeur) Non (conservée)

4. Trame Ethernet IEEE 802.3

4.1 Structure de la trame Ethernet II (DIX)

┌──────────────────┬──────────────────┬──────┬──────────────┬─────┐
│ Adresse MAC Dest │ Adresse MAC Src  │ Type │   Données    │ FCS │
│    (6 octets)    │    (6 octets)    │(2 o) │ (46–1500 o)  │(4 o)│
└──────────────────┴──────────────────┴──────┴──────────────┴─────┘
                                              ◄── Payload (PDU L3)
Champ Taille Description
Préambule + SFD 8 octets Synchronisation (non compté dans la trame)
Adresse destination 6 octets MAC du destinataire
Adresse source 6 octets MAC de l'émetteur
Type (EtherType) 2 octets Protocole de couche 3 (0x0800 = IPv4, 0x0806 = ARP)
Données (Payload) 46–1500 octets Paquet IP (typiquement)
FCS (CRC-32) 4 octets Contrôle d'erreurs

Taille minimale : 64 octets (sans préambule) — garantit la détection de collision. Taille maximale : 1518 octets (1522 avec VLAN tag) → MTU (Maximum Transmission Unit) = 1500 octets pour IP.

4.2 EtherType courants

EtherType Protocole
0x0800 IPv4
0x86DD IPv6
0x0806 ARP
0x8100 VLAN (802.1Q tag)

5. CSMA/CD et Ethernet moderne

5.1 CSMA/CD (Carrier Sense Multiple Access with Collision Detection)

Protocole d'accès au média pour Ethernet half-duplex (historique) :

Étape Action
CS — Carrier Sense Écouter si le canal est libre
MA — Multiple Access Plusieurs nœuds partagent le même média
CD — Collision Detection Détecter une collision pendant l'émission

Algorithme : 1. Écouter le canal → s'il est libre, transmettre. 2. Si collision détectée → envoyer un jam signal, puis attendre un délai aléatoire (backoff exponentiel). 3. Retenter jusqu'à succès ou abandon.

Aujourd'hui : Avec les switches et le full-duplex, CSMA/CD est virtuellement inutile (plus de collisions en pratique).

5.2 Half-duplex vs Full-duplex

Mode Principe Collisions Usage
Half-duplex Émission OU réception Possibles (CSMA/CD) Hub (obsolète)
Full-duplex Émission ET réception simultanées Impossibles Switch ↔ PC (standard actuel)

6. Commutation (Switch)

6.1 Hub vs Switch

Équipement Couche Principe Domaine collision Domaine diffusion
Hub 1 Répète le signal sur tous les ports Unique (partagé) Unique
Switch 2 Commute les trames vers le port destinataire Par port Unique (sans VLAN)
Routeur 3 Route les paquets IP — Sépare les domaines

6.2 Fonctionnement d'un switch

  1. Apprentissage : Le switch lit l'adresse MAC source de chaque trame reçue et l'enregistre dans sa table MAC (CAM table) associée au port.
  2. Commutation :
  3. Si la MAC destination est connue → envoi unicast sur le port correspondant.
  4. Si inconnue → flooding (diffusion sur tous les ports sauf le port source).
  5. Si broadcast (FF:FF:FF:FF:FF:FF) → flooding sur tous les ports.
Table MAC du Switch :
┌─────────────────────┬──────┬───────────┐
│ Adresse MAC         │ Port │ Type      │
├─────────────────────┼──────┼───────────┤
│ AA:BB:CC:11:22:33   │  1   │ Dynamique │
│ AA:BB:CC:44:55:66   │  3   │ Dynamique │
│ AA:BB:CC:77:88:99   │  5   │ Dynamique │
└─────────────────────┴──────┴───────────┘
  1. Aging : Les entrées dynamiques expirent après un délai (300 s par défaut Cisco).

6.3 Avantages du switch

  • Bande passante dédiée par port (full-duplex)
  • Pas de collisions (domaine collision par port)
  • Sécurité améliorée (trafic non diffusé inutilement)
  • Performance supérieure au hub

7. VLAN — aperçu (802.1Q)

7.1 Définition

Un VLAN (Virtual Local Area Network) est un réseau local logique créé au sein d'un même switch physique, isolant les domaines de diffusion.

7.2 Intérêt

Avantage Description
Sécurité Isoler le trafic (ex : VLAN enseignants / étudiants)
Organisation Grouper par département, fonction
Flexibilité Déplacer un hôte sans recâblage
Performance Réduire le broadcast inutile

7.3 Trame 802.1Q (Tagged)

Un tag VLAN de 4 octets est inséré entre l'adresse source et le Type :

| MAC Dest | MAC Src | Tag 802.1Q (4 o) | Type | Data | FCS |
                        └── VLAN ID (12 bits) → 4094 VLANs possibles
VLAN Usage type Université de Mostaganem
VLAN 10 Administration
VLAN 20 Salles de TP
VLAN 30 Invités / Wi-Fi

Les VLAN seront approfondis en SI-S5 et en Ingénieur.

8. Protocole ARP (aperçu)

ARP (Address Resolution Protocol) : résout une adresse IP en adresse MAC dans un LAN.

Étape Action
1 PC veut envoyer un paquet IP à 192.168.1.1
2 Il ne connaît pas la MAC → envoie une requête ARP broadcast : « Qui a 192.168.1.1 ? »
3 Le routeur répond en unicast : « 192.168.1.1 est à MAC AA:BB:CC:00:00:01 »
4 Le PC met en cache (table ARP) et envoie la trame 
> arp -a    (Windows/Linux — afficher le cache ARP)

Exemple 2 — Taille minimale de trame

Si le payload IP fait 20 octets, la trame fait 20 + 14 (en-tête Eth) + 4 (FCS) = 38 octets < 64 → padding ajouté jusqu'à 46 octets de données.
