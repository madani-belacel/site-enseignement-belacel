After completing this chapter, the student will be able to:

1. Rôle de la couche Réseau

La couche Réseau (Layer 3) assure :

Fonction Description
Adressage logique Adresses IP uniques (globalement routables)
Routage Déterminer le meilleur chemin vers la destination
Fragmentation Diviser les paquets si nécessaire (MTU)
Interconnexion Relier des réseaux hétérogènes (LAN, WAN)

Le routeur est l'équipement emblématique de la couche 3.

2.1 Caractéristiques

Propriété Valeur
Protocole IP — Internet Protocol
Version IPv4 (32 bits), IPv6 (128 bits — voir SI-S5)
Mode de service Best effort (pas de garantie de livraison)

RFC RFC 791 (IPv4)

3. Adressage IPv4

3.1 Format

  • Adresse IPv4 = 32 bits = 4 octets, notée en décimal pointé : 192.168.1.10
  • Chaque octet : 0–255 (8 bits)

3.2 Classes historiques (à connaître)

Classe 1ers bits Plage Masque par défaut Usage
A 0 1.0.0.0 – 126.255.255.255 255.0.0.0 (/8) Grands réseaux
B 10 128.0.0.0 – 191.255.255.255 255.255.0.0 (/16) Réseaux moyens
C 110 192.0.0.0 – 223.255.255.255 255.255.255.0 (/24) Petits réseaux
D 1110 224.0.0.0 – 239.255.255.255 — Multicast
E 1111 240.0.0.0 – 255.255.255.255 — Réservé

Aujourd'hui : On utilise la notation CIDR (Classless), les classes strictes sont obsolètes.

3.3 Notation CIDR

CIDR (Classless Inter-Domain Routing) : adresse/masque

Notation Masque Nombre de bits réseau Hôtes possibles
/24 255.255.255.0 24 2⁸ − 2 = 254
/25 255.255.255.128 25 2⁷ − 2 = 126
/26 255.255.255.192 26 2⁶ − 2 = 62
/30 255.255.255.252 30 2² − 2 = 2

On soustrait 2 car l'adresse réseau (tous bits hôte à 0) et l'adresse broadcast (tous bits hôte à 1) ne sont pas utilisables.

3.4 Adresses spéciales

Adresse Signification
0.0.0.0/0 Route par défaut (default route)
127.0.0.0/8 Loopback (localhost) — 127.0.0.1
255.255.255.255 Broadcast limité
169.254.0.0/16 APIPA — auto-attribution si pas de DHCP

3.5 Adresses privées (RFC 1918)

Plage Classe d'origine Usage
10.0.0.0/8 A Grandes entreprises
172.16.0.0/12 B Réseaux moyens
192.168.0.0/16 C Box, LAN domestique, TP

Ces adresses ne sont pas routées sur Internet → nécessité du NAT.

4. Sous-réseaux (Subnetting)

4.1 Principe

Diviser un réseau en sous-réseaux plus petits en empruntant des bits de la partie hôte :

Exemple : Réseau 192.168.1.0/24 → diviser en 4 sous-réseaux /26

Sous-réseau Adresse réseau Plage hôtes Broadcast
1 192.168.1.0/26 .1 – .62 192.168.1.63
2 192.168.1.64/26 .65 – .126 192.168.1.127
3 192.168.1.128/26 .129 – .190 192.168.1.191
4 192.168.1.192/26 .193 – .254 192.168.1.255

4.2 Méthode de calcul

Énoncé : IP = 192.168.10.45/26. Trouver réseau, broadcast, plage hôtes.

Solution : 1. /26 → masque = 255.255.255.192 → 256 − 192 = 64 (taille du bloc) 2. Multiples de 64 : 0, 64, 128, 192 → 45 est dans le bloc 0–63 3. Réseau = 192.168.10.0/26 4. Broadcast = 192.168.10.63 5. Hôtes = 192.168.10.1 – 192.168.10.62

4.3 Masque et opération AND

$$\text{Adresse réseau} = \text{IP} \ AND \ \text{Masque}$$

IP      : 192.168.10.45  →  11000000.10101000.00001010.00101101
Masque  : 255.255.255.192 → 11111111.11111111.11111111.11000000
AND     : 192.168.10.0   →  11000000.10101000.00001010.00000000

5. NAT — aperçu

NAT (Network Address Translation) : traduit des adresses privées en adresse publique pour accéder à Internet.

LAN (192.168.1.x) ──→ [Routeur NAT] ──→ Internet (IP publique 41.x.x.x)
Type Description
NAT statique 1 IP privée ↔ 1 IP publique
PAT/NAT overload N IP privées ↔ 1 IP publique (via ports)

Approfondi en SI-S5 et Ingénieur.

6. Routage statique

6.1 Principe

Chaque routeur contient une table de routage qui indique comment atteindre les réseaux distants :

Réseau destination Masque Next-hop (passerelle) Interface Métrique
192.168.1.0 /24 Direct Fa0/0 —
192.168.2.0 /24 Direct Fa0/1 —
0.0.0.0 /0 10.0.0.2 Fa0/0 1

6.2 Routage statique vs dynamique

Critère Statique Dynamique (OSPF, BGP)
Configuration Manuelle Automatique
Taille réseau Petit Grand
Adaptation pannes Non Oui
Niveau ISIL-S4 ✅ Aperçu seulement

Configuration statique R1 (Cisco IOS — aperçu) :

ip route 192.168.2.0 255.255.255.0 10.0.0.2
ip route 0.0.0.0 0.0.0.0 10.0.0.2    ! route par défaut

6.4 Algorithme de routage (simplifié)

Pour chaque paquet reçu : 1. Extraire l'IP destination. 2. Chercher la correspondance la plus spécifique (longest prefix match) dans la table. 3. Si trouvé → forwarder vers le next-hop ou interface directe. 4. Si non trouvé → utiliser la route par défaut (0.0.0.0/0) ou dropper.

7. ICMP

ICMP (Internet Control Message Protocol) — RFC 792 : messages de contrôle et de diagnostic pour IP.

Message Type ICMP Usage
Echo Request Type 8 ping — demande de réponse
Echo Reply Type 0 ping — réponse
Destination Unreachable Type 3 Réseau/hôte/port inaccessible
Time Exceeded Type 11 TTL expiré (traceroute) 
ping 192.168.1.1          # Test connectivité
ping -n 4 8.8.8.8         # Windows — 4 requêtes
traceroute www.univ-mosta.dz    # Linux — chemin des routeurs
tracert www.univ-mosta.dz       # Windows

8. Examples et exercices

Exercice 1 — Adressage

IP : 172.16.5.130/25. Déterminer réseau, broadcast, plage hôtes, nombre d'hôtes.

Solution /25 → masque 255.255.255.128 → blocs de 128 130 est dans le bloc 128–255 - **Réseau** : 172.16.5.128/25 - **Broadcast** : 172.16.5.255 - **Hôtes** : 172.16.5.129 – 172.16.5.254 (126 hôtes)

Exercice 2 — Routage

PC-A (192.168.1.10) envoie un paquet à PC-B (192.168.2.10). Décrire le chemin en indiquant les adresses IP et MAC à chaque étape (premier saut).

Solution 1. PC-A voit que 192.168.2.10 n'est pas dans son réseau → envoie au **passerelle par défaut** (192.168.1.1) 2. Trame L2 : Dest MAC = MAC de R1, Dest IP = 192.168.2.10 3. R1 route vers R2 via 10.0.0.0/30 4. R2 livre à PC-B sur 192.168.2.0/24
