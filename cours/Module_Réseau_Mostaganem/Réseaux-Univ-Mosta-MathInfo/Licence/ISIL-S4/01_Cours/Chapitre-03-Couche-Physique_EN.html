Chapter Objectives

After completing this chapter, the student will be able to:

  1. Identifier les supports de transmission guidés et non guidés.
  2. Expliquer les principes de la représentation numérique des signaux.
  3. Décrire les techniques de codage et de modulation.
  4. Comprendre les méthodes de multiplexage (FDM, TDM, WDM).
  5. Calculer le débit maximum théorique d'un canal (théorème de Shannon/Nyquist — notions).

1. Rôle de la couche Physique

La couche Physique (Layer 1) du modèle OSI assure :

Fonction Description
Transmission des bits Convertir les données numériques en signal physique
Spécification mécanique Connecteurs, broches (RJ-45, fibre LC/SC)
Spécification électrique/optique Tensions, niveaux lumineux, fréquences
Spécification fonctionnelle Quand émettre, quand recevoir

La couche Physique ne connaît ni adresses, ni protocoles : elle transmet des 0 et 1.

2. Supports de transmission guidés

Les signaux se propagent le long d'un média physique :

2.1 Paire torsadée (Twisted Pair)

Caractéristique Détail
Composition Deux fils de cuivre isolés, torsadés par paires
Catégories Cat 5e (1 Gbps/100m), Cat 6 (1 Gbps/100m), Cat 6a (10 Gbps/100m), Cat 7 (10 Gbps)
Connecteur RJ-45 (8 broches)
Types UTP (Unshielded) — le plus courant ; STP (Shielded) — environnements bruyants
Usage LAN Ethernet, téléphonie, câblage bâtiment

Standards Ethernet sur paire torsadée :

Standard Débit Câble Distance max
10Base-T 10 Mbps Cat 3+ 100 m
100Base-TX 100 Mbps Cat 5+ 100 m
1000Base-T 1 Gbps Cat 5e+ 100 m
10GBase-T 10 Gbps Cat 6a+ 100 m

Pourquoi torsader ? Réduit les interférences électromagnétiques (diaphonie / crosstalk).

2.2 Câble coaxial

Caractéristique Détail
Structure Conducteur central + blindage + gaine extérieure
Usage historique Ethernet 10Base2 (fine), 10Base5 (épaisse), TV câble
Usage actuel Fournisseurs d'accès (DOCSIS — Internet par câble), antennes

2.3 Fibre optique

Caractéristique Détail
Principe Transmission par impulsions lumineuses (LED ou laser)
Types Monomode (SMF) — longues distances, haut débit ; Multimode (MMF) — courtes distances
Connecteurs SC, LC, ST
Avantages Très haut débit (Tbps), faible atténuation, immunité EMI, sécurité
Inconvénients Coût, fragilité, expertise d'installation
Usage Backbone WAN, inter-datacenters, FTTH (fibre jusqu'au domicile)
Comparaison Paire torsadée Fibre optique
Débit max 10 Gbps (Cat 6a) 100+ Tbps (WDM)
Distance 100 m Kilomètres
Coût Faible Élevé
Interférences EMI Sensible Insensible
Sécurité (écoute) Possible Difficile

3. Supports de transmission non guidés

Le signal se propage dans l'atmosphère ou le vide (ondes électromagnétiques) :

Média Fréquence Portée Usage
Ondes radio 3 kHz – 1 GHz km Radio AM/FM, 4G/5G
Micro-ondes 1 – 300 GHz km (ligne de vue) Liaisons point-à-point, satellite
Infrarouge 300 GHz – 400 THz Quelques mètres Télécommandes, IrDA (obsolète)
Wi-Fi (802.11) 2,4 / 5 / 6 GHz ~50–100 m LAN sans fil
Bluetooth 2,4 GHz ~10 m PAN

Standard Bande Débit théorique max

802.11g 2,4 GHz 54 Mbps
802.11n (Wi-Fi 4) 2,4/5 GHz 600 Mbps

4. Représentation et codage des données

4.1 Types de données

Type Description Exemple
Analogique Signal continu, amplitude variable Voix, vidéo analogique
Numérique Signal discret (0 et 1) Données informatiques

La couche Physique transmet des données numériques sous forme de signaux numériques ou analogiques modulés.

4.2 Techniques de codage en bande de base

Le codage définit comment représenter les bits sur le média :

Codage Principe Usage
NRZ (Non-Return to Zero) 0 = bas, 1 = haut Simple, mais problème de synchronisation
Manchester Transition au milieu du bit (0 = ↑, 1 = ↓) Ethernet 10Base-T, auto-synchronisation
4B/5B 4 bits → 5 bits (équilibrage) Fast Ethernet 100Base-TX
8B/10B 8 bits → 10 bits Gigabit Ethernet, Fibre Channel 
NRZ :        ───┐   ┌───────┐
                 └───┘       └───

Manchester :  ┌─┐ ┌─┐ ┌─┐ ┌─┐
              │ └─┘ └─┘ └─┘ └─  (transitions = bits)

4.3 Modulation (transmission analogique)

Pour transmettre sur des canaux analogiques (radio, câble TV), on module un signal porteur :

Modulation Principe Usage
ASK (Amplitude) Amplitude varie selon le bit RFID, anciens modems
FSK (Fréquence) Fréquence varie selon le bit Modems téléphoniques
PSK (Phase) Phase varie selon le bit Wi-Fi, DSL, satellite
QAM (Amplitude + Phase) Combinaison Wi-Fi, 4G/5G, câble

5. Multiplexage

Le multiplexage permet de partager un même canal entre plusieurs communications :

Technique Sigle Principe Analogie Usage
Fréquence FDM Chaque signal sur une bande de fréquence différente Radios sur fréquences différentes Radio, TV analogique, ADSL
Temporel TDM Chaque signal a un créneau temporel Tour de parole Téléphonie numérique, E1/T1
Longueur d'onde WDM Plusieurs longueurs d'onde sur une fibre — Fibre optique (DWDM)
Code CDM Code unique par utilisateur — CDMA (3G) 
FDM :  ──[f1]──[f2]──[f3]──  →  Un canal, fréquences séparées

TDM :  ──[A][B][A][B][A][B]──  →  Un canal, créneaux alternés

6. Caractéristiques des canaux

6.1 Bande passante et débit

  • Bande passante (B) : étendue de fréquences du canal (Hz).
  • Théorème de Nyquist (canal sans bruit) :

$$C_{max} = 2B \log_2(V) \text{ bps}$$

où V = nombre de niveaux de signal.

  • Théorème de Shannon (canal avec bruit) :

$$C_{max} = B \log_2(1 + SNR) \text{ bps}$$

où SNR = rapport signal/bruit (linéaire, pas en dB).

6.2 Atténuation et amplification

  • Atténuation : Affaiblissement du signal avec la distance (dB/km).
  • Répéteur (L1) : Régénère le signal (bit par bit).
  • Amplificateur : Amplifie le signal analogique (amplifie aussi le bruit).

6.3 Débit vs distance

Média Débit ↑ → Distance…
Paire torsadée ↓ diminue
Fibre optique Peu affectée sur des centaines de km
Wi-Fi ↓ diminue fortement

7. Examples concrets

Exemple 1 — Choix du câble pour un laboratoire Université de Mostaganem

Besoin : Câbler 24 postes à 1 Gbps, distance max 80 m du switch.

Solution : Câble Cat 6 UTP, connecteurs RJ-45, standard 1000Base-T.

Exemple 2 — Calcul Shannon simplifié

Énoncé : Canal de bande passante B = 4 kHz, SNR = 31 (linéaire). Débit max ?

Solution : $$C = 4000 \times \log_2(1 + 31) = 4000 \times \log_2(32) = 4000 \times 5 = 20\,000 \text{ bps} = 20 \text{ kbps}$$
