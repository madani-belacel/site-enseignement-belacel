1. Module Overview

The Networks (UEF422) module introduces students of the ISIL program (Computer Science: Information Systems and Software) to the fundamentals of computer networks. It covers the layered architecture, essential protocols (Ethernet, IP, TCP/UDP, DNS, HTTP) and basic LAN configuration.

After completing the module, the student will be able to understand, analyze and configure a simple local network, in direct relation with the Operating Systems, Web Programming and Databases modules.

2. Learning Objectives

After completing this module, the student will be able to:

  1. Define fundamental networking concepts: topologies, network types, performance metrics.
  2. Explain the OSI layered model and the TCP/IP stack, as well as the encapsulation mechanism.
  3. Describe how the physical, data link, network, transport and application layers work.
  4. Analyze an IPv4 address, subnet mask and simple static routing table.
  5. Compare TCP and UDP protocols and identify their uses.
  6. Identify the role of network equipment (switch, router, firewall) in a LAN/WAN architecture.
  7. Configure a simple topology in Packet Tracer and verify connectivity.
  8. Capture and interpret network frames with Wireshark (beginner level).

Note: No prior networking experience is required. Familiarity with the Windows/Linux command line is a plus.

Ch. Intitulé Points clés
01 Introduction et topologies PAN, LAN, MAN, WAN ; bus, étoile, anneau, maillée ; débit, latence, gigue
02 Modèle OSI vs TCP/IP 7 vs 4 couches ; correspondance ; encapsulation/désencapsulation
03 Couche Physique UTP, fibre optique, Wi-Fi ; NRZ, Manchester ; FDM/TDM/WDM

07 Couche Application DNS (résolution) ; HTTP/1.1 ; HTTPS/TLS ; FTP, SMTP (aperçu)
