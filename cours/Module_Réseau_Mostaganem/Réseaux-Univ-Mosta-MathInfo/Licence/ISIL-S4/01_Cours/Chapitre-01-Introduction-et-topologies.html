Objectifs du chapitre

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Définir un réseau informatique et en identifier les composants (hôtes, liens, équipements).
  2. Distinguer les types de réseaux : PAN, LAN, MAN, WAN.
  3. Décrire et comparer les topologies physiques et logiques (bus, étoile, anneau, maillée).
  4. Expliquer les métriques de performance : débit, bande passante, latence, gigue, perte de paquets.
  5. Situer le rôle de l'Internet et des FAI (Fournisseurs d'Accès Internet) dans l'architecture globale.

1. Qu'est-ce qu'un réseau informatique ?

1.1 Définition

Un réseau informatique est un ensemble d'équipements informatiques (appelés nœuds ou hôtes) interconnectés par des liens de communication, permettant l'échange de données sous forme de messages numériques.

┌─────────┐         ┌─────────┐         ┌─────────┐
│  Hôte A │─────────│ Switch  │─────────│  Hôte B │
│ (PC)    │  Lien   │         │  Lien   │ (Serveur│
└─────────┘         └─────────┘         └─────────┘

Composants essentiels :

Composant Rôle Exemple
Hôte (Host) Émetteur ou récepteur de données PC, smartphone, serveur
Lien (Link) Support de transmission Câble cuivre, fibre, onde radio
Équipement intermédiaire Relais, commutation, routage Switch, routeur, point d'accès Wi-Fi
Protocole Règles de communication TCP/IP, Ethernet, HTTP

1.2 Pourquoi mettre en réseau ?

Objectif Bénéfice Exemple Université de Mostaganem
Partage de ressources Imprimante, stockage centralisé Salles informatiques MathInfo
Communication Email, messagerie, visioconférence Plateforme pédagogique
Accès à l'information Bases de données, bibliothèque en ligne Portail étudiant Université de Mostaganem
Fiabilité Redondance, sauvegarde distante Serveurs miroirs
Évolutivité Ajout de nœuds sans refonte totale Extension d'un laboratoire

2. Types de réseaux

Les réseaux se classent généralement par étendue géographique :

Type Sigle Portée Débit typique Exemple
Personal Area Network PAN ~10 m Bluetooth, USB Montre ↔ smartphone
Local Area Network LAN Bâtiment / campus 100 Mbps – 10 Gbps Réseau faculté MathInfo
Metropolitan Area Network MAN Ville 1 – 10 Gbps Réseau métropolitain d'Oran
Wide Area Network WAN Pays / monde Variable (Mbps – Tbps) Internet, liaisons opérateurs

2.1 LAN — Local Area Network

  • Couvre une zone géographique limitée (bureau, campus universitaire).
  • Propriété généralement privée (entreprise, université).
  • Technologies courantes : Ethernet (cuivre/fibre), Wi-Fi (IEEE 802.11).

2.2 WAN — Wide Area Network

  • Interconnecte des LAN distants sur de longues distances.
  • Utilise des liens d'opérateurs télécom (fibre longue distance, MPLS, satellite).
  • Internet est le plus grand WAN public au monde.

2.3 Intranet, Extranet, Internet

Concept Description Accès
Intranet Réseau privé interne utilisant les protocoles Internet Employés / étudiants uniquement
Extranet Extension de l'intranet à des partenaires externes Partenaires autorisés
Internet Réseau public mondial interconnecté Public (avec FAI)

3. Topologies physiques et logiques

3.1 Distinction physique / logique

Topologie Définition
Physique Disposition réelle des câbles et équipements
Logique Chemin que suivent les données (peut différer de la physique)

3.2 Topologies physiques classiques

a) Topologie Bus

PC1 ─── PC2 ─── PC3 ─── PC4
         │
    ═════╧═════  ← câble coaxial (bus partagé)
Avantage Inconvénient
Simple, peu de câble Point unique de défaillance (câble principal)
Facile à étendre Collisions si trafic élevé (half-duplex)

Historique : Utilisée avec Ethernet 10Base2/10Base5. Obsolète aujourd'hui.

b) Topologie Étoile (Star) ⭐ La plus courante

        PC1
         │
PC2 ─── Switch ─── PC3
         │
        PC4
Avantage Inconvénient
Panne d'un lien n'affecte qu'un seul hôte Point central (switch) critique
Performances élevées (full-duplex) Plus de câblage
Facile à administrer —

C'est la topologie standard des LAN Ethernet modernes.

c) Topologie Anneau (Ring)

PC1 ── PC2
 │       │
PC4 ── PC3
  • Chaque nœud est connecté à deux voisins formant un cercle.
  • Token Ring (IBM) : obsolète. FDDI (fibre) encore mentionné historiquement.

d) Topologie Maillée (Mesh)

PC1 ─────── PC2
 │ ╲      ╱ │
 │   ╲  ╱   │
 │    ╳     │
 │  ╱  ╲    │
 │╱     ╲   │
PC4 ─────── PC3
Type Description Usage
Maillée totale Chaque nœud connecté à tous les autres Coûteux ; réservé aux nœuds critiques
Maillée partielle Plusieurs chemins redondants Internet, réseaux opérateurs

3.3 Tableau comparatif des topologies

Topologie Fiabilité Coût Scalabilité Usage actuel
Bus Faible Faible Moyenne ❌ Obsolète
Étoile Bonne Moyen Excellente ✅ LAN standard
Anneau Moyenne Moyen Limitée ⚠️ Rare
Maillée Excellente Élevé Excellente ✅ WAN / cœur réseau

4. Métriques de performance

4.1 Bande passante (Bandwidth)

  • Définition : Capacité maximale théorique d'un lien, exprimée en bits par seconde (bps).
  • Exemples : 100 Mbps (Fast Ethernet), 1 Gbps (Gigabit Ethernet), 10 Gbps.
Unité Valeur
1 Kbps 10³ bits/s
1 Mbps 10⁶ bits/s
1 Gbps 10⁹ bits/s
1 Tbps 10¹² bits/s

⚠️ Attention : En informatique réseau, on utilise le bit (b minuscule), pas l'octet (B majuscule). 100 Mbps = 100 × 10⁶ bits/s ≈ 12,5 Mo/s (octets/s).

4.2 Débit (Throughput)

  • Définition : Quantité de données effectivement transmises par unité de temps.
  • Le débit réel est toujours ≤ bande passante (overhead des en-têtes, collisions, congestion).

$$\text{Débit utile} = \text{Bande passante} \times \text{Efficacité du protocole}$$

4.3 Latence (Delay / RTT)

  • Définition : Temps nécessaire pour qu'un bit traverse le réseau (de la source à la destination).
  • Composantes :
  • Délai de propagation : temps de parcours du signal dans le média
  • Délai de transmission : temps pour placer tous les bits sur le lien
  • Délai de traitement : temps de traitement dans les équipements
  • Délai de mise en file (queuing) : attente dans les buffers

$$\text{Latence totale} = t_{prop} + t_{trans} + t_{proc} + t_{file}$$

RTT (Round-Trip Time) : temps aller-retour d'un paquet (mesuré par ping).

4.4 Gigue (Jitter)

  • Définition : Variation de la latence entre paquets consécutifs.
  • Critique pour la VoIP (Voix sur IP) et le streaming vidéo.

4.5 Perte de paquets (Packet Loss)

  • Pourcentage de paquets non livrés à destination.
  • Causes : congestion, erreurs de transmission, buffer overflow.
  • Mesurée par des outils comme ping (statistiques) ou Wireshark.
Métrique Impact sur… Outil de mesure
Bande passante Transfert de gros fichiers iperf, speedtest
Latence Jeux en ligne, requêtes web ping
Gigue VoIP, visioconférence Wireshark
Perte Qualité streaming, TCP ping, netstat

5. Architecture Internet et modèle de service

5.1 Structure en « réseau de réseaux »

Internet n'est pas un réseau unique mais un internetwork : interconnexion de milliers de réseaux autonomes (AS — Autonomous Systems) opérés par des FAI, universités, entreprises, gouvernements.

Niveau Acteur Rôle
Tier 1 Grands opérateurs internationaux Interconnexion mondiale, peering
Tier 2 Opérateurs régionaux/nationaux Agrégation, transit
Tier 3 / FAI local FAI accès (Algérie Télécom, etc.) Connexion des abonnés
Client final Entreprise, université, particulier LAN, utilisateurs

5.2 Modèle client-serveur vs pair-à-pair (P2P)

Modèle Principe Exemple
Client-Serveur Serveur central fournit un service à de nombreux clients Web (HTTP), email (SMTP)
Pair-à-pair (P2P) Chaque nœud est client ET serveur BitTorrent, certaines applications de partage

6. Exemples concrets

Exemple 1 — Réseau d'une salle informatique Université de Mostaganem

Contexte : Salle de TP MathInfo avec 20 PC, 1 imprimante réseau, connexion Internet.

Élément Détail
Topologie Étoile (switch central 24 ports)
Type LAN Ethernet 1 Gbps
Accès Internet Routeur/pare-feu → FAI universitaire
Adressage IPv4 privées (192.168.x.x) + NAT vers Internet

Exemple 2 — Connexion domicile à Internet

[PC/Smartphone] ──Wi-Fi── [Box/Routeur] ──DSL/Fibre── [FAI] ── Internet
  1. Le PC obtient une adresse IP via DHCP (attribuée par la box).
  2. La box effectue du NAT (Network Address Translation) pour accéder à Internet avec une seule IP publique.
  3. Le FAI route les paquets vers le reste d'Internet.

Exemple 3 — Calcul de temps de transfert

Énoncé : Transférer un fichier de 50 Mo sur un lien de 100 Mbps. Quel est le temps de transmission minimum ?

Solution : - Taille = 50 Mo = 50 × 8 = 400 Mbits - Bande passante = 100 Mbps - Temps minimum = 400 / 100 = 4 secondes (sans tenir compte du overhead TCP/IP)

Exercice 1 : Un réseau a une bande passante de 1 Gbps. Quel est le temps minimum pour transmettre 2 Go de données ?

Solution 2 Go = 2 × 8 = 16 Gbits = 16 000 Mbits Temps = 16 000 / 1 000 = **16 secondes**
