TP 04 — Configuration IPv6

Attribute Value
Level Bachelor SI — S5
Estimated duration 3 h
Outil Packet Tracer
Chapters associés Ch. 06

Objectives

  • Configurer adresses IPv6 global unicast et link-local
  • Activer routage IPv6 et ping6 entre LAN
  • Observer SLAAC sur PC

Partie 1 — Topology

PC1 ── SW ── R1 ── 2001:DB8:ACAD:1::/64 (LAN1)
              |
              └── 2001:DB8:ACAD:2::/64 (LAN2) ── PC2
Équipement IPv6 GW
R1 G0/0 2001:DB8:ACAD:1::1/64 —
R1 G0/1 2001:DB8:ACAD:2::1/64 —
PC1 SLAAC ou 2001:DB8:ACAD:1::10/64 FE80::1 ou ::1
PC2 2001:DB8:ACAD:2::10/64 2001:DB8:ACAD:2::1

Partie 2 — Consignes

Étape 1 — Activer IPv6 (30 min)

ipv6 unicast-routing
interface g0/0
 ipv6 address 2001:DB8:ACAD:1::1/64
 ipv6 nd other-config-flag
 no shutdown

Étape 2 — PC configuration (45 min)

  1. PC1 : auto config IPv6 (SLAAC) ou statique.
  2. PC2 : statique 2001:DB8:ACAD:2::10/64, GW ::1.
  3. ipv6 route statique ou OSPFv3 (option avancée).

Étape 3 — Tests (60 min)

ping 2001:DB8:ACAD:2::10
ping FE80::... (link-local)
show ipv6 interface brief

Étape 4 — Dual-stack (45 min)

Ajouter IPv4 192.168.1.0/24 parallèle ; ping v4 et v6.

Partie 3 — Vérifications

Test Résultat attendu
ping global unicast Succès inter-LAN
show ipv6 route Préfixes connectés
link-local ping FE80 avec interface %

Partie 4 — Questions de bilan

  1. Différence global unicast vs link-local ?
  2. Que fait SLAAC sans DHCPv6 ?
  3. Pourquoi /64 systématique sur LAN ?

Annexe — Corrigé

ipv6 route 2001:DB8:ACAD:2::/64 2001:DB8:ACAD:2::1

SLAAC : PC reçoit RA prefix 2001:DB8:ACAD:1::/64.
