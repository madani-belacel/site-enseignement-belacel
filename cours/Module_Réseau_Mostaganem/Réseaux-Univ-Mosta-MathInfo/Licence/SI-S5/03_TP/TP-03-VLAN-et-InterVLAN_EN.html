TP 03 — VLAN et inter-VLAN

Attribute Value
Level Bachelor SI — S5
Estimated duration 3 h
Outil Packet Tracer
Chapters associés Ch. 04

Objectives

  • Créer VLAN 10 (Admin) et VLAN 20 (Invités) sur switch
  • Configurer trunk 802.1Q et router-on-a-stick
  • Tester isolation broadcast et routage inter-VLAN

Partie 1 — Topology

PC-Admin (VLAN10) ──┐
                    ├── SW1 ── trunk Fa0/24 ── R1 (G0/0.10, G0/0.20)
PC-Guest (VLAN20) ──┘
Équipement VLAN IP GW
PC-Admin 10 192.168.10.10/26 192.168.10.1
PC-Guest 20 192.168.20.10/26 192.168.20.1
R1 G0/0.10 10 192.168.10.1/26 —
R1 G0/0.20 20 192.168.20.1/26 —

Partie 2 — Consignes

Étape 1 — VLAN switch (45 min)

vlan 10
 name ADMIN
vlan 20
 name GUEST
interface range fa0/1-2
 switchport mode access
 switchport access vlan 10
interface fa0/3
 switchport mode access
 switchport access vlan 20

Étape 2 — Trunk + router-on-a-stick (60 min)

interface fa0/24
 switchport mode trunk
 switchport trunk allowed vlan 10,20

Sur R1 :

interface g0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.192
interface g0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.192

Étape 3 — Tests (45 min)

  1. ping intra-VLAN (même VLAN, 2 PC).
  2. ping inter-VLAN Admin → Guest.
  3. Simulation : broadcast ARP ne traverse pas VLAN.

Étape 4 — Security (30 min)

Tenter ping Guest → Admin ; discuter ACL future.

Partie 3 — Vérifications

Test Résultat attendu
show vlan brief VLAN 10, 20, ports corrects
show interfaces trunk Fa0/24 trunking
ping inter-VLAN Succès via R1
ping intra-VLAN isolé OK sans router

Partie 4 — Questions de bilan

  1. Pourquoi inter-VLAN nécessite un router ou switch L3 ?
  2. Role du tag 802.1Q sur le trunk ?
  3. Alternative au router-on-a-stick ?

Annexe — Corrigé

Switch L3 avec SVI interface vlan10 / vlan20 + ip routing.

Livrables

  • .pkt + schéma VLAN + réponses 3 questions
