TD 06 — IPv6

Attribut Valeur
Niveau Licence SI — S5
Durée estimée 2 h
Chapitres associés Ch. 06

Objectifs

  • Lire/écrire adresses IPv6 (compression RFC 5952)
  • Identifier link-local, global unicast, multicast
  • Comparer SLAAC, DHCPv6 et dual-stack

Exercice 1 — Notation (6 pts)

Écrire en forme compressée :

a) 2001:0DB8:0000:0000:0000:0000:0000:0001

b) FE80:0000:0000:0000:0202:B3FF:FE1E:8329

c) 2001:DB8:0:0:1:0:0:1

Décompresser : d) 2001:DB8::ACAD:1

Exercice 2 — Types d'adresses (5 pts)

Exercice 3 — ND et SLAAC (5 pts)

  1. Quel protocole IPv6 remplace ARP ?
  2. Étapes SLAAC sur un LAN /64 (RS, RA, autoconfig).
  3. Différence stateless vs stateful DHCPv6.
  4. Pourquoi /64 est standard pour un LAN IPv6 ?

Exercice 4 — Transition (4 pts)

a) Dual-stack : avantages/inconvénients.

b) Tunnel 6to4 (principe — sans config détaillée).

c) Un serveur n'a que IPv4 ; client dual-stack accède comment (DNS AAAA absent) ?

Annexe — Corrigé TD 06

Exercice 3

  1. NDP (Neighbor Discovery). 2. RS → RA prefix → autoconfig EUI-64. 3. SLAAC sans serveur vs DHCPv6 avec état. 4. SLAAC EUI-64 basé sur 64 bits interface ID.

Exercice 4

a) Coexistence v4/v6, double gestion. b) Encapsulation IPv6 dans IPv4. c) Fallback IPv4 (A record).
