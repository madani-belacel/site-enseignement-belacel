TD 08 — Applications et services

Attribut Valeur
Niveau Licence SI — S5
Durée estimée 2 h
Chapitres associés Ch. 08

Objectifs

  • Analyser résolution DNS récursive/itérative
  • Comparer HTTP/1.1 et HTTP/2 (multiplexage)
  • Configurer DHCP relay et comprendre enregistrements DNS

Exercice 1 — DNS (6 pts)

Requête www.univ-mosta.dz depuis PC campus (résolveur 8.8.8.8).

a) Ordre des serveurs consultés (récursif vs itératif).

b) Types A, AAAA, MX, CNAME — exemple each.

c) TTL = 3600 : impact changement IP serveur web.

Exercice 2 — HTTP/TLS (5 pts)

  1. Différence HTTP et HTTPS (couche, port, certificat).
  2. HTTP/2 : multiplexage sur une connexion TCP — avantage.
  3. Citer 3 codes statut : 200, 301, 404 — signification.

Exercice 3 — DHCP (5 pts)

Serveur DHCP VLAN 10 ; clients VLAN 20 (autre subnet).

a) Pourquoi ip helper-address sur switch L3 ?

b) Séquence DORA en 4 étapes.

c) Option 3 (router) et option 6 (DNS) — rôle.

Exercice 4 — Cas pratique (4 pts)

Site https://inscription.univ-mosta.dz inaccessible ; nslookup OK ; ping OK ; navigateur timeout.

  1. 3 causes possibles (L7).
  2. Commande curl -v — que vérifier ?

Annexe — Corrigé TD 08

a) PC → résolveur récursif → racine → TLD .dz → serveur autoritaire. b) A=IPv4, AAAA=IPv6, MX=mail, CNAME=alias. c) Cache 1 h — délai propagation.

Exercice 2

  1. HTTPS = HTTP + TLS port 443 + cert X.509. 2. Plusieurs requêtes parallèles sans head-of-line blocking HTTP/1.1. 3. OK / redirection permanente / not found.

Exercice 3

a) Relay broadcast DHCP inter-VLAN. b) Discover, Offer, Request, Ack. c) GW par défaut ; serveurs DNS.

Exercice 4

  1. Pare-feu 443, certificat expiré, SNI/virtual host. 2. Handshake TLS, cert, HTTP status.
