Chapter Objectives

After completing this chapter, the student will be able to:

  1. Lire et écrire des adresses IPv6 (notation complète, compressée, mixte).
  2. Identifier les types d'adresses IPv6 (unicast global, link-local, ULA, multicast).
  3. Expliquer Neighbor Discovery (ND) et SLAAC.
  4. Décrire les mécanismes de transition (dual-stack, tunneling).
  5. Configurer une adresse IPv6 de base dans Packet Tracer.

1. Motivations IPv6

Problème IPv4 Solution IPv6
Épuisement adresses (~4,3 × 10⁹) 128 bits ≈ 3,4 × 10³⁸ adresses
NAT complexifie architecture Adressage de bout en bout
En-tête complexe En-tête simplifié (40 octets fixe)
Pas de sécurité native IPsec prévu (peu déployé en pratique)

2. Notation des adresses

2.1 Format

  • 128 bits = 8 groupes de 16 bits en hexadécimal, séparés par :
  • Example : 2001:0DB8:0000:0000:0000:FF00:0042:8329

2.2 Règles de compression (RFC 5952)

Règle Example
Supprimer zéros leading par groupe 2001:DB8:0:0:0:FF00:42:8329
Une seule séquence :: pour groupes de zéros 2001:DB8::FF00:42:8329
IPv4-mapped (transition) ::FFFF:192.0.2.1

2.3 Préfixe CIDR

Identique à IPv4 : 2001:DB8:ACAD:1::/64 — typiquement /64 par sous-réseau LAN.

Longueur Usage
/32 Opérateur — agrégation
/48 Site / entreprise
/64 Sous-réseau LAN standard
/128 Hôte (loopback, serveur)

3. Types d'adresses

Type Préfixe Usage
Global Unicast 2000::/3 Internet routable
Link-Local FE80::/10 Segment local (pas routé)
Unique Local (ULA) FC00::/7 (FD00::/8) Privé (comme RFC 1918)
Multicast FF00::/8 Un-à-plusieurs
Loopback ::1/128 Équivalent 127.0.0.1
Non spécifié ::/128 Source invalide (DHCP)

Pas de broadcast en IPv6 → remplacé par multicast.

Adresses spéciales

Adresse Role
::1 Loopback
FE80::1 (typique GW link-local) Passerelle link-local
FF02::1 Tous les nœuds (multicast)
FF02::2 Tous les routers

4. En-tête IPv6

Champ Taille Role
Version 4 bits 6
Traffic Class 8 bits QoS (≈ ToS IPv4)
Flow Label 20 bits Flux identifiable
Payload Length 16 bits Taille données
Next Header 8 bits Protocol L4 ou extension
Hop Limit 8 bits ≈ TTL IPv4
Source Address 128 bits
Destination Address 128 bits

Pas de fragmentation en router (PMTUD obligatoire). En-têtes extension pour IPsec, routing, etc.

ICMPv6 (protocole 58) : remplace ICMPv4 + intègre ND (Neighbor Discovery).

5. Neighbor Discovery (ND) — RFC 4861

Équivalent IPv6 de ARP + ICMP redirect + router discovery.

Message ND Équivalent IPv4 Role
NS (Neighbor Solicitation) ARP Request Qui a cette adresse ?
NA (Neighbor Advertisement) ARP Reply Je suis ici
RS (Router Solicitation) — Demande routers
RA (Router Advertisement) — Annonce préfixe, flags 
sequenceDiagram
    participant H as Hôte
    participant R as Routeur
    H->>R: RS (Multicast FF02::2)
    R->>H: RA (Préfixe /64, flags M/O)
    H->>H: SLAAC ou DHCPv6
    H->>R: NS (DAD — Duplicate Address Detection)

SLAAC (Stateless Address Autoconfiguration)

  1. Hôte reçoit RA avec préfixe /64.
  2. Construit son adresse : préfixe + Interface ID (EUI-64 ou aléatoire privé).
  3. DAD : vérifie unicité sur le lien.
Flag RA Signification
M (Managed) Utiliser DHCPv6 pour adresse
O (Other) DHCPv6 pour autres infos (DNS)
Aucun SLAAC pur

6. DHCPv6 (aperçu)

Mode Description
Stateful Serveur attribue adresse (comme DHCPv4)
Stateless Adresse via SLAAC ; DHCPv6 fournit DNS, domaine

Ports : UDP 546 (client), 547 (serveur).

8. Configuration (Cisco IOS — aperçu)

ipv6 unicast-routing
interface GigabitEthernet0/0
 ipv6 address 2001:DB8:ACAD:1::1/64
 ipv6 nd other-config-flag
 ipv6 dhcp server LAN-V6
!
ipv6 dhcp pool LAN-V6
 address prefix 2001:DB8:ACAD:1::/64
 dns-server 2001:DB8:ACAD:1::53

PC Packet Tracer : Desktop → IP Configuration → section IPv6.

9. Exercices

Exercice 1 : Compresser 2001:0DB8:0000:0000:0000:0000:0000:0001

Solution **2001:DB8::1**

Exercice 2 : Type de FE80::A1B2:C3FF:FE00:1234 ?

Solution **Link-local** (FE80::/10)

Exercice 3 : Pourquoi /64 est-il standard pour un LAN IPv6 ?

Solution SLAAC EUI-64 utilise 64 bits pour Interface ID ; fragmentation SLAAC et ND conçus pour /64.
