Chapter Objectives

After completing this chapter, the student will be able to:

  1. Comparer les supports de transmission (cuivre, fibre, sans fil) pour un cahier des charges.
  2. Expliquer les mécanismes de détection et correction d'erreurs (CRC, FEC).
  3. Appliquer les normes de câblage structuré (TIA/EIA-568).
  4. Diagnostiquer des problèmes physiques (diaphonie, atténuation, mauvais câble).

3. Erreurs, bruit et intégrité

3.1 Types d'erreurs

Type Cause Couche concernée
Atténuation Distance, fréquence L1
Diaphonie (NEXT/FEXT) Paires adjacentes L1
EMI/RFI Interférences extérieures L1
Collisions Half-duplex (legacy) L2
Erreurs de trame Bruit, mauvais câble L2 (FCS/CRC)

3.2 Détection vs correction

Mechanism Couche Principle
Parité L2 (legacy) Bit de parité
CRC-32 (FCS) L2 Ethernet Polynôme — détection uniquement
FEC L1 (Wi-Fi, 5G) Correction sans retransmission
Retransmission TCP L4 Si perte détectée (L2/L3)

Trame Ethernet corrompue → switch/NIC silencieusement discard → TCP retransmet.

3.3 Taux d'erreur (BER)

$$\text{BER} = \frac{\text{bits erronés}}{\text{bits transmis}}$$

BER Qualité
10⁻⁹ Acceptable cuivre Ethernet
10⁻¹² Fibre optique typique

5. Exercices

Exercice 1 : Un lien Cat 5e affiche 100 Mbps au lieu de 1 Gbps. Citez 3 causes possibles couche 1–2.

Solution 1. Câble Cat 5 (pas 5e) ou câble endommagé 2. Port configuré en 100 Mbps forcé 3. Mauvaise terminaison / paire coupée 4. Auto-négociation échouée (half-duplex)

Exercice 2 : Calculer le temps de transmission d'un paquet de 1500 octets sur un lien 1 Gbps (couche 1 uniquement).

Solution 1500 × 8 = 12 000 bits → 12 000 / 10⁹ = **12 μs**
