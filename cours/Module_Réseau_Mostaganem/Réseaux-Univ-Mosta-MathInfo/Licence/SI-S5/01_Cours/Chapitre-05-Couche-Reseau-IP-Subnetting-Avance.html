Chapitre 05 — Couche Réseau : IP et subnetting avancé

Attribut Valeur
Niveau Licence SI — L3
Semestre S5
Durée estimée 6 h CM (+ TD 05, TP 02)
Chapitre 05 / 09
Références [KR] Ch. 4 ; RFC 1918, RFC 3022

Objectifs du chapitre

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Concevoir un plan d'adressage VLSM optimisé pour une topologie multi-réseaux.
  2. Calculer rapidement réseau, broadcast, plage hôtes pour tout masque CIDR.
  3. Configurer et expliquer NAT et PAT (overload).
  4. Agréger des routes (route summarization) pour simplifier les tables de routage.
  5. Configurer le routage statique avancé et la passerelle par défaut.

Plan du chapitre

  1. CIDR et VLSM — principes
  2. Méthode de calcul VLSM
  3. NAT et PAT
  4. Agrégation de routes (supernetting)
  5. Routage statique avancé
  6. Cas pratique complet
  7. Exercices et QCM

1. CIDR et VLSM

1.1 Limite du subnetting classique (FLSM)

FLSM (Fixed Length Subnet Mask) : même masque pour tous les sous-réseaux → gaspillage d'adresses.

Exemple : besoin de 3 réseaux de 30, 30 et 60 hôtes avec /26 partout → 3 × 62 = 186 adresses pour 120 hôtes.

1.2 VLSM (Variable Length Subnet Mask)

Attribuer un masque adapté à chaque sous-réseau :

Réseau Hôtes requis Masque optimal Capacité
LAN A 60 /26 62
LAN B 30 /27 30
LAN C 14 /28 14
Lien P2P 2 /30 2

1.3 Table de référence CIDR (à connaître)

CIDR Masque Hôtes CIDR Masque Hôtes
/24 255.255.255.0 254 /28 255.255.255.240 14
/25 255.255.255.128 126 /29 255.255.255.248 6
/26 255.255.255.192 62 /30 255.255.255.252 2
/27 255.255.255.224 30 /32 255.255.255.255 1 (hôte)

2. Méthode de calcul VLSM

Algorithme (ordre décroissant des besoins)

  1. Lister les réseaux par taille décroissante (plus gros d'abord).
  2. Partir du bloc principal (ex. 192.168.1.0/24).
  3. Allouer le plus grand sous-réseau en premier.
  4. Continuer avec la prochaine adresse réseau disponible.
  5. Vérifier qu'il n'y a pas de chevauchement.

Exemple complet

Bloc : 192.168.100.0/24

Réseau Hôtes Masque Réseau alloué Broadcast Plage hôtes
Siège 100 /25 192.168.100.0/25 .127 .1 – .126
Agence 50 /26 192.168.100.128/26 .191 .129 – .190
Lien R1-R2 2 /30 192.168.100.192/30 .195 .193 – .194
Wi-Fi 20 /27 192.168.100.224/27 .255 .225 – .254

Vérification : blocs contigus sans overlap ✓

Méthode binaire (rappel)

Pour 10.20.30.45/27 : - /27 → masque 255.255.255.224 → incrément 32 - 45 ∈ [32–63] → réseau 10.20.30.32/27

3. NAT et PAT

3.1 Problème

RFC 1918 — adresses privées non routables sur Internet.

3.2 NAT statique

Privée Publique
192.168.1.10 41.105.x.x

Mapping 1:1 — serveurs accessibles depuis Internet.

3.3 PAT / NAT overload

Plusieurs hôtes privés → une seule IP publique via numéros de port :

192.168.1.10:52341 ──┐
192.168.1.20:49152 ──┼──→ [NAT] ──→ 41.105.1.1:port unique ──→ Internet
192.168.1.30:50100 ──┘

Configuration Cisco (aperçu) :

ip nat inside source list 1 interface Gig0/0 overload
access-list 1 permit 192.168.1.0 0.0.0.255
interface Gig0/0
 ip nat outside
interface Gig0/1
 ip nat inside

3.4 Types NAT

Type Mapping Usage
Statique 1 privée ↔ 1 publique Serveur web interne
Dynamique Pool d'IP publiques Rare
PAT (overload) N privées ↔ 1 publique + ports Box, routeur entreprise

3.5 Limites NAT

  • Casse le modèle bout-à-bout (certaines apps : FTP, VoIP, IPsec).
  • Épuisement ports (~64 000 par IP publique).
  • IPv6 réduit le besoin de NAT (Ch. 06).

4. Agrégation de routes (Supernetting)

Résumer plusieurs réseaux contigus en une route :

Routes détaillées Route agrégée
192.168.0.0/24
192.168.1.0/24 → 192.168.0.0/23
(192.168.2.0/24 non inclus si pas contigu)

Règle : agréger uniquement des préfixes contigus alignés sur une frontière de bits.

Bénéfice : tables de routage plus petites, convergence plus rapide.

5. Routage statique avancé

5.1 Route par défaut

ip route 0.0.0.0 0.0.0.0 [next-hop | interface sortie]

5.2 Route flottante (floating static — aperçu)

Route de secours avec distance administrative plus élevée :

ip route 0.0.0.0 0.0.0.0 10.0.0.2 200   ! backup si lien principal down
ip route 0.0.0.0 0.0.0.0 10.0.0.1 1     ! principal
Source route Distance admin (Cisco)
Connecté (C) 0
Statique 1
OSPF 110
BGP externe 20

5.3 Longest prefix match (rappel approfondi)

Paquet vers 192.168.100.50 — table :

Route Match ?
192.168.0.0/16 Oui (général)
192.168.100.0/24 Oui (plus spécifique) ← choisie
0.0.0.0/0 Oui (défaut)

6. Cas pratique — PME Oran

Topologie : Siège + 2 agences + lien Internet

Site VLAN Hôtes Réseau VLSM (depuis 10.10.0.0/16)
Siège 10 200 10.10.0.0/24
Agence 1 20 50 10.10.1.0/26
Agence 2 30 50 10.10.1.64/26
Lien WAN 1 — 2 10.10.255.0/30
Lien WAN 2 — 2 10.10.255.4/30

Routeur siège : NAT PAT vers Internet + routes statiques vers agences.
