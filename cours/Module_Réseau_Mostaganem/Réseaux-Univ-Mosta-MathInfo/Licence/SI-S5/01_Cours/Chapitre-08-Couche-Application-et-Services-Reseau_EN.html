Chapitre 08 — Application Layer et services réseau

Attribute Value

Chapter Objectives

After completing this chapter, the student will be able to:

  1. Configurer et analyser un serveur DNS (zones, enregistrements, résolution récursive).
  2. Comparer HTTP/1.1, HTTP/2 et HTTPS/TLS 1.3.
  3. Expliquer le fonctionnement de DHCP (DORA, relay, options).
  4. Sécuriser les services réseau de base (DNSSEC, DoH — aperçu).

1. DNS avancé

1.1 Architecture rappel

Résolveur → Racine → TLD → Autoritaire → réponse.

1.2 Types d'enregistrements (approfondi)

Type Contenu Example SI
A IPv4 www.univ-mosta.dz → 41.107.x.x
AAAA IPv6 www.univ-mosta.dz → 2001:db8::1
CNAME Alias ftp → www
MX Mail + priorité 10 mail.univ-mosta.dz
NS Serveur autoritaire ns1.univ-mosta.dz
PTR Reverse DNS IP → nom
SOA Autorité zone Serial, refresh, TTL
TXT Texte SPF, DKIM, vérification
SRV Service + port _ldap._tcp

1.3 Zone DNS

Fichier zone (extrait BIND) :

$TTL 86400
@   IN  SOA ns1.univ-mosta.dz. admin.univ-mosta.dz. (
        2025060601  ; Serial
        3600        ; Refresh
        900         ; Retry
        604800      ; Expire
        86400 )     ; Negative TTL
    IN  NS  ns1.univ-mosta.dz.
    IN  A   41.107.50.10
www IN  A   41.107.50.10
    IN  AAAA 2001:db8:acad::10

1.4 DNS caching et TTL

  • Chaque enregistrement a un TTL (Time To Live).
  • Résolveur met en cache jusqu'à expiration → réduit charge serveurs.

1.5 DNS over HTTPS (DoH) — aperçu

  • Requêtes DNS encapsulées dans HTTPS (port 443).
  • Confidentialité : FAI ne voit pas les requêtes DNS en clair.
  • Débat : centralisation vs sécurité.

2. HTTP/2 et HTTPS/TLS

2.1 HTTP/1.1 — limites

  • Head-of-line blocking : une requête lente bloque les suivantes (même connexion keep-alive).
  • Multiples connexions TCP parallèles (6 par domaine) → overhead.

2.2 HTTP/2 (RFC 7540)

Amélioration Description
Multiplexage Plusieurs requêtes/réponses sur 1 connexion TCP
Compression en-têtes HPACK
Priorisation Streams prioritaires
Server Push Serveur envoie ressources anticipées (usage déclinant)
Format binaire Plus efficace que texte HTTP/1.1

2.3 TLS 1.3 (HTTPS)

Étape Action
ClientHello Cipher suites, key share
ServerHello Certificat, paramètres
Handshake 1-RTT (vs 2-RTT TLS 1.2)
Application HTTP chiffré (AES-GCM, ChaCha20)

Port 443 — certificat X.509 signé par CA (Autorité de Certification).

Composant Role
Certificat Lie domaine ↔ clé publique
CA Signe le certificat (Let's Encrypt, DigiCert…)
Clé privée Serveur — jamais exposée

3. DHCP avancé

3.1 Processus DORA (rappel)

Discover → Offer → Request → Acknowledge.

3.2 Options DHCP importantes

Option Code Contenu
Subnet Mask 1 Masque réseau
Router 3 Passerelle par défaut
DNS Servers 6 Serveurs DNS
Domain Name 15 Nom de domaine
Lease Time 51 Durée bail (secondes)
Server Identifier 54 IP serveur DHCP

3.3 DHCP Relay (Agent)

Quand client et serveur DHCP sont sur VLAN/networks différents :

[Client VLAN 10] ── broadcast DHCP ── [Routeur relay] ── unicast ── [Serveur DHCP VLAN 99]
                      Option 82              ip helper-address

interface Vlan10
 ip helper-address 192.168.99.5

3.4 DHCPv6 (lien Ch. 06)

Mode Flags RA Comportement
SLAAC M=0, O=0 Adresse auto
Stateful M=1 DHCPv6 attribue adresse
Stateless O=1 SLAAC + DNS via DHCPv6
