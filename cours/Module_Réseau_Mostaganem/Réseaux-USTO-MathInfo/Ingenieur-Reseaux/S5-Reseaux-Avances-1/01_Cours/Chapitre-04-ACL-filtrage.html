Objectifs pédagogiques

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Rédiger des ACL standard, étendue et nommées (IPv4).
  2. Appliquer ACL sur interfaces et VTY avec ordre de traitement.
  3. Combiner ACL avec NAT/PAT pour politiques d'accès Internet.
  4. Analyser l'impact d'une règle mal placée (implicit deny).
  5. Proposer une stratégie de filtrage par zone (admin, étudiants, serveurs).

1. Principes des ACL

Une ACL filtre paquets selon critères L3/L4. Traitement séquentiel : première correspondance gagne ; deny implicite en fin.

Type Plage Cisco Critères
Standard 1-99, 1300-1999 Source IP
Étendue 100-199, 2000-2699 Source, dest, proto, ports
Nommée ip access-list standard/extended Lisible, modifiable

Wildcard : inverse du masque — 0.0.0.255 = /24 entier.

access-list 101 permit tcp 10.10.20.0 0.0.0.255 host 10.20.1.10 eq 443
access-list 101 deny ip any any

2. ACL étendue — exemples

Politique serveur web interne :

# Action Source Dest Service
10 permit 10.10.0.0/16 10.20.1.10 TCP/443
20 permit 10.20.100.5 10.20.1.10 TCP/80
30 deny any 10.20.1.10 any
— deny implicite

Application :

interface GigabitEthernet0/1
 ip access-group 101 in

Reflexive / CBAC / ZBFW : au-delà du scope S5 (voir S8).

3. NAT et PAT avancé

Mode Usage Commande clé
Static NAT Serveur 1:1 ip nat inside source static
Dynamic NAT Pool adresses publiques ip nat pool
PAT (overload) Sortie Internet masquée overload sur interface 
R1(config)# ip nat inside source list 10 interface GigabitEthernet0/2 overload
R1(config)# access-list 10 permit 10.10.0.0 0.0.255.255
R1(config-if)# ip nat inside   ! LAN
R1(config-if)# ip nat outside  ! WAN

Ordre : ACL définissant trafic traduit → interfaces inside/outside → vérifier show ip nat translations.

4. Cas Université de Mostaganem — segmentation

Scénario : VLAN étudiants (10.10.10.0/24) accède Internet via PAT ; accès SSH admin (10.10.30.0/26) depuis bastion uniquement.

Zone Politique
Étudiants → Internet PAT + deny entrée
Admin → équipements ACL VTY source bastion
Lab → reste campus deny par défaut, permit TP
