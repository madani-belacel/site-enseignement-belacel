Objectifs pédagogiques

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Comparer les algorithmes distance-vecteur et état de liens.
  2. Expliquer convergence, métriques, boucles de routage et split horizon.

  4. Lire une table de routage enrichie (code, AD, métrique).
  5. Choisir le protocole adapté à un scénario campus vs WAN.

Plan du chapitre

  1. Motivations du routage dynamique
  2. Distance-vecteur : RIP, EIGRP (aperçu)
  3. État de liens : OSPF, IS-IS
  4. Métriques, AD, convergence

1. Motivations

Le routage statique convient aux petites topologies stables. Dès que : - le nombre de préfixes croît, - la redondance impose des chemins alternatifs, - les liens varient (WAN, 4G backup),

… un IGP (Interior Gateway Protocol) calcule automatiquement les meilleures routes.

Critère Statique Dynamique
Scalabilité Faible Élevée
Réaction panne Manuelle Automatique (secondes à minutes)
Charge admin Forte si N routes Politique + design areas
Prévisibilité Maximale Dépend du protocole

2. Distance-vecteur

Chaque routeur maintient un vecteur (destination, distance, next-hop) appris des voisins.

Algorithme de Bellman-Ford : métrique = somme des coûts ; risque de compte à l'infini si boucles.

Protocole Métrique max Mise à jour Class
RIPv1/v2 15 sauts 30 s broadcast/multicast DV
EIGRP composite (DUAL) triggered Hybride

Mécanismes anti-boucle : split horizon, route poisoning, hold-down (RIP).

RIP update (simplifié) : "Je connais 192.168.5.0/24 metric 2 via Gi0/1"

3. État de liens (Link-State)

Chaque routeur diffuse son LSA (Link-State Advertisement) ; tous construisent la même carte topologique (SPF/Dijkstra).

Étape OSPF Action
Hello Découverte voisins
DBD / LSR / LSU Sync base états liens
SPF Calcul arbre plus court chemin
Routing table Installation routes O/A/E

Avantages : convergence rapide, pas de compte à l'infini classique, support VLSM natif (OSPF v2).

4. Administrative Distance et tables

L'AD (Administrative Distance) arbitre entre sources concurrentes (plus bas = préféré) :

Source AD Cisco typique
Interface directe 0
Route statique 1
eBGP 20
OSPF 110
RIP 120
