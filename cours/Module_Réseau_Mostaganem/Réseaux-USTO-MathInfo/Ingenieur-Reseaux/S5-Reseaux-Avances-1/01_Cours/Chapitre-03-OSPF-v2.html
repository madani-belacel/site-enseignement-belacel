Objectifs pédagogiques

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Décrire l'architecture OSPF : areas, routeurs ABR/ASBR, types de LSA.
  2. Configurer OSPF single-area et multi-area sur routeurs Cisco.
  3. Interpréter show ip ospf neighbor, show ip route ospf, bases de données LSDB.
  4. Optimiser summarization inter-area et coûts des interfaces.
  5. Dépanner les adjacences (Hello/Dead, DR/BDR, auth).

1. Fondements OSPF

OSPF (Open Shortest Path First) est l'IGP dominant en entreprise et campus.

Paramètre Valeur par défaut Cisco
Métrique coût = 10^8 / bande passante (bps)
Hello 10 s (broadcast/P2P), 30 s (NBMA)
Dead 4 × Hello
Router ID Plus grand IP loopback ou manuel

Types de routeurs : - Internal : une seule area - ABR : connecté à area 0 + autre area - ASBR : redistribution vers BGP/static externe

2. Areas et backbone

La area 0 est obligatoire (backbone). Les areas non-backbone communiquent via l'area 0 uniquement.

        [Area 1]          [Area 0 — Backbone]          [Area 2]
       R1---R2(ABR)-------R3(ABR)---R4-------R5(ABR)---R6
                              |
                            ASBR → BGP
Type LSA Nom Portée Contenu
1 Router Intra-area Liens routeur
2 Network Intra-area Transit multi-access
3 Summary Inter-area Préfixes autres areas
4 ASBR Summary Inter-area Chemin vers ASBR
5 External AS Routes redistribuées

Stub / NSSA : réduire LSAs externes (aperçu S6).

3. Configuration IOS

Exemple multi-area minimal :

R1(config)# router ospf 1
R1(config-router)# router-id 1.1.1.1
R1(config-router)# network 10.1.0.0 0.0.255.255 area 1
R1(config-router)# network 10.0.12.0 0.0.0.3 area 0

R2(config)# router ospf 1
R2(config-router)# router-id 2.2.2.2
R2(config-router)# network 10.0.12.0 0.0.0.3 area 0
R2(config-router)# network 10.2.0.0 0.0.255.255 area 2

Summarization ABR :

R2(config-router)# area 1 range 10.1.0.0 255.255.0.0

4. Dépannage des adjacences

Checklist FULL non atteint :

Cause Vérification
Subnet/masque différent show ip interface
Area ID mismatch config network ... area
Hello/Dead timer doit être identique
Auth MD5 ip ospf message-digest-key
ACL bloque multicast 224.0.0.5 debug ip ospf adj

DR/BDR : élection sur segments broadcast ; sur P2P, pas de DR.

Cas Université de Mostaganem : lab OSPF area 1 (étudiants) + area 0 (cœur) — ne jamais fragmenter area 0.
