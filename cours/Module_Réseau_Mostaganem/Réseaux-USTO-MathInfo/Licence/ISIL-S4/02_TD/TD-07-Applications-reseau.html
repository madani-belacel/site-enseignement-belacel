Annexe — Corrigé TD 07

Corrigé Exercice 1

a) A = adresse IPv4 directe. CNAME = alias vers un autre nom de domaine.

b) 1. Résolveur local reçoit requête → 2. Serveur racine → 3. TLD .com → 4. Autoritaire google.com

c) Port 53, transport UDP (principalement)

d) CNAME (www → server), puis A (server → 41.107.50.10)

Corrigé Exercice 2

a) Méthode GET, ressource /cours/reseaux/index.html, version HTTP/1.1, hôte www.univ-mosta.dz

b) 200=OK, 301=Redirection permanente, 404=Non trouvé, 500=Erreur serveur, 403=Interdit

c) HTTP port 80 non chiffré ; HTTPS port 443 chiffré via TLS

Corrigé Exercice 3

Protocole Port Transport Fonction
SMTP 25 TCP Envoi email
DHCP 67/68 UDP Config IP auto
FTP 21 TCP Transfert fichiers
SSH 22 TCP Terminal sécurisé

Corrigé Exercice 4

  1. DNS query → 2. DNS response → 3. TCP handshake → 4. TLS handshake → 5. HTTP GET → 6. Encapsulation/envoi → 7. Réception HTML → 8. Affichage
