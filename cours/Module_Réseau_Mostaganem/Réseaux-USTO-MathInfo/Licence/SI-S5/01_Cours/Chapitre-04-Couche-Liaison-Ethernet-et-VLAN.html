Objectifs du chapitre

À l'issue de ce chapitre, l'étudiant sera capable de :

  1. Configurer des VLAN 802.1Q (ports access et trunk).
  2. Expliquer le routage inter-VLAN (routeur-on-a-stick, switch L3).
  3. Concevoir un plan de segmentation VLAN pour un campus ou PME.
  4. Analyser le trafic VLAN dans Wireshark et Packet Tracer.

2. VLAN 802.1Q — concepts

2.1 Problème sans VLAN

Un switch = un seul domaine de broadcast → tous les broadcast (ARP, DHCP) atteignent tous les ports.

2.2 Solution VLAN

Un VLAN (Virtual LAN) = réseau logique isolé au niveau L2.

Avantage Description
Segmentation broadcast Réduit trafic inutile
Sécurité logique Isoler invités, IoT, serveurs
Flexibilité Déplacement utilisateur sans recâblage
Organisation Par département, fonction

2.3 Identifiant VLAN (VID)

  • 12 bits dans le tag 802.1Q → 4094 VLANs utilisables (1 et 4095 réservés).
  • Plage recommandée : 1–1005 (VLAN normal range).

3. Trame 802.1Q

| Dest MAC (6) | Src MAC (6) | 802.1Q Tag (4) | EtherType (2) | Data | FCS |
                              │
                    TPID=0x8100
                    PCP (3 bits) + DEI (1) + VID (12 bits)
Champ Rôle
TPID 0x8100 — identifie tag VLAN
PCP Priorité (802.1p) — QoS L2
VID Numéro VLAN (1–4094)

4. Ports access vs trunk

Type VLAN tagué ? Usage
Access Non — untagged PC, imprimante, serveur
Trunk Oui — 802.1Q Inter-switch, switch ↔ routeur

4.1 Native VLAN

  • Sur un trunk, le trafic non tagué appartient au native VLAN (défaut : VLAN 1).
  • Règle de sécurité : ne pas utiliser VLAN 1 pour données ; aligner native VLAN des deux côtés du trunk.

4.2 Exemple de configuration (Cisco IOS — syntaxe)

! Switch — VLAN et ports access
vlan 10
 name ETUDIANTS
vlan 20
 name SERVEURS
interface FastEthernet0/1
 switchport mode access
 switchport access vlan 10
interface FastEthernet0/2
 switchport mode access
 switchport access vlan 20
! Trunk vers routeur ou switch cœur
interface GigabitEthernet0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 switchport trunk native vlan 99

5. Routage inter-VLAN

Sans routage L3, aucune communication entre VLANs (isolation L2).

5.1 Routeur-on-a-stick

[VLAN 10 PC] ── Switch ── Trunk ── [Routeur]
[VLAN 20 PC] ──          (sub-int)   Gi0/0.10 → 192.168.10.1
                                    Gi0/0.20 → 192.168.20.1

interface GigabitEthernet0/0.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface GigabitEthernet0/0.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0

5.2 Switch multicouche (L3)

Le switch effectue le routage en interne (SVI — Switched Virtual Interface) :

interface Vlan10
 ip address 192.168.10.1 255.255.255.0
interface Vlan20
 ip address 192.168.20.1 255.255.255.0
ip routing
Approche Avantage Limite
Routeur-on-a-stick Simple, peu coûteux Goulot sur lien trunk
Switch L3 Performance, faible latence Coût switch manageable

6. Conception VLAN — campus Université de Mostaganem (exemple)

VLAN ID Nom Sous-réseau IP Usage
10 ADMIN 192.168.10.0/24 Personnel administratif
20 ETUDIANTS 192.168.20.0/24 Salles TP
30 SERVEURS 192.168.30.0/24 Serveurs locaux
40 INVITES 192.168.40.0/24 Wi-Fi invités
99 NATIVE — Native trunk (pas de données)

Politique : VLAN 40 pas de routage vers VLAN 30 (serveurs) — ACL sur routeur/switch L3.

7. Sécurité VLAN (aperçu)

Menace Contre-mesure
VLAN hopping Désactiver DTP négociation ; native VLAN dédié
MAC flooding Port security (limiter MAC par port)
Accès trunk non autorisé switchport mode access sur ports postes

8. Exercices

Exercice 1 : 3 VLANs (10, 20, 30). PC-A (VLAN 10) communique avec PC-B (VLAN 20). Décrire le chemin L2/L3.

Solution PC-A → switch (trame untagged VLAN 10) → routeur/switch L3 (routage 192.168.10.x → 192.168.20.x) → switch → PC-B (trame untagged VLAN 20). IP src/dest conservées ; MAC réécrites à chaque segment.

Exercice 2 : Pourquoi le native VLAN doit-il être identique des deux côtés d'un trunk ?

Solution Sinon, trafic untagged interprété dans des VLAN différents → fuite de trafic ou perte de connectivité.
