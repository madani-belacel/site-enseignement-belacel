3. Problèmes identifiés

MODÉRÉ : Aucun fichier de correction distinct pour les TD

Les corrigés sont intégrés dans les TD MD (en annexe), ce qui est une bonne pratique. Cependant, il serait utile d'avoir des fichiers de correction séparés à distribuer aux étudiants après la séance.

MODÉRÉ : Questions de révision/QCM manquants dans certains cours

Tous les chapitres n'ont pas de section "Questions de révision" ou "QCM". Le Chapitre 01 en a, mais vérifier pour les autres.

MODÉRÉ : Schémas/images manquants dans les sources MD

Les sources MD font référence à des images (../../../Ressources-Communes/Images-Schemas/...), mais ces dossiers n'ont pas été vérifiés. Si les images sont absentes, les PDF générés seront incomplets.

MODÉRÉ : Pas de progression inter-niveaux explicite

Problème : La progression de ISIL-S4 → SI-S5 → ING-S5→S9 → RSID-M1 est bonne (du général au spécialisé), mais il n'existe pas de document expliquant cette progression aux étudiants.

LÉGER : Mise à jour de l'année

Le fichier 00_Fiche-Module.md mentionne _Mise à jour : 2025-2026_. Mettre à jour pour l'année en cours.

LÉGER : Coordonnées enseignant

Le champ "Enseignant responsable" dans la fiche module est marqué _À compléter — Faculté MathInfo, Université de Mostaganem_. Remplacer par BELACEL Madani.
