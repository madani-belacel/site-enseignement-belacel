EXAMEN 3 — Windows et Gestion de Fichiers (S1)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : C
        C — Le menu Démarrer est le point d'accès principal à tous les programmes et paramètres de Windows.
  q2 : B
        B — .xlsx est l'extension des fichiers Excel ; .docx pour Word, .pptx pour PowerPoint, .pdf pour Portable Document Format.
  q3 : B
        B — Ctrl+Z annule la dernière action (Undo). Ctrl+Y refait l'action annulée (Redo).
  q4 : B
        B — La zone de notification (systray) affiche l'heure, le volume, la batterie et les icônes d'applications en arrière-plan.
  q5 : B
        B — Windows+L verrouille immédiatement la session. Windows+E ouvre l'Explorateur, Windows+S ouvre la recherche, Windows+R ouvre Exécuter.

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Vrai
        Vrai — Le Bureau est l'espace de travail principal affichant icônes, raccourcis et fichiers.
  q7 : Faux
        Faux — .docx est l'extension des documents Microsoft Word, pas PowerPoint (qui utilise .pptx).
  q8 : Vrai
        Vrai — La zone de notification donne un accès rapide aux paramètres système (volume, luminosité, réseau, etc.).
  q9 : Faux
        Faux — Windows+R ouvre la boîte de dialogue Exécuter. C'est Windows+E qui ouvre l'Explorateur de fichiers.
  q10 : Faux
        Faux — Ctrl+C copie un élément sans le supprimer. C'est Ctrl+X qui le coupe (copie + supprime de l'emplacement d'origine).

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','b','d']
        A, B, D — Ctrl+C = Copier, Ctrl+V = Coller, Ctrl+Z = Annuler. Ctrl+X = Couper (pas Imprimer, Ctrl+P).
  q12 : ['a','b','c']
        A, B, C — L'Explorateur contient la barre d'adresse, le volet de navigation et la barre d'outils. La zone de notification appartient à la barre des tâches.
  q13 : ['a','b','c']
        A, B, C — Verrouiller la session, utiliser un mot de passe fort et sauvegarder ses fichiers sont des pratiques de sécurité essentielles. Partager son mot de passe est une mauvaise pratique.

EXERCICE 4 — TEXTE A COMPLETER (q14-q15)  [2 pts]
--------------------------------------------------
  q14 : 3-2-1
        3-2-1 — La règle 3-2-1 de sauvegarde : 3 copies, 2 supports différents, 1 copie hors site.
  q15 : explorateur
        Explorateur — L'Explorateur de fichiers (ou File Explorer) est l'outil principal de Windows pour gérer fichiers et dossiers.
