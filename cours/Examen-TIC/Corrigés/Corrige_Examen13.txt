EXAMEN 13 — HTML et CSS — Web (S2)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : C
        C — &lt;!DOCTYPE html&gt; déclare le type de document en HTML5, il est obligatoire en première ligne.
  q2 : B
        B — La balise &lt;main&gt; englobe le contenu principal unique de la page (balise sémantique).
  q3 : B
        B — L'attribut href (Hypertext REFerence) est obligatoire dans &lt;a&gt; pour spécifier la cible du lien.
  q4 : C
        C — La balise &lt;img&gt; insère une image ; elle nécessite les attributs src et alt.
  q5 : B
        B — Les balises &lt;meta&gt; se placent dans &lt;head&gt; pour les métadonnées (encodage, viewport, etc.).

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Faux
        Faux — &lt;div&gt; est une balise générique non sémantique. Les balises sémantiques sont &lt;header&gt;, &lt;nav&gt;, &lt;main&gt;, &lt;section&gt;, &lt;article&gt;, &lt;footer&gt;, etc.
  q7 : Vrai
        Vrai — Le modèle de boîte (box model) se compose de content, padding, border et margin (de l'intérieur vers l'extérieur).
  q8 : Faux
        Faux — Le sélecteur #header cible un élément avec l'id « header ». Pour une classe, on utilise .header (point).
  q9 : Vrai
        Vrai — &lt;footer&gt; est une balise sémantique qui représente le pied de page d'une section ou de la page.
  q10 : Vrai
        Vrai — L'attribut style permet d'appliquer du CSS directement sur une balise (CSS inline).

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','c']
        A, C — &lt;header&gt; et &lt;nav&gt; sont des balises sémantiques. &lt;div&gt; et &lt;span&gt; sont génériques.
  q12 : ['a','c']
        A, C — src (source de l'image) et alt (texte alternatif) sont les attributs principaux de &lt;img&gt;.
  q13 : ['a','b','d']
        A, B, D — display:flex active la disposition flexible, utilise justify-content et align-items. display:none masque l'élément.

EXERCICE 4 — TEXTE A COMPLETER (q14-q15)  [2 pts]
--------------------------------------------------
  q14 : .alerte
        Le sélecteur de classe commence par un point : .alerte { color: red; }
  q15 : media
        @media (max-width: 768px) { ... } est la syntaxe correcte d'une media query responsive.
