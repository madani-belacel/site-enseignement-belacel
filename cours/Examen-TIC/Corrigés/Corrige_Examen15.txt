EXAMEN 15 — Cloud Computing et Services Web (S2)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : B
        B — Le Cloud Computing est un modèle permettant l'accès à la demande à des ressources informatiques partagées via Internet.
  q2 : D
        D — OaaS n'existe pas. Les 3 modèles sont IaaS, PaaS et SaaS.
  q3 : B
        B — L'auto-provisionnement permet l'allocation automatique de ressources selon la demande.
  q4 : C
        C — Google Workspace (Gmail, Drive, Docs…) est un exemple de SaaS.
  q5 : A
        A — Le load balancing répartit la charge entre plusieurs serveurs.

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Vrai
        Vrai — Le paiement à l'usage est un principe fondamental du cloud computing.
  q7 : Faux
        Faux — Un cloud privé est réservé à une organisation, contrairement au cloud public.
  q8 : Vrai
        Vrai — Docker utilise la virtualisation par conteneurs, plus légère que les machines virtuelles.
  q9 : Faux
        Faux — Le modèle PaaS fournit une plateforme de développement, pas seulement des VM. C'est IaaS qui fournit des VM.
  q10 : Vrai
        Vrai — Le scaling horizontal ajoute plus de machines, contrairement au vertical (plus de puissance).
