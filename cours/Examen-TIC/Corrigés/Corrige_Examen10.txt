EXAMEN 10 — Mini-examen — Windows + Word + Excel (S1)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : B
        B — Windows + L verrouille immédiatement la session Windows.
  q2 : C
        C — Depuis Word 2007, l'extension par défaut est .docx (format Open XML).
  q3 : A
        A — =SOMME(A1:A10) additionne toutes les valeurs de A1 à A10.
  q4 : A
        A — Alt + F4 ferme l'application active sous Windows.
  q5 : A
        A — Ruban > Références > Table des matières génère une TDM à partir des styles.

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Vrai
        Vrai — La TDM automatique se base sur les styles Titre 1, Titre 2, etc.
  q7 : Vrai
        Vrai — Le format PDF préserve la mise en page d'origine du document Word.
  q8 : Vrai
        Vrai — Ctrl + S enregistre directement sans ouvrir de boîte de dialogue (si déjà enregistré).
  q9 : Vrai
        Vrai — L'extension .xlsx est celle des classeurs Microsoft Excel depuis 2007.
  q10 : Vrai
        Vrai — Le pare-feu Windows filtre le trafic réseau entrant et sortant pour protéger le PC.

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','b','c']
        A, B, C — MOYENNE(), RECHERCHEV() et CONCATENER() sont des fonctions Excel. IMPRIMER() n'existe pas.
  q12 : ['a','b','c']
        A, B, C — Les références relatives, absolues et mixtes existent dans Excel. La référence circulaire n'est pas un type de référence.
  q13 : ['a','b','c','d']
        A, B, C, D — Tous ces raccourcis sont correctement associés à leur fonction.

EXERCICE 4 — TEXTE A COMPLETER (q14-q15)  [2 pts]
--------------------------------------------------
  q14 : insertion
        Insertion — L'onglet Insertion permet d'ajouter des en-têtes, pieds de page et numéros de page.
  q15 : windows-s
        Windows + S — Ce raccourci ouvre la barre de recherche Windows.
