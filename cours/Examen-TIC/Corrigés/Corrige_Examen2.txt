EXAMEN 2 — Informatique et Architecture de l\ (S1)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : B
        B — Le processeur (CPU) exécute les instructions et effectue les calculs, c'est le cerveau de l'ordinateur.
  q2 : B
        B — La RAM est volatile : elle perd son contenu dès que l'ordinateur est éteint.
  q3 : B
        B — L'unité de contrôle dirige et coordonne le fonctionnement de toutes les unités du processeur.
  q4 : C
        C — Le clavier est un périphérique d'entrée (saisie de données). L'imprimante, l'écran et le haut-parleur sont des périphériques de sortie.
  q5 : B
        B — Le SSD (Solid State Drive) utilise de la mémoire flash sans pièces mobiles, ce qui le rend plus rapide et plus fiable qu'un HDD.

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Faux
        Faux — Le logiciel désigne les programmes et applications, pas le matériel. Le matériel (hardware) désigne les composants physiques.
  q7 : Vrai
        Vrai — La carte mère est le circuit principal qui connecte tous les composants entre eux.
  q8 : Faux
        Faux — Le système d'exploitation est un logiciel (software), pas du matériel.
  q9 : Vrai
        Vrai — Linux est un système d'exploitation distribué sous licence GNU GPL, il est libre et open source.
  q10 : Faux
        Faux — Les mises à jour corrigent les failles de sécurité, améliorent la stabilité et ajoutent de nouvelles fonctionnalités.

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','c','d']
        A, C, D — Le processeur, la RAM et la carte graphique sont des composants matériels. Windows 11 est un logiciel.
  q12 : ['a','c']
        A, C — Windows et macOS sont des systèmes propriétaires. Linux et Debian sont des systèmes libres.
  q13 : ['a','c','d']
        A, C, D — .jpg, .png et .gif sont des formats d'image. .pdf est un format de document portable.

EXERCICE 4 — TEXTE A COMPLETER (q14-q15)  [2 pts]
--------------------------------------------------
  q14 : bus
        Le bus — C'est le canal de communication qui transmet les données entre le processeur, la mémoire et les périphériques.
  q15 : Ctrl+S
        Ctrl+S — Raccourci universel pour sauvegarder le fichier en cours dans la plupart des applications.
