EXAMEN 8 — Examen Blanc Semestre 1 (S1)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : B
        B — L'architecture de Von Neumann (1945) sépare le CPU de la mémoire dans un bus commun.
  q2 : C
        C — .docx est l'extension standard des documents Word (Office 2007+).
  q3 : B
        B — Excel est un tableur qui traite les données par des formules et fonctions.
  q4 : B
        B — Ctrl + Z annule la dernière action dans Word et dans la plupart des logiciels.
  q5 : C
        C — Le disque dur ou SSD stocke les données de manière permanente (contrairement à la RAM volatile).

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Faux
        Faux — Le logiciel désigne les programmes (partie logique), le matériel désigne la partie physique.
  q7 : Vrai
        Vrai — Les styles permettent d'appliquer un formatage homogène (titres, corps, etc.) à tout le document.
  q8 : Vrai
        Vrai — =SOMME(A1:A5) additionne toutes les valeurs de A1 à A5 (toujours vrai).
  q9 : Faux
        Faux — La communication inclut le courriel, les forums, la visioconférence, les réseaux sociaux, etc.
  q10 : Faux
        Faux — Ctrl + Maj + F3 ouvre le volet des sources. Il n'existe pas de raccourci standard pour insérer la bibliothèque de sources en un clic.

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','c','d']
        A, C, D — Le processeur, le clavier et l'écran sont du matériel. Windows est un logiciel.
  q12 : ['a','b','c']
        A, B, C — .docx (Word), .xlsx (Excel), .pptx (PowerPoint) sont des extensions Office. .odt est OpenDocument (LibreOffice).
  q13 : ['a','b','d']
        A, B, D — MOYENNE(), NB() et MAX() sont des fonctions statistiques. REMPLACER() est une fonction de chaîne.

--------------------------------------------------
