EXAMEN 16 — Éthique et Cybersécurité (S2)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : C
        C — Le ransomware chiffre les données et exige le paiement d'une rançon pour la clé de déchiffrement.
  q2 : A
        A — Le phishing (hameçonnage) utilise des messages usurpés pour voler des identifiants et données sensibles.
  q3 : B
        B — Le pare-feu filtre les paquets réseau selon des règles de sécurité prédéfinies.
  q4 : B
        B — Le cheval de Troie se dissimule derrière un logiciel apparemment inoffensif pour compromettre le système.
  q5 : C
        C — Un mot de passe complexe combinant lettres (majuscules/minuscules), chiffres et caractères spéciaux est recommandé.

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Vrai
        Vrai — Le RGPD (art. 17) accorde le droit à l'effacement des données personnelles (droit à l'oubli).
  q7 : Faux
        Faux — L'open source signifie précisément que le code source est accessible et modifiable par tous.
  q8 : Vrai
        Vrai — Le ver se propage de manière autonome via les réseaux sans nécessiter d'hôte ni d'intervention humaine.
  q9 : Faux
        Faux — Un gestionnaire de mots de passe est vivement recommandé pour stocker des mots de passe complexes et uniques.
  q10 : Vrai
        Vrai — Le consentement explicite est l'un des six fondements juridiques du traitement des données sous le RGPD.

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','b','d']
        A, B, D — Le virus, le ransomware et le spyware sont des malwares. Le pare-feu est un outil de protection.
  q12 : ['b','c','d']
        B, C, D — Gestionnaire, MFA et changement régulier sont des bonnes pratiques. Utiliser le même mot de passe partout est risqué.
  q13 : ['a','b','d']
        A, B, D — Le RGPD impose le consentement, la minimisation et garantit le droit à l'oubli. Il n'est pas absent de régulation.

EXERCICE 4 — TEXTE A COMPLETER (q14-q15)  [2 pts]
--------------------------------------------------
  q14 : conformite
        Conformité — L'audit de sécurité vérifie la conformité aux normes et politiques de sécurité.
  q15 : iso27001
        ISO 27001 — Norme internationale defining l'ISMS (Information Security Management System).
