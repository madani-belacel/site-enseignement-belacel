EXAMEN 4 — Microsoft Word (S1)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : B
        B — Le ruban (Ribbon) est l'élément central de l'interface Word qui regroupe tous les outils par onglets.
  q2 : C
        C — Les commandes « Police » et « Paragraphe » se trouvent dans l'onglet « Accueil » du ruban.
  q3 : A
        A — Le volet de navigation affiche la structure des titres et permet de naviguer dans un document long.
  q4 : B
        B — La commande « Annuler » se trouve par défaut dans la barre d'outils Accès rapide (en haut à gauche).
  q5 : A
        A — Ctrl + S est le raccourci universel pour sauvegarder un fichier dans Word.

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Vrai
        Vrai — Le style « Normal » est effectivement le style par défaut de tout nouveau document Word.
  q7 : Faux
        Faux — Les styles Titre 1-3 permettent de structurer le document et de générer automatiquement une table des matières.
  q8 : Vrai
        Vrai — Word permet de créer de nouveaux styles personnalisés via le volet Styles.
  q9 : Vrai
        Vrai — La table des matières automatique est générée à partir des styles Titre appliqués au document.
  q10 : Faux
        Faux — On peut modifier librement les propriétés de tout style prédéfini dans Word (police, taille, couleur, etc.).

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','c']
        A, C — Times New Roman et Calibri sont les polices recommandées pour les documents académiques.
  q12 : ['a','b','c']
        A, B, C — Marges 2,5 cm, interligne 1,5 et police 12 pt forment la norme académique standard. L'orientation paysage n'est pas standard.
  q13 : ['a','b']
        A, B — PDF est le format privilégié pour Moodle ; le format .docx peut également être accepté.

EXERCICE 4 — TEXTE A COMPLETER (q14-q15)  [2 pts]
--------------------------------------------------
  q14 : apa
        APA — Le style APA (American Psychological Association) est le format de citation le plus utilisé en milieu universitaire francophone.
  q15 : references
        Références — L'onglet « Références » du ruban permet d'insérer des citations et de générer la bibliographie automatiquement.
