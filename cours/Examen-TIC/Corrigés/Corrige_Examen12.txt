EXAMEN 12 — Programmation et Algorithme (S2)
============================================================

EXERCICE 1 — QCM (q1-q5)  [5 pts]
--------------------------------------------------
  q1 : B
        B — Un algorithme est une suite finie et ordonnée d'instructions pour résoudre un problème.
  q2 : B
        B — Le pseudo-code est une description textuelle utilisant un vocabulaire proche du langage humain.
  q3 : C
        C — La structure SI ... ALORS (alternative) exécute une action uniquement si la condition est vraie.
  q4 : D
        D — Le type booléen ne prend que deux valeurs : vrai ou faux.
  q5 : B
        B — Faux : (5>3) est vrai mais (2<1) est faux, donc « ET » retourne faux.

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Faux
        Faux — Une variable de type entier ne peut stocker que des nombres entiers (pas de décimales).
  q7 : Vrai
        Vrai — La boucle TANT QUE teste la condition avant chaque itération (boucle pré-testée).
  q8 : Vrai
        Vrai — Le diagramme de flux utilise des formes standard : ovale=début/fin, rectangle=instruction, losange=condition.
  q9 : Faux
        Faux — L'opérateur == sert à comparer deux valeurs. L'affectation utilise = (ou :=).
  q10 : Vrai
        Vrai — Une erreur de syntaxe (syntax error) empêche la compilation ou l'interprétation du programme.

EXERCICE 3 — MULTI-CHOIX (q11-q13)  [3 pts]
--------------------------------------------------
  q11 : ['a','c','d']
        A, C, D — Python, Java et C sont des langages de programmation. HTML est un langage de balisage.
  q12 : ['a','c','d']
        A, C, D — +, *, % sont arithmétiques. == est un opérateur de comparaison.
  q13 : ['a','b','d']
        A, B, D — Les erreurs de syntaxe, de logique et d'exécution (runtime) sont les trois types principaux.

EXERCICE 4 — TEXTE A COMPLETER (q14-q15)  [2 pts]
--------------------------------------------------
  q14 : fonction
        Fonction — Une fonction retourne une valeur, une procédure effectue une action sans retour.
  q15 : portee
        Portée — La portée (scope) désigne la zone du programme où une variable est accessible.
