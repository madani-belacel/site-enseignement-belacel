============================================================

--------------------------------------------------
  q1 : B
        B — Le LAN (Local Area Network) est un réseau local couvrant un bâtiment ou un campus.
  q2 : C

  q3 : B
        B — Le Switch utilise une table d

EXERCICE 2 — VRAI/FAUX (q6-q10)  [5 pts]
--------------------------------------------------
  q6 : Vrai
        Vrai — L'adresse IPv4 est composée de 4 octets (32 bits) séparés par des points, ex. 192.168.1.1.
  q7 : Faux
        Faux — L'adresse MAC est gravée en usine dans la carte réseau. Elle peut être masquée temporairement mais pas modifiée définitivement.
  q8 : Vrai
        Vrai — Le VPN crée un tunnel chiffré permettant d'accéder à un réseau privé via Internet.
  q9 : Vrai
        Vrai — Le DNS (Domain Name System) résout les noms de domaine (ex. google.com) en adresses IP.
  q10 : Faux
        Faux — Le modèle TCP/IP comporte 4 couches (Accès réseau, Internet, Transport, Application).

--------------------------------------------------
  q11 : ['a','b','d']

  q13 : ['a','b','d']
