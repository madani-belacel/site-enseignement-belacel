Cours Informatique — ENS 2ème année — Séance 08 (FR)

Enseignant : BELACEL Madani
Module : Informatique
Niveau : ENS — 2ème année — Département de français
Durée : 1h30
Année universitaire : 2025-2026

Fiche cours — Plateforme e-learning (Moodle)

Référentiel : benchmark 10 universités algériennes + pratiques Univ-Mosta/Biskra/M'sila.

Public visé : Étudiants ENS 2ème année — Département Français

Compétences pré-requises : Toutes les séances précédentes (synthèse du module)

Objectifs transversaux : - Appliquer la programmation orientée objet (classes, héritage, encapsulation) en Python - Concevoir des algorithmes avancés (tri, recherche, récursivité) et estimer leur complexité - Modéliser des données avec le modèle relationnel et requêtes SQL de base - Comprendre l'architecture Web (HTML, CSS, JavaScript intro, HTTP) - Utiliser Git et méthodes de travail collaboratif (branches, merge) - Préparer l'enseignement de l'informatique au collège/lycée (Scratch, Python pédagogique)

Mode d'évaluation : TP POO + SQL 35 % — Projet intégré 40 % — Fiche séance pédagogique 25 %

Bibliographie : Eduscol — Programmes d'enseignement ; Scratch MIT ; Guide de l'enseignant — SNT

Objectifs pédagogiques spécifiques

À l'issue de cette séance, l'étudiant est capable de : - Connaître les programmes officiels d'informatique au collège/lycée - Concevoir une séance Scratch pour des élèves de collège - Utiliser Python comme outil pédagogique - Évaluer les compétences numériques (PIX/C2i) - Rédiger une fiche de séance pédagogique

Contexte réglementaire algérien

Ce cours s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique, consultée pour aligner ce cours sur les standards nationaux.

2. Scratch (20 min)

Scratch (scratch.mit.edu) : programmation visuelle par blocs — idéal pour collège.

Concepts enseignés : - Blocs de mouvement, apparence, son - Boucles (répéter, toujours) - Conditions (si, si… alors) - Variables et listes - Événements (quand drapeau cliqué, quand touche pressée)

Exemple d'exercice : chat qui marche 1. Quand drapeau cliqué → avancer de 10 pas 2. Si touche espace pressée → dire "Bonjour !" pendant 2 secondes 3. Rebondir si bord atteint

Progression recommandée : 1. Blocs simples (déplacement) 2. Boucles et conditions 3. Variables (score, timer) 4. Projet final (jeu de pong, quiz)

3. Python pédagogique (15 min)

Quand passer de Scratch à Python ? - Scratch : 6e-4e (découverte, logique) - Python : 3e-2de (première programmation textuelle)

Approche :

# Version Python d'un exercice Scratch
# Dire "Bonjour" quand on clique sur le drapeau

import turtle

t = turtle.Turtle()

# Avancer de 50 pas
t.forward(50)

# Tourner à droite
t.right(90)
t.forward(50)

turtle.done()

Bibliothèques pédagogiques : - turtle : dessin, déplacement (transition Scratch) - random : jeux, simulations - tkinter : interfaces graphiques simples

6. IA en classe (10 min)

Opportunités : - Assistant de correction (gagner du temps) - Génération d'exercices personnalisés - Traduction et adaptation - Aide à la rédaction de fiches

Limites et précautions : - Vérifier les résultats (IA peut se tromper) - Ne pas saisir de données personnelles d'élèves - Sensibiliser les élèves au plagiat - Citer l'utilisation de l'IA

Règle d'or : l'IA est un outil, pas un substitut au jugement de l'enseignant.

7. Charte d'usage du numérique (5 min)

Éléments à inclure dans une charte pour la classe :

  1. Utiliser son compte institutionnel uniquement
  2. Ne pas partager ses mots de passe
  3. Respecter la vie privée des camarades
  4. Signaler tout contenu inapproprié
  5. Citer ses sources (images, textes)
  6. Éteindre son téléphone en cours (sauf usage pédagogique)
  7. Demander l'autorisation avant d'enregistrer/filmer

Note pédagogique ENS

Transposition didactique : Cette séance est elle-même un exemple de transposition didactique : les concepts informatiques avancés (POO, SQL, Web) sont "transposés" en activités accessibles pour le secondaire. La progression Scratch → Python (section 3) est au cœur des programmes actuels. Le modèle de fiche de séance proposé peut être utilisé pour n'importe quel niveau. Les étudiants-enseignants doivent comprendre que la difficulté n'est pas de maîtriser l'informatique, mais de l'enseigner à des débutants — c'est tout l'enjeu de la didactique.

Conseil pour l'enseignant formateur : Organisez un micro-enseignement : chaque étudiant prépare et anime une séquence de 10 minutes sur un concept informatique (boucle, condition, variable) devant le groupe. Filmez les prestations pour un retour constructif. L'évaluation par les pairs (grille critériée) renforce la professionnalisation. N'oubliez pas de sensibiliser à la gestion de classe : que faire quand un élève bloque sur un exercice ? Comment différencier ?

Prolongement : Les étudiants peuvent concevoir une séquence complète de 3 séances sur un thème informatique (création d'un jeu Scratch, initiation à Python avec Turtle, découverte du Web avec HTML) incluant fiches élèves, grilles d'évaluation, et traces écrites. Ces productions seront réinvesties pendant le stage pratique.
