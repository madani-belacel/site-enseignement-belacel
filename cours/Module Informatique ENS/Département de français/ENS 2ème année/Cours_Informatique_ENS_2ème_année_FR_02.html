1. Pourquoi la POO ? (10 min)

Programmation procédurale (ENS1) : fonctions + données séparées. Programmation orientée objet : regroupe données et comportement dans des objets.

Avantages : - Organisation naturelle (on pense en termes d'objets du monde réel) - Réutilisable (une classe = un moule à objets) - Maintenable (modifier une classe n'affecte pas le reste) - Extensible (héritage)

Exemple concret : dans la vie scolaire, on manipule des Élèves, des Enseignants, des Notes, des Classes — ce sont des objets.

flowchart LR
    A[Problème réel<br/>gestion scolaire] --> B[Identifier les objets<br/>Élève, Note, Classe]
    B --> C[Définir les classes<br/>attributs + méthodes]
    C --> D[Instancier des objets]
    D --> E{Objet cohérent ?}
    E -->|Oui| F[Réutiliser<br/>dans d'autres contextes]
    E -->|Non| B
    F --> G[Maintenance<br/>et évolution]

2. Classe et objet (15 min)

Classe : modèle, plan de construction. Objet : réalisation concrète du modèle (instance).

# Définition de la classe
class Eleve:
    pass

# Création d'objets (instances)
eleve1 = Eleve()
eleve2 = Eleve()

print(type(eleve1))  # <class '__main__.Eleve'>

La classe est le moule ; l'objet est l'élément produit par ce moule.

3. Attributs et méthodes (15 min)

Attribut : variable attachée à un objet (son état). Méthode : fonction attachée à un objet (son comportement).

class Eleve:
    def __init__(self, nom, age):
        self.nom = nom      # Attribut d'instance
        self.age = age

    def se_presenter(self): # Méthode
        print(f"Je m'appelle {self.nom} et j'ai {self.age} ans.")

# Utilisation
e = Eleve("Ali", 20)
print(e.nom)        # Accès à l'attribut
e.se_presenter()    # Appel de la méthode

Noter : self représente l'instance courante — c'est le premier paramètre de toute méthode.

Mini-exercice : Sans regarder la suite, ajoutez une méthode est_majeur() à la classe Eleve qui retourne True si l'âge est >= 18 et False sinon. Testez-la avec e = Eleve("Ali", 20).

# Solution
class Eleve:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age

    def se_presenter(self):
        print(f"Je m'appelle {self.nom} et j'ai {self.age} ans.")

    def est_majeur(self):
        return self.age >= 18

# Test
e = Eleve("Ali", 20)
print(e.est_majeur())  # True
print(Eleve("Sara", 16).est_majeur())  # False

Cas concret : Cette méthode est_majeur() correspond à une vérification que fait un enseignant pour savoir quels élèves peuvent participer à une sortie scolaire sans autorisation parentale supplémentaire.

4. Constructeur __init__ (15 min)

La méthode __init__ est appelée automatiquement à la création de l'objet.

class Evaluation:
    def __init__(self, matiere, note, coefficient=1):
        self.matiere = matiere
        self.note = note
        self.coefficient = coefficient

    def ponderer(self):
        return self.note * self.coefficient

# Création
eval1 = Evaluation("Maths", 15, 2)
eval2 = Evaluation("Français", 12)
print(eval1.ponderer())  # 30
print(eval2.ponderer())  # 12 (coefficient par défaut = 1)

5. Variables de classe (10 min)

Attributs partagés par toutes les instances.

class Eleve:

    def __init__(self, nom):
        self.nom = nom         # Variable d'instance

e1 = Eleve("Ali")
e2 = Eleve("Sara")
print(e1.ecole)   # ENS Mostaganem
print(e2.ecole)   # ENS Mostaganem

Utilité : constantes, compteurs, configuration partagée.

5bis. La méthode __str__ pour l'affichage (5 min)

La méthode __str__ définit comment un objet est affiché avec print().

class Eleve:
    def __init__(self, nom, prenom):
        self.nom = nom
        self.prenom = prenom

    def __str__(self):
        return f"Élève : {self.prenom} {self.nom}"

e = Eleve("Belacel", "Ali")
print(e)              # Élève : Ali Belacel
print(str(e))         # Idem

Utilité pédagogique : En classe, __str__ permet d'afficher des objets de manière lisible — on évite le <__main__.Eleve object at 0x...> incompréhensible.

6. Exemple complet : classe Eleve (20 min)

class Eleve:
    ecole = "ENS Mostaganem"
    total_eleves = 0  # Compteur partagé

    def __init__(self, nom, prenom, groupe):
        self.nom = nom
        self.prenom = prenom
        self.groupe = groupe
        self.notes = []
        Eleve.total_eleves += 1

    def ajouter_note(self, note):
        if 0 <= note <= 20:
            self.notes.append(note)
        else:
            print("Note invalide")

    def moyenne(self):
        if self.notes:
            return sum(self.notes) / len(self.notes)
        return 0.0

    def afficher(self):
        print(f"{self.prenom} {self.nom} — {self.groupe}")
        print(f"  Notes : {self.notes}")
        print(f"  Moyenne : {self.moyenne():.2f}")

# Test
e = Eleve("Belacel", "Ali", "ENS1-A")
e.ajouter_note(15)
e.ajouter_note(12)
e.ajouter_note(18)
e.afficher()
print(f"Total élèves : {Eleve.total_eleves}")

6bis. Encapsulation et propriétés (15 min)

Principe : protéger les attributs en contrôlant leur accès avec des propriétés.

class Note:
    def __init__(self, valeur):
        self._valeur = 0  # Attribut "protégé" (convention : _)
        self.valeur = valeur  # Passe par le setter

    @property
    def valeur(self):
        return self._valeur

    @valeur.setter
    def valeur(self, v):
        if 0 <= v <= 20:
            self._valeur = v
        else:
            raise ValueError("La note doit être entre 0 et 20")

# Test
n = Note(15)
print(n.valeur)    # 15 (getter)
n.valeur = 18      # Setter
# n.valeur = 25   # Déclenche ValueError

En contexte scolaire : L'encapsulation est comme un carnet de notes tenu par l'enseignant : on ne peut pas modifier une note sans respecter les règles (entre 0 et 20). Le décorateur @property est le "guichet" qui vérifie chaque modification.

7. Exercice guidé : classe Matiere (10 min)

Créer une classe Matiere avec : - Attributs : nom, coefficient, nb_heures - Méthode __init__ avec paramètres - Méthode afficher() qui affiche les informations - Méthode est_importante() qui retourne True si coefficient > 2

class Matiere:
    def __init__(self, nom, coefficient, nb_heures):
        self.nom = nom
        self.coefficient = coefficient
        self.nb_heures = nb_heures

    def afficher(self):
        print(f"{self.nom} (coef {self.coefficient}, {self.nb_heures}h)")

    def est_importante(self):
        return self.coefficient > 2

7bis. Cas d'étude : Système de gestion de notes (15 min)

Assemblons les concepts dans un exemple réaliste multi-classes :

class Matiere:
    def __init__(self, nom, coefficient=1):
        self.nom = nom
        self.coefficient = coefficient

class Note:
    def __init__(self, valeur, matiere):
        self.valeur = valeur
        self.matiere = matiere

class Eleve:
    ecole = "ENS Mostaganem"

    def __init__(self, nom, prenom):
        self.nom = nom
        self.prenom = prenom
        self.notes = []

    def ajouter_note(self, valeur, matiere):
        note = Note(valeur, matiere)
        self.notes.append(note)

    def moyenne_generale(self):
        if not self.notes:
            return 0.0
        total_pondere = sum(n.valeur * n.matiere.coefficient for n in self.notes)
        total_coef = sum(n.matiere.coefficient for n in self.notes)
        return total_pondere / total_coef if total_coef else 0.0

    def __str__(self):
        return f"{self.prenom} {self.nom} — Moy : {self.moyenne_generale():.2f}"

# Utilisation
maths = Matiere("Maths", 3)
francais = Matiere("Français", 2)

ali = Eleve("Belacel", "Ali")
ali.ajouter_note(15, maths)
ali.ajouter_note(12, francais)

sara = Eleve("Benali", "Sara")
sara.ajouter_note(18, maths)
sara.ajouter_note(14, francais)

print(ali)   # Ali Belacel — Moy : 13.80
print(sara)  # Sara Benali — Moy : 16.40

Discussion : Cet exemple illustre la collaboration entre classes (Eleve, Note, Matiere). Chaque classe a une responsabilité unique (Single Responsibility Principle), ce qui rend le code maintenable et évolutif.

QCM d'auto-évaluation

  3. La méthode __init__ est : a) Appelée manuellement par le programmeur b) Appelée automatiquement à la création de l'objet ✓ c) Optionnelle pour toute classe

8. Conclusion (5 min)

La POO organise le code autour d'objets qui encapsulent données et comportement. Les classes sont réutilisables et faciles à maintenir.

Note pédagogique ENS

Transposition didactique : La notion d'objet peut être introduite dès le collège sans ordinateur par une activité débranchée : chaque élève reçoit une fiche "être vivant" avec des cases à remplir (nom, âge, couleur). La fiche vierge est la classe, la fiche remplie est l'objet. En NSI Première, on peut montrer que la classe Eleve du cours est similaire à un modèle de fiche élève qu'ils remplissent chaque année. Le parallèle avec le tableur (ligne = objet, colonne = attribut) facilite la compréhension.

Conseil pour l'enseignant formateur : Lors de la correction des TP, insistez sur la distinction classe/instance : beaucoup d'étudiants confondent Eleve (la classe) et e (l'instance). Un exercice efficace consiste à demander "Quel est le type de e ?" et "Quel est le type de Eleve ?". Proposez également un exercice où les étudiants doivent ajouter un attribut date_naissance et une méthode age() pour consolider la compréhension.

Évaluation formative : Proposez un défi codé en 10 minutes : "Créez une classe Calculatrice avec des méthodes addition, soustraction, multiplication, division (gérer la division par zéro)". Cela teste la compréhension des méthodes, des paramètres et du retour de valeur.

Prolongement : Les étudiants peuvent créer une classe SalleDeClasse qui contient une liste d'objets Eleve et des méthodes pour calculer la moyenne de la classe, lister les élèves par groupe, ou exporter les données au format CSV. Ce mini-projet prépare le projet intégré de fin de module.
