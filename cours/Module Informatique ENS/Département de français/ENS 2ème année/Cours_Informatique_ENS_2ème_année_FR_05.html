1. Pourquoi une base de données ? (10 min)

Limites d'un fichier CSV : - Pas de structure stricte - Pas de validation (notes > 20 possibles) - Difficile de faire des liens entre tables - Pas de concurrence (deux personnes ne peuvent pas écrire en même temps)

Base de données relationnelle : - Structure rigide (schéma) - Contraintes (clés, types, valeurs) - Requêtes puissantes (langage SQL) - Intégrité des données

3. SQLite et Python (10 min)

SQLite est une base de données légère, intégrée à Python (pas d'installation serveur).

import sqlite3

# Connexion (crée le fichier .db)
conn = sqlite3.connect("ecole.db")
curseur = conn.cursor()

# Exécuter une requête
curseur.execute("""
    CREATE TABLE IF NOT EXISTS eleves (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT NOT NULL,
        prenom TEXT NOT NULL,
        groupe TEXT
    )
""")

conn.commit()  # Valider
conn.close()   # Fermer

4. CREATE TABLE (10 min)

conn = sqlite3.connect("ecole.db")
c = conn.cursor()

c.execute("""
    CREATE TABLE IF NOT EXISTS matieres (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT NOT NULL,
        coefficient REAL DEFAULT 1.0
    )
""")

c.execute("""
    CREATE TABLE IF NOT EXISTS notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        eleve_id INTEGER NOT NULL,
        matiere_id INTEGER NOT NULL,
        valeur REAL NOT NULL CHECK(valeur >= 0 AND valeur <= 20),
        FOREIGN KEY (eleve_id) REFERENCES eleves(id),
        FOREIGN KEY (matiere_id) REFERENCES matieres(id)
    )
""")

conn.commit()

7. Clés étrangères et JOIN (15 min)

# Insérer une note
c.execute("""
    INSERT INTO notes (eleve_id, matiere_id, valeur)
    VALUES (?, ?, ?)
""", (1, 1, 15))

# Jointure : notes + noms des élèves + noms des matières
c.execute("""
    SELECT e.nom, e.prenom, m.nom, n.valeur
    FROM notes n
    JOIN eleves e ON n.eleve_id = e.id
    JOIN matieres m ON n.matiere_id = m.id
""")

for ligne in c.fetchall():
    print(f"{ligne[0]} {ligne[1]} — {ligne[2]} : {ligne[3]}")

8. Exemple complet : relevé de notes (15 min)

import sqlite3

conn = sqlite3.connect("ecole.db")
c = conn.cursor()

# Création des tables
c.execute("""
    CREATE TABLE IF NOT EXISTS eleves (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, prenom TEXT, groupe TEXT
    )
""")
c.execute("""
    CREATE TABLE IF NOT EXISTS matieres (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, coefficient REAL
    )
""")
c.execute("""
    CREATE TABLE IF NOT EXISTS notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        eleve_id INTEGER, matiere_id INTEGER, valeur REAL,
        FOREIGN KEY(eleve_id) REFERENCES eleves(id),
        FOREIGN KEY(matiere_id) REFERENCES matieres(id)
    )
""")

# Insertion des données
c.execute("INSERT INTO eleves VALUES (1, 'Ali', 'Belacel', 'ENS2-A')")
c.execute("INSERT INTO matieres VALUES (1, 'Informatique', 3.0)")
c.execute("INSERT INTO matieres VALUES (2, 'Français', 2.0)")
c.execute("INSERT INTO notes VALUES (NULL, 1, 1, 15)")
c.execute("INSERT INTO notes VALUES (NULL, 1, 2, 12)")

# Relevé de notes avec moyenne
c.execute("""
    SELECT e.nom, e.prenom, m.nom, n.valeur, m.coefficient
    FROM notes n
    JOIN eleves e ON n.eleve_id = e.id
    JOIN matieres m ON n.matiere_id = m.id
    WHERE e.id = 1
""")

print("=== Relevé de notes ===")
total_pondere = 0
total_coef = 0
for ligne in c.fetchall():
    print(f"{ligne[0]} {ligne[1]} — {ligne[2]} : {ligne[3]} (coef {ligne[4]})")
    total_pondere += ligne[3] * ligne[4]
    total_coef += ligne[4]

moyenne = total_pondere / total_coef if total_coef > 0 else 0
print(f"Moyenne générale : {moyenne:.2f}")

conn.commit()
conn.close()

QCM d'auto-évaluation

  2. Une clé primaire doit être : a) Unique et non nulle ✓ b) Optionnelle c) Toujours de type texte

  3. Quelle clause SQL filtre les résultats ? a) SELECT b) WHERE ✓ c) JOIN

  4. Que fait DELETE FROM eleves ? a) Supprime la table b) Supprime toutes les lignes ✓ c) Supprime une colonne

  5. Une jointure (JOIN) permet de : a) Combiner deux tables ✓ b) Trier les résultats c) Créer une nouvelle base

Conclusion

Les bases de données relationnelles et SQL sont au cœur de la gestion des données structurées. SQLite, intégré à Python, permet de prototyper rapidement une solution complète (création, insertion, interrogation, jointure) sans installation serveur. Les concepts de clé primaire, clé étrangère et jointure sont universels et se retrouvent dans tous les SGBD (MySQL, PostgreSQL, Oracle).

Note pédagogique ENS

Transposition didactique : Les bases de données peuvent être enseignées au collège et au lycée sans ordinateur, par des activités débranchées : - Fichier papier : chaque élève reçoit une fiche (table) avec des champs à remplir (nom, prénom, date de naissance). On simule une requête SELECT en triant les fiches. - Jeu de cartes : des cartes "élève" et des cartes "note" sont reliées par un trombone (clé étrangère). Les élèves doivent apparier les cartes (JOIN). - En SNT Seconde (thème "Données structurées") : faire réfléchir les élèves sur la différence entre un fichier texte non structuré et un tableau structuré (feuille de calcul). Le parallèle avec un tableur (Excel, LibreOffice Calc) est immédiat. - En NSI Première : SQL fait partie intégrante du programme. L'exemple du relevé de notes (section 8) peut être directement repris en classe.

Conseil pour l'enseignant formateur : Demander aux étudiants ENS de préparer une fiche pédagogique de 45 minutes sur les bases de données pour une classe de 4e ou de Seconde, en intégrant une activité débranchée et une activité numérique. Cela favorise la transposition didactique, compétence clé du métier d'enseignant.

Prolongement : Les étudiants peuvent créer une mini-application de gestion de bibliothèque (livres, auteurs, emprunts) avec SQLite et Python, et réfléchir aux requêtes utiles pour un enseignant (gestion des notes, des absences, des groupes).
