Cours Informatique — ENS 2ème année — Séance 07 (FR)

Enseignant : BELACEL Madani
Module : Informatique
Niveau : ENS — 2ème année — Département de français
Durée : 1h30
Année universitaire : 2026-2027

Fiche cours — Plateforme e-learning (Moodle)

Référentiel : benchmark 10 universités algériennes + pratiques Univ-Mosta/Biskra/M'sila.

Public visé : Étudiants ENS 2ème année — Département Français

Compétences pré-requises : Utilisation basique du terminal (ENS1 séance 03), projets Python

Objectifs transversaux : - Appliquer la programmation orientée objet (classes, héritage, encapsulation) en Python - Concevoir des algorithmes avancés (tri, recherche, récursivité) et estimer leur complexité - Modéliser des données avec le modèle relationnel et requêtes SQL de base - Comprendre l'architecture Web (HTML, CSS, JavaScript intro, HTTP) - Utiliser Git et méthodes de travail collaboratif (branches, merge) - Préparer l'enseignement de l'informatique au collège/lycée (Scratch, Python pédagogique)

Bibliographie : Chacon & Straub — Pro Git (git-scm.com) ; Atlassian — Git Tutorials

Objectifs pédagogiques spécifiques

À l'issue de cette séance, l'étudiant est capable de : - Initialiser un dépôt Git - Ajouter et commiter des fichiers - Créer et fusionner des branches - Push/pull sur GitHub - Rédiger un README professionnel - Utiliser .gitignore

Contexte réglementaire algérien

Ce cours s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique, consultée pour aligner ce cours sur les standards nationaux.

1. Pourquoi Git ? (10 min)

Problème : "TD_final.docx", "TD_final2.docx", "TD_version_rendu.docx"…

Solution : Git — système de contrôle de version.

Avantages : - Historique complet des modifications - Travail en équipe sans conflit - Annulation d'erreurs possible - Sauvegarde cloud (GitHub) - Portfolio de code pour enseignant

2. Installation et configuration (10 min)

Installation

# Vérifier si Git est installé
git --version

# Télécharger : git-scm.com

Configuration initiale

git config --global user.name "Madani BELACEL"
git config --global user.email "m.belacel [at] ens-mostaganem.dz"
git config --global core.editor "code --wait"

3. Commandes de base (20 min)

# Initialiser un dépôt dans le dossier projet
cd projet-ens2
git init

# Voir l'état
git status

# Ajouter un fichier au suivi (stage)
git add cours_web.html
git add .  # Ajouter tout le dossier

# Enregistrer une version (commit)
git commit -m "Ajout page web cours ENS2"

# Voir l'historique
git log --oneline

Cycle de vie d'un fichier :

4. Branches (20 min)

Branche : version parallèle du projet. Permet de travailler sur une fonctionnalité sans affecter la branche principale.

# Lister les branches
git branch

# Créer une branche
git branch fonctionnalite-quiz

# Changer de branche
git checkout fonctionnalite-quiz

# Créer et basculer (en une commande)
git checkout -b nouvelle-fonctionnalite

Fusion (merge)

# Revenir sur main
git checkout main

# Fusionner la branche de travail
git merge fonctionnalite-quiz

# Supprimer la branche après fusion
git branch -d fonctionnalite-quiz

Conflits : quand deux branches modifient la même ligne. Git affiche les deux versions, à l'utilisateur de choisir.

5. GitHub (15 min)

Créer un dépôt distant

  1. Créer un compte sur github.com
  2. Cliquer sur New repository
  3. Copier l'URL : https://github.com/user/projet.git

Lier le dépôt local → distant

git remote add origin https://github.com/user/projet.git
git push -u origin main

Mettre à jour

git push          # Envoyer ses commits
git pull          # Récupérer les commits des autres

GitHub Pages : Settings → Pages → branch: main → site web gratuit.

8. Bonnes pratiques (5 min)

  1. Commits fréquents et atomiques (une modification = un commit)
  2. Messages de commit clairs : git commit -m "Ajout fonction calcul moyenne"
  3. Ne jamais commiter : mots de passe, clés API, données élèves
  4. Faire un pull avant de commencer à travailler
  5. Utiliser des branches pour les expérimentations
  6. Ajouter un README dès le début

QCM d'auto-évaluation

  1. Quelle commande Git initialise un nouveau dépôt ? a) git start b) git init ✓ c) git new

  2. Quelle commande ajoute un fichier à la zone de staging ? a) git commit b) git add ✓ c) git push

  3. Une branche Git permet de : a) Supprimer définitivement des fichiers b) Travailler en parallèle sans affecter la branche principale ✓ c) Accélérer les commits

  4. Quelle commande envoie les commits vers GitHub ? a) git push ✓ b) git pull c) git clone

  5. Que contient le fichier .gitignore ? a) La liste des contributeurs b) Les fichiers à ne pas versionner ✓ c) Le message du dernier commit

Note pédagogique ENS

Transposition didactique : Git peut être introduit dès la classe de 3ème par une activité débranchée : chaque élève reçoit une feuille (fichier) et doit passer par des "commits" à chaque modification significative. Les branches sont représentées par des feuilles de couleur différente, et le merge par une agrafeuse qui relie les feuilles. En NSI Première, le versionnement est au programme et peut être présenté comme un carnet de bord du développement. Le parallèle avec les "versions" d'un devoir rendu par un élève est parlant.

Conseil pour l'enseignant formateur : Les étudiants ont souvent des difficultés avec les concepts de branches et de merge. Commencez par un scénario simple : "Vous travaillez sur le projet seul, vous créez une branche pour une fonctionnalité, vous la fusionnez". Une fois ce cycle maîtrisé, passez au travail collaboratif à deux sur le même dépôt. Insistez sur l'importance des messages de commit clairs — c'est une compétence professionnelle.

Prolongement : Les étudiants peuvent créer un dépôt Git de A à Z pour leur portfolio enseignant, en utilisant GitHub Pages pour le publier. Ils peuvent également expérimenter les conflits de fusion intentionnellement (deux étudiants modifient le même fichier) et apprendre à les résoudre — cette compétence est très valorisée dans le milieu professionnel.
