1. Récursivité (15 min)

Fonction récursive : fonction qui s'appelle elle-même.

Deux éléments essentiels : - Cas de base : condition d'arrêt (n'utilise pas la récursion) - Appel récursif : la fonction se rappelle avec un paramètre modifié

flowchart TD
    subgraph Récursivité
        A[factorielle 5] --> B[5 * factorielle 4]
        B --> C[4 * factorielle 3]
        C --> D[3 * factorielle 2]
        D --> E[2 * factorielle 1]
        E --> F[1 cas de base]
        F --> G[Retour 1]
        G --> H[Retour 2]
        H --> I[Retour 6]
        I --> J[Retour 24]
        J --> K[Résultat 120]
    end

Exemple : factorielle

def factorielle(n):
    if n <= 1:        # Cas de base
        return 1
    return n * factorielle(n - 1)  # Appel récursif

print(factorielle(5))  # 120 = 5*4*3*2*1

Exemple : Fibonacci

def fibonacci(n):
    if n <= 1:        # Cas de base
        return n
    return fibonacci(n-1) + fibonacci(n-2)  # Double appel

print(fibonacci(10))  # 55

Exercice rapide : Suite de Syracuse (5 min)

La conjecture de Syracuse (suite de Collatz) est définie par : - u0 = n (entier positif) - Si uk est pair : u(k+1) = uk / 2 - Si uk est impair : u(k+1) = 3 * uk + 1

Implémentez une fonction récursive syracuse(n) qui affiche les termes de la suite jusqu'à 1.

def syracuse(n):
    print(n, end=" ")
    if n == 1:           # Cas de base
        return
    if n % 2 == 0:       # Pair
        syracuse(n // 2)
    else:                # Impair
        syracuse(3 * n + 1)

syracuse(6)   # 6 3 10 5 16 8 4 2 1

Question : Tous les nombres finissent-ils par atteindre 1 ? C'est une conjecture non encore démontrée.

2. Récursivité vs itération (10 min)

# Itératif (boucle)
def factorielle_iter(n):
    resultat = 1
    for i in range(2, n + 1):
        resultat *= i
    return resultat

# Récursif
def factorielle_rec(n):
    if n <= 1:
        return 1
    return n * factorielle_rec(n - 1)
Critère Itératif Récursif
Lisibilité Simple Très lisible (mathématique)
Performance Plus rapide Plus lent (appels empilés)
Mémoire Constante O(n) pile d'appels
Usage Boucles simples Problèmes divisibles

Activité débranchée : Récursivité avec des miroirs (5 min)

Prenez deux petits miroirs face à face : l'image se répète à l'infini — récursion visuelle ! Chaque reflet est un appel récursif, l'emboîtement est la pile d'appels.

En classe : Les poupées russes (matriochkas) illustrent parfaitement la récursivité : chaque poupée en contient une plus petite.

3. Recherche dichotomique (15 min)

Principe : dans un tableau trié, comparer avec l'élément du milieu, puis chercher à gauche ou à droite.

def recherche_dichotomique(tableau, cible):
    debut = 0
    fin = len(tableau) - 1

    while debut <= fin:
        milieu = (debut + fin) // 2
        if tableau[milieu] == cible:
            return milieu          # Trouvé
        elif tableau[milieu] < cible:
            debut = milieu + 1     # Chercher à droite
        else:
            fin = milieu - 1       # Chercher à gauche

    return -1  # Non trouvé

# Test
notes = [5, 8, 10, 12, 15, 18, 20]
print(recherche_dichotomique(notes, 15))  # 4
print(recherche_dichotomique(notes, 7))   # -1

Complexité : O(log n) — beaucoup plus rapide que la recherche linéaire O(n).

Mini-exercice : Recherche dichotomique récursive (5 min)

Écrivez une version récursive de la recherche dichotomique.

def recherche_dichotomique_recursive(tableau, cible, debut=0, fin=None):
    if fin is None:
        fin = len(tableau) - 1
    if debut > fin:
        return -1
    milieu = (debut + fin) // 2
    if tableau[milieu] == cible:
        return milieu
    elif tableau[milieu] < cible:
        return recherche_dichotomique_recursive(tableau, cible, milieu + 1, fin)
    else:
        return recherche_dichotomique_recursive(tableau, cible, debut, milieu - 1)

notes = [3, 8, 10, 12, 14, 15, 18, 20]
print(recherche_dichotomique_recursive(notes, 14))  # 4

Lien avec l'enseignement : Le jeu "plus grand, plus petit" est une recherche dichotomique naturelle.

4. Tri bulle (15 min)

Principe : parcourir le tableau, comparer les éléments adjacents, les permuter s'ils sont dans le mauvais ordre.

def tri_bulle(tableau):
    n = len(tableau)
    for i in range(n):
        trie = True
        for j in range(n - i - 1):
            if tableau[j] > tableau[j + 1]:
                tableau[j], tableau[j + 1] = tableau[j + 1], tableau[j]
                trie = False
        if trie:  # Optimisation : déjà trié
            break
    return tableau

# Test
notes = [15, 8, 12, 20, 5]
print(tri_bulle(notes))  # [5, 8, 12, 15, 20]

Complexité : O(n²) dans le pire cas, O(n) si déjà trié.

Mini-exercice : Trier des mots par ordre alphabétique (5 min)

def tri_bulle_mots(mots):
    n = len(mots)
    for i in range(n):
        for j in range(n - i - 1):
            if mots[j] > mots[j + 1]:
                mots[j], mots[j + 1] = mots[j + 1], mots[j]
    return mots

prenoms = ["Zinedine", "Ali", "Sara", "Mohamed", "Aicha"]
print(tri_bulle_mots(prenoms))
# ['Aicha', 'Ali', 'Mohamed', 'Sara', 'Zinedine']

Remarque : Python compare les chaînes par ordre lexicographique (table ASCII/Unicode).

5. Tri fusion (merge sort) (15 min)

Principe : diviser le tableau en deux, trier chaque moitié récursivement, puis fusionner.

def tri_fusion(tableau):
    if len(tableau) <= 1:
        return tableau

    milieu = len(tableau) // 2
    gauche = tri_fusion(tableau[:milieu])
    droite = tri_fusion(tableau[milieu:])

    return fusionner(gauche, droite)

def fusionner(gauche, droite):
    resultat = []
    i = j = 0
    while i < len(gauche) and j < len(droite):
        if gauche[i] <= droite[j]:
            resultat.append(gauche[i])
            i += 1
        else:
            resultat.append(droite[j])
            j += 1
    resultat.extend(gauche[i:])
    resultat.extend(droite[j:])
    return resultat

# Test
notes = [15, 8, 12, 20, 5]
print(tri_fusion(notes))  # [5, 8, 12, 15, 20]

Complexité : O(n log n) dans tous les cas — plus efficace que le tri bulle.

Principe "diviser pour régner" : Le problème est divisé en sous-problèmes (diviser) jusqu'à obtenir des cas triviaux, puis les solutions sont combinées (fusionner).

6. Comparaison des tris (10 min)

Algorithme Pire cas Meilleur cas Mémoire Stable
Tri bulle O(n²) O(n) O(1) Oui
Tri fusion O(n log n) O(n log n) O(n) Oui
Tri rapide O(n²) O(n log n) O(log n) Non
Tri insertion O(n²) O(n) O(1) Oui

Pour un enseignant : - Tableau de 10 notes : tri bulle suffit - Classe de 30 élèves : tri fusion - Base de 10 000 enregistrements : tri fusion ou rapide

7. Conclusion (5 min)

La récursivité permet d'écrire des algorithmes élégants pour des problèmes divisibles. Les algorithmes de tri et de recherche sont fondamentaux et leur complexité détermine leur efficacité.

Note pédagogique ENS

Transposition didactique : La récursivité peut être introduite au collège avec les poupées russes ou les miroirs. En NSI Première, factorielle et Fibonacci sont des classiques. Le tri fusion illustre "diviser pour régner", transposable à d'autres disciplines. La recherche dichotomique est le jeu du "plus grand/plus petit".

Conseil pour l'enseignant formateur : Les étudiants confondent souvent récursivité et boucle. Insistez sur la différence : la récursivité divise le problème, l'itération répète une action. Faites tracer factorielle(4) sur papier.
