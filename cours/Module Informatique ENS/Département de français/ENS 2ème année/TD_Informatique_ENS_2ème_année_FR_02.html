Exercice 1 — Définir une classe (15 min)

Énoncé : Créer une classe Livre avec : - Attributs : titre, auteur, annee, nb_pages - Méthode __init__ avec tous les paramètres - Méthode afficher() qui affiche les informations du livre - Méthode est_long() qui retourne True si le livre a plus de 300 pages

Corrigé :

class Livre:
    def __init__(self, titre, auteur, annee, nb_pages):
        self.titre = titre
        self.auteur = auteur
        self.annee = annee
        self.nb_pages = nb_pages

    def afficher(self):
        print(f"'{self.titre}' — {self.auteur} ({self.annee}), {self.nb_pages}p.")

    def est_long(self):
        return self.nb_pages > 300

# Test
l = Livre("Informatique ENS", "Belacel", 2026, 250)
l.afficher()
print("Long ?", l.est_long())  # False

Corrigé :

class CompteBancaire:
    def __init__(self, titulaire, solde_initial=0):
        self.titulaire = titulaire
        self.solde = solde_initial if solde_initial >= 0 else 0

    def deposer(self, montant):
        if montant > 0:
            self.solde += montant
            print(f"Dépôt de {montant} € effectué.")
        else:
            print("Montant invalide.")

    def retirer(self, montant):
        if 0 < montant <= self.solde:
            self.solde -= montant
            print(f"Retrait de {montant} € effectué.")
        else:
            print("Solde insuffisant ou montant invalide.")

    def afficher(self):
        print(f"Titulaire : {self.titulaire} — Solde : {self.solde} €")

Exercice 3 — Variables de classe (15 min)

Énoncé : Créer une classe Etudiant avec : - Variable de classe universite = "ENS Mostaganem" - Variable de classe total_etudiants = 0 - Attributs d'instance : nom, groupe - Le constructeur incrémente total_etudiants - Méthode __str__ qui retourne une chaîne descriptive

Créer 3 étudiants et afficher leurs informations et le total.

Corrigé :

class Etudiant:
    universite = "ENS Mostaganem"
    total_etudiants = 0

    def __init__(self, nom, groupe):
        self.nom = nom
        self.groupe = groupe
        Etudiant.total_etudiants += 1

    def __str__(self):
        return f"{self.nom} — {self.groupe} ({self.universite})"

# Test
e1 = Etudiant("Ali", "ENS2-A")
e2 = Etudiant("Sara", "ENS2-A")
e3 = Etudiant("Mohamed", "ENS2-B")

print(e1)  # Ali — ENS2-A (ENS Mostaganem)
print(e2)
print(e3)
print(f"Total : {Etudiant.total_etudiants} étudiants")  # 3

Exercice 4 — Composition de classes (20 min)

Énoncé : Créer deux classes :

  1. Matiere avec attributs nom, coefficient
  2. Evaluation avec attributs matiere (objet Matiere), note, date
  3. Méthode ponderer() qui retourne note × coefficient

Créer une matière « Informatique » (coef 3) et une évaluation notée 15. Afficher le résultat pondéré.

Corrigé :

class Matiere:
    def __init__(self, nom, coefficient):
        self.nom = nom
        self.coefficient = coefficient

    def __str__(self):
        return f"{self.nom} (coef {self.coefficient})"

class Evaluation:
    def __init__(self, matiere, note, date):
        self.matiere = matiere
        self.note = note
        self.date = date

    def ponderer(self):
        return self.note * self.matiere.coefficient

    def __str__(self):
        return f"{self.matiere.nom} : {self.note}/20 (coefficient {self.matiere.coefficient}) → {self.ponderer()} pts"

# Test
info = Matiere("Informatique", 3)
eval1 = Evaluation(info, 15, "2026-03-15")
print(eval1)  # Informatique : 15/20 → 45 pts

Exercice 5 — Classe avec liste d'objets (20 min)

Énoncé : Créer une classe Eleve qui contient une liste d'évaluations. Ajouter les méthodes : - ajouter_evaluation(matiere, note, date) — crée une Evaluation et l'ajoute à la liste - moyenne() — calcule la moyenne pondérée - afficher_releve() — affiche toutes les évaluations et la moyenne

Corrigé :

class Eleve:
    def __init__(self, nom, prenom):
        self.nom = nom
        self.prenom = prenom
        self.evaluations = []

    def ajouter_evaluation(self, matiere, note, date):
        ev = Evaluation(matiere, note, date)
        self.evaluations.append(ev)

    def moyenne(self):
        if not self.evaluations:
            return 0.0
        total_pondere = sum(ev.ponderer() for ev in self.evaluations)
        total_coef = sum(ev.matiere.coefficient for ev in self.evaluations)
        return total_pondere / total_coef if total_coef > 0 else 0.0

    def afficher_releve(self):
        print(f"=== Relevé de {self.prenom} {self.nom} ===")
        for ev in self.evaluations:
            print(f"  {ev}")
        print(f"  Moyenne générale : {self.moyenne():.2f}/20")

# Test
francais = Matiere("Français", 2)
anglais = Matiere("Anglais", 1)

eleve = Eleve("Benali", "Sara")
eleve.ajouter_evaluation(info, 15, "2026-03-15")
eleve.ajouter_evaluation(francais, 12, "2026-03-16")
eleve.ajouter_evaluation(anglais, 18, "2026-03-17")
eleve.afficher_releve()

Note pédagogique ENS

Transposition didactique : Les concepts de classe et d'objet sont transposables au collège à travers la notion de « fiche modèle » : une classe est un modèle (template) dont chaque objet est une instance concrète (ex. : modèle de fiche élève → fiches remplies). La composition peut être illustrée par un sac de cours contenant plusieurs matières.

Conseil pour l'enseignant formateur : Faites réaliser une affiche papier représentant une classe avec ses attributs et ses méthodes, puis demandez aux étudiants de « jouer » l'exécution d'une méthode en groupe. Cette approche kinesthésique renforce la compréhension des concepts abstraits.

Prolongement : Proposer un mini-projet de création d'un système de gestion de bibliothèque avec des classes Livre, Adherent et Emprunt, incluant la persistance des données dans un fichier JSON.
