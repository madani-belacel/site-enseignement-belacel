4. Code guidé — Flask (20 min)

# app.py
from flask import Flask, render_template, request, redirect
from modele import Eleve, Note
from database import init_db, ajouter_eleve, get_eleves

app = Flask(__name__)

@app.route("/")
def index():
    return render_template("index.html")

@app.route("/eleves")
def liste_eleves():
    eleves = get_eleves()
    return render_template("eleves.html", eleves=eleves)

@app.route("/ajouter", methods=["POST"])
def ajouter():
    nom = request.form["nom"]
    prenom = request.form["prenom"]
    groupe = request.form["groupe"]
    ajouter_eleve(nom, prenom, groupe)
    return redirect("/eleves")

if __name__ == "__main__":
    init_db()
    app.run(debug=True)

5. Modèle POO (15 min)

# modele.py
class Eleve:
    def __init__(self, id, nom, prenom, groupe):
        self.id = id
        self.nom = nom
        self.prenom = prenom
        self.groupe = groupe
        self.notes = []

    def moyenne(self):
        if not self.notes:
            return 0.0
        return sum(n.valeur for n in self.notes) / len(self.notes)

    def ajouter_note(self, matiere, valeur):
        if 0 <= valeur <= 20:
            self.notes.append(Note(self.id, matiere, valeur))

class Note:
    def __init__(self, eleve_id, matiere, valeur):
        self.eleve_id = eleve_id
        self.matiere = matiere
        self.valeur = valeur

6. Base de données (10 min)

# database.py
import sqlite3

DB = "donnees/ecole.db"

def init_db():
    conn = sqlite3.connect(DB)
    c = conn.cursor()
    c.execute("""
        CREATE TABLE IF NOT EXISTS eleves (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nom TEXT NOT NULL,
            prenom TEXT NOT NULL,
            groupe TEXT
        )
    """)
    c.execute("""
        CREATE TABLE IF NOT EXISTS notes (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            eleve_id INTEGER NOT NULL,
            matiere TEXT NOT NULL,
            valeur REAL NOT NULL CHECK(valeur >= 0 AND valeur <= 20),
            FOREIGN KEY(eleve_id) REFERENCES eleves(id)
        )
    """)
    conn.commit()
    conn.close()

def get_eleves():
    conn = sqlite3.connect(DB)
    conn.row_factory = sqlite3.Row
    c = conn.cursor()
    c.execute("SELECT * FROM eleves")
    eleves = [dict(row) for row in c.fetchall()]
    conn.close()
    return eleves

Note pédagogique ENS

Transposition didactique : La méthodologie de projet présentée ici (cahier des charges, architecture, sprints) peut être transposée au collège/lycée sous forme de projet Scratch ou Python. L'important est de suivre la même démarche : 1) définir le besoin, 2) concevoir la solution, 3) implémenter par itérations, 4) tester, 5) présenter. En NSI Terminale, le projet est une épreuve du baccalauréat — cette séance prépare donc directement les futurs enseignants à accompagner leurs élèves.

Conseil pour l'enseignant formateur : Le projet ENS2 est le moment de vérité du module. Veillez à ce que chaque étudiant ait un projet fonctionnel minimal avant de viser des fonctionnalités avancées ("Make it work, then make it better"). Encouragez la collaboration mais vérifiez les contributions individuelles via Git (chaque étudiant doit commiter). Prévoyez un moment de revue de code entre pairs avant la soutenance.

Prolongement : Les étudiants peuvent étendre le projet avec des fonctionnalités avancées : import CSV (pour charger une classe existante), génération de graphiques de répartition des notes, envoi de relevés de notes par email, ou interface d'administration avec login. Ces extensions peuvent être présentées comme "bonus" lors de la soutenance et valorisées dans la note.
