Programme du Module Informatique — ENS 2ème année (FR)

Enseignant : BELACEL Madani
Établissement : École Normale Supérieure de Mostaganem
Département : Français
Module : Informatique
Niveau : 2ème année
Volume horaire : 15 séances × 1h30 = 22h30
Année universitaire : 2025-2026
Crédits : À définir selon maquette

1. Présentation du module

Le module d'Informatique pour la 2ème année ENS approfondit les compétences acquises en 1ère année. Il couvre la programmation orientée objet (POO) en Python, les algorithmes avancés (récursivité, tris, recherche), les bases de données et SQL, le développement Web fondamental (HTML/CSS/JavaScript), l'utilisation de Git pour la collaboration, et la didactique de l'informatique pour l'enseignement secondaire. L'accent est mis sur le projet intégré qui consolide l'ensemble des compétences.

2. Compétences visées

À l'issue du module, l'étudiant sera capable de :

Compétence Composantes
C1 — Programmer en POO Python Classes, objets, héritage, encapsulation, polymorphisme
C2 — Concevoir des algorithmes avancés Récursivité, tri bulle, tri fusion, recherche dichotomique, complexité
C3 — Modéliser et interroger des bases de données Modèle relationnel, SQLite, SELECT, JOIN, INSERT, normalisation
C4 — Développer des applications Web HTML5, CSS3, JavaScript, formulaires, architecture client-serveur
C5 — Utiliser Git pour la collaboration init, add, commit, branch, merge, GitHub, README
C6 — Enseigner l'informatique au secondaire Didactique, Scratch, Python pédagogique, PIX, fiche de séance
C7 — Concevoir un projet intégré Architecture Flask, base de données, déploiement, soutenance

3. Plan du module détaillé

Séance Contenu Compétences
01 Introduction ENS2 — Rappel ENS1, montée en compétence, présentation du projet C1–C7
02 POO Python 1 — Classes, objets, attributs, méthodes, constructeur __init__ C1
03 POO Python 2 — Héritage, polymorphisme, super(), encapsulation C1
04 Algorithmes avancés — Récursivité, tri bulle, tri fusion, recherche dichotomique C2
05 Bases de données — Modèle relationnel, SQLite, SELECT/JOIN, Python+DB C3
06 Développement Web — HTML, CSS, JavaScript, formulaires, client-serveur C4
07 Git et collaboration — init, add, commit, branch, merge, GitHub, README C5
08 Didactique de l'informatique — Programmes officiels, Scratch, Python pédagogique, PIX C6
09 Conception du projet ENS2 — Architecture Flask, modèle POO, base de données, planification C7
10 Projet ENS2 final et soutenance — Application Web de gestion, démo, fiche pédagogique C7

6. Références officielles algériennes

Ce programme s'inscrit dans le cadre des textes réglementaires et des référentiels nationaux algériens suivants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — texte fondateur définissant le cadre de formation des Écoles Normales Supérieures en Algérie.
  • Programme national d'Informatique des ENS algériennes — programme cadre définissant les objectifs, contenus et volumes horaires du module Informatique dans la formation des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — texte réglementaire fixant les épreuves et programmes des concours d'accès aux ENS.
  • Référentiel des compétences numériques algérien — référentiel national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants formés aux ENS.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique dans les universités algériennes, consultée pour l'élaboration de ce programme.
