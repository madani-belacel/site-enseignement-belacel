Exercice 1 — Héritage simple (15 min)

Énoncé : Créer une classe mère Personne et une classe fille Enseignant :

class Personne:
    def __init__(self, nom, prenom, email):
        # À compléter
        pass

    def se_presenter(self):
        return f"Je m'appelle {self.prenom} {self.nom}"

class Enseignant(Personne):
    def __init__(self, nom, prenom, email, matiere):
        # À compléter : appeler le constructeur parent ET stocker la matière
        pass

    def se_presenter(self):
        # À compléter : surcharger pour ajouter la matière
        pass

Corrigé :

class Personne:
    def __init__(self, nom, prenom, email):
        self.nom = nom
        self.prenom = prenom
        self.email = email

    def se_presenter(self):
        return f"Je m'appelle {self.prenom} {self.nom}"

class Enseignant(Personne):
    def __init__(self, nom, prenom, email, matiere):
        super().__init__(nom, prenom, email)
        self.matiere = matiere

    def se_presenter(self):
        base = super().se_presenter()
        return f"{base} et j'enseigne la {self.matiere}"

# Test
prof = Enseignant("Belacel", "Madani", "m.belacel@ens.dz", "Informatique")
print(prof.se_presenter())
# Je m'appelle Madani Belacel et j'enseigne l'Informatique

Exercice 2 — Surcharge et super() (15 min)

Énoncé : Créer une hiérarchie de trois niveaux :

  1. Animal : attribut nom, méthode parler() → retourne "..."
  2. Chien(Animal) : surcharge parler() → retourne "Woof !"
  3. ChienDeGarde(Chien) : surcharge parler() → utilise super().parler() puis ajoute " Méchant chien !"

Créer un ChienDeGarde nommé "Rex" et appeler parler().

Corrigé :

class Animal:
    def __init__(self, nom):
        self.nom = nom

    def parler(self):
        return "..."

class Chien(Animal):
    def parler(self):
        return "Woof !"

class ChienDeGarde(Chien):
    def parler(self):
        return super().parler() + " Méchant chien !"

# Test
rex = ChienDeGarde("Rex")
print(f"{rex.nom} dit : {rex.parler()}")
# Rex dit : Woof ! Méchant chien !

Exercice 3 — Polymorphisme (20 min)

Énoncé : Créer une fonction faire_parler(animal) qui appelle la méthode parler() de n'importe quel animal. Puis créer :

  • Chat(Animal) avec parler() → "Miaou !"
  • Vache(Animal) avec parler() → "Meuh !"
  • Canard(Animal) avec parler() → "Coin coin !"

Tester la fonction avec les trois animaux.

Corrigé :

class Chat(Animal):
    def parler(self):
        return "Miaou !"

class Vache(Animal):
    def parler(self):
        return "Meuh !"

class Canard(Animal):
    def parler(self):
        return "Coin coin !"

def faire_parler(animal):
    """Fonction polymorphe : Accepte n'importe quel Animal"""
    print(f"{animal.nom} dit : {animal.parler()}")

# Test
animaux = [
    Chat("Minou"),
    Vache("Marguerite"),
    Canard("Donald"),
    ChienDeGarde("Rex")
]

for a in animaux:
    faire_parler(a)

Résultat :

Minou dit : Miaou !
Marguerite dit : Meuh !
Donald dit : Coin coin !
Rex dit : Woof ! Méchant chien !

Exercice 4 — Encapsulation (20 min)

Énoncé : Créer une classe CompteEpargne avec : - Attribut protégé _taux (taux d'intérêt annuel en %, ex: 2.5) - Attribut privé __solde (ne peut être modifié directement) - Getter solde avec @property - Setter solde avec @solde.setter (vérifie que le montant ≥ 0) - Méthode appliquer_interets() qui ajoute les intérêts au solde

Corrigé :

class CompteEpargne:
    def __init__(self, titulaire, solde=0, taux=2.5):
        self.titulaire = titulaire
        self._taux = taux
        self.__solde = 0
        if solde >= 0:
            self.__solde = solde

    @property
    def solde(self):
        return self.__solde

    @solde.setter
    def solde(self, montant):
        if montant >= 0:
            self.__solde = montant
        else:
            print("Erreur : le solde ne peut pas être négatif.")

    def appliquer_interets(self):
        interets = self.__solde * (self._taux / 100)
        self.__solde += interets
        print(f"Intérêts de {interets:.2f} € appliqués (taux {self._taux}%).")

    def __str__(self):
        return f"{self.titulaire} — {self.__solde:.2f} €"

# Test
ce = CompteEpargne("Ali", 1000, 2.5)
print(ce)             # Ali — 1000.00 €
ce.appliquer_interets()  # Intérêts de 25.00 € appliqués
print(ce)             # Ali — 1025.00 €
# ce.__solde = 9999  # Erreur ! Attribut privé inaccessible
print(ce.solde)       # 1025.0 (via getter)

Exercice 5 — Hiérarchie scolaire complète (20 min)

Énoncé : Créer les classes suivantes avec héritage :

  1. MembreENS : nom, prenom, email
  2. Etudiant(MembreENS) : groupe, liste de notes
  3. ajouter_note(note), moyenne(), __str__()
  4. Professeur(MembreENS) : matiere, liste de cours
  5. ajouter_cours(cours), __str__()
  6. Tester avec un étudiant et un professeur

Corrigé :

class MembreENS:
    def __init__(self, nom, prenom, email):
        self.nom = nom
        self.prenom = prenom
        self.email = email

    def __str__(self):
        return f"{self.prenom} {self.nom}"

class Etudiant(MembreENS):
    def __init__(self, nom, prenom, email, groupe):
        super().__init__(nom, prenom, email)
        self.groupe = groupe
        self.notes = []

    def ajouter_note(self, note):
        if 0 <= note <= 20:
            self.notes.append(note)

    def moyenne(self):
        return sum(self.notes) / len(self.notes) if self.notes else 0.0

    def __str__(self):
        return f"{super().__str__()} — {self.groupe} (Moy: {self.moyenne():.2f})"

class Professeur(MembreENS):
    def __init__(self, nom, prenom, email, matiere):
        super().__init__(nom, prenom, email)
        self.matiere = matiere
        self.cours = []

    def ajouter_cours(self, cours):
        self.cours.append(cours)

    def __str__(self):
        return f"{super().__str__()} — {self.matiere} ({len(self.cours)} cours)"

# Test
etu = Etudiant("Benali", "Sara", "s.benali@ens.dz", "ENS2-A")
etu.ajouter_note(15)
etu.ajouter_note(12)
etu.ajouter_note(18)
print(etu)  # Sara Benali — ENS2-A (Moy: 15.00)

prof = Professeur("Belacel", "Madani", "m.belacel@ens.dz", "Informatique")
prof.ajouter_cours("POO")
prof.ajouter_cours("BD")
print(prof)  # Madani Belacel — Informatique (2 cours)

Note pédagogique ENS

Transposition didactique : L'héritage peut être introduit au collège par la notion de « catégories et sous-catégories » (ex. : Animal → Mammifère → Chien), ce qui correspond à la pensée classificatoire enseignée en sciences. Le polymorphisme s'illustre par une même consigne (« fais-toi présenter ») qui produit des résultats différents selon l'objet.

Conseil pour l'enseignant formateur : Utilisez des supports visuels (cartes de classe, diagrammes de héritage au tableau) avant de passer au code. Proposez un exercice débranché où les étudiants incarnent des objets et exécutent des méthodes en suivant le chaînage d'héritage.

Prolongement : Étudier le patron de conception « Template Method » ou « Strategy » en montrant comment l'héritage et le polymorphisme permettent de concevoir des frameworks réutilisables.
