Cours Informatique — ENS 2ème année — Séance 06 (FR)

Enseignant : BELACEL Madani
Module : Informatique
Niveau : ENS — 2ème année — Département de français
Durée : 1h30
Année universitaire : 2025-2026

Fiche cours — Plateforme e-learning (Moodle)

Référentiel : benchmark 10 universités algériennes + pratiques USTO/Biskra/M'sila.

Public visé : Étudiants ENS 2ème année — Département Français

Compétences pré-requises : Réseaux (ENS1 séance 07), fichiers Python (ENS1 séance 09)

Objectifs transversaux : - Appliquer la programmation orientée objet (classes, héritage, encapsulation) en Python - Concevoir des algorithmes avancés (tri, recherche, récursivité) et estimer leur complexité - Modéliser des données avec le modèle relationnel et requêtes SQL de base - Comprendre l'architecture Web (HTML, CSS, JavaScript intro, HTTP) - Utiliser Git et méthodes de travail collaboratif (branches, merge) - Préparer l'enseignement de l'informatique au collège/lycée (Scratch, Python pédagogique)

Mode d'évaluation : TP POO + SQL 35 % — Projet intégré 40 % — Fiche séance pédagogique 25 %

Bibliographie : MDN Web Docs (developer.mozilla.org) ; Duckett — HTML & CSS

Objectifs pédagogiques spécifiques

À l'issue de cette séance, l'étudiant est capable de : - Créer une page HTML structurée (head, body, sections) - Appliquer des styles CSS (couleurs, polices, mise en page) - Ajouter un script JavaScript simple (interaction utilisateur) - Expliquer le cycle requête/réponse HTTP - Comprendre le rôle des formulaires Web

Contexte réglementaire algérien

Ce cours s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique, consultée pour aligner ce cours sur les standards nationaux.

1. Architecture Web (10 min)

Client-serveur : le navigateur (client) envoie une requête HTTP au serveur, qui répond avec le contenu.

    Client->>Serveur: GET /index.html
    Serveur-->>Client: 200 OK [HTML]
    Client->>Serveur: GET /style.css
    Serveur-->>Client: 200 OK [CSS]
    Client->>Serveur: POST /envoyer (formulaire)
    Serveur->>BD: INSERT INTO messages
    BD-->>Serveur: OK
    Serveur-->>Client: 301 Redirect /merci

    Serveur-->>Client: 200 OK [HTML]

4. JavaScript (15 min)

JavaScript permet l'interactivité côté client.

<!DOCTYPE html>
<html>
<body>
    <h2>Calculateur de moyenne</h2>
    <input type="number" id="note1" placeholder="Note 1">
    <input type="number" id="note2" placeholder="Note 2">
    <input type="number" id="note3" placeholder="Note 3">
    <button onclick="calculer()">Calculer</button>
    <p id="resultat"></p>

    <script>
        function calculer() {
            let n1 = parseFloat(document.getElementById("note1").value);
            let n2 = parseFloat(document.getElementById("note2").value);
            let n3 = parseFloat(document.getElementById("note3").value);
            let moyenne = (n1 + n2 + n3) / 3;
            document.getElementById("resultat").innerHTML =
                "Moyenne : " + moyenne.toFixed(2);
        }
    </script>
</body>
</html>

7. Mini-projet (10 min)

Créer une page web personnelle pour votre futur métier d'enseignant : 1. Structure HTML (bio, cours, contact) 2. Style CSS (couleurs ENS : bleu foncé #003366) 3. Formulaire de contact 4. Lien vers le dépôt GitHub

QCM d'auto-évaluation

  1. Que signifie HTML ? a) HyperText Markup Language ✓ b) High Tech Modern Language c) Home Tool Markup Language

  2. Quelle balise HTML permet de créer un lien hypertexte ? a) <link> b) <a> ✓ c) <href>

  3. Quel langage contrôle l'apparence d'une page Web ? a) HTML b) CSS ✓ c) JavaScript

  4. Quel type d'input HTML est utilisé pour les mots de passe ? a) text b) password ✓ c) hidden

  5. Qu'est-ce qu'une requête HTTP GET ? a) Envoie des données au serveur via l'URL ✓ b) Modifie la base de données c) Établit une connexion permanente

Note pédagogique ENS

Transposition didactique : Le Web peut être enseigné au collège à travers la création de pages HTML simples. En SNT Seconde (thème "Web"), les élèves apprennent à distinguer client et serveur, à comprendre le rôle du navigateur, et à inspecter le code source d'une page. L'activité de mini-projet "page personnelle enseignant" peut être adaptée pour des élèves de 3ème en leur faisant créer une page HTML sur un métier qui les intéresse. La séquence client-serveur peut être simulée par un jeu de rôle : un élève est le serveur, un autre le client.

Conseil pour l'enseignant formateur : Les étudiants ont souvent du mal avec la séparation HTML/CSS. Insistez sur le principe de responsabilité unique : HTML pour le fond, CSS pour la forme. Un exercice efficace consiste à fournir le même HTML et demander aux étudiants d'appliquer des CSS différents pour produire des rendus visuels totalement différents. Cela illustre la puissance et la flexibilité du CSS.

Prolongement : Les étudiants peuvent créer un mini-site complet d'enseignant avec plusieurs pages (accueil, cours, contact), un menu de navigation responsive (media queries), et un formulaire de contact fonctionnel utilisant un service comme Formspree ou un backend Flask simple. Ils peuvent également ajouter une page "portfolio de projets" avec des captures d'écran et des liens GitHub.
