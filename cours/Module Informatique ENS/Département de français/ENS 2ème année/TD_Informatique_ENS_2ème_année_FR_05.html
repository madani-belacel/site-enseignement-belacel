Exercice 1 — CREATE TABLE et INSERT (20 min)

Énoncé : Soit le schéma relationnel d'une bibliothèque : - Auteur (id_auteur INT PRIMARY KEY, nom VARCHAR(50), prenom VARCHAR(50), annee_naissance INT) - Livre (id_livre INT PRIMARY KEY, titre VARCHAR(100), annee_publication INT, id_auteur INT REFERENCES Auteur(id_auteur))

  1. Écrire les instructions CREATE TABLE
  2. Insérer 3 auteurs et 4 livres
  3. Afficher tous les livres

Corrigé :

CREATE TABLE Auteur (
    id_auteur INT PRIMARY KEY,
    nom VARCHAR(50),
    prenom VARCHAR(50),
    annee_naissance INT
);

CREATE TABLE Livre (
    id_livre INT PRIMARY KEY,
    titre VARCHAR(100),
    annee_publication INT,
    id_auteur INT REFERENCES Auteur(id_auteur)
);

INSERT INTO Auteur VALUES

(2, 'Knuth', 'Donald', 1938),
(3, 'Turing', 'Alan', 1912);

INSERT INTO Livre VALUES
(1, 'The Art of Computer Programming', 1968, 2),
(2, 'A Discipline of Programming', 1976, 1),
(3, 'Computing Machinery and Intelligence', 1950, 3),
(4, 'Selected Writings on Computing', 1982, 1);

SELECT * FROM Livre;

Exercice 2 — SELECT et WHERE (15 min)

Énoncé : Sur la table Livre ci-dessus, écrire les requêtes suivantes :

  1. Titres des livres publiés après 1970
  2. Livres de l'auteur id_auteur = 1 (Dijkstra)
  3. Livres dont le titre contient "Programming"

Corrigé :

-- 1. Livres après 1970
SELECT titre, annee_publication
FROM Livre
WHERE annee_publication > 1970;

-- 2. Livres de Dijkstra
SELECT titre
FROM Livre
WHERE id_auteur = 1;

-- 3. Titre contient "Programming"
SELECT titre, annee_publication
FROM Livre
WHERE titre LIKE '%Programming%';

Exercice 3 — Jointure avec INNER JOIN (20 min)

Énoncé : Enrichir la base avec une table Emprunt (id_emprunt INT PRIMARY KEY, id_livre INT REFERENCES Livre, date_emprunt DATE, nom_emprunteur VARCHAR(50)).

Insérer 5 emprunts puis écrire les requêtes :

  1. Afficher chaque emprunt avec le titre du livre et le nom de l'auteur
  2. Compter le nombre d'emprunts par auteur
  3. Trouver le(s) livre(s) jamais emprunté(s)

Corrigé :

CREATE TABLE Emprunt (
    id_emprunt INT PRIMARY KEY,
    id_livre INT REFERENCES Livre(id_livre),
    date_emprunt DATE,
    nom_emprunteur VARCHAR(50)
);

INSERT INTO Emprunt VALUES
(1, 1, '2026-01-15', 'Ali'),
(2, 1, '2026-02-10', 'Sara'),
(3, 3, '2026-03-05', 'Mohamed'),
(4, 2, '2026-03-12', 'Ali'),
(5, 4, '2026-04-01', 'Sara');

-- 1. Emprunts avec titre et auteur
SELECT e.nom_emprunteur, l.titre, a.nom || ' ' || a.prenom AS auteur, e.date_emprunt
FROM Emprunt e
INNER JOIN Livre l ON e.id_livre = l.id_livre
INNER JOIN Auteur a ON l.id_auteur = a.id_auteur;

-- 2. Nombre d'emprunts par auteur
SELECT a.nom || ' ' || a.prenom AS auteur, COUNT(e.id_emprunt) AS nb_emprunts
FROM Auteur a
LEFT JOIN Livre l ON a.id_auteur = l.id_auteur
LEFT JOIN Emprunt e ON l.id_livre = e.id_livre
GROUP BY a.id_auteur, auteur;

-- 3. Livres jamais empruntés
SELECT l.titre
FROM Livre l
LEFT JOIN Emprunt e ON l.id_livre = e.id_livre
WHERE e.id_emprunt IS NULL;

Exercice 4 — Mise à jour et suppression (15 min)

Énoncé : Écrire les requêtes SQL pour :

  1. Ajouter une colonne disponible BOOLEAN à Livre
  2. Mettre à jour la colonne : TRUE si le livre n'a aucun emprunt en cours
  3. Supprimer un auteur et ses livres (CASCADE)

Corrigé :

-- 1. Ajouter colonne
ALTER TABLE Livre ADD COLUMN disponible BOOLEAN DEFAULT TRUE;

-- 2. Mettre à jour (livres ayant des emprunts = non disponibles)
UPDATE Livre SET disponible = FALSE
WHERE id_livre IN (SELECT DISTINCT id_livre FROM Emprunt);

-- Vérification
SELECT titre, disponible FROM Livre;

Exercice 5 — Modélisation complète (20 min)

Énoncé : Concevoir le schéma relationnel pour une gestion d'étudiants et de leurs inscriptions aux cours avec notes :

  1. Créer les tables Etudiant, Cours, Inscription
  2. Insérer 3 étudiants, 2 cours, 5 inscriptions
  3. Afficher pour chaque étudiant : son nom, les cours suivis et la note

Corrigé :

CREATE TABLE Etudiant (
    id_etudiant INT PRIMARY KEY,
    nom VARCHAR(50),
    prenom VARCHAR(50),
    email VARCHAR(100)
);

CREATE TABLE Cours (
    id_cours INT PRIMARY KEY,
    intitule VARCHAR(100),
    credit INT
);

CREATE TABLE Inscription (
    id_etudiant INT REFERENCES Etudiant(id_etudiant),
    id_cours INT REFERENCES Cours(id_cours),
    note DECIMAL(4,2),
    PRIMARY KEY (id_etudiant, id_cours)
);

INSERT INTO Etudiant VALUES
(1, 'Benali', 'Sara', 's.benali [at] ens.dz'),
(2, 'Ziani', 'Ahmed', 'a.ziani [at] ens.dz'),
(3, 'Kaci', 'Leila', 'l.kaci [at] ens.dz');

INSERT INTO Cours VALUES
(101, 'POO', 4),
(102, 'BD', 3);

INSERT INTO Inscription VALUES
(1, 101, 15.00),
(1, 102, 12.50),
(2, 101, 17.00),
(2, 102, 14.00),
(3, 101, 10.50);

-- Relevé complet
SELECT e.nom || ' ' || e.prenom AS etudiant,
       c.intitule AS cours,
       i.note
FROM Inscription i
JOIN Etudiant e ON i.id_etudiant = e.id_etudiant
JOIN Cours c ON i.id_cours = c.id_cours
ORDER BY etudiant, cours;

-- Moyenne par étudiant
SELECT e.nom || ' ' || e.prenom AS etudiant,
       ROUND(AVG(i.note), 2) AS moyenne
FROM Inscription i
JOIN Etudiant e ON i.id_etudiant = e.id_etudiant
GROUP BY e.id_etudiant, etudiant;

Note pédagogique ENS

Transposition didactique : La modélisation relationnelle peut être introduite au collège par la création de tableaux à double entrée (lignes = enregistrements, colonnes = attributs), ce que les élèves manipulent déjà en mathématiques. Les jointures s'illustrent par le « jeu des mots croisés » où l'on relie deux grilles par une information commune.

Conseil pour l'enseignant formateur : Commencez par un exercice « papier-crayon » de modélisation avant de passer au SQL. Demandez aux étudiants de dessiner le schéma entité-association au tableau et de vérifier les cardinalités. Insistez sur la différence entre WHERE (filtrage sur ligne) et HAVING (filtrage sur groupe).

Prolongement : Proposer un projet de création d'une petite base de données pour la bibliothèque de l'établissement avec une interface Web simple en PHP ou Python Flask permettant de lister, ajouter et rechercher des livres.
