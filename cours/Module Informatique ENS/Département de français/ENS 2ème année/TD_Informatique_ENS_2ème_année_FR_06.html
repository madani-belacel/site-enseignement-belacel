Exercice 1 — Structure HTML de base (15 min)

Énoncé : Créer une page HTML presentation.html qui présente votre CV en ligne. Inclure : - Titre "Mon CV" - En-tête avec votre nom (balise <h1>) - Une photo de profil fictive (image placeholder) - Une section "À propos" en paragraphe - Une liste de compétences (non ordonnée) - Un pied de page avec votre email

Corrigé :

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Mon CV</title>
</head>
<body>
    <header>
        <h1>Sara Benali</h1>
        <img src="https://via.placeholder.com/150" alt="Photo de profil">
    </header>

    <section>
        <h2>À propos</h2>
        <p>Étudiante en 2ème année à l'ENS Mostaganem. Passionnée d'informatique et de pédagogie.</p>
    </section>

    <section>
        <h2>Compétences</h2>
        <ul>
            <li>Python, Java, SQL</li>
            <li>Développement Web (HTML, CSS, JavaScript)</li>
            <li>Systèmes d'exploitation (Linux, Windows)</li>
        </ul>
    </section>

    <footer>
        <p>Contact : s.benali [at] ens.dz</p>
    </footer>
</body>
</html>

Exercice 3 — JavaScript : DOM et événements (20 min)

Énoncé : Ajouter un script JavaScript à la page CV pour :

  1. Un bouton "Afficher/Masquer" les compétences (toggle)
  2. Un compteur de visites stocké dans localStorage
  3. Affichage de la date et heure actuelle dans le footer

Corrigé :

<script>
    // 1. Toggle compétences
    function toggleCompetences() {
        const section = document.querySelector('section:nth-of-type(2)');
        if (section.style.display === 'none') {
            section.style.display = 'block';
            btn.textContent = 'Masquer les compétences';
        } else {
            section.style.display = 'none';
            btn.textContent = 'Afficher les compétences';
        }
    }

    const btn = document.createElement('button');
    btn.textContent = 'Masquer les compétences';
    btn.onclick = toggleCompetences;
    document.body.insertBefore(btn, document.querySelector('footer'));

    // 2. Compteur de visites
    let visites = localStorage.getItem('cv_visites') || 0;
    visites++;
    localStorage.setItem('cv_visites', visites);
    const compteur = document.createElement('p');
    compteur.textContent = `Visites : ${visites}`;
    document.querySelector('footer').appendChild(compteur);

    // 3. Horloge
    function afficherHeure() {
        const now = new Date();
        const horloge = document.getElementById('horloge');
        if (horloge) {
            horloge.textContent = now.toLocaleString('fr-FR');
        }
    }
    // Ajouter dans footer
    const horloge = document.createElement('p');
    horloge.id = 'horloge';
    document.querySelector('footer').appendChild(horloge);
    setInterval(afficherHeure, 1000);
    afficherHeure();
</script>

Exercice 4 — Formulaire avec validation (20 min)

Énoncé : Créer une page HTML contact.html avec un formulaire de contact : - Champs : nom, email, message - Validation JavaScript : nom non vide, email valide (contient @), message ≥ 10 caractères - Afficher les erreurs sous chaque champ - Au succès, afficher "Merci !" dans une boîte

Corrigé :

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Contact</title>
    <style>
        body { font-family: Arial, sans-serif; max-width: 600px; margin: 50px auto; }
        label { display: block; margin-top: 10px; font-weight: bold; }
        input, textarea { width: 100%; padding: 8px; margin-top: 5px; }
        .error { color: red; font-size: 0.9em; }
        .success { background: #d4edda; padding: 20px; border-radius: 5px; }
        button { margin-top: 15px; padding: 10px 20px; background: #4a90d9; color: white; border: none; cursor: pointer; }
    </style>
</head>
<body>
    <h1>Contactez-nous</h1>
    <form id="contactForm">
        <label>Nom :</label>
        <input type="text" id="nom">
        <div class="error" id="nomError"></div>

        <label>Email :</label>
        <input type="email" id="email">
        <div class="error" id="emailError"></div>

        <label>Message :</label>
        <textarea id="message" rows="5"></textarea>
        <div class="error" id="messageError"></div>

        <button type="submit">Envoyer</button>
    </form>
    <div id="success" style="display:none;" class="success"><h2>Merci !</h2></div>

    <script>
        document.getElementById('contactForm').onsubmit = function(e) {
            e.preventDefault();

            // Réinitialiser
            document.querySelectorAll('.error').forEach(el => el.textContent = '');
            document.getElementById('success').style.display = 'none';

            const nom = document.getElementById('nom').value.trim();
            const email = document.getElementById('email').value.trim();
            const message = document.getElementById('message').value.trim();
            let valide = true;

            if (!nom) {
                document.getElementById('nomError').textContent = 'Le nom est requis.';
                valide = false;
            }

            if (!email || !email.includes('@')) {
                document.getElementById('emailError').textContent = 'Email invalide.';
                valide = false;
            }

            if (message.length < 10) {
                document.getElementById('messageError').textContent = 'Le message doit contenir au moins 10 caractères.';
                valide = false;
            }

            if (valide) {
                document.getElementById('contactForm').reset();
                document.getElementById('success').style.display = 'block';
            }
        };
    </script>
</body>
</html>

Exercice 5 — Mini-projet : To-do list interactive (15 min)

Énoncé : Créer une to-do list avec HTML + CSS + JS dans un seul fichier. Fonctionnalités : - Champ de saisie + bouton "Ajouter" - Cliquer sur un élément le marque comme terminé (barré) - Bouton supprimer à côté de chaque tâche

Corrigé :

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>To-Do List</title>
    <style>
        body { font-family: Arial; max-width: 500px; margin: 50px auto; }
        .ajout { display: flex; gap: 10px; margin-bottom: 20px; }
        input { flex: 1; padding: 10px; }
        button { padding: 10px 20px; cursor: pointer; }
        ul { list-style: none; padding: 0; }
        li { display: flex; justify-content: space-between; align-items: center;
             padding: 10px; background: #f9f9f9; margin: 5px 0; border-radius: 5px; cursor: pointer; }
        li.fait { text-decoration: line-through; color: #888; background: #e9e9e9; }
        .suppr { background: #dc3545; color: white; border: none; padding: 5px 10px; cursor: pointer; border-radius: 3px; }
    </style>
</head>
<body>
    <h1>To-Do List</h1>
    <div class="ajout">
        <input type="text" id="tacheInput" placeholder="Nouvelle tâche...">
        <button onclick="ajouterTache()">Ajouter</button>
    </div>
    <ul id="listeTaches"></ul>

    <script>
        function ajouterTache() {
            const input = document.getElementById('tacheInput');
            const texte = input.value.trim();
            if (!texte) return;

            const li = document.createElement('li');
            li.textContent = texte;

            li.onclick = function(e) {
                if (e.target !== btn) this.classList.toggle('fait');
            };

            const btn = document.createElement('button');
            btn.textContent = '✕';
            btn.className = 'suppr';
            btn.onclick = function(e) {
                e.stopPropagation();
                li.remove();
            };

            li.appendChild(btn);
            document.getElementById('listeTaches').appendChild(li);
            input.value = '';
            input.focus();
        }

        document.getElementById('tacheInput').addEventListener('keypress', function(e) {
            if (e.key === 'Enter') ajouterTache();
        });
    </script>
</body>
</html>

Grille d'évaluation

Critère Poids Non acquis (0) Partiel (0.5) Acquis (1)
Structure HTML (titres, sections, footer) 20 % Absence d'éléments requis Partiellement complète Structure complète et valide
Mise en page CSS 20 % Aucun style appliqué Style partiel Design cohérent et responsive
Interactivité JavaScript (DOM) 20 % Aucun script Scripts partiels Toggle, compteur, horloge fonctionnels
Validation de formulaire 20 % Aucune validation Validation partielle Validation complète avec messages d'erreur
To-do list interactive 20 % Non fonctionnelle Partiellement fonctionnelle Ajout, marquage, suppression opérationnels

Note pédagogique ENS

Transposition didactique : Les concepts de HTML/CSS/JS peuvent être transposés au collège en introduisant d'abord la structure d'une page web avec HTML simple, puis la mise en forme avec CSS sans JavaScript. En lycée, on ajoute l'interactivité avec JavaScript pour créer des pages dynamiques et des formulaires.

Conseil pour l'enseignant formateur : Insister sur la séparation des préoccupations (structure/style/comportement) et sur les bonnes pratiques d'accessibilité. Proposer des exercices progressifs : d'abord reproduire des maquettes, puis créer librement.

Prolongement : Demander aux étudiants d'intégrer une API externe (ex. météo) ou de publier leur CV en ligne via GitHub Pages.
