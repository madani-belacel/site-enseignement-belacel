1) Objectifs pédagogiques

À l'issue de ce module, l'étudiant en ENS 2ème année est capable de :

  • Appliquer la programmation orientée objet (classes, héritage, encapsulation) en Python.
  • Concevoir des algorithmes avancés (tri, recherche, récursivité) et estimer leur complexité.
  • Modéliser des données avec le modèle relationnel et requêtes SQL de base.
  • Comprendre l'architecture Web (HTML, CSS, JavaScript intro, HTTP).
  • Utiliser Git et méthodes de travail collaboratif (branches, merge).
  • Préparer l'enseignement de l'informatique au collège/lycée (Scratch, Python pédagogique).
  • Articuler informatique, stage et portfolio numérique enseignant.

Contexte réglementaire algérien

Ce cours s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique, consultée pour aligner ce cours sur les standards nationaux.

Révision ENS1 : les fondamentaux (10 min)

Avant d'aborder les nouveaux concepts, rappelons les acquis essentiels de l'ENS 1ère année :

Concept ENS1 Description Exemple
Variables Stockage de données typées age = 20
Structures conditionnelles if, elif, else if note >= 10: print("Admis")
Boucles for, while pour itérer for i in range(10):
Fonctions Bloc de code réutilisable def carre(x): return x**2
Listes Collection ordonnée et mutable notes = [12, 15, 8]
Tuples Collection ordonnée et immuable coords = (3, 5)
Dictionnaires Paires clé-valeur eleve = {"nom": "Ali", "age": 20} 
# Exemple de révision : calcul de moyenne avec une fonction
def moyenne(notes):
    """Calcule la moyenne d'une liste de notes."""
    if not notes:
        return 0
    return sum(notes) / len(notes)

# Test
notes_eleve = [12, 15, 18, 10]
print(f"Moyenne : {moyenne(notes_eleve):.2f}")  # Moyenne : 13.75

Transition ENS1 → ENS2 : En 1ère année, vous avez appris à écrire des scripts isolés. En 2ème année, nous passons à la programmation structurée : projets multi-fichiers, classes, bases de données, travail collaboratif. Chaque nouveau concept sera relié à vos acquis antérieurs.

Chapitre 1 — Bilan et enjeux ENS2 (10 min)

Bilan ENS1 : Vous avez acquis les bases de l'algorithmique (variables, boucles, fonctions), de l'architecture machine et de la programmation Python. Vous êtes capables d'écrire un script de 50-100 lignes résolvant un problème simple.

Passage au niveau supérieur : ENS2 marque le passage du script isolé au projet logiciel structuré. Vous allez apprendre à organiser votre code en classes (POO) pour des programmes plus complexes, manipuler des données volumineuses avec SQL, collaborer avec Git comme dans une équipe de développement, et préparer votre future pratique d'enseignant en informatique.

Compétences futures de l'enseignant : L'enseignant d'informatique du XXIe siècle doit maîtriser l'algorithmique, la programmation, la culture numérique, et les enjeux éthiques de l'IA. Ce module construit ces compétences de manière intégrée.

Chapitre 2 — POO (20 min)

Concepts : Classe, objet, attribut, méthode. Constructeur __init__. Encapsulation, héritage simple.

Exemple concret — contexte scolaire :

class Eleve:
    def __init__(self, nom, prenom, niveau):
        self.nom = nom
        self.prenom = prenom
        self.niveau = niveau
        self.notes = []

    def ajouter_note(self, note, matiere):
        self.notes.append({"matiere": matiere, "note": note})

class Enseignant(Eleve):
    def __init__(self, nom, prenom, matiere):
        super().__init__(nom, prenom, "Enseignant")
        self.matiere_principale = matiere

Lien avec l'enseignement : En collège, la POO peut être introduite via Scratch (les lutins sont des objets avec attributs et scripts). Ce parallèle sera développé en séance 7 (Didactique).

Mini-exercice : Identifiez 3 objets du monde scolaire et listez leurs attributs et méthodes (ex. : SalleDeClasse → attributs : numero, capacite, etage ; méthodes : afficher_info(), est_disponible()).

Chapitre 3 — Algorithmes avancés (15 min)

Algorithmes abordés : - Tri bulle : comparaisons successives d'éléments adjacents — simple mais lent (O(n²)) - Tri fusion : algorithme récursif divisant le tableau en deux — efficace (O(n log n)) - Recherche dichotomique : recherche dans un tableau trié en éliminant la moitié à chaque étape (O(log n)) - Récursivité : factorielle, Fibonacci — une fonction qui s'appelle elle-même

Exemple concret : tri des notes d'une classe

notes = [12, 5, 18, 8, 15, 20, 10]
notes_triees = sorted(notes)
print(f"Notes triées : {notes_triees}")

Lien avec l'enseignement secondaire : Au collège, les élèves comparent des nombres sans stratégie explicite — l'algorithme de tri formalise cette intuition. En NSI, les algorithmes de tri sont au programme de Première et Terminale.

Chapitre 4 — Bases de données (15 min)

Concepts fondamentaux : - Modèle relationnel : organisation des données en tables reliées par des clés - SQL : langage de requêtes structurées - Intégrité : contraintes (clé primaire, clé étrangère, types) - Normalisation : 1ère forme normale (éviter les répétitions)

Exemple — gestion des notes d'une école :

CREATE TABLE Eleve (
    id_eleve INTEGER PRIMARY KEY,
    nom TEXT NOT NULL,
    prenom TEXT NOT NULL,
    classe TEXT
);

CREATE TABLE Note (
    id_note INTEGER PRIMARY KEY,
    valeur REAL CHECK(valeur >= 0 AND valeur <= 20),
    matiere TEXT,
    id_eleve INTEGER,
    FOREIGN KEY (id_eleve) REFERENCES Eleve(id_eleve)
);

Lien avec l'enseignement : Le tableur (Excel, LibreOffice Calc) est une introduction concrète aux bases de données — chaque ligne est un enregistrement, chaque colonne un champ. La transition tableur → SQL est naturelle en SNT (Thème "Données structurées").

Chapitre 5 — Web (15 min)

Architecture : - Client-serveur : le navigateur (client) envoie des requêtes HTTP au serveur qui répond - Frontend : HTML (structure), CSS (style), JavaScript (interactivité) - Backend : Flask (Python) pour créer des applications Web simples - API REST : interface standard pour échanger des données entre applications

Exemple — carnet de notes en ligne :

<!DOCTYPE html>
<html>
<head><title>Carnet de notes</title></head>
<body>
    <h1>Notes de la classe ENS2</h1>
    <table>
        <tr><th>Nom</th><th>Note</th></tr>
        <tr><td>Ali</td><td>15</td></tr>
        <tr><td>Sara</td><td>18</td></tr>
    </table>
</body>
</html>

Accessibilité Web : Utilisez des balises sémantiques (<header>, <main>, <nav>), des textes alternatifs pour les images (alt), un contraste suffisant. Ces bonnes pratiques sont essentielles pour l'enseignement inclusif.

Chapitre 6 — Git et qualité (10 min)

Commandes essentielles : git init, git add, git commit, git branch, git merge

Qualité logicielle : Documentation (README, docstrings), tests unitaires (assert), .gitignore

# Exemple de test unitaire
def moyenne(notes):
    return sum(notes) / len(notes) if notes else 0

assert moyenne([10, 20]) == 15.0
assert moyenne([]) == 0
print("Tous les tests passent ✓")

Lien avec l'enseignement : Git est un excellent outil pour enseigner la collaboration : les branches sont comme des groupes d'élèves qui travaillent sur des parties différentes d'un projet, puis fusionnent leurs travaux.

Chapitre 7 — Didactique informatique (10 min)

Contenus abordés : - Programmes officiels : SNT Seconde (1h30/sem), NSI Première/Terminale (4h/sem) - Démarche projet : les élèves construisent un projet sur plusieurs séances - Scratch → Python : transition de la programmation visuelle au code textuel - Différenciation : adapter les exercices selon le niveau des élèves - Évaluation par compétences : grilles critériées, auto-évaluation

Charte usage IA en classe : L'IA générative (ChatGPT, etc.) peut être un outil d'apprentissage si son usage est encadré. Propositions : demander aux élèves d'analyser/critiquer le code généré par IA plutôt que de le recopier.

Chapitre 8 — Projet ENS2 (5 min)

Livrable attendu : Application Web légère ou module Python POO + base SQLite + dépôt Git + fiche séance pédagogique 45 min pour cycle collège.

Exemples de sujets : 1. Carnet de notes interactif — classes Python + base SQLite + interface Flask 2. Quiz pédagogique — POO (Question, Quiz) + SQL (banque de questions) + Web (interface) 3. Gestion de bibliothèque scolaire — classes (Livre, Adherent, Emprunt) + SQL + Git

Conclusion

Ce module vous accompagne de la maîtrise technique (POO, algorithmes, bases de données, Web, Git) jusqu'à la transposition didactique pour l'enseignement secondaire. Chaque séance construit une brique du projet intégré qui viendra consolider l'ensemble des compétences visées.

Note pédagogique ENS

Transposition didactique : La vue d'ensemble du module peut être présentée aux élèves de collège/lycée sous forme de carte mentale. Dès la classe de 3ème, on peut illustrer le lien entre les blocs Scratch (programmation visuelle) et le code Python (programmation textuelle) pour montrer la progressivité des apprentissages. En SNT Seconde, le thème "Internet" peut être relié à la séance Web ; le thème "Données structurées" à la séance SQL.

Conseil pour l'enseignant formateur : Utilisez ce plan de cours comme outil de communication avec vos étudiants. Distribuez-le en début de module pour qu'ils visualisent la cohérence d'ensemble. Proposez-leur de cocher les séances au fur et à mesure, ce qui renforce le sentiment de progression. N'hésitez pas à revenir sur ce plan à chaque début de séance pour contextualiser.

Section de révision : En fin de module, organisez une séance de révision collaborative. Chaque étudiant prépare une fiche de synthèse sur un chapitre, puis les groupes échangent leurs fiches. Cette activité, appelée "classe puzzle" (Jigsaw classroom), renforce l'apprentissage actif et la responsabilisation.

Prolongement : Les étudiants peuvent créer une carte mentale numérique (XMind, FreeMind) de leur propre progression dans le module, en y ajoutant des ressources personnelles (liens, notes, exercices) — cela deviendra une base pour leur portfolio enseignant.
