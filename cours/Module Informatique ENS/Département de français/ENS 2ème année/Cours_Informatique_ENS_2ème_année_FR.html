Transition ENS1 → ENS2 : En 1ère année, vous avez appris à écrire des scripts isolés. En 2ème année, nous passons à la programmation structurée : projets multi-fichiers, classes, bases de données, travail collaboratif. Chaque nouveau concept sera relié à vos acquis antérieurs.

Chapitre 1 — Bilan et enjeux ENS2 (10 min)

Bilan ENS1 : Vous avez acquis les bases de l'algorithmique (variables, boucles, fonctions), de l'architecture machine et de la programmation Python. Vous êtes capables d'écrire un script de 50-100 lignes résolvant un problème simple.

Passage au niveau supérieur : ENS2 marque le passage du script isolé au projet logiciel structuré. Vous allez apprendre à organiser votre code en classes (POO) pour des programmes plus complexes, manipuler des données volumineuses avec SQL, collaborer avec Git comme dans une équipe de développement, et préparer votre future pratique d'enseignant en informatique.

Compétences futures de l'enseignant : L'enseignant d'informatique du XXIe siècle doit maîtriser l'algorithmique, la programmation, la culture numérique, et les enjeux éthiques de l'IA. Ce module construit ces compétences de manière intégrée.

Chapitre 2 — POO (20 min)

Concepts : Classe, objet, attribut, méthode. Constructeur __init__. Encapsulation, héritage simple.

Exemple concret — contexte scolaire :

class Eleve:
    def __init__(self, nom, prenom, niveau):
        self.nom = nom
        self.prenom = prenom
        self.niveau = niveau
        self.notes = []

    def ajouter_note(self, note, matiere):
        self.notes.append({"matiere": matiere, "note": note})

class Enseignant(Eleve):
    def __init__(self, nom, prenom, matiere):
        super().__init__(nom, prenom, "Enseignant")
        self.matiere_principale = matiere

Lien avec l'enseignement : En collège, la POO peut être introduite via Scratch (les lutins sont des objets avec attributs et scripts). Ce parallèle sera développé en séance 7 (Didactique).

Mini-exercice : Identifiez 3 objets du monde scolaire et listez leurs attributs et méthodes (ex. : SalleDeClasse → attributs : numero, capacite, etage ; méthodes : afficher_info(), est_disponible()).

Chapitre 3 — Algorithmes avancés (15 min)

Algorithmes abordés : - Tri bulle : comparaisons successives d'éléments adjacents — simple mais lent (O(n²)) - Tri fusion : algorithme récursif divisant le tableau en deux — efficace (O(n log n)) - Recherche dichotomique : recherche dans un tableau trié en éliminant la moitié à chaque étape (O(log n)) - Récursivité : factorielle, Fibonacci — une fonction qui s'appelle elle-même

Exemple concret : tri des notes d'une classe

notes = [12, 5, 18, 8, 15, 20, 10]
notes_triees = sorted(notes)
print(f"Notes triées : {notes_triees}")

Lien avec l'enseignement secondaire : Au collège, les élèves comparent des nombres sans stratégie explicite — l'algorithme de tri formalise cette intuition. En NSI, les algorithmes de tri sont au programme de Première et Terminale.

Chapitre 4 — Bases de données (15 min)

Concepts fondamentaux : - Modèle relationnel : organisation des données en tables reliées par des clés - SQL : langage de requêtes structurées - Intégrité : contraintes (clé primaire, clé étrangère, types) - Normalisation : 1ère forme normale (éviter les répétitions)

Exemple — gestion des notes d'une école :

CREATE TABLE Eleve (
    id_eleve INTEGER PRIMARY KEY,
    nom TEXT NOT NULL,
    prenom TEXT NOT NULL,
    classe TEXT
);

CREATE TABLE Note (
    id_note INTEGER PRIMARY KEY,
    valeur REAL CHECK(valeur >= 0 AND valeur <= 20),
    matiere TEXT,
    id_eleve INTEGER,
    FOREIGN KEY (id_eleve) REFERENCES Eleve(id_eleve)
);

Lien avec l'enseignement : Le tableur (Excel, LibreOffice Calc) est une introduction concrète aux bases de données — chaque ligne est un enregistrement, chaque colonne un champ. La transition tableur → SQL est naturelle en SNT (Thème "Données structurées").

Chapitre 5 — Web (15 min)

Architecture : - Client-serveur : le navigateur (client) envoie des requêtes HTTP au serveur qui répond - Frontend : HTML (structure), CSS (style), JavaScript (interactivité) - Backend : Flask (Python) pour créer des applications Web simples - API REST : interface standard pour échanger des données entre applications

Exemple — carnet de notes en ligne :

<!DOCTYPE html>
<html>
<head><title>Carnet de notes</title></head>
<body>
    <h1>Notes de la classe ENS2</h1>
    <table>
        <tr><th>Nom</th><th>Note</th></tr>
        <tr><td>Ali</td><td>15</td></tr>
        <tr><td>Sara</td><td>18</td></tr>
    </table>
</body>
</html>

Accessibilité Web : Utilisez des balises sémantiques (<header>, <main>, <nav>), des textes alternatifs pour les images (alt), un contraste suffisant. Ces bonnes pratiques sont essentielles pour l'enseignement inclusif.

Chapitre 6 — Git et qualité (10 min)

Commandes essentielles : git init, git add, git commit, git branch, git merge

Qualité logicielle : Documentation (README, docstrings), tests unitaires (assert), .gitignore

# Exemple de test unitaire
def moyenne(notes):
    return sum(notes) / len(notes) if notes else 0

assert moyenne([10, 20]) == 15.0
assert moyenne([]) == 0
print("Tous les tests passent ✓")

Lien avec l'enseignement : Git est un excellent outil pour enseigner la collaboration : les branches sont comme des groupes d'élèves qui travaillent sur des parties différentes d'un projet, puis fusionnent leurs travaux.

1. Pourquoi la POO ? (10 min)

Programmation procédurale (ENS1) : fonctions + données séparées. Programmation orientée objet : regroupe données et comportement dans des objets.

Avantages : - Organisation naturelle (on pense en termes d'objets du monde réel) - Réutilisable (une classe = un moule à objets) - Maintenable (modifier une classe n'affecte pas le reste) - Extensible (héritage)

Exemple concret : dans la vie scolaire, on manipule des Élèves, des Enseignants, des Notes, des Classes — ce sont des objets.

2. Classe et objet (15 min)

Classe : modèle, plan de construction. Objet : réalisation concrète du modèle (instance).

# Définition de la classe
class Eleve:
    pass

# Création d'objets (instances)
eleve1 = Eleve()
eleve2 = Eleve()

print(type(eleve1))  # <class '__main__.Eleve'>

La classe est le moule ; l'objet est l'élément produit par ce moule.

6bis. Encapsulation et propriétés (15 min)

Principe : protéger les attributs en contrôlant leur accès avec des propriétés.

class Note:
    def __init__(self, valeur):
        self._valeur = 0  # Attribut "protégé" (convention : _)
        self.valeur = valeur  # Passe par le setter

    @property
    def valeur(self):
        return self._valeur

    @valeur.setter
    def valeur(self, v):
        if 0 <= v <= 20:
            self._valeur = v
        else:
            raise ValueError("La note doit être entre 0 et 20")

# Test
n = Note(15)
print(n.valeur)    # 15 (getter)
n.valeur = 18      # Setter
# n.valeur = 25   # Déclenche ValueError

En contexte scolaire : L'encapsulation est comme un carnet de notes tenu par l'enseignant : on ne peut pas modifier une note sans respecter les règles (entre 0 et 20). Le décorateur @property est le "guichet" qui vérifie chaque modification.

class Matiere:
    def __init__(self, nom, coefficient=1):
        self.nom = nom
        self.coefficient = coefficient

class Note:
    def __init__(self, valeur, matiere):
        self.valeur = valeur
        self.matiere = matiere

class Eleve:
    ecole = "ENS Mostaganem"

    def __init__(self, nom, prenom):
        self.nom = nom
        self.prenom = prenom
        self.notes = []

    def ajouter_note(self, valeur, matiere):
        note = Note(valeur, matiere)
        self.notes.append(note)

    def moyenne_generale(self):
        if not self.notes:
            return 0.0
        total_pondere = sum(n.valeur * n.matiere.coefficient for n in self.notes)
        total_coef = sum(n.matiere.coefficient for n in self.notes)
        return total_pondere / total_coef if total_coef else 0.0

    def __str__(self):
        return f"{self.prenom} {self.nom} — Moy : {self.moyenne_generale():.2f}"

5. Encapsulation (15 min)

Encapsulation : protéger l'accès aux attributs pour garantir l'intégrité.

class CompteBancaire:
    def __init__(self, titulaire, solde=0):
        self.titulaire = titulaire
        self._solde = 0     # Protégé (convention : _)
        if solde >= 0:
            self._solde = solde

    def deposer(self, montant):
        if montant > 0:
            self._solde += montant

    def retirer(self, montant):
        if 0 < montant <= self._solde:
            self._solde -= montant
            return montant
        return 0

    @property           # Getter
    def solde(self):
        return self._solde

    @solde.setter       # Setter
    def solde(self, valeur):
        if valeur >= 0:
            self._solde = valeur

# Utilisation
cb = CompteBancaire("Ali", 1000)
cb.deposer(500)
print(cb.solde)        # 1500 (via le getter)
# cb._solde = 999999    # Techniquement possible mais déconseillé

Convention Python : _attribut = protégé, __attribut = privé (name mangling).

1. Récursivité (15 min)

Fonction récursive : fonction qui s'appelle elle-même.

Deux éléments essentiels : - Cas de base : condition d'arrêt (n'utilise pas la récursion) - Appel récursif : la fonction se rappelle avec un paramètre modifié

Exemple : factorielle

def factorielle(n):
    if n <= 1:        # Cas de base
        return 1
    return n * factorielle(n - 1)  # Appel récursif

print(factorielle(5))  # 120 = 5*4*3*2*1

Exemple : Fibonacci

def fibonacci(n):
    if n <= 1:        # Cas de base
        return n
    return fibonacci(n-1) + fibonacci(n-2)  # Double appel

print(fibonacci(10))  # 55

Exercice rapide : Suite de Syracuse (5 min)

La conjecture de Syracuse (suite de Collatz) est définie par : - u0 = n (entier positif) - Si uk est pair : u(k+1) = uk / 2 - Si uk est impair : u(k+1) = 3 * uk + 1

Implémentez une fonction récursive syracuse(n) qui affiche les termes de la suite jusqu'à 1.

def syracuse(n):
    print(n, end=" ")
    if n == 1:           # Cas de base
        return
    if n % 2 == 0:       # Pair
        syracuse(n // 2)
    else:                # Impair
        syracuse(3 * n + 1)

syracuse(6)   # 6 3 10 5 16 8 4 2 1

Question : Tous les nombres finissent-ils par atteindre 1 ? C'est une conjecture non encore démontrée.

3. Recherche dichotomique (15 min)

Principe : dans un tableau trié, comparer avec l'élément du milieu, puis chercher à gauche ou à droite.

def recherche_dichotomique(tableau, cible):
    debut = 0
    fin = len(tableau) - 1

    while debut <= fin:
        milieu = (debut + fin) // 2
        if tableau[milieu] == cible:
            return milieu          # Trouvé
        elif tableau[milieu] < cible:
            debut = milieu + 1     # Chercher à droite
        else:
            fin = milieu - 1       # Chercher à gauche

    return -1  # Non trouvé

# Test
notes = [5, 8, 10, 12, 15, 18, 20]
print(recherche_dichotomique(notes, 15))  # 4
print(recherche_dichotomique(notes, 7))   # -1

Complexité : O(log n) — beaucoup plus rapide que la recherche linéaire O(n).

def recherche_dichotomique_recursive(tableau, cible, debut=0, fin=None):
    if fin is None:
        fin = len(tableau) - 1

        return -1

4. Tri bulle (15 min)

Principe : parcourir le tableau, comparer les éléments adjacents, les permuter s'ils sont dans le mauvais ordre.

def tri_bulle(tableau):
    n = len(tableau)
    for i in range(n):
        trie = True
        for j in range(n - i - 1):
            if tableau[j] > tableau[j + 1]:
                tableau[j], tableau[j + 1] = tableau[j + 1], tableau[j]
                trie = False
        if trie:  # Optimisation : déjà trié
            break
    return tableau

# Test
notes = [15, 8, 12, 20, 5]
print(tri_bulle(notes))  # [5, 8, 12, 15, 20]

Complexité : O(n²) dans le pire cas, O(n) si déjà trié.

5. Tri fusion (merge sort) (15 min)

Principe : diviser le tableau en deux, trier chaque moitié récursivement, puis fusionner.

def tri_fusion(tableau):
    if len(tableau) <= 1:
        return tableau

    milieu = len(tableau) // 2
    gauche = tri_fusion(tableau[:milieu])
    droite = tri_fusion(tableau[milieu:])

    return fusionner(gauche, droite)

def fusionner(gauche, droite):
    resultat = []
    i = j = 0
    while i < len(gauche) and j < len(droite):
        if gauche[i] <= droite[j]:
            resultat.append(gauche[i])
            i += 1
        else:
            resultat.append(droite[j])
            j += 1
    resultat.extend(gauche[i:])
    resultat.extend(droite[j:])
    return resultat

# Test
notes = [15, 8, 12, 20, 5]
print(tri_fusion(notes))  # [5, 8, 12, 15, 20]

Complexité : O(n log n) dans tous les cas — plus efficace que le tri bulle.

conn = sqlite3.connect("ecole.db")

        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, prenom TEXT, groupe TEXT
    )
""")

    CREATE TABLE IF NOT EXISTS matieres (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, coefficient REAL
    )
""")
c.execute("""
    CREATE TABLE IF NOT EXISTS notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        eleve_id INTEGER, matiere_id INTEGER, valeur REAL,
        FOREIGN KEY(eleve_id) REFERENCES eleves(id),
        FOREIGN KEY(matiere_id) REFERENCES matieres(id)
    )
""")

# Insertion des données
c.execute("INSERT INTO eleves VALUES (1, 'Ali', 'Belacel', 'ENS2-A')")
c.execute("INSERT INTO matieres VALUES (1, 'Informatique', 3.0)")
c.execute("INSERT INTO matieres VALUES (2, 'Français', 2.0)")

c.execute("INSERT INTO notes VALUES (NULL, 1, 2, 12)")

# Relevé de notes avec moyenne
c.execute("""
    SELECT e.nom, e.prenom, m.nom, n.valeur, m.coefficient
    FROM notes n
    JOIN eleves e ON n.eleve_id = e.id
    JOIN matieres m ON n.matiere_id = m.id
    WHERE e.id = 1
""")

print("=== Relevé de notes ===")
total_pondere = 0
total_coef = 0

moyenne = total_pondere / total_coef if total_coef > 0 else 0

conn.close()

2. Scratch (20 min)

Scratch (scratch.mit.edu) : programmation visuelle par blocs — idéal pour collège.

Concepts enseignés : - Blocs de mouvement, apparence, son - Boucles (répéter, toujours) - Conditions (si, si… alors) - Variables et listes - Événements (quand drapeau cliqué, quand touche pressée)

Exemple d'exercice : chat qui marche 1. Quand drapeau cliqué → avancer de 10 pas 2. Si touche espace pressée → dire "Bonjour !" pendant 2 secondes 3. Rebondir si bord atteint

Progression recommandée : 1. Blocs simples (déplacement) 2. Boucles et conditions 3. Variables (score, timer) 4. Projet final (jeu de pong, quiz)

3. Python pédagogique (15 min)

Quand passer de Scratch à Python ? - Scratch : 6e-4e (découverte, logique) - Python : 3e-2de (première programmation textuelle)

Approche :

# Version Python d'un exercice Scratch
# Dire "Bonjour" quand on clique sur le drapeau

import turtle

t = turtle.Turtle()

# Avancer de 50 pas
t.forward(50)

# Tourner à droite
t.right(90)
t.forward(50)

turtle.done()

Bibliothèques pédagogiques : - turtle : dessin, déplacement (transition Scratch) - random : jeux, simulations - tkinter : interfaces graphiques simples

5. Modèle POO (15 min)

# modele.py
class Eleve:
    def __init__(self, id, nom, prenom, groupe):
        self.id = id
        self.nom = nom
        self.prenom = prenom
        self.groupe = groupe
        self.notes = []

    def moyenne(self):
        if not self.notes:
            return 0.0
        return sum(n.valeur for n in self.notes) / len(self.notes)

    def ajouter_note(self, matiere, valeur):
        if 0 <= valeur <= 20:
            self.notes.append(Note(self.id, matiere, valeur))

class Note:
    def __init__(self, eleve_id, matiere, valeur):
        self.eleve_id = eleve_id
        self.matiere = matiere
        self.valeur = valeur

6. Base de données (10 min)

# database.py
import sqlite3

DB = "donnees/ecole.db"

def init_db():
    conn = sqlite3.connect(DB)
    c = conn.cursor()
    c.execute("""
        CREATE TABLE IF NOT EXISTS eleves (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nom TEXT NOT NULL,
            prenom TEXT NOT NULL,
            groupe TEXT
        )
    """)
    c.execute("""
        CREATE TABLE IF NOT EXISTS notes (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            eleve_id INTEGER NOT NULL,
            matiere TEXT NOT NULL,
            valeur REAL NOT NULL CHECK(valeur >= 0 AND valeur <= 20),
            FOREIGN KEY(eleve_id) REFERENCES eleves(id)
        )
    """)
    conn.commit()
    conn.close()

def get_eleves():
    conn = sqlite3.connect(DB)
    conn.row_factory = sqlite3.Row
    c = conn.cursor()
    c.execute("SELECT * FROM eleves")
    eleves = [dict(row) for row in c.fetchall()]
    conn.close()
    return eleves
