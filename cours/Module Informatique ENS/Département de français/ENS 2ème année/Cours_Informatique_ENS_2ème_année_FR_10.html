Cours Informatique — ENS 2ème année — Séance 10 (FR)

Enseignant : BELACEL Madani
Module : Informatique
Niveau : ENS — 2ème année — Département de français
Durée : 1h30
Année universitaire : 2025-2026

Fiche cours — Plateforme e-learning (Moodle)

Référentiel : benchmark 10 universités algériennes + pratiques Univ-Mosta/Biskra/M'sila.

Public visé : Étudiants ENS 2ème année — Département Français

Compétences pré-requises : Projet ENS2 développé (séance 09), Git, POO, SQL, Flask

Objectifs transversaux : - Appliquer la programmation orientée objet (classes, héritage, encapsulation) en Python - Concevoir des algorithmes avancés (tri, recherche, récursivité) et estimer leur complexité - Modéliser des données avec le modèle relationnel et requêtes SQL de base - Comprendre l'architecture Web (HTML, CSS, JavaScript intro, HTTP) - Utiliser Git et méthodes de travail collaboratif (branches, merge) - Préparer l'enseignement de l'informatique au collège/lycée (Scratch, Python pédagogique)

Mode d'évaluation : TP POO + SQL 35 % — Projet intégré 40 % — Fiche séance pédagogique 25 %

Bibliographie : MDN Web Docs ; Flask Documentation ; Git Book

Objectifs pédagogiques spécifiques

À l'issue de cette séance, l'étudiant est capable de : - Présenter un projet logiciel complet - Démontrer les fonctionnalités développées - Expliquer les choix techniques et d'architecture - Montrer le dépôt Git avec historique - Présenter la fiche séance pédagogique associée

Contexte réglementaire algérien

Ce cours s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique, consultée pour aligner ce cours sur les standards nationaux.

3. Démo en direct — scénario type (20 min)

Scénario de démonstration :

  1. Accueil — Page d'accueil avec présentation
  2. Ajout d'élève — Saisir "Belacel", "Ali", "ENS2-A"
  3. Ajout de notes — Informatique: 15, Français: 12, Anglais: 18
  4. Calcul de moyenne — Vérifier que la moyenne s'affiche correctement
  5. Relevé de notes — Afficher le tableau complet
  6. Export CSV — Télécharger le fichier et l'ouvrir dans Excel
  7. GitHub — Montrer le dépôt, les commits, le README

Erreurs à anticiper : - Ajouter une note > 20 → message d'erreur attendu - Supprimer un élève → confirmation - Navigation → responsive (mobile/desktop)

4. Questions techniques possibles (15 min)

Préparer les réponses à ces questions :

POO : - Pourquoi as-tu choisi l'héritage dans ton modèle ? - Quelle est la différence entre attribut de classe et d'instance ? - Comment as-tu implémenté l'encapsulation ?

Base de données : - Pourquoi SQLite plutôt que MySQL/PostgreSQL ? - Quelle est la clé primaire ? Pourquoi AUTOINCREMENT ? - Comment as-tu géré la contrainte 0 ≤ note ≤ 20 ?

Web : - Explique le cycle requête/réponse dans Flask - Comment passes-tu des données du Python au HTML ? - Qu'est-ce qu'une route dans Flask ?

Git : - Montre un commit où tu as corrigé un bug - Quelle est la différence entre merge et rebase ? - Comment gères-tu un conflit de fusion ?

Pédagogie : - Comment adapterais-tu ce projet pour des élèves de 3ème ? - Quelle trace écrite proposes-tu aux élèves ? - Comment évalues-tu les compétences PIX ?

5. Fiche séance pédagogique (15 min — travail individuel)

Rédiger une fiche de séance de 45 minutes pour le collège, en lien avec le projet.

Sujet proposé : Découvrir la programmation avec Scratch — Créer un quiz interactif

Utiliser le modèle vu à la séance 08 :

# Fiche de séance — Quiz interactif avec Scratch

**Niveau :** 3ème (Cycle 4)
**Thème :** Algorithmique et programmation
**Durée :** 45 minutes

## Objectifs
- Utiliser une variable (score)
- Implémenter une condition (si la réponse est correcte)
- Créer une boucle de jeu

## Déroulement
1. Découverte (5 min) : montrer le quiz finalisé
2. Variables (10 min) : créer variable "score"
3. Questions (15 min) : ajouter 3 questions avec conditions
4. Test (10 min) : jouer et debugger
5. Bilan (5 min) : trace écrite

## Évaluation
- Quiz final fonctionnel (3 questions minimum)
- Variable score qui s'incrémente
- Message de feedback (bravo/essaye encore)

Note pédagogique ENS

Transposition didactique : Cette séance de soutenance est elle-même un modèle pour les enseignants : elle montre comment structurer une évaluation de projet (critères transparents, démo en direct, questions techniques, fiche pédagogique). Ce format peut être adapté pour des élèves de collège (soutenance de projet Scratch de 5 minutes) ou de lycée (soutenance NSI de 15-20 minutes). L'évaluation par grille critériée est une pratique recommandée dans le programme officiel.

Conseil pour l'enseignant formateur : La soutenance est un moment clé : elle évalue non seulement le code mais aussi la capacité à communiquer et à argumenter. Encouragez les étudiants à préparer un script et à répéter. Prévoyez un vidéoprojecteur pour la démo et testez-le avant. Les questions techniques (section 4) doivent être adaptées au niveau de chaque étudiant. Un étudiant plus faible peut se voir poser des questions sur les bases (différence classe/instance) tandis qu'un étudiant avancé peut être interrogé sur les choix d'architecture.

Prolongement : Le projet ENS2 devient la pièce maîtresse du portfolio enseignant. Les étudiants sont encouragés à : - Présenter le projet lors d'entretiens pour des postes d'enseignant - L'améliorer pendant le stage pratique avec des retours d'élèves - Le publier sur GitHub Pages comme démonstration de leurs compétences - L'étendre avec des fonctionnalités inspirées de leur expérience de stage
