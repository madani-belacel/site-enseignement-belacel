1. Présentation du module

Le module d'Informatique pour la 1ère année ENS vise à fournir aux futurs enseignants les compétences fondamentales en informatique nécessaires à leur pratique professionnelle. Il couvre l'architecture des ordinateurs, les systèmes d'exploitation, l'algorithmique, les structures de données, les réseaux, la sécurité, et l'initiation à la programmation Python. L'accent est mis sur les applications pédagogiques et la transposition didactique des concepts pour l'enseignement secondaire.

1 bis. Contexte réglementaire algérien

Ce programme s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique dans les universités algériennes, consultée pour l'élaboration de ce programme.

2. Compétences visées

À l'issue du module, l'étudiant sera capable de :

Compétence Composantes
C1 — Comprendre l'architecture machine Modèle de von Neumann, cycle d'exécution, hiérarchie mémoire, périphériques
C2 — Maîtriser les systèmes d'exploitation Processus, fichiers, arborescence, ligne de commande, permissions
C3 — Concevoir des algorithmes Pseudo-code structuré, variables, conditions, boucles, complexité O(n)/O(n²)
C4 — Utiliser des structures de données Tableaux, piles (LIFO), files (FIFO), listes chaînées, choix adapté au problème
C5 — Comprendre les principes réseau Adressage IP, DNS, HTTP/HTTPS, modèle client-serveur, protocoles
C6 — Appliquer la sécurité informatique CID, mots de passe, MFA, phishing, sauvegarde 3-2-1, RGPD
C7 — Programmer en Python Variables, types, conditions, boucles, fonctions, fichiers, projets pédagogiques
C8 — Didactique de l'informatique Transposition des concepts, activités pour le secondaire, évaluation, projet

7. Conseils pédagogiques pour l'enseignant ENS

Approche recommandée

  1. Progression spiralaire : chaque concept est introduit simplement puis approfondi à la séance suivante
  2. Concret d'abord : partir d'exemples concrets (vie quotidienne, enseignement) avant l'abstraction
  3. Activités débranchées : utiliser des activités sans ordinateur pour les concepts abstraits (pile = assiettes, file = cantine)
  4. Transposition : montrer comment chaque concept s'enseigne au collège/lycée (SNT, NSI)
  5. Projet fédérateur : le projet Python fil rouge permet l'intégration de toutes les compétences

Liens avec les programmes du secondaire
