Objectifs pédagogiques

À l'issue de cette séance de TD, l'étudiant est capable de : - Distinguer les types de données (entier, réel, booléen, chaîne) et les utiliser correctement - Écrire des algorithmes utilisant des structures conditionnelles (si/sinon) et des boucles (pour, tant que) - Concevoir un algorithme complet de calcul de moyenne avec recherche du min/max - Estimer et comparer la complexité algorithmique de différents algorithmes (O(1), O(n), O(n²)) - Analyser un problème et le décomposer en étapes algorithmiques

Exercice 1 — Variables et types (15 min)

Énoncé : Identifier le type (entier, réel, booléen, chaîne) de chaque valeur :

  1. 42
  2. "Bonjour"
  3. 3.14
  4. vrai
  5. 'A'
  6. -5
  7. 0.001
  8. "123"

Corrigé : 1. Entier (int) 2. Chaîne (string) 3. Réel (float) 4. Booléen (bool) 5. Chaîne (string) — un caractère seul reste une chaîne 6. Entier (int) 7. Réel (float) 8. Chaîne (string) — les guillemets indiquent une chaîne même si le contenu est numérique

Q : Quel est le résultat de int(3.14) ? De float("42") ? - R : int(3.14) = 3 (troncature). float("42") = 42.0

Exercice 2 — Conditions (20 min)

Énoncé : Écrire en pseudo-code un algorithme qui :

  1. Demande l'âge de l'utilisateur
  2. Affiche « Majeur » si l'âge ≥ 18, « Mineur » sinon
  3. Si l'âge ≥ 65, afficher « Senior » en plus

Corrigé :

AFFICHER "Quel est votre âge ?"
LIRE age
SI age >= 18 ALORS
    AFFICHER "Majeur"
    SI age >= 65 ALORS
        AFFICHER "Senior"
    FIN SI
SINON
    AFFICHER "Mineur"
FIN SI

Code Python équivalent

age = int(input("Quel est votre âge ? "))
if age >= 18:
    print("Majeur")
    if age >= 65:
        print("Senior")
else:
    print("Mineur")

Variante — Classification complète

SI age < 13 ALORS
    AFFICHER "Enfant"
SINON SI age < 18 ALORS
    AFFICHER "Adolescent"
SINON SI age < 65 ALORS
    AFFICHER "Adulte"
SINON
    AFFICHER "Senior"
FIN SI

Table de vérité :

Âge Affichage
10 Mineur
18 Majeur
65 Majeur, Senior

Exercice 3 — Boucles (20 min)

Énoncé : Écrire en pseudo-code :

  1. Afficher les nombres pairs de 2 à 20 (inclus)
  2. Calculer la somme des nombres de 1 à n (n saisi par l'utilisateur)
  3. Afficher la table de multiplication d'un nombre saisi (de 1 à 10)

Corrigé :

// 1. Nombres pairs
POUR i DE 2 À 20 PAS 2 FAIRE
    AFFICHER i
FIN POUR

// 2. Somme 1 à n
AFFICHER "Donner n"
LIRE n
somme ← 0
POUR i DE 1 À n FAIRE
    somme ← somme + i
FIN POUR
AFFICHER "Somme : ", somme

// 3. Table de multiplication
AFFICHER "Donner un nombre"
LIRE nb
POUR i DE 1 À 10 FAIRE
    AFFICHER nb, " × ", i, " = ", nb * i
FIN POUR

Schéma de l'algorithme (somme 1 à n)

flowchart TD
    A[Début] --> B[Afficher 'Donner n']
    B --> C[Lire n]
    C --> D[somme ← 0]
    D --> E[i ← 1]
    E --> F{i <= n ?}
    F -->|Oui| G[somme ← somme + i]
    G --> H[i ← i + 1]
    H --> F
    F -->|Non| I[Afficher somme]
    I --> J[Fin]

Table de traçage (n = 5)

i somme i ≤ 5 ?
1 1 Vrai
2 3 Vrai
3 6 Vrai
4 10 Vrai
5 15 Vrai
6 — Faux → fin

Résultat : somme = 15

Code Python équivalent

# 1. Nombres pairs de 2 à 20
for i in range(2, 21, 2):
    print(i)

# 2. Somme 1 à n
n = int(input("Donner n : "))
somme = 0
for i in range(1, n + 1):
    somme += i
print("Somme :", somme)

# 3. Table de multiplication
nb = int(input("Donner un nombre : "))
for i in range(1, 11):
    print(nb, "×", i, "=", nb * i)

Variante TANT QUE : remplacer POUR i DE 1 À n par i ← 1 / TANT QUE i <= n / i ← i + 1.

Exercice 4 — Algorithme complet (20 min)

Énoncé : Écrire un algorithme qui : 1. Demande 5 notes à l'utilisateur 2. Calcule la moyenne 3. Affiche « Admis » si moyenne ≥ 10, « Ajourné » sinon 4. Affiche la note la plus haute et la plus basse

Corrigé :

max ← 0
min ← 20
somme ← 0
POUR i DE 1 À 5 FAIRE
    AFFICHER "Note ", i, " : "
    LIRE note
    somme ← somme + note
    SI note > max ALORS max ← note FIN SI
    SI note < min ALORS min ← note FIN SI
FIN POUR
moyenne ← somme / 5
AFFICHER "Moyenne : ", moyenne
SI moyenne >= 10 ALORS
    AFFICHER "Admis"
SINON
    AFFICHER "Ajourné"
FIN SI
AFFICHER "Meilleure note : ", max
AFFICHER "Moins bonne note : ", min

Table de traçage (notes [8, 12, 15, 6, 19])

i note somme max min
— — 0 0 20
1 8 8 8 8
2 12 20 12 8
3 15 35 15 8
4 6 41 15 6
5 19 60 19 6

Moyenne = 60 / 5 = 12 → Admis | Meilleure : 19 | Moins bonne : 6

Code Python équivalent

max_note = 0
min_note = 20
somme = 0

for i in range(1, 6):
    note = float(input(f"Note {i} : "))
    somme += note
    if note > max_note:
        max_note = note
    if note < min_note:
        min_note = note

moyenne = somme / 5
print("Moyenne :", moyenne)
if moyenne >= 10:
    print("Admis")
else:
    print("Ajourné")
print("Meilleure note :", max_note)
print("Moins bonne note :", min_note)

Variante mention : ≥ 16 « Très bien » | ≥ 14 « Bien » | ≥ 12 « Assez bien » | ≥ 10 « Passable » | < 10 « Insuffisant »

Généralisation : remplacer 5 par N saisi par l'utilisateur.

Exercice 5 — Complexité (10 min)

Énoncé : Pour chaque algorithme, estimer la complexité (O(1), O(n), O(n²)) :

  1. Accéder au 3ème élément d'un tableau
  2. Parcourir un tableau de 100 éléments
  3. Comparer chaque élément d'un tableau avec tous les autres
  4. Lire le premier caractère d'une chaîne
  5. Rechercher un nom dans une liste non triée de n noms

Corrigé : 1. O(1) — accès direct par indice 2. O(n) — parcours linéaire 3. O(n²) — double boucle imbriquée 4. O(1) — accès direct 5. O(n) — dans le pire cas, on parcourt toute la liste

Analyse détaillée

Algorithme Complexité Opérations (n=100)
Accès par indice O(1) 1
Parcours simple O(n) 100
Double boucle O(n²) 10 000
Boucle triple O(n³) 1 000 000

QCM d'auto-évaluation

  1. Quel est le type de "42" en pseudo-code ? a) Entier b) Chaîne ✓ c) Réel

  2. Une structure conditionnelle utilise le mot-clé : a) POUR b) SI ✓ c) TANT QUE

  3. Quelle boucle est la plus adaptée pour parcourir un tableau de taille connue ? a) POUR ✓ b) TANT QUE c) RÉPÉTER

  4. La complexité d'une double boucle imbriquée (pour i, pour j) est : a) O(n) b) O(n²) ✓ c) O(1)

  5. Dans l'algorithme de moyenne, trouver la note maximale nécessite : a) Un parcours du tableau ✓ b) Un tri complet c) Une recherche dichotomique

Note pédagogique ENS

Transposition didactique

L'algorithmique est au cœur des programmes de SNT (Seconde) et de NSI (Première/Terminale). En Seconde, on se limite à lire et modifier des algorithmes simples. En Première NSI, les élèves écrivent leurs premiers algorithmes en Python. L'analogie de la recette de cuisine fonctionne bien : les ingrédients sont les variables, les étapes sont les instructions, et les choix (si la sauce est trop liquide, ajouter de la farine) sont les conditions.

Conseil pour l'enseignant formateur

L'exercice 4 (algorithme complet) est l'exercice le plus important : il mobilise toutes les notions du TD. Demander aux étudiants d'écrire d'abord l'algorithme sur papier, puis de le tester mentalement avec des notes exemples (par exemple : 8, 12, 15, 6, 19). Vérifier que chaque étudiant suit l'exécution pas à pas (traçage manuel). La complexité (exercice 5) est une notion difficile : l'expliquer visuellement avec des graphiques.

Prolongement

Demander aux étudiants de traduire l'algorithme de l'exercice 4 en Python dans un fichier moyenne.py. Ajouter une fonction qui détermine si la moyenne est « Très bien » (≥ 16), « Bien » (≥ 14), « Assez bien » (≥ 12), « Passable » (≥ 10) ou « Insuffisant » (< 10). Tester avec différents jeux de notes.
