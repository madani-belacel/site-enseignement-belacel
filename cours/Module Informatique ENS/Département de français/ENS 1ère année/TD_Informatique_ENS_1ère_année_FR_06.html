Exercice 1 — Tableaux (15 min)

Énoncé : On a le tableau suivant : notes ← [12, 15, 8, 19, 10]

  1. Quelle est la valeur de l'élément à l'indice 3 ? (Indices commençant à 1)
  2. Écrire un algorithme qui calcule la somme des éléments du tableau.
  3. Écrire un algorithme qui trouve la valeur maximale.

Corrigé : 1. notes[3] = 8 (les indices commencent à 1 en pseudo-code conventionnel)

// 2. Somme
somme ← 0
POUR i DE 1 À 5 FAIRE
    somme ← somme + notes[i]
FIN POUR
AFFICHER "Somme : ", somme

// 3. Maximum
max ← notes[1]
POUR i DE 2 À 5 FAIRE
    SI notes[i] > max ALORS
        max ← notes[i]
    FIN SI
FIN POUR
AFFICHER "Max : ", max

Table de traçage — Somme

1 12 12
2 15 27
3 8 35
4 19 54
5 10 64

Table de traçage — Maximum

Questions complémentaires

Q1 — Minimum : Écrire l'algorithme pour trouver la valeur minimale. - R : Même principe que max, mais avec < et initialisation à notes[1].

Q2 — Moyenne : Calculer la moyenne des notes. - R : somme / 5 = 64 / 5 = 12,8.

Exercice 2 — Pile (LIFO) (20 min)

Énoncé : Simuler l'exécution des opérations suivantes sur une pile initialement vide. Indiquer l'état de la pile après chaque opération.

empiler(10)
empiler(20)
empiler(30)
x ← depiler()
empiler(40)
y ← depiler()
z ← depiler()

Corrigé : | Opération | Pile après opération | Valeur retournée | |-----------|---------------------|------------------| | Initial | [] | — | | empiler(10) | [10] | — | | empiler(20) | [10, 20] | — | | empiler(30) | [10, 20, 30] | — | | depiler() | [10, 20] | 30 | | empiler(40) | [10, 20, 40] | — | | depiler() | [10, 20] | 40 | | depiler() | [10] | 20 |

Question : À quoi correspond cette structure dans un logiciel de traitement de texte ? (Réponse : la fonction Annuler / Ctrl+Z)

Code Python équivalent

pile = []
pile.append(10)        # empiler(10)
pile.append(20)        # empiler(20)
pile.append(30)        # empiler(30)
x = pile.pop()         # depiler() → x = 30
pile.append(40)        # empiler(40)
y = pile.pop()         # depiler() → y = 40
z = pile.pop()         # depiler() → z = 20

Questions : Quelles sont les valeurs de x, y, z ? Que reste-t-il dans la pile ? - R : x=30, y=40, z=20. Pile : [10].

Exercice 3 — File (FIFO) (20 min)

Énoncé : Simuler l'exécution des opérations suivantes sur une file initialement vide.

enfiler("A")
enfiler("B")
x ← defiler()
enfiler("C")
y ← defiler()
enfiler("D")
z ← defiler()

Corrigé : | Opération | File après opération | Valeur retournée | |-----------|---------------------|------------------| | Initial | [] | — | | enfiler("A") | ["A"] | — | | enfiler("B") | ["A", "B"] | — | | defiler() | ["B"] | "A" | | enfiler("C") | ["B", "C"] | — | | defiler() | ["C"] | "B" | | enfiler("D") | ["C", "D"] | — | | defiler() | ["D"] | "C" |

Question : Dans quel contexte réel utilise-t-on une file d'attente en informatique ? (Réponse : file d'impression, requêtes serveur, buffer vidéo)

Code Python équivalent

from collections import deque
file = deque()
file.append("A")        # enfiler("A")
file.append("B")        # enfiler("B")
x = file.popleft()      # defiler() → x = 'A'
file.append("C")        # enfiler("C")
y = file.popleft()      # defiler() → y = 'B'
file.append("D")        # enfiler("D")
z = file.popleft()      # defiler() → z = 'C'

Question : Quelle différence fondamentale entre pile et file ? Quel élément reste dans la file ? - R : Pile=LIFO, File=FIFO. Il reste ["D"].

Exercice 4 — Choix de structure (15 min)

Énoncé : Quelle structure de données (tableau, pile, file, liste chaînée) est la plus adaptée pour :

  1. L'historique de navigation (page précédente)
  2. Une liste d'attente au guichet
  3. Les notes des étudiants d'une classe (accès rapide par numéro d'étudiant)
  4. Une liste de courses où on ajoute/supprime au milieu fréquemment
  5. Les appels à une fonction récursive

Corrigé : 1. Pile (LIFO — on remonte dans l'historique) 2. File (FIFO — premier arrivé, premier servi) 3. Tableau (accès direct par indice = numéro étudiant) 4. Liste chaînée (insertion/suppression au milieu sans décaler les éléments) 5. Pile (pile d'appels — chaque appel ajoute un cadre de pile, le retour dépile)

Justifications détaillées

Cas Structure Pourquoi pas une autre ?
Historique navigation Pile Une file donnerait l'ordre inverse (première page visitée en premier)
Liste d'attente File Une pile servirait le dernier arrivé en premier (injuste)
Notes des étudiants Tableau Accès O(1) par indice ; une liste chaînée nécessiterait un parcours
Liste de courses Liste chaînée Un tableau nécessite de décaler les éléments lors d'insertion/suppression
Appels récursifs Pile Chaque appel s'empile, le return dépile — pile d'appels système

Exercice 5 — Algorithme avec pile (15 min)

Énoncé : Écrire un algorithme qui vérifie si une expression parenthésée est correcte, par exemple (3 + 2) × (5 - 1) est correcte mais (3 + 2 × (5 - 1) ne l'est pas.

Principe : utiliser une pile. Quand on lit ( on empile, quand on lit ) on dépile. Si on dépile sur une pile vide ou si la pile n'est pas vide à la fin, l'expression est incorrecte.

Corrigé :

expression ← "(3 + 2) × (5 - 1)"
pile ← []

POUR i DE 1 À longueur(expression) FAIRE
    car ← expression[i]
    SI car = '(' ALORS
        empiler(pile, '(')
    SINON SI car = ')' ALORS
        SI pile est vide ALORS
            AFFICHER "Erreur : parenthèse fermante sans ouvrante"
            STOP
        SINON
            depiler(pile)
        FIN SI
    FIN SI
FIN POUR

SI pile est vide ALORS
    AFFICHER "Expression correcte"
SINON
    AFFICHER "Erreur : il manque ", taille(pile), " parenthèse(s) fermante(s)"
FIN SI

Table de traçage pour "(3+2)×(5-1)"

Caractère Action Pile après
( Empiler [ '(' ]
3 Ignorer [ '(' ]
+ Ignorer [ '(' ]
2 Ignorer [ '(' ]
) Dépiler []
× Ignorer []
( Empiler [ '(' ]
5 Ignorer [ '(' ]
- Ignorer [ '(' ]
1 Ignorer [ '(' ]
) Dépiler []

Résultat : Pile vide → expression correcte ✓

Extension — Multi-types de parenthèses

Adapter l'algorithme pour gérer (), [] et {} avec concordance des types.

SI car = '(' OU car = '[' OU car = '{' ALORS
    empiler(pile, car)
SINON SI car = ')' ALORS
    SI pile vide OU depiler(pile) ≠ '(' ALORS erreur
SINON SI car = ']' ALORS
    SI pile vide OU depiler(pile) ≠ '[' ALORS erreur
SINON SI car = '}' ALORS
    SI pile vide OU depiler(pile) ≠ '{' ALORS erreur
FIN SI

Note pédagogique ENS

Transposition didactique

Les piles et files sont des notions très visuelles et concrètes. En collège/lycée, on peut les introduire avec des objets physiques : une pile d'assiettes (LIFO) et une file d'attente à la cantine (FIFO). Les élèves peuvent jouer le rôle d'opérations (empiler/dépiler, enfiler/défiler) en se plaçant en file indienne. L'algorithme de parenthésage est un classique de NSI Terminale.

Conseil pour l'enseignant formateur

Pour les exercices 2 et 3, faire jouer les simulations au tableau avec des volontaires : un étudiant est la pile, un autre est l'opérateur. Chaque empilement/dépilement est matérialisé par un post-it au tableau. La visualisation physique aide à comprendre la différence entre LIFO et FIFO. L'exercice 4 (choix de structure) est excellent pour la discussion collective : chaque proposition peut être débattue.

Prolongement

Étendre l'exercice 5 pour gérer les trois types de parenthèses : (), [], {}. L'algorithme doit vérifier la concordance : une parenthèse fermante doit correspondre à la dernière ouvrante du même type. Implémenter cet algorithme en Python (parentheses.py) avec une classe Pile.
