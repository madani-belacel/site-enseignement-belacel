Exercice 1 — Recherche séquentielle et dichotomique (20 min)

Énoncé : Créer un script recherche.py qui implémente deux algorithmes de recherche :

  1. recherche_sequentielle(liste, valeur) — parcourt la liste et retourne l'indice ou -1
  2. recherche_dichotomique(liste, valeur) — recherche dans une liste triée (diviser pour régner)

Pour chaque algorithme, compter le nombre de comparaisons effectuées et les comparer.

Corrigé :

def recherche_sequentielle(liste, valeur):
    """Recherche séquentielle. Retourne l'indice ou -1."""
    comparaisons = 0
    for i, v in enumerate(liste):
        comparaisons += 1
        if v == valeur:
            print(f"  Séquentielle : {comparaisons} comparaison(s)")
            return i
    print(f"  Séquentielle : {comparaisons} comparaison(s)")
    return -1

def recherche_dichotomique(liste, valeur):
    """Recherche dichotomique (liste triée). Retourne l'indice ou -1."""
    comparaisons = 0
    debut, fin = 0, len(liste) - 1
    while debut <= fin:
        comparaisons += 1
        milieu = (debut + fin) // 2
        if liste[milieu] == valeur:
            print(f"  Dichotomique : {comparaisons} comparaison(s)")
            return milieu
        elif liste[milieu] < valeur:
            debut = milieu + 1
        else:
            fin = milieu - 1
    print(f"  Dichotomique : {comparaisons} comparaison(s)")
    return -1

# Test
donnees = [2, 5, 8, 12, 16, 23, 38, 45, 56, 67, 78, 89, 92, 99, 101]
print(f"Liste : {donnees}")
print(f"Recherche de 67 :")
print(f"  Indice trouvé : {recherche_sequentielle(donnees, 67)}")
print(f"  Indice trouvé : {recherche_dichotomique(donnees, 67)}")

print(f"\nRecherche de 3 (inexistant) :")
print(f"  Indice trouvé : {recherche_sequentielle(donnees, 3)}")
print(f"  Indice trouvé : {recherche_dichotomique(donnees, 3)}")

Question pédagogique : Sur une liste de 1 000 000 éléments, combien de comparaisons au maximum pour chaque méthode ? (Réponse : séquentielle = 1 000 000, dichotomique = log₂(1 000 000) ≈ 20)

Exercice 2 — Tri par sélection (20 min)

Énoncé : Créer un script tri_selection.py qui implémente le tri par sélection. Le programme doit : 1. Implémenter tri_selection(liste) qui trie la liste en place 2. Afficher la liste avant et après le tri 3. Compter le nombre d'échanges et de comparaisons 4. Tester sur une liste générée aléatoirement de 10 entiers

Rappel du principe : À chaque itération, on cherche le minimum dans la partie non triée et on le place en début de cette partie.

Corrigé :

import random

def tri_selection(liste):
    """Tri par sélection. Retourne le nombre d'échanges et comparaisons."""
    n = len(liste)
    echanges = 0
    comparaisons = 0
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            comparaisons += 1
            if liste[j] < liste[min_idx]:
                min_idx = j
        if min_idx != i:
            liste[i], liste[min_idx] = liste[min_idx], liste[i]
            echanges += 1
    return echanges, comparaisons

# Test
liste = [random.randint(0, 100) for _ in range(10)]
print(f"Liste originale : {liste}")
ech, comp = tri_selection(liste)
print(f"Liste triée      : {liste}")
print(f"Échanges : {ech}, Comparaisons : {comp}")
print(f"Complexité : O(n²) avec n = {len(liste)} → ~{len(liste)**2 // 2} comparaisons")

Exercice 3 — Pile avec validation de parenthèses (20 min)

Énoncé : Créer un script parentheses.py qui étend l'algorithme de validation de parenthèses vu en cours. Le programme doit :

  1. Implémenter une classe Pile avec les méthodes empiler(), depiler(), est_vide(), taille()
  2. Utiliser cette classe pour valider des expressions avec (), [], {}
  3. En cas d'erreur, indiquer précisément où se trouve le problème (position du caractère)

Corrigé :

class Pile:
    """Implémentation d'une pile LIFO."""
    def __init__(self):
        self._elements = []

    def empiler(self, element):
        self._elements.append(element)

    def depiler(self):
        if not self.est_vide():
            return self._elements.pop()
        return None

    def sommet(self):
        if not self.est_vide():
            return self._elements[-1]
        return None

    def est_vide(self):
        return len(self._elements) == 0

    def taille(self):
        return len(self._elements)

def valider_parentheses(expression):
    """Valide le parenthésage et retourne (valide, erreur_position, message)."""
    correspondance = {")": "(", "]": "[", "}": "{"}
    ouvrantes = "([{"
    fermantes = ")]}"
    pile = Pile()

    for i, char in enumerate(expression):
        if char in ouvrantes:
            pile.empiler(char)
        elif char in fermantes:
            if pile.est_vide():
                return False, i, f"Parenthèse fermante '{char}' sans ouvrante à la position {i}"
            sommet = pile.depiler()
            if sommet != correspondance[char]:
                return False, i, f"Non concordance : '{sommet}' ouvert mais '{char}' fermé à la position {i}"

    if not pile.est_vide():
        return False, len(expression) - 1, f"Il manque {pile.taille()} parenthèse(s) fermante(s)"

    return True, -1, "Expression correcte"

# Tests
expressions = [
    "(3 + 2) × [5 - {1 + 2}]",
    "(3 + 2] × [5 - {1 + 2})",
    "((1 + 2) × 3)",
    "({[)]}",
    "((({}))"
]

for expr in expressions:
    valide, pos, msg = valider_parentheses(expr)
    etat = "✓" if valide else "✗"
    print(f"{etat} {expr[:50]:50s} → {msg}")

Exercice 4 — Algorithmes sur les listes (filtrage et transformation) (15 min)

Énoncé : Créer un script filtrage.py qui, à partir d'une liste de notes aléatoires (20 notes entre 0 et 20) :

  1. Calcule la moyenne, la médiane et l'écart-type manuellement (sans statistics module)
  2. Filtre pour obtenir les notes ≥ 10 (admis)
  3. Crée une nouvelle liste avec les notes augmentées de 1 point (bonus, plafonné à 20)
  4. Utilise des listes en compréhension (list comprehension)

Corrigé :

import random
import math

notes = [random.randint(0, 20) for _ in range(20)]
print(f"Notes originales : {notes}")

# 1. Statistiques manuelles
moyenne = sum(notes) / len(notes)
notes_triees = sorted(notes)
n = len(notes_triees)
mediane = (notes_triees[n // 2 - 1] + notes_triees[n // 2]) / 2 if n % 2 == 0 else notes_triees[n // 2]
variance = sum((x - moyenne) ** 2 for x in notes) / n
ecart_type = math.sqrt(variance)

print(f"Moyenne  : {moyenne:.2f}")
print(f"Médiane  : {mediane:.2f}")
print(f"Écart-type : {ecart_type:.2f}")

# 2. Notes ≥ 10
admis = [n for n in notes if n >= 10]
print(f"Admis (≥10) : {admis} ({len(admis)}/{len(notes)})")

# 3. Bonus plafonné
bonus = [min(n + 1, 20) for n in notes]
print(f"Avec bonus : {bonus}")

Exercice 5 — Algorithme de tri fusion (récursif) (10 min)

Énoncé : Créer un script tri_fusion.py qui implémente le tri fusion (merge sort), un algorithme récursif de complexité O(n log n).

Principe : diviser la liste en deux, trier chaque moitié récursivement, puis fusionner les deux moitiés triées.

Corrigé :

import random

def tri_fusion(liste):
    """Tri fusion récursif."""
    if len(liste) <= 1:
        return liste

    milieu = len(liste) // 2
    gauche = tri_fusion(liste[:milieu])
    droite = tri_fusion(liste[milieu:])

    return fusionner(gauche, droite)

def fusionner(gauche, droite):
    """Fusionne deux listes triées."""
    resultat = []
    i = j = 0
    while i < len(gauche) and j < len(droite):
        if gauche[i] <= droite[j]:
            resultat.append(gauche[i])
            i += 1
        else:
            resultat.append(droite[j])
            j += 1
    resultat.extend(gauche[i:])
    resultat.extend(droite[j:])
    return resultat

# Test
liste = [random.randint(0, 100) for _ in range(15)]
print(f"Originale : {liste}")
triee = tri_fusion(liste)
print(f"Triée      : {triee}")
print(f"Complexité : O(n log n) avec n = {len(liste)}")

Note pédagogique ENS

Transposition didactique

Ce TD montre comment les concepts d'algorithmique (recherche, tri) et structures de données (pile) vus en cours s'implémentent concrètement en Python. Ces algorithmes sont au programme de NSI Terminale. La comparaison des complexités (O(n) vs O(log n) vs O(n²) vs O(n log n)) est un objectif clé du programme. En classe de Première NSI, on peut commencer par la recherche séquentielle et le tri par sélection avant d'aborder la dichotomique et le tri fusion.

Conseil pour l'enseignant formateur

L'exercice 1 est fondamental : faire exécuter mentalement les deux algorithmes sur un petit jeu de données avant de les coder. Pour l'exercice 2, demander aux étudiants de tracer l'évolution du tableau à chaque itération sur une feuille. L'exercice 3 (parenthésage) est un excellent exemple de l'utilité des piles. L'exercice 5 (tri fusion) introduit la récursivité : la maîtriser est difficile mais cruciale pour la suite du programme.

Prolongement
