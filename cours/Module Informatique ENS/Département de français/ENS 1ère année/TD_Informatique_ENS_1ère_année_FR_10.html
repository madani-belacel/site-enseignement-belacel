Exercice 1 — Classe File d'attente (20 min)

Énoncé : Créer un script file_attente.py qui implémente une classe File avec : 1. Les méthodes enfiler(), defiler(), tete(), est_vide(), taille() 2. Une méthode afficher() qui montre l'état de la file 3. Un test avec une simulation de guichet : des clients arrivent et sont servis

Corrigé :

from collections import deque

class File:
    """Implémentation d'une file FIFO."""
    def __init__(self):
        self._elements = deque()

    def enfiler(self, element):
        self._elements.append(element)

    def defiler(self):
        if not self.est_vide():
            return self._elements.popleft()
        return None

    def tete(self):
        if not self.est_vide():
            return self._elements[0]
        return None

    def est_vide(self):
        return len(self._elements) == 0

    def taille(self):
        return len(self._elements)

    def afficher(self):
        print(f"File : {list(self._elements)} (tête → {self.tete()}, {self.taille()} client(s))")

# Simulation de guichet
print("=== Simulation de guichet ===\n")
file = File()

# Arrivée des clients
for nom in ["Ali", "Sara", "Mohamed", "Leila", "Ahmed"]:
    file.enfiler(nom)
    print(f"✓ {nom} arrive dans la file.")

print(f"\nÉtat initial :")
file.afficher()

# Service
print("\nService en cours :")
while not file.est_vide():
    client = file.defiler()
    print(f"→ Service de {client} terminé.")
    if not file.est_vide():
        print(f"  Prochain client : {file.tete()}")

print("\n✓ Tous les clients ont été servis.")

Exercice 2 — Évaluation d'expression postfixée (RPN) (20 min)

Énoncé : Créer un script rpn.py qui évalue une expression en notation polonaise inversée (NPI/RPN) en utilisant une pile.

Principe : L'opérateur suit ses opérandes. Exemple : 3 4 + = 3 + 4 = 7

Exemples : - 3 4 + → 7 - 5 3 8 + - → 5 - (3 + 8) = -6 - 10 4 2 + * → 10 × (4 + 2) = 60

Corrigé :

def evaluer_rpn(expression):
    """Évalue une expression en notation polonaise inversée."""
    pile = []
    operateurs = {
        "+": lambda a, b: a + b,
        "-": lambda a, b: a - b,
        "*": lambda a, b: a * b,
        "/": lambda a, b: a / b if b != 0 else None
    }

    elements = expression.split()
    for elem in elements:
        if elem in operateurs:
            if len(pile) < 2:
                return "Erreur : pas assez d'opérandes"
            b = pile.pop()
            a = pile.pop()
            resultat = operateurs[elem](a, b)
            if resultat is None:
                return "Erreur : division par zéro"
            pile.append(resultat)
        else:
            try:
                pile.append(float(elem))
            except ValueError:
                return f"Erreur : élément invalide '{elem}'"

    if len(pile) != 1:
        return f"Erreur : {len(pile)} résultats au lieu de 1"
    return pile[0]

# Tests
expressions = [
    "3 4 +",
    "5 3 8 + -",
    "10 4 2 + *",
    "15 7 1 1 + - / 3 * 2 1 1 + + -",
    "4 0 /"
]

for expr in expressions:
    resultat = evaluer_rpn(expr)
    print(f"{expr:30s} → {resultat}")

Exercice 3 — Parcours en largeur d'un graphe (BFS) (20 min)

Énoncé : Créer un script bfs.py qui implémente un parcours en largeur (Breadth-First Search) en utilisant une file. Le graphe représente le plan d'une école : chaque pièce est reliée à d'autres par des couloirs.

graph TD
    ENTREE --> HALL
    HALL --> SALLE1
    HALL --> CDI
    HALL --> BUREAU
    CDI --> SALLE2
    BUREAU --> SALLE3
    SALLE1 --> SALLE2
    SALLE2 --> SALLE3

Corrigé :

from collections import deque

def bfs(graphe, depart):
    """Parcours en largeur à partir d'un nœud."""
    visites = set()
    file = deque()
    ordre = []

    file.append(depart)
    visites.add(depart)

    print(f"Parcours en largeur depuis '{depart}' :")

    while file:
        courant = file.popleft()
        ordre.append(courant)
        print(f"  Visite : {courant}")

        for voisin in sorted(graphe[courant]):
            if voisin not in visites:
                visites.add(voisin)
                file.append(voisin)

    return ordre

# Graphe : plan de l'école
ecole = {
    "Entrée": ["Hall"],
    "Hall": ["Entrée", "Salle1", "CDI", "Bureau"],
    "Salle1": ["Hall", "Salle2"],
    "Salle2": ["CDI", "Salle1", "Salle3"],
    "Salle3": ["Bureau", "Salle2"],
    "CDI": ["Hall", "Salle2"],
    "Bureau": ["Hall", "Salle3"]
}

ordre_visite = bfs(ecole, "Entrée")
print(f"\nOrdre de visite : {' → '.join(ordre_visite)}")

# Question : quelle est la distance (nombre de portes) entre l'entrée et la salle 3 ?
# Réponse : Entrée → Hall → Bureau → Salle3 (3 portes)

Exercice 4 — Dictionnaire d'étudiants avec recherche multicritère (15 min)

Énoncé : Créer un script etudiants.py qui gère une base de données d'étudiants (liste de dictionnaires). Le programme : 1. Crée une liste d'au moins 5 étudiants avec : nom, notes (liste), groupe, filière 2. Calcule la moyenne de chaque étudiant 3. Propose des fonctions de recherche par groupe, par filière, par moyenne 4. Trie les étudiants par moyenne décroissante

Corrigé :

def creer_etudiant(nom, groupe, filiere, notes):
    """Crée un dictionnaire étudiant."""
    moyenne = sum(notes) / len(notes) if notes else 0
    return {
        "nom": nom,
        "groupe": groupe,
        "filiere": filiere,
        "notes": notes,
        "moyenne": round(moyenne, 2)
    }

def rechercher_par_groupe(etudiants, groupe):
    """Recherche les étudiants d'un groupe."""
    return [e for e in etudiants if e["groupe"] == groupe]

def rechercher_par_filiere(etudiants, filiere):
    """Recherche les étudiants d'une filière."""
    return [e for e in etudiants if e["filiere"] == filiere]

def rechercher_par_moyenne(etudiants, seuil):
    """Recherche les étudiants avec moyenne ≥ seuil."""
    return [e for e in etudiants if e["moyenne"] >= seuil]

def trier_par_moyenne(etudiants):
    """Trie par moyenne décroissante."""
    return sorted(etudiants, key=lambda e: e["moyenne"], reverse=True)

# Création de la base
etudiants = [
    creer_etudiant("Ali", "G1", "Français", [15, 12, 18]),
    creer_etudiant("Sara", "G1", "Français", [18, 16, 17]),
    creer_etudiant("Mohamed", "G2", "Anglais", [10, 11, 9]),
    creer_etudiant("Leila", "G2", "Français", [16, 14, 19]),
    creer_etudiant("Ahmed", "G1", "Anglais", [8, 10, 12]),
    creer_etudiant("Fatima", "G2", "Anglais", [14, 15, 13])
]

print("=== Tous les étudiants ===")
for e in etudiants:
    print(f"{e['nom']:<10} {e['groupe']:<4} {e['filiere']:<10} Notes : {e['notes']} Moy : {e['moyenne']}")

print(f"\n=== Groupe G1 ===")
for e in rechercher_par_groupe(etudiants, "G1"):
    print(f"  {e['nom']} — {e['filiere']} — Moy : {e['moyenne']}")

print(f"\n=== Moyenne ≥ 14 ===")
for e in rechercher_par_moyenne(etudiants, 14):
    print(f"  {e['nom']} — {e['moyenne']}")

print(f"\n=== Classement général ===")
for i, e in enumerate(trier_par_moyenne(etudiants), 1):
    print(f"{i:2d}. {e['nom']:<10} {e['moyenne']:.2f}")

Exercice 5 — Compression par dictionnaire (run-length encoding) (10 min)

Énoncé : Créer un script rle.py qui implémente un algorithme simple de compression : - Le codage RLE (Run-Length Encoding) remplace les répétitions par (valeur, nombre) - Exemple : AAABBBCCDAA → [('A',3), ('B',3), ('C',2), ('D',1), ('A',2)] - Implémenter compresser(chaine) et decompresser(donnees)

Corrigé :

def compresser(chaine):
    """Compresse une chaîne avec RLE."""
    if not chaine:
        return []

    resultat = []
    courant = chaine[0]
    compteur = 1

    for c in chaine[1:]:
        if c == courant:
            compteur += 1
        else:
            resultat.append((courant, compteur))
            courant = c
            compteur = 1

    resultat.append((courant, compteur))
    return resultat

def decompresser(donnees):
    """Décompresse des données RLE."""
    return "".join(c * n for c, n in donnees)

# Tests
exemple = "AAABBBCCDAA"
print(f"Originale   : {exemple}")
compresse = compresser(exemple)
print(f"Compressée  : {compresse}")
print(f"Taux : {len(str(compresse)) / len(exemple) * 100:.1f}% de la taille originale")
decompresse = decompresser(compresse)
print(f"Décompressée : {decompresse}")
print(f"Identique ? {exemple == decompresse}")

# Autre test
texte = "WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"
comp = compresser(texte)
print(f"\nTexte original : {len(texte)} caractères")
print(f"Texte compressé : {len(comp)} paires")
print(f"Taux de compression : {len(comp) / len(texte) * 100:.1f}%")

Note pédagogique ENS

Transposition didactique

Ce TD de synthèse mobilise toutes les compétences acquises : classes, piles, files, dictionnaires, algorithmes. La notation polonaise inversée (exercice 2) est un excellent exemple de l'utilité des piles en informatique. Le parcours en largeur (exercice 3) introduit les graphes, concept fondamental pour l'enseignement de NSI Terminale. La compression RLE (exercice 5) est intuitive et visuelle : les élèves comprennent vite le principe.

Conseil pour l'enseignant formateur

L'exercice 2 (RPN) est souvent source de confusion car les élèves doivent lire l'expression différemment. Faire calculer « à la main » plusieurs expressions RPN au tableau avant de coder. Pour l'exercice 3 (BFS), utiliser un grand papier ou le tableau pour simuler physiquement le parcours : placer des post-its représentant les salles et les relier par des fils, puis déplacer un pion. L'exercice 5 (RLE) est ludique : demander aux étudiants de trouver des exemples de répétitions dans leur propre nom ou dans des phrases.
