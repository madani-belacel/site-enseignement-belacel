Objectifs pédagogiques spécifiques

À l'issue de cette séance, l'étudiant est capable de : - Structurer un projet Python en modules (main.py, fonctions.py, donnees.csv) - Gérer les erreurs d'exécution avec try/except - Lire et écrire des fichiers CSV avec le module csv - Développer un générateur de fiches de révision à partir d'un CSV - Développer un calculateur de moyenne avec export CSV - Présenter son projet selon la grille d'évaluation de la soutenance

Contexte réglementaire algérien

Ce cours s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique, consultée pour aligner ce cours sur les standards nationaux.

import csv, random

def charger_fiches(f):
    try:
        with open(f, encoding="utf-8") as fh:
            return list(csv.DictReader(fh))
    except FileNotFoundError:
        print(f"Fichier introuvable.")
        return []

def lancer_quiz(fs):
    if not fs: return
    random.shuffle(fs); score = 0
    for f in fs:
        print(f"\nConcept : {f['Concept']}")
        input("Entrée..."); print(f"Définition : {f['Définition']}")
        if input("Correct ? (o/n): ")=="o": score+=1
    print(f"Score: {score}/{len(fs)}")

if __name__ == "__main__":
    lancer_quiz(charger_fiches("revision.csv"))

6. Projet — Calculateur de moyenne (15 min)

import csv

def saisir_notes():
    eleves = []
    print("\n--- SAISIE DES NOTES ---")
    while True:
        nom = input("\nNom (ou 'fin') : ").strip()
        if nom.lower() == "fin": break
        notes = []
        for i in range(1, 4):
            while True:
                try:
                    n = float(input(f"  Note {i} (0-20) : "))
                    if 0 <= n <= 20:
                        notes.append(n); break
                    print("Note invalide.")
                except ValueError:
                    print("Entrez un nombre.")
        moy = round(sum(notes)/len(notes), 2)
        eleves.append({"nom": nom, "notes": notes, "moyenne": moy})
        print(f"→ {nom}: {moy:.2f}")
    return eleves

def stats(eleves):
    if not eleves: return
    moyennes = [e["moyenne"] for e in eleves]
    print(f"\nEffectif: {len(eleves)} | Classe: {sum(moyennes)/len(moyennes):.2f}")
    print(f"Max: {max(moyennes):.2f} | Min: {min(moyennes):.2f}")

def exporter(eleves, fichier="resultats.csv"):
    with open(fichier, "w", newline="", encoding="utf-8") as f:
        cols = ["Nom", "Note1", "Note2", "Note3", "Moyenne", "Mention"]
        w = csv.DictWriter(f, fieldnames=cols)
        w.writeheader()
        for e in eleves:
            m = e["moyenne"]
            mention = "TB" if m >= 16 else "B" if m >= 14 else "AB" if m >= 12 else "P" if m >= 10 else "NV"
            w.writerow({"Nom": e["nom"], "Note1": e["notes"][0],
                       "Note2": e["notes"][1], "Note3": e["notes"][2],
                       "Moyenne": f"{m:.2f}", "Mention": mention})
    print(f"Exporté dans {fichier}")

if __name__ == "__main__":
    e = saisir_notes()
    if e: stats(e); exporter(e)

Note pédagogique ENS

Transposition didactique : Le projet Python final valide l'ensemble des compétences du module (C1–C8). La démarche suivie (spécifications → conception → implémentation → test → soutenance) est exactement celle du Bac NSI en France. Les compétences développées sont transposables au lycée comme suit :

Compétence Activité transposable au lycée
Structures de projet Le découpage en main.py / fonctions.py / donnees.csv est le modèle à enseigner en NSI dès la Première
Gestion d'erreurs try/except avec messages explicites : exigible en NSI Terminale pour valider la compétence « Robustesse »
Fichiers CSV Le format CSV (export Moodle, Excel, Pronote) est le format d'échange de données le plus courant en milieu scolaire
Quiz pédagogique Programme interactif utilisable dans toutes les disciplines : langues, histoire, sciences
Calculateur de moyenne Automatisation du suivi des notes : outil concret que le futur enseignant peut déployer dans sa classe

Activités recommandées pour la classe : 1. Analyse d'un projet existant — Distribuer un projet Python complet et demander aux élèves d'identifier le rôle de chaque fichier et fonction 2. Cahier des charges — Faire rédiger le cahier des charges avant de coder (compétence « Expression des besoins » du CRCN) 3. Revue de code — En binôme, chaque étudiant révise le code de l'autre et propose des améliorations 4. Présentation orale — La soutenance de 5 minutes prépare aux épreuves orales du Bac (Grand Oral, NSI) 5. Adaptation à un niveau inférieur — Demander aux étudiants de simplifier le quiz pour des élèves de 6e (activité de transposition didactique)

Conseil pour l'enseignant formateur : Le projet final est l'aboutissement du module ; il doit être valorisé comme une production personnelle. Accompagner les étudiants dans le choix du sujet (quiz pédagogique, calculateur de moyenne, jeu éducatif) et veiller à ce qu'ils respectent les étapes de développement (spécifications → conception → implémentation → test). La soutenance de 5 minutes doit être chronométrée et évaluée selon des critères clairs (qualité du code, pertinence pédagogique, présentation orale).

Prolongement : En ENS 2ème année, le projet peut être enrichi par la POO (classes Question, Quiz, Joueur), le développement Web avec Flask (formulaires et base de données SQLite), l'exposition des résultats via une API REST, ou encore un projet interdisciplinaire (quiz d'histoire-géographie, exercices de mathématiques, flashcards de langues).
