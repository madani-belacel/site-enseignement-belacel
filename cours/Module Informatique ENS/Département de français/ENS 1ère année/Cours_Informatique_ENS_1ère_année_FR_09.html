Objectifs pédagogiques spécifiques

À l'issue de cette séance, l'étudiant est capable de : - Justifier le choix de Python pour l'enseignement de la programmation - Installer et configurer un environnement Python (IDLE, VS Code, Thonny) - Déclarer et utiliser les types de base (int, float, str, bool) - Structurer un programme avec conditions (if/elif/else) et boucles (for/while) - Définir et appeler des fonctions avec paramètres et valeur de retour - Lire et écrire dans un fichier texte depuis un script Python

Contexte réglementaire algérien

Ce cours s'inscrit dans le cadre réglementaire algérien de formation des enseignants :

  • Arrêté ministériel portant création des ENS (cycle Licence/Master) — définit le cadre institutionnel des Écoles Normales Supérieures et leur mission de formation des enseignants.
  • Programme national d'Informatique des ENS algériennes — fixe les objectifs, contenus et volumes horaires du module Informatique dans la formation initiale des enseignants.
  • Arrêté 712 fixant le programme des concours ENS — détermine les épreuves et les programmes des concours d'accès aux ENS, en cohérence avec les contenus enseignés.
  • Référentiel des compétences numériques algérien — cadre national (en cours d'élaboration) définissant les compétences numériques attendues des enseignants.
  • Benchmark des 10 universités algériennes — étude comparative des pratiques d'enseignement de l'informatique, consultée pour aligner ce cours sur les standards nationaux.

3. Variables et types (15 min)

En Python, les variables sont des étiquettes pointant vers des objets. Pas de déclaration de type explicite.

age = 20                  # int
pi = 3.14159              # float
nom = "Madani"            # str
est_enseignant = True     # bool

print(type(age))          # <class 'int'>
print(f"{nom} a {age} ans")  # f-string (Python 3.6+)

# Conversion de type
age_str = "20"
age_int = int(age_str)           # "20" → 20
note = float(input("Note : "))   # Saisie → float

Parallèle pseudo-code ↔ Python :

Concept Pseudo-code Python
Affectation age ← 20 age = 20
Affichage AFFICHER age print(age)
Saisie LIRE age input()
Commentaire // texte # texte
Comparaison age == 18 age == 18

Piège : = est l'affectation, == est la comparaison.

5. Boucles (15 min)

Boucle for — parcours d'une séquence

for i in range(5):
    print(f"Itération {i}")

for i in range(1, 10, 2):
    print(i)                    # 1, 3, 5, 7, 9

noms = ["Ali", "Sara", "Mohamed"]
for nom in noms:
    print(f"Bonjour {nom}")

for i, nom in enumerate(noms):
    print(f"{i+1}. {nom}")

Boucle while — répétition conditionnelle

reponse = ""
while reponse != "oui" and reponse != "non":
    reponse = input("Continue ? (oui/non) : ").lower()

compteur = 0
while compteur < 5:
    print(f"Compteur : {compteur}")
    compteur += 1

6. Fonctions (15 min)

def calculer_moyenne(notes):
    """Calcule la moyenne d'une liste de notes."""
    return sum(notes) / len(notes)

def saluer(nom, message="Bienvenue"):
    print(f"{message}, {nom} !")

notes = [15, 12, 18, 10, 14]
moy = calculer_moyenne(notes)
print(f"Moyenne : {moy:.2f}")

saluer("Ali")                # Bienvenue, Ali !
saluer("Sara", "Bonjour")    # Bonjour, Sara !

def notes_min_max(notes):
    return min(notes), max(notes)  # Retourne un tuple

mini, maxi = notes_min_max(notes)
print(f"Min: {mini}, Max: {maxi}")

Pourquoi des fonctions ? Réutilisabilité, lisibilité, testabilité, modularité.

Bonnes pratiques : noms en verbes, docstring entre """, un retour par fonction.

7. Entrées/sorties et fichiers (10 min)

# Saisie utilisateur
nom = input("Entrez votre nom : ")

# Écriture fichier
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("Nom,Note\n")
    f.write("Ali,15\n")
    f.write("Sara,18\n")
# Le with ferme automatiquement

# Lecture fichier
with open("notes.txt", "r", encoding="utf-8") as f:
    for ligne in f:
        print(ligne.strip())

# Modes : "r" lecture, "w" écriture (écrase), "a" ajout

# Traitement CSV simple
with open("notes.txt", "r") as f:
    f.readline()   # Ignorer en-tête
    total = 0
    n = 0
    for ligne in f:
        nom, note = ligne.strip().split(",")
        total += float(note)
        n += 1
    print(f"Moyenne : {total/n:.2f}")

Contexte pédagogique : le format CSV est omniprésent dans l'éducation (export Moodle, Excel, bulletins).

8. Mini-projet (5 min)

Quiz de vocabulaire anglais/français — combinant tous les concepts :

questions = {
    "chat": "cat", "chien": "dog", "maison": "house",
    "livre": "book", "école": "school", "professeur": "teacher"
}

def poser_question(mot_fr, mot_en):
    reponse = input(f"Traduire '{mot_fr}' : ").strip().lower()
    if reponse == mot_en:
        print("✓ Correct !")
        return True
    print(f"✗ Faux. Réponse : {mot_en}")
    return False

score = 0
for fr, en in questions.items():
    if poser_question(fr, en):
        score += 1
print(f"Score : {score}/{len(questions)}")

QCM d'auto-évaluation

  1. Quelle fonction affiche du texte dans la console en Python ? a) input() b) print() ✓ c) write()

  2. Quel type retourne input() ? a) int b) float c) str ✓

  3. Quel mot-clé définit une fonction ? a) function b) def ✓ c) define

  4. Quelle boucle est idéale pour parcourir une liste ? a) while b) for ✓ c) repeat

  5. Quel mode d'ouverture permet l'écriture (écrase) ? a) "r" b) "w" ✓ c) "a"

Niveau Thème Activité recommandée

NSI Terminale Récursivité et fichiers Lire un fichier CSV de notes, calculer les statistiques, exporter un bulletin.
Mathématiques Simulation Écrire une fonction qui simule le lancer d'un dé (random), répéter N fois, compter les fréquences.
Interdisciplinaire Quiz de vocabulaire Le mini-projet de quiz (section 8) peut être adapté en cours de langue : l'élève programme un quiz pour ses camarades.

Démarche pédagogique progressive : 1. Lire : analyser un script existant, repérer les blocs (variables, conditions, boucles) 2. Modifier : changer des valeurs, ajouter une condition, étendre une boucle 3. Créer : écrire un script répondant à un cahier des charges simple 4. Évaluer : tester avec différents jeux de données, détecter et corriger les erreurs

Conseil pour l'enseignant formateur : - Utiliser Thonny pour la découverte (débogueur pas à pas visible), puis VS Code pour les projets - Privilégier les exercices contextuels (calcul de moyenne, quiz, convertisseur) plutôt que des exercices décontextualisés - Montrer systématiquement le parallèle pseudo-code ↔ Python pour ancrer les concepts vus en cours d'algorithmique (séance 05) - Prévoir des fiches d'aide (memento Python) que les étudiants conservent pour les séances suivantes - Éviter : utiliser Thonny portable ou Replit pour les premières séances (préférer une installation locale)

Prolongement : Les étudiants peuvent explorer les bibliothèques Python pour l'enseignement : turtle (graphiques), pygame (jeux), matplotlib (visualisation). Proposer une activité complémentaire : créer un petit exercice de vocabulaire français avec des flashcards aléatoires utilisant tkinter ou un quiz interactif en ligne de commande avec chronomètre (time). Ces activités sont directement transposables en cours de langue ou d'histoire-géographie.
