TP Informatique — ENS 1ère année — TP 01 (FR)

Enseignant : BELACEL Madani
Module : Informatique
Niveau : ENS — 1ère année — Département de français
Durée : 1h30
Année universitaire : 2025-2026

Objectifs pédagogiques

À l'issue de ce TP, l'étudiant est capable de : - Installer et configurer Python sur sa machine - Écrire et exécuter un premier script Python - Utiliser les fonctions print() et input() - Déclarer et manipuler des variables (int, float, str, bool) - Effectuer des opérations arithmétiques et des conversions d'unités - Structurer un programme simple avec des conditions

Exercice 1 — Premier script (10 min)

Énoncé : Créer un script Python nommé presentation.py qui affiche votre nom, prénom et groupe.

Exemple attendu :

Nom : BELACEL
Prénom : Madani
Groupe : ENS1 Français

Corrigé :

print("Nom : BELACEL")
print("Prénom : Madani")
print("Groupe : ENS1 Français")

Exercice 2 — Variables et types (15 min)

Énoncé : Créer un script variables.py qui : 1. Déclare une variable nom (str), age (int), taille (float), est_etudiant (bool) 2. Affiche le type de chaque variable avec type() 3. Affiche une phrase récapitulative en utilisant une f-string

Exemple attendu :

<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>
Je m'appelle Madani, j'ai 20 ans, je mesure 1.75 m, étudiant : True

Corrigé :

nom = "Madani"
age = 20
taille = 1.75
est_etudiant = True

print(type(nom))
print(type(age))
print(type(taille))
print(type(est_etudiant))

print(f"Je m'appelle {nom}, j'ai {age} ans, je mesure {taille} m, étudiant : {est_etudiant}")

Exercice 3 — Opérations arithmétiques (15 min)

Énoncé : Créer un script calculs.py qui : 1. Demande deux nombres à l'utilisateur avec input() 2. Calcule et affiche leur somme, différence, produit, quotient et puissance 3. Gère le cas où le deuxième nombre est 0 (afficher « Division impossible »)

Exemple attendu :

Premier nombre : 10
Deuxième nombre : 3
10 + 3 = 13
10 - 3 = 7
10 × 3 = 30
10 / 3 = 3.33
10 ^ 3 = 1000

Corrigé :

a = float(input("Premier nombre : "))
b = float(input("Deuxième nombre : "))

print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} × {b} = {a * b}")

if b != 0:
    print(f"{a} / {b} = {a / b:.2f}")
else:
    print("Division impossible")

print(f"{a} ^ {b} = {a ** b}")

Exercice 4 — Convertisseur d'unités (20 min)

Énoncé : Créer un script convertisseur.py qui : 1. Demande une température en degrés Celsius 2. Convertit en Fahrenheit (F = C × 9/5 + 32) 3. Convertit en Kelvin (K = C + 273.15) 4. Affiche les résultats avec 2 décimales

Exemple attendu :

Température en °C : 25
25.00°C = 77.00°F
25.00°C = 298.15 K

Corrigé :

celsius = float(input("Température en °C : "))
fahrenheit = celsius * 9/5 + 32
kelvin = celsius + 273.15

print(f"{celsius:.2f}°C = {fahrenheit:.2f}°F")
print(f"{celsius:.2f}°C = {kelvin:.2f} K")

Diagramme de flux du convertisseur :

flowchart TD
    A[Début] --> B[Saisir température en °C]
    B --> C{Entrée valide ?}
    C -->|Non| D[Afficher erreur]
    D --> B
    C -->|Oui| E[Calculer Fahrenheit]
    E --> F[Calculer Kelvin]
    F --> G[Afficher résultats]
    G --> H[Fin]

Exercice 5 — Calculateur de moyenne (15 min)

Énoncé : Créer un script moyenne.py qui : 1. Demande 3 notes à l'utilisateur 2. Calcule la moyenne 3. Affiche la moyenne avec 2 décimales 4. Affiche « Admis » si moyenne ≥ 10, « Ajourné » sinon

Exemple attendu :

Note 1 : 14
Note 2 : 12
Note 3 : 16
Moyenne : 14.00/20 — Admis

Corrigé :

n1 = float(input("Note 1 : "))
n2 = float(input("Note 2 : "))
n3 = float(input("Note 3 : "))

moyenne = (n1 + n2 + n3) / 3

print(f"Moyenne : {moyenne:.2f}/20", end=" — ")
if moyenne >= 10:
    print("Admis")
else:
    print("Ajourné")

Exercice 6 — Défi : calculatrice pédagogique (15 min)

Énoncé : Créer un script calculatrice.py qui : 1. Demande deux nombres à l'utilisateur 2. Demande l'opération souhaitée (+, -, *, /) 3. Effectue l'opération et affiche le résultat 4. Affiche un message d'erreur si l'opération est inconnue ou si division par zéro

Exemple attendu :

Nombre 1 : 15
Nombre 2 : 4
Opération (+, -, *, /) : /
15.0 / 4.0 = 3.75

Corrigé :

a = float(input("Nombre 1 : "))
b = float(input("Nombre 2 : "))
op = input("Opération (+, -, *, /) : ")

if op == "+":
    print(f"{a} + {b} = {a + b}")
elif op == "-":
    print(f"{a} - {b} = {a - b}")
elif op == "*":
    print(f"{a} × {b} = {a * b}")
elif op == "/":
    if b != 0:
        print(f"{a} / {b} = {a / b}")
    else:
        print("Erreur : division par zéro")
else:
    print("Opération inconnue")

Organigramme de la calculatrice :

flowchart TD
    A[Début] --> B[Saisir nombre a]
    B --> C[Saisir nombre b]
    C --> D[Saisir opérateur]
    D --> E{Opérateur ?}
    E -->|"+"| F[Afficher a + b]
    E -->|"-"| G[Afficher a - b]
    E -->|"*"| H[Afficher a × b]
    E -->|"/"| I{b = 0 ?}
    I -->|Oui| J[Erreur division par zéro]
    I -->|Non| K[Afficher a / b]
    E -->|Autre| L[Opération inconnue]
    F --> M[Fin]
    G --> M
    H --> M
    J --> M
    K --> M
    L --> M

Note pédagogique ENS

Transposition didactique

Ce TP d'introduction à Python est conçu pour les futurs enseignants de français appelés à enseigner l'informatique au collège et au lycée (SNT en Seconde, NSI au lycée général). La progression pédagogique suit une difficulté croissante : découverte → manipulation → création. Le convertisseur d'unités (exercice 4) est un excellent support pour aborder les grandeurs et mesures en interdisciplinarité avec les sciences physiques. Le défi calculatrice (exercice 6) peut être proposé comme projet maison et constitue un modèle réutilisable en classe : un élève de collège peut le personnaliser pour créer sa propre calculatrice pédagogique.

Conseil formateur

Veiller à ce que chaque étudiant ait Python installé et fonctionnel avant le début du TP. Prévoir 15 minutes de battement pour les problèmes d'installation. Encourager les binômes pour l'entraide mais demander un rendu individuel. Pour les élèves de collège, remplacer le défi calculatrice par un programme qui affiche « Bonjour + prénom » pour éviter la surcharge cognitive.

Prolongement

Les étudiants peuvent créer un programme complet de « Cahier de textes numérique » qui enregistre les leçons du jour, les exercices à faire et les évaluations, avec la date et le niveau de classe concerné.
