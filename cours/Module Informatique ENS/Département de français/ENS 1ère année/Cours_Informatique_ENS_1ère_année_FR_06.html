Objectifs pédagogiques spécifiques

À l'issue de cette séance, l'étudiant est capable de : - Définir une structure de données et expliquer son rôle algorithmique - Distinguer accès direct (O(1)) et accès séquentiel (O(n)) dans un tableau - Implémenter les opérations push, pop, peek d'une pile (LIFO) et enqueue, dequeue d'une file (FIFO) - Modéliser une liste chaînée avec nœuds et pointeurs - Choisir la structure adaptée (tableau, pile, file, liste chaînée) selon le problème

1. Notion de structure de données (5 min)

Une structure de données est une organisation logique des données en mémoire permettant des opérations efficaces (ajout, suppression, recherche, parcours).

Critères de choix : type d'accès (direct/séquentiel), dynamisme (taille fixe/variable), type d'opérations fréquentes.

2. Tableaux (array) (15 min)

Un tableau est une zone mémoire contiguë contenant des éléments de même type, chacun repéré par un indice.

// Pseudo-code : déclaration et accès
notes: TABLEAU[10] D'ENTIERS
notes[0] ← 15
notes[1] ← 12
notes[2] ← 18

// Parcours et somme
somme ← 0
POUR i DE 0 À 9 FAIRE
    somme ← somme + notes[i]
FIN POUR

Complexités fondamentales : - Accès par indice : O(1) — calcul direct de l'adresse mémoire : addr = base + i × taille_élément - Parcours séquentiel : O(n) — il faut visiter chaque élément - Insertion au milieu : O(n) — décalage des éléments suivants

Propriétés : taille fixe (statique), contiguë en mémoire, accès aléatoire instantané.

Exemple pédagogique NSI : un tableau de 30 notes pour une classe. Calcul de la moyenne en O(n). Recherche du maximum en O(n).

3. Piles — LIFO (20 min)

Principe : Last In, First Out — le dernier élément ajouté est le premier retiré.

Analogie : une pile d'assiettes. On pose la nouvelle assiette sur le dessus ; on prend toujours celle du dessus.

// Opérations sur une pile
PILE pile ← VIDE

empiler(pile, 10)    // [10]
empiler(pile, 20)    // [10, 20]
empiler(pile, 30)    // [10, 20, 30]
x ← depiler(pile)    // x = 30, pile = [10, 20]
y ← depiler(pile)    // y = 20, pile = [10]
Opération Rôle Complexité
push(v) Ajouter au sommet O(1)
pop() Retirer et renvoyer le sommet O(1)
peek() Consulter le sommet sans retirer O(1)
is_empty() Vérifier si la pile est vide O(1)

Exemples concrets : - Ctrl+Z (annulation) : chaque action est empilée, Ctrl+Z dépile - Historique navigateur : bouton « Précédent » dépile les URLs visitées - Pile d'appels (call stack) : le système empile les appels de fonctions

Enseignement NSI : la pile d'appels explique la récursivité. Chaque appel récursif empile un nouveau cadre ; le retour dépile.

4. Files — FIFO (20 min)

Principe : First In, First Out — le premier élément ajouté est le premier retiré.

Analogie : une file d'attente à la cantine. Le premier arrivé est le premier servi.

// Opérations sur une file
FILE file ← VIDE

enfiler(file, 10)    // [10]
enfiler(file, 20)    // [10, 20]
enfiler(file, 30)    // [10, 20, 30]
x ← defiler(file)    // x = 10, file = [20, 30]
y ← defiler(file)    // y = 20, file = [30]
Opération Rôle Complexité
enqueue(v) Ajouter à la fin (queue) O(1)
dequeue() Retirer et renvoyer le début (tête) O(1)
front() Consulter la tête sans retirer O(1)
is_empty() Vérifier si la file est vide O(1)

Exemples concrets : - File d'impression : les documents s'impriment dans l'ordre d'envoi - Tampon clavier : les touches sont traitées dans l'ordre de frappe - Gestionnaire de tâches : files d'attente des processus CPU

5. Listes chaînées (15 min)

Une liste chaînée est une structure dynamique où chaque élément (nœud) contient une valeur et un pointeur vers le nœud suivant.

// Structure d'un nœud
Noeud {
    valeur: ENTIER
    suivant: POINTEUR_VERS_Noeud
}

        N2["Nœud 2<br/>valeur: 20<br/>suivant: *"]
        N3["Nœud 3<br/>valeur: 30<br/>suivant: null"]
    end

    TETE["TÊTE"] --> N1
    N1 -->|"pointeur"| N2
    N2 -->|"pointeur"| N3
    N3 --> FIN["null (fin)"]

    style FIN fill:#95a5a6,color:#fff

Caractéristiques : - Taille dynamique : pas de limite fixe, la mémoire est allouée au fur et à mesure - Insertion au début : O(1) — il suffit de modifier le pointeur de tête - Insertion au milieu : O(1) — si on a le pointeur vers le nœud précédent - Accès par indice : O(n) — obligé de parcourir depuis la tête - Recherche : O(n) — parcours séquentiel obligatoire

Pseudo-code insertion au début :

// Insérer valeur au début d'une liste chaînée
FONCTION inserer_debut(tete, valeur)
    nouveau ← NOUVEAU_Noeud(valeur)
    nouveau.suivant ← tete
    RETOURNER nouveau  // nouvelle tête
FIN FONCTION

Critère Tableau Liste chaînée
Accès par indice O(1) — direct O(n) — séquentiel
Insertion début O(n) — décalage O(1) — pointeur
Insertion fin O(1) — si place O(1) — si queue connue
Suppression O(n) — décalage O(1) — pointeur
Recherche O(n) O(n)
Mémoire Fixe, contiguë Dynamique, dispersée
Cache CPU Favorable (localité) Défavorable

Guide de choix : - Accès fréquent par position → Tableau (ex: liste de notes indicées) - Insertions/suppressions fréquentes au début ou au milieu → Liste chaînée - Opérations LIFO → Pile (ex: historique, annulation) - Opérations FIFO → File (ex: file d'attente, tampon) - Taille inconnue à l'avance → Liste chaînée

QCM d'auto-évaluation

  1. Quelle est la complexité d'accès à un élément dans un tableau par son indice ? a) O(n) b) O(1) ✓ c) O(n²)

  2. Dans une pile LIFO, quel élément retire-t-on avec pop() ? a) Le premier ajouté b) Le dernier ajouté ✓ c) L'élément au milieu

  3. Quelle analogie représente le mieux une file FIFO ? a) Une pile d'assiettes b) Une file d'attente au guichet ✓ c) Un tableau d'affichage

  4. Dans une liste chaînée, quel est le coût d'une insertion au début ? a) O(1) ✓ b) O(n) c) O(n²)

  5. Quelle structure de données utilise le bouton « Précédent » du navigateur ? a) File b) Pile ✓ c) Liste chaînée

Conclusion (5 min)

Les structures de données sont des outils algorithmiques essentiels. Un tableau favorise l'accès rapide (O(1)). Une liste chaînée favorise l'insertion dynamique (O(1)). La pile organise le « dernier arrivé, premier servi » (LIFO) ; la file organise le « premier arrivé, premier servi » (FIFO). Le choix de la structure détermine l'efficacité du programme.

Prochain cours : Réseaux et Internet — comprendre comment les ordinateurs communiquent.

Note pédagogique ENS

Transposition didactique : - SNT Seconde : utiliser des activités débranchées pour piles (assiettes, livres) et files (file d'attente physique) - NSI Première : implémenter une pile en Python avec une liste ; visualiser la pile d'appels récursifs - Lien interdisciplinaire : en mathématiques, la pile sert à évaluer les expressions arithmétiques (notation polonaise inverse)

Conseil pour l'enseignant formateur : Faire tracer l'évolution de la pile et de la file au tableau étape par étape. Chaque élève manipule des post-its représentant les nœuds.

Prolongement : Les étudiants peuvent approfondir en découvrant les structures de données avancées : arbres binaires de recherche, graphes, tables de hachage. Proposer une activité complémentaire en NSI : implémenter un correcteur orthographique simple avec une table de hachage pour vérifier les mots d'un texte français.
