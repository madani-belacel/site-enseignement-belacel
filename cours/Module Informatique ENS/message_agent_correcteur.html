Pipeline obligatoire

Les dossiers AN sont des traductions des dossiers FR. Tu dois : 1. Enrichir les sources FR d'abord 2. Retraduire FR → AN une fois l'enrichissement terminé 3. Corriger le script de génération PDF pour les deux départements

Anomalies critiques (par priorité)

P1 — C1 : Pages PDF insuffisantes

Constat : Tous les PDF sauf Cours FR 1ère et TP font 2-3 pages. Beaucoup trop compact (100-220 lignes/page). Illisible pour 1h30 de cours/TD.

Objectif : Chaque PDF (Cours, TD, TP) doit faire 5+ pages avec contenu plein, aéré et lisible (police 11pt+, marges normales).

Actions :

Dossier Ce qui doit être enrichi
FR 1ère 10 TD (206-445 lignes → cible 300-500 lignes)
FR 2ème 10 Cours (192-348 lignes) + 10 TD (163-447 lignes)
AN 1ère Traduction de FR 1ère après enrichissement
AN 2ème Traduction de FR 2ème après enrichissement

Pistes d'enrichissement (sans gonflage artificiel) : - Cours : exemples concrets pour enseignants, études de cas, mini-exercices intégrés, schémas Mermaid supplémentaires, encadrés historiques, activités débranchées, sections de révision - TD : détailler chaque énoncé (contexte, objectif, durée), sous-questions, variantes, différenciation, corrigés pas-à-pas commentés, Mermaid - TP : captures d'écran, scénarios pédagogiques, code commenté, exercices de mise en situation

Priorité absolue : - FR 2ème Cours 01 : 192 lignes → cible 300+ (ajouter section révision ENS1, exercices mise en train) - FR 1ère TD 01 : premier TD, doit être le plus riche possible

Script PDF : La génération produit 6-7 pages pour FR 1ère Cours mais 2-3 pages pour AN avec le même contenu — le convertisseur est cassé pour le dossier AN. Vérifier police, marges, densité. Unifier pour les 4 dossiers.

P2 — C2 : Référentiel officiel algérien absent

Constat : Les seules références citées sont françaises (SNT/NSI, CRCN/PIX, Ministère français). Aucune référence au cadre algérien alors que le module est pour l'ENS algérienne.

Documents à citer (dans Programme.md et au moins 2-3 Cours) : - Arrêté ministériel portant création des ENS (cycle Licence/Master) - Programme national d'Informatique des ENS algériennes - Arrêté 712 fixant le programme des concours ENS - Référentiel des compétences numériques algérien (si existant) - Benchmark 10 universités algériennes → si le document source est introuvable, le supprimer ou le produire

Ne pas supprimer les références SNT/NSI — elles sont pertinentes pour la transposition pédagogique — mais ajouter le cadre algérien en complément.

P3 — C3 : Dépendance template externe

Constat : Les templates (Templatte/PG-fr.docx, Templatte/PG-en.docx, Templatte/Presentation_BELACEL_V3.pptx, etc.) sont référencés dans les en-têtes .md mais situés dans /home/madani/Bureau/Habilitation_Universitaire/Templatte/, pas dans les dossiers de module. Cela concerne FR 2ème, AN 1ère, AN 2ème (FR 1ère a ses templates en local).

Action : Soit copier les templates dans un dossier Templatte/ local à chaque module, soit modifier les chemins dans les en-têtes pour utiliser le chemin absolu.

Ce que tu NE dois PAS faire

  • ❌ Ne pas modifier les archives ZIP (créées séparément pour vérification externe)
  • ❌ Ne pas enrichir directement les fichiers AN — enrichis les FR puis retraduis
  • ❌ Ne pas supprimer les références SNT/NSI françaises — ajouter le cadre algérien en complément
  • ❌ Ne pas générer les PDF toi-même — ils seront regénérés automatiquement après tes corrections des .md et du script
  • ❌ Ne pas modifier les fichiers dans suivi/ (ce sont les rapports d'audit)

Ordre recommandé

  1. Enrichir tous les fichiers .md FR (Cours + TD) — cible 300-500 lignes par fichier
  2. Ajouter les références algériennes (C2) dans Programme.md et 2-3 Cours FR

  4. Créer Programme.md manquants (M1)
  5. Corriger les permissions (M2)
  6. Uniformiser les libellés (M3-M4)
  7. Retraduire FR enrichi → AN
  8. Corriger le script de génération PDF pour produire 5+ pages partout
