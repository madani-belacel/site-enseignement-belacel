1. Présentation du module

Le module Informatique ENS prépare les futurs enseignants à maîtriser les concepts fondamentaux de l'informatique, de la programmation et du numérique éducatif. Il vise à former des enseignants capables d'intégrer les outils numériques dans leur pratique pédagogique et d'enseigner l'informatique aux niveaux collège et lycée.

Public visé : Étudiants ENS 1ère année (débutants en programmation) et ENS 2ème année (approfondissement).

2. Objectifs pédagogiques généraux

ENS 1ère année

  • Comprendre l'architecture machine et les systèmes d'exploitation
  • Concevoir des algorithmes et structures de données élémentaires
  • Maîtriser les principes réseau et la sécurité informatique de base
  • S'initier à Python pour l'enseignement

ENS 2ème année

  • Appliquer la programmation orientée objet (classes, héritage, encapsulation) en Python
  • Concevoir des algorithmes avancés (tri, recherche, récursivité)
  • Modéliser des données avec le modèle relationnel et SQL
  • Comprendre l'architecture Web (HTML/CSS/JS)
  • Utiliser Git pour la collaboration
  • Préparer l'enseignement de l'informatique (Scratch, Python pédagogique)

4. Programme détaillé — ENS 1ère année

Séance Thème Contenu Supports
01 Introduction à l'informatique pour l'enseignement Architecture du module, objectifs, évaluation Cours, TD
02 Représentation de l'information Binaire, hexa, ASCII/UTF-8, codage images Cours, TD
03 Architecture machine et cycle d'exécution Von Neumann, CPU, hiérarchie mémoire, OS Cours, TD
04 Systèmes d'exploitation et processus Noyau, processus, fichiers, ligne de commande Cours, TD
05 Algorithmique fondamentale Variables, conditions, boucles, pseudo-code, complexité Cours, TD
06 Structures de données Tableaux, piles (LIFO), files (FIFO), listes chaînées Cours, TD
07 Introduction aux réseaux et Internet IP, DNS, HTTP/HTTPS, client-serveur, cloud Cours, TD
08 Sécurité informatique et éthique numérique CID, mots de passe, phishing, RGPD, éthique enseignant Cours, TD
09 Initiation Python Variables, types, conditions, boucles, fonctions, fichiers Cours, TD
10 Projet ENS1 Quiz pédagogique, calculateur de moyenne, soutenance Cours, TD

5. Programme détaillé — ENS 2ème année

Séance Thème Contenu Supports
01 Introduction ENS2 — Rappel et enjeux Bilan ENS1, montée en compétence, présentation projet Cours, TD
02 POO Python 1 — Classes et objets Classe, attribut, méthode, constructeur __init__ Cours, TD
03 POO Python 2 — Héritage et polymorphisme super(), surcharge, encapsulation, héritage multiple Cours, TD
04 Algorithmes avancés Récursivité, tri bulle, tri fusion, recherche dichotomique Cours, TD
05 Bases de données et SQL Modèle relationnel, SQLite, SELECT/JOIN, Python+DB Cours, TD
06 Développement Web HTML, CSS, JavaScript, formulaires, client-serveur Cours, TD
07 Git et collaboration init, add, commit, branch, merge, GitHub, README Cours, TD
08 Didactique de l'informatique Programmes officiels, Scratch, Python pédagogique, PIX Cours, TD
09 Conception du projet ENS2 Architecture Flask, modèle POO, base de données, planification Cours, TD
10 Projet ENS2 final et soutenance Application Web de gestion de notes, démo, fiche pédagogique Cours, TD
