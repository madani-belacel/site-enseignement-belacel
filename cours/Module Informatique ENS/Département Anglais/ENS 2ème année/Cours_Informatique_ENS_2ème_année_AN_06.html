Computer Science Course — ENS Year 2 — Session 06 (EN)

Instructor : BELACEL Madani
Module: Computer Science
Level : ENS — Year 2 — English Department

Academic year : 2025-2026

Course Sheet — E-learning Platform (Moodle)

Reference framework : benchmark of 10 Algerian universities + practices USTO/Biskra/M'sila.

Target audience : ENS Year 2 Students — English Department

Prerequisite skills : Networks (ENS1 session 07), Python files (ENS1 session 09)

Cross-curricular objectives : - Apply object-oriented programming (classes, inheritance, encapsulation) in Python - Design advanced algorithms (sorting, searching, recursion) and estimate their complexity - Model data with the relational model and basic SQL queries - Understand Web architecture (HTML, CSS, JavaScript intro, HTTP) - Use Git and collaborative work methods (branches, merge) - Prepare the teaching of computer science in middle/high school (Scratch, pedagogical Python)

Assessment method : OOP Lab + SQL 35 % — Integrated Project 40 % — Pedagogical Session Sheet 25 %

Bibliography : MDN Web Docs (developer.mozilla.org) ; Duckett — HTML & CSS

Specific Learning Objectives

At the end of this session, the student is able to : - Create a structured HTML page (head, body, sections) - Apply CSS styles (colors, fonts, layout) - Add a simple JavaScript script (user interaction) - Explain the HTTP request/response cycle - Understand the role of Web forms

1. Web Architecture (10 min)

Client-server : the browser (client) sends an HTTP request to the server, which responds with the content.

4. JavaScript (15 min)

JavaScript enables client-side interactivity.

<!DOCTYPE html>
<html>
<body>
    <h2>Average Calculator</h2>
    <input type="number" id="grade1" placeholder="Grade 1">
    <input type="number" id="grade2" placeholder="Grade 2">
    <input type="number" id="grade3" placeholder="Grade 3">
    <button onclick="calculate()">Calculate</button>
    <p id="result"></p>

    <script>
        function calculate() {
            let n1 = parseFloat(document.getElementById("grade1").value);
            let n2 = parseFloat(document.getElementById("grade2").value);
            let n3 = parseFloat(document.getElementById("grade3").value);
            let average = (n1 + n2 + n3) / 3;
            document.getElementById("result").innerHTML =
                "Average: " + average.toFixed(2);
        }
    </script>
</body>
</html>

Pedagogical Note ENS

Teaching transposition : The Web can be taught in middle school through the creation of simple HTML pages. In SNT Seconde (theme "Web"), students learn to distinguish client and server, understand the role of the browser, and inspect the source code of a page. The "teacher personal page" mini-project activity can be adapted for 9th-grade students by having them create an HTML page about a career that interests them. The client-server sequence can be simulated through a role-play: one student is the server, another is the client.

Trainer advice : Students often struggle with the HTML/CSS separation. Emphasize the single responsibility principle: HTML for content, CSS for presentation. An effective exercise consists of providing the same HTML and asking students to apply different CSS to produce completely different visual renderings. This illustrates the power and flexibility of CSS.

Extension : Students can create a complete mini-teacher website with multiple pages (home, courses, contact), a responsive navigation menu (media queries), and a functional contact form using a service like Formspree or a simple Flask backend. They can also add a "project portfolio" page with screenshots and GitHub links.
