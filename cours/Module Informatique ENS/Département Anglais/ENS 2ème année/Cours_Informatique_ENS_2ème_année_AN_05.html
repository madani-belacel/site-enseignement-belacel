Computer Science Course — ENS Year 2 — Session 05 (EN)

Instructor : BELACEL Madani
Module : Computer Science
Level : ENS — Year 2 — English Department
Duration : 1h30
Academic Year : 2025-2026

Course sheet — E-learning platform (Moodle)

Reference : benchmark 10 Algerian universities + Univ-Mosta/Biskra/M'sila practices.

Target audience : ENS 2nd year students — English Department

Prerequisite skills : Algorithms (session 04), Python OOP (sessions 02-03)

Cross-cutting objectives : - Apply object-oriented programming (classes, inheritance, encapsulation) in Python - Design advanced algorithms (sorting, searching, recursion) and estimate their complexity - Model data with the relational model and basic SQL queries - Understand Web architecture (HTML, CSS, JavaScript intro, HTTP) - Use Git and collaborative work methods (branches, merge) - Prepare for teaching computer science in middle/high school (Scratch, pedagogical Python)

Assessment method : OOP + SQL Practical 35 % — Integrated project 40 % — Pedagogical lesson plan 25 %

Bibliography : Connolly & Begg — Database Systems ; Beaulieu — Learning SQL (O'Reilly)

Specific Learning Objectives

After this session, the student is able to : - Explain the relational model (tables, rows, columns) - Create a table with SQLite - Write SELECT, WHERE, JOIN queries - Insert and update data - Understand the notion of primary and foreign key

1. Why a database ? (10 min)

Limitations of a CSV file : - No strict structure - No validation (grades > 20 possible) - Difficult to make links between tables - No concurrency (two people cannot write at the same time)

Relational database : - Rigid structure (schema) - Constraints (keys, types, values) - Powerful queries (SQL language) - Data integrity

3. SQLite and Python (10 min)

SQLite is a lightweight database, built into Python (no server installation).

import sqlite3

# Connection (creates the .db file)
conn = sqlite3.connect("ecole.db")
curseur = conn.cursor()

# Execute a query
curseur.execute("""
    CREATE TABLE IF NOT EXISTS eleves (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT NOT NULL,
        prenom TEXT NOT NULL,
        groupe TEXT
    )
""")

conn.commit()  # Validate
conn.close()   # Close

4. CREATE TABLE (10 min)

conn = sqlite3.connect("ecole.db")
c = conn.cursor()

c.execute("""
    CREATE TABLE IF NOT EXISTS matieres (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT NOT NULL,
        coefficient REAL DEFAULT 1.0
    )
""")

c.execute("""
    CREATE TABLE IF NOT EXISTS notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        eleve_id INTEGER NOT NULL,
        matiere_id INTEGER NOT NULL,
        valeur REAL NOT NULL CHECK(valeur >= 0 AND valeur <= 20),
        FOREIGN KEY (eleve_id) REFERENCES eleves(id),
        FOREIGN KEY (matiere_id) REFERENCES matieres(id)
    )
""")

conn.commit()

INSERT

7. Foreign keys and JOIN (15 min)

# Insert a grade
c.execute("""
    INSERT INTO notes (eleve_id, matiere_id, valeur)
    VALUES (?, ?, ?)
""", (1, 1, 15))

# Join : grades + student names + subject names
c.execute("""
    SELECT e.nom, e.prenom, m.nom, n.valeur
    FROM notes n
    JOIN eleves e ON n.eleve_id = e.id
    JOIN matieres m ON n.matiere_id = m.id
""")

for ligne in c.fetchall():
    print(f"{ligne[0]} {ligne[1]} — {ligne[2]} : {ligne[3]}")

8. Complete example : grade report (15 min)

import sqlite3

conn = sqlite3.connect("ecole.db")
c = conn.cursor()

# Create tables
c.execute("""
    CREATE TABLE IF NOT EXISTS eleves (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, prenom TEXT, groupe TEXT
    )
""")
c.execute("""
    CREATE TABLE IF NOT EXISTS matieres (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, coefficient REAL
    )
""")
c.execute("""
    CREATE TABLE IF NOT EXISTS notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        eleve_id INTEGER, matiere_id INTEGER, valeur REAL,
        FOREIGN KEY(eleve_id) REFERENCES eleves(id),
        FOREIGN KEY(matiere_id) REFERENCES matieres(id)
    )
""")

# Insert data
c.execute("INSERT INTO eleves VALUES (1, 'Ali', 'Belacel', 'ENS2-A')")
c.execute("INSERT INTO matieres VALUES (1, 'Computer Science', 3.0)")
c.execute("INSERT INTO matieres VALUES (2, 'French', 2.0)")
c.execute("INSERT INTO notes VALUES (NULL, 1, 1, 15)")
c.execute("INSERT INTO notes VALUES (NULL, 1, 2, 12)")

# Grade report with average
c.execute("""
    SELECT e.nom, e.prenom, m.nom, n.valeur, m.coefficient
    FROM notes n
    JOIN eleves e ON n.eleve_id = e.id
    JOIN matieres m ON n.matiere_id = m.id
    WHERE e.id = 1
""")

print("=== Grade Report ===")
total_pondere = 0
total_coef = 0
for ligne in c.fetchall():
    print(f"{ligne[0]} {ligne[1]} — {ligne[2]} : {ligne[3]} (coef {ligne[4]})")
    total_pondere += ligne[3] * ligne[4]
    total_coef += ligne[4]

moyenne = total_pondere / total_coef if total_coef > 0 else 0
print(f"Overall average : {moyenne:.2f}")

conn.commit()
conn.close()

Conclusion

Relational databases and SQL are at the heart of structured data management. SQLite, built into Python, allows quickly prototyping a complete solution (creation, insertion, querying, joining) without server installation. The concepts of primary key, foreign key and join are universal and found in all DBMS (MySQL, PostgreSQL, Oracle).

Pedagogical Note ENS

Teaching transposition : Databases can be taught in middle and high school without a computer, through unplugged activities : - Paper file : each student receives a card (table) with fields to fill (name, first name, date of birth). We simulate a SELECT query by sorting the cards. - Card game : "student" cards and "grade" cards are linked by a paperclip (foreign key). Students must match the cards (JOIN). - In 10th grade SNT (theme "Structured Data") : make students think about the difference between an unstructured text file and a structured table (spreadsheet). The parallel with a spreadsheet (Excel, LibreOffice Calc) is immediate. - In 11th grade NSI : SQL is an integral part of the curriculum. The grade report example (section 8) can be directly reused in class.

Trainer advice : Ask ENS students to prepare a 45-minute pedagogical lesson plan on databases for an 8th or 10th grade class, incorporating an unplugged activity and a digital activity. This promotes teaching transposition, a key skill of the teaching profession.

Extension : Students can create a mini library management application (books, authors, loans) with SQLite and Python, and think about useful queries for a teacher (grade management, absences, groups).
