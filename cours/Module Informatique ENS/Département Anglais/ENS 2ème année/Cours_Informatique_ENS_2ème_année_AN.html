1. Why OOP ? (10 min)

Procedural programming (ENS1) : functions + separate data. Object-oriented programming : groups data and behaviour into objects.

Advantages : - Natural organisation (we think in terms of real-world objects) - Reusable (a class = a mould for objects) - Maintainable (modifying a class does not affect the rest) - Extensible (inheritance)

Concrete example : in school life, we handle Students, Teachers, Grades, Classes — these are objects.

3. Attributes and methods (15 min)

Attribute : variable attached to an object (its state). Method : function attached to an object (its behaviour).

class Eleve:
    def __init__(self, nom, age):
        self.nom = nom      # Instance attribute
        self.age = age

    def se_presenter(self): # Method
        print(f"Je m'appelle {self.nom} et j'ai {self.age} ans.")

# Usage
e = Eleve("Ali", 20)
print(e.nom)        # Access attribute
e.se_presenter()    # Call method

Note : self represents the current instance — it is the first parameter of every method.

6. Complete example : Eleve class (20 min)

class Eleve:
    ecole = "ENS Mostaganem"
    total_eleves = 0  # Shared counter

    def __init__(self, nom, prenom, groupe):
        self.nom = nom
        self.prenom = prenom
        self.groupe = groupe
        self.notes = []
        Eleve.total_eleves += 1

    def ajouter_note(self, note):
        if 0 <= note <= 20:
            self.notes.append(note)
        else:
            print("Invalid grade")

    def moyenne(self):
        if self.notes:
            return sum(self.notes) / len(self.notes)
        return 0.0

    def afficher(self):
        print(f"{self.prenom} {self.nom} — {self.groupe}")
        print(f"  Grades : {self.notes}")
        print(f"  Average : {self.moyenne():.2f}")

# Test
e = Eleve("Belacel", "Ali", "ENS1-A")
e.ajouter_note(15)
e.ajouter_note(12)
e.ajouter_note(18)
e.afficher()
print(f"Total students : {Eleve.total_eleves}")

1. Inheritance (15 min)

Principle : a class can inherit attributes and methods from another class.

Vocabulary : - Parent class (super-class) : base class - Child class (sub-class) : inherits and can add/modify

class Personne:
    def __init__(self, nom, prenom):
        self.nom = nom
        self.prenom = prenom

    def se_presenter(self):
        return f"{self.prenom} {self.nom}"

class Eleve(Personne):   # Eleve inherits from Personne
    def __init__(self, nom, prenom, groupe):
        super().__init__(nom, prenom)  # Call parent constructor
        self.groupe = groupe

2. Override (10 min)

A child class can redefine a method from the parent class.

class Personne:
    def description(self):
        return "A person"

class Enseignant(Personne):
    def __init__(self, nom, matiere):
        self.nom = nom
        self.matiere = matiere

    def description(self):  # Override
        return f"Teacher of {self.matiere}"

p = Personne()
e = Enseignant("Mr. Belacel", "Computer Science")
print(p.description())  # "A person"

3. The super() function (10 min)

super() allows calling a method from the parent class.

class Enseignant(Personne):
    def __init__(self, nom, prenom, matiere):
        super().__init__(nom, prenom)  # Calls Personne.__init__
        self.matiere = matiere

        # Extends the parent method

5. Encapsulation (15 min)

Encapsulation : protecting access to attributes to guarantee integrity.

class CompteBancaire:
    def __init__(self, titulaire, solde=0):
        self.titulaire = titulaire
        self._solde = 0     # Protected (convention : _)
        if solde >= 0:
            self._solde = solde

    def deposer(self, montant):
        if montant > 0:
            self._solde += montant

    def retirer(self, montant):
        if 0 < montant <= self._solde:
            self._solde -= montant
            return montant
        return 0

    @property           # Getter
    def solde(self):
        return self._solde

    @solde.setter       # Setter
    def solde(self, valeur):
        if valeur >= 0:
            self._solde = valeur

# Usage
cb = CompteBancaire("Ali", 1000)
cb.deposer(500)
print(cb.solde)        # 1500 (via getter)
# cb._solde = 999999    # Technically possible but discouraged

Python convention : _attribut = protected, __attribut = private (name mangling).

7. Complete example : school system (15 min)

class Personne:
    def __init__(self, nom, prenom, email):
        self.nom = nom
        self.prenom = prenom
        self.email = email

    def __str__(self):
        return f"{self.prenom} {self.nom}"

class Eleve(Personne):
    def __init__(self, nom, prenom, email, groupe):
        super().__init__(nom, prenom, email)
        self.groupe = groupe
        self.notes = []

    def ajouter_note(self, note, matiere):
        self.notes.append({"matiere": matiere, "note": note})

    def moyenne_generale(self):
        if not self.notes:
            return 0.0
        return sum(n["note"] for n in self.notes) / len(self.notes)

class Enseignant(Personne):
    def __init__(self, nom, prenom, email, matiere):
        super().__init__(nom, prenom, email)
        self.matiere = matiere

    def __str__(self):
        return f"{self.prenom} {self.nom} — {self.matiere}"

3. Binary search (15 min)

Principle : in a sorted array, compare with the middle element, then search left or right.

def recherche_dichotomique(tableau, cible):
    debut = 0
    fin = len(tableau) - 1

    while debut <= fin:
        milieu = (debut + fin) // 2
        if tableau[milieu] == cible:
            return milieu          # Found
        elif tableau[milieu] < cible:
            debut = milieu + 1     # Search right
        else:
            fin = milieu - 1       # Search left

    return -1  # Not found

# Test
notes = [5, 8, 10, 12, 15, 18, 20]
print(recherche_dichotomique(notes, 15))  # 4
print(recherche_dichotomique(notes, 7))   # -1

Complexity : O(log n) — much faster than linear search O(n).

4. Bubble sort (15 min)

Principle : traverse the array, compare adjacent elements, swap them if they are in the wrong order. Repeat until the array is sorted.

def tri_bulle(tableau):
    n = len(tableau)
    for i in range(n):
        trie = True
        for j in range(n - i - 1):
            if tableau[j] > tableau[j + 1]:
                tableau[j], tableau[j + 1] = tableau[j + 1], tableau[j]
                trie = False
        if trie:  # Optimisation : already sorted
            break
    return tableau

# Test
notes = [15, 8, 12, 20, 5]
print(tri_bulle(notes))  # [5, 8, 12, 15, 20]

Complexity : O(n²) in the worst case, O(n) if already sorted.

5. Merge sort (15 min)

Principle : divide the array into two, sort each half recursively, then merge.

def tri_fusion(tableau):
    if len(tableau) <= 1:
        return tableau

    milieu = len(tableau) // 2
    gauche = tri_fusion(tableau[:milieu])
    droite = tri_fusion(tableau[milieu:])

    return fusionner(gauche, droite)

def fusionner(gauche, droite):
    resultat = []
    i = j = 0
    while i < len(gauche) and j < len(droite):
        if gauche[i] <= droite[j]:
            resultat.append(gauche[i])
            i += 1
        else:
            resultat.append(droite[j])
            j += 1
    resultat.extend(gauche[i:])
    resultat.extend(droite[j:])
    return resultat

# Test
notes = [15, 8, 12, 20, 5]
print(tri_fusion(notes))  # [5, 8, 12, 15, 20]

Complexity : O(n log n) in all cases — more efficient than bubble sort.

import sqlite3

conn = sqlite3.connect("ecole.db")
c = conn.cursor()

# Create tables
c.execute("""
    CREATE TABLE IF NOT EXISTS eleves (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, prenom TEXT, groupe TEXT
    )
""")
c.execute("""
    CREATE TABLE IF NOT EXISTS matieres (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nom TEXT, coefficient REAL
    )
""")
c.execute("""
    CREATE TABLE IF NOT EXISTS notes (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        eleve_id INTEGER, matiere_id INTEGER, valeur REAL,
        FOREIGN KEY(eleve_id) REFERENCES eleves(id),
        FOREIGN KEY(matiere_id) REFERENCES matieres(id)
    )
""")

# Insert data
c.execute("INSERT INTO eleves VALUES (1, 'Ali', 'Belacel', 'ENS2-A')")
c.execute("INSERT INTO matieres VALUES (1, 'Computer Science', 3.0)")
c.execute("INSERT INTO matieres VALUES (2, 'French', 2.0)")
c.execute("INSERT INTO notes VALUES (NULL, 1, 1, 15)")
c.execute("INSERT INTO notes VALUES (NULL, 1, 2, 12)")

# Grade report with average
c.execute("""
    SELECT e.nom, e.prenom, m.nom, n.valeur, m.coefficient
    FROM notes n
    JOIN eleves e ON n.eleve_id = e.id
    JOIN matieres m ON n.matiere_id = m.id
    WHERE e.id = 1
""")

print("=== Grade Report ===")
total_pondere = 0
total_coef = 0
for ligne in c.fetchall():
    print(f"{ligne[0]} {ligne[1]} — {ligne[2]} : {ligne[3]} (coef {ligne[4]})")
    total_pondere += ligne[3] * ligne[4]
    total_coef += ligne[4]

moyenne = total_pondere / total_coef if total_coef > 0 else 0
print(f"Overall average : {moyenne:.2f}")

conn.commit()
conn.close()

class Eleve:
    def __init__(self, id, nom, prenom, groupe):
        self.id = id
        self.nom = nom
        self.prenom = prenom
        self.groupe = groupe
        self.notes = []

    def moyenne(self):
        if not self.notes:
            return 0.0
        return sum(n.valeur for n in self.notes) / len(self.notes)

    def ajouter_note(self, matiere, valeur):
        if 0 <= valeur <= 20:
            self.notes.append(Note(self.id, matiere, valeur))

# database.py
import sqlite3

DB = "donnees/ecole.db"

def init_db():
    conn = sqlite3.connect(DB)
    c = conn.cursor()
    c.execute("""
        CREATE TABLE IF NOT EXISTS eleves (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nom TEXT NOT NULL,
            prenom TEXT NOT NULL,
            groupe TEXT
        )
    """)
    c.execute("""
        CREATE TABLE IF NOT EXISTS notes (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            eleve_id INTEGER NOT NULL,
            matiere TEXT NOT NULL,
            valeur REAL NOT NULL CHECK(valeur >= 0 AND valeur <= 20),
            FOREIGN KEY(eleve_id) REFERENCES eleves(id)
        )
    """)
    conn.commit()
    conn.close()

def get_eleves():
    conn = sqlite3.connect(DB)
    conn.row_factory = sqlite3.Row
    c = conn.cursor()
    c.execute("SELECT * FROM eleves")
    eleves = [dict(row) for row in c.fetchall()]
    conn.close()
    return eleves

Pedagogical Note ENS

Teaching transposition : This defense session is itself a model for teachers: it shows how to structure a project evaluation (transparent criteria, live demo, technical questions, pedagogical sheet). This format can be adapted for middle school students (5-minute Scratch project defense) or high school students (15-20 minute NSI defense). Criteria-based grid assessment is a recommended practice in the official curriculum.

Trainer advice : The defense is a key moment: it evaluates not only the code but also the ability to communicate and argue. Encourage students to prepare a script and rehearse. Provide a projector for the demo and test it beforehand. The technical questions (section 4) should be adapted to each student's level. A weaker student can be asked basic questions (difference class/instance) while an advanced student can be questioned about architectural choices.

Extension : The ENS2 project becomes the centerpiece of the teaching portfolio. Students are encouraged to : - Present the project during interviews for teaching positions - Improve it during the practical internship with student feedback - Publish it on GitHub Pages as a demonstration of their skills - Extend it with features inspired by their internship experience
