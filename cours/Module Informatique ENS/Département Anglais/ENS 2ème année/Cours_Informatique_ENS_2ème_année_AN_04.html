1. Recursion (15 min)

Recursive function : a function that calls itself.

Two essential elements : - Base case : stopping condition (does not use recursion) - Recursive call : the function calls itself with a modified parameter

        C --> D[3 * factorial 2]

        F --> G[Return 1]

    end

Example : factorial

def factorielle(n):
    if n <= 1:        # Base case
        return 1
    return n * factorielle(n - 1)  # Recursive call

print(factorielle(5))  # 120 = 5×4×3×2×1

Example : Fibonacci

def fibonacci(n):
    if n <= 1:        # Base case
        return n
    return fibonacci(n-1) + fibonacci(n-2)  # Double call

print(fibonacci(10))  # 55

2. Recursion vs iteration (10 min)

# Iterative (loop)
def factorielle_iter(n):
    resultat = 1
    for i in range(2, n + 1):
        resultat *= i
    return resultat

# Recursive
def factorielle_rec(n):
    if n <= 1:
        return 1
    return n * factorielle_rec(n - 1)
Criterion Iterative Recursive
Readability Simple Very readable (mathematical)
Performance Faster Slower (stacked calls)
Memory Constant O(n) call stack
Usage Simple loops Divisible problems

3. Binary search (15 min)

Principle : in a sorted array, compare with the middle element, then search left or right.

def recherche_dichotomique(tableau, cible):
    debut = 0
    fin = len(tableau) - 1

    while debut <= fin:
        milieu = (debut + fin) // 2
        if tableau[milieu] == cible:
            return milieu          # Found
        elif tableau[milieu] < cible:
            debut = milieu + 1     # Search right
        else:
            fin = milieu - 1       # Search left

    return -1  # Not found

# Test
notes = [5, 8, 10, 12, 15, 18, 20]
print(recherche_dichotomique(notes, 15))  # 4
print(recherche_dichotomique(notes, 7))   # -1

Complexity : O(log n) — much faster than linear search O(n).

4. Bubble sort (15 min)

Principle : traverse the array, compare adjacent elements, swap them if they are in the wrong order. Repeat until the array is sorted.

def tri_bulle(tableau):
    n = len(tableau)
    for i in range(n):
        trie = True
        for j in range(n - i - 1):
            if tableau[j] > tableau[j + 1]:
                tableau[j], tableau[j + 1] = tableau[j + 1], tableau[j]
                trie = False
        if trie:  # Optimisation : already sorted
            break
    return tableau

# Test
notes = [15, 8, 12, 20, 5]
print(tri_bulle(notes))  # [5, 8, 12, 15, 20]

Complexity : O(n²) in the worst case, O(n) if already sorted.

5. Merge sort (15 min)

Principle : divide the array into two, sort each half recursively, then merge.

def tri_fusion(tableau):
    if len(tableau) <= 1:
        return tableau

    milieu = len(tableau) // 2
    gauche = tri_fusion(tableau[:milieu])
    droite = tri_fusion(tableau[milieu:])

    return fusionner(gauche, droite)

def fusionner(gauche, droite):
    resultat = []
    i = j = 0
    while i < len(gauche) and j < len(droite):
        if gauche[i] <= droite[j]:
            resultat.append(gauche[i])
            i += 1
        else:
            resultat.append(droite[j])
            j += 1
    resultat.extend(gauche[i:])
    resultat.extend(droite[j:])
    return resultat

# Test
notes = [15, 8, 12, 20, 5]
print(tri_fusion(notes))  # [5, 8, 12, 15, 20]

Complexity : O(n log n) in all cases — more efficient than bubble sort.

6. Comparison of sorting algorithms (10 min)

Algorithm Worst case Best case Memory Stable
Bubble sort O(n²) O(n) O(1) Yes
Merge sort O(n log n) O(n log n) O(n) Yes
Quick sort O(n²) O(n log n) O(log n) No
Insertion sort O(n²) O(n) O(1) Yes

For a teacher : - Array of 10 grades : bubble sort suffices (simple to understand) - Class of 30 students : merge sort (faster) - Database of 10,000 records : merge sort or quick sort

7. Conclusion (5 min)

Recursion allows writing elegant algorithms for divisible problems. Sorting and searching algorithms are fundamental, and their complexity determines their efficiency.

Pedagogical Note ENS

Teaching transposition : Recursion can be introduced in middle school with the example of Russian dolls (matryoshka) or mirrors reflecting each other. In 11th grade NSI, factorial and Fibonacci are classics of the curriculum. Merge sort perfectly illustrates the "divide and conquer" strategy which can be transposed to other disciplines (essay writing, problem solving). Binary search can be presented as the "higher/lower" game that children play intuitively.

Trainer advice : Students often confuse recursion and loops. Insist on the conceptual difference : recursion divides the problem, iteration repeats an action. The recursive/iterative comparison table (section 2) is an excellent summary tool. To assess understanding, ask students to manually trace the execution of factorielle(4) on paper.

Extension : Students can implement quick sort and experimentally compare its performance with merge sort on lists of increasing size. They can also create a small program that generates a comparison graph of execution times with matplotlib.
