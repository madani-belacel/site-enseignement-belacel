2. Scratch (20 min)

Scratch (scratch.mit.edu) : visual block programming — ideal for middle school.

Concepts taught : - Movement, looks, sound blocks - Loops (repeat, forever) - Conditions (if, if… then) - Variables and lists - Events (when flag clicked, when key pressed)

Example exercise : walking cat 1. When flag clicked → move 10 steps 2. If space key pressed → say "Hello !" for 2 seconds 3. Bounce if edge reached

Recommended progression : 1. Simple blocks (movement) 2. Loops and conditions 3. Variables (score, timer) 4. Final project (pong game, quiz)

3. Pedagogical Python (15 min)

When to move from Scratch to Python ? - Scratch : 6e-4e (discovery, logic) - Python : 3e-2de (first textual programming)

Approach :

# Python version of a Scratch exercise
# Say "Hello" when you click on the flag

import turtle

t = turtle.Turtle()

# Move forward 50 steps
t.forward(50)

# Turn right
t.right(90)
t.forward(50)

turtle.done()

Pedagogical libraries : - turtle : drawing, movement (Scratch transition) - random : games, simulations - tkinter : simple graphical interfaces

6. AI in the classroom (10 min)

Opportunities : - Grading assistant (save time) - Personalized exercise generation - Translation and adaptation - Help with writing lesson sheets

Limits and precautions : - Verify results (AI can be wrong) - Do not enter personal student data - Raise student awareness about plagiarism - Cite AI usage

Golden rule : AI is a tool, not a substitute for the teacher's judgment.

7. Digital usage charter (5 min)

Elements to include in a classroom charter :

  1. Use only your institutional account
  2. Do not share your passwords
  3. Respect classmates' privacy
  4. Report any inappropriate content
  5. Cite your sources (images, texts)
  6. Turn off your phone in class (unless for pedagogical use)
  7. Ask permission before recording/filming

8. Conclusion (5 min)

As a future teacher, you must master both computer science concepts and their didactics. Scratch for middle school, Python for high school, and a solid digital ethics for all.

Next course : ENS2 project design — Web application or Python OOP module.

Pedagogical Note ENS

Teaching transposition : This session is itself an example of teaching transposition: advanced computer science concepts (OOP, SQL, Web) are "transposed" into accessible activities for secondary education. The Scratch → Python progression (section 3) is at the heart of current programs. The proposed session sheet model can be used for any level. Student-teachers must understand that the difficulty is not mastering computer science, but teaching it to beginners — this is the whole challenge of didactics.

Trainer advice : Organize a micro-teaching session: each student prepares and leads a 10-minute sequence on a computer science concept (loop, condition, variable) in front of the group. Film the presentations for constructive feedback. Peer assessment (criteria-based grid) strengthens professionalization. Do not forget to raise awareness about classroom management: what to do when a student is stuck on an exercise? How to differentiate instruction ?

Extension : Students can design a complete sequence of 3 sessions on a computer science topic (creating a Scratch game, introduction to Python with Turtle, discovering the Web with HTML) including student worksheets, assessment grids, and written summaries. These productions will be reused during the practical internship.
