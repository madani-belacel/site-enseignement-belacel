Computer Science Module Syllabus — ENS Year 2 (EN)

Instructor: BELACEL Madani
Institution: École Normale Supérieure de Mostaganem
Department: English
Module: Computer Science
Level: Year 2
Workload: 15 sessions × 1h30 = 22h30
Academic Year: 2025-2026
Credits: To be defined per official framework

1. Module Overview

The Computer Science module for ENS Year 2 deepens the competencies acquired in Year 1. It covers object-oriented programming (OOP) in Python, advanced algorithms (recursion, sorting, searching), databases and SQL, fundamental Web development (HTML/CSS/JavaScript), Git for collaboration, and didactics of computer science for secondary education. Emphasis is placed on the integrated project that consolidates all competencies.

2. Targeted Competencies

By the end of the module, the student will be able to:

Competency Components
C1 — Program in Python OOP Classes, objects, inheritance, encapsulation, polymorphism
C2 — Design advanced algorithms Recursion, bubble sort, merge sort, binary search, complexity
C3 — Model and query databases Relational model, SQLite, SELECT, JOIN, INSERT, normalisation
C4 — Develop Web applications HTML5, CSS3, JavaScript, forms, client-server architecture
C5 — Use Git for collaboration init, add, commit, branch, merge, GitHub, README
C6 — Teach computer science in secondary school Didactics, Scratch, pedagogical Python, PIX, lesson plans
C7 — Design an integrated project Flask architecture, database, deployment, project defence

3. Detailed Module Plan

Session Content Competencies
01 Introduction ENS2 — ENS1 review, skill building, project presentation C1–C7
02 Python OOP 1 — Classes, objects, attributes, methods, __init__ constructor C1
03 Python OOP 2 — Inheritance, polymorphism, super(), encapsulation C1
04 Advanced algorithms — Recursion, bubble sort, merge sort, binary search C2
05 Databases — Relational model, SQLite, SELECT/JOIN, Python+DB C3
06 Web Development — HTML, CSS, JavaScript, forms, client-server C4
07 Git and collaboration — init, add, commit, branch, merge, GitHub, README C5
08 Didactics of computer science — Official curricula, Scratch, pedagogical Python, PIX C6
09 ENS2 Project design — Flask architecture, OOP model, database, planning C7
10 Final ENS2 Project and defence — Management Web app, demo, lesson plan C7

Tutorials (TD 01–10)

TD Theme

6. Algerian Official Framework References

This syllabus is developed within the framework of the following Algerian regulatory texts and national reference systems:

  • Ministerial decree establishing the ENS (Bachelor's/Master's cycle) — the founding text defining the training framework for the Écoles Normales Supérieures in Algeria.
  • National Computer Science Curriculum for Algerian ENS — the framework curriculum defining the objectives, content, and workload of the Computer Science module in teacher training.
  • Decree 712 setting the ENS competitive examination program — the regulatory text defining the tests and programs for ENS entrance examinations.
  • Algerian Digital Competency Framework — the national reference framework (under development) defining the digital competencies expected of teachers trained at ENS.
  • Benchmark of 10 Algerian universities — a comparative study of computer science teaching practices in Algerian universities, consulted for the development of this syllabus.
