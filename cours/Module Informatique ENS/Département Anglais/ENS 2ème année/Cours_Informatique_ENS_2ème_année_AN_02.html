1. Why OOP ? (10 min)

Procedural programming (ENS1) : functions + separate data. Object-oriented programming : groups data and behaviour into objects.

Advantages : - Natural organisation (we think in terms of real-world objects) - Reusable (a class = a mould for objects) - Maintainable (modifying a class does not affect the rest) - Extensible (inheritance)

Concrete example : in school life, we handle Students, Teachers, Grades, Classes — these are objects.

2. Class and object (15 min)

Class : model, construction plan. Object : concrete realisation of the model (instance).

# Class definition
class Eleve:
    pass

# Creating objects (instances)
eleve1 = Eleve()
eleve2 = Eleve()

print(type(eleve1))  # <class '__main__.Eleve'>

The class is the mould ; the object is the element produced by this mould.

3. Attributes and methods (15 min)

Attribute : variable attached to an object (its state). Method : function attached to an object (its behaviour).

class Eleve:
    def __init__(self, nom, age):
        self.nom = nom      # Instance attribute
        self.age = age

    def se_presenter(self): # Method
        print(f"Je m'appelle {self.nom} et j'ai {self.age} ans.")

# Usage
e = Eleve("Ali", 20)
print(e.nom)        # Access attribute
e.se_presenter()    # Call method

Note : self represents the current instance — it is the first parameter of every method.

4. __init__ constructor (15 min)

The __init__ method is automatically called when the object is created.

class Evaluation:
    def __init__(self, matiere, note, coefficient=1):
        self.matiere = matiere
        self.note = note
        self.coefficient = coefficient

    def ponderer(self):
        return self.note * self.coefficient

# Creation
eval1 = Evaluation("Maths", 15, 2)
eval2 = Evaluation("French", 12)
print(eval1.ponderer())  # 30
print(eval2.ponderer())  # 12 (default coefficient = 1)

5. Class variables (10 min)

Attributes shared by all instances.

class Eleve:
    ecole = "ENS Mostaganem"  # Class variable

    def __init__(self, nom):
        self.nom = nom         # Instance variable

e1 = Eleve("Ali")
e2 = Eleve("Sara")
print(e1.ecole)   # ENS Mostaganem
print(e2.ecole)   # ENS Mostaganem

Use : constants, counters, shared configuration.

6. Complete example : Eleve class (20 min)

class Eleve:
    ecole = "ENS Mostaganem"
    total_eleves = 0  # Shared counter

    def __init__(self, nom, prenom, groupe):
        self.nom = nom
        self.prenom = prenom
        self.groupe = groupe
        self.notes = []
        Eleve.total_eleves += 1

    def ajouter_note(self, note):
        if 0 <= note <= 20:
            self.notes.append(note)
        else:
            print("Invalid grade")

    def moyenne(self):
        if self.notes:
            return sum(self.notes) / len(self.notes)
        return 0.0

    def afficher(self):
        print(f"{self.prenom} {self.nom} — {self.groupe}")
        print(f"  Grades : {self.notes}")
        print(f"  Average : {self.moyenne():.2f}")

# Test
e = Eleve("Belacel", "Ali", "ENS1-A")
e.ajouter_note(15)
e.ajouter_note(12)
e.ajouter_note(18)
e.afficher()
print(f"Total students : {Eleve.total_eleves}")

7. Guided exercise : Matiere class (10 min)

Create a Matiere class with : - Attributes : nom, coefficient, nb_heures - __init__ method with parameters - afficher() method that displays the information - est_importante() method that returns True if coefficient > 2

class Matiere:
    def __init__(self, nom, coefficient, nb_heures):
        self.nom = nom
        self.coefficient = coefficient
        self.nb_heures = nb_heures

    def afficher(self):
        print(f"{self.nom} (coef {self.coefficient}, {self.nb_heures}h)")

    def est_importante(self):
        return self.coefficient > 2

Pedagogical Note ENS

Teaching transposition : The notion of an object can be introduced in middle school without a computer through an unplugged activity : each student receives a "living being" card with fields to fill (name, age, colour). The blank card is the class, the filled card is the object. In 11th grade NSI, one can show that the Eleve class from the course is similar to a student record form they fill each year. The parallel with a spreadsheet (row = object, column = attribute) facilitates understanding.

Trainer advice : When grading practical work, insist on the class/instance distinction : many students confuse Eleve (the class) and e (the instance). An effective exercise is to ask "What is the type of e ?" and "What is the type of Eleve ?". Also propose an exercise where students must add a date_naissance attribute and an age() method to consolidate understanding.

Extension : Students can create a SalleDeClasse class that contains a list of Eleve objects and methods to compute the class average, list students by group, or export data to CSV format. This mini-project prepares the integrated end-of-module project.
