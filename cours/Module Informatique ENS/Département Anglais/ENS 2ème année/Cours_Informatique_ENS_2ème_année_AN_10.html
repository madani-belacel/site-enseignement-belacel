Computer Science Course — ENS Year 2 — Session 10 (EN)

Instructor : BELACEL Madani
Module: Computer Science
Level : ENS — Year 2 — English Department
Duration : 1h30
Academic year : 2025-2026

Course Sheet — E-learning Platform (Moodle)

Reference framework : benchmark of 10 Algerian universities + practices USTO/Biskra/M'sila.

Target audience : ENS Year 2 Students — English Department

Prerequisite skills : ENS2 project developed (session 09), Git, OOP, SQL, Flask

Cross-curricular objectives : - Apply object-oriented programming (classes, inheritance, encapsulation) in Python - Design advanced algorithms (sorting, searching, recursion) and estimate their complexity - Model data with the relational model and basic SQL queries - Understand Web architecture (HTML, CSS, JavaScript intro, HTTP) - Use Git and collaborative work methods (branches, merge) - Prepare the teaching of computer science in middle/high school (Scratch, pedagogical Python)

Assessment method : OOP Lab + SQL 35 % — Integrated Project 40 % — Pedagogical Session Sheet 25 %

Bibliography : MDN Web Docs ; Flask Documentation ; Git Book

Specific Learning Objectives

At the end of this session, the student is able to : - Present a complete software project - Demonstrate the developed features - Explain technical and architectural choices - Show the Git repository with history - Present the associated pedagogical session sheet

3. Live demo — typical scenario (20 min)

Demonstration scenario :

  1. Home — Home page with presentation
  2. Add student — Enter "Belacel", "Ali", "ENS2-A"
  3. Add grades — Computer Science: 15, French: 12, English: 18
  4. Average calculation — Verify that the average displays correctly
  5. Grade report — Display the complete table
  6. CSV export — Download the file and open it in Excel
  7. GitHub — Show the repository, commits, README

Errors to anticipate : - Adding a grade > 20 → expected error message - Deleting a student → confirmation - Navigation → responsive (mobile/desktop)

4. Possible technical questions (15 min)

Prepare answers to these questions :

OOP : - Why did you choose inheritance in your model ? - What is the difference between a class attribute and an instance attribute ? - How did you implement encapsulation ?

Database : - Why SQLite rather than MySQL/PostgreSQL ? - What is the primary key ? Why AUTOINCREMENT ? - How did you handle the 0 ≤ grade ≤ 20 constraint ?

Web : - Explain the request/response cycle in Flask - How do you pass data from Python to HTML ? - What is a route in Flask ?

Git : - Show a commit where you fixed a bug - What is the difference between merge and rebase ? - How do you handle a merge conflict ?

Pedagogy : - How would you adapt this project for 9th grade students ? - What written summary do you propose for students ? - How do you assess PIX skills ?

5. Pedagogical session sheet (15 min — individual work)

Write a 45-minute session sheet for middle school, related to the project.

Proposed topic : Discovering programming with Scratch — Creating an interactive quiz

Use the model from session 08 :

# Session Sheet — Interactive quiz with Scratch

**Level :** 9th grade (Cycle 4)
**Theme :** Algorithms and programming
**Duration :** 45 minutes

## Objectives
- Use a variable (score)
- Implement a condition (if the answer is correct)
- Create a game loop

## Procedure
1. Discovery (5 min): show the completed quiz
2. Variables (10 min): create "score" variable
3. Questions (15 min): add 3 questions with conditions
4. Test (10 min): play and debug
5. Review (5 min): written summary

## Assessment
- Functional final quiz (3 questions minimum)
- Score variable that increments
- Feedback message (well done/try again)

Pedagogical Note ENS

Teaching transposition : This defense session is itself a model for teachers: it shows how to structure a project evaluation (transparent criteria, live demo, technical questions, pedagogical sheet). This format can be adapted for middle school students (5-minute Scratch project defense) or high school students (15-20 minute NSI defense). Criteria-based grid assessment is a recommended practice in the official curriculum.

Trainer advice : The defense is a key moment: it evaluates not only the code but also the ability to communicate and argue. Encourage students to prepare a script and rehearse. Provide a projector for the demo and test it beforehand. The technical questions (section 4) should be adapted to each student's level. A weaker student can be asked basic questions (difference class/instance) while an advanced student can be questioned about architectural choices.

Extension : The ENS2 project becomes the centerpiece of the teaching portfolio. Students are encouraged to : - Present the project during interviews for teaching positions - Improve it during the practical internship with student feedback - Publish it on GitHub Pages as a demonstration of their skills - Extend it with features inspired by their internship experience
