Computer Science Course — ENS Year 2 — Session 01 (EN)

Instructor : BELACEL Madani
Institution : École Normale Supérieure de Mostaganem
Module : Computer Science
Level : ENS — Year 2
Duration : 1h30
Academic Year : 2026-2027

Course sheet — E-learning platform (Moodle)

Reference : benchmark 10 Algerian universities + Univ-Mosta/Biskra/M'sila practices.

Target audience : ENS 1st and 2nd year students — French and English Departments

Prerequisite skills : Baccalaureate ; CS Bachelor Level 1 recommended

Cross-cutting objectives : - Understand machine architecture and operating systems - Design algorithms and elementary data structures - Master networking principles and basic computer security - Get started with Python for teaching

Assessment method : Tutorial 40 % + Python Practical 35 % + MCQ 25 %

Bibliography : Computer Architecture 1 — Univ. Biskra ; Computer Security S6 — Univ. M'sila ; Goupille — Computer Technology

1) Learning Objectives

After this module, the ENS 2nd year student is able to :

  • Apply object-oriented programming (classes, inheritance, encapsulation) in Python.
  • Design advanced algorithms (sorting, searching, recursion) and estimate their complexity.
  • Model data with the relational model and basic SQL queries.
  • Understand Web architecture (HTML, CSS, JavaScript intro, HTTP).
  • Use Git and collaborative work methods (branches, merge).
  • Prepare for teaching computer science in middle/high school (Scratch, pedagogical Python).
  • Articulate computer science, internship and digital teaching portfolio.

Algerian Regulatory Context

This course falls within the Algerian regulatory framework for teacher training:

  • Ministerial decree establishing ENS (Bachelor's/Master's cycle) — defines the institutional framework of the Écoles Normales Supérieures and their mission of teacher training.
  • National Computer Science curriculum for Algerian ENS — sets the objectives, content and hourly volumes of the Computer Science module in initial teacher training.
  • Decree 712 setting the ENS competition syllabus — determines the tests and programs for ENS entrance competitions, consistent with the taught content.
  • Algerian digital competency framework — national framework (under development) defining the digital competencies expected of teachers.
  • Benchmark of 10 Algerian universities — comparative study of computer science teaching practices, consulted to align this course with national standards.

Chapter 1 — ENS2 Review and Challenges (10 min)

Transition from isolated script to structured software project. Future teacher skills : algorithms, programming, digital culture, AI ethics.

Chapter 2 — OOP (20 min)

Class, object, attribute, method. Constructor __init__. Encapsulation, simple inheritance. Example : class Eleve, class Enseignant(Eleve) — adapted to the school context.

Chapter 3 — Advanced Algorithms (15 min)

Bubble sort, merge sort (notion), binary search (sorted array). Recursion : factorial, Fibonacci. Complexity comparison.

Chapter 4 — Databases (15 min)

Relational model : table, primary key, foreign key. SQL : SELECT, WHERE, JOIN, INSERT. Integrity and normalisation (1NF intro).

Chapter 5 — Web (15 min)

HTML structure, CSS styling, simple JavaScript event. Client-server, forms, REST API (notion). Web accessibility.

Chapter 6 — Git and Quality (10 min)

git init, add, commit, branch, merge. README, .gitignore. Unit tests intro (assert).

Chapter 7 — Computer Science Didactics (10 min)

Official curricula, project approach, Scratch → Python. Differentiation, competency-based assessment. AI usage charter in class.

Chapter 8 — ENS2 Project (5 min)

Deliverable : lightweight Web application or Python OOP module + SQLite database + Git repository + 45 min pedagogical lesson plan for middle school.

Conclusion

This module accompanies you from technical mastery (OOP, algorithms, databases, Web, Git) to didactic transposition for secondary education. Each session builds a brick of the integrated project that will consolidate all targeted skills.

Next lesson : Object-oriented programming — classes, objects and methods in Python.

Pedagogical Note ENS

Teaching transposition : The module overview can be presented to middle/high school students in the form of a mind map. From 9th grade onward, one can illustrate the link between Scratch blocks (visual programming) and Python code (textual programming) to show the progression of learning. In 10th grade SNT, the "Internet" theme can be linked to the Web session ; the "Structured Data" theme to the SQL session.

Trainer advice : Use this course plan as a communication tool with your students. Distribute it at the beginning of the module so they can visualize the overall coherence. Have them check off sessions as they go, which reinforces the sense of progress. Do not hesitate to revisit this plan at the start of each session to contextualize.

Extension : Students can create a digital mind map (XMind, FreeMind) of their own progress in the module, adding personal resources (links, notes, exercises) — this will become a foundation for their teaching portfolio.
