Computer Science Course — ENS Year 2 — Session 07 (EN)

Instructor : BELACEL Madani
Module: Computer Science
Level : ENS — Year 2 — English Department
Duration : 1h30
Academic year : 2025-2026

Course Sheet — E-learning Platform (Moodle)

Reference framework : benchmark of 10 Algerian universities + practices Univ-Mosta/Biskra/M'sila.

Target audience : ENS Year 2 Students — English Department

Prerequisite skills : Basic terminal usage (ENS1 session 03), Python projects

Cross-curricular objectives : - Apply object-oriented programming (classes, inheritance, encapsulation) in Python - Design advanced algorithms (sorting, searching, recursion) and estimate their complexity - Model data with the relational model and basic SQL queries - Understand Web architecture (HTML, CSS, JavaScript intro, HTTP) - Use Git and collaborative work methods (branches, merge) - Prepare the teaching of computer science in middle/high school (Scratch, pedagogical Python)

Assessment method : OOP Lab + SQL 35 % — Integrated Project 40 % — Pedagogical Session Sheet 25 %

Bibliography : Chacon & Straub — Pro Git (git-scm.com) ; Atlassian — Git Tutorials

Specific Learning Objectives

At the end of this session, the student is able to : - Initialize a Git repository - Add and commit files - Create and merge branches - Push/pull to GitHub - Write a professional README - Use .gitignore

Course Plan

  1. Why Git ?
  2. Installation and configuration
  3. Basic commands (init, add, commit, status)
  4. Branches (branch, merge)
  5. GitHub: remote, push, pull
  6. README and documentation
  7. Best practices for teachers

1. Why Git ? (10 min)

Problem : "TD_final.docx", "TD_final2.docx", "TD_version_final.docx"…

Solution : Git — version control system.

Advantages : - Complete history of modifications - Teamwork without conflicts - Error rollback possible - Cloud backup (GitHub) - Code portfolio for teachers

2. Installation and configuration (10 min)

Installation

# Check if Git is installed
git --version

# Download: git-scm.com

Initial configuration

git config --global user.name "Madani BELACEL"
git config --global user.email "m.belacel@ens-mostaganem.dz"
git config --global core.editor "code --wait"

3. Basic commands (20 min)

# Initialize a repository in the project folder
cd projet-ens2
git init

# View status
git status

# Add a file to tracking (stage)
git add cours_web.html
git add .  # Add entire folder

# Save a version (commit)
git commit -m "Add ENS2 web course page"

# View history
git log --oneline

4. Branches (20 min)

Branch : parallel version of the project. Allows working on a feature without affecting the main branch.

# List branches
git branch

# Create a branch
git branch quiz-feature

# Switch branch
git checkout quiz-feature

# Create and switch (in one command)
git checkout -b new-feature

Merge

# Switch back to main
git checkout main

# Merge the working branch
git merge quiz-feature

# Delete the branch after merging
git branch -d quiz-feature

gitGraph
    commit id: "Initial commit"

Conflicts : when two branches modify the same line. Git shows both versions, the user must choose.

5. GitHub (15 min)

Create a remote repository

  1. Create an account on github.com
  2. Click on New repository
  3. Copy the URL : https://github.com/user/projet.git

Link local → remote repository

git remote add origin https://github.com/user/projet.git
git push -u origin main

Update

git push          # Send your commits
git pull          # Fetch others' commits

GitHub Pages : Settings → Pages → branch: main → free website.

8. Best practices (5 min)

  1. Frequent and atomic commits (one modification = one commit)
  2. Clear commit messages : git commit -m "Add average calculation function"
  3. Never commit : passwords, API keys, student data
  4. Always pull before starting to work
  5. Use branches for experiments
  6. Add a README from the start

MCQ Self-Assessment

  1. Which Git command initializes a new repository ? a) git start b) git init ✓ c) git new

  2. Which command adds a file to the staging area ? a) git commit b) git add ✓ c) git push

  3. A Git branch allows you to : a) Permanently delete files b) Work in parallel without affecting the main branch ✓ c) Speed up commits

  4. Which command sends commits to GitHub ? a) git push ✓ b) git pull c) git clone

  5. What does the .gitignore file contain ? a) The list of contributors b) Files not to be versioned ✓ c) The last commit message

9. Conclusion (5 min)

Git is the standard tool of modern development. It allows you to keep a history, collaborate, and showcase your work (GitHub portfolio).

Next course : Didactics of computer science — teaching in middle/high school.

Pedagogical Note ENS

Teaching transposition : Git can be introduced as early as 9th grade through an unplugged activity: each student receives a sheet (file) and must go through "commits" at each significant modification. Branches are represented by different colored sheets, and merging by a stapler that binds the sheets together. In NSI Première, versioning is part of the curriculum and can be presented as a development logbook. The parallel with the "versions" of an assignment submitted by a student is revealing.

Trainer advice : Students often struggle with the concepts of branches and merging. Start with a simple scenario: "You work on the project alone, you create a branch for a feature, you merge it." Once this cycle is mastered, move on to collaborative work with two people on the same repository. Emphasize the importance of clear commit messages — this is a professional skill.

Extension : Students can create a Git repository from scratch for their teacher portfolio, using GitHub Pages to publish it. They can also intentionally experiment with merge conflicts (two students modify the same file) and learn to resolve them — this skill is highly valued in the professional environment.
