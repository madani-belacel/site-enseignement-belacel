1. Module Overview

The Computer Science module for ENS Year 1 aims to equip future teachers with fundamental computer science competencies necessary for their professional practice. It covers computer architecture, operating systems, algorithms, data structures, networks, security, and an introduction to Python programming. Emphasis is placed on pedagogical applications and didactic transposition of concepts for secondary education.

2. Targeted Competencies

By the end of the module, the student will be able to:

Competency Components
C1 — Understand machine architecture Von Neumann model, execution cycle, memory hierarchy, peripherals
C2 — Master operating systems Processes, files, directory tree, command line, permissions
C3 — Design algorithms Structured pseudocode, variables, conditions, loops, O(n)/O(n²) complexity
C4 — Use data structures Arrays, stacks (LIFO), queues (FIFO), linked lists, problem-appropriate selection
C5 — Understand networking principles IP addressing, DNS, HTTP/HTTPS, client-server model, protocols
C6 — Apply computer security CIA triad, passwords, MFA, phishing, 3-2-1 backup, GDPR
C7 — Program in Python Variables, types, conditions, loops, functions, files, educational projects
C8 — Didactics of computer science Concept transposition, secondary-level activities, assessment, project

3. Detailed Module Plan

Part 1 — Architecture and Systems (Sessions 01–04)

Session Content Competencies
01 Introduction — Module plan, objectives, bibliography, assessment C1–C8
02 Information representation — Binary, hexadecimal, ASCII/UTF-8, image encoding C1
03 Machine architecture — Von Neumann model, fetch-decode-execute cycle, memory hierarchy C1
04 Operating systems — Processes, threads, files, directory tree, command line C2

Part 2 — Algorithms and Data Structures (Sessions 05–06)

Session Content Competencies
05 Fundamental algorithms — Pseudocode, variables, conditions, loops, complexity C3
06 Data structures — Arrays, stacks (LIFO), queues (FIFO), linked lists C4

Part 3 — Networks and Security (Sessions 07–08)

Session Content Competencies
07 Networks and Internet — IP, DNS, HTTP/HTTPS, client-server, cloud C5
08 Security and ethics — CIA triad, passwords, phishing, 3-2-1, GDPR C6

Part 4 — Python Programming (Sessions 09–10)

Session Content Competencies
09 Introduction to Python — Variables, conditions, loops, functions, files C7
10 Python Project — Complete program, structuring, CSV, error handling, defence C7, C8

Tutorials (TD 01–10)

TD Theme
01 General review and synthesis
02 Binary conversions and encoding
03 Architecture and execution cycle
04 Operating systems and files
05 Algorithms (pseudocode)
06 Data structures (stacks, queues)
07 Networks and protocols
08 Security and GDPR
09 Advanced Python — algorithms and structures
10 Python Project — synthesis and evaluation

Practical Labs (TP 01–08)

TP Theme Level
01 First steps with Python Beginner
02 Conditional structures Beginner
03 Loops and iterations Beginner
04 Functions and modularity Intermediate
05 Lists and arrays Intermediate
06 Stacks and queues in Python Intermediate
07 Files, CSV and educational projects Advanced
08 Mini complete project: pedagogical quiz Advanced

4. Assessment

Component Weight Description
Tutorials (continuous assessment) 40 % Written exercises and problem-solving
Python Lab (TP) 35 % Practical machine-based assessment of scripts
Project + MCQ 25 % Pedagogical Python project + knowledge MCQ

Python Lab Grading Rubric

Criterion Excellent (4) Good (3) Satisfactory (2) Insufficient (1)
Correct syntax Executable code without errors Minor errors Blocking errors Does not execute
Algorithmic logic Optimal solution Good approach Partial approach No approach
Structuring Functions, modularity Acceptable organisation Poorly structured No structure
Error handling Complete (try/except, validation) Partial Minimal Absent
Documentation Comments + docstrings Key comments Few comments No comments

6. Algerian Official Framework References

This syllabus is developed within the framework of the following Algerian regulatory texts and national reference systems:

  • Ministerial decree establishing the ENS (Bachelor's/Master's cycle) — the founding text defining the training framework for the Écoles Normales Supérieures in Algeria.
  • National Computer Science Curriculum for Algerian ENS — the framework curriculum defining the objectives, content, and workload of the Computer Science module in teacher training.
  • Decree 712 setting the ENS competitive examination program — the regulatory text defining the tests and programs for ENS entrance examinations.
  • Algerian Digital Competency Framework — the national reference framework (under development) defining the digital competencies expected of teachers trained at ENS.
  • Benchmark of 10 Algerian universities — a comparative study of computer science teaching practices in Algerian universities, consulted for the development of this syllabus.
