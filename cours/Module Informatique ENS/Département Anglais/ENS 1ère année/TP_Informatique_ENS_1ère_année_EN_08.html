Learning Objectives

Exercise 2 — CSV Loading Module (15 min)

Problem statement: Create the question loading functions in quiz.py: 1. load_questions(filename) — loads the CSV and returns a list of dictionaries 2. filter_by_category(questions, category) — filters questions by category 3. shuffle_questions(questions) — randomly shuffles

Solution:

import csv
import random
import time
from datetime import date

def load_questions(filename):
    """Loads questions from a CSV file."""
    questions = []
    try:
        with open(filename, "r", encoding="utf-8") as f:
            reader = csv.DictReader(f)
            for row in reader:
                questions.append({
                    "category": row["Category"],
                    "question": row["Question"],
                    "answer": row["Answer"]
                })
    except FileNotFoundError:
        print(f"Error: file {filename} not found.")
        return []
    return questions

def filter_by_category(questions, category):
    """Filters questions by category."""
    if category == "All":
        return questions
    return [q for q in questions if q["category"] == category]

def shuffle_questions(questions):
    """Randomly shuffles questions."""
    random.shuffle(questions)
    return questions

def main_menu():
    """Displays the main menu and handles choices."""
    questions = load_questions("questions.csv")
    if not questions:
        return
    categories = ["All", "Architecture", "Algorithms", "Python", "Networks"]
    while True:
        print("\n" + "="*40)
        print("1. Start quiz")
        print("2. Rules")
        print("3. Quit")
        choice = input("Your choice: ")
        if choice == "1":
            for i, cat in enumerate(categories, 1):
                print(f"{i}. {cat}")
            try:
                c = int(input("Category (1-5): "))
                cat = categories[c - 1] if 1 <= c <= 5 else "All"
            except (ValueError, IndexError):
                cat = "All"
            qf = filter_by_category(questions, cat)
            print(f"Questions: {len(qf)} in '{cat}'")
            run_quiz(qf, input("Your name: "))
        elif choice == "2":
            print("• Text answer • 4 categories • Score /20 • CSV export")
        elif choice == "3":
            print("Goodbye!")
            break
        else:
            print("Invalid choice.")

Exercise 4 — Random Selection and Scoring (15 min)

Problem statement: Add quiz functions with random selection, scoring, and grade. The program shuffles questions, asks each question, checks the answer, and assigns a grade.

Solution:

def ask_question(question):
    """Asks a question and returns True if correct."""
    print(f"\n[{question['category']}] {question['question']}")
    answer = input("Your answer: ").strip().lower()
    expected = question['answer'].strip().lower()
    if answer == expected:
        print("✓ Correct!")
        return True
    else:
        print(f"✗ Wrong. Answer: {question['answer']}")
        return False

def run_quiz(questions, student_name=""):
    """Runs the quiz with random shuffle and timer."""
    if not questions:
        print("No questions to ask.")
        return

    questions = shuffle_questions(questions)
    score = 0
    total = len(questions)
    start = time.time()

    print(f"\n=== Quiz started! ({total} questions) ===")
    for i, q in enumerate(questions, 1):
        print(f"\nQuestion {i}/{total}")
        if ask_question(q):
            score += 1

    elapsed = time.time() - start
    show_results(score, total, elapsed)
    export_choice = input("\nExport results? (y/n): ")
    if export_choice == "y" and student_name:
        export_results(score, total, elapsed, student_name)

def show_results(score, total, elapsed):
    """Displays results with grade."""
    percentage = (score / total * 100) if total > 0 else 0
    print("\n" + "="*40)
    print("           RESULTS")
    print("="*40)
    grade = round(score / total * 20, 2) if total > 0 else 0
    print(f"Score: {score}/{total} ({percentage:.1f}%)")
    print(f"Grade: {grade}/20")
    print(f"Time: {elapsed:.1f}s")

    if percentage == 100:
        remark = "Perfect!"
    elif percentage >= 80:
        remark = "Very good!"
    elif percentage >= 60:
        remark = "Good!"
    elif percentage >= 40:
        remark = "Could do better."
    else:
        remark = "Needs review."
    print(f"Remark: {remark}")

def export_results(score, total, elapsed, student_name, filename="resultats.csv"):
    """Exports quiz results to a CSV file."""
    with open(filename, "a", newline="", encoding="utf-8") as f:
        writer = csv.writer(f)
        if f.tell() == 0:
            writer.writerow(["Date", "Student", "Score", "Total",
                            "Percentage", "Grade_20", "Time_s"])
        grade = round(score / total * 20, 2) if total > 0 else 0
        percentage = f"{score/total*100:.1f}" if total > 0 else "0"
        writer.writerow([date.today(), student_name, score, total,
                        percentage, grade, f"{elapsed:.1f}"])
    print(f"Results exported to {filename}")

Pedagogical Note ENS

Teaching transposition

This mini-project is the culmination of the module. It mobilizes all the skills acquired: variables, conditions, loops, functions, lists, dictionaries, CSV files, and error handling. - For future teachers: This quiz is a directly reusable tool. They can adapt the questions to their subject (history, languages, sciences) and use the CSV export to track student progress. - In secondary school: Simplify by keeping only a single category of questions.

Trainer advice

Guide students in structuring the project: splitting into functions, separate data file, error handling. The project can be done in pairs (pair programming). Evaluate code quality (comments, naming) as much as functionality. For high school students, lighten the requirements by removing the CSV export.

Extension

Transform the quiz into a web application with Flask (ENS Year 2 curriculum). Add an SQLite database to store questions and user scores. This capstone project can become the subject of the ENS1 project presented in session 10.
