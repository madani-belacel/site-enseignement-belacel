Idée 1 The goal of this mini-projectL'objectif de ce mini-projet

We will build our first AI: a program that recognizes 3 species of flower (iris) from 4 measurements. It is a classic first project that works on any computer.

Nous allons construire notre première IA : un programme qui reconnaît 3 espèces de fleurs (iris) à partir de 4 mesures. C'est un premier projet classique qui fonctionne sur n'importe quel ordinateur.

Q1. What are we predicting?

R1. The species of an iris flower: setosa, versicolor or virginica.

Q1. Que prédisons-nous ?

R1. L'espèce d'une fleur d'iris : setosa, versicolor ou virginica.

Q2. Which data does it use?

R2. 4 measurements taken on each flower: sepal/petal length and width.

Q2. Quelles données utilise-t-il ?

R2. 4 mesures prises sur chaque fleur : longueur/largeur du sépale et du pétale.

Q3. Why this example?

R3. It is small, free, balanced, and perfect to understand the 6 steps of course 04.

Q3. Pourquoi cet exemple ?

R3. Il est petit, gratuit, équilibré et parfait pour comprendre les 6 étapes du cours 04.

Idée 2 Where to run the codeOù exécuter le code

The easiest way: Google Colab, free and in the browser. Open colab.research.google.com, create a notebook, paste the code into a cell and run it with Shift+Enter.

Le plus simple : Google Colab, gratuit et dans le navigateur. Ouvre colab.research.google.com, crée un cahier, colle le code dans une cellule et exécute-le avec Shift+Entrée.

Q1. What is a notebook?

R1. A document that mixes text, code and results. Each block is called a "cell".

Q1. Qu'est-ce qu'un cahier (notebook) ?

R1. Un document qui mélange texte, code et résultats. Chaque bloc s'appelle une « cellule ».

Q2. How do I run a cell?

R2. Click on the cell and press Shift+Enter.

Q2. Comment exécuter une cellule ?

R2. Clique sur la cellule et appuie sur Shift+Entrée.

Q3. Do I need to install Python?

R3. No. Colab already has Python and the AI libraries installed.

Q3. Dois-je installer Python ?

R3. Non. Colab a déjà Python et les bibliothèques d'IA installés.

Idée 3 The complete codeLe code complet

Here is the whole mini AI in about fifteen lines. The comments explain each part. Read the comments first, then run the code.

Voici toute la mini-IA en une quinzaine de lignes. Les commentaires expliquent chaque partie. Lis d'abord les commentaires, puis lance le code.

# 1. Import the needed libraries
import pandas as pd
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 2. Load the iris dataset (150 flowers)
iris = load_iris()

# 3. Split the data: 70% for training, 30% for testing
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.3, random_state=42
)

# 4. Choose a model
model = RandomForestClassifier()

# 5. Train it
model.fit(X_train, y_train)

# 6. Make predictions on new data
predictions = model.predict(X_test)

# 7. Measure the accuracy
print("Accuracy:", accuracy_score(y_test, predictions))

Q1. What does step 5 (fit) do?

R1. It trains the model with 70% of the flowers, so it learns the patterns.

Q1. Que fait l'étape 5 (fit) ?

R1. Elle entraîne le modèle avec 70% des fleurs, pour qu'il apprenne les régularités.

Q2. What does the last line print?

R2. The percentage of correct answers on the 30% of flowers the model has never seen.

Q2. Qu'affiche la dernière ligne ?

R2. Le pourcentage de bonnes réponses sur les 30% de fleurs que le modèle n'a jamais vues.

Q3. Do I need to understand every line right now?

R3. No. First run it and look at the result. Understanding will come with time.

Q3. Dois-je comprendre chaque ligne maintenant ?

R3. Non. D'abord lance-le et regarde le résultat. La compréhension viendra avec le temps.

Idée 4 Train and test splitLa séparation entraînement / test

70% of the flowers are used to learn, and 30% are kept aside to check. Never check with data the model has already seen.

70% des fleurs servent à apprendre, et 30% sont gardés pour vérifier. Ne vérifie jamais avec des données que le modèle a déjà vues.

Q1. Why separate train and test?

R1. To prove that the model generalizes and does not just memorize.

Q1. Pourquoi séparer entraînement et test ?

R1. Pour prouver que le modèle généralise et ne se contente pas de mémoriser.

Q2. Which percentage to choose?

R2. About 70-80% for training and 20-30% for testing is a common choice.

Q2. Quel pourcentage choisir ?

R2. Environ 70-80% pour l'entraînement et 20-30% pour le test est un choix courant.

Q3. What is random_state=42?

R3. A fixed value so the split is the same every time: the project is reproducible.

Q3. Qu'est-ce que random_state=42 ?

R3. Une valeur fixe pour que la séparation soit toujours la même : le projet est reproductible.

Idée 5 Reading the resultLire le résultat

If the accuracy is around 90% or more, the AI works. If it is bad, the usual fixes are: more data, better data, or a different model.

Si la précision est d'environ 90% ou plus, l'IA fonctionne. Si elle est mauvaise, les corrections habituelles sont : plus de données, de meilleures données ou un autre modèle.

Q1. What does accuracy = 0.95 mean?

R1. 95% of the tested flowers were correctly classified.

Q1. Que signifie précision = 0.95 ?

R1. 95% des fleurs testées ont été bien classées.

Q2. Is 100% normal?

R2. Sometimes on easy data, but on real problems it usually means the data is too small or too easy.

Q2. 100%, est-ce normal ?

R2. Parfois sur des données faciles, mais sur de vrais problèmes cela signifie généralement que les données sont trop petites ou trop faciles.

Q3. What if accuracy is low (60%)?

R3. Increase the data, clean it better, or try another model with different settings.

Q3. Que faire si la précision est faible (60%) ?

R3. Augmenter les données, mieux les nettoyer, ou essayer un autre modèle avec d'autres réglages.

Idée 6 Predict one new flowerPrédire une seule fleur

You can ask the trained model to classify a flower that you invent: give the 4 measurements and the model answers the species.

Tu peux demander au modèle entraîné de classifier une fleur que tu inventes : tu donnes les 4 mesures et le modèle répond l'espèce.

# Invent a flower: [sepal_length, sepal_width, petal_length, petal_width]
new_flower = [[5.1, 3.5, 1.4, 0.2]]
species = model.predict(new_flower)
print("Index of species:", species[0])
# 0 = setosa, 1 = versicolor, 2 = virginica

Q1. What is new_flower?

R1. An invented example: one line of 4 numbers, the flower measurements.

Q1. Qu'est-ce que new_flower ?

R1. Un exemple inventé : une ligne de 4 nombres, les mesures de la fleur.

Q2. Why does it answer with a number?

R2. The model works with numbers. The number 0, 1 or 2 corresponds to one species.

Q2. Pourquoi répond-il avec un nombre ?

R2. Le modèle travaille avec des nombres. Le nombre 0, 1 ou 2 correspond à une espèce.

Q3. What does "0 = setosa" mean?

R3. The dataset target names: index 0 is setosa, 1 is versicolor, 2 is virginica.

Q3. Que signifie « 0 = setosa » ?

R3. Les noms des cibles du jeu de données : l'index 0 est setosa, 1 versicolor, 2 virginica.

Idée 7 The same steps when cookingLes mêmes étapes quand on cuisine

Preparing a meal is similar: 1) choose the dish (problem), 2) buy ingredients (data), 3) wash and cut (prepare), 4) follow a recipe (model), 5) cook (train), 6) taste and adjust (test).

Préparer un repas, c'est pareil : 1) choisir le plat (problème), 2) acheter les ingrédients (données), 3) laver et couper (préparer), 4) suivre une recette (modèle), 5) cuisiner (entraîner), 6) goûter et ajuster (tester).

Q1. What is the recipe in AI?

R1. The chosen model with its settings.

Q1. Quelle est la recette dans l'IA ?

R1. Le modèle choisi avec ses réglages.

Q2. What is "cooking" in AI?

R2. Training: the moment when the model learns from the data.

Q2. Qu'est-ce que « cuisiner » dans l'IA ?

R2. L'entraînement : le moment où le modèle apprend à partir des données.

Q3. What is "tasting" in AI?

R3. Testing: checking the result and improving based on the feedback.

Q3. Qu'est-ce que « goûter » dans l'IA ?

R3. Tester : vérifier le résultat et améliorer à partir des retours.

Idée 8 Where to find your first projectsOù trouver tes premiers projets

Free tutorials exist on the scikit-learn website and from Google. Also, the iris dataset is built into scikit-learn, so you can type the code and run it immediately.

Il existe des tutoriels gratuits sur le site de scikit-learn et chez Google. En plus, le jeu de données iris est intégré à scikit-learn, donc tu peux taper le code et l'exécuter immédiatement.

Q1. Is the iris data free?

R1. Yes, it is built into scikit-learn: load_iris() gives it to you for free.

Q1. Les données iris sont-elles gratuites ?

R1. Oui, elles sont intégrées à scikit-learn : load_iris() te les donne gratuitement.

Q2. Can I start with another dataset as easily?

R2. Yes: scikit-learn has several small built-in datasets (digits, wine, breast cancer).

Q2. Puis-je commencer avec un autre jeu de données aussi facilement ?

R2. Oui : scikit-learn a plusieurs petits jeux de données intégrés (digits, vin, cancer du sein).

Q3. Is there a community to help?

R3. Yes: forums, question sites and tutorials by many teachers and students.

Q3. Y a-t-il une communauté pour aider ?

R3. Oui : des forums, des sites de questions et des tutoriels de nombreux enseignants et étudiants.

Idée 9 The most common beginner mistakesLes erreurs de débutant les plus courantes

1) testing on the training data, 2) dirty data, 3) choosing a huge model for a tiny problem. Avoid these and you save many hours.

1) tester sur les données d'entraînement, 2) des données sales, 3) choisir un énorme modèle pour un petit problème. Évite ces erreurs et tu gagnes beaucoup d'heures.

Q1. Why not test on training data?

R1. Because the model has already seen it; the score would be fake and too good.

Q1. Pourquoi ne pas tester sur les données d'entraînement ?

R1. Parce que le modèle les a déjà vues ; le score serait faux et trop beau.

Q2. Why does dirty data hurt?

R2. The model learns from the data, so errors in the data become errors in the AI.

Q2. Pourquoi des données sales nuisent-elles ?

R2. Le modèle apprend à partir des données, donc les erreurs des données deviennent des erreurs de l'IA.

Q3. What is a "too big model"?

R3. A deep network with millions of parameters for 30 lines of data: it will simply memorize.

Q3. Qu'est-ce qu'un « modèle trop gros » ?

R3. Un réseau profond avec des millions de paramètres pour 30 lignes de données : il va simplement mémoriser.

Idée 10 Your next 5 stepsTes 5 prochaines étapes

1) try the digits dataset (images of numbers), 2) change the model and watch the score, 3) make your own small dataset in a table, 4) train a tiny neural network, 5) build a real project that you care about.

1) essaie le jeu de données digits (images de chiffres), 2) change de modèle et observe le score, 3) fabrique ton propre petit jeu de données dans un tableau, 4) entraîne un petit réseau de neurones, 5) réalise un vrai projet qui te tient à cœur.

Q1. What is the digits dataset?

R1. Computer-drawn images of the numbers 0 to 9, a classic image classification exercise.

Q1. Qu'est-ce que le jeu de données digits ?

R1. Des images de chiffres de 0 à 9 dessinées par ordinateur, un exercice classique de classification d'images.

Q2. What is the best next step?

R2. Re-do the same project with a different model and see how the accuracy changes.

Q2. Quelle est la meilleure prochaine étape ?

R2. Refaire le même projet avec un autre modèle et observer comment la précision change.

Q3. When to start deep learning?

R3. After you are comfortable with the 6 steps and the basic models.

Q3. Quand commencer le deep learning ?

R3. Après être à l'aise avec les 6 étapes et les modèles de base.
