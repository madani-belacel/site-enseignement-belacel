🤖 Séance 07 — Programmer avec l'IA : mini-projet Python + API

Module Intelligence Artificielle — 2ème année PEP · ENS Université de Mostaganem

💡 Astuce IA — Ta clé API dans un gestionnaire de mots de passe
Une clé API (DeepSeek, OpenAI…) créée un jour se perd un jour. Enregistre-la dans Bitwarden ou KeePass dès sa création, avec l'URL du tableau de bord. Tu ne la recopies plus jamais dans un fichier, un e-mail ou un dépôt public — les trois endroits où elle serait volée en quelques heures.

🎯 En une phrase

À la fin de cette séance, tu sauras faire écrire, lancer et comprendre un mini-projet Python qui interroge une vraie API — et tu auras un script qui tourne sur ton ordinateur.

💡 Pourquoi c'est utile pour toi

Tu n'es pas informaticien, mais tu as des tâches répétitives : renommer des photos, récupérer des informations qui changent (météo, dates, devises), nettoyer un tableau avant un devoir. Un script de 20 lignes te fait gagner des heures. Et surtout : l'IA ne te rend plus un script, elle te rend quelqu'un qui sait s'en servir — c'est la différence entre taper des commandes et être autonome sur son ordinateur.

🔑 Les 3 idées essentielles

  • Une API, c'est un serveur qui répond à ta question : tu envoies une requête, tu reçois du texte structuré (JSON). C'est exactement ce que fait ton téléphone quand il affiche la météo.
  • L'IA écrit, toi tu lis. Un script que tu ne comprends pas est un script que tu ne pourras pas corriger le jour où il casse.
  • Une erreur = une information. Colle le message d'erreur exact à l'IA : la cause se trouve presque toujours dans la dernière ligne affichée.
🔧 IA au quotidien — Écrire un script Python pour renommer 200 photos
Tu dois renommer 200 photos pour un projet. Tu demandes à ChatGPT : « Écris-moi un script Python qui renomme toutes les photos d'un dossier en photo_001.jpg, photo_002.jpg… » L'IA te donne le script prêt à copier. Tu le lances dans le terminal, en 3 secondes tout est renommé. Tu gagnes 2 heures.

📋 Comment faire — pas à pas

Étape 1 — Comprendre ce qu'est une API (4 min)

📍 chatgpt.com ⏱️ 4 min

Ce que tu vas faire : te construire une image mentale juste de l'API avant d'écrire une seule ligne de code. Sans ça, tu copieras du code aveuglément.

Ce que tu tapes :

Explique-moi ce qu'est une API en 3 phrases, avec une analogie de restaurant. Puis donne-moi un exemple d'API que je peux appeler gratuitement, sans clé, pour commencer.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

Une API (interface de programmation), c'est :

  1. Un service qui accepte des questions écrites selon une règle précise et qui répond dans un format précis.
  2. Analogie du restaurant : tu es le client, le menu est la documentation de l'API, le serveur est l'API, et la cuisine est l'ordinateur qui calcule. Tu ne rentres pas en cuisine : tu commandes, tu reçois ton plat.
  3. Concrètement, tu envoies une adresse web (l'endpoint) et tu reçois du texte structuré en retour, presque toujours en JSON.

Exemple gratuit sans clé : Open-Meteo (météo ouverte).

https://api.open-meteo.com/v1/forecast?latitude=48.85&longitude=2.35&current=temperature_2m

Réponse : {"current":{"temperature_2m":24.3},"timezone":"Europe/Paris"}

Copie cette adresse dans ton navigateur : tu vois la réponse immédiatement, sans rien installer.

Demande toujours l'analogie avant la définition technique. Si l'analogie tient debout, tu as compris ; si l'IA peine à en trouver une, c'est que le concept est plus complexe qu'il n'y paraît.
⚠️ Piège à éviter : ne commence pas par une API payante ou qui demande une carte bancaire — Open-Meteo, Wikipedia et la plupart des API publiques sont gratuites et suffisent pour un premier projet.

Étape 2 — Faire écrire ton script par ChatGPT (7 min)

📍 chatgpt.com ⏱️ 7 min

Ce que tu vas faire : demander un script complet, commenté, sans dépendance cachée. C'est ici que la précision du prompt décide de la qualité du code.

Ce que tu tapes :

Tu es développeur Python. Écris un script qui : 1) interroge l'API Open-Meteo pour la météo actuelle de Paris, 2) affiche la température et l'heure en français, 3) n'exige aucune clé API, 4) s'exécute avec « python meteo.py ». Commente chaque bloc de code, et rappelle la commande pour installer le module manquant.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

# meteo.py — météo actuelle de Paris (API Open-Meteo, sans clé)
import requests

# 1) On prépare la requête : coordonnées de Paris + paramètres demandés
url = "https://api.open-meteo.com/v1/forecast"
params = {
    "latitude": 48.85,
    "longitude": 2.35,
    "current": "temperature_2m,weather_code",
    "timezone": "Europe/Paris",
}

# 2) On appelle l'API et on vérifie que tout s'est bien passé
reponse = requests.get(url, params=params, timeout=10)
reponse.raise_for_status()
data = reponse.json()

# 3) On affiche le résultat en français
print("=== Météo à Paris ===")
print("Heure locale :", data["current"]["time"])
print("Température  :", data["current"]["temperature_2m"], "°C")

Installation requise : pip install requests

Sortie obtenue :

=== Météo à Paris ===
Heure locale : 2026-09-22T14:00
Température  : 24.3 °C
Exige « commente chaque bloc » et « sans clé API » dès le premier prompt : un script commenté est un script que tu pourras relire dans six mois, et tu évites d'attendre une validation qui ne viendra jamais.
⚠️ Piège à éviter : ne copie jamais un script que tu n'as pas lu ligne par ligne — le jour où il affichera une erreur, l'IA ne sera pas là pour toi.

Étape 3 — Lancer le script et traiter l'erreur (5 min)

📍 Terminal (ou VS Code) ⏱️ 5 min

Ce que tu vas faire : exécuter le script, et si une erreur apparaît, la faire diagnostiquer correctement. C'est la compétence la plus rentable de toute la séance.

Ce que tu tapes :

J'ai lancé « python meteo.py » et j'obtiens : ModuleNotFoundError: No module named 'requests' Explique la cause en une phrase et donne la commande exacte à taper. Ensuite, redis-moi comment lancer le script.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

Cause : le module requests n'est pas installé dans l'environnement Python que tu utilises.

  1. Installe-le : pip install requests (sur macOS/Linux : pip3 install requests).
  2. Relance : python meteo.py.
  3. Si l'erreur persiste, c'est que tu as plusieurs Python d'installés : tape python --version et pip --version et envoie-moi les deux résultats.

Sortie attendue :

Successfully installed requests-2.32.3
=== Météo à Paris ===
Température  : 24.3 °C
Colle l'erreur exacte, en entier, telle qu'elle s'affiche — jamais ton résumé. Le nom du module manquant, le numéro de ligne et le chemin du fichier contiennent déjà 90 % de la réponse.
⚠️ Piège à éviter : ne lance jamais une commande d'installation proposée par l'IA sans avoir lu son nom : un paquet mal orthographié peut être un paquet piégé.

Étape 4 — Personnaliser le script (6 min)

📍 chatgpt.com ⏱️ 6 min

Ce que tu vas faire : transformer un script générique en ton script — une ville au choix, un affichage propre, un fichier de sortie. C'est là que le projet devient le tien.

Ce que tu tapes :

Modifie mon script en demandant la ville en ligne de commande (par défaut : Paris), avec une petite table d'identification des villes (Paris 48.85/2.35, Madrid 40.42/-3.70, Rome 41.90/12.50). Affiche une ligne par ville, puis écris le résultat dans meteo.txt. Envoie le script COMPLET, pas un extrait.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

# meteo.py — plusieurs villes d'Europe
import sys
import requests

VILLES = {
    "paris":      ("Paris",     48.85, 2.35),
    "madrid":     ("Madrid",    40.42, -3.70),
    "rome":       ("Rome",      41.90, 12.50),
}

choix = sys.argv[1].lower() if len(sys.argv) > 1 else "paris"
nom, lat, lon = VILLES[choix]

url = "https://api.open-meteo.com/v1/forecast"
r = requests.get(url, params={"latitude": lat, "longitude": lon,
                              "current": "temperature_2m",
                              "timezone": "Europe/Paris"}, timeout=10)
r.raise_for_status()
t = r.json()["current"]["temperature_2m"]

ligne = f"{nom:12} {t:5.1f} °C"
print(ligne)
with open("meteo.txt", "a", encoding="utf-8") as f:
    f.write(ligne + "
")

Utilisation : python meteo.py rome → Rome 26.1 °C

Le fichier meteo.txt accumule tes relevés : tu peux comparer Rome et Paris sur une semaine.

Écris systématiquement « envoie le script COMPLET, pas un extrait » : les IA tronquent volontiers les réponses longues et te laissent un code incomplet qu'il faudra re-demander.
⚠️ Piège à éviter : ne demande jamais cinq modifications d'un coup — la quatrième et la cinquième disparaissent le plus souvent. Une modification à la fois, tu relances ensuite.

Étape 5 — Pouvoir expliquer ton script (4 min)

📍 chatgpt.com ⏱️ 4 min

Ce que tu vas faire : vérifier que le code est vraiment tien. C'est l'étape qui transforme un copier-coller en compétence — et la seule qui te protège à l'oral du projet.

Ce que tu tapes :

Explique ce script ligne par ligne comme à un étudiant qui verra Python pour la première fois. Puis donne-moi 3 questions pour vérifier que j'ai compris, sans y répondre.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

Ligne 1 — import requests : tu embarques la bibliothèque qui sait parler aux sites web, comme si tu prenais un téléphone avant d'appeler quelqu'un.

Ligne 3 — VILLES = {...} : un dictionnaire, c'est une table de correspondance. Ici il associe le nom tapé par l'utilisateur à un nom d'affichage et à des coordonnées.

Ligne 9 — sys.argv[1]... : ce que tu écris après python meteo.py dans le terminal arrive ici sous forme de texte. S'il n'y a rien, on prend « paris » par défaut.

Ligne 13 — requests.get(...) : l'appel à l'API. Les paramètres deviennent une adresse complète ; le serveur répond par du JSON.

Ligne 17 — raise_for_status() : garde-fou. Si le serveur répond « erreur 4xx/5xx », le script s'arrête au lieu d'afficher n'importe quoi.

Ligne 19-20 — r.json()["current"]...` : on ouvre la réponse comme un tiroir imbriqué et on sort la valeur de la température.

3 questions pour vérifier :

  1. Que se passe-t-il si tu tapes python meteo.py sans argument ?
  2. À quelle ligne le script parle-t-il à Internet, et que renvoie cette ligne ?
  3. Pourquoi raise_for_status() est-il utile si l'API tombe en panne ?
Réponds aux 3 questions à voix haute, sans regarder le script. Si tu bloques, relis l'explication une fois : la question à laquelle tu ne réponds pas est exactement celle qui tombera à l'oral.
⚠️ Piège à éviter : ne présente jamais un script que tu ne peux pas expliquer — la première question d'un jury est toujours « montre-moi la ligne qui appelle l'API ».

🎨 Bonus — Demander un schéma en ASCII à l'IA

Un schéma en ASCII est un dessin fait uniquement avec des caractères du clavier (tirets, barres, flèches, plus). Ça marche partout, sans image. Très utile pour comprendre une idée visuellement en un coup d'œil.

Comment demander un schéma à l'IA ? Ajoute simplement « avec un schéma en ASCII » à la fin de ton prompt.

Exemple 1 — Comprendre la structure de ta Faculté

Situation : tu veux comprendre et retenir l'organisation de la Faculté des Langues Étrangères (FLE).

Montre-moi la structure de la Faculté des Langues Étrangères (Université de Mostaganem) avec ses 3 départements (Anglais, Français, Espagnol), avec un schéma en ASCII.

Voici ce que l'IA va probablement te répondre :

📌 En résumé — Comment demander un schéma ASCII

Ce que tu veux Ce que tu tapes
Un schéma simple … avec un schéma en ASCII
Comparer deux choses … avec un schéma en ASCII qui compare A et B
Un schéma pour un enfant … avec un schéma en ASCII très simple, sans jargon
Un schéma en plusieurs étapes … avec un schéma en ASCII montrant les 4 étapes dans l'ordre

⚠️ Attention : un schéma ASCII fonctionne bien pour des idées simples (2 à 5 éléments). Pour des concepts complexes, demande plutôt une liste structurée ou un tableau.

🧪 Exemples réels

Exemple 1 — Définir un mot anglais dans son programme (département Anglais)

Situation : tu rédiges un commentaire de texte et tu hésites sur un mot : est-il correct ? Que signifie-t-il exactement ? Tu veux la réponse avec des exemples, pas un simple lien.

Ce que tu tapes :

Écris un script Python qui interroge l'API gratuite dictionaryapi.dev, prend un mot saisi en ligne de commande et affiche en français : la définition, le type de mot et un exemple d'utilisation. Commente chaque bloc.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

# dico.py — définition d'un mot en anglais
import sys
import requests

mot = sys.argv[1] if len(sys.argv) > 1 else "evidence"
r = requests.get(f"https://api.dictionaryapi.dev/api/v2/entries/en/{mot}", timeout=10)

if r.status_code != 200:
    print("Mot introuvable dans le dictionnaire.")
else:
    entree = r.json()[0]
    print(f"Mot : {entree['word']}")
    for sens in entree["meanings"][:2]:
        print(f"Type : {sens['partOfSpeech']}")
        for d in sens["definitions"][:2]:
            print("  -", d["definition"])
            if "example" in d:
                print("    Exemple :", d["example"])

Sortie :

Mot : evidence
Type : noun
  - the available facts or information indicating whether a belief is true.
    Exemple : There was no physical evidence of sabotage.
Ajoute « affiche aussi la transcription phonétique » : tu gagnes la prononciation en même temps que la définition, sans ouvrir un deuxième site.

Exemple 2 — Récupérer la liste des départements de ta Faculté (département Français)

Situation : tu dois produire une fiche sur ta faculté pour un exposé et tu veux des données officielles et à jour, pas recopiées d'un PDF de 2019.

Ce que tu tapes :

Écris un script qui interroge l'API de l'OpenStreetMap (Nominatim) pour trouver « Faculté des Langues Étrangères Mostaganem » et affiche le nom exact, la latitude, la longitude et le lien vers la carte. Commente chaque bloc.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

# faculte.py — localiser la Faculté sur OpenStreetMap (sans clé)
import requests

# 1) Recherche textuelle : l'API renvoie une liste de lieux qui correspondent
params = {"q": "Faculté des Langues Étrangères Mostaganem",
          "format": "json", "limit": 1}
r = requests.get("https://nominatim.openstreetmap.org/search",
                 params=params, headers={"User-Agent": "projet-etu/1.0"}, timeout=10)
r.raise_for_status()
resultats = r.json()

# 2) On affiche le premier résultat, s'il existe
if resultats:
    lieu = resultats[0]
    print("Nom  :", lieu["display_name"])
    print("Lat  :", lieu["latitude"])
    print("Lon  :", lieu["longitude"])
    print("Carte : https://www.openstreetmap.org/?mlat="
          f"{lieu['latitude']}&mlon={lieu['longitude']}#map=17/{lieu['latitude']}/{lieu['longitude']}")
else:
    print("Aucun lieu trouvé, essaie une formulation plus courte.")

Sortie :

Nom  : Faculté des Langues Étrangères, Rue ..., Mostaganem, Algérie
Lat  : 35.9339
Lon  : 0.2817
Carte : https://www.openstreetmap.org/?mlat=35.9339&mlon=0.2817#map=17/35.9339/0.2817
Ligne User-Agent obligatoire : sans elle, OpenStreetMap bloque ta requête. C'est le genre de détail que l'IA oublie si tu ne demandes pas « un script qui respecte les règles de l'API ».

Exemple 3 — Comparer la météo de 3 villes espagnoles (département Espagnol)

Situation : exposé sur les climats d'Espagne. Tu veux trois relevés réels à afficher, plutôt que trois chiffres recopiés.

Ce que tu tapes :

Écris un script qui affiche la température actuelle de Madrid, Séville et Valence dans un tableau aligné, avec les noms en espagnol, puis indique laquelle est la plus chaude. Boucle sur les trois villes, une seule requête par ville.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

# espana.py — comparaison de trois villes espagnoles
import requests

VILLES = [("Madrid", 40.42, -3.70), ("Sevilla", 37.39, -5.99),
          ("València", 39.47, -0.38)]

resultats = []
for nom, lat, lon in VILLES:                      # une requête par ville
    r = requests.get("https://api.open-meteo.com/v1/forecast",
                     params={"latitude": lat, "longitude": lon,
                             "current": "temperature_2m"}, timeout=10)
    r.raise_for_status()
    resultats.append((nom, r.json()["current"]["temperature_2m"]))

print(f"{'Ville':10} {'Température':>12}")
for nom, t in resultats:
    print(f"{nom:10} {t:10.1f} °C")

plus_chaude = max(resultats, key=lambda x: x[1])
print("La plus chaude :", plus_chaude[0])

Sortie :

Ville        Température
Madrid              27.4 °C
Sevilla             31.2 °C
València            28.1 °C
La plus chaude : Sevilla
Réutilise la boucle pour 5 villes : tu changes uniquement la liste VILLES. C'est la première leçon de la programmation — la donnée change, la logique reste.

🎓 Les astuces que personne ne dit

  • Une modification à la fois. Tu ajoutes une fonctionnalité par prompt, jamais cinq — sinon tu ne sais plus laquelle a échoué.
  • « Script complet, pas d'extrait ». Répète-le dans chaque prompt de modification : les IA tronquent les réponses longues.
  • Colle l'erreur exacte. Le texte brut du terminal, pas ton résumé : module, ligne, chemin — tout compte.
  • Exige les commentaires. Un script commenté est un script que tu comprendras au moment des partiels, pas celui que tu jetteras.
  • « Sans clé API ». Pour un premier projet, uniquement des API gratuites et ouvertes : tu ne bloqueras jamais sur une validation bancaire.
  • Vérifie dans la doc officielle. Les IA se trompent parfois sur les noms de fonctions : le site de la bibliothèque fait foi.
  • Garde les versions. meteo_v1.py, meteo_v2.py… Tu pourras toujours revenir à la version qui marchait.

⚠️ Erreurs à éviter

  • ❌ Copier-coller le script sans le lire → tu ne sauras pas le corriger. ✅ Relis chaque ligne et commente-la à ta façon avant de lancer.
  • ❌ Demander « un script pour tout faire » → tu reçois du code ingérable. ✅ Découpe : un script = une tâche précise.
  • ❌ Utiliser une API qui réclame ta carte bancaire pour un exercice → tu exposes tes données. ✅ Reste sur des API ouvertes : Open-Meteo, Wikipedia, Nominatim.

🧠 À retenir

  • Une API = une requête → une réponse JSON. Tu l'as vue fonctionner dans ton navigateur avant d'écrire du code.
  • Prompt précis : rôle, 4 contraintes numérotées, « commente chaque bloc », « sans clé », « script complet ».
  • Une erreur se traite en collant le message exact, jamais un résumé.
  • Tu personnalises une modification à la fois, en gardant les versions intermédiaires.
  • Tu sais expliquer ton script ligne par ligne — c'est ça, l'autonomie.

❓ Questions que tout le monde se pose sur l'IA

1. Où l'IA trouve-t-elle ses exemples ?

L'IA apprend dans des data centers (immenses salles de serveurs) appartenant à des sociétés : OpenAI pour ChatGPT, Google pour Gemini, DeepSeek pour DeepSeek.

Elle apprend à partir de milliards de pages web publiques : Wikipedia, forums, livres numérisés, articles. Ce ne sont PAS les ordinateurs des utilisateurs connectés à Internet.

⚠️ Ton PC, ton téléphone, le PC de ton voisin : rien de tout ça n'est utilisé pour entraîner ChatGPT. Seul un data center de la société est utilisé.

2. Peut-on créer une IA simple avec 1000 photos de chats ?

Oui, c'est possible en 30 minutes avec Google Colab (gratuit). Voici les étapes :

  1. Collecte : 500 photos de chats + 500 photos d'autres choses, dans deux dossiers.
  2. Entraînement : un petit réseau de neurones apprend la différence (code fourni ci-dessous).
  3. Test : tu lui montres une nouvelle photo, il dit « Chat » ou « Pas chat ».

🤖 Code Python minimal (Google Colab)

import tensorflow as tf

train = tf.keras.utils.image_dataset_from_directory(
    "dataset/", image_size=(128,128), batch_size=32)

model = tf.keras.Sequential([
    tf.keras.layers.Rescaling(1./255),
    tf.keras.layers.Conv2D(32, 3, activation='relu'),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Conv2D(64, 3, activation='relu'),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(2, activation='softmax')
])

model.compile(optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy'])
model.fit(train, epochs=10)
⚠️ Important : ce programme calcule, il ne « comprend » pas. Il a juste appris quelles formes ressemblent à un chat.

3. IA et robots : quelle différence ?

Un robot = un corps mécanique. L'IA = un cerveau logiciel. On peut les combiner :

Exemple L'IA fait Le robot fait
Aspirateur RoombaDécide où allerSe déplace, aspire
Voiture TeslaReconnaît les piétonsFreine, tourne

Mais la majorité des IA n'ont pas de robot. ChatGPT, Perplexity, Gemini : aucun corps, juste du texte.

Solution privée : utilise une IA locale (Ollama) sur ton propre ordinateur. Aucune donnée ne sort. C'est la seule solution totalement privée. Pour les mots de passe, utilise Bitwarden ou KeePass (gratuits et chiffrés).

5. Chaque pays utilise l'IA différemment

L'IA n'est ni bonne ni mauvaise. Tout dépend de qui l'utilise et pourquoi. Exemples :

  • Médecine — détecter un cancer sur une radio
  • Agriculture — prévoir les récoltes, détecter les maladies des plantes
  • Transport — GPS, voitures autonomes, gestion du trafic
  • Finance — détecter la fraude bancaire
  • Surveillance — reconnaissance faciale dans les lieux publics (usage controversé)
  • Militaire — drones autonomes (usage controversé)
  • Éducation — corriger les copies, adapter les exercices

🔒 Vos données sont-elles en sécurité ?

1. Où sont stockés vos e-mails Gmail ?

Gmail est hébergé dans les data centers de Google, répartis dans le monde entier. Google possède 21 data centers, dont 5 en Europe (Irlande, Pays-Bas, Danemark, Finlande, Belgique).

⚠️ Aucun data center Google dans la plupart des pays du Sud. Vos e-mails, vos documents, et le travail de thèse partagé avec votre encadrant sont stockés à l'étranger — probablement aux États-Unis ou en Europe.

2. Un employé Google peut-il lire vos e-mails ?

Techniquement oui, mais sous contrôle. Google a trois niveaux d'accès :

  1. Vous : accès direct, chiffré.
  2. Employés Google autorisés : accès possible avec une justification professionnelle.
  3. Services Google : accès automatique pour le fonctionnement.

Ce qui protège : vérification des antécédents, accords de confidentialité, journal Access Transparency (chaque accès est enregistré).

Ce qui ne protège PAS : si la justice américaine ordonne l'accès, Google doit obéir — même pour des données stockées en Europe. Le U.S. CLOUD Act étend la juridiction des tribunaux américains à toutes les données contrôlées par des sociétés américaines.

4. « Ça laisse les pays du tiers-monde en retard » — VRAI

Votre intuition est confirmée par la Banque Mondiale :

« L'infrastructure et les systèmes qui sous-tendent l'économie numérique des pays à revenu faible et intermédiaire sont souvent construits, détenus ou exploités par des acteurs qu'ils ne contrôlent ni ne régulent pleinement. »
  • Dépendance technologique : les pays du Sud n'ont pas d'infrastructure IA locale.
  • Fuite de données : les données partent à l'étranger pour être traitées.
  • Biais culturels : les modèles sont entraînés sur des données du Nord, imposant leurs visions du monde.

🧠 Quiz — vérifie ta compréhension

  1. Que renvoie une API quand on l'appelle ?
    (Réponse : du texte structuré, presque toujours en JSON.)
  2. Que faut-il coller à l'IA quand le script plante, et pourquoi ?
    (Réponse : le message d'erreur exact, en entier — il contient le module, la ligne et le chemin.)
  3. À quelle ligne de notre script la communication avec Internet se fait-elle ?
    (Réponse : la ligne requests.get(...) — c'est elle qui envoie la requête.)
  4. Pourquoi demander « sans clé API » dans le prompt ?
    (Réponse : pour éviter une API payante ou exigeant une carte bancaire, et pouvoir exécuter le script immédiatement.)
  5. Comment protéger ton travail contre une mauvaise modification ?
    (Réponse : garder des versions (meteo_v1.py, meteo_v2.py) et une modification à la fois.)

📖 Glossaire

  • API — Interface qui permet à deux logiciels de se parler selon des règles précises (requête → réponse).
  • Endpoint — L'adresse exacte à laquelle tu envoies ta requête (ex. api.open-meteo.com/v1/forecast).
  • JSON — Format de réponse structuré, lisible par les humains et par les programmes.
  • Clé API — Mot de passe qui identifie ton application auprès du service. Jamais dans un code partagé.
  • Module / bibliothèque — Fichier Python écrit par quelqu'un d'autre que tu importes (requests, sys).
  • Requête HTTP — Le message envoyé au serveur : GET lit, POST envoie des données.
