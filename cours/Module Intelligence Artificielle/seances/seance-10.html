💡 Astuce IA — Cmd/Ctrl + Z avant de fermer une session Cursor
Avant de quitter Cursor, passe un Cmd/Ctrl + Z et regarde le diff : tu vois immédiatement ce que l'IA a changé dans ton fichier. Si quelque chose te chiffonne, annule ; sinon ferme l'esprit tranquille. Ce réflexe de 5 secondes t'évite de retrouver le lendemain un mélange de deux versions.

🎯 En une phrase

À la fin de cette séance, tu sauras utiliser Cursor pour décrire une modification en français et la voir s'appliquer dans ton code — ligne par ligne, en comprenant chaque changement avant de l'accepter.

💡 Pourquoi c'est utile pour toi

Avec un chat, tu copies du code d'un onglet vers l'autre et tu espères que rien ne se perd. Cursor va plus loin : tu écris « ajoute un champ email avec validation », l'IA te montre les lignes à ajouter et à supprimer dans ton propre fichier, et tu acceptes ou refuses. Pour un étudiant qui débute, c'est la première fois que modifier du code ressemble à corriger un texte avec un surligneur — en voyant exactement ce qui change.

🔑 Les 3 idées essentielles

  • Cursor est un éditeur avant d'être une IA : c'est VS Code amélioré. Tout ce que tu as appris en séance 9 (terminal, fichiers, raccourcis) fonctionne à l'identique.
  • Le diff, c'est le cœur du sujet : le vert ajoute, le rouge supprime. Aucune modification ne devrait entrer dans ton fichier sans que tu aies lu les deux couleurs.
  • Ton code part vers le modèle : ce que tu as ouvert sert de contexte à l'IA. C'est puissant — et c'est exactement pour ça qu'on n'ouvre pas un travail sensible dans Cursor.
🔧 IA au quotidien — Trouver une info officielle en 10 secondes (mieux que Google)
Tu cherches une date ou un tarif officiel. Tu poses la question à Perplexity : « Quel est le tarif de l'inscription au DSD ? Donne-moi la source officielle. » L'IA te répond en 10 secondes avec le lien vers le document d'origine. Gagne du temps, mais vérifie toujours le lien : l'IA peut se tromper.

Étape 1 — Installer Cursor et importer ton projet (5 min)

📍 cursor.com ⏱️ 5 min

Ce que tu vas faire : télécharger Cursor sur le site officiel, t'inscrire, puis ouvrir ton dossier de travail. Cursor propose une version d'essai gratuite et une formule Hobby gratuite : on n'utilise jamais d'installation « craquée ».

Ce que tu poses comme question (avant d'installer) :

Où télécharger Cursor de façon officielle ? Quelles sont les formules gratuites disponibles pour un étudiant, et quelle est la différence entre la formule Hobby et la formule Pro ?

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de ChatGPT

  1. Téléchargement officiel : cursor.com (le bouton « Download » détecte Windows/macOS/Linux). Méfie-toi des miroirs de téléchargement sur les forums.
  2. Formule Hobby (gratuite) : éditions complétion limitées chaque mois + accès de base au Chat — largement suffisant pour la séance.
  3. Formule Pro (payante) : requêtes illimitées et modèles avancés. Si tu es étudiant, regarde d'abord si ton établissement propose un accès groupé avant de payer.
  4. Premier lancement : Cursor propose d'importer tes réglages et extensions VS Code — accepte, tu retrouves tes habitudes immédiatement.

Import du projet : File → Open Folder… → sélectionne projet-ia. La barre latérale affiche tes fichiers, comme dans VS Code.

Ouvre un dossier de projet, jamais un fichier isolé : l'IA se sert des autres fichiers comme contexte, et un dossier vide donne des réponses génériques.
⚠️ Piège à éviter : n'utilise jamais une version modifiée ou « crackée » de Cursor : outre l'illégalité, ces exécutables contiennent le plus souvent des programmes de minage ou des logiciels espions.

Étape 2 — Modifier le code avec Cmd/Ctrl + K (7 min)

📍 Curseur → raccourci Cmd/Ctrl + K ⏱️ 7 min

Ce que tu vas faire : sélectionner une portion de code, demander une modification en langage naturel, puis lire le diff proposé. C'est la fonctionnalité qui rend Cursor célèbre.

Ce que tu tapes (dans le champ d'édition inline qui s'ouvre sur ta sélection) :

Ajoute un champ email avec validation (regex simple), affiche une erreur en français si l'adresse est invalide, et ne recharge pas la page à l'envoi.

Voici ce que l'IA va probablement te proposer :

🤖 Diff proposé par Cursor

<form id="inscription">
  <label>Nom : <input type="text" name="nom" required></label>
+ <label>Email : <input type="email" name="email" id="email" required></label>
+ <small id="err-email" style="color:#c0392b"></small>
  <button type="submit">S'inscrire</button>
</form>

Et le script associé :

+ const form = document.getElementById("inscription");
+ form.addEventListener("submit", (e) => {
+   const email = document.getElementById("email").value;
+   const ok = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);   // regex simple
+   if (!ok) {
+     e.preventDefault();                                   // on bloque l'envoi
+     document.getElementById("err-email").textContent =
+       "Adresse e-mail invalide (ex. nom@exemple.com).";
+   }
+ });

Lecture du diff : le vert ajoute le champ, le message d'erreur et le bloc de validation ; le rouge (aucun ici) aurait supprimé. Cmd/Ctrl + Entrée accepte, Échap annule.

Sélectionne une fonction à la fois, jamais tout le fichier : le diff reste lisible, et une erreur d'IA reste isolée dans un seul bloc.
⚠️ Piège à éviter : n'accepte jamais un diff « rouge + vert » que tu n'as pas lu : une ligne supprimée peut être ton seul garde-fou (une vérification de sécurité, une condition d'arrêt).

Étape 3 — Poser une question sur ton code existant (5 min)

📍 Chat latéral (Cmd/Ctrl + L) ⏱️ 5 min

Ce que tu vas faire : demander à Cursor d'expliquer un code que tu as reçu — le tien ou celui d'un camarade. C'est l'usage le plus honnête de l'éditeur IA : comprendre, pas produire.

Ce que tu tapes (dans le Chat latéral) :

Explique ce fichier comme à un étudiant de 2ème année qui découvre JavaScript. Donne-moi : 1) ce qu'il fait en une phrase, 2) les 3 lignes clés, 3) une modification que je peux tester sans casser le reste.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de Cursor Chat

1) En une phrase : ce formulaire vérifie que l'adresse e-mail saisie est bien formée avant d'autoriser l'envoi, et affiche un message d'erreur en français sinon.

2) Les 3 lignes clés :

  1. e.preventDefault() — empêche le navigateur d'envoyer le formulaire (sinon la validation ne servirait à rien).
  2. const ok = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email) — la regex : « il y a un @, pas d'espace, et un point après ».
  3. document.getElementById("err-email") — c'est lui qui écrit le message d'erreur dans la page.

3) Modification sûre à tester : ajoute minlength="8" à l'input email — ou change le message d'erreur en anglais. Aucune autre ligne n'est concernée, tu verras l'effet immédiatement.

→ Le Chat cite les fichiers ouverts : c'est pour ça que ta question porte sur un vrai fichier et non sur un copier-coller.

Demande systématiquement « une modification que je peux tester sans casser le reste » : tu progresses par petits pas vérifiables, au lieu de tout casser d'un coup.
⚠️ Piège à éviter : ne pose jamais une question floue comme « c'est quoi ce code ? » — reprends le format « 1 phrase / 3 lignes clés / 1 test » : c'est ce format qui produit une réponse exploitable.

Étape 4 — Générer un fichier complet à partir d'une description (6 min)

📍 Composer du Chat (Cmd/Ctrl + I) ⏱️ 6 min

Ce que tu vas faire : décrire un outil dont tu as besoin et laisser Cursor créer les fichiers. Tu vérifies ensuite chaque fichier créé — c'est l'étape où l'éditeur IA devient un vrai assistant de projet.

Ce que tu tapes (raccourci Cmd/Ctrl + I, mode « Agent ») :

Crée un outil en 2 fichiers : stats.py lit un fichier de notes « Nom;note », affiche la moyenne, la note max/min et un histogramme ASCII des tranches (0-5, 6-10, 11-15, 16-20) ; README.md explique l'utilisation en 5 lignes. Commente le code en français.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de Cursor

« Je crée les deux fichiers dans le dossier ouvert. »

# stats.py — statistiques simples sur un fichier de notes
notes = []
for ligne in open("notes.txt", encoding="utf-8"):   # une ligne « Nom;note »
    if ";" in ligne:
        nom, val = ligne.split(";")
        notes.append(float(val.strip().replace(",", ".")))

moy = sum(notes) / len(notes)
print(f"Moyenne : {moy:.2f} / 20")
print(f"Max : {max(notes):.1f}   Min : {min(notes):.1f}")

tranches = [0] * 4                    # 4 compartiments
for n in notes:
    tranches[min(int(n // 5), 3)] += 1   # 0-5, 6-10, 11-15, 16-20
print("
Histogramme :")
for i, c in enumerate(tranches):
    print(f"{i*5}-{i*5+5} | {'#' * c} ({c})")

Regarde la barre latérale : chaque fichier créé doit être ouvert et relu. Un fichier qu'on n'a jamais ouvert est un fichier qu'on ne maîtrise pas — et c'est souvent celui qui casse.
⚠️ Piège à éviter : ne laisse jamais l'agent écrire dans un dossier qui contient tes travaux en cours : ouvre un sous-dossier test/ pour l'expérimentation.

Étape 5 — Valider, annuler et garder le contrôle (4 min)

📍 Historique des modifications ⏱️ 4 min

Ce que tu vas faire : apprendre à défaire proprement. Un développeur assisté passe autant de temps à annuler qu'à accepter — c'est la compétence qui protège ton travail.

Ce que tu tapes (raccourci Cmd/Ctrl + Z, puis dans le Chat) :

Annule la dernière modification et explique en 2 phrases ce que changeait le code supprimé, pour que je comprenne ce que je viens de refuser.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de Cursor

« Modification annulée, le fichier est revenu à son état précédent.

Ce que faisait le code supprimé : il vérifiait la longueur du mot de passe (8 caractères minimum) avant l'envoi, et bloquait la requête sinon. Sans lui, le formulaire accepte n'importe quelle saisie côté serveur — le navigateur ne protège rien à lui seul.

À retenir : une règle de validation côté « client » (le navigateur) sert au confort ; la vraie sécurité se place côté « serveur ». Si tu retires l'une, garde l'autre. »

→ Tu peux vérifier : git diff (ou l'historique Cursor, Cmd/Ctrl + Shift + H) montre l'état exact du fichier.

Avant une grosse séance de modification, enregistre une copie (fichier_v1.py) ou initie un dépôt git init : en un geste, tu reviens à l'état de départ.
⚠️ Piège à éviter : ne termine jamais une session sur un diff non validé ni refusé — ferme le fichier sans répondre et tu auras, le lendemain, un mélange de deux versions impossibles à démêler.

Comment demander un schéma à l'IA ? Ajoute simplement « avec un schéma en ASCII » à la fin de ton prompt.

Exemple 2 — Automatiser le dépouillement d'un contrôle (département Français)

Situation : 3 copies scannées, notes manuscrites, et un tableau à remplir avant demain.

Ce que tu tapes (Composer, mode Agent) :

Dans dossier copies/, il y a 3 fichiers texte déjà extraits (etudiant1.txt …). Écris depouillement.py qui lit chaque fichier, cherche une note au format « x/20 » ou « x,5 », calcule la moyenne, affiche un tableau aligné (Nom, Note, Appréciation : <10 insuffisant, 10-12 passable, 12-14 bien, 14+ très bien), puis écrit le tout dans notes_final.csv. Commente en français.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de Cursor

# depouillement.py — relevé de notes à partir de textes extraits
import re, glob

def appreciation(n):                     # barème imposé
    return "insuffisant" if n < 10 else "passable" if n < 12            else "bien" if n < 14 else "tres bien"

resultats = []
for chemin in sorted(glob.glob("copies/etudiant*.txt")):
    texte = open(chemin, encoding="utf-8").read()
    m = re.search(r"(\d{1,2}(?:[,.]\d)?)\s*/\s*20", texte)   # « 13,5/20 »
    if m:
        note = float(m.group(1).replace(",", "."))
        resultats.append((chemin.split("/")[-1], note))

print(f"{'Nom':15} {'Note':>6}  Appréciation")
for nom, n in resultats:
    print(f"{nom:15} {n:6.1f}  {appreciation(n)}")

moy = sum(n for _, n in resultats) / len(resultats)
print(f"\nMoyenne de la promotion : {moy:.2f}/20")

with open("notes_final.csv", "w", encoding="utf-8") as f:   # pour le tableur
    f.write("Nom;Note;Appreciation\n")
    for nom, n in resultats:
        f.write(f"{nom};{n};{appreciation(n)}\n")

etudiant1.txt     13.5  bien
etudiant2.txt      9.0  insuffisant
etudiant3.txt     15.0  tres bien

Moyenne de la promotion : 12.50/20

Exemple 3 — Construire un mini-lexique espagnol interactif (département Espagnol)

Situation : révision en 10 minutes par jour : tu veux un programme qui te fait réciter ton lexique et te note.

Ce que tu tapes (Composer) :

Crée quiz.py : charge vocabulario.txt (« espagnol = français »), en choisit 10 au hasard, affiche l'espagnol, demande le français, note « bien » ou « faux — réponse : … », affiche le score final sur 10 et relance tant que l'utilisateur tape « o ». Commente en français.

Voici ce que l'IA va probablement te répondre :

🤖 Réponse typique de Cursor

# quiz.py — récitation du lexique espagnol
import random

paires = []
for ligne in open("vocabulario.txt", encoding="utf-8"):
    if "=" in ligne:
        esp, fra = ligne.split("=", 1)
        paires.append((esp.strip(), fra.strip()))

reponse = "o"
while reponse == "o":                       # rejouer tant que « o »
    epreuve = random.sample(paires, min(10, len(paires)))
    score = 0
    for esp, fra in epreuve:
        saisie = input(f"{esp} = ? ").strip().lower()
        if saisie == fra.lower():
            score += 1
            print("  ✓ bien")
        else:
            print(f"  ✗ faux — réponse : {fra}")
    print(f"Score : {score}/10")
    reponse = input("Encore ? (o/n) ").strip().lower()

Exemple de session :

el apodo = ? apelido
  ✓ bien
la chispa = ? etincelle
  ✗ faux — réponse : étincelle
Score : 9/10
Encore ? (o/n)
Ajoute « garde les 3 mots ratés dans ratés.txt » : ta prochaine session se concentre sur tes vraies faiblesses — c'est la définition même d'une révision efficace.

🎓 Les astuces que personne ne dit

  • Une fonction sélectionnée à la fois. Cmd/Ctrl + K sur un bloc court : le diff reste lisible et l'erreur reste isolée.
  • « Sans casser le reste ». Ajoute cette phrase à toute demande de modification : l'IA limite alors son périmètre.
  • Le format 1 phrase / 3 lignes / 1 test pour expliquer un code : c'est le format qui produit une réponse exploitable.
  • Copie de sécurité avant grosse session. fichier_v1.py ou git init : annuler devient instantané.
  • Agent sur dossier vide. Ouvre toujours un sous-dossier test/ pour expérimenter, jamais tes travaux en cours.
  • Échap est une réponse. Refuser une proposition fait partie du métier — c'est comme ça que le code reste le tien.
  • Rien de sensible à l'écran. Clés, mots de passe, noms d'élèves : jamais dans un fichier ouvert dans Cursor.

⚠️ Erreurs à éviter

  • ❌ Accepter un diff rouge+vert sans le lire → une ligne supprimée peut être ton garde-fou. ✅ Lis les deux couleurs avant Cmd/Ctrl + Entrée.
  • ❌ Une version « craquée » de l'éditeur → illicite et souvent piégée. ✅ Formule gratuite officielle ou essai officiel.
  • ❌ Travailler dans le dossier de tes devoirs → l'agent réécrit tout. ✅ Sous-dossier test/ pour l'expérimentation.

❓ Questions que tout le monde se pose sur l'IA

1. Où l'IA trouve-t-elle ses exemples ?

L'IA apprend dans des data centers (immenses salles de serveurs) appartenant à des sociétés : OpenAI pour ChatGPT, Google pour Gemini, DeepSeek pour DeepSeek.

Elle apprend à partir de milliards de pages web publiques : Wikipedia, forums, livres numérisés, articles. Ce ne sont PAS les ordinateurs des utilisateurs connectés à Internet.

⚠️ Ton PC, ton téléphone, le PC de ton voisin : rien de tout ça n'est utilisé pour entraîner ChatGPT. Seul un data center de la société est utilisé.

2. Peut-on créer une IA simple avec 1000 photos de chats ?

Oui, c'est possible en 30 minutes avec Google Colab (gratuit). Voici les étapes :

  1. Collecte : 500 photos de chats + 500 photos d'autres choses, dans deux dossiers.
  2. Entraînement : un petit réseau de neurones apprend la différence (code fourni ci-dessous).
  3. Test : tu lui montres une nouvelle photo, il dit « Chat » ou « Pas chat ».

🤖 Code Python minimal (Google Colab)

import tensorflow as tf

train = tf.keras.utils.image_dataset_from_directory(
    "dataset/", image_size=(128,128), batch_size=32)

model = tf.keras.Sequential([
    tf.keras.layers.Rescaling(1./255),
    tf.keras.layers.Conv2D(32, 3, activation='relu'),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Conv2D(64, 3, activation='relu'),
    tf.keras.layers.MaxPooling2D(),
    tf.keras.layers.Flatten(),
    tf.keras.layers.Dense(64, activation='relu'),
    tf.keras.layers.Dense(2, activation='softmax')
])

model.compile(optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy'])
model.fit(train, epochs=10)
⚠️ Important : ce programme calcule, il ne « comprend » pas. Il a juste appris quelles formes ressemblent à un chat.

5. Chaque pays utilise l'IA différemment

L'IA n'est ni bonne ni mauvaise. Tout dépend de qui l'utilise et pourquoi. Exemples :

  • Médecine — détecter un cancer sur une radio
  • Agriculture — prévoir les récoltes, détecter les maladies des plantes
  • Transport — GPS, voitures autonomes, gestion du trafic
  • Finance — détecter la fraude bancaire
  • Surveillance — reconnaissance faciale dans les lieux publics (usage controversé)
  • Militaire — drones autonomes (usage controversé)
  • Éducation — corriger les copies, adapter les exercices

🔒 Vos données sont-elles en sécurité ?

1. Où sont stockés vos e-mails Gmail ?

Gmail est hébergé dans les data centers de Google, répartis dans le monde entier. Google possède 21 data centers, dont 5 en Europe (Irlande, Pays-Bas, Danemark, Finlande, Belgique).

⚠️ Aucun data center Google dans la plupart des pays du Sud. Vos e-mails, vos documents, et le travail de thèse partagé avec votre encadrant sont stockés à l'étranger — probablement aux États-Unis ou en Europe.

2. Un employé Google peut-il lire vos e-mails ?

Techniquement oui, mais sous contrôle. Google a trois niveaux d'accès :

  1. Vous : accès direct, chiffré.
  2. Employés Google autorisés : accès possible avec une justification professionnelle.
  3. Services Google : accès automatique pour le fonctionnement.

Ce qui protège : vérification des antécédents, accords de confidentialité, journal Access Transparency (chaque accès est enregistré).

Ce qui ne protège PAS : si la justice américaine ordonne l'accès, Google doit obéir — même pour des données stockées en Europe. Le U.S. CLOUD Act étend la juridiction des tribunaux américains à toutes les données contrôlées par des sociétés américaines.

4. « Ça laisse les pays du tiers-monde en retard » — VRAI

Votre intuition est confirmée par la Banque Mondiale :

« L'infrastructure et les systèmes qui sous-tendent l'économie numérique des pays à revenu faible et intermédiaire sont souvent construits, détenus ou exploités par des acteurs qu'ils ne contrôlent ni ne régulent pleinement. »
  • Dépendance technologique : les pays du Sud n'ont pas d'infrastructure IA locale.
  • Fuite de données : les données partent à l'étranger pour être traitées.
  • Biais culturels : les modèles sont entraînés sur des données du Nord, imposant leurs visions du monde.

📖 Glossaire

  • Diff — Comparaison visuelle de deux versions : vert (ajout), rouge (suppression).
  • Édition inline — Modification demandée directement sur la sélection (Cmd/Ctrl + K).
  • Mode Agent — Mode où l'IA crée et modifie plusieurs fichiers pour atteindre un objectif.
  • Contexte — Fichiers et sélections envoyés au modèle pour nourrir sa réponse.
  • Regex — Motif de recherche sur du texte (ici : valider une adresse e-mail).
  • Reculer (undo) — Annuler la dernière action (Cmd/Ctrl + Z) pour restaurer l'état précédent.
