Module Intelligence Artificielle

Comprendre l'IA, ses usages et ses limites — puis réaliser sa première IA

  1. Accueil
  2. Enseignement
  3. Cours
  4. Module Intelligence Artificielle

Description : Le module Intelligence Artificielle explique l'IA avec des mots très simples, donne des exemples de la vie quotidienne et montre comment réaliser une IA à partir de zéro — même sans avoir jamais programmé.

Niveaux couverts : 2ème année PEP · Débutants complets (aucune connaissance préalable requise) · Prérequis : savoir utiliser un ordinateur et Internet.

Pourquoi apprendre l'IA ?

Ce module n'est pas un cours « d'expert ». Il apprend à utiliser l'IA comme un outil de travail et de révision : chercher une information fiable, résumer un cours, préparer un exposé, réviser un examen, rédiger et traduire, puis écrire du code assisté.

À quoi ça sert concrètement ? À gagner du temps sur les tâches répétitives, à mieux chercher et vérifier l'information, à éviter les erreurs et les hallucinations, et à devenir autonome avec des outils gratuits.

  • Pour comprendre : ce qu'est l'IA, comment elle travaille en mots simples, et la différence entre les assistants de conversation (ChatGPT, Grok, DeepSeek) et les assistants de code (OpenCode, Cursor).
  • Pour étudier : 14 outils d'IA, résumé de cours, fiches de révision, QCM et flashcards.
  • Pour produire : exposés, rapports, correction, traduction FR / EN / AR.
  • Pour programmer : VS Code + Copilot, Cursor, OpenCode + DeepSeek, et un premier agent IA.
  • Pour agir de façon responsable : charte d'usage, cybersécurité, éthique, publication dans une revue Q1.

📋 Comment réaliser une IA en 6 étapes (résumé)

La méthode complète est détaillée dans les cours 04 et 05

  1. Étape 1 — Définir le problème : posez une question précise, par exemple « est-ce que cet e-mail est un spam ? »
  2. Étape 2 — Collecter les données : rassemblez des exemples (vieilles e-mails déjà classés, photos, chiffres…).
  3. Étape 3 — Préparer les données : nettoyez les erreurs et transformez tout en nombres.
  4. Étape 4 — Choisir un modèle : importez un programme prêt à l'emploi (par ex. scikit-learn).
  5. Étape 5 — Entraîner le modèle : montrez les exemples au modèle pour qu'il apprenne.
  6. Étape 6 — Tester et améliorer : vérifiez sur des données jamais vues, mesurez la précision, améliorez.

💡 Conseils

Pour tirer le meilleur parti de ce module

  • Commencez par le Cours 01 puis suivez l'ordre des cours.
  • Choisissez une langue (🇬🇧 ou 🇫🇷) et restez-y pour ne pas confondre les termes.
  • Le Cours 05 utilise Google Colab, gratuit, qui fonctionne directement dans le navigateur — aucune installation n'est nécessaire.
  • Pour le parcours des séances, commencez par la Séance 01 et la page des 152 astuces.
  • Reproduisez chaque exemple, puis adaptez-le à votre propre idée.
