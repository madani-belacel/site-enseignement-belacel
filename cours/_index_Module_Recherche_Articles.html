📘 Module Recherche & Articles — Plan de Formation

Ce module vous guide pas à pas depuis l'installation de l'environnement jusqu'à la reproduction complète des quatre protocoles de recherche. Chaque section contient des cours théoriques et des travaux pratiques.

🗺️ Parcours pédagogique

🌱
22 sessions

Base Cooja / RPL / IoT

Fondamentaux : installation Contiki-NG, simulateur Cooja, protocole RPL, premières simulations.

Cours TP FR
🔧
20+ sessions

RPLMQOS (RPLCB)

Protocole RPL avec mécanisme de Contrôle par Bit (CB) — Comparaison RPL vs RPLCB.

Cours TP RPLCB
⚡
20+ sessions

AER-RPL (RPL-AER)

Routage adaptatif énergétique avec prédiction LSTM, détection d'attaques et métrique MCS.

Cours TP RPL-AER
🎯
20+ sessions

AER-MQoS

Extension multi-objectifs avec QoS, fiabilité des liens, files d'attente WRR et apprentissage Q-learning.

Cours TP AER-MQoS
🛡️
20+ sessions

IDS-IOT (RPL-ClusterIDS)

Système de détection d'intrusion distribué avec clustering adaptatif pour réseaux RPL.

Cours TP IDS-IOT

📋 Structure recommandée

  1. Étape 1 : Commencez par Base Cooja/RPL/IoT — installez l'environnement et faites vos premières simulations
  2. Étape 2 : Passez à RPLMQOS (RPLCB) — comprenez l'extension du protocole RPL
  3. Étape 3 : Étudiez AER-RPL (RPL-AER) — routage adaptatif et prédiction d'énergie
  4. Étape 4 : Approfondissez avec AER-MQoS — QoS multi-objectifs et Q-learning
  5. Étape 5 : Terminez par IDS-IOT — détection d'intrusion distribuée
📦 Codes sources
  • RPLCB — Code source pour l'article Computer Networks
  • RPL-AER — Routage adaptatif énergétique pour l'agriculture de précision
  • AER-MQoS — Routage multi-objectifs QoS pour réseaux IoT
  • IDS-IOT — Détection d'intrusion pour réseaux RPL

💡 Conseil : Clonez les dépôts dans votre espace de travail Contiki-NG avant de commencer les TP.
