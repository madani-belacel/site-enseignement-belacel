Revue Pédagogique — Module Recherche Documentaire M2 DLE

Date : 2026-06-06
Reviewer : OpenCode
Périmètre : Département Français + Anglais / Master 2 - DLE

1. Résumé

Critère Note Commentaire
Exhaustivité ✅ 10 cours + 10 TD complets
Volume PDF ✅ 500-550 KB par fichier (bon contenu LaTeX)
Volume MD ⚠️ MD squelettiques (~30 lignes, renvois PDF)
TD / Exercices ✅ 5 exercices avec corrigés
Contexte M2 DLE ✅ Exercices adaptés au mémoire de didactique

2. Points forts

  • Public cible bien identifié : les exercices sont contextualisés pour M2 DLE
  • Exercices concrets : portails CIEP, British Council, Google Scholar alerts, corpus linguistiques (BNC), OER
  • Progression logique : des notions de base aux outils avancés
  • TD complets : 5 exercices avec corrigés détaillés
  • Volume PDF satisfaisant : 500-550 KB (contenu LaTeX substantiel)

3. Problèmes identifiés

MODÉRÉ : Fichiers MD squelettiques

Exemple : Cours_Recherche_Documentaire_M2_DLE_05_FR.md — 30 lignes seulement.

Tous les cours MD (01-10) se contentent de :

## Plan de la séance
Voir PDF et PPTX associés — 8 sections pédagogiques, 5 exercices TD (1h30).

Le contenu réel est dans les PDF générés par LaTeX, mais les fichiers MD sources ne sont pas autonomes. En cas de perte des PDF, le contenu est irrécupérable.

Recommandation : Ajouter le plan détaillé et les sections principales dans le MD, même en résumé.

MODÉRÉ : Pas de programme de module

Problème : Aucun fichier Programme.md ou plan de module.

Recommandation : Créer un descriptif de module avec : - Objectifs généraux de la Recherche Documentaire pour M2 DLE - Prérequis (méthodologie, niveau de langue) - Planning des 10 séances - Bibliographie générale - Modalités d'évaluation (TD, dossier documentaire, QCM)

MODÉRÉ : Faible différenciation FR/EN

Problème : Les versions FR et EN semblent être des traductions directes. Les ressources mentionnées sont parfois FR (CIEP, Eduscol) même dans la version EN.

Recommandation : Adapter les ressources anglaises pour le public anglophone (ex. remplacer CIEP par British Council, Eduscol par DfE).

MODÉRÉ : Pas d'évaluation des acquis

Les cours manquent d'exercices d'auto-évaluation (QCM, quiz) pour permettre aux étudiants de vérifier leur compréhension.
