3. Problèmes supplémentaires

Contenu squelettique (FR_10 et autres)

Cours_Informatique_ENS_1ère_année_FR_10.md contient uniquement :

## Panorama des services Internet *(10 min)*
Contenu détaillé : voir PDF officiel...
## Moteurs et métamoteurs de recherche *(15 min)*
Contenu détaillé : voir PDF officiel...

Pas de contenu réel — seulement des renvois vers le PDF. Le MD n'est pas autonome.

Fiche Moodle identique dans tous les fichiers

Les sections ## Fiche cours — Plateforme e-learning (Moodle) sont identiques dans tous les cours d'un même niveau (mêmes objectifs transversaux, même évaluation, même bibliographie). Chaque cours devrait avoir ses propres objectifs spécifiques.

Pas de programme de module

Aucun fichier Programme.md dans le module Informatique ENS.

Volume insuffisant

Les PDF font ~77 KB, significativement plus petits que les PDF Réseaux (500-600 KB) ou Recherche Doc (500-550 KB). Bien que ce soit text-only, le volume paraît léger pour des cours de 1h30.
