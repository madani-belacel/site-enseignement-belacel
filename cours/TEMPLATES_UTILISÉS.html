Pipeline de build

  1. Source Markdown (.md)
  2. Conversion LaTeX (.tex) via script Python
  3. Compilation PDF (pdflatex/xelatex)
  4. Fusion avec couverture (PG-fr.docx / PG-An.docx)
  5. Génération PPTX (via python-pptx et template V3)
