Cours 08 — Introduction aux Protocoles de Recherche

Cours 08 — Durée estimée : 2h — Présentation des 4 protocoles

1. Introduction

Ce cours présente quatre protocoles de recherche qui étendent RPL pour répondre à des problématiques spécifiques : contrôle de congestion, prédiction énergétique, qualité de service multi-objectifs, et détection d'intrusion. Ces protocoles font l'objet d'articles scientifiques et leurs codes sources sont disponibles sur GitHub.

2. RPLCB — RPL with Control Bit Mechanism

Référence : Article publié dans Computer Networks (Elsevier)

Dépôt : github.com/madani-belacel/RPLCB

Problématique : RPL standard souffre de congestion aux nœuds proches de la racine. Les paquets sont perdus lorsque les buffers des routeurs sont saturés.

Solution proposée : RPLCB ajoute un bit de contrôle (CB) dans les paquets de données pour signaler la congestion de manière précoce :

  • Un bit dans l'en-tête IPv6 indique l'état de congestion
  • Les nœuds intermédiaires détectent la congestion (buffer occupancy)
  • Le bit CB est activé quand le buffer dépasse un seuil (ex: 60%)
  • Le récepteur adapte son taux d'envoi en fonction du bit CB
  • Résultat : meilleure répartition de la charge, moins de pertes

Mécanisme :

Si (buffer_occupancy > SEUIL) {
    Activer le bit CB dans l'en-tête
    Transférer le paquet normalement
}
Si (paquet reçu avec CB == 1) {
    Réduire le taux d'envoi de 20%
} else {
    Augmenter progressivement le taux d'envoi
}

3. RPL-AER — Adaptive Energy-efficient Routing with LSTM

Référence : Article sur le routage adaptatif énergétique pour l'agriculture de précision

Dépôt : github.com/madani-belacel/RPL-AER

Problématique : Dans les réseaux agricoles, les nœuds ont une énergie limitée et sont exposés à des conditions variables. Le routage doit s'adapter à l'énergie résiduelle et à la fiabilité des liens.

Solution proposée : RPL-AER combine trois innovations :

  • Prédiction LSTM : un modèle d'apprentissage profond (LSTM) prédit la consommation énergétique future basée sur l'historique
  • Détection d'attaques : identification des nœuds malveillants par analyse comportementale
  • Métrique MCS : Multi-Criteria Score combinant énergie résiduelle, qualité du lien (ETX), et niveau de confiance

4. AER-MQoS — Adaptive Energy-efficient Routing with Multi-Objective QoS

Référence : Article sur le routage multi-objectifs QoS

Dépôt : github.com/madani-belacel/AER-MQoS

Problématique : Les applications IoT ont des exigences QoS variées (fiabilité, latence, débit) qui ne sont pas prises en compte par RPL standard.

Solution proposée : AER-MQoS intègre :

  • Fiabilité des liens : estimation dynamique basée sur l'ETX et le SNR
  • Files d'attente WRR : Weighted Round Robin pour prioriser le trafic (urgent vs normal)
  • Q-learning : apprentissage par renforcement pour optimiser le choix des parents selon les objectifs QoS

5. IDS-IOT — Distributed Intrusion Detection System

Référence : Article sur la détection d'intrusion distribuée

Dépôt : github.com/madani-belacel/IDS-IOT

Problématique : Les réseaux RPL sont vulnérables aux attaques (selective forwarding, sinkhole, blackhole). Les solutions de sécurité centralisées ne passent pas à l'échelle.

Solution proposée : IDS-IOT déploie un système de détection distribué :

  • Clustering adaptatif : les nœuds sont organisés en clusters avec des nœuds moniteurs
  • Analyse comportementale : chaque moniteur analyse le trafic de ses voisins
  • Détection multi-attaques : blackhole, selective forwarding, sinkhole, Sybil
  • Réaction : isolation des nœuds malveillants et mise à jour du routage

8. Résumé

Les quatre protocoles de recherche (RPLCB, RPL-AER, AER-MQoS, IDS-IOT) étendent RPL pour répondre à des défis spécifiques : congestion, énergie, QoS et sécurité. Chacun introduit des mécanismes innovants (bit de contrôle, LSTM, Q-learning, clustering distribué) qui peuvent être reproduits et évalués avec Cooja. Le TP 14 permettra de comparer expérimentalement l'un de ces protocoles avec RPL standard.
