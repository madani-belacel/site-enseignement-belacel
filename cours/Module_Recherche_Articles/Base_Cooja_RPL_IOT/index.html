🌱 Base Cooja / RPL / IoT

Module : Recherche & Articles — Base Cooja / RPL / IoT
  • Auteur : Dr. Madani BELACEL
  • Objectif : Acquérir les fondamentaux de l'IoT, du simulateur Cooja, du système d'exploitation Contiki-NG et du protocole de routage RPL
  • Nombre de sessions : 8 cours théoriques + 14 travaux pratiques (22 sessions)
  • Prérequis : Notions de base en réseaux informatiques, commandes Linux, programmation C élémentaire
  • Année : 2025-2026

📋 Parcours pédagogique

Ce parcours vous guide depuis les concepts fondamentaux de l'IoT jusqu'à la réalisation d'un projet de synthèse. Il est structuré en 22 sessions alternant cours théoriques et travaux pratiques.

📖 Cours théoriques

  • Cours 01 Introduction à l'IoT et aux réseaux de capteurs sans fil (WSN)
  • Cours 02 Architecture des réseaux IoT (IEEE 802.15.4, 6LoWPAN, CoAP)
  • Cours 03 Le protocole RPL — Principes fondamentaux
  • Cours 04 Métriques de routage RPL (ETX, OF0, MRHOF)
  • Cours 05 Collecte de métriques dans Cooja
  • Cours 06 Personnalisation du firmware Contiki-NG
  • Cours 07 Modèles de mobilité et d'énergie
  • Cours 08 Introduction aux protocoles de recherche (RPLCB, RPL-AER, AER-MQoS, IDS-IOT)

🔧 Travaux pratiques

  • TP 01 Installation de Contiki-NG et Cooja sur Ubuntu
  • TP 02 Première simulation Cooja (Hello World)
  • TP 03 Communication UDP entre deux nœuds
  • TP 04 Simulation RPL de base avec 3 nœuds
  • TP 05 Analyse des messages DIO, DAO, DIS
  • TP 06 Création de topologies RPL (10+ nœuds)
  • TP 07 Mesure du PDR, latence, consommation d'énergie
  • TP 08 Scripts Python pour l'analyse des résultats
  • TP 09 Modification d'une application UDP dans Contiki-NG
  • TP 10 Ajout de capteurs simulés (température, humidité)
  • TP 11 Simulation avec nœuds mobiles
  • TP 12 Simulation avec récolte d'énergie solaire
  • TP 13 Utilisation des plugins avancés Cooja
  • TP 14 Projet de synthèse : évaluation comparative

📌 Organisation recommandée

  1. Phase 1 (Cours 01-02 + TP 01-03) : Découvrez l'IoT et installez votre environnement de travail
  2. Phase 2 (Cours 03-04 + TP 04-06) : Maîtrisez le protocole RPL et ses métriques
  3. Phase 3 (Cours 05-06 + TP 07-10) : Collectez des métriques et personnalisez le firmware
  4. Phase 4 (Cours 07-08 + TP 11-14) : Modèles avancés, mobilité, énergie et projet final
