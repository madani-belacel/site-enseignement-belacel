TP 13 — Utilisation des Plugins Avancés Cooja

TP 13 — Durée estimée : 2h — Prérequis : TP 01 à TP 12

1. Objectifs

  • Maîtriser la Timeline pour l'analyse temporelle des paquets
  • Configurer l'environnement radio (UDGM, MRM)
  • Créer un plugin Cooja simple en Java
  • Automatiser les simulations avec des scripts Java

2. Timeline View — Analyse temporelle

La Timeline (View → Timeline) affiche graphiquement l'activité de chaque nœud dans le temps :

  • Lignes horizontales : chaque nœud a sa propre ligne
  • Blocs verts : transmission radio (TX)
  • Blocs bleus : réception radio (RX)
  • Blocs gris : CPU actif
  • Flèches : lien entre émission et réception

Utilisation :

  1. Lancez une simulation avec 5 nœuds (1 racine + 4 clients)
  2. Ouvrez la Timeline view
  3. Observez les transmissions : qui envoie, quand, à qui
  4. Zoomez sur un intervalle spécifique pour analyser les collisions

3. Modèles d'environnement radio

Cooja propose plusieurs modèles de propagation radio :

ModèleDescriptionUtilisation
UDGM (Unit Disk Graph Model)Modèle simple : portée fixe avec probabilité constanteTests rapides, scénarios idéaux
UDGM with Distance LossProbabilité de réception diminue avec la distanceScénarios plus réalistes
MRM (Multi-path Ray-tracing Model)Modèle avancé avec réflexions, obstaclesScénarios indoor complexes

Configuration : Simulation → "Radio medium" → choisissez le modèle

4. Scripting Cooja avec Java

Cooja est écrit en Java et permet le scripting pour automatiser les simulations. Créez un fichier MonScript.java :

import org.contikios.cooja.*;
import org.contikios.cooja.plugins.*;
import javax.swing.*;

public class MonScript {
  public static void main(String[] args) {
    // Créer l'interface Cooja
    final Cooja gui = new Cooja();
    gui.start();

    // Créer une simulation
    Simulation sim = gui.createSimulation(null);
    sim.setSimulationName("Simulation_Automatique");

    // Ajouter des nœuds
    MoteInterfaceHandler handler = new MoteInterfaceHandler();
    MoteType moteType = new MoteType();
    moteType.setCompileCommands("make TARGET=cooja mon_app.cooja");

    // Ajouter 10 nœuds
    for(int i=0; i<10; i++) {
      Mote mote = moteType.generateMote(sim);
      mote.getInterfaces().getPosition().setCoordinates(
        Math.random()*100, Math.random()*100, 0);
      sim.addMote(mote);
    }

    // Configurer la durée
    sim.startSimulation();
    try {
      Thread.sleep(60000); // 60s
    } catch(InterruptedException e) {}

    // Arrêter et exporter
    sim.stopSimulation();
    System.out.println("Simulation terminée");
  }
}

5. Création d'un plugin personnalisé

Les plugins Cooja sont des classes Java qui étendent Plugin :

package org.contikios.cooja.plugins;

import org.contikios.cooja.*;
import javax.swing.*;
import java.awt.event.*;

public class MonPlugin extends Plugin {
  private JTextArea textArea;

  public MonPlugin(Simulation sim, Cooja gui) {
    super(sim, gui);
    textArea = new JTextArea();
    textArea.setEditable(false);
    JButton btn = new JButton("Afficher logs");
    btn.addActionListener(e -> refreshLogs());
    add(textArea, BorderLayout.CENTER);
    add(btn, BorderLayout.SOUTH);
  }

  private void refreshLogs() {
    // Parcourir les nœuds et collecter les logs
    StringBuilder sb = new StringBuilder();
    for(Mote m : getSimulation().getMotes()) {
      sb.append("Mote ").append(m.getID())
        .append(": ").append(m.getInterfaces().toString())
        .append("\n");
    }
    textArea.setText(sb.toString());
  }
}

6. Export et analyse avancée

Cooja permet d'exporter les données de simulation dans plusieurs formats :

  • CSC : format natif de Cooja pour sauvegarder/charger des simulations
  • CSV : via les plugins (PowerTracker, Radio Logger)
  • PCAP : export des paquets au format Wireshark (Tools → Radio messages → PCAP)

7. Analyse PCAP avec Wireshark

Activez l'export PCAP dans Radio messages, puis ouvrez le fichier avec Wireshark :

wireshark capture.pcap

Dans Wireshark, vous pouvez filtrer :

  • icmpv6 — pour voir tous les messages RPL
  • icmpv6.type == 155 — messages RPL (DIO, DAO, DIS)
  • udp.port == 8765 — données applicatives
