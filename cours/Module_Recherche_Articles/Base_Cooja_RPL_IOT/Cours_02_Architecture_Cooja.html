Cours 02 Architecture du simulateur Cooja

Cours 02
  • Duree : 1h30
Objectifs pedagogiques
  1. Comprendre l architecture de Cooja
  2. Maitriser l interface utilisateur
  3. Savoir creer et configurer une simulation
  4. Connaitre les plugins disponibles

1. Presentation de Cooja

Cooja est le simulateur reseau de Contiki-NG, ecrit en Java.

2. Plugins essentiels

  • Simulation Control : Demarrer/pause/arreter
  • Network : Vue topologique
  • Radio messages : Paquets echanges
  • PowerTracker : Mesure consommation
  • Mote output : Console des noeuds

3. Fichiers .csc

Les configurations sont au format XML.
