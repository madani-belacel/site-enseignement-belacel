TP 03 — Communication UDP entre deux nœuds

TP 03 — Durée estimée : 2h — Prérequis : TP 02

1. Objectifs

  • Comprendre la communication UDP dans Contiki-NG
  • Créer un client UDP et un serveur UDP
  • Compiler avec make TARGET=cooja
  • Observer les échanges de paquets dans Cooja

2. Structure d'un projet UDP Contiki-NG

Un projet Contiki-NG pour Cooja nécessite :

  • Un fichier source .c avec le code applicatif
  • Un Makefile qui référence Contiki-NG
  • Un fichier project-conf.h optionnel pour la configuration

3. Code du serveur UDP (udp-server.c)

#include "contiki.h"
#include "net/ip/uip.h"
#include "net/ipv6/uip-ds6.h"
#include "net/ip/uip-udp-packet.h"
#include 

#define UDP_PORT 8765

PROCESS(udp_server_process, "UDP Server");
AUTOSTART_PROCESSES(&udp_server_process);

static struct uip_udp_conn *server_conn;

PROCESS_THREAD(udp_server_process, ev, data)
{
  uip_ipaddr_t client_ip;
  PROCESS_BEGIN();

  server_conn = udp_new(NULL, UIP_HTONS(UDP_PORT), NULL);
  udp_bind(server_conn, UIP_HTONS(UDP_PORT));

  printf("Serveur UDP démarré sur le port %d\n", UDP_PORT);

  while(1) {
    PROCESS_YIELD();
    if(ev == tcpip_event) {
      if(uip_newdata()) {
        uip_ipaddr_copy(&client_ip, &UIP_IP_BUF->srcipaddr);
        printf("Reçu de ");
        uip_debug_ipaddr_print(&client_ip);
        printf(" : %s\n", (char *)uip_appdata);

        udp_packet_send(server_conn, "OK", 2);
        printf("Réponse envoyée\n");
      }
    }
  }

  PROCESS_END();
}

4. Code du client UDP (udp-client.c)

#include "contiki.h"
#include "net/ip/uip.h"
#include "net/ipv6/uip-ds6.h"
#include "net/ip/uip-udp-packet.h"
#include 

#define UDP_PORT 8765

PROCESS(udp_client_process, "UDP Client");
AUTOSTART_PROCESSES(&udp_client_process);

static struct uip_udp_conn *client_conn;
static struct etimer et;

PROCESS_THREAD(udp_client_process, ev, data)
{
  uip_ipaddr_t server_ip;
  PROCESS_BEGIN();

  etimer_set(&et, CLOCK_SECOND * 5);

  /* Adresse IPv6 du serveur (adresse lien-local par défaut) */
  uip_ip6addr(&server_ip, 0xfe80, 0, 0, 0, 0, 0, 0, 0);
  client_conn = udp_new(&server_ip, UIP_HTONS(UDP_PORT), NULL);
  udp_bind(client_conn, UIP_HTONS(UDP_PORT));

  printf("Client UDP démarré\n");

  while(1) {
    PROCESS_YIELD();
    if(ev == PROCESS_EVENT_TIMER) {
      printf("Envoi d'un paquet au serveur\n");
      udp_packet_send(client_conn, "Hello Serveur!", 14);
      etimer_restart(&et);
    }
    if(ev == tcpip_event && uip_newdata()) {
      printf("Réponse reçue : %s\n", (char *)uip_appdata);
    }
  }

  PROCESS_END();
}

5. Makefile

CONTIKI = ../..
all: udp-server.cooja udp-client.cooja
include $(CONTIKI)/Makefile.include

Compilation :

make TARGET=cooja

6. Configuration de la simulation

  1. Créez une nouvelle simulation dans Cooja
  2. Ajoutez un nœud Sky avec le firmware udp-server.cooja
  3. Ajoutez un nœud Sky avec le firmware udp-client.cooja
  4. Placez les nœuds à moins de 100 mètres (portée radio)
  5. Ouvrez le panneau Radio messages (Tools → Radio messages)
  6. Démarrez la simulation

7. Observation des résultats

Dans le panneau Log, vous devriez voir :

[ID:1] Serveur UDP démarré sur le port 8765
[ID:2] Client UDP démarré
[ID:2] Envoi d'un paquet au serveur
[ID:1] Reçu de fe80::2 : Hello Serveur!
[ID:1] Réponse envoyée
[ID:2] Réponse reçue : OK

Dans le panneau Radio messages, vous pouvez observer chaque paquet échangé avec ses caractéristiques (taille, type, source, destination).

8. Explication ligne par ligne

  • udp_new() : crée une nouvelle connexion UDP vers une adresse et un port
  • udp_bind() : lie la connexion à un port local
  • udp_packet_send() : envoie un paquet UDP
  • tcpip_event : événement déclenché à la réception d'un paquet
  • uip_newdata() : vérifie si de nouvelles données sont disponibles
  • UIP_IP_BUF->srcipaddr : adresse IP source du paquet reçu

9. Exercices

  1. Modifiez le client pour envoyer un message avec un numéro de séquence incrémenté
  2. Ajoutez un deuxième client et observez les échanges
  3. Mesurez le temps d'aller-retour (RTT) entre l'envoi et la réponse
