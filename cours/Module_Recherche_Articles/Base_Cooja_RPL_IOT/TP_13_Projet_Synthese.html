TP 13 — Projet de Synthèse : Évaluation Comparative RPL

TP 13 — Durée : 4h — Prérequis : tous les TP précédents
🎯 Objectifs
  • Mettre en œuvre l'ensemble des compétences acquises
  • Comparer OF0, MRHOF et un paramétrage personnalisé
  • Rédiger un rapport d'analyse

1. Cahier des charges

Vous devez réaliser une étude comparative complète de 3 configurations RPL :

  1. Configuration A : OF0 — RPL_CONF_OF = rpl_of0, paramètres par défaut
  2. Configuration B : MRHOF standard — RPL_CONF_OF = rpl_mrhof, paramètres par défaut
  3. Configuration C : MRHOF optimisé — MRHOF avec hysteresis = 128, DIO_INTERVAL_MIN = 10

2. Topologie de test

Grille 5×4 (20 nœuds) : 1 serveur (racine) + 19 clients. Transmission range = 70m. Perte = 10%. Durée = 600s.

3. Métriques à mesurer

MétriqueMéthode de mesure
PDRRX/TX par nœud, PDR moyen global
Latence (RTT)Timestamp avant envoi, après réception
ÉnergiePowerTracker (mJ total)
Profondeur maxNombre de sauts max dans le DODAG
OverheadNombre de DIO/DAO émis
Temps de convergenceTemps pour que tous les nœuds soient connectés

4. Plan d'expérience

  1. Pour chaque configuration, créez une simulation
  2. Lancez la simulation et exportez les logs
  3. Exécutez le script Python d'analyse
  4. Relevez les métriques dans un tableur
  5. Générez des graphiques comparatifs

5. Rendu attendu

📦 Livrables (rapport de 5-10 pages)
  • Introduction : objectifs, contexte
  • Méthodologie : configurations, topologie, métriques
  • Résultats : tableaux, graphiques pour chaque métrique
  • Analyse : interprétation des résultats, classement
  • Conclusion : recommandations, perspectives
  • Annexes : scripts Python, captures d'écran

6. Script d'analyse complet

#!/usr/bin/env python3
# analyse_comparative.py - Analyse multi-configurations
import re, sys, json
from collections import defaultdict

def analyse_log(fichier):
    log = open(fichier).read()
    tx = defaultdict(int)
    rx = defaultdict(int)
    rtt = []
    dio = len(re.findall(r'DIO', log))
    dao = len(re.findall(r'DAO', log))
    for line in log.split('\n'):
        m = re.search(r'\[ID:(\d+)\] Sending request', line)
        if m: tx[int(m.group(1))] += 1
        m = re.search(r'\[ID:(\d+)\] Received request', line)
        if m: rx[int(m.group(1))] += 1
        m = re.search(r'RTT: (\d+)', line)
        if m: rtt.append(int(m.group(1)))
    total_tx = sum(tx.values())
    total_rx = sum(rx.values())
    pdr = (total_rx / total_tx * 100) if total_tx > 0 else 0
    return {
        'pdr': round(pdr, 1),
        'rtt_moy': round(sum(rtt)/len(rtt), 1) if rtt else 0,
        'dio': dio, 'dao': dao,
        'tx': total_tx, 'rx': total_rx
    }

if __name__ == '__main__':
    for config in ['OF0', 'MRHOF', 'MRHOF_opt']:
        f = f'COOJA_{config}.log'
        try:
            r = analyse_log(f)
            print(f"\n=== {config} ===")
            for k, v in r.items():
                print(f"  {k}: {v}")
        except: print(f"Fichier {f} non trouvé")
