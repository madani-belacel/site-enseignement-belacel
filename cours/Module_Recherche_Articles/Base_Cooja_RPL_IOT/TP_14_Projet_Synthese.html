TP 14 — Projet de Synthèse : Évaluation Comparative

TP 14 — Durée estimée : 6h (2 sessions) — Projet final du module

1. Objectifs

  • Concevoir une simulation comparative entre RPL standard et un protocole de recherche
  • Définir un jeu de métriques pertinentes (PDR, énergie, latence)
  • Exécuter 5 simulations avec des seeds aléatoires différentes
  • Analyser les résultats et créer des graphiques comparatifs
  • Rédiger un rapport de synthèse

6. Analyse statistique

Pour chaque métrique, calculez :

Moyenne = somme des valeurs / 5
Écart-type = sqrt(somme((x - moyenne)²) / 4)
Intervalle de confiance à 95% = moyenne ± 1.96 × (écart-type / sqrt(5))

7. Graphiques à produire

Générez au moins 4 graphiques :

  1. PDR comparatif : barres avec intervalles de confiance
  2. Latence comparée : boîtes à moustaches (boxplot)
  3. Énergie totale : barres groupées par protocole
  4. Messages de contrôle : nombre de DIO/DAO émis

Exemple avec matplotlib :

import matplotlib.pyplot as plt
import numpy as np

protocoles = ['RPL Standard', 'RPLCB']
pdr_moyen = [91.2, 96.8]
pdr_std = [2.1, 1.5]

plt.bar(protocoles, pdr_moyen, yerr=pdr_std,
        capsize=5, color=['blue', 'green'])
plt.ylabel('PDR (%)')
plt.title('Comparaison du PDR')
plt.savefig('comparaison_pdr.png')

8. Rapport de synthèse

Rédigez un rapport contenant :

  1. Introduction : contexte, problématique, protocoles comparés
  2. Méthodologie : plan d'expérience, paramètres, topologie
  3. Résultats : tableaux et graphiques pour chaque métrique
  4. Discussion : analyse des résultats, avantages/inconvénients, limites
  5. Conclusion : quel protocole est le meilleur et pour quelles raisons
