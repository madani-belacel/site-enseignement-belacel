TP 06 — Création de topologies RPL (10+ nœuds)

TP 06 — Durée estimée : 2h — Prérequis : TP 04, TP 05

1. Objectifs

  • Créer des topologies de grande taille (10, 20, 30 nœuds)
  • Expérimenter avec des topologies en grille et aléatoires
  • Utiliser le visualiseur de topologie de Cooja
  • Analyser la structure du DODAG en fonction de la topologie
  • Observer les relations parent-enfant dans différents déploiements

2. Topologie en grille (Grid)

Une topologie en grille place les nœuds à intervalles réguliers. C'est utile pour simuler un déploiement structuré (ex: champs agricoles).

Configuration de la grille 3×4 (12 nœuds)

  1. Créez une simulation nommée Topologie_Grille
  2. Ajoutez 1 racine UDP server (nœud 1) positionnée au centre (100, 50)
  3. Ajoutez 11 clients UDP positionnés en grille 3×4
Positions de la grille 3×4 (espacement 40m) :
(20,10) (60,10) (100,10) (140,10)
(20,50) (60,50) (100,50) (140,50)  ← racine au centre
(20,90) (60,90) (100,90) (140,90)
  1. Réglez la portée radio à 60 mètres (UDGM : Transmission range = 60 m)
  2. Démarrez la simulation et observez la formation du DODAG

3. Topologie aléatoire (Random)

Une topologie aléatoire simule un déploiement non structuré, plus réaliste pour les WSN.

Configuration aléatoire avec 20 nœuds

  1. Créez une simulation nommée Topologie_Aleatoire
  2. Ajoutez 1 racine UDP server (position fixe : 80, 80)
  3. Ajoutez 19 clients avec positions aléatoires :
// Script pour générer des positions aléatoires (200x200)
x = rand() % 200
y = rand() % 200
  1. Réglez la portée radio à 50 mètres
  2. Démarrez la simulation

4. Utilisation du visualiseur de topologie

Cooja offre une vue réseau qui montre les connexions entre nœuds :

  • Les lignes en trait plein indiquent les liens parents-enfants
  • Les lignes en pointillé indiquent les voisins radio (portée mais pas forcément parent)
  • La couleur des nœuds peut indiquer le rank (clair = faible, foncé = élevé)

Pour exporter la topologie : Tools → Topology visualizer (ou capture d'écran)

Pour chaque configuration, notez :

  • La profondeur maximale du DODAG (rank le plus élevé)
  • Le nombre de voisins par nœud (densité du réseau)
  • Le nombre de sauts moyen pour atteindre la racine
  • Les nœuds qui n'ont qu'un seul parent potentiel (goulots d'étranglement)

6. Impact de la densité sur le DODAG

Expérience : faites varier la portée radio et observez l'impact sur la structure du DODAG.

7. Exercices

  1. Créez une topologie en grille 5×6 (30 nœuds) avec la racine au centre. Combien de niveaux de profondeur ?
  2. Dans une topologie aléatoire de 20 nœuds, identifiez les nœuds qui ont le plus de parents potentiels
  3. Comparez le nombre de messages DIO émis dans les topologies grille et aléatoire (utilisez le Radio Logger)
  4. Quelle est la topologie la plus résiliente (meilleure connectivité) ? Justifiez
