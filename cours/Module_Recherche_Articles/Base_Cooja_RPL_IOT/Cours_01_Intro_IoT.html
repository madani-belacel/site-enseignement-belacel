Cours 01 — Introduction à l'IoT et aux Réseaux de Capteurs Sans Fil (WSN)

Cours 01 — Durée estimée : 2h — Chapitre introductif

1. Qu'est-ce que l'Internet des Objets (IoT) ?

L'Internet des Objets (IoT) désigne l'interconnexion d'objets physiques équipés de capteurs, d'actionneurs et de capacités de communication via Internet. Contrairement aux réseaux traditionnels où les utilisateurs génèrent le trafic, les objets communiquent entre eux de manière autonome (M2M).

Un système IoT typique comprend :

  • Des capteurs : mesurent des grandeurs physiques (température, humidité, pression, lumière)
  • Des actionneurs : agissent sur l'environnement (ouvrir une vanne, allumer une lampe)
  • Des modules de communication : transmettent les données (radio, Wi-Fi, LoRa, BLE)
  • Une infrastructure réseau : achemine les données vers des plateformes de traitement
  • Des applications : analysent et visualisent les données collectées

2. Architecture en couches de l'IoT

L'architecture IoT se décompose généralement en trois couches :

Couche Perception

Elle regroupe les objets physiques (capteurs, actionneurs, RFID) qui interagissent avec l'environnement. Les nœuds capteurs sont souvent appelés motes dans le contexte des WSN.

Couche Réseau

Assure la transmission des données des capteurs vers les serveurs de traitement. Elle utilise des protocoles comme IPv6, 6LoWPAN, RPL, CoAP. C'est la couche la plus critique en termes de consommation d'énergie.

Couche Application

Fournit les services aux utilisateurs finaux : visualisation, analyse, alertes, prise de décision. Exemples : plateformes ThingsBoard, AWS IoT, Azure IoT Hub.

3. Réseaux de Capteurs Sans Fil (WSN)

Un WSN est un réseau composé de nœuds capteurs autonomes distribués spatialement qui coopèrent pour surveiller des conditions physiques ou environnementales.

Caractéristiques principales :

  • Contraintes énergétiques : les nœuds fonctionnent sur batterie, la durée de vie est cruciale
  • Auto-organisation : le réseau doit se configurer sans intervention humaine
  • Passage à l'échelle : support de quelques dizaines à plusieurs milliers de nœuds
  • Environnement dynamique : pannes, interférences radio, mobilité
  • Topologie variable : les nœuds peuvent être ajoutés ou retirés dynamiquement

5. Défis techniques

  • Énergie : maximiser l'autonomie des nœuds (duty-cycling, récolte d'énergie)
  • Scalabilité : gérer des réseaux de grande taille avec des protocoles adaptés
  • Sécurité : protéger les données et le réseau contre les intrusions (chiffrement, authentification)
  • Qualité de service (QoS) : garantir fiabilité, latence, débit selon l'application
  • Interopérabilité : faire communiquer des objets de différents fabricants
  • Fiabilité : assurer la transmission malgré les pertes radio et les pannes

6. Contiki-NG et Cooja

Contiki-NG est un système d'exploitation open-source pour l'IoT, successeur de Contiki. Il supporte de nombreuses plateformes matérielles (Zolertia Z1, CC2538, TI CC2650) et implémente les protocoles standards (6LoWPAN, RPL, CoAP).

Cooja est le simulateur intégré à Contiki-NG qui permet d'exécuter et de déboguer des applications sans matériel physique. Il offre une vue réseau, une timeline et des outils d'analyse.

7. Résumé

Ce cours a introduit les concepts fondamentaux de l'IoT et des WSN. Les points clés à retenir sont : l'architecture en trois couches, les caractéristiques des WSN (énergie, auto-organisation, passage à l'échelle), les applications variées et les défis techniques. Les prochains cours approfondiront les protocoles réseau spécifiques à l'IoT.
