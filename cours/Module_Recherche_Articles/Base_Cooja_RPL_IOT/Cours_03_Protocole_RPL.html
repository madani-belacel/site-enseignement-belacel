Cours 03 — Le Protocole RPL : Principes Fondamentaux

Cours 03 — Durée estimée : 2h30 — Référence : RFC 6550
🎯 Objectifs d'apprentissage
  • Comprendre le DODAG (Destination Oriented Directed Acyclic Graph)
  • Maîtriser le concept de rank
  • Distinguer DIO, DAO, DIS
  • Comprendre le Trickle Timer
  • Connaître OF0 et MRHOF

1. Introduction à RPL

RPL (RFC 6550) est le protocole de routage standard pour les réseaux LLN (Low-Power and Lossy Networks). Il construit un DODAG orienté vers la racine, utilise le rank pour éviter les boucles, et emploie trois messages de contrôle (DIO, DAO, DIS) régulés par Trickle Timer.

2. Le DODAG

Graphe acyclique orienté partant de la racine vers les feuilles. Propriétés : orientation vers la racine, acyclique, plusieurs instances possibles.

3. Le Rank

Entier représentant la distance logique à la racine (rank=256 pour la racine). Le rank augmente en s'éloignant. Un nœud ne peut pas être parent d'un nœud de rank supérieur.

4. Messages de contrôle

MessageRôleDirection
DIOAnnonce le DODAG (configuration, rank)Racine → Feuilles
DAOEnregistre les routes descendantesFeuilles → Racine
DISSollicite un DIO d'un voisinNouveau nœud → Réseau

5. Fonctions Objectifs

  • OF0 (RFC 6552) : rank = 256 × nombre de sauts
  • MRHOF (RFC 6719) : rank = parent_rank + ETX(parent) avec hystérésis
