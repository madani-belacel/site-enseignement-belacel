TP 01 — Installation de Contiki-NG et Cooja sur Ubuntu

TP 01 — Durée estimée : 2h — Prérequis : Ubuntu 20.04/22.04

1. Objectifs

  • Installer les dépendances système nécessaires à Contiki-NG
  • Cloner le dépôt Contiki-NG depuis GitHub
  • Configurer la variable d'environnement CONTIKI
  • Compiler et lancer le simulateur Cooja
  • Vérifier le bon fonctionnement de l'environnement

2. Prérequis système

Contiki-NG nécessite un système Linux (Ubuntu 20.04 LTS ou 22.04 LTS recommandé). Assurez-vous d'avoir au moins 4 Go de RAM et 5 Go d'espace disque libre.

3. Installation des dépendances

Ouvrez un terminal et exécutez les commandes suivantes :

sudo apt update
sudo apt upgrade -y
sudo apt install -y build-essential git openjdk-11-jdk ant \
  flex bison libtool-bin pkg-config libboost-dev \
  libboost-system-dev libboost-thread-dev \
  libboost-program-options-dev libboost-test-dev \
  libglib2.0-dev libssl-dev unzip wget python3 python3-pip

Note : Si openjdk-11-jdk n'est pas disponible, vous pouvez utiliser openjdk-17-jdk ou openjdk-8-jdk.

4. Clonage de Contiki-NG

Créez un répertoire de travail et clonez le dépôt officiel :

mkdir ~/contiki-ng
cd ~/contiki-ng
git clone https://github.com/contiki-ng/contiki-ng.git .

5. Configuration de la variable CONTIKI

Ajoutez la variable d'environnement dans votre fichier ~/.bashrc :

echo "export CONTIKI=~/contiki-ng" >> ~/.bashrc
source ~/.bashrc

Vérifiez que la variable est bien définie :

echo $CONTIKI

Le résultat doit afficher /home/votre_nom/contiki-ng.

6. Compilation et lancement de Cooja

Rendez-vous dans le répertoire Cooja et lancez la compilation :

cd $CONTIKI/tools/cooja
make cooja

Cette commande compile Cooja avec Apache Ant. À la fin, la fenêtre du simulateur devrait s'ouvrir automatiquement.

Vous pouvez aussi lancer Cooja via la commande Ant :

cd $CONTIKI/tools/cooja
ant run

7. Test de compilation d'un exemple

Pour vérifier que la chaîne de compilation fonctionne, compilez l'exemple hello-world :

cd $CONTIKI/examples/hello-world
make TARGET=cooja

Si la compilation réussit, un fichier hello-world.cooja est généré dans le répertoire.

8. Débogage des problèmes courants

ProblèmeCauseSolution
Java not foundJDK manquantInstaller openjdk-11-jdk
Ant: command not foundAnt manquantsudo apt install ant
Makefile: XX: recipe failedDépendance manquanteVérifier les paquets listés en section 3
Cooja ne se lance pasProblème d'affichageVérifier qu'un serveur X est actif
Erreur de version JavaJava 8+ requissudo update-alternatives --config java

9. Vérification finale

Une fois Cooja lancé, vous devriez voir :

  • Une fenêtre avec une barre de menus (File, Edit, Simulation, Tools, Help)
  • Le panneau "Network" pour visualiser les nœuds
  • Le panneau "Timeline" pour l'analyse temporelle

Félicitations ! Votre environnement Contiki-NG/Cooja est opérationnel. Vous êtes prêt pour le TP suivant.

10. Livrables

  • Capture d'écran de Cooja lancé avec succès
  • Sortie de echo $CONTIKI
  • Sortie de la compilation hello-world
