Cours 04 — Métriques de Routage RPL (ETX, OF0, MRHOF)

Cours 04 — Durée estimée : 2h — Références : RFC 6551, RFC 6552, RFC 6719

1. Introduction aux métriques de routage RPL

Les métriques de routage permettent d'évaluer la qualité des liens et des chemins dans un réseau RPL. La fonction objectif (OF) utilise ces métriques pour calculer le rank et sélectionner le meilleur parent. Les métriques sont définies dans la RFC 6551.

2. ETX — Expected Transmission Count

L'ETX est la métrique la plus utilisée dans RPL. Elle représente le nombre moyen de transmissions nécessaires pour envoyer avec succès un paquet sur un lien.

Calcul de l'ETX :

ETX = 1 / (df × dr)

Où :

  • df (delivery forward) : probabilité qu'un paquet soit reçu par le destinataire
  • dr (delivery reverse) : probabilité qu'un accusé de réception soit reçu par l'émetteur

Exemple : si df = 0.8 et dr = 0.9, alors ETX = 1 / (0.8 × 0.9) = 1.39. Cela signifie qu'en moyenne, 1.39 transmissions sont nécessaires pour qu'un paquet arrive à destination.

Propriétés de l'ETX :

  • ETX = 1 pour un lien parfait (aucune perte)
  • ETX augmente quand la qualité du lien se dégrade
  • ETX tend vers l'infini quand le lien devient inutilisable
  • L'ETX d'un chemin est la somme des ETX de chaque lien

Implémentation dans Contiki-NG : L'ETX est calculé via les paquets de données et les accusés de réception au niveau MAC. Le module os/net/mac/ maintient une estimation continue de la qualité des liens.

3. OF0 — Objective Function 0 (Min Hop Rank)

OF0 (RFC 6552) est la fonction objectif la plus simple. Elle base le choix du parent sur le nombre de sauts (hop count).

Calcul du rank avec OF0 :

Rank = 256 × hop_count

Où hop_count est le nombre de sauts depuis la racine. La racine a un rank de 256.

Caractéristiques :

  • Simple et prévisible
  • Ne tient pas compte de la qualité des liens
  • Peut choisir des chemins longs mais de mauvaise qualité
  • Utile comme solution de base ou de référence
  • Moins performant en environnement avec pertes

Remarque : l'échelle du rank dans Contiki-NG utilise un facteur de 256 (ou 128 selon la configuration). Un nœud fils doit avoir un rank strictement supérieur à celui de son parent.

4. MRHOF — Minimum Rank with Hysteresis Objective Function

MRHOF (RFC 6719) est la fonction objectif la plus utilisée dans les réseaux RPL réels. Elle utilise l'ETX comme métrique principale et intègre un mécanisme d'hystérésis pour éviter les changements fréquents de parent (oscillations).

Calcul du rank avec MRHOF :

Rank = parent_rank + ETX(link) × MinHopRankIncrease

Où MinHopRankIncrease est une constante (généralement 256).

4.1 Mécanisme d'hystérésis

L'hystérésis évite les changements de parent trop fréquents qui déstabilisent le réseau. Un nœud change de parent uniquement si :

ETX(nouveau_parent) < ETX(parent_actuel) - SEUIL_HYSTERESIS

Où SEUIL_HYSTERESIS est généralement 64 (en unités de rank).

Avantages :

  • Réduit les oscillations de routage
  • Évite les changements inutiles pour de petites variations de qualité
  • Améliore la stabilité du DODAG

4.2 Sélection du parent préféré

Avec MRHOF, un nœud :

  1. Collecte les DIO de ses voisins (contenant leur rank et l'ETX du lien)
  2. Calcule son propre rank potentiel pour chaque voisin
  3. Sélectionne le voisin qui minimise son rank
  4. Vérifie la condition d'hystérésis avant de changer

6. Autres métriques RPL

La RFC 6551 définit également d'autres métriques :

  • Latence : délai de transmission sur un lien
  • Énergie résiduelle : niveau de batterie restant
  • Débit : capacité du lien
  • Fiabilité : taux de succès des transmissions

Ces métriques peuvent être combinées via une fonction objectif personnalisée.

7. Configuration dans Contiki-NG

La fonction objectif est configurée dans project-conf.h :

#define RPL_CONF_OF rpl_mrhof   /* Utilise MRHOF */
/* ou */
#define RPL_CONF_OF rpl_of0     /* Utilise OF0 */

Les paramètres de MRHOF :

#define RPL_CONF_MINHOPRANKINC  256
#define RPL_CONF_ETX              /* Active le calcul ETX */
#define RPL_CONF_HYSTERESIS      64

8. Résumé

L'ETX est la métrique de qualité de lien la plus utilisée dans RPL. OF0 utilise le nombre de sauts (simple mais peu performant) tandis que MRHOF utilise l'ETX avec hystérésis (plus performant et stable). Le choix de la fonction objectif impacte directement la qualité et la stabilité du routage.
