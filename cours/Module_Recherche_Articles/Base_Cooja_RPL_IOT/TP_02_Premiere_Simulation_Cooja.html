TP 02 — Première Simulation Cooja (Hello World)

TP 02 — Durée estimée : 1h30 — Prérequis : TP 01 (Cooja installé)

1. Objectifs

  • Créer une nouvelle simulation dans Cooja
  • Ajouter des nœuds de type Sky mote
  • Écrire et compiler un programme Hello World simple
  • Exécuter la simulation et observer les messages dans le panneau de logs
  • Comprendre l'interface de Cooja (Network view, Timeline, Log)

2. Lancement de Cooja

Depuis un terminal :

cd $CONTIKI/tools/cooja
make cooja

Patientez pendant la compilation. La fenêtre principale de Cooja s'ouvre.

3. Création d'une nouvelle simulation

  1. Menu File → New simulation
  2. Donnez un nom : HelloWorld_Simulation
  3. Laissez les paramètres par défaut (Radio medium : UDGM, Start delimiter : 1 s)
  4. Cliquez sur Create

La fenêtre principale affiche maintenant l'onglet "Network" vide.

4. Ajout de nœuds

  1. Menu Nodes → Add node (ou clic droit dans la vue Network)
  2. Sélectionnez Sky mote comme type de nœud
  3. Cliquez sur Create — un nœud apparaît dans la vue
  4. Répétez pour ajouter un second nœud
  5. Positionnez les nœuds à environ 50 mètres de distance

5. Écriture du programme Hello World

Créez un fichier hello-world.c dans votre répertoire de travail :

#include "contiki.h"
#include 

PROCESS(hello_world_process, "Hello World Process");
AUTOSTART_PROCESSES(&hello_world_process);

PROCESS_THREAD(hello_world_process, ev, data)
{
  PROCESS_BEGIN();

  printf("Hello World! Je suis un nœud Cooja.\n");
  printf("Mon nom est : %s\n", PROCESS_NAME());

  PROCESS_END();
}

6. Compilation et association du firmware

Dans Cooja, pour chaque nœud :

  1. Sélectionnez le nœud dans la vue Network
  2. Onglet "Mote" → Compiler
  3. Collez le code source dans l'éditeur
  4. Cliquez sur Compile — la compilation doit réussir sans erreur
  5. Répétez pour l'autre nœud

Vous pouvez aussi créer un projet séparé avec un Makefile :

CONTIKI = ../..
all: hello-world.cooja
include $(CONTIKI)/Makefile.include

Puis compiler avec :

make TARGET=cooja hello-world.cooja

7. Exécution de la simulation

  1. Ouvrez le panneau Log (View → Log)
  2. Cliquez sur le bouton Start (triangle vert) dans la barre d'outils
  3. Observez les messages dans le panneau Log : chaque nœud affiche "Hello World!"

8. Exploration de l'interface Cooja

Network view : affiche la position des nœuds et les connexions radio. Les lignes pointillées indiquent les liens de communication possibles. La couleur des nœuds change selon leur état.

Timeline : affiche une chronologie des événements (transmissions, réceptions, éveils). Utile pour analyser le comportement temporel du réseau.

Log : affiche les messages de débogage émis par les nœuds via printf(). Chaque message est horodaté et identifié par le nœud émetteur.

Radio messages : outil d'analyse des paquets échangés (activation via Tools → Radio messages).

9. Exercices

  1. Modifiez le programme pour que chaque nœud affiche son ID : printf("Node ID: %d\n", node_id);
  2. Ajoutez une boucle pour envoyer "Hello" toutes les 5 secondes en utilisant etimer
  3. Ajoutez un troisième nœud et vérifiez qu'il s'affiche aussi
