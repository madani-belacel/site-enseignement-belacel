TP 01 — Installation de Contiki-NG et Cooja

TP 01 — Durée : 2h — Prérequis : Ubuntu 20.04/22.04
🎯 Objectifs
  • Installer les dépendances
  • Cloner Contiki-NG
  • Configurer CONTIKI
  • Compiler et lancer Cooja
  • Compiler hello-world

1. Dépendances

$ sudo apt update && sudo apt upgrade -y
$ sudo apt install -y build-essential git openjdk-11-jdk ant \
  flex bison libtool-bin pkg-config libboost-dev \
  libboost-system-dev libboost-thread-dev \
  libboost-program-options-dev libboost-test-dev \
  libglib2.0-dev libssl-dev unzip wget python3 python3-pip
✅ Vérification 
$ java -version
$ git --version
$ ant -version
openjdk version "11.0.22"
git version 2.34.1
Apache Ant(TM) 1.10.12
⚠️ Dépannage Java

Si openjdk-11-jdk indisponible : sudo apt install openjdk-17-jdk puis sudo update-alternatives --config java

2. Clonage

$ cd /home/madani
$ git clone https://github.com/contiki-ng/contiki-ng.git
$ ls contiki-ng/
✅ Vérification arch CODE_OF_CONDUCT.md examples LICENSE.md Makefile.include os README.md tests tools

3. Variable CONTIKI

$ echo 'export CONTIKI=/home/madani/contiki-ng' >> ~/.bashrc
$ source ~/.bashrc
$ echo $CONTIKI

Résultat : /home/madani/contiki-ng

4. Lancement de Cooja

$ cd $CONTIKI/tools/cooja
$ make cooja
✅ Vérification

Fenêtre Cooja avec menus File, Edit, Simulation, Tools, Help. Panneaux Network et Timeline.

5. Test hello-world

$ cd $CONTIKI/examples/hello-world
$ make TARGET=cooja

Résultat : hello-world.cooja généré.
