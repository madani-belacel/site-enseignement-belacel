Cours 01 — Introduction à Contiki-NG et à l'écosystème IoT

Cours 01 — Durée estimée : 2h — Chapitre introductif
🎯 Objectifs d'apprentissage
  • Comprendre ce qu'est Contiki-NG et son rôle dans l'IoT
  • Connaître l'architecture générale de Contiki-NG
  • Identifier les composants de l'écosystème IoT (WSN, RPL, 6LoWPAN, CoAP)
  • Comprendre le rôle du simulateur Cooja
  • Savoir naviguer dans l'arborescence du code source

1. Qu'est-ce que Contiki-NG ?

Contiki-NG (Contiki Next Generation) est un système d'exploitation open-source pour l'Internet des Objets (IoT), successeur de Contiki OS développé initialement par Adam Dunkels à SICS (Suède).

Contiki-NG supporte de nombreuses plateformes matérielles (Zolertia Z1, CC2538DK, TI CC2650, nRF52840) et implémente les protocoles standards : 6LoWPAN (RFC 4944), RPL (RFC 6550), CoAP (RFC 7252), MQTT-SN.

2. Architecture de Contiki-NG

contiki-ng/
├── arch/          # Code spécifique aux plateformes
├── examples/      # Exemples (hello-world, rpl-udp, etc.)
├── os/            # Noyau, protocoles réseau, services
│   ├── net/       # Pile réseau (IPv6, 6LoWPAN, RPL, UDP)
│   ├── sys/       # Services système (processus, timers)
│   └── lib/       # Bibliothèques (coap, mqtt, json)
├── tools/         # Cooja, serialdump, tunslip6
└── tests/         # Tests automatisés

3. Le modèle de processus protothreads

Contiki-NG utilise des protothreads : des threads coopératifs légers avec une seule pile.

PROCESS(mon_processus, "Description");
AUTOSTART_PROCESSES(&mon_processus);

PROCESS_THREAD(mon_processus, ev, data)
{
  PROCESS_BEGIN();

  while(1) {
    PROCESS_WAIT_EVENT();
    /* Traitement */
  }

  PROCESS_END();
}

4. Le simulateur Cooja

Cooja est un simulateur de réseau pour Contiki-NG, écrit en Java. Il permet d'exécuter du code réellement compilé, de visualiser les échanges radio, de mesurer l'énergie, et d'analyser avec des plugins.

6. Exemple : Hello World

#include "contiki.h"
#include <stdio.h>

PROCESS(hello_world_process, "Hello world");
AUTOSTART_PROCESSES(&hello_world_process);

PROCESS_THREAD(hello_world_process, ev, data)
{
  PROCESS_BEGIN();
  printf("Hello, world!\n");
  PROCESS_END();
}
