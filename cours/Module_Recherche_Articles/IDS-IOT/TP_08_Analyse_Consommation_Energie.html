TP 08 — Analyse de la consommation d'énergie

TP 08 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 1 séance
  • Prérequis : Données parsées disponibles

Objectif

Analyser la consommation d'énergie des différentes variantes de RPL-ClusterIDS, comparer les politiques contextuelles Full, Balanced et Eco, et quantifier le trade-off entre sécurité et énergie.

1. Métrique ENERGY_UPDATE

Les logs METRIC contiennent des événements ENERGY_UPDATE qui rapportent l'énergie consommée par chaque nœud.

grep "ENERGY_UPDATE" data/real/raw/MAIN_rank_seed1.csc.testlog | head -10

Format : METRIC,time,node,ENERGY_UPDATE,energy_mJ,"details"

2. Calcul de l'énergie moyenne par nœud

python3 << 'EOF'
import csv, glob

energy = {}
for f in glob.glob("data/real/parsed/*MAIN*.csv"):
    with open(f) as fh:
        reader = csv.DictReader(fh)
        for row in reader:
            if row["event_type"] == "ENERGY_UPDATE":
                node = row["node_id"]
                val = float(row["value"])
                energy[node] = energy.get(node, []) + [val]

for node, vals in sorted(energy.items()):
    avg = sum(vals) / len(vals)
    print(f"Node {node}: avg energy = {avg:.2f} mJ ({len(vals)} samples)")
EOF

3. Comparaison des variantes

Comparez l'énergie totale consommée par chaque variante :

python3 << 'EOF'
import csv, glob

variant_energy = {}
for f in glob.glob("data/real/parsed/*.csv"):
    variant = f.split("/")[-1].split("_")[0]
    total = 0
    with open(f) as fh:
        reader = csv.DictReader(fh)
        for row in reader:
            if row["event_type"] == "ENERGY_UPDATE":
                total += float(row["value"])
    variant_energy[variant] = variant_energy.get(variant, 0) + total

for v, e in sorted(variant_energy.items()):
    print(f"{v}: {e:.0f} mJ total")
EOF
