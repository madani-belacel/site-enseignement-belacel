TP 08 — Analyse de la consommation d'énergie

TP 08 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 06, logs NRG disponibles
Objectif pédagogique : Analyser les métriques NRG : CH vs membres, impact des modes Full/Balanced/Eco.

1. Extraire les métriques NRG

cd /home/madani/contiki-ng/examples/IDS_IOT
grep "METRIC,NRG" results/pilot/MAIN_mixed_seed1.log

Format : METRIC,NRG,seed,variant,role,mode,cpu_pct,ram_kb,energest_delta_pct

2. CH vs membres

python3 -c "
import re
ch_cpu,mem_cpu=[],[]; ch_ram,mem_ram=[],[]; ch_ener,mem_ener=[],[]
with open('results/pilot/MAIN_mixed_seed1.log') as f:
for line in f:
if 'METRIC,NRG' in line:
p=line.strip().split(',')
role=int(p[5]); cpu=int(p[7]); ram=int(p[8]); ener=int(p[9])
if role==1:
ch_cpu.append(cpu);ch_ram.append(ram);ch_ener.append(ener)
else:
mem_cpu.append(cpu);mem_ram.append(ram);mem_ener.append(ener)
def avg(l): return sum(l)/len(l) if l else 0
print(f'CH: CPU={avg(ch_cpu):.1f}% RAM={avg(ch_ram):.0f}Ko Energ={avg(ch_ener):.1f}%')
print(f'Membre: CPU={avg(mem_cpu):.1f}% RAM={avg(mem_ram):.0f}Ko Energ={avg(mem_ener):.1f}%')
print(f'Surcharge: CPU+{avg(ch_cpu)-avg(mem_cpu):.1f}% RAM+{avg(ch_ram)-avg(mem_ram):.0f}Ko Energ+{avg(ch_ener)-avg(mem_ener):.1f}%')
"

3. Impact des politiques

python3 -c "
from collections import defaultdict
ms=defaultdict(lambda:{'cpu':[],'ener':[]})
with open('results/pilot/MAIN_mixed_seed1.log') as f:
for line in f:
if 'METRIC,NRG' in line:
p=line.strip().split(','); mode=int(p[6]); cpu=int(p[7]); ener=int(p[9])
ms[mode]['cpu'].append(cpu); ms[mode]['ener'].append(ener)
modes={0:'Full',1:'Balanced',2:'Eco'}
for m,d in sorted(ms.items()):
print(f"{modes[m]:>10}: CPU={sum(d['cpu'])/len(d['cpu']):.1f}% Energ={sum(d['ener'])/len(d['ener']):.1f}%")
"
Vérification :
  1. CH consomment plus que membres (surcharge 20-30%)
  2. Eco < Full (économie 30-40%)
  3. MAIN consomme plus que B1 (plus de traitement distribué)
  4. CPU entre 3-12% (réaliste)
Dépannage : Si CPU>100% ou RAM>65535, vérifiez IDS_CONF_CAMPAIGN_METRICS=1 à la compilation.
Question réflexive : La surcharge CH de +24% est-elle acceptable ? Compromis sécurité vs durée de vie ?
