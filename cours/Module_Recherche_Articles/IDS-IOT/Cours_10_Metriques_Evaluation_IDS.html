Métriques d'évaluation IDS

Cours 10 — Module IDS-IOT / RPL-ClusterIDS
  • Auteur : Dr. Madani BELACEL
  • Tables : Tables II–IX dans l'article Elsevier

1. Matrice de confusion

Les métriques de détection sont basées sur la matrice de confusion :

  • VP (Vrai Positif) — Attaque détectée correctement
  • FP (Faux Positif) — Alerte pour un comportement normal
  • VN (Vrai Négatif) — Comportement normal correctement identifié
  • FN (Faux Négatif) — Attaque non détectée

2. Detection Rate (DR) / Recall

Le taux de détection mesure la proportion d'attaques correctement identifiées :

DR = VP / (VP + FN)

Un DR élevé (proche de 1) signifie que l'IDS détecte la plupart des attaques. RPL-ClusterIDS vise DR > 90% pour les attaques simples, > 80% pour les attaques mixtes.

3. False Positive Rate (FPR)

Le taux de faux positifs mesure la proportion de comportements normaux incorrectement signalés comme attaques :

FPR = FP / (FP + VN)

Un FPR bas (idéalement < 5%) est essentiel pour éviter la fatigue des alertes. L'agrégation CH de RPL-ClusterIDS réduit le FPR de 40-60% par rapport à une détection locale.

4. Précision (Precision)

La précision mesure la proportion d'alertes qui sont correctes :

Précision = VP / (VP + FP)

5. F1-Score

Le F1-Score est la moyenne harmonique de la précision et du rappel :

F1 = 2 · (Précision · Rappel) / (Précision + Rappel)

Cette métrique unique permet de comparer globalement les variantes. Un F1 > 0.85 est considéré comme excellent.

6. Overhead énergétique

L'overhead énergétique mesure l'énergie supplémentaire consommée par le mécanisme IDS par rapport à RPL standard (B1) :

Overhead_E = (E_IDS - E_B1) / E_B1 · 100%

Mesuré via le modèle d'énergie de Cooja (energest). Les overheads typiques :

  • Full mode : 15-20%
  • Balanced mode : 8-10%
  • Eco mode : 3-5%

7. Latence de détection

La latence de détection est le temps entre le début d'une attaque et la première alerte générée :

Latence = t_alerte - t_attaque

Elle dépend de la politique contextuelle et de la période de rapport LAS. En mode Full, la latence moyenne est de 5-15 secondes simulées.

9. Interpretation des résultats

Les résultats préliminaires (pilot campaign) montrent :

  • DR > 94% pour l'attaque rank en mode Full
  • FPR < 6% pour toutes les attaques en mode Full
  • CLUSTERIDS (MAIN) surpasse systématiquement les ablations
  • L'agrégation CH améliore le F1-Score de 0.12 à 0.15 par rapport à la détection locale
Note : Ces résultats sont préliminaires (phase 2.1). La campagne complète permettra de les consolider statistiquement sur 30+ seeds.
