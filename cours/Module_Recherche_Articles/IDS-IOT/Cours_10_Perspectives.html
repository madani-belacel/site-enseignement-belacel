Métriques d'évaluation et perspectives

Cours 10 — Module IDS-IOT / RPL-ClusterIDS
  • Auteur : Dr. Madani BELACEL
  • Durée : 1 séance
  • Objectif : Maîtriser les métriques de détection et identifier les perspectives de recherche
Objectif pédagogique : Maîtriser DR, FAR, F1, métriques système (énergie, latence, CPU, RAM), pipeline et perspectives.

1. Métriques de détection

MétriqueFormule
DR (Detection Rate)TP / (TP + FN)
FAR (False Alarm Rate)FP / (FP + TN)
PrécisionTP / (TP + FP)
F1-Score2×TP / (2×TP + FP + FN)

2. Métriques système (logs METRIC)

  • DET : TP, FP, TN, FN, DR
  • NRG : rôle, mode, CPU%, RAM, énergie
  • LAT : latence moyenne (s)
  • ALERT : nœuds, alarmes/heure
  • CLUST : temps, tenure CH, re-cluster, NRE
  • TEMP : phase (stab/attack/recovery), DR
  • MODE : mode contextuel, DR, FAR, CPU%

3. Format METRIC

METRIC,,,,,
Ex: METRIC,DET,1,MAIN,mixed,45,3,120,32,0.9375

4. Pipeline de traitement

  1. Parse logs METRIC → CSV structuré
  2. Calcule DR, FAR, F1 par variante et scénario
  3. Génère Tables II–IX (LaTeX)
  4. Génère 11 figures TikZ/PGFPlots

5. Perspectives

  • Apprentissage automatique embarqué (forêt aléatoire, SVM léger)
  • Intégration LQI dans l'affinité
  • Validation matérielle (Zolertia RE-Mote, Energest réel)
  • Nouvelles attaques : sybil, hello flood, sinkhole
  • Déploiement multi-saut > 100 nœuds
Question réflexive : Quelle métrique est la plus importante pour un IDS en IoT critique (surveillance médicale) : DR, FAR ou F1 ? Justifiez.
