Variants et études d'ablation

Cours 09 — Module IDS-IOT / RPL-ClusterIDS
  • Auteur : Dr. Madani BELACEL
  • Durée : 2 séances
  • Objectif : Comprendre les 8 variantes et l'impact de chaque composant par ablation
Objectif pédagogique : Comprendre le protocole d'ablation : chaque variante désactive un composant pour mesurer sa contribution.

1. Les huit variantes

VarianteLabelDescriptionMacro
B1B1Centralisé border routerIDS_VARIANT_B1
B2B2Flat distribuéIDS_VARIANT_B2
B3B3Centralisé vérificationIDS_VARIANT_B3
MAINMAINComplet (clustering + CH)IDS_VARIANT_MAIN
NOCLUSNO_CLUSTSans clusteringIDS_ABLATION_NOCLUS
NOCTXFIXED_MODESans politique contextuelleIDS_ABLATION_NOCTX
NOENRFIXED_NRGÉnergie fixe (NRE=80)IDS_ABLATION_NOENR
NOMLMEMBERSSans confirmation CHIDS_ABLATION_NOML

2. Sélection par variante dans run_ids_overlay()

#if IDS_VARIANT_B1
    if(NETSTACK_ROUTING.node_is_root()) { ids_member_tick(...); }
#elif IDS_VARIANT_B2
    ids_member_tick(...);
#elif IDS_VARIANT_B3
    if(node_is_root()) { ids_member_tick(); ids_ch_tick(); }
    else { ids_member_tick(); }
#else /* MAIN */
    ids_member_tick(...);
    ids_ch_tick(ids_member_las(), ids_member_alarm());
#endif

3. Effet attendu des ablations

  • NOCLUS : chaque nœud est CH → surcoût énergétique
  • NOCTX : pas d'adaptation → consommation constante
  • NOENR : NRE fixe → pas d'energy-scaling du LAS
  • NOML : pas de confirmation CH → plus de FP, conso réduite
Question réflexive : Si NOML (MEMBERS) a plus de FP mais une conso réduite, dans quel scénario est-ce acceptable ? Comment l'ablation aide-t-elle à décider ?
