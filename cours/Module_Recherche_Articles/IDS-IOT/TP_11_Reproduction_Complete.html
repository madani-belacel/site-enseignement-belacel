TP 11 — Reproduction complète de la campagne

TP 11 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 3 séances (peut nécessiter plusieurs heures de calcul)
  • Prérequis : Tous les TP précédents réussis

Objectif

Exécuter le pipeline complet de RPL-ClusterIDS : de la génération des scénarios à la compilation du manuscrit LaTeX. Ce TP synthétise l'ensemble des compétences acquises dans le module.

1. Vérification de l'environnement

# Vérifier les dépendances
python3 --version
pdflatex --version
which cooja  # ou le chemin vers Cooja
echo "CONTIKI=$CONTIKI"
echo "IDS_ROOT=$IDS_ROOT"

2. Nettoyage des données précédentes

# Optionnel : archiver les anciens résultats
mkdir -p archive/$(date +%Y%m%d_%H%M)
mv data/real/raw/* archive/.../
mv data/real/parsed/* archive/.../
mv tables/* archive/.../
mv Figures/* archive/.../
make clean

3. Étape 1 : Générer les scénarios

python3 scripts/generate_campaign_csc.py \
  --campaign \
  --nodes 50 \
  --malicious 5 \
  --seeds 10 \
  --output sim/scenarios/
echo "Scénarios générés : $(ls sim/scenarios/*.csc | wc -l)"

4. Étape 2 : Compiler tous les variants

cd code_source_RPL_ClusterIDS
./simulations/scripts/build_variant.sh all
echo "Builds : $(ls simulations/build/*.cooja | wc -l)"

5. Étape 3 : Lancer la campagne complète

cd $IDS_CODE/simulations/scripts
NUM_SEEDS=10 SIM_TIMEOUT_MS=300000 ./run_ids_campaign.sh all
# ⚠️ Cette étape peut prendre plusieurs heures

6. Étape 4 : Parser les logs

python3 scripts/parse_cooja_ids_metrics.py \
  --input data/real/raw/ \
  --output data/real/parsed/

7. Étape 5 : Calculer les statistiques

python3 scripts/statistics/compute_statistics.py \
  --input data/real/parsed/ \
  --output tables/ \
  --format latex

8. Étape 6 : Générer les figures

python3 scripts/python/generate_figures.py \
  --csv data/real/parsed/agg \
  --out Figures/

9. Étape 7 : Compiler le manuscrit

cd $IDS_ROOT
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
# Vérifier que main.pdf a été généré
ls -la main.pdf

10. Utilisation du pipeline Docker (alternative)

cd docker
docker build -t ids-iot-pipeline .
docker run --rm \
  -v $(pwd)/../:/workspace \
  ids-iot-pipeline \
  bash /workspace/run_pipeline.sh

11. Validation des résultats

Après la compilation, vérifiez :

  • Que main.pdf contient bien 11 figures
  • Que les Tables II-IX sont présentes
  • Que les résultats sont cohérents (DR > 90% pour MAIN, FPR < 10%)
  • Comparez avec les données de la campagne pilote

Rendu attendu

Produisez un fichier reproduction_complete.txt avec :

  1. Le log complet de chaque étape (temps d'exécution, nb de fichiers)
  2. Les éventuelles erreurs et leurs résolutions
  3. La taille du fichier main.pdf généré
  4. Un tableau récapitulatif des résultats (DR, FPR, F1 pour MAIN)
  5. Le lien vers le PDF final (main.pdf)
