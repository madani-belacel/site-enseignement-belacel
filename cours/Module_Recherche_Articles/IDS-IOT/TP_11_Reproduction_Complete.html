TP 11 — Reproduction complète de la campagne

TP 11 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 10, pipeline complet opérationnel
Objectif pédagogique : Reproduire intégralement la campagne : compilation → scénarios → simulation → analyse → tables → figures.

1. Script de reproduction complet

#!/bin/bash
# reproduce_campaign.sh — Reproduction complète de RPL-ClusterIDS
set -e
BASE=/home/madani/contiki-ng/examples/IDS_IOT
CONTIKI=/home/madani/contiki-ng

# Étape 1: Compiler tous les variants
cd $BASE/code_source_RPL_ClusterIDS
for v in MAIN B1 B2 B3 NOCLUS NOCTX NOENR NOML; do
make IDS_VARIANT=$v TARGET=cooja clean
make IDS_VARIANT=$v TARGET=cooja IDS_CONF_CAMPAIGN_METRICS=1
cp clusterids-node.cooja clusterids-node-$v.cooja
done

# Étape 2: Générer les scénarios
cd $BASE
python3 scripts/generer_scenarios_cooja.py \
--output sim/campaign/ \
--variants MAIN B1 B2 B3 NOCLUS NOCTX NOENR NOML \
--scenarios none rank sel_fwd dao_flood wormhole mixed \
--nodes 50 --seeds $(seq -s ' ' 1 10)

# Étape 3: Lancer la campagne
python3 scripts/run_campaign_parallel.py \
--input sim/campaign/ --output results/campaign/ --workers 4

# Étape 4: Analyser les logs
python3 scripts/analyse_logs_campagne.py \
--input results/campaign/ --output results/analysis/

# Étape 5: Générer les tables
python3 scripts/generer_tables_article.py \
--input results/campaign/ --output results/tables/

# Étape 6: Générer les figures
python3 scripts/generer_figures_article.py \
--input results/campaign/ --output results/figures/

echo "Campagne reproduite avec succès !"

2. Exécution

chmod +x reproduce_campaign.sh
# ATTENTION: cette campagne complète peut prendre plusieurs heures
# ./reproduce_campaign.sh

3. Estimation du temps

  • 8 variants × 6 scénarios × 10 seeds = 480 simulations
  • ~10 min par simulation × 480 / 4 workers = ~20 heures
  • Prévoir une exécution overnight

4. Vérification

Vérification : Vérifiez la présence de tous les fichiers attendus :
  • results/campaign/*.log (480 fichiers)
  • results/tables/table_II*.tex à table_IX*.tex
  • results/figures/fig_*.tex (11 fichiers)
Dépannage : Si la campagne est trop longue, réduisez à 3 seeds (au lieu de 10) pour un test plus rapide.
