TP 09 — Statistiques comparatives (Tables II–IX)

TP 09 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 07-08, données agrégées
Objectif pédagogique : Générer les Tables II-IX de l'article avec generer_tables_article.py.

1. Générer les tables LaTeX

cd /home/madani/contiki-ng/examples/IDS_IOT
python3 scripts/generer_tables_article.py \
--input results/pilot/ --output results/tables/ --format latex

2. Tables générées

  • table_II_detection_rate.tex
  • table_III_false_alarm_rate.tex
  • table_IV_f1_score.tex
  • table_V_energy_consumption.tex
  • table_VI_context_policy.tex
  • table_VII_latency.tex
  • table_VIII_cpu_ram.tex
  • table_IX_ablation_study.tex

3. Examiner Table II

cat results/tables/table_II_detection_rate.tex
Vérification :
  1. MAIN a le DR le plus élevé
  2. B1 a le DR le plus bas
  3. Ablations : performances intermédiaires
  4. Scénario 'none' : DR=1.0
