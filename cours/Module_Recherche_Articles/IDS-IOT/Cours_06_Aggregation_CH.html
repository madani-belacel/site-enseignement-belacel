Agrégation au niveau Cluster Head

Cours 06 — Module IDS-IOT / RPL-ClusterIDS
  • Auteur : Dr. Madani BELACEL
  • Durée : 1 séance
  • Objectif : Comprendre ids_ch.c : confirmation des alertes, agrégation LAS
Objectif pédagogique : Analyser ids_ch.c : confirmation, matrice de confusion consolidée, différence détection membre vs CH.

1. Code de confirmation

void ids_ch_tick(uint8_t member_las, uint8_t member_alarm) {
    uint8_t attack_active = ids_attack_is_active();
    if(!ch_elect_is_head()) { return; }  // Seuls les CH confirment
    confirmed = 0;
    if(member_alarm && member_las > IDS_THRESHOLD_CH) {
        if(attack_active) { tp++; confirmed = 1; }
        else { fp++; }
    } else if(attack_active) { fn++; }
    else { tn++; }
}

3. Comparaison des variants

  • B1 : border router uniquement
  • B2 : plat (flat), chaque nœud pour soi
  • B3 : border router vérifie (centralisé)
  • MAIN : CH vérifie (distribué hiérarchique)
