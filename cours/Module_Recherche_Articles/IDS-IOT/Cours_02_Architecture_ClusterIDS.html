2. Diagramme de flux du processus principal

PROCESS_THREAD(clusterids_node_process, ev, data) {
  PROCESS_BEGIN();
  // Initialisation
  clus_form_init(); ch_elect_init(); ids_member_init();
  ids_ch_init(); ctx_policy_init(); ids_attack_init();
  if(node_id == 1) NETSTACK_ROUTING.root_start();

  while(1) {
    PROCESS_WAIT_EVENT_UNTIL(etimer_expired(&periodic)
                          || etimer_expired(&ids_tick)
                          || etimer_expired(&metrics_tick));
    if(etimer_expired(&ids_tick)) {  // Toutes les 5s
      sim_seconds += 5;
      run_ids_overlay(pick_traffic_class());
    }
    if(etimer_expired(&metrics_tick)) {  // Toutes les 60s
      emit_campaign_metrics();
    }
    if(etimer_expired(&periodic)) {  // ~30s ajusté par profil C0-C3
      simple_udp_sendto(&udp_conn, payload, len, NULL);
    }
  }
  PROCESS_END();
}

3. Cheminement des données de détection

  1. ids_attack_tick() active/désactive les signaux selon sim_seconds
  2. ids_member_tick() lit 4 signaux, applique masque (policy), EWMA, calcule LAS
  3. Si LAS > 50 → alarme membre = 1
  4. ids_ch_tick() confirme si alarme ET LAS > 50
  5. emit_campaign_metrics() log toutes les 60s
