TP 05 — Simulation campagne pilote

TP 05 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Script : run_ids_campaign.sh

Objectif

Lancer la campagne de simulation pilote en mode smoke (test rapide avec 3 seeds, timeout 90s), vérifier le pipeline complet de la simulation, et examiner les logs produits (COOJA.testlog).

1. Localiser le script de campagne

ls code_source_RPL_ClusterIDS/simulations/scripts/
# run_ids_campaign.sh doit s'y trouver

2. Configurer les variables

export IDS_ROOT=/home/madani/contiki-ng/examples/IDS_IOT
export IDS_CODE=$IDS_ROOT/code_source_RPL_ClusterIDS
export CONTIKI=/home/madani/contiki-ng

3. Lancer le mode smoke

cd $IDS_CODE/simulations/scripts
NUM_SEEDS=3 SIM_TIMEOUT_MS=90000 ./run_ids_campaign.sh smoke

Ce mode exécute :

  • 3 seeds aléatoires
  • Timeout de 90 secondes par simulation
  • Variant MAIN uniquement (ou tous si spécifié)
  • Une attaque rank par défaut

4. Observer le déroulement

Le script affiche la progression :

[CAMPAIGN] Starting smoke test with 3 seeds...
[CAMPAIGN] Seed 1/3: running MAIN_rank...
[CAMPAIGN]   COOJA: Simulation time: 300000ms
[CAMPAIGN]   COOJA: METRIC lines: 1245
[CAMPAIGN] Seed 2/3: running MAIN_rank...
[...]
[CAMPAIGN] Smoke test completed in 47s

5. Examiner les logs

Les logs sont stockés dans le répertoire data/real/raw/ :

ls $IDS_ROOT/data/real/raw/
# Vous devriez voir des fichiers comme :
# MAIN_rank_seed1.csc.testlog
# MAIN_rank_seed2.csc.testlog
# MAIN_rank_seed3.csc.testlog

6. Analyser COOJA.testlog

Examinez le contenu d'un fichier testlog :

head -50 $IDS_ROOT/data/real/raw/MAIN_rank_seed1.csc.testlog

Repérez les lignes METRIC :

METRIC,120000,1,CH_ELECTED,1,"fitness=0.91"
METRIC,121000,2,LAS_COMPUTED,0.45,"R1=0.0 R2=0.8 R3=0.1 R4=0.9"
METRIC,122000,2,LAS_REPORTED,0.45,"dest_ch=1"
METRIC,123000,1,ALERT_GENERATED,1,"suspect=2 type=rank_attack"

7. Vérifier les alertes

Comptez le nombre d'alertes générées :

grep -c "ALERT_GENERATED" $IDS_ROOT/data/real/raw/MAIN_rank_seed1.csc.testlog

8. Mode campagne complète (si le temps le permet)

Le script peut aussi lancer la campagne complète :

NUM_SEEDS=10 SIM_TIMEOUT_MS=300000 ./run_ids_campaign.sh all

⚠️ Attention : la campagne complète peut prendre plusieurs heures.

Rendu attendu

Dans un fichier campagne_pilote_log.txt, notez :

  1. Le nombre total de lignes METRIC par seed
  2. Le nombre d'alertes générées par seed
  3. Les types d'événements observés dans les logs
  4. Le temps d'exécution total du mode smoke
