TP 05 — Simulation campagne pilote (50 nœuds)

TP 05 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 04, scénarios .csc générés
Objectif pédagogique : Lancer une campagne pilote 50 nœuds pour MAIN, B1, B2 × none, mixed × 3 seeds.

1. Générer les scénarios pilotes

cd /home/madani/contiki-ng/examples/IDS_IOT
python3 scripts/generer_scenarios_cooja.py \
--output sim/pilot/ \
--variants MAIN B1 B2 \
--scenarios none mixed \
--nodes 50 --seeds 1 2 3

2. Lancer en mode headless

cd /home/madani/contiki-ng
java -mx512m -jar tools/cooja/dist/cooja.jar \
-nogui="/home/madani/contiki-ng/examples/IDS_IOT/sim/pilot/MAIN_none_seed1.csc" \
-contiki=/home/madani/contiki-ng > pilot_MAIN_none_1.log 2>&1

3. Script parallèle

cd /home/madani/contiki-ng/examples/IDS_IOT
python3 scripts/run_campaign_parallel.py \
--input sim/pilot/ --output results/pilot/ --workers 4

4. Vérification

Vérification : Vérifiez : fichiers .log non vides, ≥10 lignes METRIC,DET, champs seed/variant/scenario corrects.
Dépannage : Si Cooja échoue en headless, vérifiez Java 11+ et augmentez -mx à 1g.
Question réflexive : Pourquoi 3 seeds ? Effet de la seed sur TP/FP ?
