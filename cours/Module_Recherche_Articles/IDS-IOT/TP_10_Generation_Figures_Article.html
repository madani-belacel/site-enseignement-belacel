TP 10 — Génération de figures pour l'article

TP 10 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Script : generate_figures.py

Objectif

Utiliser le script generate_figures.py pour produire les 11 figures de l'article au format TikZ/PGFPlots. Comprendre le workflow de génération de figures publication-quality pour Computer Networks (Elsevier).

1. Localiser le script

ls scripts/python/
# generate_figures.py doit s'y trouver

2. Afficher l'aide

python3 scripts/python/generate_figures.py --help

3. Générer toutes les figures

python3 scripts/python/generate_figures.py \
  --csv data/real/parsed/agg \
  --out Figures/

5. Examiner une figure générée

ls Figures/
cat Figures/fig02-detection-rate.tex

6. Workflow TikZ/PGFPlots

Les figures sont générées au format TikZ/PGFPlots, un package LaTeX qui produit des graphiques vectoriels de haute qualité :

  • Le script Python lit les CSV agrégés
  • Il génère du code LaTeX TikZ avec les données
  • Les fichiers .tex sont inclus dans le manuscrit principal via \input{Figures/fig02...}
  • La compilation LaTeX produit les graphiques vectoriels

7. Personnalisation des figures

Vous pouvez personnaliser les figures en modifiant les paramètres dans generate_figures.py :

  • Couleurs (palette Elsevier)
  • Épaisseur des lignes
  • Police et taille des labels
  • Dimensions (width, height)
  • Légendes et annotations

8. Compilation avec le manuscrit

Pour compiler le manuscrit avec les figures :

cd $IDS_ROOT
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex

9. Alternative : export PNG

Si vous n'avez pas LaTeX complet, exportez en PNG :

python3 scripts/python/generate_figures.py \
  --csv data/real/parsed/agg \
  --out Figures/ \
  --format png
