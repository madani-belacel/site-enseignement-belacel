Règles de détection au niveau membre (R1–R4)

Cours 05 — Module IDS-IOT / RPL-ClusterIDS
  • Auteur : Dr. Madani BELACEL
  • Durée : 2 séances
  • Objectif : Comprendre les 4 règles de détection, le LAS (Eq. 4), EWMA, matrice de confusion
Objectif pédagogique : Analyser ids_member.c : règles R1-R4, LAS, EWMA, matrice de confusion locale.

1. Les quatre règles (R1–R4)

RègleBitAttaqueSignal
R10x01Rank Attack75-85
R20x02Selective Forwarding35-75 (selon classe)
R30x04DAO Flood60-70
R40x08Wormhole70-80 (25% silence)

2. Lissage EWMA

ewma[i] = (ewma[i] * 7 + raw[i]) / 8;
if(raw[i] > ewma[i] + 15) { det[i] = raw[i]; }

Facteur 7/8 = 0.875, seuil de détection = EWMA + 15.

3. Score LAS (Eq. 4)

las = (det[0] * 3 + det[1] * 2 + det[2] + det[3]) / 4;

Poids : R1×3 (rank, le plus dangereux), R2×2 (selective forwarding), R3×1, R4×1.

Si NRE < 20%, LAS divisé par 2 (energy-scaling).

4. Alarme et matrice de confusion

alarm = las > IDS_THRESHOLD_LAS ? 1 : 0;  // seuil = 50

if(alarm && ids_attack_is_active())  tp_m++;
else if(alarm && !ids_attack_is_active()) fp_m++;
else if(!alarm && ids_attack_is_active()) fn_m++;
else tn_m++;

5. Masques selon politique

ModeMasqueRègles
Full0x0FR1+R2+R3+R4
Balanced0x07R1+R2+R3
Eco0x03R1+R2
Vérification : Rank attack signal=80, ewma=30 → 80 > 45 → vrai. LAS = (80×3)/4 = 60 > 50 → alarme.
Dépannage : Si le taux de FP est trop élevé, augmentez le seuil EWMA+15 ou IDS_THRESHOLD_LAS dans ids_conf.h.
Question réflexive : Pourquoi utiliser un EWMA plutôt que la valeur brute ? Comment le facteur 7/8 influence-t-il la réactivité ?
