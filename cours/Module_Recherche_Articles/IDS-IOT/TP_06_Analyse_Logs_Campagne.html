TP 06 — Analyse des logs METRIC de campagne

TP 06 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 05, results/pilot/ disponible
Objectif pédagogique : Parser les logs METRIC, calculer DR/FAR/F1 par variante, produire un CSV.

1. Analyse des logs

cd /home/madani/contiki-ng/examples/IDS_IOT
python3 scripts/analyse_logs_campagne.py \
--input results/pilot/ --output results/analysis/ \
--csv results/analysis/metrics.csv

2. Examiner le CSV

cat results/analysis/metrics.csv

3. Comparaison MAIN vs B1

python3 -c "
import csv
with open('results/analysis/metrics.csv') as f:
for row in csv.DictReader(f):
if row['scenario']=='mixed':
print(f\"{row['variant']:>8} DR={row['dr']:.4f} FAR={row['far']:.4f} F1={row['f1']:.4f}\")
"
Vérification :
  1. MAIN DR > B1 (détection distribuée plus efficace)
  2. MAIN FAR < B1 (confirmation CH réduit les FP)
  3. Scénario 'none' : DR=1.0, FAR=0.0
Dépannage : Si CSV vide, vérifiez les logs avec : grep -c 'METRIC,DET' results/pilot/*.log
Question réflexive : Interprétez la différence DR entre MAIN (0.9375) et B1 (0.6640) pour mixed. Pourquoi le système complet détecte-t-il mieux ?
