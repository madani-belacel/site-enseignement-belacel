TP 03 — Simulation test avec 3 nœuds dans Cooja

TP 03 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 02, Contiki-NG avec Cooja, Java
Objectif pédagogique : Lancer une simulation 3 nœuds (1 root + 2 membres) dans Cooja, observer les logs de détection.

1. Lancer Cooja

cd /home/madani/contiki-ng
ant run # ou java -jar tools/cooja/dist/cooja.jar

2. Créer la simulation

  1. File → New Simulation
  2. Nom : IDS-IOT-test-3nodes
  3. Radio medium : UDGM
  4. Créer

3. Ajouter les nœuds

  1. Mote → Add motes → Sky mote
  2. Firmware : code_source_RPL_ClusterIDS/clusterids-node.cooja
  3. Ajoutez 3 motes

Positions : N1(50,50) root, N2(80,50) membre, N3(50,80) membre.

4. Lancer la simulation

# Cliquez Start dans Cooja
# Observation des logs UDP et METRIC

5. Logs attendus

METRIC,DET,0,MAIN,none,12,0,48,0,1.0000
METRIC,NRG,0,MAIN,1,0,8,4200,62
METRIC,LAT,0,MAIN,none,18

6. Vérification

Vérification :
  1. 3 nœuds forment un DODAG RPL
  2. Node 1 (ID=1) est root
  3. Paquets UDP échangés
  4. Logs METRIC toutes les 60s
Dépannage : Si pas de communication, vérifiez portée UDGM (≥50m). Si pas de root, vérifiez node_id==1 dans clusterids-node.c.
Question réflexive : Pourquoi 3 nœuds seulement ? Quels aspects ne peuvent pas être validés avec si peu de nœuds ?
