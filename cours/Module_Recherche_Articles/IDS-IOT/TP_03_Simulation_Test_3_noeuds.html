TP 03 — Simulation test avec 3 nœuds

TP 03 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 1 séance
  • Prérequis : TP 02 réussi (builds disponibles), Cooja opérationnel

Objectif

Lancer une première simulation de test avec le variant CLUSTERIDS (MAIN) sur une topologie de 3 nœuds, vérifier l'initialisation des modules IDS, observer les logs structurés, et valider le bon fonctionnement du pipeline.

1. Préparer la simulation de base

Un template CSC de base pour 3 nœuds est disponible dans simulations/templates/ :

ls code_source_RPL_ClusterIDS/simulations/templates/

Copiez basic_3nodes.csc dans votre répertoire de travail :

cp code_source_RPL_ClusterIDS/simulations/templates/basic_3nodes.csc .
# Ou utilisez le template fourni

2. Configurer le firmware

Assurez-vous que le template CSC pointe vers le firmware MAIN compilé :

<firmware>
  <compile>
    <command>make TARGET=cooja IDS_VARIANT=MAIN IDS_CONF_CAMPAIGN_METRICS=1</command>
  </compile>
</firmware>

3. Lancer la simulation

Via Cooja (GUI) :

ant run &
# Dans Cooja : File -> Open -> basic_3nodes.csc
# Puis : Simulation -> Start

Via la ligne de commande (headless) :

cd code_source_RPL_ClusterIDS/simulations
../../tools/cooja/dist/cooja -nogui=<chemin>/basic_3nodes.csc

4. Observer les logs

Pendant la simulation, observez la console Cooja. Cherchez les messages suivants :

  • [IDS] Initializing RPL-ClusterIDS... — Initialisation du module IDS
  • [CLUSTER] Forming clusters... — Début de la formation des clusters
  • [CH_ELECT] Electing cluster head... — Élection du CH
  • [MEMBER] Applying rules R1-R4... — Activation des règles de détection
  • [METRIC] ... — Lignes de log structuré (si metrics activé)

5. Vérifier les lignes METRIC

Les logs METRIC,... suivent le format :

METRIC,sim_time,node_id,event_type,value,details

Exemple :

METRIC,120000,2,LAS_COMPUTED,0.23,"R1=0.1 R2=0.3 R3=0.2 R4=0.3"
METRIC,150000,1,CH_ELECTED,1,"fitness=0.87"
METRIC,180000,2,LAS_REPORTED,0.23,"dest_ch=1"

6. Simulation avec attaque

Modifiez le template CSC pour activer une attaque rank sur le nœud 2 :

# Dans project-conf.h ou via les variables Cooja :
IDS_CONF_ATTACK_ENABLED=1
IDS_CONF_ATTACK_TYPE=ATTACK_RANK
IDS_CONF_ATTACK_START=60000

Relancez la simulation et observez les alertes générées.

7. Analyse des résultats

Notez dans un fichier simulation_3nodes.txt :

  1. Les messages d'initialisation IDS observés
  2. Le nombre de lignes METRIC générées
  3. Les alertes détectées pendant l'attaque
  4. Le temps de détection (simulation time) de la première alerte
