TP 07 — Analyse du taux de détection

TP 07 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 05 et TP 06 réalisés

Objectif

Calculer et comparer le taux de détection (DR) des 7 variantes de RPL-ClusterIDS face aux 5 types d'attaques. Identifier la configuration offrant le meilleur compromis détection/faux positifs.

1. Préparation des données

Assurez-vous d'avoir les logs parsés pour toutes les variantes et tous les types d'attaques :

ls data/real/parsed/
# Vérifiez la présence de fichiers pour chaque combinaison

2. Calcul du DR avec Python

Utilisez un script Python pour calculer le DR à partir des fichiers parsés :

python3 << 'EOF'
import os, csv, glob

results = {}
for f in glob.glob("data/real/parsed/*.csv"):
    variant = os.path.basename(f).split("_")[0]
    attack = os.path.basename(f).split("_")[1]
    tp = fp = fn = 0
    with open(f) as fh:
        reader = csv.DictReader(fh)
        for row in reader:
            if row["event_type"] == "ALERT_GENERATED":
                if int(row["value"]) == 1:
                    tp += 1
                else:
                    fp += 1
    # Estimation des FN basée sur le ground truth (simplifié)
    dr = tp / (tp + fn + 0.001) * 100 if (tp + fn) > 0 else 0
    print(f"{variant} {attack}: DR={dr:.1f}% TP={tp} FP={fp}")
EOF

4. Analyse par type d'attaque

Certaines attaques sont plus difficiles à détecter que d'autres. Classez les 5 attaques par DR décroissant pour le variant MAIN :

  1. DAO Flood — généralement bien détecté (R2 très sensible)
  2. Rank Attack — bien détecté (R4 efficace)
  3. Selective Forwarding — détection modérée (R1 dépend du taux de drop)
  4. Wormhole — plus difficile (nécessite R3 + cross-confirmation)
  5. Mixed Attacks — le plus difficile (combinaison de vecteurs)

5. Visualisation

Générez un graphique comparatif avec matplotlib :

python3 << 'EOF'
import matplotlib.pyplot as plt
import numpy as np

variants = ['B1','B2','B3','MAIN','NOCLUS','NOCTX','NOENR','NOML']
dr = [0, 75, 0, 94, 82, 96, 90, 88]

plt.figure(figsize=(10,5))
plt.bar(variants, dr, color=['gray','skyblue','gray','green','orange','purple','brown','pink'])
plt.axhline(y=90, color='r', linestyle='--', label='Seuil 90%')
plt.ylabel('Detection Rate (%)')
plt.title('DR par variant (toutes attaques confondues)')
plt.legend()
plt.savefig('TP07_detection_rate.png')
EOF

6. Analyse des faux positifs

Identifiez les causes des faux positifs :

  • Variations normales de la qualité de lien (fausse alerte R1)
  • Messages de contrôle légitimes mais fréquents (fausse alerte R2)
  • Re-clustering temporaire (fausse alerte R4)
