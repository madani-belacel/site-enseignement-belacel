TP 07 — Analyse du taux de détection (DR, FAR)

TP 07 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 2 séances
  • Prérequis : TP 06, CSV disponible
Objectif pédagogique : Analyser DR, FAR, F1 par variante et scénario. Produire des graphiques comparatifs.

1. Agrégation par variante

cd /home/madani/contiki-ng/examples/IDS_IOT
python3 scripts/analyse_logs_campagne.py \
--input results/pilot/ --output results/analysis/ \
--csv results/analysis/aggregated.csv --aggregate variant

2. Matrice de confusion détaillée

python3 -c "
import csv
from collections import defaultdict
stats = defaultdict(lambda: {'tp':0,'fp':0,'tn':0,'fn':0})
with open('results/analysis/metrics.csv') as f:
for row in csv.DictReader(f):
k = (row['variant'], row['scenario'])
stats[k]['tp']+=int(row['tp'])
stats[k]['fp']+=int(row['fp'])
stats[k]['tn']+=int(row['tn'])
stats[k]['fn']+=int(row['fn'])
for (v,s),m in sorted(stats.items()):
dr = m['tp']/(m['tp']+m['fn']) if (m['tp']+m['fn']) else 0
far = m['fp']/(m['fp']+m['tn']) if (m['fp']+m['tn']) else 0
print(f'{v:>8} {s:>8} TP={m[tp]:>5} FP={m[fp]:>4} TN={m[tn]:>5} FN={m[fn]:>4} DR={dr:.4f} FAR={far:.4f}')
"

3. Visualisation

python3 scripts/analyse_logs_campagne.py \
--input results/pilot/ --output results/analysis/ --plot
