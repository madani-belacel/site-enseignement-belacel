TP 02 — Compilation des 7 variants

TP 02 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 1 séance
  • Prérequis : Contiki-NG installé, variable CONTIKI configurée

Objectif

Compiler l'ensemble des 8 variants du firmware RPL-ClusterIDS pour la plateforme Cooja en utilisant le script build_variant.sh. Comprendre le rôle de chaque variant dans l'étude d'ablation.

1. Configuration de l'environnement

Assurez-vous que Contiki-NG est installé et que la variable CONTIKI pointe vers votre installation :

export CONTIKI=/home/madani/contiki-ng
export IDS_ROOT=/home/madani/contiki-ng/examples/IDS_IOT
export IDS_CODE=$IDS_ROOT/code_source_RPL_ClusterIDS
echo $CONTIKI
echo $IDS_CODE

2. Compilation manuelle d'un variant

Avant d'utiliser le script, testez la compilation manuelle du variant MAIN :

cd $IDS_CODE
make clean
make TARGET=cooja IDS_VARIANT=MAIN IDS_CONF_CAMPAIGN_METRICS=1

3. Utilisation du script build_variant.sh

Le script automatise la compilation des 8 variantes :

cd $IDS_CODE/simulations/scripts
./build_variant.sh all

Le script produit les fichiers .csc et .cooja dans simulations/build/.

4. Variantes disponibles

VariantDescriptionRôle dans l'ablation
B1RPL standard, pas d'IDSBaseline minimale
B2RPL + IDS basique (pas de clustering)Impact du clustering
B3RPL + clustering (pas d'IDS)Impact de l'IDS
CLUSTERIDS (MAIN)RPL-ClusterIDS completProposition complète
NOCLUSMAIN sans clusteringAblation clustering
NOCTXMAIN sans politique contextuelleAblation ctx_policy
NOENRMAIN avec CH non basé sur énergieAblation fitness énergie
NOMLMAIN sans LAS/MLAblation apprentissage

5. Vérification des builds

Pour chaque variant, vérifiez que le fichier .cooja a été généré :

ls -la $IDS_CODE/simulations/build/*.cooja

6. Compilation individuelle

Vous pouvez aussi compiler un variant spécifique :

./build_variant.sh B1
./build_variant.sh B2
./build_variant.sh MAIN

7. Résolution des problèmes

  • Erreur "CONTIKI not defined" : Vérifiez la variable d'environnement
  • Erreur de compilation C : Vérifiez que les flags du variant sont corrects dans Makefile
  • Erreur "target cooja not found" : Vérifiez que Contiki-NG supporte la plateforme cooja

Rendu attendu

Notez dans un fichier compilation_log.txt :

  1. La sortie de ./build_variant.sh all
  2. La liste des fichiers .cooja produits
  3. Les éventuelles erreurs et leurs résolutions
