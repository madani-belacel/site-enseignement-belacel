TP 02 — Compilation des 8 variants

TP 02 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 1 séance
  • Prérequis : Contiki-NG, toolchain ARM, TP 01 réalisé
Objectif pédagogique : Compiler les 8 variantes pour Cooja, comprendre les différences de compilation.

1. Préparation

cd /home/madani/contiki-ng/examples/IDS_IOT/code_source_RPL_ClusterIDS
export CONTIKI=/home/madani/contiki-ng

2. Compiler MAIN

make IDS_VARIANT=MAIN TARGET=cooja

Résultat attendu :

Compiling platform Cooja
Compiling clusterids-node.c
Compiling clus_form.c ... Linking clusterids-node.cooja
Done
Vérification : ls -la clusterids-node.cooja (taille ~250-350 Ko).

3. Compiler toutes les variantes

make IDS_VARIANT=B1 TARGET=cooja clean && make IDS_VARIANT=B1 TARGET=cooja
cp clusterids-node.cooja clusterids-node-B1.cooja
make IDS_VARIANT=B2 TARGET=cooja clean && make IDS_VARIANT=B2 TARGET=cooja
cp clusterids-node.cooja clusterids-node-B2.cooja
make IDS_VARIANT=B3 TARGET=cooja clean && make IDS_VARIANT=B3 TARGET=cooja
cp clusterids-node.cooja clusterids-node-B3.cooja
make IDS_VARIANT=MAIN TARGET=cooja clean && make IDS_VARIANT=MAIN TARGET=cooja
cp clusterids-node.cooja clusterids-node-MAIN.cooja
make IDS_VARIANT=NOCLUS TARGET=cooja clean && make IDS_VARIANT=NOCLUS TARGET=cooja
cp clusterids-node.cooja clusterids-node-NOCLUS.cooja
make IDS_VARIANT=NOCTX TARGET=cooja clean && make IDS_VARIANT=NOCTX TARGET=cooja
cp clusterids-node.cooja clusterids-node-NOCTX.cooja
make IDS_VARIANT=NOENR TARGET=cooja clean && make IDS_VARIANT=NOENR TARGET=cooja
cp clusterids-node.cooja clusterids-node-NOENR.cooja
make IDS_VARIANT=NOML TARGET=cooja clean && make IDS_VARIANT=NOML TARGET=cooja
cp clusterids-node.cooja clusterids-node-NOML.cooja

4. Compilation avec logs de campagne

make IDS_VARIANT=MAIN TARGET=cooja clean
make IDS_VARIANT=MAIN TARGET=cooja IDS_CONF_CAMPAIGN_METRICS=1 IDS_CAMPAIGN_SEED=1 IDS_CAMPAIGN_SCENARIO=mixed

5. Vérification

Vérification : Comparez les tailles des binaires. B1 (centralisé) devrait être légèrement plus petit que MAIN.
Dépannage : Si erreur 'contiki.h: No such file', vérifiez que CONTIKI pointe vers /home/madani/contiki-ng.
Question réflexive : Pourquoi le binaire B1 est-il plus petit que MAIN ? Quels composants sont exclus ?
