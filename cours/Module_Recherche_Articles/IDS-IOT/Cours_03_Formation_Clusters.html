Formation des clusters et fonction d'affinité

Cours 03 — Module IDS-IOT / RPL-ClusterIDS
  • Auteur : Dr. Madani BELACEL
  • Durée : 2 séances
  • Code source : clus_form.c / clus_form.h

1. Principe du clustering adaptatif

Le clustering adaptatif de RPL-ClusterIDS organise dynamiquement les nœuds en groupes (clusters) où chaque membre est associé à un Cluster Head (CH). Contrairement aux approches statiques, les clusters évoluent en fonction de la topologie, de l'énergie résiduelle et de la confiance entre nœuds.

2. Fonction d'affinité (Eq. 1)

L'affinité entre un nœud i et un CH potentiel j est calculée par :

Aff(i,j) = α · SS(i,j) + β · E_res(j) + γ · T(i,j)

Où :

  • SS(i,j) — Puissance du signal reçu (RSSI) entre i et j, normalisée
  • E_res(j) — Énergie résiduelle du CH potentiel j, normalisée
  • T(i,j) — Niveau de confiance basé sur l'historique des interactions
  • α, β, γ — Poids configurables (α + β + γ = 1)

Un nœud s'affilie au CH qui maximise Aff(i,j). L'implémentation se trouve dans clus_form.c via la fonction compute_affinity().

3. Algorithme de formation

  1. Découverte : chaque CH potentiel broadcast un message CH_ADV contenant son fitness et son énergie résiduelle
  2. Évaluation : chaque nœud membre calcule l'affinité avec chaque CH voisin
  3. Affiliation : le nœud envoie un message JOIN_REQ au CH avec la plus haute affinité
  4. Confirmation : le CH répond par JOIN_ACK et met à jour sa table des membres
  5. Itération : le processus se répète périodiquement ou en cas de déclenchement de re-clustering

4. Critère de re-clustering (Eq. 2)

Le re-clustering est déclenché si :

ΔAff(i) > θ_recluster · AvgAff(cluster)

Où ΔAff(i) est la diminution de l'affinité du nœud i avec son CH depuis la dernière affiliation, et θ_recluster un seuil paramétrable (typiquement 0.3). Le re-clustering peut aussi être déclenché périodiquement (toutes les T_recluster secondes).

5. Stabilité des clusters

Pour éviter les oscillations (effet ping-pong), un mécanisme de hysteresis est implémenté : un nœud ne peut changer de cluster que si la nouvelle affinité dépasse l'ancienne d'au moins δ_hyst = 0.15. De plus, un timer de cooldown empêche les re-affiliations trop fréquentes.

6. Implémentation dans clus_form.c

Le module clus_form.c expose les fonctions principales :

  • compute_affinity(node_id, ch_id) — Calcule Aff(i,j) selon Eq. 1
  • cluster_formation() — Exécute l'algorithme de formation complet
  • check_reclustering() — Vérifie les critères de re-clustering Eq. 2
  • get_affinity_matrix() — Retourne la matrice d'affinité courante
Note : Les poids α, β, γ sont définis dans project-conf.h et peuvent être ajustés selon les priorités du réseau (ex. : favoriser l'énergie plutôt que la qualité de signal).
