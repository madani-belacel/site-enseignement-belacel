TP 01 — Explorer le dépôt IDS-IOT et le code source

TP 01 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 1 séance
  • Prérequis : Git, Ubuntu 22.04+
Objectif pédagogique : Naviguer dans le dépôt, comprendre l'organisation des répertoires, identifier les fichiers sources, variantes et données.

1. Structure racine

cd /home/madani/contiki-ng/examples/IDS_IOT
ls -la

Identifiez :

  • main.tex — Manuscrit Elsevier
  • code_source_RPL_ClusterIDS/ — Firmware Contiki-NG
  • SIMULATION_CAMPAIGN_READY/ — Scripts de campagne
  • data/ — Données de simulation
  • scripts/ — Scripts Python
  • Figures/ — 11 figures TikZ
  • tables/ — Tables II–IX
  • docker/ — Support Docker

cd code_source_RPL_ClusterIDS

4. Lire la configuration

cat ids_conf.h

5. Vérification

Vérification : Produisez structure_depot.txt avec l'arborescence commentée (≥15 lignes). Exemple : IDS_IOT/ ├── main.tex # Manuscrit Elsevier ├── code_source_RPL_ClusterIDS/ │ ├── clusterids-node.c # Processus principal │ ├── clus_form.c # Formation clusters │ ├── ch_elect.c # Élection CH │ ├── ids_member.c # Détection membre │ ├── ids_ch.c # Agrégation CH │ ├── ctx_policy.c # Politiques contextuelles │ ├── ids_attack.c # Générateurs d'attaques │ ├── ids_campaign_log.c# Log METRIC │ └── variants/ # 8 fichiers imacros-*.h ├── SIMULATION_CAMPAIGN_READY/ ├── data/ ├── scripts/ └── docker/
