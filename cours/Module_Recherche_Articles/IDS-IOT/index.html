IDS-IOT — Détection d'Intrusion RPL-ClusterIDS

Module : Recherche & Articles — RPL-ClusterIDS
  • Auteur : Dr. Madani BELACEL
  • Objectif : Étudier, implémenter et évaluer RPL-ClusterIDS, un système de détection d'intrusion distribué avec clustering adaptatif pour les réseaux IoT basés sur RPL
  • Nombre de sessions : 11 cours théoriques + 12 travaux pratiques (23 sessions)
  • Prérequis : Notions en réseaux IoT, protocole RPL, Contiki-NG, programmation C et Python, simulateur Cooja
  • Dépôt : github.com/madani-belacel/IDS-IOT
  • Journal cible : Computer Networks (Elsevier)
  • Année : 2025-2026

Présentation

RPL-ClusterIDS est un système de détection d'intrusion distribué (DIDS) conçu pour les réseaux IoT basés sur le protocole de routage RPL (IPv6 Routing Protocol for Low-Power and Lossy Networks). Il adopte une architecture à deux niveaux : les nœuds membres surveillent le trafic local et calculent un score d'anomalie local (LAS), tandis que les Cluster Heads (CH) agrègent ces scores pour une détection consolidée. Le clustering adaptatif repose sur une fonction d'affinité combinant puissance du signal, énergie résiduelle et confiance, avec une élection de CH basée sur une fonction de fitness multi-critères.

Le système supporte 5 types d'attaques RPL : manipulation de rang (rank attack), forwarding sélectif (selective forwarding), tunnel wormhole, inondation DAO (DAO flood) et attaques mixtes. Trois politiques contextuelles (Full, Balanced, Eco) permettent d'ajuster le niveau de surveillance en fonction de l'énergie disponible. L'évaluation comparative repose sur 7 variantes (B1, B2, B3, CLUSTERIDS, NOCLUS, NOCTX, NOENR, NOML) pour isoler l'impact de chaque composant.

Organisation recommandée

  1. Phase 1 (Cours 01-02 + TP 01-02) : Découvrez l'IDS distribué, son architecture, clonez le dépôt et compilez les variants
  2. Phase 2 (Cours 03-05 + TP 03-04) : Comprenez la formation des clusters, l'élection CH, les règles de détection, et les attaques RPL
  3. Phase 3 (Cours 06-08 + TP 05-06) : Agrégation CH, politiques contextuelles, lancez la campagne pilote et analysez les logs
  4. Phase 4 (Cours 09-11 + TP 07-12) : Ablations, métriques, pipeline complet, statistiques comparatives, figures et synthèse
