TP 04 — Génération de scénarios Cooja

TP 04 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 1 séance
  • Script : generate_campaign_csc.py

Objectif

Utiliser le script generate_campaign_csc.py pour générer les scénarios de simulation Cooja (.csc) de la campagne. Comprendre la topologie en grille (grid), la configuration des nœuds malveillants et les paramètres de simulation.

1. Localiser le script

ls SIMULATION_CAMPAIGN_READY/
# Cherchez generate_campaign_csc.py

2. Syntaxe du script

python3 generate_campaign_csc.py --help

Paramètres principaux :

  • --variant — B1, B2, B3, MAIN, NOCLUS, NOCTX, NOENR, NOML
  • --nodes — Nombre de nœuds total (ex: 50)
  • --attack — Type d'attaque (rank, sel_fwd, wormhole, dao_flood, mixed)
  • --malicious — Nombre de nœuds malveillants
  • --seed — Seed aléatoire pour la génération
  • --output — Répertoire de sortie

3. Générer un scénario simple

python3 generate_campaign_csc.py \
  --variant MAIN \
  --nodes 50 \
  --attack rank \
  --malicious 5 \
  --seed 1 \
  --output ./scenarios/

4. Comprendre la topologie en grille

La topologie par défaut est une grille régulière (5×10 pour 50 nœuds). Les nœuds sont espacés de 60-80m pour assurer une connectivité RPL. La racine (node ID 1) est placée au centre. Les nœuds malveillants sont placés aléatoirement dans la grille.

5. Examiner le fichier CSC généré

cat scenarios/MAIN_rank_50_1.csc

Identifiez les sections :

  • <simulation> — Paramètres généraux (durée, seed, etc.)
  • <field> — Dimensions du terrain
  • <mote> — Définition de chaque nœud (position, firmware, variables)
  • <plugin> — Plugins Cooja (collecte, logging, etc.)

6. Générer tous les scénarios d'une campagne

Le script peut générer l'ensemble des combinaisons variant × attaque × seed :

python3 generate_campaign_csc.py --campaign --output ./campaign_scenarios/

Cela produit les fichiers organisés par répertoire : campaign_scenarios/{VARIANT}_{ATTACK}/

7. Visualiser la topologie

Le script génère optionnellement un fichier SVG de la topologie :

python3 generate_campaign_csc.py \
  --variant MAIN --nodes 50 --attack mixed --malicious 5 --seed 1 \
  --visualize --output ./scenarios/

Rendu attendu

Générez 5 scénarios (rank, sel_fwd, wormhole, dao_flood, mixed) pour le variant MAIN et notez dans un fichier scenarios_log.txt les chemins des fichiers générés, le nombre de nœuds, et la position des nœuds malveillants.
