TP 01 — Cloner et explorer le dépôt IDS-IOT

TP 01 — Module IDS-IOT / RPL-ClusterIDS
  • Durée : 1 séance
  • Prérequis : Git, Ubuntu 22.04+

Objectif

Cloner le dépôt GitHub IDS-IOT, naviguer dans la structure du projet, et comprendre l'organisation des répertoires et des fichiers sources.

1. Cloner le dépôt

# Les codes sont déjà présents localement
# Si nécessaire, cloner depuis GitHub:
# git clone https://github.com/madani-belacel/IDS-IOT.git
cd /home/madani/contiki-ng/examples/IDS_IOT

📂 Codes sources disponibles localement : Ces codes sont déjà présents sur votre machine dans le dossier /home/madani/contiki-ng/examples/IDS_IOT. Vous pouvez également les cloner depuis GitHub si nécessaire.

2. Explorer la structure racine

ls -la

Vous devriez voir :

  • main.tex — Manuscrit au format Elsevier elsarticle
  • main-ieee.tex — Variante IEEE
  • sections/ — 11 sections LaTeX
  • tables/ — Tables II–IX
  • Figures/ — 11 figures TikZ/PGFPlots
  • SIMULATION_CAMPAIGN_READY/ — Scripts de campagne
  • code_source_RPL_ClusterIDS/ — Firmware Contiki-NG
  • data/ — Données de simulation (estimated/ et real/)
  • scripts/ — Scripts Python d'analyse et de génération
  • docker/ — Support Docker
  • anomalies/ — Rapports d'audit IA

3. Explorer le code source

cd code_source_RPL_ClusterIDS
ls -la

Identifiez les fichiers suivants :

  • clusterids-node.c — Point d'entrée du firmware IDS
  • clus_form.c / clus_form.h — Formation des clusters
  • ch_elect.c / ch_elect.h — Élection CH
  • ids_member.c / ids_member.h — Détection membre
  • ids_ch.c / ids_ch.h — Agrégation CH
  • ctx_policy.c / ctx_policy.h — Politiques contextuelles
  • ids_attack.c / ids_attack.h — Générateurs d'attaques
  • ids_campaign_log.c / ids_campaign_log.h — Log structuré

4. Examiner les variantes

ls variants/

Listez les fichiers de configuration de variantes :

  • imacros-B1.h — Standard RPL (pas d'IDS)
  • imacros-B2.h — RPL + IDS basique (pas de clustering)
  • imacros-B3.h — RPL + clustering (pas d'IDS)
  • imacros-MAIN.h — RPL-ClusterIDS complet
  • imacros-NOCLUS.h — Ablation : pas de clustering
  • imacros-NOCTX.h — Ablation : pas de politique contextuelle
  • imacros-NOENR.h — Ablation : CH non basé sur l'énergie
  • imacros-NOML.h — Ablation : pas de LAS/ML

5. Lire la documentation

Parcourez les fichiers README :

cat README.md
cat code_source_RPL_ClusterIDS/README.md

6. Vérification

À l'issue de ce TP, vous devez être capable de :

  1. Expliquer la structure générale du dépôt IDS-IOT
  2. Identifier le rôle de chaque module C
  3. Lister les 8 variantes et leur objectif
  4. Localiser les scripts de campagne et les données

Rendu attendu

Rédigez un fichier structure_depot.txt contenant l'arborescence commentée du dépôt (au moins 15 lignes).
