TP 01 — Cloner et explorer le dépôt RPLCB

Cloner et explorer le dépôt RPLCB
  • Durée : 2h TP
  • Objectif : Cloner le dépôt GitHub RPLCB et explorer sa structure
  • Prérequis : Git installé, compte GitHub (optionnel)

1. Cloner le dépôt

Ouvrez un terminal et exécutez :

# Les codes sont déjà présents localement
# Si nécessaire, cloner depuis GitHub:
# git clone https://github.com/madani-belacel/RPLCB.git
# Aller dans le dossier des codes locaux
cd /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL

📂 Codes sources disponibles localement : Ces codes sont déjà présents sur votre machine dans le dossier /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL. Vous pouvez également les cloner depuis GitHub si nécessaire.

2. Explorer la structure

Listez le contenu du dépôt :

ls -la
ls -la /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/

Vous devriez voir :

  • /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPL/ — Version standard de l'application UDP
  • /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPLCB/ — Version avec Control Bit
  • /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/sim_25.csc — Simulation 25 nœuds
  • /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/sim_50.csc — Simulation 50 nœuds
  • /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/sim_80.csc — Simulation 80 nœuds
  • /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/plot_lifetime_analysis.py — Script Python d'analyse

3. Examiner les sources RPL

cat /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPL/udp-client.c
cat /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPL/udp-server.c
cat /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPL/Makefile

Remarquez l'utilisation de l'API Contiki-NG : PROCESS_THREAD, UDP_CONNECTION, etc.

4. Examiner les sources RPLCB

diff /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPL/udp-client.c /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPLCB/udp-client.c

Cette commande diff montre les différences entre les deux versions. Cherchez les lignes contenant "cb" ou "control_bit".

5. Examiner le Makefile

cat /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPL/Makefile
cat /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPLCB/Makefile

Comparez les deux Makefiles. Notez les modules inclus (ex: MODULES += ...).

6. Examiner les fichiers de simulation CSC

Les fichiers .csc sont au format XML. Ouvrez sim_25.csc :

head -100 /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/sim_25.csc

Identifiez : le type de radio (UDGM), la durée de simulation, les positions des nœuds.

7. Questions et rendu

  1. Quelle est la différence principale entre les fichiers udp-client.c de RPL et RPLCB ?
  2. Combien de nœuds sont définis dans sim_25.csc ?
  3. Quels modules supplémentaires sont inclus dans le Makefile RPLCB ?
  4. Décrivez l'arborescence complète du dépôt.
