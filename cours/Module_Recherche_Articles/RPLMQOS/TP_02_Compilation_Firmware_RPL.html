TP 02 — Compilation du firmware RPL standard

Compilation du firmware RPL standard
  • Durée : 2h TP
  • Objectif : Compiler le firmware RPL standard pour Cooja
  • Prérequis : Contiki-NG installé, TP 01 réalisé

1. Vérifier l'environnement

Avant de compiler, assurez-vous que Contiki-NG est correctement installé :

which msp430-gcc || which arm-none-eabi-gcc
echo $CONTIKI
ls $CONTIKI

Si $CONTIKI n'est pas défini, définissez-le :

export CONTIKI=/home/madani/contiki-ng

2. Compiler le firmware RPL standard

Placez-vous dans le répertoire RPL et lancez la compilation :

cd /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPL
make TARGET=cooja clean
make TARGET=cooja udp-server.cooja
make TARGET=cooja udp-client.cooja

3. Vérifier la compilation

Si la compilation réussit, vous obtiendrez des fichiers .cooja :

ls -la *.cooja
ls -la build/

Vérifiez la taille des fichiers : un firmware typique fait entre 40 et 60 Ko.

4. Résoudre les erreurs courantes

ErreurCause probableSolution
msp430-gcc: command not foundChaîne de compilation manquanteapt install gcc-msp430
CONTIKI not definedVariable d'environnement manquanteexport CONTIKI=...
make: *** No rule to make targetMakefile incorrectVérifier le nom du projet dans Makefile
undefined referenceModule manquantVérifier MODULES dans Makefile

5. Examiner le résultat de compilation

Le fichier .cooja est le firmware binaire qui sera chargé dans les nœuds simulés Cooja. Il contient le code compilé pour l'architecture cible (par défaut : Z1 mote).
