RPLMQOS — Protocole RPLCB

Module : Recherche & Articles — RPLMQOS / RPLCB
  • Auteur : Dr. Madani BELACEL
  • Objectif : Étudier, implémenter et évaluer le protocole RPLCB (RPL Control Bit), une extension QoS de RPL pour les réseaux de capteurs sans fil
  • Nombre de sessions : 9 cours théoriques + 13 travaux pratiques (22 sessions)
  • Prérequis : Notions en réseaux IoT, protocole RPL, Contiki-NG, programmation C et Python
  • Dépôt : github.com/madani-belacel/RPLCB
  • Année : 2025-2026

Présentation

RPLCB (RPL Control Bit) est un protocole de routage proposé pour les réseaux de capteurs sans fil (WSN) basé sur RPL (IPv6 Routing Protocol for Low-Power and Lossy Networks). L'idée principale est d'ajouter un bit de contrôle (Control Bit) dans les messages de routage pour permettre une sélection de parent basée sur des métriques multiples (PDR, latence, énergie résiduelle) au lieu de la métrique unique ETX utilisée par RPL standard. Ce module de 22 sessions couvre la théorie, l'implémentation et l'évaluation complète de RPLCB par simulation sur Contiki-NG/Cooja.

Organisation recommandée

  1. Phase 1 (Cours 01-03 + TP 01-03) : Découvrez RPLCB, son architecture, et mettez en place l'environnement de compilation
  2. Phase 2 (Cours 04-05 + TP 04-05) : Lancez les premières simulations et observez le comportement des protocoles
  3. Phase 3 (Cours 06 + TP 06-09) : Collectez et analysez les données comparatives (énergie, latence, PDR, durée de vie)
  4. Phase 4 (Cours 07-09 + TP 10-13) : Exploitez les scripts Python, générez des figures, menez l'évaluation complète
