Cours 06 — Analyse comparative RPL vs RPLCB

Analyse comparative RPL vs RPLCB
  • Durée : 2h CM
  • Objectif : Maîtriser la méthodologie de comparaison et l'analyse statistique des résultats

1. Méthodologie de comparaison

La comparaison entre RPL et RPLCB doit suivre une méthodologie rigoureuse :

  1. Mêmes conditions expérimentales : même topologie, même trafic, même seed pour chaque paire de runs
  2. Répétitions multiples : au moins 10 runs indépendants par configuration
  3. Mesures synchronisées : collecter les métriques aux mêmes instants dans les deux protocoles
  4. Analyse statistique : moyenne, écart-type, intervalles de confiance, tests de significativité

2. Analyse statistique

Pour chaque métrique, on calcule :

  • Moyenne : &bar;x = (1/n) ∑ x_i
  • Écart-type : s = sqrt( ∑(x_i - &bar;x)² / (n-1) )
  • Intervalle de confiance à 95% : IC = &bar;x ± t_(n-1, 0.025) s / sqrt(n)

L'intervalle de confiance permet de déterminer si la différence entre RPL et RPLCB est statistiquement significative. Si les IC ne se chevauchent pas, la différence est significative.

3. Test de Student (t-test)

Le test de Student permet de comparer les moyennes de deux échantillons (RPL et RPLCB) :

H₀ : μ_RPL = μ_RPLCB (pas de différence)
H₁ : μ_RPL ≠ μ_RPLCB (différence significative)

t = (&bar;x₁ - &bar;x₂) / sqrt(s₁²/n₁ + s₂²/n₂)

Si |t| > t_critique, on rejette H₀.

4. Analyse par densité de nœuds

L'analyse comparative doit être menée pour chaque densité (25, 50, 80 nœuds) :

  • 25 nœuds : faible densité, peu d'interférences, RPL et RPLCB proches
  • 50 nœuds : densité moyenne, les différences commencent à apparaître
  • 80 nœuds : forte densité, les avantages de RPLCB sont les plus visibles

5. Visualisation des résultats

Les graphiques typiques pour la comparaison sont :

  • Boîtes à moustaches (box plots) : distribution des métriques pour chaque protocole
  • Graphiques en barres : moyenne + barre d'erreur (IC 95%)
  • Courbes d'évolution : métrique en fonction du nombre de nœuds
  • Heatmaps : consommation d'énergie spatiale

6. Questions de révision

  1. Pourquoi est-il important d'utiliser les mêmes seeds pour RPL et RPLCB ?
  2. Interprétez un intervalle de confiance à 95%.
  3. Si l'IC de RPL est [85, 92] et celui de RPLCB est [88, 95], peut-on conclure à une différence significative ? Justifiez.
  4. Quel test statistique recommandez-vous pour comparer RPL et RPLCB ?
  5. Comment la densité de nœuds influence-t-elle les performances relatives de RPLCB ?
