TP 10 — Scripts Python d'analyse RPLCB

Scripts Python d'analyse
  • Durée : 2h TP
  • Objectif : Comprendre et modifier le script plot_lifetime_analysis.py
  • Prérequis : Python 3, matplotlib, numpy installés

1. Explorer le script plot_lifetime_analysis.py

cat /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/plot_lifetime_analysis.py

Ce script Python analyse les données de durée de vie extraites des simulations RPL et RPLCB. Identifiez :

  • Les bibliothèques importées (matplotlib, numpy, csv)
  • Les fonctions définies
  • Le format de données attendu
  • Les figures générées

2. Exécuter le script

Placez vos données dans le format attendu et exécutez :

cd projet-RPLCB
python3 plot_lifetime_analysis.py

Les figures générées (PNG) apparaissent dans le répertoire courant.

3. Comprendre le code

Le script contient typiquement :

  • Une fonction load_energest_data(filename) pour charger les données
  • Une fonction compute_lifetime(energy_data) pour estimer la durée de vie
  • Une fonction plot_lifetime_comparison(rpl_data, rplcb_data) pour générer la figure

4. Ajouter une nouvelle métrique

Modifiez le script pour ajouter l'analyse du PDR en plus de la durée de vie :

def plot_pdr_comparison(rpl_pdr, rplcb_pdr):
    """Ajoute un graphique comparatif du PDR."""
    fig, ax = plt.subplots()
    ax.bar(['RPL', 'RPLCB'], [rpl_pdr, rplcb_pdr])
    ax.set_ylabel('PDR (%)')
    ax.set_title('Comparaison du PDR')
    plt.savefig('pdr_comparison.png')

5. Personnaliser les figures

Améliorez la qualité des figures pour publication :

  • Utilisez plt.style.use('seaborn-v0_8-whitegrid')
  • Ajoutez des barres d'erreur (écart-type)
  • Modifiez les couleurs (bleu RPL, orange RPLCB)
  • Sauvegardez en haute résolution : plt.savefig('fig.png', dpi=300)

6. Questions et rendu

  1. Expliquez le fonctionnement de la fonction compute_lifetime().
  2. Quelles figures sont générées par le script original ?
  3. Ajoutez la métrique PDR au script et générez la figure correspondante.
  4. Comparez les figures générées avec et sans barres d'erreur.
