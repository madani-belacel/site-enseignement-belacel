TP 02 — Compilation du firmware RPL-MQoS

2h TP
  • Durée : 2h TP
  • Objectif : Compiler le firmware pour Sky

1. Vérification des prérequis

$ command -v msp430-gcc && echo "OK" || echo "MANQUANT"

2. Compilation

$ cd /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL
$ make TARGET=sky 2>&1
  CC       rpl-mqos-example.c
  CC       src/rpl-mqos.c
  CC       src/rpl-mqos-metrics.c
  LD       rpl-mqos-example.sky
  text    data     bss     dec     hex
  45236   1236    9876   56348    dc1c

3. Vérification du binaire

$ ls -la rpl-mqos-example.sky && file rpl-mqos-example.sky
-rw-rw-r-- 1 user user 56348 ... rpl-mqos-example.sky
MSP430 IEEE695 object file (COFF)
Dépannage
  • Problème : msp430-gcc not found
    Solution : cd $HOME/contiki-ng/tools && sudo ./install-msp430.sh
  • Problème : contiki.h not found
    Solution : Vérifier CONTIKI dans le Makefile
Questions
  1. Taille du binaire ? (56348)
  2. Que signifient text/data/bss ?
  3. Commande pour nettoyer ? (make TARGET=sky clean)
