TP 12 — Génération de figures pour publication

Génération de figures pour publication
  • Durée : 3h TP
  • Objectif : Produire des figures de qualité publication pour un journal (Computer Networks)
  • Prérequis : Toutes les données collectées, TP 10-11 réalisés

1. Standards pour Computer Networks (Elsevier)

  • Format : PDF (vectoriel) ou PNG 300 DPI minimum
  • Dimensions : 1 colonne (85 mm) ou 2 colonnes (170 mm)
  • Polices : Arial ou Helvetica, 8-10 pt
  • Couleurs : adaptées pour impression N/B
  • Légendes : auto-explicatives, en dessous de la figure

2. Figure 1 : PDR comparison

import matplotlib.pyplot as plt
import numpy as np

nodes = [25, 50, 80]
rpl_mean = [91.2, 85.6, 78.3]
rpl_std = [2.1, 3.4, 4.2]
rplcb_mean = [93.1, 89.4, 84.7]
rplcb_std = [1.8, 2.7, 3.5]

fig, ax = plt.subplots(figsize=(3.5, 2.5))  # 1 colonne
x = np.arange(len(nodes))
w = 0.35
ax.bar(x - w/2, rpl_mean, w, yerr=rpl_std, label='RPL', capsize=3)
ax.bar(x + w/2, rplcb_mean, w, yerr=rplcb_std, label='RPLCB', capsize=3)
ax.set_xticks(x)
ax.set_xticklabels([f'{n} nœuds' for n in nodes])
ax.set_ylabel('PDR (%)')
ax.legend()
plt.tight_layout()
plt.savefig('fig1_pdr.pdf', dpi=300)

3. Figure 2 : Box plot latence

fig, ax = plt.subplots(figsize=(3.5, 3))
data = [rpl_lat_25, rpl_lat_50, rpl_lat_80,
        rplcb_lat_25, rplcb_lat_50, rplcb_lat_80]
labels = ['RPL-25', 'RPL-50', 'RPL-80',
          'RPLCB-25', 'RPLCB-50', 'RPLCB-80']
colors = ['#3498db']*3 + ['#e67e22']*3
bp = ax.boxplot(data, labels=labels, patch_artist=True)
for patch, color in zip(bp['boxes'], colors):
    patch.set_facecolor(color)
ax.set_ylabel('Latence (ms)')
plt.xticks(rotation=45)
plt.tight_layout()
plt.savefig('fig2_latence.pdf', dpi=300)
