TP 08 — Analyse de la latence et du PDR

Analyse de la latence et du PDR
  • Durée : 2h TP
  • Objectif : Calculer et comparer la latence et le PDR entre RPL et RPLCB
  • Prérequis : TP 06 réalisé, logs disponibles

1. Structure des logs Cooja

Les logs Cooja contiennent des lignes de ce type :

ID:1  Timestamp: 123456  "Sending seqno 42"
ID:3  Timestamp: 124567  "Received seqno 42 from 1"

2. Calcul du PDR

Le PDR (Packet Delivery Ratio) se calcule simplement :

# Compter les paquets émis
EMIS=$(grep "Sending" rpl_25.log | wc -l)
# Compter les paquets reçus (côté serveur)
RECUS=$(grep "Received" rpl_25.log | wc -l)
PDR=$(echo "scale=2; $RECUS * 100 / $EMIS" | bc)
echo "PDR = $PDR%"

3. Calcul de la latence

Pour chaque paquet, la latence est la différence entre timestamp de réception et d'émission :

import re

emissions = {}  # seqno -> timestamp
receps = {}     # seqno -> timestamp

with open("sim.log") as f:
    for line in f:
        m = re.search(r"Sending seqno (\d+)", line)
        if m:
            ts = int(re.search(r"Timestamp: (\d+)", line).group(1))
            emissions[m.group(1)] = ts
        m = re.search(r"Received seqno (\d+)", line)
        if m:
            ts = int(re.search(r"Timestamp: (\d+)", line).group(1))
            receps[m.group(1)] = ts

latences = []
for seqno in receps:
    if seqno in emissions:
        lat = receps[seqno] - emissions[seqno]
        latences.append(lat)

print(f"Latence moyenne: {sum(latences)/len(latences):.2f} ms")
print(f"Latence max: {max(latences):.2f} ms")
print(f"Latence min: {min(latences):.2f} ms")
