TP 03 — Compilation du firmware RPLCB

Compilation du firmware RPLCB
  • Durée : 2h TP
  • Objectif : Compiler le firmware RPLCB et comparer avec RPL standard
  • Prérequis : TP 02 réalisé

1. Compiler le firmware RPLCB

Placez-vous dans le répertoire RPLCB et compilez :

cd /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/RPLCB
make TARGET=cooja clean
make TARGET=cooja udp-server.cooja
make TARGET=cooja udp-client.cooja

2. Comparer les tailles

Comparez les tailles des firmwares RPL et RPLCB :

ls -la ../RPL/*.cooja
ls -la *.cooja

La différence de taille correspond à l'ajout du code CB.

3. Analyser les différences de compilation

Examinez les logs de compilation pour repérer les fichiers compilés supplémentaires :

make TARGET=cooja udp-server.cooja 2>&1 | grep -E "CC|LD"

4. Examiner le Makefile RPLCB

cat Makefile

Comparez-le avec le Makefile RPL :

diff ../RPL/Makefile Makefile

Repérez les différences dans les MODULES inclus.

5. Vérifier les symboles CB

Utilisez nm ou objdump pour vérifier que les symboles liés au CB sont présents :

nm udp-server.cooja | grep -i cb
nm udp-server.cooja | grep control

6. Questions et rendu

  1. Quelle est la différence de taille entre le firmware RPL et RPLCB ?
  2. Quels fichiers supplémentaires sont compilés dans RPLCB ?
  3. Y a-t-il des warnings spécifiques à RPLCB ?
  4. Expliquez comment le Makefile inclut les modules nécessaires au CB.
