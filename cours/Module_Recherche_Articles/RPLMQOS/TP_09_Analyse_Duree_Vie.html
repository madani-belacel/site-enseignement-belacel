TP 09 — Analyse de la durée de vie

Analyse de la durée de vie
  • Durée : 2h TP
  • Objectif : Calculer et comparer la durée de vie du réseau RPL vs RPLCB
  • Prérequis : Données d'énergie collectées (TP 07)

1. Estimation de la durée de vie à partir de l'énergie

À partir de la consommation d'énergie mesurée sur une simulation de durée T, on estime la durée de vie :

Batterie = 2000 mAh, Tension = 3V
Énergie_totale = 2000  3  3.6 = 21600 J

Puissance_moyenne = Énergie_consommée / T_simulation
Durée_de_vie = Énergie_totale / Puissance_moyenne

2. Calcul du FND (First Node Death)

Le FND est le temps où le premier nœud épuise sa batterie. Pour le déterminer :

  1. Pour chaque nœud, calculez la puissance moyenne consommée
  2. Estimez le temps d'épuisement : T_vie_i = E_batterie / P_i
  3. FND = min(T_vie_i) sur tous les nœuds

3. Script Python pour la durée de vie

import csv

BATTERY_MAH = 2000
VOLTAGE = 3.0
ENERGY_J = BATTERY_MAH * VOLTAGE * 3.6

nodes_lifetime = []
with open('energest_rpl_25.csv') as f:
    for line in f:
        if line.startswith('#'):
            continue
        parts = line.strip().split(',')
        node_id = parts[1]
        t_cpu, t_lpm, t_tx, t_rx = map(float, parts[2:6])
        sim_time = float(parts[0]) / 1000  # ms -> s
        
        p_cpu = t_cpu * 1.8e-3 * VOLTAGE / sim_time
        p_lpm = t_lpm * 0.0545e-3 * VOLTAGE / sim_time
        p_tx = t_tx * 17.4e-3 * VOLTAGE / sim_time
        p_rx = t_rx * 19.7e-3 * VOLTAGE / sim_time
        p_total = p_cpu + p_lpm + p_tx + p_rx
        
        lifetime = ENERGY_J / p_total if p_total > 0 else float('inf')
        nodes_lifetime.append(lifetime)
        print(f"Node {node_id}: {lifetime/3600:.2f} hours")

nodes_lifetime.sort()
fnd = nodes_lifetime[0]
hnd = nodes_lifetime[len(nodes_lifetime)//2]
lnd = nodes_lifetime[-1]
print(f"FND: {fnd/3600:.2f}h, HND: {hnd/3600:.2f}h, LND: {lnd/3600:.2f}h")
