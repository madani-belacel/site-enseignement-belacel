TP 07 — Analyse de la consommation d'énergie

Analyse de la consommation d'énergie
  • Durée : 2h TP
  • Objectif : Analyser et comparer la consommation d'énergie entre RPL et RPLCB
  • Prérequis : TP 06 réalisé, données energest collectées

1. Format des logs Energest

Les logs Energest dans Cooja ont ce format :

# Time, Node, CPU (s), LPM (s), TX (s), RX (s)
300000,1,12.34,156.78,5.21,8.43
300000,2,11.22,158.90,4.87,7.65
...

2. Calculer l'énergie par nœud

Utilisez les paramètres de consommation du CC2420 :

  • CPU actif : 1.8 mA 3V = 5.4 mW
  • LPM : 0.0545 mA 3V = 0.1635 mW
  • TX : 17.4 mA 3V = 52.2 mW
  • RX : 19.7 mA 3V = 59.1 mW
Énergie (mJ) = temps_CPU  5.4 + temps_LPM  0.1635
              + temps_TX  52.2 + temps_RX  59.1

3. Script Python pour l'énergie

import csv
import sys

I_CPU, I_LPM, I_TX, I_RX = 1.8, 0.0545, 17.4, 19.7
V = 3.0

def energy_from_times(t_cpu, t_lpm, t_tx, t_rx):
    return (t_cpu*I_CPU + t_lpm*I_LPM + t_tx*I_TX + t_rx*I_RX) * V

with open(sys.argv[1]) as f:
    for line in f:
        if line.startswith('#'):
            continue
        parts = line.strip().split(',')
        t_cpu, t_lpm, t_tx, t_rx = map(float, parts[2:6])
        e = energy_from_times(t_cpu, t_lpm, t_tx, t_rx)
        print(f"Node {parts[1]}: {e:.2f} mJ")
