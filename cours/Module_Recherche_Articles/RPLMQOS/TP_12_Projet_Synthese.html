TP 12 — Projet de synthèse

4h TP
  • Durée : 4h TP
  • Objectif : Réaliser une évaluation complète de RPL-MQoS

1. Objectifs

  1. Compiler le firmware pour Sky et Zoul
  2. Simuler avec Cooja (25, 50, 80 nœuds)
  3. Collecter les logs de simulation
  4. Analyser PDR, latence, ETX moyen
  5. Comparer avec RPL standard
  6. Rédiger un rapport d'analyse

2. Grille d'évaluation

CritèrePoints
Compilation réussie (2 plateformes)2 pts
Simulation 25 nœuds + logs3 pts
Analyse PDR et ETX3 pts
Analyse énergétique2 pts
Comparaison RPL vs RPL-MQoS3 pts
Rapport et conclusions2 pts
Total15 pts

3. Livrables

  • Code source compilé (.sky, .zoul)
  • Logs de simulation (3 scénarios)
  • Script d'analyse Python
  • Rapport (PDF, 4-6 pages)

4. Questions de synthèse

Questions
  1. Quels sont les avantages mesurables de RPL-MQoS par rapport à RPL standard ?
  2. Comment les poids des métriques influencent-ils la sélection de parent ?
  3. Quel est l'impact du nombre de nœuds sur le PDR et la latence ?
  4. Proposez une extension à RPL-MQoS et justifiez son intérêt.
  5. Quelles limites avez-vous identifiées dans l'implémentation actuelle ?
