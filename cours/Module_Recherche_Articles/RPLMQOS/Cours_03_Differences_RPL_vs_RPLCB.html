Cours 03 — Différences entre RPL standard et RPLCB

Différences RPL vs RPLCB
  • Durée : 2h CM
  • Objectif : Analyser systématiquement les différences entre RPL standard et RPLCB

2. Différence dans la construction du DODAG

Dans RPL standard, le DODAG est construit uniquement sur la base du rang (rank), lui-même calculé à partir de l'ETX. Chaque nœud choisit le parent avec le plus faible ETX vers le root. Dans RPLCB, la construction du DODAG suit les mêmes étapes, mais avec une étape supplémentaire :

  1. Un nœud reçoit des DIO de plusieurs parents potentiels
  2. Étape RPL standard : classer les parents par ETX croissant
  3. Étape RPLCB supplémentaire : exclure tous les parents avec CB=1
  4. Sélectionner le parent avec le meilleur ETX parmi les candidats restants

3. Analyse de l'overhead

L'overhead supplémentaire de RPLCB est minimal :

  • Overhead par message DIO : +1 octet (option CB : 1 octet Type + 1 octet Length + 1 octet valeur) — soit 3 octets supplémentaires
  • Fréquence des messages : identique à RPL standard (pas de messages supplémentaires)
  • Overhead de traitement : négligeable (comparaison d'un bit supplémentaire)

Dans un réseau de 50 nœuds avec 1000 échanges DIO, l'overhead total ajouté par RPLCB est d'environ 3 Ko, ce qui est négligeable devant le trafic de données.

4. Cas où RPLCB surpasse RPL

Les simulations montrent que RPLCB est particulièrement bénéfique dans les scénarios suivants :

  • Réseaux hétérogènes : nœuds avec capacités énergétiques différentes (certains sur batterie, d'autres sur secteur)
  • Fort trafic : lorsque la congestion est fréquente, le CB permet d'éviter les nœuds saturés
  • Applications QoS-sensibles : trafic prioritaire qui doit éviter les nœuds à faible énergie
  • Longues durées de vie requises : le CB permet de préserver les nœuds les plus faibles
