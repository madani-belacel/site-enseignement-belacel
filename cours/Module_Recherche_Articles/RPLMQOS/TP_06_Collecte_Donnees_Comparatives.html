TP 06 — Collecte données comparatives

Collecte données comparatives
  • Durée : 2h TP
  • Objectif : Collecter et organiser les données des simulations RPL et RPLCB
  • Prérequis : TP 04 et TP 05 réalisés

1. Exécuter les simulations avec la même seed

Pour une comparaison valide, les deux simulations doivent partager la même graine aléatoire :

Simulation 1 (RPL) : seed = 12345
Simulation 2 (RPLCB) : seed = 12345 (identique)

Dans Cooja, modifiez la seed via Settings -> Random seed.

2. Exporter les logs

Après chaque simulation extrayez :

  • Le log des messages Cooja (tout le trafic)
  • Le log de l'analyseur de puissance (energest)
  • Le compteur de paquets reçus (côté serveur)

Convention de nommage :

rpl_25_seed12345.log
rplcb_25_seed12345.log
rpl_25_seed12345_energest.log
rplcb_25_seed12345_energest.log

3. Structurer les données en CSV

Créez un fichier CSV pour chaque métrique. Exemple pour le PDR :

Protocole, NbNoeuds, Seed, PaquetsEmis, PaquetsRecus, PDR
RPL,25,12345,750,682,90.93
RPLCB,25,12345,750,698,93.07

4. Organiser le répertoire de données

data/
  RPL/
    25_noeuds/
      seed_12345/
        sim.log
        energest.log
      seed_12346/
        ...
    50_noeuds/
    80_noeuds/
  RPLCB/
    (même structure)

5. Script de parsing simple (bash)

#!/bin/bash
# Extraire le PDR des logs
LOG=$1
EMIS=$(grep "Sending" $LOG | wc -l)
RECUS=$(grep "Received" $LOG | wc -l)
PDR=$(echo "scale=2; $RECUS * 100 / $EMIS" | bc)
echo "PDR: $PDR%"
