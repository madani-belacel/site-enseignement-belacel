TP 11 — Simulations à densité variable

Simulations à densité variable
  • Durée : 3h TP
  • Objectif : Évaluer la scalabilité de RPL et RPLCB avec 25, 50 et 80 nœuds
  • Prérequis : TP 04-09 réalisés (maîtrise des simulations)

2. Automatisation des simulations

Créez un script bash pour lancer les simulations en batch :

#!/bin/bash
# run_all_simulations.sh
SEEDS=(12345 12346 12347 12348 12349 12350 12351 12352 12353 12354)
PROTOCOLS=("RPL" "RPLCB")
NODES=(25 50 80)

for proto in "${PROTOCOLS[@]}"; do
  for nodes in "${NODES[@]}"; do
    for seed in "${SEEDS[@]}"; do
      echo "Running $proto ${nodes}n seed=$seed"
      # Lancer Cooja en mode non-interactif
      # java -jar cooja.jar -nogui=sim_${nodes}.csc ...
    done
  fi
done

3. Analyser la scalabilité

Pour chaque métrique, créez un graphique de scalabilité : axe X = nombre de nœuds, axe Y = valeur de la métrique. Deux courbes : RPL et RPLCB. Ces graphiques montrent comment chaque protocole se comporte quand le réseau grandit.

4. Créer les courbes de scalabilité

import matplotlib.pyplot as plt
import numpy as np

nodes = [25, 50, 80]
rpl_pdr = [91.2, 85.6, 78.3]
rplcb_pdr = [93.1, 89.4, 84.7]

plt.plot(nodes, rpl_pdr, 'o-', label='RPL')
plt.plot(nodes, rplcb_pdr, 's-', label='RPLCB')
plt.xlabel('Nombre de nœuds')
plt.ylabel('PDR (%)')
plt.legend()
plt.grid()
plt.savefig('scalability_pdr.png', dpi=300)
