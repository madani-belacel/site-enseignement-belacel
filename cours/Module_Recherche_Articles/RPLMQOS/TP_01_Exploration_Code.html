TP 01 — Exploration du code source RPL-MQoS

2h TP
  • Durée : 2h TP
  • Objectif : Explorer la structure du projet

1. Naviguer dans le projet

$ cd /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL
$ ls -la

2. Compter les lignes

$ wc -l src/*.c include/*.h Makefile project-conf.h

 391 src/rpl-mqos-metrics.c

  59 include/rpl-mqos-metrics.h

3. Examiner le Makefile
