TP 04 — Simulation scénario RPL 25 nœuds

Simulation RPL 25 nœuds
  • Durée : 2h TP
  • Objectif : Lancer la simulation RPL avec 25 nœuds dans Cooja
  • Prérequis : Firmware RPL compilé, TP 01-03 réalisés

1. Lancer Cooja

cd contiki-ng/tools/cooja
ant run

Ou utilisez le script :

./gradlew run

2. Ouvrir le fichier de simulation

Dans Cooja : File -> Open Simulation, naviguez jusqu'à /home/madani/contiki-ng/examples/projet_madani/RPLMQoS_BELACEL/sim_25.csc.

La simulation s'ouvre avec 25 nœuds disposés en grille 5x5. Identifiez :

  • Le nœud 1 (root) : souvent au centre ou au bord
  • Les nœuds clients UDP : les autres nœuds
  • La portée radio (cercle autour de chaque nœud)

3. Configurer les firmwares

Vérifiez que chaque nœud utilise le firmware RPL standard compilé :

  • Motivations -> charger firmware
  • Le serveur (root) utilise udp-server.cooja
  • Les clients utilisent udp-client.cooja

4. Lancer la simulation

Cliquez sur le bouton Start. Observez :

  • La formation du DODAG (messages DIO diffusés)
  • L'échange de paquets UDP (couleurs dans le Network Viewer)
  • Le temps simulé (en bas à droite)

5. Collecter les logs

Activez le logging : Tools -> Log output. Sauvegardez les logs :

Fichier -> Save log as -> rpl_25_noeuds.log

6. Observer le DODAG

Utilisez le Network Viewer pour visualiser le DODAG. Les lignes représentent les liens parent-enfant. Notez la profondeur et la distribution.

7. Questions et rendu

  1. Combien de temps a duré la simulation (temps simulé) ?
  2. Quelle est la topologie du DODAG formé ? (profondeur, nombre de niveaux)
  3. Combien de paquets UDP ont été reçus par le root ?
  4. Notez les observations sur le comportement de RPL standard.
