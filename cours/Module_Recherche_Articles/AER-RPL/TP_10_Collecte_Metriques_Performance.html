TP 10 : Collecte des métriques de performance

TP 10 — Collecte des métriques de performance
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Collecter et organiser les métriques de performance RPL-AER

1. Extraire les logs PERF

Les logs de performance sont générés par le sink sous le format [PERF] :

grep "\[PERF\]" simulation_logs.txt > perf_logs.txt

2. Format des logs PERF

[PERF] Time=360s Nodes=40 PDR=97.5% Latency=18.3ms Throughput=312bps Power=4.2mW
[PERF] Time=720s Nodes=40 PDR=96.8% Latency=21.5ms Throughput=298bps Power=4.1mW

3. Parser et structurer

import re
import csv

perf_data = []
with open('perf_logs.txt') as f:
    for line in f:
        m = re.search(r'Time=(\d+)s.*PDR=([\d.]+)% Latency=([\d.]+)ms Throughput=(\d+)bps Power=([\d.]+)mW', line)
        if m:
            perf_data.append({
                'time': int(m.group(1)),
                'pdr': float(m.group(2)),
                'latency': float(m.group(3)),
                'throughput': int(m.group(4)),
                'power': float(m.group(5))
            })

# Calculer les statistiques globales
pdr_values = [d['pdr'] for d in perf_data]
lat_values = [d['latency'] for d in perf_data]
thr_values = [d['throughput'] for d in perf_data]

print(f"PDR: min={min(pdr_values):.1f}% avg={sum(pdr_values)/len(pdr_values):.1f}% max={max(pdr_values):.1f}%")
print(f"Latence: min={min(lat_values):.1f}ms avg={sum(lat_values)/len(lat_values):.1f}ms")
print(f"Throughput: min={min(thr_values)}bps avg={sum(thr_values)/len(thr_values):.0f}bps")

Générez un fichier de résumé structuré :

5. Créer un fichier CSV

with open('performance_metrics.csv', 'w', newline='') as f:
    writer = csv.DictWriter(f, fieldnames=['time','pdr','latency','throughput','power'])
    writer.writeheader()
    writer.writerows(perf_data)

6. Visualiser les métriques

import matplotlib.pyplot as plt

times = [d['time'] for d in perf_data]
pdr = [d['pdr'] for d in perf_data]

plt.plot(times, pdr, 'b-', marker='s')
plt.xlabel('Temps (s)')
plt.ylabel('PDR (%)')
plt.ylim(90, 100)
plt.grid(True)
plt.title('Évolution du PDR au fil du temps')
plt.savefig('pdr_evolution.png')
plt.show()
