TP 07 : Simulation avec attaques

TP 07 — Simulation avec attaques
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Configurer des nœuds attaquants, observer la détection, comparer les Trust scores

1. Comprendre la configuration des attaques

RPL-AER permet de configurer des nœuds malveillants dans project-conf.h :

#define ATTACK_SINKHOLES      1    // Activer l'attaque sinkhole
#define ATTACK_SINKHOLE_NODES 22,25  // IDs des nœuds attaquants
#define ATTACK_SF_ENABLED     1    // Activer selective forwarding
#define ATTACK_SF_NODES       30     // ID du nœud attaquant

2. Lancer la simulation avec attaques

Ouvrez la simulation et activez les nœuds attaquants. Lancez la simulation et observez :

  • Les logs [ATTACK] générés par attack_detector.c
  • Les logs [TRUST] montrant la dégradation du Trust score
  • L'évolution du PDR (Packet Delivery Ratio)

3. Extraire les logs de confiance

grep "\[TRUST\]" simulation_logs.txt > trust_logs.txt

4. Analyser les Trust scores

import re
import matplotlib.pyplot as plt

trust_data = []
with open('trust_logs.txt') as f:
    for line in f:
        m = re.search(r'Node (\d+): Neighbor (\d+) Trust=([\d.]+)', line)
        if m:
            trust_data.append({
                'observer': int(m.group(1)),
                'target': int(m.group(2)),
                'trust': float(m.group(3))
            })

# Trust score moyen des nœuds attaquants vs honnêtes
attack_nodes = [22, 25, 30]
attack_trust = [d['trust'] for d in trust_data if d['target'] in attack_nodes]
honest_trust = [d['trust'] for d in trust_data if d['target'] not in attack_nodes]

print(f"Trust moyen attaquants: {sum(attack_trust)/len(attack_trust):.3f}")
print(f"Trust moyen honnêtes: {sum(honest_trust)/len(honest_trust):.3f}")

5. Évolution temporelle du Trust

# Pour le nœud attaquant 22
node22_trust = [d for d in trust_data if d['target'] == 22]
trust_values = [d['trust'] for d in node22_trust]

plt.plot(trust_values, 'r-', label='Nœud 22 (attaquant)')
plt.axhline(y=0.3, color='gray', linestyle='--', label='Seuil malveillant')
plt.xlabel('Observation')
plt.ylabel('Trust Score')
plt.legend()
plt.title('Évolution du Trust Score — Attaquant Sinkhole')
plt.savefig('trust_attacker.png')
plt.show()

6. Mesurer le taux de détection

# Combien de fois les attaquants sont-ils identifiés comme malveillants ?
flagged = [d for d in trust_data if d['trust'] < 0.3]
flagged_attackers = [d for d in flagged if d['target'] in attack_nodes]
detection_rate = len(flagged_attackers) / len(flagged) * 100 if flagged else 0
print(f"Taux de détection: {detection_rate:.1f}%")

7. Comparer PDR avec et sans attaques

Relancez la simulation SANS attaques (désactivez ATTACK_SINKHOLES et ATTACK_SF_ENABLED). Comparez le PDR :

# Extraire PDR des logs [PERF]
grep "\[PERF\]" simulation_logs.txt | grep "PDR"
