TP 08 : Scripts de génération de scénarios

TP 08 — Scripts de génération de scénarios
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 45 minutes
  • Objectifs : Générer des scénarios de simulation avec des paramètres variés

1. Scripts de génération de scénarios

Le script generate_csc.py permet de générer des fichiers de simulation Cooja avec des paramètres personnalisés.

Objectifs pédagogiques
  • Comprendre le fonctionnement du script generate_csc.py
  • Générer des scénarios avec différentes configurations
  • Analyser l'impact des paramètres sur la topologie
  • Automatiser la génération de multiples scénarios

2. Exploration du script

python3 generate_csc.py --help

Paramètres disponibles :

  • -n : Nombre de nœuds clients
  • -s : Proportion de nœuds solaires (0.0 à 1.0)
  • -m : Proportion de nœuds mobiles (0.0 à 1.0)
  • -o : Fichier de sortie

3. Génération de scénarios variés

# Scénario 1: 20 nœuds, 50% solaire, 0% mobile
python3 generate_csc.py -n 19 -s 0.5 -m 0.0 -o scenario_20_static.csc

# Scénario 2: 40 nœuds, 30% solaire, 20% mobile
python3 generate_csc.py -n 39 -s 0.3 -m 0.2 -o scenario_40_mixed.csc

# Scénario 3: 60 nœuds, 50% solaire, 50% mobile
python3 generate_csc.py -n 59 -s 0.5 -m 0.5 -o scenario_60_high_mobility.csc

4. Script d'automatisation

1 #!/usr/bin/env python3 2 import subprocess 3 import os 4 5 configs = [ 6 {"n": 19, "s": 0.3, "m": 0.1, "name": "20_static"}, 7 {"n": 39, "s": 0.5, "m": 0.3, "name": "40_mixed"}, 8 {"n": 59, "s": 0.7, "m": 0.5, "name": "60_advanced"}, 9 {"n": 79, "s": 0.4, "m": 0.2, "name": "80_dense"}, 10 ] 11 12 for cfg in configs: 13 output = f"scenario_{cfg['name']}.csc" 14 cmd = ["python3", "generate_csc.py", 15 "-n", str(cfg["n"]), 16 "-s", str(cfg["s"]), 17 "-m", str(cfg["m"]), 18 "-o", output] 19 print(f"Génération de {output}...") 20 subprocess.run(cmd, check=True) 21 print(f" Fichier créé: {os.path.getsize(output)} octets")

5. Analyse de la topologie générée

head -50 scenario_40_mixed.csc
Vérification

Vérifiez que chaque fichier .csc généré a une taille non nulle. Utilisez grep -c '' *.csc pour compter les nœuds.

Dépannage

Erreur 'script not found' : assurez-vous d'exécuter depuis le répertoire racine du projet RPL-AER.

Questions de réflexion
  1. Comment la position aléatoire des nœuds affecte-t-elle la topologie ?
  2. Quel est l'impact du nombre de nœuds sur la congestion réseau ?
  3. Comment la proportion de nœuds solaires influence-t-elle le DODAG ?
  4. Quelle configuration recommanderiez-vous pour un champ de 2 hectares ?
  5. Comment valider qu'un fichier .csc est correctement formaté ?
Livrables

Script batch_generate.py, 4 fichiers .csc avec différentes configurations, fichier topology_report.txt décrivant chaque scénario.
