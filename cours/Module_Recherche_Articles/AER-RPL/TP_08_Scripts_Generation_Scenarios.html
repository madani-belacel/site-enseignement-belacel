TP 08 : Scripts de génération de scénarios

TP 08 — Scripts de génération de scénarios
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Maîtriser generate_csc.py pour créer des scénarios personnalisés

1. Présentation de generate_csc.py

Le script tools/generate_csc.py génère des fichiers de simulation Cooja (.csc) avec des paramètres personnalisés.

# Afficher l'aide
python3 tools/generate_csc.py --help

2. Options disponibles

OptionDescriptionDéfaut
-nNombre de nœuds40
-sSurface de simulation (m)500
-mPourcentage de nœuds mobiles10
-wPourcentage de nœuds avec récolte solaire30
-hActiver les attaques (sinkhole)0
-dDurée de la simulation (secondes)3600
-rGraine aléatoire12345

3. Créer des scénarios personnalisés

3.1. Scénario dense (80 nœuds)

python3 tools/generate_csc.py -n 80 -s 300 -d 1800 -r 42
# Génère: rpl-aer-simulation_80nodes.csc

3.2. Scénario agricole (30% solaire)

python3 tools/generate_csc.py -n 60 -s 500 -w 30 -m 10 -d 7200
# 60 nœuds, 30% solaire, 10% mobile

3.3. Scénario urbain (faible mobilité, pas de solaire)

python3 tools/generate_csc.py -n 100 -s 200 -w 0 -m 5 -d 3600
# 100 nœuds en zone urbaine dense

3.4. Scénario avec attaques

python3 tools/generate_csc.py -n 50 -h 1 -d 1800 -r 99
# 50 nœuds avec attaques sinkhole activées

4. Comprendre le format CSC

Ouvrez le fichier .csc généré pour comprendre sa structure :

<simconf>
  <project EXPORT="discard">
    <title>RPL-AER Simulation</title>
    <randomseed>12345</randomseed>
    <motedelay_us>1000</motedelay_us>
  </project>
  <plugin>...</plugin>
  <mote>...</mote>  <!-- Définition d'un nœud -->
</simconf>

5. Comparer les scénarios

Générez deux scénarios avec des paramètres différents et comparez les fichiers .csc :

python3 tools/generate_csc.py -n 20 -s 200 -o scenario_20.csc
python3 tools/generate_csc.py -n 50 -s 400 -o scenario_50.csc
diff scenario_20.csc scenario_50.csc
