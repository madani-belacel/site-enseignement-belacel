Cours 06 : Module de confiance et sécurité

Cours 06 — Module de confiance et sécurité
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Comprendre le module de confiance et les mécanismes de sécurité de RPL-AER

1. Module de confiance (Trust)

Le module de confiance (Trust Module) est un composant essentiel de RPL-AER qui évalue la fiabilité des nœuds voisins. Il calcule un score de confiance basé sur :

  • Le RSSI (Received Signal Strength Indicator) des paquets reçus
  • Le taux d'acquittement (ACK) des transmissions
  • La détection d'anomalies comportementales
Objectifs pédagogiques
  • Comprendre le rôle du module de confiance dans la sécurité du routage
  • Analyser les mécanismes de détection comportementale
  • Étudier l'interaction entre Trust et MCS
  • Interpréter les logs de sécurité

Exemple de sortie :

RPL-AER: Attack=0, Anomaly=0
RPL-AER: Attack=1, Anomaly=1

Où Attack=0 = AUCUNE attaque, Attack=1 = SINKHOLE, Attack=2 = SELECTIVE_FORWARDING.
