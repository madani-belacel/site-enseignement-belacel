TP 05 : Analyse des logs LSTM

TP 05 — Analyse des logs LSTM
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Analyser les prédictions LSTM, calculer la MAE, évaluer la qualité de prédiction

1. Extraire les logs LSTM

grep "\[LSTM\]" simulation_logs.txt > lstm_logs.txt

2. Format des logs

[LSTM] Node 12: Pred=4.32mW Actual=4.18mW Error=0.14mW MAE=0.12

Champs : Node ID, Pred (prédiction), Actual (consommation réelle), Error (différence absolue), MAE (moyenne cumulative).

3. Parser les logs avec Python

import re
import matplotlib.pyplot as plt

lstm_data = []
with open('lstm_logs.txt') as f:
    for line in f:
        m = re.search(r'Node (\d+): Pred=([\d.]+)mW Actual=([\d.]+)mW Error=([\d.]+)mW MAE=([\d.]+)', line)
        if m:
            lstm_data.append({
                'node': int(m.group(1)),
                'pred': float(m.group(2)),
                'actual': float(m.group(3)),
                'error': float(m.group(4)),
                'mae': float(m.group(5))
            })

4. Calculer la MAE globale

errors = [d['error'] for d in lstm_data]
mae_global = sum(errors) / len(errors)
print(f"MAE globale: {mae_global:.3f} mW")

5. Analyser par nœud

for node_id in sorted(set(d['node'] for d in lstm_data)):
    node_errors = [d['error'] for d in lstm_data if d['node'] == node_id]
    node_mae = sum(node_errors) / len(node_errors)
    node_max_error = max(node_errors)
    print(f"Node {node_id}: MAE={node_mae:.3f}mW MaxError={node_max_error:.3f}mW")

6. Visualiser prédiction vs réalité

node12 = [d for d in lstm_data if d['node'] == 12]
timesteps = range(len(node12))
preds = [d['pred'] for d in node12]
actuals = [d['actual'] for d in node12]

plt.plot(timesteps, preds, label='Prédiction', marker='o')
plt.plot(timesteps, actuals, label='Réel', marker='x')
plt.xlabel('Échantillon')
plt.ylabel('Consommation (mW)')
plt.legend()
plt.title('Prédiction LSTM vs Consommation Réelle — Nœud 12')
plt.savefig('lstm_prediction_node12.png')
plt.show()

7. Détecter les dérives

Analysez l'évolution de la MAE dans le temps pour détecter une éventuelle dérive du modèle :

cumulative_mae = []
window = 10
for i in range(window, len(errors)+1, window):
    window_mae = sum(errors[i-window:i]) / window
    cumulative_mae.append(window_mae)

plt.plot(cumulative_mae)
plt.xlabel('Fenêtre (10 échantillons)')
plt.ylabel('MAE (mW)')
plt.title('Évolution de la MAE')
plt.savefig('lstm_mae_evolution.png')
plt.show()
