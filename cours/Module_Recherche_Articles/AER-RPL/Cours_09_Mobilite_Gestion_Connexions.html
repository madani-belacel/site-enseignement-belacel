Cours 09 : Mobilité et gestion des connexions

Cours 09 — Mobilité et gestion des connexions
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Comprendre la gestion de la mobilité et son impact sur le protocole RPL-AER

1. Gestion de la mobilité dans RPL-AER

RPL-AER supporte les nœuds mobiles grâce à un modèle de mobilité Random Waypoint. Ce modèle permet de simuler des scénarios agricoles avec des drones ou robots se déplaçant dans le champ.

Objectifs pédagogiques
  • Comprendre le modèle Random Waypoint pour la mobilité
  • Analyser l'impact de la mobilité sur le routage RPL
  • Étudier la gestion des changements de parent
  • Interpréter l'effet de la mobilité sur le MCS

2. Configuration de la mobilité

Les constantes dans rpl-aer.h:142-143 :

1 #define RPL_AER_MOBILITY_STATIC 0 2 #define RPL_AER_MOBILITY_MOBILE 1

3. Mise à jour de la mobilité

Le Makefile active le support mobilité via :

1 CFLAGS += -DMOBILITY_SUPPORT=1 2 CFLAGS += -DRANDOM_WAYPOINT=1

4. Impact de la mobilité sur l'ECS

Comme vu dans le Cours 05, la mobilité réduit le facteur de mobilité de l'ECS :

1 if (rpl_aer_ctx.mobility_state == RPL_AER_MOBILITY_MOBILE) { 2 mobility_factor = 0.6f; // Reduce score for mobile nodes 3 }

Un nœud mobile voit son ECS réduit de 40%, ce qui le rend moins attractif comme parent.

5. Défis du routage avec mobilité

  • Changements de parent fréquents : Un nœud mobile change régulièrement de parent, ce qui augmente la signalisation RPL (DIS, DIO)
  • Ruptures de lien : Les liens avec les nœuds mobiles sont moins stables, augmentant le taux de perte
  • Mise à jour du DODAG : Le DODAG doit être mis à jour fréquemment pour refléter la topologie changeante
  • Consommation énergétique : Les mises à jour fréquentes consomment plus d'énergie

6. Logs de mobilité

Exemple de logs montrant la mobilité :

RPL-AER: Mobility state changed to MOBILE
RPL-AER: Parent change detected, new parent=6
RPL-AER: MCS=0.523 (NRE=0.750, PEC=0.500, ECS=0.480)

Notez l'ECS réduit à 0.480 à cause du facteur de mobilité (0.6).

Questions de réflexion
  1. Pourquoi un nœud mobile reçoit-il un ECS réduit ?
  2. Quel est l'impact de la mobilité sur le nombre de changements de parent ?
  3. Comment le modèle Random Waypoint simule-t-il des déplacements réalistes ?
  4. Quels sont les compromis entre mobilité et performance du routage ?
  5. Proposer une amélioration pour mieux gérer les nœuds mobiles.
