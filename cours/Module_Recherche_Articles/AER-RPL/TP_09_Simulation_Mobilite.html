TP 09 : Simulation avec mobilité

TP 09 — Simulation avec mobilité
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Observer l'impact de la mobilité sur RPL-AER, mesurer le temps de convergence et le PDR

1. Configurer la mobilité

Dans project-conf.h, vérifiez que la mobilité est activée (par défaut 28% de nœuds mobiles).

Générez un scénario avec 28% de mobilité :

python3 tools/generate_csc.py -n 50 -s 500 -m 28 -d 3600 -r 77

2. Lancer la simulation

Ouvrez le fichier .csc généré dans Cooja. Observez le mouvement des nœuds mobiles (marqués avec une icône différente).

3. Observer les changements de parent

Les nœuds mobiles changent fréquemment de parent. Cherchez ces événements dans les logs :

grep "new parent" simulation_logs.txt | head -20

4. Mesurer le temps de convergence

Le temps de convergence est le temps nécessaire au DODAG pour se stabiliser après un changement :

import re
import matplotlib.pyplot as plt

# Extraire les événements de changement de parent
parent_changes = []
with open('simulation_logs.txt') as f:
    for line in f:
        m = re.search(r'Node (\d+): new parent Node (\d+) .*old parent Node (\d+)', line)
        if m:
            parent_changes.append({
                'node': int(m.group(1)),
                'new_parent': int(m.group(2)),
                'old_parent': int(m.group(3))
            })

print(f"Nombre total de changements de parent: {len(parent_changes)}")
mobile_nodes = [x for x in parent_changes if x['node'] > 37]  # ex: mobiles > 37
print(f"Changements (mobiles): {len(mobile_nodes)}")
fixed_nodes = [x for x in parent_changes if x['node'] <= 37]
print(f"Changements (fixes): {len(fixed_nodes)}")

5. Analyser le PDR avec mobilité

grep "PDR" simulation_logs.txt
# Format: [PERF] PDR=94.2% Latency=45ms

7. Analyser l'impact sur le MCS

Comparez le MCS des nœuds mobiles vs fixes en extrayant les logs MCS :

grep "\[MCS\]" simulation_logs.txt | grep "Node 3[89]\|Node 4[01]" > mcs_mobile.txt
grep "\[MCS\]" simulation_logs.txt | grep "Node [2-9]" > mcs_fixed.txt
wc -l mcs_mobile.txt mcs_fixed.txt
