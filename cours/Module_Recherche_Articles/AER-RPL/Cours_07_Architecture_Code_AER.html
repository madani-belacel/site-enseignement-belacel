2. rpl-aer.c — Logique principale

Ce fichier est le cœur du protocole. Il implémente la fonction objective personnalisée qui utilise le MCS à la place de l'ETX :

// rpl-aer.c — Fonction objective personnalisée
static rpl_parent_t *best_parent(rpl_parent_t *p1, rpl_parent_t *p2) {
    float mcs1 = get_parent_mcs(p1);
    float mcs2 = get_parent_mcs(p2);
    if (mcs1 > mcs2) return p1;
    return p2;
}

Le fichier gère également les mises à jour périodiques du MCS et l'émission des logs.

3. rpl-aer-sink.c — Nœud puits

Le sink (nœud 1 par défaut) est le point de collecte de toutes les données. Il n'exécute pas l'algorithme de sélection de parent car il est la racine du DODAG. Ses responsabilités :

  • Initialiser le DODAG avec un instance ID RPL-AER
  • Collecter les métriques de tous les nœuds (PDR, latence, énergie)
  • Générer des logs de performance [PERF]
  • Recevoir et stocker les paquets UDP des clients

4. udp-client.c et udp-server.c

Ces fichiers implémentent le trafic applicatif. Les clients UDP envoient périodiquement des paquets de données au serveur (sink) :

// udp-client.c — Envoi périodique
static void send_packet(void *ptr) {
    // Créer un paquet avec un timestamp
    packetbuf_clear();
    struct metrics *m = get_current_metrics();
    memcpy(packetbuf_dataptr(), m, sizeof(*m));
    packetbuf_set_datalen(sizeof(*m));
    // Envoyer au sink
    udp_send(&client_conn, sizeof(*m));
}

5. Interaction entre les modules

Le diagramme d'interaction est le suivant :

  1. rpl-aer.c appelle mcs_calculator.c pour obtenir le MCS de chaque parent potentiel
  2. mcs_calculator.c sollicite harvest_module.c pour l'ECS, lstm_predictor.c pour le PEC, et le module énergétique pour le NRE
  3. trust_module.c surveille les voisins et peut ajuster le MCS final via un facteur de confiance
  4. attack_detector.c analyse les logs RSSI et les taux d'ACK pour identifier les anomalies
  5. Le sink collecte les métriques via une structure partagée dans rpl-aer.h

6. Configuration dans project-conf.h

Le fichier project-conf.h centralise tous les paramètres ajustables :

#define RPL_AER_MCS_ALPHA       0.5
#define RPL_AER_MCS_BETA        0.3
#define RPL_AER_MCS_GAMMA       0.2

#define RPL_AER_TRUST_ENABLED   1

#define RPL_AER_MOBILITY_ENABLED 1
