TP 12 : TP de synthèse RPL-AER

TP 12 — TP de synthèse RPL-AER
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 2h00
  • Objectifs : Réaliser une campagne complète de simulations et produire un rapport d'analyse

1. TP de synthèse RPL-AER

Ce TP de synthèse vise à réaliser une campagne complète de simulations et d'analyses pour évaluer RPL-AER dans différents scénarios, et produire un rapport scientifique structuré.

Objectifs pédagogiques
  • Réaliser une campagne complète de simulations RPL-AER
  • Analyser l'impact des paramètres (énergie, mobilité, attaques) sur les performances
  • Synthétiser les résultats sous forme de rapport scientifique
  • Préparer une présentation des résultats

2. Plan de la campagne

Réalisez les simulations suivantes (30 minutes chacune) :

Scénario Nœuds % Solaire % Mobile Attaques
Baseline200%0%Non
Solaire4050%0%Non
Mobilité4030%50%Non
Attaques4030%0%Oui
Complet6040%30%Oui

3. Métriques à collecter

  • PDR (Packet Delivery Ratio) — pour chaque scénario
  • Latence moyenne (ms)
  • Énergie résiduelle finale (mWh)
  • Nombre d'attaques détectées
  • Évolution du MCS dans le temps
  • Nombre de changements de parent (mobilité)

4. Analyse comparative

5. Structure du rapport

Le rapport doit contenir :

  • Introduction : contexte et objectifs
  • Méthodologie : description des scénarios et paramètres
  • Résultats : tableaux et figures pour chaque métrique
  • Discussion : analyse des résultats et comparaisons
  • Conclusion : enseignements et perspectives

Vérification

Vérifiez que tous les logs sont présents dans cooja_results/ et que les scripts Python produisent des sorties cohérentes.

Dépannage

Si une simulation échoue, vérifiez les logs d'erreur dans la console Cooja. Réduisez le nombre de nœuds si nécessaire.

Questions de réflexion
  1. Quel scénario donne les meilleures performances globales ?
  2. Quel est l'impact cumulé de la mobilité et des attaques sur le PDR ?
  3. Comment les résultats de RPL-AER se comparent-ils à RPL standard ?
  4. Quelles sont les limitations de votre campagne de simulation ?
  5. Proposer des améliorations pour une future version de RPL-AER.
Livrables

Rapport scientifique complet (PDF ou Markdown) contenant : introduction, méthodologie, résultats (tableaux + figures), discussion, conclusion. Tous les scripts Python utilisés. Fichiers de logs des 5 scénarios.
