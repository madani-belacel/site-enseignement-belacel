TP 12 : TP de synthèse RPL-AER

TP 12 — TP de synthèse RPL-AER
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 3h
  • Objectifs : Réaliser le workflow complet de RPL-AER et produire un mini-rapport d'analyse

Objectif du TP de synthèse

Ce TP de synthèse vous demande de réaliser l'ensemble du workflow RPL-AER, depuis le clonage du dépôt jusqu'à l'analyse des résultats, et de produire un mini-rapport scientifique synthétisant vos observations.

Étape 1 : Cloner et compiler

# Les codes sont déjà présents localement
# Si nécessaire, cloner depuis GitHub:
# git clone https://github.com/madani-belacel/RPL-AER.git
cd /home/madani/contiki-ng/examples/projet_madani/RPL-AER-main/examples/rpl-aer
make TARGET=cooja

Étape 2 : Générer un scénario personnalisé

Générez un scénario avec les paramètres suivants :

  • 50 nœuds
  • Surface 600x600 m
  • 20% mobiles, 30% solaires
  • Attaques sinkhole activées
  • Durée : 1 heure simulée
python3 ../tools/generate_csc.py -n 50 -s 600 -m 20 -w 30 -h 1 -d 3600 -r 2025

Étape 3 : Lancer la simulation

Ouvrez le scénario dans Cooja, lancez la simulation et collectez les logs :

nc localhost 6000 > aer_synthese_logs.txt

Étape 4 : Extraire les métriques

python3 ../tools/simulate_results.py --log-file aer_synthese_logs.txt --output-dir synthese_results/ --csv --figures

Étape 5 : Analyser les logs

Analysez :

  • Les logs MCS : évolution, comparaison entre types de nœuds
  • Les logs LSTM : MAE, qualité de prédiction
  • Les logs HARVEST : bilan énergétique des nœuds solaires
  • Les logs TRUST : détection des attaquants
  • Les logs PERF : PDR, latence, throughput

Étape 6 : Rédiger un mini-rapport

Créez un fichier rapport_synthese.md structuré comme suit :

# Rapport de synthèse RPL-AER
