TP 04 : Analyse des logs MCS

TP 04 — Analyse des logs MCS
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Analyser les logs MCS, extraire NRE/PEC/ECS, comprendre l'évolution temporelle

1. Extraire les logs MCS

Après avoir lancé la simulation, extrayez les lignes MCS des logs :

grep "\[MCS\]" simulation_logs.txt > mcs_logs.txt

2. Analyser le format des logs

Chaque ligne MCS a le format :

[MCS] Node XX: NRE=X.XXX PEC=X.XXX ECS=X.XXX MCS=X.XXX

Utilisez Python pour parser ces lignes :

import re

logs = []
with open('mcs_logs.txt') as f:
    for line in f:
        m = re.search(r'Node (\d+): NRE=([\d.]+) PEC=([\d.]+) ECS=([\d.]+) MCS=([\d.]+)', line)
        if m:
            logs.append({
                'node': int(m.group(1)),
                'nre': float(m.group(2)),
                'pec': float(m.group(3)),
                'ecs': float(m.group(4)),
                'mcs': float(m.group(5))
            })

3. Analyser les statistiques

Pour chaque nœud, calculez :

import statistics

for node_id in set(l['node'] for l in logs):
    node_logs = [l for l in logs if l['node'] == node_id]
    avg_nre = statistics.mean(l['nre'] for l in node_logs)
    avg_mcs = statistics.mean(l['mcs'] for l in node_logs)
    min_nre = min(l['nre'] for l in node_logs)
    print(f"Node {node_id}: avg_NRE={avg_nre:.3f} avg_MCS={avg_mcs:.3f} min_NRE={min_nre:.3f}")

4. Évolution temporelle du MCS

Créez un graphique de l'évolution du MCS pour plusieurs nœuds :

import matplotlib.pyplot as plt

# Grouper par intervalle de temps (toutes les 10 entrées)
for node_id in [2, 5, 10, 15]:
    node_logs = [l for l in logs if l['node'] == node_id]
    mcs_values = [l['mcs'] for l in node_logs]
    plt.plot(mcs_values, label=f'Node {node_id}')

plt.xlabel('Échantillon')
plt.ylabel('MCS')
plt.legend()
plt.title('Évolution du MCS au fil du temps')
plt.savefig('mcs_evolution.png')
plt.show()

5. Corrélation NRE vs MCS

Analysez la corrélation entre NRE et MCS pour vérifier que le NRE est bien le facteur dominant :

nre_values = [l['nre'] for l in logs]
mcs_values = [l['mcs'] for l in logs]
correlation = statistics.correlation(nre_values, mcs_values)
print(f"Corrélation NRE-MCS: {correlation:.3f}")

6. Comparer les types de nœuds

Si vous avez identifié les types de nœuds dans la simulation, comparez leurs MCS :

# Nœuds Battery: 2-25, Solar: 26-37, Mobile: 38-41 (exemple)
battery_mcs = [l['mcs'] for l in logs if 2 <= l['node'] <= 25]
solar_mcs = [l['mcs'] for l in logs if 26 <= l['node'] <= 37]
mobile_mcs = [l['mcs'] for l in logs if 38 <= l['node'] <= 41]

print(f"Battery avg MCS: {statistics.mean(battery_mcs):.3f}")
print(f"Solar avg MCS:   {statistics.mean(solar_mcs):.3f}")
print(f"Mobile avg MCS:  {statistics.mean(mobile_mcs):.3f}")
