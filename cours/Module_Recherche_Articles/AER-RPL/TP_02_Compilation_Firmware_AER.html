TP 02 : Compilation du firmware RPL-AER

TP 02 — Compilation du firmware RPL-AER
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Compiler le firmware RPL-AER pour Cooja, comprendre la configuration

1. Prérequis

Avant de commencer, assurez-vous que Contiki-NG et les outils de compilation sont installés :

# Vérifier l'installation de Contiki-NG
ls $CONTIKI_DIR
echo $CONTIKI_DIR

# Vérifier la chaîne de compilation pour Cooja
which msp430-gcc || which arm-none-eabi-gcc

2. Utiliser build_and_test.sh

Le script build_and_test.sh automatise la compilation :

cd /home/madani/contiki-ng/examples/projet_madani/RPL-AER-main
./tools/build_and_test.sh

Ce script effectue les opérations suivantes :

  • Compilation du firmware pour la plateforme Cooja (native)
  • Vérification des erreurs de compilation
  • Lancement des tests unitaires (si présents)

3. Compilation manuelle avec make

Vous pouvez aussi compiler manuellement :

cd examples/rpl-aer
make TARGET=cooja

Les fichiers binaires générés sont :

  • rpl-aer.cooja — Firmware pour nœud normal
  • rpl-aer-sink.cooja — Firmware pour nœud sink
  • udp-client.cooja — Application cliente
  • udp-server.cooja — Application serveur

4. Comprendre le Makefile

Ouvrez le Makefile et examinez :

cat examples/rpl-aer/Makefile

Points clés à identifier :

  • La variable CONTIKI pointant vers le répertoire racine de Contiki-NG
  • Les modules inclus (PROJECT_SOURCEFILES)
  • Les flags de compilation spécifiques

5. Configuration dans project-conf.h

Le fichier project-conf.h contrôle les fonctionnalités activées :

// Désactiver/activer des modules
#define RPL_AER_TRUST_ENABLED   1   // Activer le module de confiance
#define RPL_AER_HARVEST_ENABLED 1   // Activer la récolte solaire
#define RPL_AER_MOBILITY_ENABLED 1  // Activer la mobilité

// Configurer les poids MCS
#define MCS_ALPHA 0.5
#define MCS_BETA  0.3
#define MCS_GAMMA 0.2

// Configurer le LSTM
#define LSTM_WINDOW_SIZE 5
#define LSTM_UPDATE_INTERVAL 300  // secondes

6. Modifier la configuration

Essayez de modifier project-conf.h pour :

  1. Désactiver le module de confiance (RPL_AER_TRUST_ENABLED 0)
  2. Changer les poids MCS (α=0.4, β=0.4, γ=0.2)
  3. Recompiler avec make TARGET=cooja

7. Vérification des binaires

Vérifiez que les fichiers .cooja ont été générés :

ls -la *.cooja
