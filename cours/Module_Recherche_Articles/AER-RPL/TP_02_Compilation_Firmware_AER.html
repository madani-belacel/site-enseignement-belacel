TP 02 : Compilation du firmware RPL-AER

TP 02 — Compilation du firmware RPL-AER
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 45 minutes
  • Objectifs : Compiler le firmware RPL-AER pour la plateforme Cooja

1. Préparation de l'environnement

Avant de compiler, vérifiez que Contiki-NG est correctement installé :

cd /home/madani/contiki-ng
ls examples/projet_madani/RPL-AER-main/
echo $CONTIKI
Objectifs pédagogiques
  • Compiler le firmware RPL-AER pour la plateforme Cooja
  • Comprendre le rôle du Makefile et des flags de compilation
  • Résoudre les erreurs de compilation courantes
  • Vérifier la production des firmwares .csc et .elf

2. Compilation des firmwares

Utilisez le script build_and_test.sh :

cd /home/madani/contiki-ng/examples/projet_madani/RPL-AER-main
./build_and_test.sh

Sortie attendue :

[INFO] Vérification de l'environnement...
[SUCCESS] Environnement vérifié
[INFO] Compilation pour la cible cooja...
[SUCCESS] Compilation terminée
Build terminé avec succès!

3. Compilation manuelle

make TARGET=cooja
make TARGET=cooja rpl-aer-client.csc
make TARGET=cooja rpl-aer-sink.csc

4. Nettoyage avant compilation

./build_and_test.sh -c

5. Vérification des firmwares produits

ls -la *.csc *.elf 2>/dev/null

6. Analyse du Makefile

Examinez les flags de compilation :

grep "CFLAGS" Makefile

Résultat attendu :

CFLAGS += -DRPL_AER=1
CFLAGS += -DMCS_METRIC=1
CFLAGS += -DLSTM_PREDICTION=1
CFLAGS += -DSECURITY_ACK=1
CFLAGS += -DRSSI_ANOMALY=1
CFLAGS += -DSOLAR_ENERGY_SIM=1
CFLAGS += -DATTACK_SIMULATION=1
CFLAGS += -DMOBILITY_SUPPORT=1
Vérification

Vérifiez que les fichiers rpl-aer-client.csc et rpl-aer-sink.csc existent avec une taille non nulle. Utilisez : ls -la *.csc

Dépannage

Erreur 'Contiki-NG not found' : modifiez CONTIKI_PATH dans build_and_test.sh pour pointer vers /home/madani/contiki-ng. Erreur de compilation : vérifiez que tous les fichiers sources (.c) sont présents.

Questions de réflexion
  1. Quels sont les flags qui activent la sécurité ?
  2. Que se passe-t-il si on enlève -DLSTM_PREDICTION=1 ?
  3. Pourquoi compile-t-on des .csc et pas directement des .elf ?
  4. Quel est le rôle de TARGET=cooja ?
  5. Comment ajouter un nouveau fichier source au projet ?
