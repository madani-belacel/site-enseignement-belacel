Cours 05 : ECS — Environmental Context Score

Cours 05 — ECS — Environmental Context Score
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Comprendre le modèle de récolte solaire et le calcul du score contextuel environnemental

1. Contexte : récolte d'énergie solaire dans les WSN

Dans les applications agricoles, les nœuds IoT peuvent être équipés de panneaux solaires pour prolonger leur autonomie, voire fonctionner indéfiniment si la récolte excède la consommation. RPL-AER intègre un module de récolte (harvest_module.c) qui modélise la production solaire en fonction des conditions environnementales.

2. Modèle de récolte solaire

Le modèle utilisé est basé sur l'équation de l'irradiance solaire :

P_harvest = η × A × G × (1 + α × (T - 25))

Avec :

  • η : Rendement du panneau solaire (typiquement 15-20%)
  • A : Surface du panneau (m²)
  • G : Irradiance solaire (W/m²), typiquement 100-1000 W/m²
  • α : Coefficient de température (-0.004 /°C pour les panneaux silicium)
  • T : Température ambiante (°C)

3. Simulation d'irradiance dans Cooja

Dans la simulation, l'irradiance est simulée selon un cycle jour/nuit :

// harvest_module.c — simulation d'irradiance
float get_solar_irradiance(uint32_t time_seconds) {
    float hour = (time_seconds % 86400) / 3600.0;
    if (hour < 6 || hour > 18) return 0;  // Nuit
    float peak = 1000;  // W/m2 à midi
    float irradiance = peak * sin(M_PI * (hour - 6) / 12);
    if (irradiance < 0) irradiance = 0;
    return irradiance;
}

4. Calcul de l'ECS

L'ECS combine trois sous-scores environnementaux :

ECS = w_sol × S_solaire + w_meteo × S_meteo + w_temp × S_temperature
  • S_solaire : Ratio de récolte solaire effective (énergie récoltée / énergie maximale possible)
  • S_meteo : Indice météo (1 pour ciel clair, 0.5 pour nuageux, 0 pour pluie)
  • S_temperature : Score de température (optimal à 25°C, dégradé à 0°C et 50°C)
  • w_sol, w_meteo, w_temp : Poids configurables (défaut : 0.5, 0.3, 0.2)

5. Impact de l'ECS sur le routage

L'ECS permet de favoriser les nœuds bénéficiant de conditions environnementales favorables :

  • Un nœud avec panneau solaire bien exposé (ECS > 0.7) est prioritaire comme parent car il peut recharger sa batterie.
  • Un nœud à l'ombre ou en conditions défavorables (ECS < 0.3) sera évité car sa batterie risque de s'épuiser sans pouvoir se recharger.
