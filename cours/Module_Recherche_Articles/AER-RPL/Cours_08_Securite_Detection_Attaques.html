Cours 08 : Sécurité et détection d'attaques

Cours 08 — Sécurité et détection d'attaques
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Comprendre les mécanismes de détection d'attaques et leur impact sur les métriques

1. Types d'attaques ciblées

RPL-AER intègre un mécanisme de détection d'attaques spécifiques aux réseaux RPL :

  • Attaque Sinkhole : Un nœud malveillant attire tout le trafic en prétendant avoir le meilleur chemin vers le sink, puis droppe les paquets.
  • Attaque Selective Forwarding : Un nœud malveillant transmet sélectivement certains paquets et en droppe d'autres.
Objectifs pédagogiques
  • Comprendre les mécanismes des attaques sinkhole et selective forwarding
  • Analyser l'implémentation de la détection d'attaques
  • Étudier les indicateurs de compromission (RSSI, ACK)
  • Interpréter les logs d'attaques

2. Configuration des attaques

Les constantes dans rpl-aer.h:138-140 :

3. Simulation d'attaques

Dans rpl-aer.c:197-210, la fonction rpl_aer_detect_attacks() :

1 void rpl_aer_detect_attacks(void) { 2 uint8_t rand_val = random_rand() % 100; 3 if (rand_val < (ATTACK_PROBABILITY * 100)) { 4 rpl_aer_ctx.attack_state = RPL_AER_ATTACK_SINKHOLE; 5 rpl_aer_attack_count++; 6 } else if (rand_val < ((ATTACK_PROBABILITY + SELECTIVE_FORWARDING_PROBABILITY) * 100)) { 7 rpl_aer_ctx.attack_state = RPL_AER_ATTACK_SELECTIVE_FORWARDING; 8 rpl_aer_attack_count++; 9 } else { 10 rpl_aer_ctx.attack_state = RPL_AER_ATTACK_NONE; 11 } 12 }

4. Détection RSSI

  • Un RSSI anormalement bas peut indiquer un nœud malveillant
  • Le seuil RSSI_THRESHOLD est configurable dans project-conf.h

5. Logs de performance avec attaques

La fonction rpl_aer_log_performance() (rpl-aer.c:313-317) :

1 void rpl_aer_log_performance(void) { 2 LOG_INFO("RPL-AER: Performance - PDR=%.1f%%, Attacks=%lu\n", 3 (float)rpl_aer_delivered_count / (float)rpl_aer_packet_count * 100, 4 rpl_aer_attack_count); 5 }

Exemple de sortie avec attaques :

RPL-AER: Performance - PDR=72.3%, Attacks=5
RPL-AER: Securite: Attack=1 (SINKHOLE), Anomaly=1

Questions de réflexion
  1. Comment une attaque sinkhole affecte-t-elle le PDR ?
  2. Quel est l'effet d'une attaque selective forwarding sur la latence ?
  3. Pourquoi le RSSI est-il un indicateur utile pour détecter les attaques ?
  4. Comment RPL-AER distingue-t-il une attaque d'une perte de paquet légitime ?
  5. Proposer un scénario où une attaque n'est pas détectée par le système actuel.
