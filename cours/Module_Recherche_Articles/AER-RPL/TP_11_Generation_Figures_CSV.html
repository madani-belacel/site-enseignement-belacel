TP 11 : Génération de figures et CSV

TP 11 — Génération de figures et CSV
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Générer les fichiers CSV de résultats et les figures pour publication

1. Utiliser simulate_results.py

Le script simulate_results.py automatise l'extraction des métriques et la génération de CSV et figures :

# Extraire les résultats avec génération de CSV
python3 tools/simulate_results.py \
    --log-file simulation_logs.txt \
    --output-dir results/ \
    --csv

# Générer les figures
python3 tools/simulate_results.py \
    --log-file simulation_logs.txt \
    --output-dir results/ \
    --figures

2. Examiner les fichiers CSV générés

ls results/
cat results/figure_data_energy.csv
cat results/figure_data_qos.csv

3. Analyser figure_data_energy.csv

Ce fichier contient les données énergétiques structurées par nœud et par intervalle de temps :

import pandas as pd
import matplotlib.pyplot as plt

df_energy = pd.read_csv('results/figure_data_energy.csv')
print(df_energy.describe())

# Évolution du MCS pour les 5 premiers nœuds
for node in df_energy['Node'].unique()[:5]:
    node_data = df_energy[df_energy['Node'] == node]
    plt.plot(node_data['Time'], node_data['MCS'], label=f'Node {node}')

plt.xlabel('Temps (s)')
plt.ylabel('MCS')
plt.legend()
plt.title('Évolution du MCS par nœud')
plt.savefig('results/mcs_per_node.png')
plt.show()

4. Analyser figure_data_qos.csv

df_qos = pd.read_csv('results/figure_data_qos.csv')
print(df_qos.head())

5. Générer des figures personnalisées

Créez une figure comparant RPL-AER avec RPL standard (si vous avez les deux jeux de logs) :

# Comparaison RPL standard vs RPL-AER
plt.figure(figsize=(8, 5))
categories = ['PDR (%)', 'Latence (ms)', 'Énergie (mW)']
rpl_std = [94.2, 25.3, 5.1]
rpl_aer = [97.5, 18.2, 4.2]

x = range(len(categories))
plt.bar(x, rpl_std, width=0.35, label='RPL standard', color='#e74c3c')
plt.bar([i + 0.35 for i in x], rpl_aer, width=0.35, label='RPL-AER', color='#2ecc71')
plt.xticks([i + 0.175 for i in x], categories)
plt.ylabel('Valeur')
plt.legend()
plt.title('Comparaison RPL standard vs RPL-AER')
plt.savefig('results/comparison.png')
plt.show()

6. Exporter pour publication

# Générer des figures en haute résolution
python3 tools/simulate_results.py \
    --log-file simulation_logs.txt \
    --output-dir results/ \
    --figures --dpi 300 --format pdf
