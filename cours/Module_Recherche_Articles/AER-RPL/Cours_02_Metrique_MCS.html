Cours 02 : La métrique Multi-Criteria Score (MCS)

Cours 02 — La métrique Multi-Criteria Score (MCS)
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Comprendre la formule MCS, le rôle de chaque composante et la configuration des poids

1. Principe général

Le Multi-Criteria Score (MCS) est la métrique centrale de RPL-AER. Contrairement à l'ETX qui ne considère que la qualité du lien, le MCS intègre trois dimensions critiques pour l'agriculture de précision : l'énergie disponible, la consommation prévue et le contexte environnemental.

Le MCS remplace l'ETX dans la fonction objective de RPL pour la sélection du parent préféré (Preferred Parent). Un score MCS élevé indique un nœud mieux adapté pour servir de parent.

2. Formule mathématique

Le MCS est calculé comme une somme pondérée :

MCS = α × NRE + β × PEC + γ × ECS

Avec :

  • NRE (Normalized Residual Energy) : Énergie résiduelle normalisée entre 0 et 1
  • PEC (Predictive Energy Consumption) : Score de prédiction de consommation entre 0 et 1
  • ECS (Environmental Context Score) : Score contextuel environnemental entre 0 et 1
  • α, β, γ : Poids de chaque composante, avec α + β + γ = 1

3. Composantes détaillées

NRE — Normalized Residual Energy

Le NRE représente la fraction d'énergie restante dans la batterie du nœud :

NRE = E_residuelle / E_maximale

Un nœud avec une batterie pleine a NRE = 1. Un nœud presque épuisé a NRE proche de 0. Cette composante favorise les nœuds ayant le plus d'énergie disponible.

PEC — Predictive Energy Consumption

Le PEC est issu d'une prédiction LSTM de la consommation future. Un PEC élevé signifie que le nœud prévoit une faible consommation dans le futur immédiat, le rendant plus fiable comme parent. Le calcul détaillé est présenté dans le Cours 04.

ECS — Environmental Context Score

L'ECS intègre les conditions environnementales : présence de récolte solaire, luminosité, température. Un nœud avec panneau solaire exposé au soleil aura un ECS élevé. Le calcul détaillé est présenté dans le Cours 05.

4. Configuration des poids α, β, γ

Les poids sont configurables dans le fichier project-conf.h :

#define MCS_ALPHA 0.5
#define MCS_BETA  0.3
#define MCS_GAMMA 0.2

La configuration par défaut (α=0.5, β=0.3, γ=0.2) donne la priorité à l'énergie résiduelle, suivie de la prédiction de consommation et du contexte environnemental. Ces poids peuvent être adaptés selon l'application :

  • Agriculture en plein champ : α=0.4, β=0.3, γ=0.3 (plus d'importance à l'environnement)
  • Serre avec éclairage artificiel : α=0.5, β=0.4, γ=0.1 (moins d'importance à l'environnement)
  • Réseau à forte mobilité : α=0.6, β=0.3, γ=0.1 (priorité à l'énergie stable)

5. Impact sur la sélection du parent

Dans RPL standard, chaque nœud choisit son parent préféré comme celui ayant le plus petit ETX (meilleure qualité de lien). Avec RPL-AER, le nœud calcule le MCS pour chaque parent potentiel et sélectionne celui ayant le MCS le plus élevé.

Exemple de calcul :

Parent A : NRE=0.9, PEC=0.7, ECS=0.5
MCS_A = 0.5×0.9 + 0.3×0.7 + 0.2×0.5 = 0.76

Parent B : NRE=0.4, PEC=0.8, ECS=0.9
MCS_B = 0.5×0.4 + 0.3×0.8 + 0.2×0.9 = 0.62

Parent C : NRE=0.7, PEC=0.6, ECS=0.7
MCS_C = 0.5×0.7 + 0.3×0.6 + 0.2×0.7 = 0.67

Le parent A (MCS=0.76) est sélectionné.

Même si le Parent B a une meilleure prédiction (PEC) et un meilleur contexte (ECS), son énergie résiduelle faible (NRE=0.4) le rend moins fiable. Le Parent A, avec une énergie abondante, est préféré.

6. Implémentation dans mcs_calculator.c

Le fichier mcs_calculator.c implémente le calcul du MCS :

// Extrait simplifié du calcul MCS
float compute_mcs(float nre, float pec, float ecs) {
    float alpha = MCS_ALPHA;
    float beta  = MCS_BETA;
    float gamma = MCS_GAMMA;
    return alpha * nre + beta * pec + gamma * ecs;
}

Le module mcs_calculator reçoit les valeurs NRE, PEC et ECS des modules respectifs et retourne le score MCS utilisé par la fonction objective.
