TP 03 : Simulation RPL-AER avec 40 nœuds

TP 03 — Simulation RPL-AER avec 40 nœuds
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Lancer la simulation, observer les logs MCS, comprendre la topologie RPL-AER

1. Ouvrir la simulation dans Cooja

Lancez Cooja et ouvrez le fichier de simulation :

# Depuis le répertoire Contiki-NG
cd contiki-ng
ant run  # ou ./tools/cooja/runcooja.sh

# Dans Cooja : File -> Open ->
# RPL-AER/simulation/rpl-aer-simulation.csc

2. Examiner la configuration de la simulation

La simulation comprend :

  • 40 nœuds déployés dans une zone de 500x500 m
  • 1 sink (nœud 1) au centre de la zone
  • Nœuds Battery : 60% (24 nœuds) — batteries seules
  • Nœuds Solar : 30% (12 nœuds) — avec panneaux solaires
  • Nœuds Mobile : 10% (4 nœuds) — mobiles avec panneaux solaires

3. Lancer la simulation

Dans Cooja, cliquez sur le bouton Start. Laissez tourner pendant 10 minutes de temps simulé.

Observez :

  • La construction du DODAG (flèches entre les nœuds)
  • Les messages de contrôle RPL (DIO, DAO, DIS)
  • Les logs dans la console Cooja

4. Observer les logs MCS

Dans la console Cooja, cherchez les lignes contenant [MCS] :

[MCS] Node 12: NRE=0.950 PEC=0.723 ECS=0.512 MCS=0.788
[MCS] Node 15: NRE=0.342 PEC=0.821 ECS=0.634 MCS=0.554

Notez comment le NRE varie entre les nœuds (élevé pour les nœuds neufs, faible pour les nœuds actifs).

5. Analyser l'évolution temporelle

Laissez tourner la simulation plus longtemps et observez l'évolution des logs :

[MCS] Node 12: NRE=0.821 PEC=0.745 ECS=0.523 MCS=0.742  (t=500s)
[MCS] Node 12: NRE=0.698 PEC=0.712 ECS=0.498 MCS=0.680  (t=1000s)
[MCS] Node 12: NRE=0.523 PEC=0.689 ECS=0.472 MCS=0.587  (t=1500s)

6. Observer les types de nœuds

Identifiez les différences de comportement entre :

  • Nœuds Battery : NRE diminue régulièrement, pas de récolte
  • Nœuds Solar : NRE varie avec le cycle jour/nuit (récolte le jour, consommation la nuit)
  • Nœuds Mobile : Changements fréquents de parent, MCS fluctuant

7. Sauvegarder les logs

Dans Cooja : Tools -> Serial Socket (SERVER). Connectez-vous avec :

nc localhost 6000 > simulation_logs.txt

8. Questions

  1. Combien de temps faut-il au DODAG pour se stabiliser après le démarrage ?
  2. Quel nœud a le MCS le plus élevé après 500 secondes ? Le plus bas ?
  3. Observez-vous des changements de parent pendant la simulation ? À quelle fréquence ?
  4. Comment le MCS des nœuds solaires varie-t-il avec le cycle jour/nuit ?
