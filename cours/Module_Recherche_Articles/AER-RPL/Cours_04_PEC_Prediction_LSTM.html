Cours 04 : PEC — Prédiction LSTM de consommation

Cours 04 — PEC — Prédiction LSTM de consommation
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h30
  • Objectifs : Comprendre le PEC basé sur la prédiction LSTM de consommation énergétique

1. Prédiction LSTM dans RPL-AER

Le PEC (Predictive Energy Consumption) utilise un réseau de neurones LSTM (Long Short-Term Memory) pour prédire la consommation future d'énergie d'un nœud. Cette prédiction permet d'anticiper l'épuisement des batteries avant qu'il ne se produise.

Objectifs pédagogiques
  • Comprendre le rôle de la prédiction LSTM dans le routage
  • Analyser les structures de données LSTM dans le code
  • Étudier le processus d'inférence et d'apprentissage
  • Interpréter la conversion prédiction → PEC

2. Structure LSTM

Dans rpl-aer.h:39-44 :

1 typedef struct { 2 float history[LSTM_WINDOW_SIZE]; 3 float prediction; 4 float weights[LSTM_WINDOW_SIZE]; 5 uint8_t window_index; 6 } rpl_aer_lstm_t;

Le LSTM maintient un historique des LSTM_WINDOW_SIZE dernières valeurs d'énergie, des poids pour l'apprentissage, et un index circulaire.

3. API du LSTM Predictor

Le fichier lstm_predictor.h:14-18 déclare l'API :

1 void lstm_predictor_init(void); 2 void lstm_predictor_update(float value); 3 float lstm_predictor_predict(void); 4 float lstm_predictor_mae(void); 5 void lstm_predictor_log(void);

4. Calcul du PEC

Dans rpl-aer.c:52-58, le PEC est calculé à partir de la prédiction LSTM :

1 float rpl_aer_calculate_pec(void) { 2 float prediction = lstm_model_predict(); 3 rpl_aer_ctx.mcs.pec = 1.0f - prediction; 4 return rpl_aer_ctx.mcs.pec; 5 }

La prédiction LSTM est inversée (1 - prediction) pour que :

  • Une faible consommation prédite → PEC élevé → Meilleur score
  • Une forte consommation prédite → PEC faible → Moins attractif

5. Apprentissage LSTM (Training)

La fonction rpl_aer_lstm_train() (rpl-aer.c:162-172) effectue l'apprentissage :

1 void rpl_aer_lstm_train(void) { 2 float target = lstm_model_predict(); 3 float error = target - lstm_model_predict(); 4 LOG_INFO("RPL-AER: LSTM Training - Target: %.3f, " 5 "Prediction: %.3f, Error: %.3f\n", 6 target, lstm_model_predict(), error); 7 }

6. Logs LSTM

Sortie typique dans les logs :

RPL-AER: LSTM Training - Target: 0.650, Prediction: 0.620, Error: 0.030
RPL-AER: LSTM Training - Target: 0.610, Prediction: 0.590, Error: 0.020
Questions de réflexion
  1. Pourquoi utilise-t-on un LSTM plutôt qu'une simple moyenne mobile ?
  2. Que signifie un PEC = 0.8 ? Un nœud avec ce PEC est-il attractif ?
  3. Quel est l'impact de LSTM_WINDOW_SIZE sur la qualité de la prédiction ?
  4. Si la prédiction LSTM est de 0.9, quel est le PEC correspondant ?
  5. Comment l'erreur de prédiction (target - prediction) influence-t-elle l'apprentissage ?
