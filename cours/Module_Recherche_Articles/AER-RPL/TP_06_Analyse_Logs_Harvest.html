TP 06 : Analyse des logs Harvest

TP 06 — Analyse des logs Harvest
  • Auteur : Dr. Madani BELACEL
  • Durée estimée : 1h
  • Objectifs : Analyser les logs de récolte solaire, évaluer l'efficacité des panneaux

1. Extraire les logs HARVEST

grep "\[HARVEST\]" simulation_logs.txt > harvest_logs.txt

2. Format des logs

[HARVEST] Node 8: Harvested=12.5mW Stored=8.2mW Consumed=4.3mW
[HARVEST] Node 8: Harvested=0.0mW Stored=0.0mW Consumed=4.3mW

3. Parser les logs

import re
import matplotlib.pyplot as plt

harvest_data = []
with open('harvest_logs.txt') as f:
    for line in f:
        m = re.search(r'Node (\d+): Harvested=([\d.]+)mW Stored=([\d.]+)mW Consumed=([\d.]+)mW', line)
        if m:
            harvest_data.append({
                'node': int(m.group(1)),
                'harvested': float(m.group(2)),
                'stored': float(m.group(3)),
                'consumed': float(m.group(4))
            })

4. Analyser le cycle jour/nuit

node8 = [d for d in harvest_data if d['node'] == 8]
harvested = [d['harvested'] for d in node8]

plt.plot(harvested)
plt.xlabel('Échantillon')
plt.ylabel('Énergie récoltée (mW)')
plt.title('Cycle de récolte solaire — Nœud 8')
plt.savefig('solar_cycle_node8.png')
plt.show()

5. Calculer le bilan énergétique

for node_id in sorted(set(d['node'] for d in harvest_data)):
    node_logs = [d for d in harvest_data if d['node'] == node_id]
    total_harvested = sum(d['harvested'] for d in node_logs)
    total_consumed = sum(d['consumed'] for d in node_logs)
    total_stored = sum(d['stored'] for d in node_logs)
    efficiency = (total_stored / total_harvested * 100) if total_harvested > 0 else 0
    print(f"Node {node_id}: Harvested={total_harvested:.1f}mW "
          f"Consumed={total_consumed:.1f}mW "
          f"Stored={total_stored:.1f}mW "
          f"Efficiency={efficiency:.1f}%")

7. Évaluer l'autonomie

Estimez la durée de vie des nœuds solaires vs batterie :

# Pour un nœud batterie (consommation moyenne de 4.3 mW)
battery_capacity_mwh = 2000 * 3.0  # 6000 mWh
avg_consumption = 4.3  # mW
lifetime_hours = battery_capacity_mwh / avg_consumption
print(f"Autonomie batterie seule: {lifetime_hours:.0f}h")

# Pour un nœud solaire (récolte moyenne de 8.5 mW le jour)
solar_gain = 8.5  # mW récoltés en moyenne le jour
net_consumption = max(0, avg_consumption - solar_gain)
lifetime_solar = battery_capacity_mwh / net_consumption if net_consumption > 0 else float('inf')
print(f"Autonomie avec solaire: {lifetime_solar:.0f}h")
