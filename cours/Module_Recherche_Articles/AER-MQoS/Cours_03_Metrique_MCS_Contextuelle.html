Cours 03 — Métrique MCS contextuelle

Type : Cours théorique — Durée : 1h30
Objectif : Maîtriser la métrique composite MCS, sa formule, ses composantes et le mécanisme d'ajustement contextuel des poids
Prérequis : Cours 01, Cours 02
Telecharger PDF Telecharger PPTX

1. Définition de la métrique MCS

La métrique MCS (Multi-Objective Composite Score) est une métrique de routage composite qui agrège trois indicateurs de performance :

  • NRE — Normalized Residual Energy : énergie résiduelle normalisée du parent candidat
  • ETXnorm — ETX normalisé : fiabilité du lien inversée et normalisée
  • TrustScore — Score de confiance : évaluation de la fiabilité du nœud basée sur l'historique ETX et les anomalies

2. Formule de la métrique

Le MCS est calculé comme une somme pondérée :

MCS(parent) = alpha * NRE(parent) + beta * (1 - ETX_norm(parent)) + gamma * TrustScore(parent)

Où :

  • alpha, beta, gamma sont des poids contextuels dans [0, 1] avec alpha + beta + gamma = 1
  • NRE(parent) ∈ [0, 1] — 1 = pleine charge, 0 = batterie épuisée
  • ETX_norm(parent) ∈ [0, 1] — ETX normalisé par rapport à une valeur maximale de référence
  • TrustScore(parent) ∈ [0, 1] — 1 = totalement fiable, 0 = suspect

Un score MCS élevé indique un parent de meilleure qualité. Le parent avec le MCS le plus élevé est choisi comme parent préféré dans le DODAG.

3. Pondération contextuelle

Les poids alpha, beta, gamma ne sont pas fixes. Ils s'adaptent aux conditions du réseau selon des règles contextuelles :

4. Adaptation par Q-learning du poids gamma

En plus de l'ajustement contextuel statique, le poids gamma (confiance) est dynamiquement adapté par un agent Q-learning. L'agent observe l'état du réseau (PDR, énergie moyenne, taux d'anomalies) et sélectionne des actions qui modifient gamma pour maximiser une récompense combinée (PDR × Énergie × Confiance).

Ce mécanisme est détaillé dans le Cours 05. Il permet à AER-MQoS de s'adapter en continu aux conditions changeantes du réseau sans intervention humaine.

5. Implémentation dans aer_rpl_plus.c

Le module principal aer_rpl_plus.c contient les fonctions clés :

  • mcs_calculate(parent) — calcule le score MCS d'un parent candidat
  • aer_rpl_calculate_contextual_weights() — détermine alpha/beta/gamma selon le contexte
  • aer_rpl_update_metrics() — met à jour NRE, ETX_norm et TrustScore périodiquement
  • aer_rpl_parent_select() — sélectionne le meilleur parent via MCS
/* Extrait simplifié du calcul MCS */
double mcs_calculate(const rpl_parent_t *parent) {
    double nre = aer_rpl_energy_get_nre(parent);
    double etx = aer_rpl_get_etx_normalized(parent);
    double trust = aer_rpl_trust_get_score(parent);
    double alpha, beta, gamma;
    aer_rpl_calculate_contextual_weights(&alpha, &beta, &gamma);
    return alpha * nre + beta * (1.0 - etx) + gamma * trust;
}

6. Exemple de calcul

Considérons un parent avec NRE = 0.9, ETX_norm = 0.3, TrustScore = 0.95, dans un contexte normal (alpha=0.3, beta=0.35, gamma=0.35) :

MCS = 0.3 * 0.9 + 0.35 * (1 - 0.3) + 0.35 * 0.95
   = 0.27 + 0.35 * 0.7 + 0.3325
   = 0.27 + 0.245 + 0.3325
   = 0.8475

Un second parent avec NRE = 0.4, ETX_norm = 0.1, TrustScore = 0.5 donnerait MCS = 0.4575. Le premier parent est donc préféré.

7. Avantages de l'approche composite

  • Holistique : intègre énergie, fiabilité ETX et confiance en une seule métrique
  • Contextuelle : les poids s'adaptent aux conditions réseau
  • Apprentissage : gamma affine par Q-learning pour des performances optimales
  • Résiliente : le TrustScore protège contre les anomalies et attaques

8. Résumé

La métrique MCS est le coeur d'AER-MQoS. Elle synthétise trois dimensions essentielles du routage IoT en une note composite, pondérée contextuellement et adaptée par apprentissage. Les cours suivants détaillent chaque composante : WRR pour l'ordonnancement, Q-learning pour l'adaptation, modèle NRE pour l'énergie et Trust Score pour la confiance.
