Cours 04 — Ordonnancement WRR (Weighted Round Robin)

Type : Cours théorique — Durée : 1h00
Objectif : Comprendre l'ordonnanceur WRR, son rôle dans la différenciation QoS, son implémentation et son interaction avec la couche MAC
Prérequis : Cours 02 (classes QoS), notions d'ordonnancement réseau
Télécharger PDF Télécharger PPTX

1. Principe du Weighted Round Robin

Le Weighted Round Robin (WRR) est un algorithme d'ordonnancement qui sert les files d'attente de manière cyclique, en allouant à chaque file un nombre de paquets proportionnel à son poids. Contrairement au Round Robin pur qui sert une quantité égale de paquets par file, le WRR permet une différenciation pondérée du service.

Dans AER-MQoS, le cycle WRR sert les paquets dans l'ordre C0, C1, C2, C3 selon les poids respectifs 6, 3, 2, 1. Ainsi, sur un cycle complet de 12 paquets (6+3+2+1), C0 transmet 6 paquets, C1 en transmet 3, C2 en transmet 2, et C3 en transmet 1.

2. Implémentation dans aer_qos_queue.c

/* Structure d'une file QoS */
struct aer_qos_queue {
    struct queue_item *head;
    struct queue_item *tail;
    uint8_t length;
    uint8_t weight;      /* 6, 3, 2 ou 1 */
    uint8_t deficit;     /* compteur pour le WRR */
};

/* Quatre files, une par classe */
static struct aer_qos_queue queues[AER_QOS_NUM_CLASSES];

3. Algorithme WRR détaillé

/* Pseudo-code de l'ordonnanceur WRR */
function aer_qos_wrr_schedule():
    for i in 0..3:  // initialiser les déficits
        queues[i].deficit = queues[i].weight
    while there are packets:
        for i in 0..3:
            if queues[i].deficit > 0 AND queues[i].length > 0:
                packet = dequeue(queues[i])
                queues[i].deficit--
                return packet
        // cycle terminé, réinitialiser les déficits
        for i in 0..3:
            queues[i].deficit = queues[i].weight

4. Observabilité et debug

Le module produit des logs [QUEUE] permettant de suivre en temps réel l'état des files :

[QUEUE] Enqueue pkt=0x100 class=C0 len=3
[QUEUE] Dequeue pkt=0x100 class=C0 len=2
[QUEUE] WRR schedule: C0(6/6) C1(3/3) C2(2/2) C3(1/1)

5. Résumé

L'ordonnanceur WRR avec les poids 6:3:2:1 est le mécanisme central de différenciation QoS d'AER-MQoS. Il garantit que les paquets prioritaires sont servis plus fréquemment tout en évitant la famine des classes inférieures.
