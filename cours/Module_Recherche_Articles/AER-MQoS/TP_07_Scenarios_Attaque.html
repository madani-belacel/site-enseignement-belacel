TP 07 — Scénarios d'attaque

Type : Travail pratique — Durée : 1h30
Objectif : Exécuter des simulations avec attaques (rank anomaly, selective forwarding, mixed) et observer la résilience d'AER-MQoS via le Trust Score
Prérequis : TP 03, Cours 07 (Trust Score)
Telecharger PDF Telecharger PPTX

1. Types d'attaques simulées

AER-MQoS inclut trois scénarios d'attaque dans les simulations :

AttaqueComportement du nœud malveillantImpact attendu
Rank anomalyAnnonce un rank anormalement bas pour attirer le trafic (sinkhole)Augmentation du trafic vers l'attaquant, pertes possibles
Selective forwardingNe transmet qu'une partie des paquets reçusBaisse du PDR, augmentation des retransmissions
MixedCombine rank anomaly et selective forwardingEffet cumulé : attracteur + pertes

2. Localiser les fichiers d'attaque

Trouvez les fichiers de simulation d'attaque dans le dépôt :

find . -name "*attack*" -o -name "*attaque*" -o -name "*anomaly*"

Ils devraient se trouver dans simulations/attack/ ou similaire.

3. Lancer une simulation avec attaque rank anomaly

# Lancer la simulation avec attaque
./tools/cooja/cooja -nogui -contiki=.. \
  -simulation=simulations/attack/aer-attack-rank-anomaly.csc \
  > attack_rank.log 2>&1

4. Analyser les logs Trust Score

Extrayez les logs [TRUST] qui montrent l'évolution du score de confiance :

grep "\[TRUST\]" attack_rank.log > trust_logs.txt
head -20 trust_logs.txt

Le format typique :

[TRUST] Node:1.1.1.5 Neighbor:1.1.1.2 ETX=2.3 TrustScore=0.675
[TRUST] Node:1.1.1.5 Neighbor:1.1.1.3 ETX=1.2 TrustScore=0.950

5. Observer la pénalité d'anomalie

Cherchez dans les logs la détection d'anomalie :

grep -i "anomaly\|penalty\|suspect" attack_rank.log

Vous devriez voir des messages comme :

[TRUST] Anomaly detected: Node 1.1.1.3 rank_inconsistency
[TRUST] Penalty applied to 1.1.1.3: TrustScore 0.950 -> 0.475

6. Comparer PDR avec et sans attaque

Comparez les métriques de campagne :

grep "\[METRIC\]" attack_rank.log
grep "\[METRIC\]" campagne_grid_30.log  # simulation sans attaque

Quelle est la différence de PDR ? Comment le Trust Score a-t-il mitigé l'impact ?

7. Attaque selective forwarding

Répétez les étapes 3 à 6 avec le fichier d'attaque selective forwarding :

./tools/cooja/cooja -nogui -contiki=.. \
  -simulation=simulations/attack/aer-attack-selective-fwd.csc \
  > attack_selective.log 2>&1

8. Attaque mixte

Lancez la simulation d'attaque mixte (rank anomaly + selective forwarding) :

./tools/cooja/cooja -nogui -contiki=.. \
  -simulation=simulations/attack/aer-attack-mixed.csc \
  > attack_mixed.log 2>&1
