TP 12 — TP de synthèse AER-MQoS

Type : Travail pratique — Durée : 3h00 (hors temps de calcul)
Objectif : Réaliser le workflow complet AER-MQoS : compilation → simulation → parsing → analyse → publication de figures. Produire un mini-rapport d'évaluation comparative.
Prérequis : Tous les cours et TP précédents
Télécharger PDF Télécharger PPTX

1. Présentation du TP de synthèse

Ce TP final vous demande de réaliser l'ensemble du workflow d'évaluation d'AER-MQoS, de la compilation des firmwares à la production de figures comparatives exploitables pour un article.

2. Étape 1 : Compilation (TP 02)

cd /home/madani/contiki-ng/examples/AER-MQoS
git checkout v1.1
./scripts/build_variant.sh
find code_source_AER_MQoS -name "*.cooja" -exec ls -lh {} \;

3. Étape 2 : Simulation test (TP 03)

./tools/cooja/cooja -nogui -contiki=.. \
  -simulation=simulations/AER-MQoS-3nodes-template.csc > test_3nodes.log 2>&1
grep "\[METRIC\]" test_3nodes.log

4. Étape 3 : Campagne multi-seed (TP 08)

nohup ./scripts/run_multi_seed_campaign.sh > campagne_synthese.log 2>&1 &
echo "Campagne lancée, PID: $!"

5. Étape 4 : Parsing (TP 09)

python3 scripts/parse_cooja_metrics.py --dir logs/ --output synthese_metrics.csv

6. Étape 5 : Génération de figures (TP 10)

python3 << 'EOF'
import pandas as pd, matplotlib.pyplot as plt, seaborn as sns
sns.set_style('whitegrid')
df = pd.read_csv('synthese_metrics.csv')
fig, axes = plt.subplots(1, 3, figsize=(16, 5))
sns.barplot(data=df, x='variant', y='PDR', ax=axes[0], capsize=0.1)
axes[0].set_title('PDR global')
sns.barplot(data=df, x='variant', y='Latence_avg', ax=axes[1], capsize=0.1)
axes[1].set_title('Latence moyenne (ms)')
sns.barplot(data=df, x='variant', y='Energie_consommee', ax=axes[2], capsize=0.1)
axes[2].set_title('Energie consommée (mAh)')
plt.tight_layout()
plt.savefig('synthese_figures.png', dpi=200)
print("Figures de synthèse sauvegardées")
EOF

7. Mini-rapport de synthèse

Rédigez un mini-rapport (2-3 pages) contenant : introduction, méthodologie, résultats, analyse, figures et conclusion.

8. Critères d'évaluation

CritèrePoints
Compilation (4 variantes sans erreur)20%
Campagne (16 simulations terminées)20%
Parsing (fichier CSV correct)15%
Figures (3 graphiques clairs)20%
Rapport (analyse complète)25%
Félicitations ! Vous avez complété le parcours complet AER-MQoS, de la théorie à la pratique, en passant par la simulation, l'analyse et la reproduction de résultats scientifiques.
