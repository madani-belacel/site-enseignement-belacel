TP 12 — TP de synthèse AER-MQoS

Type : Travail pratique — Durée : 3h00 (hors temps de calcul)
Objectif : Réaliser le workflow complet AER-MQoS : compilation → simulation → parsing → analyse → publication de figures. Produire un mini-rapport d'évaluation comparative.
Prérequis : Tous les cours et TP précédents
Telecharger PDF Telecharger PPTX

1. Présentation du TP de synthèse

Ce TP final vous demande de réaliser l'ensemble du workflow d'évaluation d'AER-MQoS, de la compilation des firmwares à la production de figures comparatives exploitables pour un article. Vous travaillerez de manière autonome en suivant les étapes ci-dessous, et produirez un mini-rapport synthétisant vos résultats et conclusions.

2. Étape 1 : Compilation (TP 02)

Compilez les 4 variantes du protocole :

cd /home/madani/contiki-ng/examples/AER-MQoS
git checkout v1.1
./scripts/build_variant.sh
# Vérification
find code_source_AER_MQoS -name "*.cooja" -exec ls -lh {} \;

3. Étape 2 : Simulation test (TP 03)

Lancez une simulation de validation avec 3 nœuds pour vérifier que tout fonctionne :

./tools/cooja/cooja -nogui -contiki=.. \
  -simulation=simulations/AER-MQoS-3nodes-template.csc \
  > test_3nodes.log 2>&1
grep "\[METRIC\]" test_3nodes.log

4. Étape 3 : Campagne multi-seed (TP 08)

Lancez la campagne complète (16 simulations) :

nohup ./scripts/run_multi_seed_campaign.sh > campagne_synthese.log 2>&1 &
echo "Campagne lancée, PID: $!"

5. Étape 4 : Parsing (TP 09)

Pendant ou après la campagne, préparez le parsing :

# Vérifier l'avancement
tail -5 campagne_synthese.log
# Une fois terminée :
python3 scripts/parse_cooja_metrics.py --dir logs/ \
  --output synthese_metrics.csv
echo "Parsing terminé : $(wc -l synthese_metrics.csv) lignes"

6. Étape 5 : Analyse des queues et MCS (TP 05, TP 06)

Analysez les logs d'une simulation pour observer le comportement du WRR et du MCS :

# Analyse WRR
grep "\[QUEUE\] WRR schedule" logs/aer_mqos/20260601.log | head -10
# Analyse MCS
grep "\[MCS\]" logs/aer_mqos/20260601.log | head -10

7. Étape 6 : Génération de figures (TP 10)

Produisez les 3 figures principales :

python3 << 'EOF'
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
sns.set_style('whitegrid')
df = pd.read_csv('synthese_metrics.csv')

fig, axes = plt.subplots(1, 3, figsize=(16, 5))

# PDR
sns.barplot(data=df, x='variant', y='PDR', ax=axes[0], capsize=0.1)
axes[0].set_title('PDR global')
axes[0].tick_params(axis='x', rotation=15)

# Latence
sns.barplot(data=df, x='variant', y='Latence_avg', ax=axes[1], capsize=0.1)
axes[1].set_title('Latence moyenne (ms)')
axes[1].tick_params(axis='x', rotation=15)

# Énergie
sns.barplot(data=df, x='variant', y='Energie_consommee', ax=axes[2], capsize=0.1)
axes[2].set_title('Énergie consommée (mAh)')
axes[2].tick_params(axis='x', rotation=15)

plt.tight_layout()
plt.savefig('synthese_figures.png', dpi=200)
print("Figures de synthèse sauvegardées")
EOF

8. Étape 7 : Analyse statistique

Effectuez les tests de significativité :

python3 << 'EOF'
import pandas as pd
from scipy import stats
df = pd.read_csv('synthese_metrics.csv')
aer = df[df['variant']=='AER-MQoS']
for v in ['RPL-MRHOF', 'RPL-MQoS-style', 'RPL-AER-style']:
    other = df[df['variant']==v]
    t, p = stats.ttest_ind(aer['PDR'], other['PDR'])
    print(f"AER-MQoS vs {v} (PDR): t={t:.3f} p={p:.4f} {'***' if p<0.001 else '**' if p<0.01 else '*' if p<0.05 else 'ns'}")
EOF

9. Mini-rapport de synthèse

Rédigez un mini-rapport (2-3 pages) contenant :

  1. Introduction : rappel du contexte et des objectifs d'AER-MQoS (5 lignes)
  2. Méthodologie : variantes comparées, topologie, seeds, métriques (10 lignes)
  3. Résultats : tableau comparatif des métriques par variante
  4. Analyse : interprétation des résultats, compromis QoS vs énergie
  5. Figures : les 3 graphiques générés (PDR, latence, énergie)
  6. Conclusion : AER-MQoS est-il supérieur ? Dans quelles conditions ? (5 lignes)
