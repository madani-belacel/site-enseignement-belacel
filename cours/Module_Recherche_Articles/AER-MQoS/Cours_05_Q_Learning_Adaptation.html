Cours 05 — Q-learning pour l'adaptation des poids

Type : Cours théorique — Durée : 1h30
Objectif : Comprendre l'agent Q-learning qui adapte dynamiquement le poids gamma de la métrique MCS
Prérequis : Cours 03 (MCS), notions de base en apprentissage automatique
Télécharger PDF Télécharger PPTX

1. Pourquoi l'apprentissage par renforcement ?

Les réseaux IoT sont dynamiques : la qualité des liens fluctue, les nœuds s'épuisent énergétiquement, des attaques peuvent survenir. Un réglage statique des poids de la métrique MCS ne peut pas s'adapter à ces variations. L'apprentissage par renforcement (RL) permet à chaque nœud d'apprendre en ligne la meilleure politique d'ajustement du poids gamma, basée sur l'expérience locale.

2. Principes du Q-learning

Le Q-learning est un algorithme RL model-free qui apprend une fonction Q(s, a) estimant la qualité d'une action a dans un état s. La mise à jour suit l'équation de Bellman :

Q(s, a) = Q(s, a) + lr * [r + gamma_max * max_a' Q(s', a') - Q(s, a)]

3. Formalisation du problème d'adaptation de gamma

ComposantDéfinition
État (s)Tuple (PDR, énergie_moyenne, taux_anomalies) quantifié en 3 niveaux chacun → 27 états
Action (a)Modification de gamma : {−0.1, −0.05, 0, +0.05, +0.1} (5 actions discrètes)
Récompense (r)r = PDR * énergie_moyenne * TrustScore_moyen
Politiqueε-greedy : exploration (ε=0.1) ou exploitation (1−ε)

4. Implémentation dans aer_rpl_qlearn.c

/* Extrait simplifié de la mise à jour Q-learning */
void qlearn_update(uint8_t state, uint8_t action,
                   double reward, uint8_t next_state) {
    double max_next = q_table[next_state][0];
    for (int a = 1; a < NUM_ACTIONS; a++) {
        if (q_table[next_state][a] > max_next)
            max_next = q_table[next_state][a];
    }
    double td_error = reward + DISCOUNT * max_next - q_table[state][action];
    q_table[state][action] += LR * td_error;
}

5. Résumé

Le Q-learning permet à AER-MQoS d'ajuster dynamiquement le poids gamma de la confiance dans la métrique MCS, en apprenant de l'expérience locale de chaque nœud. Cette capacité d'adaptation distingue AER-MQoS des protocoles statiques.
