Cours 05 — Q-learning pour l'adaptation des poids

Type : Cours théorique — Durée : 1h30
Objectif : Comprendre l'agent Q-learning qui adapte dynamiquement le poids gamma de la métrique MCS
Prérequis : Cours 03 (MCS), notions de base en apprentissage automatique
Telecharger PDF Telecharger PPTX

1. Pourquoi l'apprentissage par renforcement ?

Les réseaux IoT sont dynamiques : la qualité des liens fluctue, les nœuds s'épuisent énergétiquement, des attaques peuvent survenir. Un réglage statique des poids de la métrique MCS ne peut pas s'adapter à ces variations. L'apprentissage par renforcement (RL) permet à chaque nœud d'apprendre en ligne la meilleure politique d'ajustement du poids gamma, basée sur l'expérience locale.

2. Principes du Q-learning

Le Q-learning est un algorithme RL model-free qui apprend une fonction Q(s, a) estimant la qualité d'une action a dans un état s. La mise à jour suit l'équation de Bellman :

Q(s, a) = Q(s, a) + lr * [r + gamma_max * max_a' Q(s', a') - Q(s, a)]

Où :

  • lr — taux d'apprentissage (learning rate)
  • r — récompense immédiate reçue après l'action
  • gamma_max — facteur d'actualisation (discount factor)
  • s' — nouvel état après l'action
  • max_a' Q(s', a') — estimation de la meilleure action future

3. Formalisation du problème d'adaptation de gamma

L'agent Q-learning d'AER-MQoS est défini par :

ComposantDéfinition
État (s)Tuple (PDR, énergie_moyenne, taux_anomalies) quantifié en 3 niveaux chacun → 27 états
Action (a)Modification de gamma : {−0.1, −0.05, 0, +0.05, +0.1} (5 actions discrètes)
Récompense (r)r = PDR * énergie_moyenne * TrustScore_moyen (produit des trois métriques)
Politiqueε-greedy : exploration (ε=0.1) ou exploitation (1−ε)

4. Implémentation dans aer_rpl_qlearn.c

Le module aer_rpl_qlearn.c implémente l'agent RL avec les fonctions :

  • qlearn_init() — initialise la Q-table à zéro
  • qlearn_get_state() — quantifie l'état réseau actuel (PDR, énergie, anomalies)
  • qlearn_select_action(state) — choisit une action selon ε-greedy
  • qlearn_update(state, action, reward, next_state) — met à jour Q(s, a)
  • qlearn_get_gamma() — retourne le gamma ajusté pour le calcul MCS
/* Extrait simplifié de la mise à jour Q-learning */
void qlearn_update(uint8_t state, uint8_t action,
                   double reward, uint8_t next_state) {
    double max_next = q_table[next_state][0];
    for (int a = 1; a < NUM_ACTIONS; a++) {
        if (q_table[next_state][a] > max_next)
            max_next = q_table[next_state][a];
    }
    double td_error = reward + DISCOUNT * max_next - q_table[state][action];
    q_table[state][action] += LR * td_error;
}

5. Exploration vs Exploitation

L'équilibre exploration/exploitation est géré par la politique ε-greedy :

  • Avec probabilité ε (0.1), l'agent choisit une action aléatoire (exploration)
  • Avec probabilité 1−ε, l'agent choisit l'action avec la Q-valeur maximale (exploitation)

Au fil du temps, ε peut décroître (annealing) pour favoriser l'exploitation après une phase d'exploration suffisante.

6. Convergence de l'apprentissage

Le Q-learning converge vers la politique optimale sous certaines conditions :

  • Tous les couples (état, action) doivent être visités infiniment souvent
  • Le taux d'apprentissage lr doit décroître avec le temps
  • L'environnement doit être stationnaire à long terme

Dans la pratique, l'agent AER-MQoS converge après 500 à 1000 itérations, ce qui correspond à quelques minutes de simulation Cooja. La convergence se traduit par une stabilisation de gamma autour d'une valeur optimale pour les conditions données.

7. Exemple d'adaptation

Supposons que le réseau subisse soudainement des pertes élevées (PDR chute à 60%). L'agent observe l'état (PDR_bas, énergie_moyenne, anomalies_faibles). Avec la politique ε-greedy, il peut essayer de réduire gamma (favoriser ETX plutôt que confiance) pour donner plus de poids à la fiabilité des liens. Si cette action augmente le PDR, la récompense positive renforce Q(état, réduire_gamma) et l'agent continuera à adopter ce comportement dans des situations similaires.

8. Intégration dans AER-MQoS

L'agent Q-learning fonctionne en parallèle du mécanisme de pondération contextuelle (Cours 03). La pondération contextuelle fournit une base de poids adaptée aux conditions immédiates, tandis que le Q-learning affine gamma pour optimiser la récompense à long terme. Les deux mécanismes sont complémentaires : l'un est réactif (contextuel), l'autre est proactif (apprentissage).

9. Résumé

Le Q-learning permet à AER-MQoS d'ajuster dynamiquement le poids gamma de la confiance dans la métrique MCS, en apprenant de l'expérience locale de chaque nœud. Cette capacité d'adaptation distingue AER-MQoS des protocoles statiques et améliore les performances dans des environnements IoT changeants.
