TP 09 — Parsing des logs de campagne

Type : Travail pratique — Durée : 1h00
Objectif : Extraire les données structurées des logs bruts en utilisant les scripts d'analyse, comprendre le format METRIC
Prérequis : TP 08 (logs générés), Python 3
Telecharger PDF Telecharger PPTX

1. Structure du module Aer_campaign_log

Le module Aer_campaign_log est intégré au firmware et produit en fin de simulation un résumé structuré [METRIC]. Examinez son implémentation dans le code source :

grep -n "METRIC" code_source_AER_MQoS/examples/aer-mqos/*.c

2. Format des logs METRIC

Chaque ligne [METRIC] contient les champs :

[METRIC] PDR=0.92
[METRIC] Latence_avg=45.3ms
[METRIC] Latence_max=187.2ms
[METRIC] Energie_consommee=127.5
[METRIC] NRE_min=0.31
[METRIC] C0_PDR=0.98
[METRIC] C1_PDR=0.94
[METRIC] C2_PDR=0.88
[METRIC] C3_PDR=0.79
[METRIC] Paquets_emis=1520
[METRIC] Paquets_recus=1398

3. Extraire les métriques d'un log

Utilisez la commande grep pour extraire les lignes METRIC d'un fichier de log :

grep "\[METRIC\]" logs/aer_mqos/20260601.log

4. Utiliser le script parse_cooja_metrics.py

Le dépôt fournit un script Python pour parser automatiquement les logs :

python3 scripts/parse_cooja_metrics.py logs/aer_mqos/20260601.log

Ce script extrait toutes les métriques et les affiche dans un format structuré (JSON ou CSV).

5. Parser tous les logs d'une campagne

Pour traiter l'ensemble des logs de la campagne multi-seed :

python3 scripts/parse_cooja_metrics.py --dir logs/ --output campaign_results.csv

Le fichier CSV produit aura une ligne par simulation avec toutes les métriques.

6. Vérifier les données parsées

Inspectez le fichier CSV généré :

head -5 campaign_results.csv
wc -l campaign_results.csv

Vérifiez que vous avez bien 16 lignes (4 variantes × 4 seeds) plus l'en-tête.

7. Parser les logs QUEUE et MCS

Le script peut également extraire les logs détaillés :

python3 scripts/parse_cooja_metrics.py --parse-queue --parse-mcs \
  --dir logs/ --output detailed_results/

Cette commande crée des fichiers séparés pour les données de files d'attente et de scores MCS.

8. Écrire un parser personnalisé

Pour aller plus loin, écrivez votre propre script de parsing :

python3 << 'EOF'
import csv, re, os
logs_dir = 'logs/'
rows = []
for root, dirs, files in os.walk(logs_dir):
    for fname in files:
        if fname.endswith('.log'):
            path = os.path.join(root, fname)
            variant = os.path.basename(root)
            seed = fname.replace('.log', '')
            with open(path) as f:
                metrics = {}
                for line in f:
                    m = re.search(r'\[METRIC\]\s+(\w+)=([0-9.]+)', line)
                    if m:
                        metrics[m.group(1)] = m.group(2)
                if metrics:
                    metrics['variant'] = variant
                    metrics['seed'] = seed
                    rows.append(metrics)
# Sauvegarder en CSV
with open('custom_metrics.csv', 'w', newline='') as f:
    if rows:
        w = csv.DictWriter(f, fieldnames=rows[0].keys())
        w.writeheader()
        w.writerows(rows)
print(f"Parsed {len(rows)} simulations -> custom_metrics.csv")
EOF
