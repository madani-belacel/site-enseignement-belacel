TP 10 — Génération de figures comparatives

Type : Travail pratique — Durée : 1h30
Objectif : Créer des graphiques comparatifs entre les 4 variantes (PDR, latence, énergie) avec barres d'erreur, exploitables pour publication
Prérequis : TP 09 (fichier CSV), matplotlib, seaborn, pandas

2. Diagramme comparatif PDR

Générez un diagramme à barres du PDR par variante :

python3 << 'EOF'
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.read_csv('campaign_results.csv')
sns.set_style('whitegrid')

fig, ax = plt.subplots(figsize=(10, 6))
sns.barplot(data=df, x='variant', y='PDR', capsize=0.1, ax=ax)
ax.set_title('PDR comparatif par variante', fontsize=14)
ax.set_xlabel('Variante')
ax.set_ylabel('PDR (%)')

# Ajouter les valeurs sur les barres
for p in ax.patches:
    ax.annotate(f'{p.get_height():.2f}', 
                (p.get_x() + p.get_width()/2., p.get_height()),
                ha='center', va='bottom')

plt.tight_layout()
plt.savefig('pdr_comparison.png', dpi=150)
print("Figure sauvegardée: pdr_comparison.png")
EOF

3. Comparatif PDR par classe

Créez un graphique montrant le PDR par classe (C0 à C3) pour chaque variante :

python3 << 'EOF'
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('campaign_results.csv')
classes = ['C0_PDR', 'C1_PDR', 'C2_PDR', 'C3_PDR']
fig, axes = plt.subplots(2, 2, figsize=(12, 10))
axes = axes.flatten()

for i, variant in enumerate(df['variant'].unique()):
    ax = axes[i]
    vdata = df[df['variant'] == variant]
    means = [vdata[c].mean() for c in classes]
    stds = [vdata[c].std() for c in classes]
    ax.bar(classes, means, yerr=stds, capsize=5)
    ax.set_title(f'PDR par classe - {variant}')
    ax.set_ylabel('PDR (%)')
    ax.set_ylim(0, 1)

plt.tight_layout()
plt.savefig('pdr_by_class.png', dpi=150)
print("Figure sauvegardée: pdr_by_class.png")
EOF

4. Comparatif latence et énergie

Générez un graphique combiné latence + énergie :

python3 << 'EOF'
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('campaign_results.csv')
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(14, 5))

# Latence
variants = df.groupby('variant')['Latence_avg'].agg(['mean', 'std'])
ax1.bar(variants.index, variants['mean'], yerr=variants['std'], capsize=5)
ax1.set_title('Latence moyenne par variante')
ax1.set_ylabel('Latence (ms)')

# Energie
variants_e = df.groupby('variant')['Energie_consommee'].agg(['mean', 'std'])
ax2.bar(variants_e.index, variants_e['mean'], yerr=variants_e['std'], capsize=5)
ax2.set_title('Consommation énergétique par variante')
ax2.set_ylabel('Énergie (mAh)')

plt.tight_layout()
plt.savefig('latency_energy_comparison.png', dpi=150)
print("Figure sauvegardée: latency_energy_comparison.png")
EOF

5. Analyse statistique (test de Student)

Vérifiez si les différences entre AER-MQoS et RPL-MRHOF sont statistiquement significatives :

python3 << 'EOF'
from scipy import stats
import pandas as pd

df = pd.read_csv('campaign_results.csv')
aer = df[df['variant'] == 'AER-MQoS']['PDR']
mrhof = df[df['variant'] == 'RPL-MRHOF']['PDR']
t_stat, p_value = stats.ttest_ind(aer, mrhof)
print(f"Test de Student AER-MQoS vs RPL-MRHOF:")
print(f"  t-statistique = {t_stat:.4f}")
print(f"  p-value = {p_value:.4f}")
if p_value < 0.05:
    print("  -> Différence significative (p < 0.05)")
else:
    print("  -> Pas de différence significative")
EOF

6. Figure publication-ready

Pour une figure exploitable dans un article, personnalisez le style :

python3 << 'EOF'
import pandas as pd
import matplotlib.pyplot as plt
# Style pour publication
plt.rcParams.update({
    'font.family': 'serif',
    'font.size': 11,
    'axes.labelsize': 12,
    'axes.titlesize': 13,
    'legend.fontsize': 10,
})
df = pd.read_csv('campaign_results.csv')
fig, ax = plt.subplots(figsize=(8, 5))
colors = ['#2ecc71', '#3498db', '#e74c3c', '#f39c12']
variants = ['RPL-MRHOF', 'RPL-MQoS-style', 'RPL-AER-style', 'AER-MQoS']
for i, v in enumerate(variants):
    vdata = df[df['variant'] == v]
    ax.errorbar(i, vdata['PDR'].mean(), yerr=vdata['PDR'].std(),
                fmt='o', color=colors[i], capsize=6, capthick=2,
                markersize=10, label=v)
ax.set_xticks(range(4))
ax.set_xticklabels(variants, rotation=15, ha='right')
ax.set_ylabel('PDR')
ax.set_title('Comparaison PDR global')
ax.legend()
ax.grid(axis='y', alpha=0.3)
plt.tight_layout()
plt.savefig('pdr_publication_figure.png', dpi=300)
print("Figure publication-ready sauvegardée")
EOF
