TP 06 — Analyse des scores MCS

Type : Travail pratique — Durée : 1h00
Objectif : Analyser les logs [MCS] pour extraire les poids alpha/beta/gamma, observer leur variation contextuelle et corréler avec les conditions réseau
Prérequis : TP 04, notions de la métrique MCS (Cours 03)
Telecharger PDF Telecharger PPTX

1. Extraire les logs [MCS]

Les logs [MCS] contiennent les scores calculés pour chaque parent candidat. Extrayez-les :

grep "\[MCS\]" campagne_grid_30.log > mcs_logs.txt
wc -l mcs_logs.txt

2. Structure des logs [MCS]

Chaque ligne [MCS] a le format suivant :

[MCS] Timestamp:120500 Node:1.1.1.5 Parent:1.1.1.2 score=0.8475 (alpha=0.30 beta=0.35 gamma=0.35)
[MCS] Timestamp:120500 Node:1.1.1.5 Parent:1.1.1.3 score=0.7231 (alpha=0.30 beta=0.35 gamma=0.35)

On y trouve :

  • Le timestamp et le nœud qui calcule
  • L'adresse du parent candidat
  • Le score MCS calculé
  • Les poids alpha, beta, gamma utilisés

3. Analyser la distribution des poids

Extrayez les poids uniques utilisés :

grep -oP 'alpha=\K[0-9.]+' mcs_logs.txt | sort | uniq -c
grep -oP 'beta=\K[0-9.]+' mcs_logs.txt | sort | uniq -c
grep -oP 'gamma=\K[0-9.]+' mcs_logs.txt | sort | uniq -c

Comparez avec les poids contextuels théoriques du Cours 03.

4. Suivre l'évolution temporelle de gamma

Si le Q-learning est actif, gamma peut varier. Tracez son évolution :

python3 << 'EOF'
import re
with open('mcs_logs.txt') as f:
    lines = f.readlines()
# Extraire timestamps et gamma
data = []
for line in lines:
    m = re.search(r'Timestamp:(\d+).*gamma=([0-9.]+)', line)
    if m:
        data.append((int(m.group(1)), float(m.group(2))))
# Afficher les points de changement
prev = None
for ts, g in data:
    if g != prev:
        print(f"Timestamp {ts}: gamma={g}")
        prev = g
EOF

5. Corréler MCS avec ETX et NRE

Comparez les scores MCS avec les valeurs d'ETX et de NRE pour vérifier la cohérence :

python3 << 'EOF'
import re
# Lire les logs MCS et ENERGY
with open('mcs_logs.txt') as f:
    mcs_lines = f.readlines()
# Extraire quelques échantillons
for line in mcs_lines[:20]:
    m = re.search(r'Node:(\S+) Parent:(\S+) score=([0-9.]+)'
                  r' alpha=([0-9.]+) beta=([0-9.]+) gamma=([0-9.]+)', line)
    if m:
        node, parent, score, a, b, g = m.groups()
        print(f"Node {node} -> Parent {parent}: MCS={score} "
              f"(a={a} b={b} g={g})")
EOF

6. Vérifier la sélection du parent

Pour un nœud donné, vérifiez que le parent avec le score MCS le plus élevé est choisi :

python3 << 'EOF'
import re
from collections import defaultdict
with open('mcs_logs.txt') as f:
    lines = f.readlines()
# Pour chaque nœud et timestamp, trouver le meilleur parent
candidates = defaultdict(list)
for line in lines:
    m = re.search(r'Timestamp:(\d+) Node:(\S+) Parent:(\S+) score=([0-9.]+)', line)
    if m:
        ts, node, parent, score = m.groups()
        candidates[(ts, node)].append((float(score), parent))
for key in sorted(candidates.keys())[:5]:
    ts, node = key
    best = max(candidates[key], key=lambda x: x[0])
    print(f"T{ts} {node}: best={best[1]} score={best[0]}")
EOF

7. Corrélation avec les conditions réseau

Croisez les logs MCS avec les logs de performance (PDR, énergie) pour observer comment les poids s'adaptent :

# Extraire les PDR par intervalle
grep "PDR" campagne_grid_30.log | head -5
# Comparer avec les poids MCS au même moment

Quand le PDR est bas, beta devrait augmenter. Quand l'énergie est faible, alpha devrait augmenter.
