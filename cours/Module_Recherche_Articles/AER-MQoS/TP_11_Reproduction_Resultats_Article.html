TP 11 — Reproduction des résultats de l'article

Type : Travail pratique — Durée : 2h00 (hors temps de calcul)
Objectif : Reproduire les résultats expérimentaux de l'article AER-MQoS en utilisant la release v1.1
Prérequis : Tous les TP précédents
Télécharger PDF Télécharger PPTX

1. Utiliser la release v1.1

cd /home/madani/contiki-ng/examples/AER-MQoS
git checkout v1.1
git log --oneline -1

2. Compiler les 4 variantes

./scripts/build_variant.sh
find code_source_AER_MQoS -name "*.cooja" -o -name "*.sky"

3. Lancer la campagne multi-seed complète

nohup ./scripts/run_multi_seed_campaign.sh > reproduction_v1.1.log 2>&1 &

4. Extraire les métriques

python3 scripts/parse_cooja_metrics.py --dir logs/ --output reproduction_metrics.csv

5. Comparer avec les résultats de l'article

python3 << 'EOF'
import pandas as pd
df = pd.read_csv('reproduction_metrics.csv')
reference = {
    'RPL-MRHOF':     {'PDR': 0.78, 'Latence_avg': 67.2},
    'RPL-MQoS-style':{'PDR': 0.85, 'Latence_avg': 52.1},
    'RPL-AER-style': {'PDR': 0.76, 'Latence_avg': 71.8},
    'AER-MQoS':      {'PDR': 0.92, 'Latence_avg': 45.3},
}
for variant in df['variant'].unique():
    vdata = df[df['variant'] == variant]
    pdr_mean = vdata['PDR'].mean()
    lat_mean = vdata['Latence_avg'].mean()
    ref = reference.get(variant, {})
    print(f"{variant}: PDR={pdr_mean:.3f} (art:{ref.get('PDR','N/A')}) Lat={lat_mean:.1f} (art:{ref.get('Latence_avg','N/A')})")
    if ref:
        print(f"  Ecart PDR: {abs(pdr_mean-ref['PDR'])/ref['PDR']*100:.1f}%")
EOF
✅ Vérification : Les écarts entre résultats reproduits et ceux de l'article doivent être inférieurs à 5%.
  1. Les résultats reproduits sont-ils cohérents avec ceux de l'article ?
  2. Y a-t-il des écarts significatifs ? Si oui, pourquoi ?
  3. Que peut-on conclure sur la reproductibilité des résultats ?
