TP 11 — Reproduction des résultats de l'article

Type : Travail pratique — Durée : 2h00 (hors temps de calcul)
Objectif : Reproduire les résultats expérimentaux de l'article AER-MQoS en utilisant la release v1.1, en suivant pas à pas le protocole de reproduction
Prérequis : Tous les TP précédents
Telecharger PDF Telecharger PPTX

1. Utiliser la release v1.1

Pour garantir la reproductibilité exacte, utilisez la release v1.1 taguée sur GitHub :

# Les codes sont déjà présents localement
# Si nécessaire, cloner depuis GitHub:
# git clone https://github.com/madani-belacel/AER-MQoS.git
cd /home/madani/contiki-ng/examples/AER-MQoS
git checkout v1.1
git log --oneline -1

2. Compiler les 4 variantes

Compilez les firmwares comme au TP 02 :

./scripts/build_variant.sh

Vérifiez que tous les binaires sont présents :

ls -lh code_source_AER_MQoS/*.cooja 2>/dev/null
# ou chercher les binaires
find code_source_AER_MQoS -name "*.cooja" -o -name "*.sky"

3. Lancer la campagne multi-seed complète

C'est l'étape la plus longue. Lancez les 16 simulations :

nohup ./scripts/run_multi_seed_campaign.sh > \
  reproduction_v1.1.log 2>&1 &

Pendant que les simulations tournent, notez les temps de début et de fin.

4. Extraire les métriques

Une fois la campagne terminée, extrayez les résultats :

python3 scripts/parse_cooja_metrics.py --dir logs/ \
  --output reproduction_metrics.csv

5. Comparer avec les résultats de l'article

L'article présente des tableaux de résultats et des figures. Comparez :

python3 << 'EOF'
import pandas as pd
# Résultats reproduits
df = pd.read_csv('reproduction_metrics.csv')
# Résultats de l'article (valeurs de référence)
reference = {
    'RPL-MRHOF':  {'PDR': 0.78, 'Latence_avg': 67.2},
    'RPL-MQoS-style': {'PDR': 0.85, 'Latence_avg': 52.1},
    'RPL-AER-style':  {'PDR': 0.76, 'Latence_avg': 71.8},
    'AER-MQoS':   {'PDR': 0.92, 'Latence_avg': 45.3},
}
for variant in df['variant'].unique():
    vdata = df[df['variant'] == variant]
    pdr_mean = vdata['PDR'].mean()
    lat_mean = vdata['Latence_avg'].mean()
    ref = reference.get(variant, {})
    print(f"\n{variant}:")
    print(f"  PDR: reproduit={pdr_mean:.3f} article={ref.get('PDR','N/A')}")
    print(f"  Latence: reproduit={lat_mean:.1f} article={ref.get('Latence_avg','N/A')}")
    if ref:
        pdr_err = abs(pdr_mean - ref['PDR']) / ref['PDR'] * 100
        print(f"  Écart PDR: {pdr_err:.1f}%")
EOF

6. Générer les figures de l'article

Utilisez les scripts de génération de figures fournis :

python3 scripts/generate_figures.py --input reproduction_metrics.csv \
  --output figures/

Comparez les figures générées avec celles de l'article (mêmes axes, mêmes échelles).

7. Vérifier l'analyse statistique

Effectuez les tests statistiques :

python3 << 'EOF'
from scipy import stats
import pandas as pd
df = pd.read_csv('reproduction_metrics.csv')
# ANOVA pour comparer les 4 variantes
variants_groups = [df[df['variant'] == v]['PDR'] 
                   for v in df['variant'].unique()]
f_stat, p_value = stats.f_oneway(*variants_groups)
print(f"ANOVA: F={f_stat:.4f} p={p_value:.6f}")
if p_value < 0.001:
    print("Différence hautement significative (p<0.001)")
# Post-hoc : comparer AER-MQoS à chaque variante
aer = df[df['variant'] == 'AER-MQoS']['PDR']
for v in df['variant'].unique():
    if v == 'AER-MQoS':
        continue
    other = df[df['variant'] == v]['PDR']
    t, p = stats.ttest_ind(aer, other)
    print(f"AER-MQoS vs {v}: t={t:.4f} p={p:.6f}")
EOF

8. Documenter la reproduction

Créez un rapport de reproduction contenant :

  1. Les informations sur l'environnement (OS, version Contiki-NG, version Cooja, Java)
  2. Le hash du commit utilisé (git rev-parse HEAD)
  3. Les résultats reproduits sous forme de tableau
  4. Les figures reproduites
  5. Les tests statistiques et leur interprétation
  6. Les éventuels écarts par rapport à l'article et leur explication

  3. Les figures générées sont-elles visuellement similaires à celles de l'article ?
