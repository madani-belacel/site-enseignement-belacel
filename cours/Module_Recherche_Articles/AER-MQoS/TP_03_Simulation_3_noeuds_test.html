TP 03 — Simulation test avec 3 nœuds

Type : Travail pratique — Durée : 1h00
Objectif : Lancer une première simulation AER-MQoS avec 3 nœuds, vérifier la connectivité RPL et observer les logs QoS
Prérequis : TP 02 (firmware compilé), Cooja installé
Télécharger PDF Télécharger PPTX

1. Localiser le template de simulation

find . -name "*3nodes*" -o -name "*3-noeuds*"

2. Lancer Cooja

cd contiki-ng/tools/cooja
ant run

3. Lancer la simulation sans interface graphique

./tools/cooja/cooja -nogui -contiki=.. -simulation=simulations/AER-MQoS-3nodes-template.csc > logs_3nodes.txt 2>&1

4. Observer les logs attendus

[QUEUE] Enqueue pkt=0x100 class=C0 len=1
[QUEUE] WRR schedule: serving class C0 (deficit=5)
[RPL] DIO sent from 1.1.1.1
[QUEUE] Dequeue pkt=0x100 class=C0 len=0
[MCS] Parent 1.1.1.2 score=0.8475 (alpha=0.30 beta=0.35 gamma=0.35)
[ENERGY] Node 1.1.1.3 NRE=0.97
✅ Vérification : Vérifiez que le DODAG se forme correctement, que les paquets C0 sont servis avant les autres classes et que le ratio de service correspond à 6:3:2:1.
⚠️ Dépannage : Si Cooja ne démarre pas, vérifiez la variable JAVA_HOME et la présence de Java : java -version.
  1. Combien de paquets C0, C1, C2, C3 ont été transmis ?
  2. Quel est le PDR global ? Et par classe ?
  3. Le DODAG s'est-il correctement formé ?
