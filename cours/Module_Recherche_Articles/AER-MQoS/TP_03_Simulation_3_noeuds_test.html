TP 03 — Simulation test avec 3 nœuds

Type : Travail pratique — Durée : 1h00
Objectif : Lancer une première simulation AER-MQoS avec 3 nœuds, vérifier la connectivité RPL et observer les logs QoS
Prérequis : TP 02 (firmware compilé), Cooja installé
Telecharger PDF Telecharger PPTX

1. Localiser le template de simulation

Le dépôt AER-MQoS contient des fichiers de simulation Cooja prêts à l'emploi. Trouvez le template 3 nœuds :

find . -name "*3nodes*" -o -name "*3-noeuds*"

Le fichier devrait être AER-MQoS-3nodes-template.csc dans le dossier simulations/.

2. Lancer Cooja

Démarrez Cooja depuis le répertoire Contiki-NG :

cd contiki-ng/tools/cooja
ant run

Ou utilisez le script s'il existe :

./tools/cooja/cooja

3. Ouvrir le template de simulation

Dans Cooja :

  1. Menu File → Open Simulation
  2. Naviguez vers AER-MQoS-3nodes-template.csc
  3. Ouvrez le fichier

La simulation doit montrer 3 nœuds : un puits (sink), un nœud intermédiaire et un nœud source.

4. Examiner la configuration

Avant de lancer, examinez les paramètres :

  • Radio medium : UDGM (Unit Disk Graph Medium) avec pertes paramétrées
  • Durée de simulation : typiquement 60 secondes
  • Application : l'application UDP génère des paquets de différentes classes (C0, C1, C2, C3)
  • Firmware : le binaire compilé au TP 02 doit être associé à chaque nœud

5. Lancer la simulation

Cliquez sur le bouton Start dans Cooja. Observez la sortie console (Tools → Serial Socket ou Mote output).

Vous devriez voir des logs de type :

[QUEUE] Enqueue pkt=0x100 class=C0 len=1
[QUEUE] WRR schedule: serving class C0 (deficit=5)
[RPL] DIO sent from 1.1.1.1
[QUEUE] Dequeue pkt=0x100 class=C0 len=0
[MCS] Parent 1.1.1.2 score=0.8475 (alpha=0.30 beta=0.35 gamma=0.35)
[ENERGY] Node 1.1.1.3 NRE=0.97

6. Vérifier la connectivité RPL

Utilisez les logs RPL pour vérifier :

  • La formation du DODAG
  • L'échange de messages DIO et DAO
  • La sélection du parent préféré par chaque nœud
  • La transmission de paquets de données du source vers le puits

7. Observer la différenciation QoS

Le template 3 nœuds génère des paquets de différentes classes. Vérifiez dans les logs :

  • Que les paquets C0 sont servis avant les autres classes
  • Que le ratio de service correspond approximativement à 6:3:2:1
  • Que les files d'attente sont correctement gérées

8. Arrêter la simulation et collecter les logs

Après 60 secondes, arrêtez la simulation. Sauvegardez la sortie console dans un fichier :

# Si vous utilisez le mode terminal
./tools/cooja/cooja -nogui -contiki=.. -simulation=simulations/AER-MQoS-3nodes-template.csc > logs_3nodes.txt 2>&1

9. Questions

  1. Combien de paquets C0, C1, C2, C3 ont été transmis ?
  2. Quel est le PDR global ? Et par classe ?
  3. Le DODAG s'est-il correctement formé ?
  4. Y a-t-il des pertes ? Lesquelles et pourquoi ?
