🗣️ Dialogue 1 — What is the Internet?

Student: Sir, what is the Internet in simple words?
Monsieur, qu'est-ce qu'Internet en termes simples ?
Teacher: The Internet is a worldwide network that connects millions of computers and allows them to exchange data.
Internet est un réseau mondial qui connecte des millions d'ordinateurs et leur permet d'échanger des données.
Student: Is it like a big highway?
Est-ce comme une grande autoroute ?
Teacher: Yes. We often call it the information highway because data travels across it at high speed.
Oui. On l'appelle souvent l'autoroute de l'information parce que les données y circulent à grande vitesse.
Student: Who owns the Internet?
Qui possède Internet ?
Teacher: Nobody owns it. It is a collection of networks managed by many organisations around the world.
Personne ne le possède. C'est un ensemble de réseaux gérés par de nombreuses organisations dans le monde.

🗣️ Dialogue 2 — What is a network?

Student: What do we mean by a network?
Qu'entend-on par réseau ?
Teacher: A network is a set of connected devices that can communicate with each other.
Un réseau est un ensemble d'appareils connectés qui peuvent communiquer entre eux.
Student: Can a network be small?
Un réseau peut-il être petit ?
Teacher: Yes. A home network with a few devices connected to a Wi-Fi router is already a network.
Oui. Un réseau domestique avec quelques appareils connectés à un routeur Wi-Fi est déjà un réseau.
Student: And the Internet is the biggest network?
Et Internet est le plus grand réseau ?
Teacher: Exactly. It is the network of networks.
Exactement. C'est le réseau des réseaux.

🗣️ Dialogue 3 — What is Wi-Fi?

Student: What is Wi-Fi exactly?
Qu'est-ce que le Wi-Fi exactement ?
Teacher: Wi-Fi is a wireless technology that connects your devices to a network or to the Internet without cables.
Le Wi-Fi est une technologie sans fil qui connecte vos appareils à un réseau ou à Internet sans câbles.
Student: Is Wi-Fi the same as the Internet?
Le Wi-Fi est-il la même chose qu'Internet ?
Teacher: No. Wi-Fi is only the wireless connection. The Internet is the global network you reach through that connection.
Non. Le Wi-Fi n'est que la connexion sans fil. Internet est le réseau mondial que vous atteignez grâce à cette connexion.
Student: Can I have Wi-Fi without Internet?
Puis-je avoir le Wi-Fi sans Internet ?
Teacher: Yes. You can create a local Wi-Fi network at home even if the Internet is not working.
Oui. Vous pouvez créer un réseau Wi-Fi local à la maison même si Internet ne fonctionne pas.

🗣️ Dialogue 4 — Internet vs the Web

Student: Are the Internet and the Web the same thing?
Internet et le Web sont-ils la même chose ?
Teacher: No. This is a very common confusion. The Internet is the network. The Web is one of the services that runs on it.
Non. C'est une confusion très courante. Internet est le réseau. Le Web est l'un des services qui fonctionnent dessus.
Student: What other services exist on the Internet?
Quels autres services existent sur Internet ?
Teacher: E-mail, instant messaging, file transfer, video conferencing, and many others.
Le courriel, la messagerie instantanée, le transfert de fichiers, la visioconférence, et bien d'autres.
Student: So when I open Chrome, I am using the Web?
Donc quand j'ouvre Chrome, j'utilise le Web ?
Teacher: Yes. The browser allows you to access the World Wide Web.
Oui. Le navigateur vous permet d'accéder au World Wide Web.

🗣️ Dialogue 5 — What is a website and a web page?

Student: What is the difference between a website and a web page?
Quelle est la différence entre un site web et une page web ?
Teacher: A website is a collection of pages about the same topic, available at one main address. A web page is a single document on that site.
Un site web est un ensemble de pages sur le même sujet, disponible à une adresse principale. Une page web est un document unique sur ce site.
Student: Can you give an example?
Pouvez-vous donner un exemple ?
Teacher: The university website is a site. The page with the exam timetable is one web page of that site.
Le site de l'université est un site. La page avec le calendrier des examens est une page web de ce site.
Student: What language are web pages written in?
Dans quel langage les pages web sont-elles écrites ?
Teacher: Mainly in HTML, often with CSS for design and JavaScript for interactivity.
Principalement en HTML, souvent avec CSS pour le design et JavaScript pour l'interactivité.

🗣️ Dialogue 6 — What is a web browser?

Student: What is a browser and why do we need it?
Qu'est-ce qu'un navigateur et pourquoi en a-t-on besoin ?
Teacher: A browser is a program that allows you to access and view websites. Without a browser you cannot surf the Web.
Un navigateur est un programme qui vous permet d'accéder et de visualiser les sites web. Sans navigateur vous ne pouvez pas naviguer sur le Web.
Student: What are the most common browsers?
Quels sont les navigateurs les plus courants ?
Teacher: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, and Opera.
Google Chrome, Mozilla Firefox, Microsoft Edge, Safari et Opera.
Student: Is it better to use only one browser?
Est-il préférable d'utiliser un seul navigateur ?
Teacher: It is good to know at least two. Sometimes a website works better on one browser than on another.
Il est bon d'en connaître au moins deux. Parfois un site fonctionne mieux sur un navigateur que sur un autre.

🗣️ Dialogue 7 — What is a URL?

Student: What does URL mean?
Que signifie URL ?
Teacher: URL means Uniform Resource Locator. It is the full address of a web page or a file on the Internet.
URL signifie Uniform Resource Locator. C'est l'adresse complète d'une page web ou d'un fichier sur Internet.
Student: Can you explain the parts of a URL?
Pouvez-vous expliquer les parties d'une URL ?
Teacher: For example in https://www.example.com/page: “https” is the protocol, “www.example.com” is the domain name, and “/page” is the path.
Par exemple dans https://www.example.com/page : « https » est le protocole, « www.example.com » est le nom de domaine, et « /page » est le chemin.
Student: Why is https better than http?
Pourquoi https est-il mieux que http ?
Teacher: Because the “s” means secure. The connection is encrypted and safer for personal data.
Parce que le « s » signifie sécurisé. La connexion est chiffrée et plus sûre pour les données personnelles.

🗣️ Dialogue 8 — How search engines work

Student: How does a search engine like Google find information?
Comment un moteur de recherche comme Google trouve-t-il l'information ?
Teacher: Search engines use programs called crawlers or spiders that visit web pages, read them, and index the content.
Les moteurs de recherche utilisent des programmes appelés crawlers ou spiders qui visitent les pages web, les lisent et indexent le contenu.
Student: What happens when I type a query?
Que se passe-t-il quand je tape une requête ?
Teacher: The search engine looks in its index and shows the pages that best match your keywords, ranked by relevance.
Le moteur de recherche regarde dans son index et affiche les pages qui correspondent le mieux à vos mots-clés, classées par pertinence.
Student: Does Google visit every page in real time?
Google visite-t-il chaque page en temps réel ?
Teacher: No. It shows results from its index, which is updated regularly but not instantly for every page.
Non. Il montre des résultats de son index, qui est mis à jour régulièrement mais pas instantanément pour chaque page.

🗣️ Dialogue 9 — Effective search techniques

Student: How can I search more effectively?
Comment puis-je rechercher plus efficacement ?
Teacher: Use precise keywords, put exact expressions between quotation marks, and use filters when necessary.
Utilisez des mots-clés précis, mettez les expressions exactes entre guillemets, et utilisez les filtres quand c'est nécessaire.
Student: How do I search for an exact phrase?
Comment rechercher une expression exacte ?
Teacher: Put the phrase between quotation marks. For example: "teach English online".
Mettez l'expression entre guillemets. Par exemple : "teach English online".
Student: How can I find only PDF files?
Comment trouver uniquement des fichiers PDF ?
Teacher: Add filetype:pdf to your search. For example: digital literacy filetype:pdf.
Ajoutez filetype:pdf à votre recherche. Par exemple : digital literacy filetype:pdf.

🗣️ Dialogue 10 — Using the minus sign and other operators

Student: How can I exclude a word from my search results?
Comment puis-je exclure un mot de mes résultats de recherche ?
Teacher: Put a minus sign just before the word you want to exclude. For example: apple -fruit.
Mettez un signe moins juste avant le mot que vous voulez exclure. Par exemple : apple -fruit.
Student: What other useful operators exist?
Quels autres opérateurs utiles existent ?
Teacher: You can use site: to search only on one website, or OR to look for one term or another.
Vous pouvez utiliser site: pour chercher uniquement sur un site, ou OR pour chercher un terme ou un autre.
Student: Can you give an example with site:?
Pouvez-vous donner un exemple avec site: ?
Teacher: Yes: “ICT education site:edu” will look for the expression mainly on educational websites.
Oui : « ICT education site:edu » cherchera l'expression principalement sur des sites éducatifs.

🗣️ Dialogue 11 — Evaluating online sources – the CRAP test

Student: How can we know if an online source is reliable?
Comment savoir si une source en ligne est fiable ?
Teacher: One useful method is the CRAP test: Currency, Reliability, Authority and Purpose.
Une méthode utile est le test CRAP : Currency, Reliability, Authority et Purpose.
Student: What does Currency mean?
Que signifie Currency ?
Teacher: It means checking the date of publication and whether the information is still up to date.
Cela signifie vérifier la date de publication et si l'information est encore à jour.
Student: And Authority?
Et Authority ?
Teacher: Authority means checking who wrote the text and what their qualifications and affiliation are.
Authority signifie vérifier qui a écrit le texte et quelles sont ses qualifications et son affiliation.

🗣️ Dialogue 12 — Why purpose matters

Student: Why do we need to check the purpose of a source?
Pourquoi devons-nous vérifier le but d'une source ?
Teacher: Because some texts try to sell a product, promote an idea, or persuade the reader instead of simply informing.
Parce que certains textes cherchent à vendre un produit, promouvoir une idée, ou persuader le lecteur au lieu de simplement informer.
Student: How can I recognise a biased source?
Comment reconnaître une source biaisée ?
Teacher: Look at the language: emotional words, lack of sources, one-sided arguments, or hidden advertising are warning signs.
Regardez le langage : mots émotionnels, absence de sources, arguments à sens unique, ou publicité cachée sont des signes d'alerte.
Student: Should we always cross-check information?
Devons-nous toujours recouper les informations ?
Teacher: Yes. Good researchers never rely on a single source, especially on the open Web.
Oui. Les bons chercheurs ne se fient jamais à une seule source, surtout sur le Web ouvert.

🗣️ Dialogue 13 — Google Scholar and academic research

Student: What is Google Scholar?
Qu'est-ce que Google Scholar ?
Teacher: Google Scholar is a search engine specialised in scientific articles, theses, books and academic publications.
Google Scholar est un moteur de recherche spécialisé dans les articles scientifiques, les thèses, les livres et les publications académiques.
Student: Is it better than normal Google for university work?
Est-il meilleur que Google normal pour le travail universitaire ?
Teacher: Yes, for academic work it is much more relevant because it focuses on scholarly sources.
Oui, pour le travail académique il est beaucoup plus pertinent car il se concentre sur les sources savantes.
Student: Can we find free articles there?
Pouvons-nous y trouver des articles gratuits ?
Teacher: Sometimes yes. Many authors deposit free versions of their papers. Always check the access options.
Parfois oui. Beaucoup d'auteurs déposent des versions gratuites de leurs articles. Vérifiez toujours les options d'accès.

🗣️ Dialogue 14 — National and institutional digital libraries

Student: Are there other good academic platforms besides Google Scholar?
Y a-t-il d'autres bonnes plateformes académiques en plus de Google Scholar ?
Teacher: Yes. In Algeria we have the SNDL (Système National de Documentation en Ligne). Many universities also have their own digital libraries.
Oui. En Algérie nous avons le SNDL (Système National de Documentation en Ligne). Beaucoup d'universités ont aussi leurs propres bibliothèques numériques.
Student: What kind of resources can we find on the SNDL?
Quel type de ressources peut-on trouver sur le SNDL ?
Teacher: Scientific journals, e-books, theses and databases that are not freely available on the open Web.
Des revues scientifiques, des livres numériques, des thèses et des bases de données qui ne sont pas librement disponibles sur le Web ouvert.
Student: Do we need a special account?
Avons-nous besoin d'un compte spécial ?
Teacher: Usually yes. Access is often given through the university network or with institutional credentials.
Habituellement oui. L'accès est souvent donné via le réseau universitaire ou avec des identifiants institutionnels.

🗣️ Dialogue 15 — Bookmarks and organisation

Student: How can we organise the useful websites we find?
Comment organiser les sites utiles que nous trouvons ?
Teacher: Use the bookmark function of your browser and create folders by topic: “Grammar”, “Listening”, “Academic writing”, etc.
Utilisez la fonction de signets de votre navigateur et créez des dossiers par thème : « Grammaire », « Écoute », « Écriture académique », etc.
Student: Is it better than copying the URL in a document?
Est-ce mieux que de copier l'URL dans un document ?
Teacher: Both methods are useful. Bookmarks are quick to access. A document allows you to add comments and share the list.
Les deux méthodes sont utiles. Les signets sont rapides d'accès. Un document vous permet d'ajouter des commentaires et de partager la liste.
Student: Can we synchronise bookmarks across devices?
Pouvons-nous synchroniser les signets entre appareils ?
Teacher: Yes. If you sign in to Chrome or Firefox with an account, your bookmarks can follow you on different computers.
Oui. Si vous vous connectez à Chrome ou Firefox avec un compte, vos signets peuvent vous suivre sur différents ordinateurs.

🗣️ Dialogue 16 — Tabs, history and privacy

Student: What is the difference between a window and a tab?
Quelle est la différence entre une fenêtre et un onglet ?
Teacher: A window is a separate browser instance. Tabs allow you to open several pages inside the same window.
Une fenêtre est une instance séparée du navigateur. Les onglets permettent d'ouvrir plusieurs pages dans la même fenêtre.
Student: What is the browser history?
Qu'est-ce que l'historique du navigateur ?
Teacher: It is the list of websites you have visited. You can use it to find a page again or clear it for privacy.
C'est la liste des sites que vous avez visités. Vous pouvez l'utiliser pour retrouver une page ou l'effacer pour la confidentialité.
Student: When should we use private or incognito mode?
Quand devons-nous utiliser le mode privé ou navigation privée ?
Teacher: When you do not want the browser to save your history, cookies or temporary files on that device.
Quand vous ne voulez pas que le navigateur enregistre votre historique, vos cookies ou fichiers temporaires sur cet appareil.

🗣️ Dialogue 17 — Cookies and tracking

Student: What are cookies?
Que sont les cookies ?
Teacher: Cookies are small files that websites store on your computer to remember information about your visit.
Les cookies sont de petits fichiers que les sites web stockent sur votre ordinateur pour se souvenir d'informations sur votre visite.
Student: Are all cookies dangerous?
Tous les cookies sont-ils dangereux ?
Teacher: No. Some are useful (for example to stay logged in). Others are used for advertising and tracking.
Non. Certains sont utiles (par exemple pour rester connecté). D'autres sont utilisés pour la publicité et le pistage.
Student: How can we control them?
Comment pouvons-nous les contrôler ?
Teacher: Through the browser settings you can block third-party cookies, delete existing ones, or accept them only on certain sites.
Via les paramètres du navigateur vous pouvez bloquer les cookies tiers, supprimer ceux qui existent, ou les accepter seulement sur certains sites.

🗣️ Dialogue 18 — Safe browsing habits

Student: What simple habits make browsing safer?
Quelles habitudes simples rendent la navigation plus sûre ?
Teacher: Check that the site uses https, do not click on suspicious links, avoid downloading unknown files, and keep the browser updated.
Vérifiez que le site utilise https, ne cliquez pas sur des liens suspects, évitez de télécharger des fichiers inconnus, et gardez le navigateur à jour.
Student: What should we do if a site looks strange?
Que faire si un site paraît étrange ?
Teacher: Leave it immediately. Do not enter any personal information or password.
Quittez-le immédiatement. N'entrez aucune information personnelle ni mot de passe.
Student: Is public Wi-Fi safe for important activities?
Le Wi-Fi public est-il sûr pour les activités importantes ?
Teacher: Not really. Avoid online banking or entering passwords on public Wi-Fi unless you use a reliable VPN.
Pas vraiment. Évitez les opérations bancaires ou la saisie de mots de passe sur le Wi-Fi public sauf si vous utilisez un VPN fiable.

🗣️ Dialogue 19 — The Internet for English language learning

Student: How can we use the Internet specifically to improve our English?
Comment utiliser Internet spécifiquement pour améliorer notre anglais ?
Teacher: You can watch authentic videos, listen to podcasts, read online articles, join language forums, and use interactive exercises.
Vous pouvez regarder des vidéos authentiques, écouter des podcasts, lire des articles en ligne, rejoindre des forums linguistiques, et utiliser des exercices interactifs.
Student: Which sites do you recommend for beginners?
Quels sites recommandez-vous pour les débutants ?
Teacher: BBC Learning English, British Council LearnEnglish, VOA Learning English, and simple graded readers online.
BBC Learning English, British Council LearnEnglish, VOA Learning English, et de simples lectures graduées en ligne.
Student: Is YouTube useful for learning English?
YouTube est-il utile pour apprendre l'anglais ?
Teacher: Yes, if you choose good channels and activate subtitles when necessary. It is an excellent source of authentic input.
Oui, si vous choisissez de bonnes chaînes et activez les sous-titres si nécessaire. C'est une excellente source d'input authentique.

🗣️ Dialogue 20 — Conclusion: Become a smart Internet user

Student: What should we remember from this course on the Internet?
Que devons-nous retenir de ce cours sur Internet ?
Teacher: Remember that the Internet is a powerful network, the Web is only one of its services, and searching effectively requires both technique and critical thinking.
Retenez qu'Internet est un réseau puissant, que le Web n'est qu'un de ses services, et que rechercher efficacement demande à la fois de la technique et de l'esprit critique.
Student: What is the most important skill for us as future teachers?
Quelle est la compétence la plus importante pour nous en tant que futurs enseignants ?
Teacher: The ability to find reliable information quickly, evaluate sources, and guide students toward quality digital resources.
La capacité à trouver rapidement une information fiable, à évaluer les sources, et à guider les étudiants vers des ressources numériques de qualité.
Student: Thank you, sir. I feel more confident about using the Internet for my studies.
Merci, monsieur. Je me sens plus confiant pour utiliser Internet dans mes études.
Teacher: Very good. Next time we will study online communication and e-mail. See you soon.
Très bien. La prochaine fois nous étudierons la communication en ligne et le courriel. À bientôt.
