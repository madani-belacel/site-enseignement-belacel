Comprendre le code : l'IA comme professeur particulierUnderstand code: AI as a private teacherفهم الكود: الذكاء الاصطناعي كمدرّس خصوصي

Ne demandez jamais « fais mon TP » : demandez « explique-moi ». Un étudiant qui comprend 10 programmes expliqués progresse ; celui qui rend 10 programmes générés stagne.

  • Prompt explication : « Explique ce code ligne par ligne, comme à un débutant : [coller le code]. »
  • Prompt algorithme : « Explique la recherche du maximum dans une liste avec un exemple chiffré pas à pas. »
  • Prompt comparaison : « Quelle est la différence entre une boucle for et while ? Un exemple chacun. »
🧩 🔗 Rappel séance 6 : le tuteur socratique posait des questions au lieu de donner les réponses. Aujourd'hui, on le CODE : notre script posera des questions à Gemini au lieu de tout faire à notre place.

Never ask "do my assignment": ask "explain to me". A student who understands 10 explained programs progresses; one who submits 10 generated programs stagnates.

  • Explanation prompt: "Explain this code line by line, like to a beginner: [paste code]."
  • Algorithm prompt: "Explain finding the maximum in a list with a step-by-step number example."
  • Comparison prompt: "What is the difference between for and while loops? One example each."
🧩 🔗 Reminder of session 6: the Socratic tutor asked questions instead of giving answers. Today, we CODE it: our script will ask Gemini questions instead of doing everything for us.

لا تطلب « أنجز واجبي » أبداً: اطلب « اشرح لي ». الطالب الذي يفهم عشرة برامج مشروحة يتقدّم؛ ومن يسلّم عشرة برامج مولّدة يراوح.

  • صياغة الشرح: « اشرح هذا الكود سطراً سطراً كمبتدئ: [الصق الكود] ».
  • صياغة الخوارزمية: « اشرح البحث عن أكبر عنصر في قائمة بمثال رقمي خطوة بخطوة ».
  • صياغة المقارنة: « ما الفرق بين حلقتي for وwhile؟ مثال لكل منهما ».
🧩 🔗 تذكير بالحصة 6: المدرّس السقراطي كان يطرح أسئلة بدل إعطاء الأجوبة. اليوم سنبرمجه: برنامجنا سيطرح أسئلة على Gemini بدل فعل كل شيء بدلاً منا.

Déboguer : lire l'erreur avant de la réparerDebug: read the error before fixing itتصحيح الأخطاء: اقرأ الخطأ قبل إصلاحه

Un message d'erreur n'est pas une insulte : c'est une adresse (le numéro de ligne) et un diagnostic (le type d'erreur). Montrez les deux à l'IA, et demandez d'abord le POURQUOI.

  • Méthode en 3 temps : 1) lire la dernière ligne de l'erreur ; 2) demander « pourquoi cette erreur ? » ; 3) seulement ensuite « comment corriger ? ».
  • Prompt modèle : « Voici mon code [coller] et l'erreur [coller]. Explique la cause en 2 phrases, puis propose UNE correction. »
  • Erreurs classiques PEP : indentation, deux-points oubliés, variable non définie, mélange de types.
💡 Astuce : après la correction, demandez « donne-moi un mini-exercice similaire pour vérifier que j'ai compris ». La boucle est bouclée : erreur → cause → correction → vérification.
🧩 🧪 Exemple concret : moyenne = total / nombre. Une TypeError mélangeant texte et nombres → cause : un âge lu comme texte → correction : int(age). Demandez ensuite un exercice similaire avec des notes.

An error message is not an insult: it is an address (the line number) and a diagnosis (the error type). Show both to AI, and ask for the WHY first.

  • 3-step method: 1) read the last line of the error; 2) ask "why this error?"; 3) only then "how to fix?"
  • Model prompt: "Here is my code [paste] and the error [paste]. Explain the cause in 2 sentences, then suggest ONE fix."
  • Classic PEP mistakes: indentation, missing colons, undefined variable, mixed types.
💡 Tip: after the fix, ask "give me a similar mini-exercise to check I understood". The loop is closed: error → cause → fix → check.
🧩 🧪 Concrete example: average = total / count. A TypeError mixing text and numbers → cause: an age read as text → fix: int(age). Then ask for a similar exercise with grades.

رسالة الخطأ ليست إهانة: بل عنوان (رقم السطر) وتشخيص (نوع الخطأ). اعرضهما على الذكاء الاصطناعي، واطلب لماذا أولاً.

  • منهجية بثلاث خطوات: 1) اقرأ آخر سطر من الخطأ؛ 2) اسأل « لماذا هذا الخطأ؟ »؛ 3) ثم فقط « كيف أصلح؟ ».
  • صياغة نموذجية: « هذا كودي [الصق] والخطأ [الصق]. اشرح السبب في جملتين، ثم اقترح تصحيحاً واحداً ».
  • أخطاء PEP الكلاسيكية: المسافة البادئة، نقطتان منسيتان، متغير غير معرّف، خلط الأنواع.
💡 نصيحة: بعد التصحيح اطلب « أعطني تمريناً مصغّراً مشابهاً لأتحقق أني فهمت ». الحلقة مكتملة: خطأ ← سبب ← تصحيح ← تحقق.
🧩 🧪 مثال ملموس: المعدل = المجموع / العدد. خطأ نوع يخلط نصاً وأعداداً ← السبب: عمر مقروء كنص ← التصحيح: int(age). ثم اطلب تمريناً مشابهاً بالعلامات.

Le mini-projet : votre assistant qui appelle GeminiThe mini-project: your assistant calling Geminiالمشروع المصغّر: مساعدك الذي يستدعي Gemini

Une API (interface de programmation) est un guichet : votre script envoie du texte, le modèle géant répond. Avec une clé gratuite, 15 lignes de Python suffisent pour avoir VOTRE chatbot.

  1. Clé gratuite : aller sur ai.google.dev → « Get API key » → copier (comme un mot de passe, jamais partagée).
  2. Installer : python -m pip install google-generativeai dans le terminal.
  3. Copier le script assistant_chat.py ci-dessous, coller la clé, exécuter : python assistant_chat.py.
  4. Tester : poser 3 questions de révision de votre module préféré.
# assistant_chat.py -- mini assistant IA (projet seance 07)
# Installation : python -m pip install google-generativeai
import google.generativeai as genai

# 1. Cle gratuite sur https://ai.google.dev (ne jamais la partager !)
genai.configure(api_key="COLLE_TA_CLE_ICI")

# 2. Choix du modele (rapide et gratuit)
model = genai.GenerativeModel("gemini-2.0-flash")

print("Assistant IA pour etudiant (tape 'quit' pour sortir)")
while True:
    question = input("\nToi > ")
    if question.lower() in ("quit", "exit"):
        break
    reponse = model.generate_content(question)
    print("IA   >", reponse.text)
⚠️ 🔒 Sécurité : la clé API, c'est un mot de passe payant. Jamais dans un devoir rendu, jamais sur GitHub, jamais en photo. Si elle fuite, la régénérer sur ai.google.dev.

  2. Install: python -m pip install google-generativeai in the terminal.
  3. Copy the assistant_chat.py script below, paste the key, run: python assistant_chat.py.
  4. Test: ask 3 revision questions from your favourite module.

Aller plus loin : Copilot, Cursor et la mémoireGo further: Copilot, Cursor and memoryللمضي أبعد: Copilot وCursor والذاكرة

Deuxième étage de la fusée : les assistants intégrés à l'éditeur (complétion pendant la frappe) et l'historique (le chatbot qui se souvient).

  • Cursor / Copilot : écrivez un commentaire « # fonction qui calcule la moyenne », laissez l'outil proposer le code, LISEZ-LE avant d'accepter.
  • Mémoire : la version assistant_memoire.py garde les 6 derniers échanges : testez « et en arabe ? » après une question.
  • Limite : l'assistant écrit vite mais ne comprend pas votre TP — seul votre test (exécution + cas limites) valide.
# assistant_memoire.py -- meme assistant, AVEC memoire de conversation
import google.generativeai as genai

genai.configure(api_key="COLLE_TA_CLE_ICI")
model = genai.GenerativeModel("gemini-2.0-flash")

# Nouveaute : l'historique garde le contexte des questions precedentes
historique = []

print("Assistant avec memoire (tape 'quit' pour sortir)")
while True:
    question = input("\nToi > ")
    if question.lower() in ("quit", "exit"):
        break
    historique.append("Etudiant : " + question)
    prompt = "\n".join(historique[-6:])  # les 6 derniers echanges
    reponse = model.generate_content(prompt)
    historique.append("IA : " + reponse.text)
    print("IA   >", reponse.text)

Comment en profiter au maximumHow to get the most out of itكيف تستفيد إلى أقصى حد

Le programmeur augmenté : l'IA propose, vous disposez. Chaque ligne générée est relue, exécutée et testée — c'est ce qui distingue l'étudiant de l'opérateur de copier-coller.

🎯 ➡️ Pont vers la séance 8 : un programme qui écrit bien impressionne, mais un étudiant qui écrit bien convainc : votre assistant servira aussi à relire vos textes (correction expliquée, séance 8).
  • ✅ Explique-moi d'abord : toujours comprendre avant de rendre.
  • ✅ Une erreur = une leçon : noter la cause dans un carnet de bugs.
  • ✅ Versionnez : garder assistant_chat.py puis assistant_memoire.py (voir la progression).
  • ✅ Testez les limites : question vide, très longue, en arabe dialectal — que se passe-t-il ?
⚠️ ❌ Erreurs à éviter : rendre du code non exécuté, partager sa clé API, croire que « ça marche une fois » = « c'est correct » (tester les cas limites).

📖 Glossaire📖 Glossary📖 مسرد المصطلحات

API — API

Guichet logiciel : votre programme envoie une demande, le service (Gemini) répond.

A software counter: your program sends a request, the service (Gemini) answers.

شبّاك برمجي: برنامجك يرسل طلباً، والخدمة (Gemini) تجيب.

Clé API — API key

Mot de passe personnel qui identifie vos appels au service ; gratuite mais facturable, à protéger.

A personal password identifying your calls to the service; free but billable, protect it.

كلمة مرور شخصية تعرّف استدعاءاتك للخدمة؛ مجانية لكن قابلة للفوترة، احمها.

Débogage — Debugging

Art de trouver la cause d'une erreur (lire, diagnostiquer) avant de la corriger.

The art of finding an error's cause (read, diagnose) before fixing it.

فن إيجاد سبب الخطأ (اقرأ، شخّص) قبل تصحيحه.

Bibliothèque (package) — Library (package)

Code prêt à l'emploi qu'on installe (pip install) pour utiliser un service comme Gemini.

Ready-to-use code you install (pip install) to use a service like Gemini.

كود جاهز يُثبَّت (pip install) لاستعمال خدمة مثل Gemini.

Historique de conversation — Conversation history

Échanges précédents renvoyés au modèle pour qu'il garde le contexte.

Previous exchanges resent to the model so it keeps context.
